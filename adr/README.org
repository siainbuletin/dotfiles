#+title: Architecture decision records
#+startup: overview

Decisions about how I work with AI-made changes on this repository, one file each. The top-level [[file:../README.org::*Reviewing and merging AI-made changes on macOS][README.org]] only summarises the current choices and links here for the reasons.

Each record has a status (accepted, superseded or rejected), the context, the decision, the alternatives that were considered and the consequences. To change a decision, write a new record that supersedes the old one and set the old one's =#+status:= to =superseded by NNNN=; do not rewrite history.

*Not verified on my Mac.* The records were written from a Linux container. Tool behaviour comes from each project's documentation and source, and anything I have not tried is marked /untested/.
