#+title: Dotfiles changelog
#+startup: overview

Changes to the dotfiles that are not the Emacs configuration: the repository layout, the other tools' settings and the scripts around them. Changes to the Emacs configuration are in [[file:emacs-modular/.config/emacs-modular/CHANGELOG.org][the Emacs changelog]]. Changes are grouped by the feature they build or fix. Within a set the pull requests follow the order they depend on each other, the base first. Each line starts with its pull request number, then the author, then what happened: ✨ Added, 🔧 Changed, 🐛 Fixed, 🔥 Removed, 💡 Proposed; the category headings are not repeated.

* Moving from yadm to Stow
/2026-11-02 to 2026-11-07./ The repository is a normal Git repository in =~/dotfiles= with one Stow package per tool, not a yadm repository on =$HOME=. The Emacs side of the move (=emacs-pr=, Magit, =sp-dotfiles-dir=) is in the Emacs changelog under "Reviewing and merging in Magit".

- [[https://github.com/siainbuletin/dotfiles/pull/271][#271]] (Claude) ✨ Added =stow-migration/=: a package map (=packages.tsv=), =migrate.sh= with preflight, backup, restructure, dry run, cutover, verify, retire and rollback (files Stow replaces go to a backup folder, never deleted), a guide, and ADR 0023. Nothing is moved by merging it. Rehearsed in a scratch home folder on Linux with Stow 2.3.1.
- [[https://github.com/siainbuletin/dotfiles/pull/274][#274]] (Sia) 🔧 Changed the repository layout: every tracked file moved into a Stow package, one per tool, with =git mv= so history follows; the yadm alternates became the =alacritty-darwin=, =alacritty-linux= and =alacritty-windows= packages; =.Xauthority=, the yadm config and the old blacklist =.gitignore= are dropped; the CI workflow paths follow. The Emacs configuration is now in =emacs-modular/.config/emacs-modular/=.
- [[https://github.com/siainbuletin/dotfiles/pull/287][#287]] (Claude) 🔧 Changed ADR 0001 to "superseded by 0023", with a short dated note and its text untouched, and ADR 0023 to "accepted", with a new section "Why I chose Stow after all": easier versioning, docs and Magit, sync problems, and untracked files slowing branches in VSCode and SourceGit.
- [[https://github.com/siainbuletin/dotfiles/pull/293][#293]] (Claude) 🔧 Changed the Stow guide: how to get pulled changes into Emacs (=git pull= in =~/dotfiles=, =stow -R= only when files are added or removed), the "cannot stow ... neither a link nor a directory" error with its cause and why not to use plain =stow=, =--adopt= or =yadm pull=, and =STALE=ok= for =migrate.sh=, which lets =dryrun= and =cutover= continue when the home files are only older copies of repo files (the old versions still go to the backup). Follows #271.
- [[https://github.com/siainbuletin/dotfiles/pull/307][#307]] (Claude) 🔧 Changed the Stow guide =stow-migration/README.md= into =README.org= and updated the three references to it (=migrate.sh=, ADR 0023 and the =sp-vcontrol= doc).

* One layer key for window managers
/2026-11-04 to 2026-11-07./ Option is Meta in Emacs on the Mac, so AeroSpace, i3 and sway stop binding Alt/Option and share one layer key, Caps Lock held. Design: "Same keys on macOS, Linux and Windows" in [[file:emacs-modular/.config/emacs-modular/docs/architecture/global-keymap-namespaces.org][the keymap design]]. The Emacs side of the same pull request is in the Emacs changelog under "Global keybindings in one keymap per feature".

- [[https://github.com/siainbuletin/dotfiles/pull/284][#284]] (Claude) 🔧 Changed =aerospace.toml=: the main-mode =alt-*= bindings are gone (hold Caps Lock plus =h/j/k/l=, =1=-=9=, =a b d e m t w=, =Tab=, =/=, =,= instead; Caps Lock plus =Shift+;= enters service mode, whose joins are =shift-hjkl=). ✨ Added =hammerspoon/.config/hammerspoon/aerospace-keys.lua=: Caps Lock becomes F18 (=hidutil=) and F18 held plus the old key runs the same =aerospace= command. 🔧 Changed i3 (=setxkbmap -option caps:super=, dmenu on =$mod+d= instead of Alt+Space) and sway (=$mod= is Mod4, =xkb_options caps:super=). Windows has no window manager here. Not run on any system (none in the container); the =aerospace= path in =aerospace-keys.lua= needs checking.
- [[https://github.com/siainbuletin/dotfiles/pull/296][#296]] (Claude) 🔧 Changed i3 and sway so that nothing binds Mod4 and the Windows key reaches Emacs: Caps Lock becomes the Level 3 shift (=lv3:caps_switch=, Mod5) and =$mod= is =Mod5=, replacing the =caps:super= of #284; it is the same physical layer key as AeroSpace on the Mac. Not taken: =caps:hyper= (Hyper often shares Mod4 in X), Alt as =$mod= (clashes with Meta) and Ctrl+Alt chords. Caveat: Caps+letter yields AltGr-level characters on layouts that have them, but the window manager grabs the bound combinations first. Not run in i3 or sway (none in the container).
- [[https://github.com/siainbuletin/dotfiles/pull/305][#305]] (Claude) 🐛 Fixed Hammerspoon failing at load with =attempt to index a boolean value (global 'stackline')=, which stopped the AeroSpace keys: =init.lua= loads =aerospace-keys= first and wraps stackline in =pcall=. stackline itself stays broken (empty =stackline.lua=).
- [[https://github.com/siainbuletin/dotfiles/pull/306][#306]] (Claude) ✨ Added =aerospace.org=, a literate source that tangles to =aerospace.toml= (unchanged), explaining every setting and why Hammerspoon runs the keys.
- [[https://github.com/siainbuletin/dotfiles/pull/309][#309]] (Claude) 🐛 Fixed the Caps Lock layer not opening when Shift is held first (move window, move to workspace): the layer key is also bound with Shift. A diagnosis from the code, not run on the Mac.
- [[https://github.com/siainbuletin/dotfiles/pull/312][#312]] (Claude) 🐛 Fixed AeroSpace's service mode having no way out: =esc= now runs =mode main= before =reload-config=, and Caps+Esc runs =aerospace mode main=. Not run on the Mac.
- [[https://github.com/siainbuletin/dotfiles/pull/313][#313]] (Claude) 🔧 Changed Caps+Shift+; to toggle the service mode (leave it with the key that enters it), using =aerospace list-modes --current=. Follows #312.
- [[https://github.com/siainbuletin/dotfiles/pull/322][#322]] (Claude) ✨ Added Caps+Ctrl+h/j/k/l to run =aerospace join-with= directly, so windows can always be stacked (the service-mode =shift-hjkl= clashed with the layer's move keys).
- [[https://github.com/siainbuletin/dotfiles/pull/323][#323]] (Claude) 🔧 Changed =aerospace.org= and =aerospace.toml= to =config-version = 2= with =persistent-workspaces = []=, which also removes the =reload-config= warning; behaviour is unchanged.

* DEVONthink PDFs from Finder and Alfred
/2026-11-11./ Opening a PDF indexed in DEVONthink from outside Emacs. The Emacs side is in the Emacs changelog under "DEVONthink, litdb and literature notes".

- [[https://github.com/siainbuletin/dotfiles/pull/379][#379]] (Claude) ✨ Added =devonthink-open= (macOS): Finder and Alfred open an indexed PDF in its DEVONthink record. One applet reads the settings, resolves symlinks, looks the PDF up in every open database and opens the item link or the fallback viewer; =dt-open= is removed and the package is listed as macOS only in =stow-migration/packages.tsv=. Not run on a Mac when merged.
- [[https://github.com/siainbuletin/dotfiles/pull/382][#382]] (Claude) 🐛 Fixed =devonthink-open= losing the old PDF viewer: it stays as the fallback and the applet can log why a lookup failed. Follows #379.
