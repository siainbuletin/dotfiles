**** What

The posframe is a fixed 75% of the frame width again, for every command including =M-x=, instead of following the length of the prompt. This is the setup of #144 with no change: =sp-posframe-width-fraction= (0.75) and =sp-posframe-get-size=, which sets =:width=, =:min-width= and =:max-width= of the size from =vertico-posframe-get-size= and leaves the height to the package. It is wired in through =vertico-posframe-size-function=.

Nothing else comes back with it: no prompt styling, no dotted line, no dimming, no text size reset of the posframe. This is step 3 of the rebuild plan in the doc, taken as its own pull request so a bug points at one change.

Docs (=sp-posframe.org=) and CHANGELOG updated.
