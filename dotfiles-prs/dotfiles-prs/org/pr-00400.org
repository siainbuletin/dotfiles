**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- Emacs printed =Fetch dir data failed with error: (end-of-file)= at startup.

**** Cause
:PROPERTIES:
:CUSTOM_ID: cause
:END:
- The message comes from Dirvish (=dirvish--dir-data-async=), not from an Info =dir= file.
- =tabspaces= restores the saved session at startup, including a dired buffer (=~/Documents/writing/thesis/chapters/= in =var/tabspaces-session.eld=).
- That opens a Dirvish buffer while Emacs is still starting, and its background directory scan returns nothing.

**** Fix
:PROPERTIES:
:CUSTOM_ID: fix
:END:
- Register the =dired= buffer kind in =sp-tabs= with =#'ignore= for save and restore.
- Dired buffers are no longer saved, and old dired records in the session file are skipped.
- Same change in =docs/tangles/ui/sp-tabs.org= (new section with bullets).

:CUSTOM_ID: not-tested
:END:
- Emacs cannot boot the real config in the cloud container.
- Not confirmed that the child process is killed mid-run rather than failing; this fix removes the trigger either way.
