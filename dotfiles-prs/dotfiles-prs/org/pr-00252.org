Two modules differed from what their docs tangle to on =main=. The docs are authoritative, so the =.el= files follow them:

- *=sp-org-tag-groups.el=*: the committed file had the old =sp-org-tag-group-of= and no =sp-org-tag-groups--explicit-groups=, which the new =sp-org-tag-group-of= calls, so any tag lookup would signal a void function. Re-tangled.

The third difference on =main=, =sp-search.el=, is fixed in #253.

=tools/check-tangle.sh= shows no difference for these two modules in Emacs 29.3 batch. Not run in the interactive config.
