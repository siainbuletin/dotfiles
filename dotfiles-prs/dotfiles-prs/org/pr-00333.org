- Adds =sp-author-notes-works-dryrun= (preview, writes nothing) and =sp-author-notes-works-convert= (writes), named per ADR 0025, for the author note in the current buffer.
- Formatting is reused, not duplicated: the lint's =sp-author-notes--person-pass= and =sp-author-notes-works-spec=.
- *Edited works:* a second table under an =Edited works= heading lists works whose =pub-editor= links to the person and whose =pub-author= does not (=sp-author-notes-edited-spec=). New spec key =:except-prop= in the query tables makes that exclusion.
- *Lint:* =sp-author-notes= adds the =Edited works= heading and table only to a person linked under =pub-editor= in some litnote (a mistyped key counts). Everyone else gets the =Works= table alone.
- *Works commands:* add the second table only when the database has a work the person only edited.
- *BibTeX:* =sp-author-notes-bibtex= reads =editor= fields (editor-only entries too) and links a litnote with =pub-editor= when the person only edited the entry.
- Docs (bullet lists) in =docs/tangles/funct/sp-org-lint.org= and the query-tables doc; tests added; no CHANGELOG edits.
