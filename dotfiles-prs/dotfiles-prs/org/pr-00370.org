**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- =org-semantic-binary-install= failed with =Wrong type argument: number-or-marker-p, "Killed: 9"=.
  - macOS SIGKILLed the freshly copied binary when the installer ran =--version=.
  - =process-file= returns a string on a signal, and the package calls =zerop= on it.
- =sp-semantic.el= now:
  - deletes the old binary before an install, so the new copy gets a fresh inode;
  - wraps =org-semantic-binary-version=: on that error it removes the quarantine flag, signs ad hoc (=codesign --force --sign -=), and retries once;
  - installs the binary under =var/org-semantic/= (git-ignored) instead of the top of the config.
- The 40 MB binary was tracked in the repo and symlinked by Stow, so installs wrote through the symlink into the repo. It is deleted from the tree here.
- Doc updated in =docs/tangles/academic/sp-semantic.org= (bullet list) with the tangled =.el=.
