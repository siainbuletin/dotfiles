Replaces #22, which GitHub would not reopen after its branch was rebased (#18 to #20 are merged into =main=, so this PR is no longer stacked).

*Before:* about thirty modules spelled out =~/notes=, =~/bibliography=, =~/Documents/literature=, =~/src= and the like, so the configuration only worked with one machine's layout and a test run could not be kept away from the real notes. =init.el= ended in a Custom block with a list of =/Users/siainbuletin/notes/...= agenda files, which made =org-agenda= open every one of them. The system modules sat in their own =env/= directory.

*After:*

- A new first module, =sp-paths=, names each location once (=sp-notes-dir=, =sp-documents-dir=, =sp-literature-dir=, =sp-bibliography-dir=, =sp-org-dir=, =sp-src-dir=, =sp-git-dir=, =sp-clones-dir=, =sp-data-home=, =sp-yadm-repo=, =sp-chrome-history-file=) and offers =sp-path= to build a path below one. The modules use these instead of literals. Each location can be overridden from the environment (=SP_NOTES_DIR=, =SP_BIBLIOGRAPHY_DIR=, =SP_DOCUMENTS_DIR=, =SP_ORG_DIR=, =SP_SRC_DIR=, =SP_GIT_DIR=, =SP_CLONES_DIR=, =XDG_DATA_HOME=). Defaults come from =~=, and the Chrome history path has a macOS, Windows and Linux default.
- =env/= moves to =base/= (=sp-env=, =sp-exwm=, =sp-macos=, =sp-syslinux=, =sp-syswin=), in =libraries/modules/= and in =docs/tangles/=. The tangle paths, =docs/main.org= and =conditional-loading.org= follow. =sp-env= requires =sp-paths= and explains in its commentary that the =SP_*= overrides are read before the shell environment is imported.
- The whole Custom block at the end of =init.el= is removed, so =sp-vulpea-para= decides which agenda files load.

*Behaviour notes:*

- On your Mac every path default resolves to what it was before.
- Removing the Custom block also drops what it set besides the agenda files (fonts, =sia/modeline=, =custom-safe-themes=, =package-selected-packages=, =helm-minibuffer-history-key=, =transient-show-menu=, =bibtex-aux-opt-alist= and the four =org-extra-emphasis= faces). They fall back to defaults until set in a module.

*How:* the literate sources in =docs/tangles/= are edited together with the modules. The branch content is the same as #22 (rebased onto =main= with the merged #20); I did not start the full configuration, so please try a launch on your Mac.
