** Description
Found with the Terminal test of =findLink=: =Can't get every «class DTcn» of "/Users/.../file.pdf". (-1728)=. Inside =tell application id "DNtp"=, =contents of candidate= is read as DEVONthink's "content" class, so the lookup never worked and every PDF opened in the fallback viewer.

- =findLink= loops over the paths outside the tell block; =linkInDatabases= gets a plain text variable; =waitForDatabases= holds the wait loop.
- Settings errors are kept (=cfgError=) and logged even with debug off. Open question: =readConfig= returned =cfgDebug:false= for a config with ~DT_OPEN_DEBUG=1~; the cause is not known yet, the error will now show in =tell s to readConfig()= and in the log.
