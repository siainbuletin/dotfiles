** Description
/Requested by *Sia*/

*Removed:* the minor-mode count. The square with =0f0431= was the Material Design puzzle glyph (=nerd-icons-mdicon "nf-md-puzzle"=), missing from the font in use; the whole segment is gone (=C-h m=, or a click on the major mode box, lists the modes).

*mode-line-maker* ([[https://github.com/rougier/mode-line-maker][rougier/mode-line-maker]], installed with =use-package :ensure (:host github ...)=): the left and right parts of the bottom line are now aligned and truncated by it.

- Lambda: =sp-modeline-parts-compose= calls =mode-line-maker--make= (private function, the public =mode-line-maker= returns a format and lambda-line wants a string); falls back to the old =:align-to= space if the package is missing.
- Prot: =sp-prot-modeline-format= stays one list, split at =mode-line-format-right-align= and given to =mode-line-maker=.
- =mode-line-maker-alignment= and =-truncation-rule= apply to both; the padding face follows the theme.

*Clocked task widget* (=clock= segment, right side, boxed keyword in the fourth accent colour):

- Shows keyword, heading (cut to =sp-modeline-parts-clock-width=) and clocked time while an entry is clocked in; nothing otherwise. =mouse-1= goes to the entry, =mouse-3= opens =org-agenda=.
- On clock-in an entry that already has an open todo keyword is switched to =sp-modeline-parts-clock-keyword= (=PROG=, in =sp-org-keywords=; =nil= to keep the state; not set if you already set =org-clock-in-switch-to-state=).
- Fringe arrow on the clocked heading from =org-clock-in-hook= / =org-clock-out-hook=, after your snippet (=sp-modeline-parts-clock-arrow=).

*Shared document:* =docs/tangles/tooling/modeline-customization.org= (differences between the lambda-line and Prot mode lines, the shared settings, recipes). The differences table was written from the code of the two modules, not from the earlier report.

*Not tested* (no Emacs in the container; =.el= files only paren-checked): =mode-line-maker--make= inside lambda-line's compose, =mode-line-window-selected-p= inside its nested =format-mode-line=, the clock-in state switch with =org-clock-in-switch-to-state= as a function, the fringe arrow, and that Prot's =(mode-line-maker ...)= form works as =mode-line-format= together with the keycast anchor. Speed: the package's README says its lines draw two to three times slower.
