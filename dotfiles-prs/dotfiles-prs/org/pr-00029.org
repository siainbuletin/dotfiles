**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
New module =sp-magit-style= (=libraries/modules/prog/=, loaded right after =sp-vcontrol=), with literate doc =docs/tangles/prog/sp-magit-style.org= and a CHANGELOG entry.

- =magit-section-heading=: height 1.15, bold, overline (extended across the window)
- =magit-diff-file-heading=: slightly larger, bold
- Folded/expanded indicators: Nerd Font chevrons via =magit-section-visibility-indicators= (work in a TTY too)
- Icons before every file and directory via =magit-format-file-function=, using =nerd-icons-icon-for-file= / =-for-dir=. =nerd-icons= is already set up in =sp-icons=, so no new package is added.
- Options: =sp-magit-style-icons=, =sp-magit-style-heading-height=.

Applies to =M-x yadm= (=magit-status "~/"=) as well, since it is plain Magit.
