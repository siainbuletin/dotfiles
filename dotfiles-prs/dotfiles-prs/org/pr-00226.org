**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
Note IDs in collection views render as Org links with the target note's title.

- *=vulpea-ui= collection views* (the named views in =sp-vulpea-ui=): =sp-vulpea-ui-collection-link-ids=, =:around= advice on =vulpea-ui-collection--column-raw-value=. In =meta=, =property= and =fn= cells, a bare note ID shows as its note's title, and =[[ID:..][..]]= text shows as its description, in =org-link= face. RET or a click on the link follows it; RET elsewhere in the row still visits the note. The package source is untouched.
- *Query tables* (=sp-collection-query-tables=): the =:id= column and meta values that are an ID become =[[id:ID][Title]]= links (Org block writes them; exc and vui show and follow them). A meta cell that holds a link is read-only in vui and exc.
- Shared helper =sp-org-link-link-ids= in =sp-org-id-link= (next to =sp-org-link-linkify=): looks the ID up in the Vulpea database, strips brackets from the title and lower-cases =[[ID:= so Org can follow it.
- Docs (=sp-vulpea=, =sp-org-id-link=, =sp-collection-query-tables=) and CHANGELOG updated.
