**** What was wrong
:PROPERTIES:
:CUSTOM_ID: what-was-wrong
:END:
- Stacking is =join-with=, which only existed in AeroSpace's service mode as plain =shift-h/j/k/l=.
- After =Caps+Shift+;=, Caps Lock is usually still held, so Hammerspoon's layer takes =Shift+h/j/k/l= as /move window/ first. Both tools then compete for the same chord, so joining only works sometimes (when Caps is released first).

**** Fix
:PROPERTIES:
:CUSTOM_ID: fix
:END:
- =Caps+Ctrl+h/j/k/l= runs =aerospace join-with <dir>= directly on the layer, with no service mode.
- The layer key is also bound with Ctrl, so Ctrl-then-Caps works.
- =aerospace.org= documents the new keys. The service-mode keys are unchanged.
