**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- Requested: inline keywords in Org text (for example in a draft for a project) show up in the agenda as problems to fix.
- New agenda view =x=, "Inline keywords to fix", in =sp-agenda-views.el= (the owner of =org-agenda-custom-commands=, ADR 0009).
- Also on =C-c o x= (=sp-agenda-views-inline=).
- It uses Org's search view with a regexp, so each hit is an agenda entry with its context that jumps to the place on =RET=.

**** Settings
:PROPERTIES:
:CUSTOM_ID: settings
:END:
- =sp-agenda-views-inline-keywords=: =FIXME=, =CITE=, =TK=, =XXX=; whole words only. Changing it re-installs the view.
- =sp-agenda-views-inline-extra-dirs=: =sp-writing-projects=. Its Org files are scanned besides the agenda files, because draft headings are not always agenda entries.
- The file title is shown as the prefix column (reuses =sp-agenda-views-file-title=).

**** Reading I chose
:PROPERTIES:
:CUSTOM_ID: reading-i-chose
:END:
- "Inline" means a keyword anywhere in an entry's heading or body, not an Org TODO keyword.
- The agenda shows problems on demand in its own view; it is not added to the main PARA view or the morning list.
