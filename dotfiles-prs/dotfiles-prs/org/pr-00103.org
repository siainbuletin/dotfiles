** Description
/Requested by *Sia*/

*Before:* box titles ("General agenda", "Thesis", ...) were the same size as the rows, TODO keywords in the boxes had no colour, and the agenda buttons opened the regular =org-agenda=.

*After:*

- *Titles larger:* new =sp-dashboard-heading-face=, a level 1 heading of the sp themes (colour from =fg-heading-1=, height from =sp-theme-headings=). The label is measured in pixels and the gap before the key is one exact-width space, so the right edge of each box stays straight; a label too wide is cut with an ellipsis. The icon is followed by one space in these titles. Menu blocks (Config, Notes) have the same titles.
- *TODO keywords coloured* by the face Org uses (=org-todo-keyword-faces=, else =org-todo= / =org-done=). Following the sp-themes design from #89, =sp-theme-engine= gets two roles, =fg-todo= (red) and =fg-done= (green), and maps =org-todo=, =org-done= and the new heading face to them, so every theme and flavor carries it. Only the keyword is coloured; TAB still stops once per entry, and the bullet and keyword are clickable through a keymap.
- *=org-other-agenda=* replaces =org-agenda-list= for all four agenda buttons. The files are bound for the call and kept buffer-locally in =org-other-agenda-settings= so refreshing keeps them; deadlines are one agenda block of the next =sp-dashboard-deadlines-days= days. General agenda no longer opens the agenda workspace. Without the package it falls back to =org-agenda-list=.
- Doc and CHANGELOG updated.

*Checked:* Emacs 29.3 headless (layout, TAB, privacy/Focus, clicking a TODO) and a real GUI under a virtual X display, where titles are larger, coloured and aligned, TODO keywords red. *Not checked:* =org-other-agenda= itself (it and its dependencies =textui= and =embark= could not be installed in the container, so only the fallback ran), the real theme colours (I set the faces by hand to the theme values), a Mac or 4K display.
