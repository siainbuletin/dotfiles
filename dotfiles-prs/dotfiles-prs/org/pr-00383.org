**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
Authors or editors that are organisations (e.g. the Endnotes collective, technically anonymous) were read as =Last, First= personal names. Now:

- A BibTeX name in double braces, ={{Endnotes}}=, is an organisation, in =.bib= files and in =pub-author= / =pub-editor= values.
- New defcustom =sp-author-notes-organisations=: names that are organisations even without braces (ignoring case and accents).
- An organisation is never flipped from =Last, First=, so ={{Doe, Roe Press}}= keeps its comma.
- =and= and =;= inside braces no longer split a name (={{Marx and Engels Institute}}=), in both =sp-author-notes= and =sp-author-notes-bibtex=.
- An organisation matches BibTeX authors by its whole name only, not by last name and initial.
- The note made for an organisation gets the =person= tag plus the =institution= tag (already in =sp-org-tag-registry=; setting =sp-author-notes-organisation-tag=), so Works tables and BibTeX commands keep working.
- A note tagged only =institution= is found and linked as an author note.
- The code lives in =docs/tangles/funct/sp-org-lint.org=; the =.el= files are re-tangled from it.
