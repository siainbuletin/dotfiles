*Before:* the Vulpea modules were spread over =libraries/modules/text/= (=base=, =ui=, =para=, =schemas=, =ext=, =ext-back=, =split=) and =funct/= (=convert-properties=, =grouped-backlinks=, =org-ql=), each with its own doc. =sp-vulpea-ext= also required =sp-vulpea-table=.

*After:*

- The ten modules moved (=git mv=) into =libraries/modules/vulpea/=, code unchanged, each still its own =.el= with its own =provide=. There is no loader module (an earlier version of this PR had =sp-vulpea=; removed as asked): =sp-org-ext= requires =sp-vulpea-base=, =-ui=, =-para=, =-schemas= and =-ext= itself, as before, and =-ext= still requires =-convert-properties=, =-grouped-backlinks= and =-split=.
- Their ten docs are now one, =docs/tangles/vulpea/sp-vulpea.org=, with a section per file (same approach as #71): each section sets its target with a =:header-args:emacs-lisp+: :tangle ...= property. The old =sp-vulpea-split-old.org= note moved beside it.
- =sp-vulpea-table= is excluded, as asked: the require is gone from =sp-vulpea-ext= (code and doc) and =sp-org-ext= requires it after the Vulpea modules.
- =docs/main.org= gets a =vulpea/= section (links go to sections of the combined doc); =load-order.org= and its SVG (re-rendered with Graphviz), =conditional-loading.org= and the =sp-org-ext= doc follow. =tests/sp-vulpea-para-test.el= points at the new path. CHANGELOG has a "Vulpea modules" set.

*Choices:* =sp-vulpea-ext-back= (an empty slot) and =sp-vulpea-org-ql= (a draft that runs a query at load) are moved and documented but not required by anything, as before; tangling gives =ext-back= its skeleton instead of an empty file. =sp-vulpea-grouped-backlinks= requires =sp-vulpea-table-core= (for the note selector), so Vulpea still pulls in that one table file.

*Checked* (Emacs, container): tangling =sp-vulpea.org= gives the ten files identical to the old ones (apart from the =sp-vulpea-ext= change and the =ext-back= skeleton), parens check, and the 5 =sp-vulpea-para= ERT tests pass from the new path. *Not checked:* a real start with Elpaca and the vault.
