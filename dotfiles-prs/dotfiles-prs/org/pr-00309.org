**** Symptom
:PROPERTIES:
:CUSTOM_ID: symptom
:END:
Caps Lock + number (focus, workspaces) works, but Caps Lock + Shift combos (move window, move to workspace) do nothing, and with a text box focused they type capitals.

**** Likely cause
:PROPERTIES:
:CUSTOM_ID: likely-cause
:END:
The layer key (F18, from Caps Lock) is bound with =hs.hotkey.bind({}, "f18", ...)=. A hotkey only matches the modifiers it is bound with, so F18 pressed while Shift is already held is not that hotkey: the layer never opens, and Shift+letter types a capital. Pressing Caps Lock first and Shift second would already have worked, so this only breaks when Shift goes down first (or at the same time).

**** Change
:PROPERTIES:
:CUSTOM_ID: change
:END:
- =aerospace-keys.lua=: the layer key is bound twice, with no modifiers and with =shift=, both entering and leaving the same layer.
- =aerospace.org=: one line saying the layer opens in either order.
