**** Problem
:PROPERTIES:
:CUSTOM_ID: problem
:END:
- BibTeX author =Arthur, Christopher J.= gave the title =J. Arthur (2022) Capital as...= instead of =Arthur (2022) ...=.

**** Cause
:PROPERTIES:
:CUSTOM_ID: cause
:END:
- =sp-litnotes-titles--split-name= is the one function that finds the surname. The backfill (=sp-litnotes-meta--new-title=), titles report/convert and the BibTeX-authors path all call it.
- Names are flipped to =First Last= before it runs, so it used its "particle" rule: lower-case words before the last word belong to the surname.
- That test ran with =case-fold-search= on, so the initial =J.= counted as a lower-case particle and went into the surname.

**** Change
:PROPERTIES:
:CUSTOM_ID: change
:END:
- Particles are matched case-sensitively, and only whole lower-case words (=van=, =de la=) count.
- Commas are split outside braces only: ={Smith, Jones}, Ann= has surname =Smith, Jones=; =Last, Jr., First= has surname =Last=.
- ={World Bank}= stays one surname; no comma and one word stays as is.
- Tests (=tests/sp-litnotes-titles-test.el=, =tests/sp-litnotes-meta-test.el=): the forms above, =case-fold-search= on and off, BibTeX authors, and the backfill title. 34/34 pass on Emacs 29.3 batch.
- No CHANGELOG edits.
