**** Cause
:PROPERTIES:
:CUSTOM_ID: cause
:END:
- =ibuffer-saved-filter-groups= only stores groups. Nothing called =ibuffer-switch-to-saved-filter-groups=, so the list was never sectioned.
- =nerd-icons-ibuffer-mode= (enabled in =sp-icons=) overwrites =ibuffer-formats= with =nerd-icons-ibuffer-formats=, so the custom column widths were never used.

**** Fix
:PROPERTIES:
:CUSTOM_ID: fix
:END:
- =sp-buffers-activate-filter-groups= runs on =ibuffer-mode-hook= and switches to the "Main" groups.
- Column widths: name 36 (24 in the compact format), mode 18, =:elide= for long text, file path takes the remaining width.
- The same widths are set for =nerd-icons-ibuffer-formats= after that package loads, keeping the icon column.
- Same change in =docs/tangles/ui/sp-buffers.org=, with bullets.
