/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW2FEnkbKDW2SF6o1VMULYvEt][project thread]]/

New module =sp-litnotes-meta= (doc: =docs/tangles/academic/sp-litnotes-meta.org=). After =citar-create-note= it fills the first section of the note from the BibTeX entry:

- =pub-author=: one link per author (=author=, else =editor=). Matched by name against existing notes in the Vulpea db (a =person= note wins); if none exists, a new =person= note with an ID is written and linked.
- =pub-title=, =pub-year= (year, else =date=, else the crossref's year).
- =bib-parent=: link to the litnote of the =crossref=d entry, only if that note exists (otherwise left out, with a message).
- =bib-project=: minibuffer picker over notes tagged =project=, default the thesis.

Existing values are never changed. =M-x sp-litnotes-meta-fill= does the same for an existing note; =sp-litnotes-meta-auto= turns the advice off.

Tests: =tests/sp-litnotes-meta-test.el= (6 pass in Emacs 29, Vulpea stubbed). Not run on the real vault or with real =citar-vulpea=: the note file must exist on disk right after =citar-create-note= for the advice to find it.
