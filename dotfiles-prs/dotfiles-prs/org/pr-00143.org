1. *Single load.* The module was in =sp-late-modules=, but =sp-tab-inbox=, =sp-collection-query-tables-core= (so =sp-org-ext=), =sp-move-region-to-heading= and =sp-org-link-conversion= required it, so it loaded at startup and the late entry only logged =[skip] already loaded=. Those four requires are removed (none calls anything from it); it loads once, as a late module. Until then, note prompts show no tag emoji.
2. *Rename* =sp-tag-emoji= to =sp-org-tag-groups= (file, feature, literate doc, every symbol prefix), because the tags and their grouping come first and the emoji and background colours are the decoration.
3. *Families became groups*, no aliases: =sp-org-tag-families= is =sp-org-tag-groups-alist=, =sp-org-tag-family-of= is =sp-org-tag-group-of=, =sp-org-tag-groups-family-colors= is =sp-org-tag-groups-colors=; ADR 0020 is =0020-tag-groups.org=.
4. No other module is double-listed (checked =init.el= lists and =sp-config-profiles.el=).

Init code or Customize settings using the old names need renaming. Earlier CHANGELOG entries keep the old names.
