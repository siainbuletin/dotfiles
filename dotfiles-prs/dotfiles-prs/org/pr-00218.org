**** Cause
:PROPERTIES:
:CUSTOM_ID: cause
:END:
=sp-dashboard--scan-file= (added in #213) reads each changed agenda file with =insert-file-contents= in a =with-temp-buffer=, then sets =buffer-file-name=. The insert leaves the buffer modified, so when =with-temp-buffer= kills it Emacs asks =Buffer  *temp*-123456 modified; kill anyway?=, once per scanned file. =--debug-init= shows nothing because it is a prompt, not an error. Before #213 the files were visited through =org-map-entries= on file lists, with no such buffer.

**** Fix
:PROPERTIES:
:CUSTOM_ID: fix
:END:
Mark the buffer unmodified before setting =buffer-file-name= and again after =org-mode=. Module, tangled doc, CHANGELOG and one ERT test updated.
