** Description
Requested: PDFs should open in a separate DEVONthink window instead of the small viewer beneath the database view, and several PDFs must be possible at once.

- =openInDatabases= now calls DEVONthink's =open window for record= and =activate=, instead of =open location= with the =x-devonthink-item://= link (which replaced the previous PDF in the main window's viewer).
- Several PDFs: a Finder selection sent in one event is handled one after the other, each getting a window.
- =DT_OPEN_MODE= (window/reveal) is removed from the code, the config and the docs.
- Handlers renamed: =openInDEVONthink=, =findAndOpen=, =openInDatabases= (true/false instead of a link).
- Not run on a Mac. Not checked: what DEVONthink does when a window for that record is already open.
