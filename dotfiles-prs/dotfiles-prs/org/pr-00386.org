**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- =sp-litnotes-meta-backfill-all-children= already inserted a =collection-query-table= block for a book or collection; it now also picks the right view for a reference work or an encyclopedia (by the BibTeX type tag, =sp-litnotes-meta-parent-views=).
- New command =M-x sp-litnotes-meta-refresh-all-tables= refreshes every chapter table in the vault in one go:
  - Syncs the Vulpea database first (=sp-litnotes-meta-refresh-sync=), since the DB can lag.
  - Parents are found from the chapters: every =bib-parent= of a note tagged =booksection=, =incollection=, =inreference= or =encyclopedia=. So an encyclopedia article whose parent is tagged =encyclopedia= or =collection= gets its table in either case.
  - A parent without a block gets one above its first heading; a tagged note with no chapters and no block is left alone.
  - =C-u= is a dry run. A summary buffer lists tables added, changed, unchanged, failures, and =bib-parent= ids missing from the database.
- New built-in views =reference-entries= and =encyclopedia-articles= (sorted by title; entries have no pages).
- =sp-bibtex-types-tag-alist= now maps =inreference=, =reference=, =mvreference=.
- =sp-collec-query-check-rules= takes a list of parent tags per child tag, with rules for =inreference= (reference or book) and =encyclopedia= (encyclopedia or collection), so the =:check= column does not flag them.
