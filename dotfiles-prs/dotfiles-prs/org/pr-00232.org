**** Summary

Hovering a =[cite:@key]= link raised =void-function citar-get-template= (muted by safe_call), so neither the tooltip nor the echo area showed anything. =citar-get-template= and =citar-format--entry= (as called) are not part of citar's current API.

- =sp-cite-hover--reference= now uses the public =citar-format-reference=, which applies the =preview= template of =citar-templates=.
- Errors from citar give nil (tooltip then shows "not found in the bibliography"), so a hover never signals.
- Doc (=sp-academic.org=, "Citation hover") edited and tangled to =sp-citations.el=; CHANGELOG entry added.
