** Description
Adds a macOS Stow package =devonthink-open=.

- =dt-open= looks each PDF up in every open DEVONthink database (=lookup records with path=, as in the DT forum threads) and opens the =x-devonthink-item://= link; PDFs that are not indexed go to a fallback viewer (Preview, configurable) and never to DEVONthink.
- =dt-open-install= builds =DT Open PDF.app= (an applet that calls =dt-open=), registers it for =com.adobe.pdf= and makes it the default PDF viewer, so Finder double-click and Alfred's file picker both use it. =--uninstall= restores the previous default.
- Not run on a Mac. Tested here: bash syntax and =dt-open='s decisions against stand-ins for =osascript=/=open=. Untested: the AppleScript lookup, =osacompile=/=PlistBuddy=/=codesign=, and LaunchServices registration.
