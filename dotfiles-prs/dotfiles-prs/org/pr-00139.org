** Description
*Before:* =sp-load-theme= from any buffer ended in the Dashboard.

*Cause:* =sp-dashboard= hangs =sp-dashboard--theme-changed= on =enable-theme-functions= and =disable-theme-functions=. It ran =sp-dashboard-refresh= inside the Dashboard buffer, which kills and redraws it with =sp-dashboard-screen=, and that ends in =switch-to-buffer "Dashboard"=. =with-current-buffer= does not change the selected window, so the redraw put the Dashboard in whichever window you were using.

*After:* the splash is redrawn inside =with-selected-window= of the window that already shows it, and not at all when no window does (the palette is still applied; =g= redraws a hidden Dashboard). The selection is restored by =with-selected-window=.

*Checked* (Emacs 29.3, windows only): with the Dashboard in a second window the refresh runs there and the selected window stays; with no window showing it, no refresh runs. *Not checked:* the real Dashboard on macOS.
