** Description
/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW21mXvibxgZ5NzrmRV92h1on][project thread]]/

*Before:* checkbox lists under a =Tasks= heading in the vault are invisible to the agenda and org-gtd, and TODO-like words (=DOING=, =WAITING=, =STARTED=, ...) that are not declared in =init.el= or in the file are plain text to Org.

*After:* new module =sp-org-normalise= (=libraries/modules/custom/=, literate doc =docs/tangles/custom/sp-org-normalise.org=, listed in =docs/main.org=, loaded from =init.el= after =sp-org-issues=).

- =M-x sp-org-normalise-inventory=: every keyword-like heading word with heading and file counts, how many files do not recognise it, and what the mapping table does with it.
- =M-x sp-org-normalise-preview=: report buffer of proposed changes per file; =RET= visits a change. Writes nothing.
- =M-x sp-org-normalise-run=: the preview, then per file yes / no / choose each change / quit. Buffers are left modified and unsaved (=sp-org-normalise-save-after-apply= to change).
- Checkbox items under a =Tasks= heading become child headings: =[ ]= TODO, =[X]= DONE, =[-]= PROG. Nested lines stay in the body. A checklist under a heading that already has a keyword is left alone.
- =sp-org-normalise-keyword-map= (editable) rewrites =DOING=, =WAITING=, =CANCELLED=, ... to the org-gtd set; words not in it are only reported. A =#+todo:= line is proposed for files that would otherwise use an unknown keyword; files with their own sequence are only noted.
- Code blocks and drawers are never read. All =defcustom=s are in the group =sp-org-normalise=. No external packages.

*Checked* (headless Emacs 29.3, container only, fake vault in a temp directory): 24 ERT tests in =tests/sp-org-normalise-test.el= (tangled from the doc), plus a manual run of inventory, preview and apply on a small fake vault. The tests started red and were fixed (case-folding of the keyword regexp; undeclared words wrongly triggering a =#+todo:= line).

*Not checked:* the interactive prompts (=read-char-choice=, =y-or-n-p=) and the report buffer in a real Emacs, and anything on the real vault, TRAMP or Windows paths. The default map rewrites =DOING= and =WAITING=, which =sp-org-taskman-extra= currently sets globally; remove them from the map if you want to keep those.

Run it with =emacs -Q --batch -L libraries/modules/custom -l tests/sp-org-normalise-test.el -f ert-run-tests-batch-and-exit= from the =init.el= folder.
