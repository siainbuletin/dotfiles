** Description
/Requested by *Sia*/

*Before:* =sp-dashboard-public-conditions= was empty, the privacy mode only changed on =P=/=g=, and TODO lines were not clickable by default.

*After:*

- =sp-dashboard-condition-focus= is the default condition. True while =sp-dashboard-focus-flag-file= exists (a macOS Shortcuts automation can =touch=/=rm= it when a Focus turns on/off), or while macOS lists a Focus as on in =~/Library/DoNotDisturb/DB/Assertions.json=. =sp-dashboard-focus-modes= limits it to some Focus modes.
- =M-x sp-dashboard-public-facing-mode=: global minor mode, lighter = Public=, forces public mode (private entries hidden) over the other settings.
- The dashboard remembers whether it was drawn as public. A timer (=sp-dashboard-public-check-interval=, 30 s) and file watches on the two Focus files compare that to the current status while the buffer exists, and toggling the mode does so too. A visible Dashboard is redrawn in its window; a hidden one is killed, so it never comes back showing entries it should now hide.
- =sp-dashboard-agenda-todos-clickable= is now =t=: =RET= or a click on a TODO visits the entry (each TODO is a =TAB= stop).
- Doc and CHANGELOG updated; the doc tangles to the =.el=.

*Checked* (Emacs 29.3, headless): flag file on/off redraws and hides/shows the private entry; the minor mode forces and releases public; the Assertions parser and the mode filter work on a made-up file; clicking a TODO opens its Org file at the entry. *Not checked:* macOS itself. The real =Assertions.json= layout and whether Emacs can read it (it may need Full Disk Access) are from memory, so the flag-file route is the reliable one.
