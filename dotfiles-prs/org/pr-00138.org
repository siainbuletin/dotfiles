- Stacked on #137 (which is stacked on #136); retarget to =main= as they merge.
- Brings back the nano-style =M-x= that was removed from =sp-mini-frame= while it was being made to work, now on the posframe:
  - the prompt in inverse bold with a one-pixel box (=sp-posframe-nano-commands=);
  - the dotted line under the input (=sp-posframe-divider-char=, =-divider-priority=), in the divider colour of =sp-nano-style=. It has 300 characters and =truncate-lines= is on in that minibuffer, so the window cuts it and it no longer wraps in a narrow frame;
  - the dimming of the frame behind =sp-select-note=, =sp-insert-note= and =sp-collec-query-select-note= (=sp-posframe-dim-functions=).
- Not brought back: the colour handling (#121/#123) and the computed fixed height, which only existed to work around =mini-frame=.
- Styling runs in =condition-case=, so an error cannot stop the prompt.
- Docs (=sp-posframe.org=, dividers guide) and CHANGELOG updated.
