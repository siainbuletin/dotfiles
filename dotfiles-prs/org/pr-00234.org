Adds two built-in columns to =sp-collection-query-tables=:

- =:refs= shows the =ROAM_REFS= property (a property, not Vulpea meta, so a plain string column could not reach it).
- =:pdf= reads the citation keys in =ROAM_REFS= (=@key= or =cite:key=) and shows the files =citar-get-files= finds, as =[[file:...]]= links (empty without a file).

Example: =#+BEGIN: collection-query-table :tags ("litnote") :columns (:title :refs :pdf)=

Edited in the doc and in =sp-collection-query-tables-core.el= (tangle by hand: no Emacs in the container, so the tangle check and the new test in =tests/sp-collection-query-tables-test.el= were not run). The PDF comes from the local library only; a DEVONthink link is not included.
