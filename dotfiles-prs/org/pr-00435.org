**** Problem
:PROPERTIES:
:CUSTOM_ID: problem
:END:
- After selecting a sentence in a PDF opened in a separate DEVONthink viewer window, =C-c k d s= (=sp-devonthink-store-link=) said =DEVONthink has no record open in its front window=.
- Cause: the AppleScript read only =think window 1= (the main window). A record shown in a standalone viewer window or another window is not that window.
- The =if:= prefix in the message is Emacs's own display of an error signalled inside an =if= form, not a malformed message; I left it and reworded the message itself.

**** Change
:PROPERTIES:
:CUSTOM_ID: change
:END:
- The script now visits every DEVONthink window front to back (=every window=), reading =content record=, =current page= and =selected text= from each.
- The first window with selected text wins; with no selection, the frontmost window that has a record wins.
- Error message now says =DEVONthink has no open window with a record (open the PDF in DEVONthink first)=.
- Doc: =sp-devonthink.org= (tangled to =sp-devonthink.el=); 2 new ERT tests; tangle check passes.
