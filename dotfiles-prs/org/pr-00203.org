**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
=org-table-widget= was already enabled in =sp-textui=, but it ran with defaults that look nothing like Obsidian, and =org-modern= was drawing its own borders over the same tables (its README says to turn =org-modern-table= off). In =sp-org-tables=:

- =org-modern-table= is =nil=; zebra stripes are off.
- Widget borders and header row take quiet colours blended from the theme (=sp-org-tables-border-strength= 0.22, =sp-org-tables-header-strength= 0.07), recomputed on =enable-theme-functions=.
- =sp-org-tables-quiet-pipes-mode= (on in Org buffers) dims =|= and rule lines of the plain-text table, for terminals and while a table is revealed for editing.

**** Is it possible?
:PROPERTIES:
:CUSTOM_ID: is-it-possible
:END:
Nearly, in a GUI. The widget always draws a full grid (outer box and vertical bars), so borders can be made faint but not removed. For fully borderless Obsidian rows a different renderer would be needed. In plain text, Org cannot hide the pipes without hurting editing, so they are only dimmed.

**** Tested
:PROPERTIES:
:CUSTOM_ID: tested
:END:
4 ERT tests in Emacs 29.3 batch (colour blend, =org-modern-table=, dimmed pipes). The doc tangles to the module. Not seen in a graphical Emacs: please restart and look at a table, then adjust the two strength options to taste.
