**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- *Registry:* =sp-org-tag-registry.el= holds the note tags in =org-tag-persistent-alist=. The task tags stay in =org-tag-alist= (=sp-org-taskman-extra=).
- *=M-x sp-org-tag-add=:* inserts a tag above a marker line in the registry file, saves it and runs =load-file=, so it works without restarting. It asks first if the tag is close to a registered one (typo guard).
- *=M-x sp-org-tag-lint=:* scans the vault (vulpea db, else =~/notes=) and reports unregistered tags in =#+filetags:= and on headings, with the likely typo, plus notes with no =#+filetags:= (for =sp-tag-emoji=). =RET= visits, =a= registers, =g= reruns. =sp-org-tag-lint-buffer= does one file.
- *=sp-org-create-note-and-link=* and *wikilink conversion:* both ask for at least one note tag (unknown ones can be registered on the spot) and write =#+filetags:=.
- *=sp-split-leave-parents=:* binds =org-use-tag-inheritance= to the new =sp-split-inherit-tags= (nil), only while it runs.
