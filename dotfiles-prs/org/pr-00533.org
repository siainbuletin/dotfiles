**** What changed
:PROPERTIES:
:CUSTOM_ID: what-changed
:END:
- Three kinds of note, told by Org footnote *label* (=sp-note-kinds=, new):
  - footnote: any other label (unchanged)
  - see-also note: =[fn:see-1]=, drawn as a Tufte sidenote
  - endnote: =[fn:end-1]=, collected in a Notes section
  - prefixes are options: =sp-note-see-also-prefix=, =sp-note-endnote-prefix=
- Today (before): =sp-see-also= read any footnote with an =id:= link, inline or numbered.
- =sp-see-also=:
  - reads =see-N= notes; endnotes never count; old footnotes still count while =sp-see-also-legacy-footnotes= is non-nil (default)
  - =sp-see-also-note-new= (=C-; n a=): asks for the note, inserts =[fn:see-N]= and the definition in the =Footnotes= section
  - =sp-see-also-convert-footnotes= (=C-; n M=): migrates inline and numbered see-also footnotes
  - cache version 5 → 6
- Endnotes: =sp-note-endnote-new= (=C-; n e=), template =sp-note-insert-endnotes-section= (=C-; n E=).
- Numbering: =sp-note-renumber= (=C-; n r=) numbers each kind in text order, so =see-2= before =see-1= is swapped; runs after a new note, =org-footnote-normalize= and Org's footnote adjusting.
- Org and lint:
  - =org-footnote-normalize= / =org-footnote-sort= no longer touch these notes (a guard hides them from Org during the call)
  - =sp-org-lint-footnotes= leaves them where they are
- Typst (=sp-typst=): =#see-also[..]= (marginalia sidenote, or footnote with =sp-typst-see-also-style= = =footnote=), =#endnote[..]= and =#endnotes()=; =docs/typst/template.typ= and new =docs/typst/sidenotes.typ=.
- =sp-reading-sidenotes= now draws =see-N= notes through the shared parser.
- LaTeX mapping: not done (not cheap enough; see the sp-typst doc).
