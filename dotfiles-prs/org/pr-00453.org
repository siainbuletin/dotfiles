- New module =sp-pdf-reader= (=docs/tangles/academic/sp-pdf-reader.org=):
  - =use-package emureader :ensure t= (GNU ELPA through Elpaca; no hand-cloned checkout).
  - =sp-pdf-open FILE &optional PAGE=: opens in emureader at a PDF page (from 1); falls back to =find-file= with a message when emureader is not installed or built.
