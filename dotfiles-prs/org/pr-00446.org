**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Request:* insert a citation and be asked for the page right away, under a binding different from the normal insert, so that not every citation gets a page.
- *New command* =sp-citations-insert-with-page=, bound to =C-c B= in Org buffers.
  - =C-c b= (=org-cite-insert=) is unchanged and never asks.
  - Choose references with =citar-select-refs=; then one prompt per key.
  - Result: =[cite:@key p. 12]=; several keys: =[cite:@a p. 3; @b]=.
- *Prompt default:* the first page of the entry's BibTeX =pages= field (=12--30= gives =12=; a chapter uses its own =pages=). Delete it and press RET for no page (=@key= alone).
- *Answer format:* =12= becomes =p. 12=, =12-14= becomes =pp. 12-14=, anything else (=ch. 3=) is kept as typed.
- *Inside an existing citation* on the same line: the new keys are added before the closing bracket with =; =.
- *Binding choice:* =C-c B= is the capital of the existing local =C-c b=; Org buffers only, GUI only, no =C-z/C-c/C-x/C-v= root, no =SPC=, no global key taken (checked: =C-c B= is unbound anywhere in the modules). Like =C-c b= it is a mode-local key and moves with it when the leader keymaps of the design in #278 are built.
- Docs: bullet section in =sp-academic.org=, =.el= re-tangled (=tools/check-tangle.sh= clean).
- Tests: =tests/sp-citations-page-test.el=, 10 ERT tests pass on Emacs 29.3 batch (first page, locator format, one/several keys, empty answer, joining an existing citation, non-Org buffer, no selection). =when-let*=/=if-let*= only. No CHANGELOG edit.
- *Not tested with real Citar:* =citar-select-refs= and =citar-get-value= are stubbed; the real prompt and the =pages= field of your bibliography have not been run.
