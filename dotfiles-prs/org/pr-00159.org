**** Why
:PROPERTIES:
:CUSTOM_ID: why
:END:
On macOS the frame made by =sp-quick-capture-popup= (#131) was blank and Emacs hung (beachball), and AeroSpace tiled it to full size. =org-protocol= would not help: it opens the same frame.

**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- =tools/quick-capture-native=: =osascript= shows a native dialog for the line, the script sends it to the running Emacs with =emacsclient -e '(sp-quick-capture "…")'= (backslashes and quotes escaped), and a notification shows what was written or the error. No Emacs frame, so nothing for AeroSpace to tile or for =mini-frame= to interfere with.
- =sp-quick-capture= now returns the preview text (used for the notification). New ERT test; 9 tests pass in Emacs 29.3 batch.
- Doc and CHANGELOG updated. The Emacs-frame path is left in place but marked unconfirmed.
