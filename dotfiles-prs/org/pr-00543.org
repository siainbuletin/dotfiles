**** Summary
:PROPERTIES:

:END:
- *Key chosen: =C-; "=* (leader, then Shift-'), global, two keys instead of =C-c C-,= then =q= and a paste.
- Why this key:
  - on the leader root, not under a group, so it is as short as it can be
  - letters at the root are group names; punctuation is free (only =.= is used)
  - no CUA keys (=C-z/c/x/v=), no Alfred (Cmd+Space), no Ctrl+Space; GUI-only like the rest of the leader
- New command =sp-org-insert-quote-from-kill= in =sp-org-base=:
  - fills the block with =(current-kill 0 t)=, the ring is not rotated or changed
  - active region: the region is cut and put in the block instead
  - =C-u= (and no region): empty block; empty kill ring: empty block, no error
  - starts on its own line (inserts a newline when point is mid-line)
  - trailing newlines dropped, text properties dropped, lines starting with =*= or =#+= escaped with a comma
  - point ends after =#+end_quote= (inside the block when it is empty)
- Binding and autoload in =sp-keys=; docs (bullet lists) in =sp-org-base.org=, =sp-keys.org= and =global-keymap-namespaces.org= ("Root keys").
- Tests (Emacs 29.3): 10 new in =tests/sp-org-base-quote-test.el=, 1 new in =tests/sp-keys-test.el=; all pass.
- =tools/check-tangle.sh=: only these two docs (other drift is the known Org-version artifact, not committed).
