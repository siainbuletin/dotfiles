**** What changes
:PROPERTIES:
:CUSTOM_ID: what-changes
:END:
- Caps+x finds the item with the exact title =Text Selection=, searched in the whole menu bar (so the menu it sits in does not matter), and chooses it to leave highlight mode.
- Highlighting counts as on when Highlight Text has a check mark and Text Selection has none. If neither shows a check mark, the last state the key set is used.
- If Text Selection is not found, an alert says so and nothing changes. The alert after switching is now "Text Selection".
- The colour cache from #517 only holds the Format menu colour paths, never tool names, so it needed no change.
- The menu bar is read once per press (before, it was read once for the Annotate menu); there is no extra cost.
