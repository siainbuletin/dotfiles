**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
=sp-litnotes-titles-dryrun= and =-convert= can now take the authors, year and title from the BibTeX entry of each note's citekey, so every litnote title can be brought to the =Last (Year) Title= standard.

- =C-u M-x sp-litnotes-titles-dryrun=: BibTeX fills what the note lacks (=missing=).
- =C-u C-u M-x sp-litnotes-titles-dryrun=: BibTeX wins over the meta lines (=always=).
- =sp-litnotes-titles-bibtex= sets the mode without a prefix argument (default nil, so nothing changes unless asked).
- The dry run still writes nothing. The report shows the proposed titles, marks values taken from BibTeX (=from BibTeX: authors, year=), and lists notes whose citekey has no entry. =convert= is unchanged otherwise (one confirmation, backups).

**** How
:PROPERTIES:
:CUSTOM_ID: how
:END:
- Reuses =sp-litnotes-meta--field=/=--year= (braces, LaTeX accents to Unicode, year from =date= or =crossref=) and =sp-author-notes-bibtex--files=.
- New =sp-litnotes-meta-build-index=: the =.bib= files are read once per run (in a first background slice) into =sp-litnotes-meta--index=; =sp-litnotes-meta--entry= uses it when set. Without it, behaviour is as before.
- Source edited in =sp-org-lint.org= and =sp-litnotes-meta.org= and tangled. Five new ERT tests; =sp-litnotes-titles= and =sp-litnotes-meta= tests all pass on Emacs 29.3 (20/20). Not run on the real vault.

**** Ambiguities I resolved
:PROPERTIES:
:CUSTOM_ID: ambiguities-i-resolved
:END:
- =sp-bibtex-dir= no longer exists (merged into =sp-bibliography-dir=), so the files come from the usual registered list.
- Names come from the =author= field only, never =editor=. =and others= is dropped, a name wholly in braces is one name, and last names are used as written (so no accent-insensitive matching is needed for titles).
- In =missing= mode an ambiguous =pub-author= also counts as lacking.
- Citekeys must match the entry exactly; the first key with an entry wins.
- Values typed in during =convert= win over BibTeX. Meta lines are not written; =sp-litnotes-meta-fill= does that.
