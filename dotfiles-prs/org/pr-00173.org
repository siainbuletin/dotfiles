Adds =rel-anno-fa2= to =sp-graphs=: the relationship annotator's scope drawn as a ForceAtlas2 graph in an Emacs buffer with [[https://github.com/elij/graph-fa2][elij/graph-fa2]].

*How I read the request:* a new force-directed view next to the existing browser graph (which is unchanged), because graph-fa2 draws SVG in a buffer rather than in a browser.

- =graph-fa2= is installed with =use-package= and Elpaca =:ensure (:host github :repo "elij/graph-fa2")=; edge labels on, label wrap 18.
- Same starting note and depth prompt, same scope as the browser graph.
- Depth: node radius shrinks with the level below the start (=relationship-annotator-fa2-radius=, 18 down to 7); last-level nodes show =(+N)= hidden children.
- Nodes show the title and =#tags= instead of plain dots.
- Links show the relation (=parent=, =supports=, ...) in the relation's colour, as arrows.
- Node fill comes from the tag group of the first grouped tag (=sp-org-tag-group-of=, =sp-org-tag-groups-colors=, =sp-org-tag-groups-palette=), light or dark by frame background.
- Clicking a node visits the note.
- Literate doc and CHANGELOG updated.

Not run: the container has no Emacs, so this was only read against graph-fa2's source. Worth checking in a real session: that tags wrap legibly, that the label colour reads on your theme, and that the click hook fires.
