**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
New module =sp-litnotes-titles= (section of =docs/tangles/academic/sp-academic.org=, required by =sp-litnotes=). Litnotes are identified by =ROAM_REFS= now, so the title no longer has to be the citekey.

- =M-x sp-litnotes-titles-report= is a dry run (writes nothing): per note, the references, old and new =#+title:= (from =pub-title=), old and new file name, and =file:= links elsewhere that name the old file. Skipped or flagged: no =:ID:= drawer, no or empty =pub-title=, a file name in neither scheme, a title with no slug, a new name that already exists or that two notes would share, case-only changes; notes that share a title are listed too.
- =M-x sp-litnotes-titles-apply= shows that report, asks once, copies each note to =var/litnote-title-backups/<time>/=, writes the title, renames the file, then =vulpea-db--forget-file= (old path), =org-id-add-location= and =vulpea-db-update-file= (same calls as =sp-split--denote-rename=). The =:ID:= is checked unchanged after the write; locked files and files with unsaved buffers are skipped.
- File names: Denote =ID--slug__keywords.org= (the litnotes of citar-denote) and =YYYYMMDDHHMMSS_slug.org= are read; the identifier, separator and keywords stay and only the slug is rebuilt (lower case, ASCII, 100 characters at most; =sp-litnotes-titles-slug-function=). =sp-litnotes-titles-rename-files= nil copies titles only.
- Independent of the =ROAM_REFS= conversion of #210: it can run before or after it.
