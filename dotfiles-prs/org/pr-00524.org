**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- New module =sp-bibtex-biblatex= (literate doc =docs/tangles/academic/sp-bibtex-biblatex.org=) renames BibTeX-only fields to BibLaTeX names and writes accents as Unicode.
  - =journal= to =journaltitle=, =address= and =place= to =location=, =school= to =institution=, =archiveprefix= and =primaryclass= to the =eprint= names.
  - =@electronic= and =@webpage= become =@online=.
  - =f{\"u}r= becomes =für=; protective braces, =\&=, =\%=, =\_= stay.
  - A name whose BibLaTeX twin exists with another text is left and reported.
- Never changed: dates (you chose to keep =year= and =month=), citekeys, =file= fields, =url=, =doi=. Citekeys and PDF names stay ASCII; the report lists the 11 keys and 284 =file= fields with non-ASCII characters on a copy of your library.
- Safety: dry-run report first (=C-; L b f L=), one question, backup per run, =C-; L b f r= restores. A binary file with a =.bib= name (=epistemologie.bib= is a macOS alias) and non-UTF-8 files are skipped. The result must have the same keys in the same order or nothing is written.
- Keys: =C-; L b f l= convert, =L= report, =r= restore.
- Findings are in =docs/architecture/biblatex-and-typst.org=:
  - your exports use CSL (citeproc), not biber, so no document needs BibTeX-only features;
  - =bibtex-mode= handles BibLaTeX with the =biblatex= dialect (already set); it lacks =@video=, =@review=, =@standard=, =@audio=, which the converter adds while it works;
  - Typst reads =.bib= as BibLaTeX through Hayagriva and accepts =journal=/=journaltitle=, =address=/=location=, =school=/=institution= and =date= or =year=+=month=, but not =place= or =@webpage=;
  - =org-cite-export-processors= has no =typst= entry, so a Typst export uses citeproc text, not =#cite=; a one-line follow-up, not changed here.
