**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
Hovering over an Org =[cite:@key]= link now shows the full formatted reference, as in Obsidian's Pandoc Reference List. It lives in =sp-citations= (the bibliography files are registered by =sp-bibprocess=; the rendering uses =citar=).

- *Tooltip*: a =help-echo= on the link, shown when the mouse rests on it.
- *Echo area*: an Eldoc function, shown when point is on the link.
- =sp-cite-hover-display= (default =(tooltip echo)=) picks either, both or neither.
- The text is the =preview= template of =citar-templates=, so changing that template changes the hover text. With several keys, the one under the mouse or point is shown (the first on the prefix/suffix). A missing key shows =@key: not found in the bibliography=.

Docs: new "Citation hover" section in =docs/tangles/academic/sp-academic.org=; the =.el= is tangled from it (tangling also removed some trailing whitespace in untouched lines of =sp-citations.el=). CHANGELOG entry added under Open pull requests.
