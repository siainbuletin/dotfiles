**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
Typing a partial name in =C-x b= and pressing =RET= created a new buffer. Vertico's default =vertico-preselect= is =prompt=, which keeps the typed text selected, so =RET= submits it. =sp-completion= now sets =vertico-preselect= to =first=, so the best match is selected.

- =M-RET= (=vertico-exit-input=) still submits exactly what you typed, for a new buffer name.
- The setting applies to every Vertico prompt, not only buffers. If you want it for buffers only, say so and I will scope it.
- Updated the literate doc =sp-completion.org= and CHANGELOG.org.
