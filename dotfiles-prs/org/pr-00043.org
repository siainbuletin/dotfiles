** Description
/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW2XeAdUCvg6CzkNNnvnLZg74][project thread]]/

*Before:* three Vulpea table modules (=sp-vulpea-dblock=, =sp-vulpea-vui-table=, =sp-vulpea-table-views=) that had to be required in order, with positional saved views, =vui= as the only interactive renderer, and a few bugs (sorting by title did nothing, =|= in a cell broke the Org table, editing a heading's row rewrote the file's top meta, inline tables left the note modified after a save).

*After:* =sp-vulpea-table= is the one entry point (=sp-vulpea-ext= requires only it) and loads six parts around one query description, a plist:

- =-core=: spec, one =vulpea-db-query= predicate (tags all/any/none, directories, TODO states, links, meta key/value, parent, level, title regexp), cells, sorting, writing meta back, refresh broadcast.
- =-menu=: a transient menu (=C-c w T=) showing each setting's value beside its key; open, preview count, insert as =vulpea-table= block, save/load/delete views.
- =-views=: saved views as spec plists; the first version's file is converted when read.
- =-org=: the =vulpea-table= dynamic block (title links, escaped cells) and a read-only Org buffer renderer.
- =-exc=: a renderer that draws the table with [[https://github.com/yibie/grid-table][exc]] (needs Emacs 29.1 and ETAF): frozen header, meta columns editable in place and written to the note, =C-c o= / =C-c q= / =C-c C-u=.
- =-vui=: the old vui table and inline tables, ported to specs, kept as the fallback.
- =sp-vulpea-table-renderer= is =auto= (exc, then vui, then org), =exc=, =vui= or =org=. Old =sia-vulpea-*= commands remain as obsolete aliases.

Packages come from =use-package= with Elpaca =:ensure= recipes (ecss, ebox, etaf with =:files ("*.el" "lisp/*.el")=, and exc from =yibie/grid-table=, the only address that resolved). exc is not part of emacs-taf; it is built on it.

Docs: one literate doc =docs/tangles/funct/sp-vulpea-table.org= writes all seven files (tangles back identical) and replaces the three old docs; =docs/main.org= module tree and =CHANGELOG.org= updated; the requires in the =sp-vulpea-ext= and =sp-vulpea-grouped-backlinks= docs follow.

*Tested* (container, Emacs 29.3, real Vulpea database of 3 then 1000 notes, no display): every filter, sorting, the dynamic block, view save/load and old-format conversion, writing meta back (and refusing a heading note), the Org, vui and exc renderers, in-place editing and the read-only guards in exc, the menu's commands with prompts stubbed, byte-compile. Opening 1000 notes, uncompiled: exc about 2.1 s, vui 2.8 s, Org 2.9 s.

*Not tested:* the menu on screen, tables in a graphical frame, mouse use, vui field editing, inline tables, Elpaca building ETAF and exc (the recipes are untested), the Transient version on your Mac, anything on your real notes or macOS. A step-by-step plan for comparing exc and vui is in the project files (=renderer-test-plan.md=).
