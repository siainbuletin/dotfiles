**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- An existing =* Sections= heading is reused (any level, tags allowed); the dblock goes at the start of its content, after a property drawer, with a blank line before and after.
- A chapter table block never stays outside that heading: above the first heading, under another heading, or after text under Sections, it is moved on re-run.
- Every table block is brought into the saved template format =#+BEGIN: collection-query-table :view "NAME"=:
  - =vulpea-table= is renamed, other parameters stay.
  - Parameters equal to a view become =:view NAME=.
  - A block for the note itself (=:parent-of= self or its ID) gets the note's view; the old line shows in the preview.
  - Blocks with =:view=, or for another note, are kept.
- Idempotent: blocks already in place are not touched.
- =C-u= preview lists "Would be fixed" with what would happen (heading added, table moved, header old and new); it writes nothing.
- A real run copies each note to =sp-litnotes-meta-backup-directory/<time>/= before saving, and the summary links the folder.
- =backfill-children= uses the same function.
- Literate doc updated as bullets; ERT tests added (moves, reuse, migration, preview and backup). Tests were run with stubs on Emacs 29.3; 5 other tests in the file already failed on =main= in this container and still do.
- No CHANGELOG edits.
