Follow-up to #271. Every change works with the current yadm setup and with the Stow layout, so it can be merged before you run the cutover.

- =emacs-pr.fish=: uses =git -C ~/dotfiles= when that repo exists (else =yadm=) and finds the config under =emacs-modular/.config/emacs-modular= when the checkout has the Stow layout.
- =sp-globals=: new =sp-dotfiles-dir= (=~/dotfiles/=) and =sp-dotfiles-work-tree=; =sp-yadm-repo= defaults to =~/dotfiles/.git= when it exists, so =sp-org-issues= worktrees follow it.
- =sp-vcontrol=: =M-x yadm= opens Magit on the dotfiles work tree; =vc-follow-symlinks= is =t= so Magit finds the repo through the links.
- =sp-agenda-views=: the config view lists Org files from the same work tree.
- =sp-env=: comment and doc say =GIT_CEILING_DIRECTORIES= is only needed while yadm is used (left in the list).
- Org docs edited together with the =.el= files; CHANGELOG entry added.

Not run in Emacs or fish (neither is in the container); the =tangle= check is the real test for the =.el=/doc match.
