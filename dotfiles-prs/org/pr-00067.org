** Description
/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW2BXvYbsL5hJPxFZGv79aHKm][project thread]]/

Implements the proposal from the thread's analysis doc. Reasons and alternatives are in =adr/0009-one-agenda-owner-per-setting.org= and =adr/0010-phase-out-denote.org=.

*Agenda*

- =sp-vulpea-para= turns on =vulpea-para-agenda-mode=: it owns =org-agenda-files=, filters =cemetery= notes (=sp-vulpea-para-agenda-note-p=, tested), and keeps =inbox.org= always listed. The three other =org-agenda-files= settings are gone.
- The =org-mem= agenda hook is removed from =sp-org-node-mem=; the old code is kept in ADR 0009.
- New =sp-org-keywords= is the only setter of =org-todo-keywords= (one constant per use) and gives =vulpea-para-done-keywords=. Its doc has a use-case table with empty columns to fill in, and the removed Workflow Status settings.
- =sp-agenda-views= assigns =org-agenda-custom-commands= once (PARA, native and issue views) and holds every agenda key; =sp-org-issues=, =sp-org-base= and =sp-org-taskman-extra= point to it. Commands that restrict the files bind =vulpea-para-agenda-inhibit-files-update=.
- =org-agenda-prefix-format= is one alist in =sp-org-agenda=.
- The =sp-denote= agenda hooks are removed; Denote is to be phased out (ADR 0010).

*Capture*

- =sp-org-capture= assigns =org-capture-templates= once (t, i, p, I, n, l); the only inbox is =~/notes/inbox.org=.

*Load order*: =sp-org-keywords= after =sp-org-base=; =sp-org-capture= and =sp-agenda-views= last (=init.el=, both lists; =sp-org-ext= no longer requires them). =docs/load-order-modules.svg= is redrawn.

*Not done / to check*

- Nothing was run with the real packages. Run vulpea-para's backfill once so existing files get the =agenda= tag.
- =C-c d c= (org-gtd capture) is unbound; =C-c d p= still processes org-gtd's own inbox.
- Dashboard/splash link and org-ql in the agenda were left out as asked.
