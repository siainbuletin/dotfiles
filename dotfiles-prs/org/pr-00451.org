**** What it does
:PROPERTIES:
:CUSTOM_ID: what-it-does
:END:
- =C-c k d A= (=sp-devonthink-insert-annotation-link=): asks for a citekey, then inserts a =devonthink:UUID::PAGE= link to one highlight of the record's PDF.
  - Two modes: =latest= (most recently created highlight) or =choose= (completing-read: page, creation date, text, comment).
  - =sp-devonthink-annotation-default= (=choose=) sets the mode; a prefix argument takes the other.
- =C-c k d L= (=sp-devonthink-insert-latest-annotation-link=): the thin command for =latest=.
- Uses =sp-devonthink-record= (#437), so a chapter without its own record lists the parent book's highlights (a message says so).
- =tools/devonthink-highlights.py --annotations= prints every highlight with page, text, comment, creation and modification date (PyMuPDF).
- Link format is unchanged, so =org-open= and export work as before.

**** Assumed, not verified (not run on the Mac)
:PROPERTIES:
:CUSTOM_ID: assumed-not-verified-not-run-on-the-mac
:END:
- DEVONthink's AppleScript only gives an annotation /count/ per record, not the annotations; so highlights are read from the PDF file, as in #420.
- The link opens the *page* of the highlight, not the highlight itself: I know no DEVONthink URL parameter that selects an annotation.
- Assumes DEVONthink writes its highlights into the file as standard highlight annotations with a =/CreationDate=.
  - Without a creation date the modification date is used; without either, the last one in the file counts as "latest".
- Assumes a highlight made in DEVONthink is saved to the file straight away (it may only appear after the PDF is closed).
- Page labels (#438) do not apply on this base: pages are physical PDF pages, which is what ~?page=~ uses. Showing printed pages in the list is a follow-up once #438 is merged.
