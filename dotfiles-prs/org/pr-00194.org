*Stacked on #193* (base branch =193-author-notes=; retarget to =main= once #193 is merged).

Adds =sp-author-notes-bibtex= (=M-x sp-author-notes-bibtex=): the "additional" view of the author notes, for works that exist only as BibTeX entries.

- Reads the =.bib= files of =sp-bibtex-files= (keys like =smith2020attention=).
- Compares the title of every =:person:= note with each entry's =author= field: *exact* after flipping =Last, First=, *possible* when last name and first initial agree.
- Leaves out entries that already have a litnote (key found in the head or file name of a note in =litnotes/=: =REFERENCES=, =ROAM_REFS=, =#+reference:=, =@key=).
- Report buffer, one section per author note. =c= creates the litnote for the entry at point, =C= for all exact entries of the section (both ask first), =RET=/=o= visit, =g= refreshes.
- The note is made by =sp-author-notes-bibtex-create-function= (=citar-create-note= by default, so the =sp-litnotes= templates apply), then a =- pub-author :: [[id:...][Name]]= line is added so it joins the =Works= table.

Docs: =docs/tangles/funct/sp-author-notes-bibtex.org= (the =.el= is tangled from it), README and CHANGELOG entries, loaded in =init.el= after =sp-author-notes=.
