**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Request:* show the backlinks and the other =vulpea-ui= widgets in a buffer apart from the sidebar, so a tiling window manager (AeroSpace, i3, sway) can place it in a frame of its own.
- *New module* =sp-vulpea-ui-view= (=libraries/modules/vulpea/=), documented in =sp-vulpea.org= as a bullet-point part.
  - =M-o v= (=sp-vulpea-ui-view-toggle=) opens the view in a new frame named =vulpea-ui-view= and closes it again. =q= closes, =g= refreshes. No =C-z/C-c/C-x/C-v= root, no Cmd+Space or Ctrl+Space; GUI only.
  - It mounts =vulpea-ui-sidebar-root=, the sidebar's own root component, in its own buffer. So the view shows the same widgets in the same order: backlinks, grouped backlinks, see-also, concept usage, Link inbox, book position, and whatever is registered later.
  - It follows the most recently used window that shows a vulpea note, in any frame. It keeps the last note while a non-note buffer is selected.
  - It refreshes while idle and drops the caches when the note database changes, like the sidebar.
  - A click in the view opens the note in the note window, not in the view (an =:around= advice on =vulpea-ui--get-main-window=), and focuses that frame.
  - Settings (group =sp-vulpea-ui-view=): =use-frame= (nil shows it in a window of the current frame), =frame-name=, =frame-parameters=, =return-focus=, =focus-on-visit=.
- *AeroSpace:* a suggested =[[on-window-detected]]= rule for the frame title is in =aerospace.org= as a doc note (=:tangle no=; =aerospace.toml= is unchanged). It is only needed if the frame floats.
- *Relies on =vulpea-ui= internals* (=vulpea-ui-sidebar-root=, =vulpea-ui--get-note-from-buffer=, =vulpea-ui--get-main-window=, four jump functions); the doc lists them.
- Tests: =tests/sp-vulpea-ui-view-test.el=, 10 ERT tests pass on Emacs 29.3 batch (followed note, sync and render kinds, main-window advice, focus advice, frame name, toggle and teardown). =.el= and test re-tangled from the doc; =when-let*= only, no CHANGELOG edit.
- *Not tested with real =vulpea-ui=/=vui=, or a real second frame:* both are stubbed, and headless Emacs cannot make a frame. Please try it on the Mac.
