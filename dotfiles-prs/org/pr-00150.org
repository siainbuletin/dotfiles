/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW22ZZGo68EvQH83Ucp2ATJwU][project thread]]/

Adds =sp-org-insert-config-doc-link= (=C-c l c= in Org mode), which inserts at point a =file:= link to a file in the configuration docs, from any note (e.g. in =~/notes=), without touching the vulpea database.

- Picks the file with the same fuzzy search as =sp-find-file=, restricted to =.org= files under =sp-config-docs-directory= (=docs/= next to =init.el=).
- =file:= link with the path abbreviated to =~/=; the docs have no =:ID:=, and an =id:= link would need them in the database. Description defaults to the file's =#+title= (prefix argument asks for it).
- =sp-navi=: =sp-find-file= is split into =sp-find-file-options=, =sp-find-file--read= and the new =sp-find-file-pick=; =C-x C-f= behaves as before.
- Literate docs of =sp-navi=, =sp-org-id-link= and =sp-org-base= updated and checked to match the code.

Not run in Emacs (none in the container).
