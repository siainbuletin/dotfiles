**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
New module =sp-reading-sidenotes= (ui), doc =docs/tangles/ui/sp-reading-sidenotes.org=, tests =tests/sp-reading-sidenotes-test.el=.

- In =sp-reading-mode=, each see-also footnote (=[fn::[[id:...][Concept]]]=) shows as a small number in the text and as a Tufte-style sidenote in the right margin. The file is not changed (overlays only).
- Footnotes come from =sp-see-also-parse-buffer= (#366), no second parser.
- The note starts on the line of its number, wraps in the margin (=sp-reading-sidenote-margin=, 30 columns), and moves down if it would overlap the previous one. It is redone on window changes, text scale and edits (idle timer).
- Turns on/off with =sp-reading-mode= (=sp-reading-sidenotes=), or alone with =C-c w s=. The right margin is widened while it is on and restored afterwards. Narrow windows keep the plain footnotes.
- =M-x sp-reading-sidenotes-export= exports the note with =ox-tufte= (installed via =use-package= + Elpaca =:ensure=) and opens the HTML.

**** Notes
:PROPERTIES:
:CUSTOM_ID: notes
:END:
- *Stacked on #366* (base branch =claude/project-thread-7yi4nb=); retarget to =main= after it merges.
- =ox-tufte= is an export backend, so it cannot draw in an Emacs window: the on-screen sidenotes use the Emacs margin display, and ox-tufte makes the matching HTML. It turns every inline footnote into a sidenote, not only see-also ones.
- The frame is not resized for the wider margin; the text column narrows instead.
- No CHANGELOG edits (nightly tidy).
