- *Changed =.bib= fields* (=sp-litnotes-meta-fill-all-dryrun= / =-convert=):
  - a pub-author, pub-editor, pub-title or pub-year that differs from the BibTeX entry is now listed as =update KEY :: old -> new=
  - new option =sp-litnotes-meta-update-changed= (default on); with it off, a prefix argument still forces updates
  - =bib-parent= is never updated here
- *bib-parent lint* (=sp-litnotes-meta-parent-lint-dryrun= / =-convert=):
  - lists notes whose bib-parent links the note itself, links another note than the crossref's, or has no crossref in the entry, or whose crossref has no note
  - shared report buffer: =d= drops a note for later, =u= brings it back, =A= fixes the rest
  - convert asks once, then per batch: fix all, choose note by note (fix, remove the link, skip), skip or quit
  - backup of each note first, same folder as the meta fill
- *Stop after a few batches*:
  - new =sp-batch-report-run-batches= and =sp-batch-report-batch-size= (50): before each batch apply, choose each, skip, or quit; what was not reached stays as it was
  - used by the meta fill convert, the bib-parent lint, =sp-vulpea-meta-order-convert= and the keyword conversion of all notes
  - not yet: litnote titles and refs converts (they write in =sp-async-work= timer slices) and the BibTeX lint, which already has apply/skip/quit per batch
