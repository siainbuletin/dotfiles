**** What changed
:PROPERTIES:
:CUSTOM_ID: what-changed
:END:
- =C-c h= (=sp-org-insert-inline-comment=) with an active region now wraps it in =@@comment:= ... =@@=.
- Without a region it still inserts =@@comment:@@= with point inside.
- Bug fixed: the mark stayed active over the new comment, so a second =C-c h= nested another comment inside it. The mark is now deactivated and point ends after the comment.
- Multi-line regions: each non-blank line becomes its own comment.
  - The font-lock rule matches one line only, so one comment across lines would export but never highlight.
  - Indentation, trailing spaces and blank lines stay outside the markers.
- A region containing =@@= is refused with a =user-error= (nothing changes).
- A whitespace-only region counts as no region.
- The edit is one undo step (=atomic-change-group=).
- Point at the start or end of the region gives the same result.
- Literate doc updated first, =.el= re-tangled (=tools/check-tangle.sh= shows only this module changed by this PR).
- No =CHANGELOG.org= edit (nightly tidy owns it).
