/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW2A2eSSDFWoiCBPbnU5SKFk9][project thread]]/

Before: =init.el= ended with Customize-generated =custom-set-variables= and =custom-set-faces= blocks (about 190 lines, mostly a snapshot of =org-agenda-files=), and =sp-fonts= set the default face three times in competing ways.

After: =init.el= has no such blocks. Every setting is in the module that owns it, and =custom-file= points to =var/etc/custom.el= (set in =early-init.el=, never loaded), so Customize can't write into =init.el= again.

| Setting                                                                                                   | Now                                                                                                                                                                                                       |
|-----------------------------------------------------------------------------------------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Fonts (=sp-ui-default-font=, =sp-ui-variable-width-font=, =ha-= lists, direct =set-face-attribute= calls) | =sp-fonts= is rebuilt around =fontaine=: one =regular= preset, Aporetic Sans Mono 150 as the default face, Aporetic Serif Mono 120 as variable-pitch (placeholder until the variable fonts are organised) |
| =sia/modeline=                                                                                            | default changed to =doom-modeline= in =sp-choose-modeline= (matches its commentary)                                                                                                                       |
| =bibtex-aux-opt-alist=                                                                                    | =:custom= of =use-package bibtex= in =sp-bibprocess=                                                                                                                                                      |
| =transient-show-menu=, =helm-minibuffer-history-key=                                                      | =:custom= in =sp-base-libraries=                                                                                                                                                                          |
| =org-default=, =org-extra-emphasis*= faces                                                                | =set-face-attribute= in =sp-org-emphasis=                                                                                                                                                                 |
| =custom-safe-themes=                                                                                      | dropped; =sp-themes= already sets it to =t=                                                                                                                                                               |
| =org-agenda-files=                                                                                        | dropped; =sp-org-agenda= sets the directories and =sp-org-node-mem= rebuilds the list after each scan                                                                                                     |
| =package-selected-packages=, =package-vc-selected-packages=                                               | dropped; elpaca does not use them                                                                                                                                                                         |

Docs for the touched modules and =CHANGELOG.org= are updated.

Not verified (no Emacs in the container):

- =fontaine= preset keys and =fontaine-restore-latest-preset= follow its documented API but were not run; the default face is now Aporetic Sans Mono 150 instead of the PT Mono 120 that used to win at the end of startup.
- =M-+=, ~M-=~ and =M--= now change the default face height by one point; =fontaine-set-preset= resets it.
- Until =org-mem= finishes its first scan, the agenda uses =~/notes/area/= and =~/notes/inbox/= instead of the old saved list of about 150 files.
- A theme that defines the Org faces could override the =set-face-attribute= values; the old =custom-set-faces= always took precedence.
