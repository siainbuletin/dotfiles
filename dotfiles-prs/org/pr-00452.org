**** What it does
:PROPERTIES:
:CUSTOM_ID: what-it-does
:END:
- Selecting text in DEVONthink's PDF viewer still needs DEVONthink's Highlight action; DEVONthink has no setting for "highlight on select".
- This PR does that action for Sia, two ways:
  - =C-c k d h= (=sp-devonthink-highlight-selection=): one key presses Highlight.
  - =C-c k d H= (=sp-devonthink-auto-highlight-mode=): select in DEVONthink and nothing else; about two seconds later the selection is highlighted.
- How the mode works:
  - Looks at the front window's =selected text= every second, only while Emacs is not the focused app.
  - Highlights once the same selection survived two looks, then not again until the selection is cleared.
  - Stops itself with a message on any error.
- How Highlight is pressed: =System Events= clicks the menu item named =Highlight= (=sp-devonthink-highlight-menu-item=), found by name in every menu.
- Needs the Accessibility permission for Emacs.
- Literate source: =docs/tangles/academic/sp-devonthink-autohighlight.org= (bullet lists).
- 11 ERT tests cover the pure parts (settling, no repeats, re-arming, quoting, key bindings); the AppleScript was not run.
