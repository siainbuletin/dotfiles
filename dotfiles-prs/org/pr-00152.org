**** What
:PROPERTIES:

Text typed in =M-x= glitches and disappears in =vertico-posframe= (and did in =mini-frame=). Only =M-x= is nano-styled, so the suspects are the three nano parts in =sp-posframe=. The dotted line stays, as asked.

- Prompt: =:inverse-video= and =:box= are replaced by explicit swapped colours (=sp-posframe--prompt-block=). The box makes the first line taller than the others, and reverse video in a child frame is a likely source of the invisible text (#121).
- Dotted line: its overlay is now created like Vertico's own (empty, both markers advancing). Before, the front marker did not advance, so the overlay grew to cover the typed input.
- The literate doc has a new section with checks to run in the open =M-x= and a list of hooks to remove one by one, to find the cause if this does not fix it.
