Follows #193. In =sp-author-notes=:

- =pub-author= values with quoted names (="A", "B"=, ="A" "B"=, or a stray ="Tim Wildschut=) give one author, and one =:person:= note, per name. A comma inside quotes (="Lee, Ann"=) is still flipped.
- =[[denote:ID][Name]]= links become =[[id:...]]= links when a note with that Denote identifier (=#+identifier:= or the file name) and an =:ID:= exists; otherwise they are reported and left alone. The preview lists them.
- Unquoted names are split as before (=;= or =and=, never a comma). Links mixed with loose words are still left alone.

Tested: 13 ERT tests in Emacs 29.3 batch with a temporary vault (=sp-org--write-note= stubbed). Not run on the real =~/notes= or with vulpea.
