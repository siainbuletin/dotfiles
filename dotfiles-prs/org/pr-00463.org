**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- Cause of "emureader does not load" and =elpaca-update-all= failing with =(wrong-type-argument stringp nil)= in =elpaca-git--fetch=:
  - Elpaca's cached GNU ELPA menu (=var/elpaca/cache/gnu-elpa.eld=) was last written on Oct 7.
  - emureader was renamed from emacs-reader on Nov 4 (0.4.0), so the cached menu has no recipe for it.
  - =:ensure t= then queues a recipe with no repository; the fetch fails, nothing is built, and =apropos= finds no =emureader-*= command.
  - =lsp-mode= fails only because it waits on emureader.
- Fix: =use-package emureader :ensure (:repo "https://codeberg.org/MonadicSheep/emureader.git")= (the upstream GNU ELPA mirrors).
- Literate doc updated as bullet lists (reason, build step, what is still unverified).
