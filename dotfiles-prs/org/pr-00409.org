**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Alignment:* nothing is padded with spaces any more. The three spaces before each column are one space stretched (=display (space :align-to N)=) to the column where it starts, so the columns line up in any font, including a proportional one.
- *Citekeys first, capped at 45:* columns are served by priority (=sp-citations-column-priorities=): citekey and year, then title and authors, then tags. The citekey column takes the width of the longest key but is limited to 45 characters (=sp-citations-column-max-widths=, commit 45221b0). In the =bibliography= repo (master, 15,129 keys) the longest key is 77 characters, then 61, 57, 56; 99% are 44 or less, so only the few longer keys are cut. #410 adds a lint that flags and shortens keys over 45.
- *Room for titles:* the entry type and =beref= columns are no longer shown (easy to restore in =citar-templates=); tags only get what titles and authors do not need.
- *Indicators:* emoji 🌿️ link, 📁️ file, 📝️ note, 🎓️ cited (new), with no padding between them. An absent one is a blank of the same width; one stretched space ends the block. The faces and Modus colours from #405 are removed, since emoji have their own colours.
- *Why an override:* citar builds the padding from the last character of each indicator, so an empty padding would replace the emoji by a space; =sp-citations--indicator-symbols= overrides =citar--make-indicator-symbols=.
- Docs updated in =docs/tangles/academic/sp-academic.org= (bullet lists); =sp-citations.el= is the matching tangle. No CHANGELOG edit.
