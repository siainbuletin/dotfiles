**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- *=litdb= source* for =consult-omni= (in =sp-browsing=): shells out to the =litdb= CLI asynchronously (the previous call is killed as you type, 60 s timeout), so the slow first litdb call does not freeze Emacs.
  - =litdb= runs =litdb fulltext= and is in the default =consult-omni-multi-sources=.
  - =litdb semantic= runs =litdb vsearch= (loads the model on each call, so it is only a command, =consult-omni-litdb-semantic=).
  - Results are candidates in the minibuffer; =RET= on one opens its address (OpenAlex/DOI) with =browse-url=, or visits the file. Generic: any record litdb holds (e.g. later from DEVONthink) shows up.
  - Disabled when the =litdb= program is not on =exec-path=. =b=/=B= in =sp-search-menu=.
- *No accidental Google*: =RET= on input that is not a result (results not arrived yet) ran =consult-omni-external-search= in the browser. =sp-consult-omni-ignore-new= now only says nothing was opened.

Docs (=sp-browsing.org=, =sp-search.org=), tangled modules and CHANGELOG updated; tangle check agrees for these files.
