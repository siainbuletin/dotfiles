**** What changes
:PROPERTIES:
:CUSTOM_ID: what-changes
:END:
- Replaces the global Cmd+Ctrl+Option+H leader (and its Cmd+Option+Space comment) in =hammerspoon/.config/hammerspoon/devonthink.lua=.
- =Caps+x=: Tools > Annotate > Highlight Text.
- =Caps+c=: next colour (Yellow, Red, Green, Blue), then highlight again.
- Keys act only when DEVONthink 3 or 4 is frontmost; elsewhere they do nothing.
- The activation watcher is removed: highlight mode starts only when you press the key.

**** Why these keys
:PROPERTIES:
:CUSTOM_ID: why-these-keys
:END:
- The layer never reaches Emacs and uses no Option, Cmd+Space or Ctrl+Space chord.
- =x= and =c= are free in the layer (used: h/j/k/l, 1-9, a, b, d, e, m, t, w, =/=, =,=, tab, return, escape).
- A native App Shortcut did not work, so no DEVONthink-side setup is needed.
