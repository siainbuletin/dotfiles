**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- New module =sp-vulpea-grouped-backlinks-widget= registers a =vulpea-ui= widget, =grouped-backlinks=, at order 310 (right after the standard =backlinks= widget at 300).
  - Registered like the Link inbox widgets in =sp-tab-inbox=: a =vui-defcomponent= plus =vulpea-ui-register-widget=.
  - Shows the note =vulpea-ui= shows (=use-vulpea-ui-note=), so it follows the main note with the rest of that sidebar. The sidebar's follow toggle does not apply to it.
  - Each group is its name and count, then a =vulpea-ui-note-link= per note (opens in the main window).
  - Reuses =sp-vulpea-grouped-backlinks-sorted=, so the Org view, sidebar and widget agree.
- It is a separate file so =sp-vulpea-grouped-backlinks= needs neither =vulpea-ui= nor =vui= at load time. =sp-vulpea-ext= requires it after the grouping module (=vulpea-ui= is loaded by then through =sp-vulpea-ui=).
- Literate doc (=sp-vulpea.org=, now twelve files) and the module table in =README.org= updated; the commentary no longer says "NOT YET a widget".
