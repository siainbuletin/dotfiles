The 0.85 relative height of #146 made the dashboard boxes misalign. Removed =sp-fonts-dashboard-menu-height= and =sp-fonts-ui-faces=. Instead =sp-dashboard-menu-face= is added to =fontaine-faces= (in the =:config= of the fontaine block, before the first preset is set) and the =t= preset sets =:sp-dashboard-menu-face-height= to 1.0, so the dashboard is back on the grid of the =default= font and a preset can change the height. I read fontaine's source (3.1.0): =fontaine-faces= is a plain list of faces, and a preset reads =:FACE-height= as a multiple of the =default= height. Docs and CHANGELOG updated.

Any other height makes box text and box lines differ in width, so boxes only align at 1.0 unless the layout is moved to pixel widths.
