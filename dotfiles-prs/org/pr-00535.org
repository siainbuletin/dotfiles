- New =sp-check-tangle= in =sp-org-babel= (next to =sp-tangle-changed=), with =check-tangle= as an alias.
  - Runs =tools/check-tangle.sh= from =user-emacs-directory= with =compilation-start=, so Emacs stays usable.
  - Output goes to =*sp-check-tangle*=; the echo area says =passed= or =FAILED=.
  - =g= in the buffer re-runs it.
  - =user-error= if the script is missing or not executable.
  - =sp-check-tangle-script= holds the script path.
- Docs (bullets): new section in =docs/tangles/text/sp-org-babel.org=, plus mentions in =docs/tangling-instructions.org=, =README.org= and =docs/architecture/stable-and-sandbox-emacs.org=.
