Design doc =docs/architecture/devonthink-emacs-integration.org= for a deeper DEVONthink and Emacs integration: search (DEVONthink and =litdb=), page-level links back to DEVONthink, browsing and tagging from Emacs, and a two-way link between a record and its litnote. Page-level indexing is limited to documents with annotations or a read =read-status=, to keep the =litdb= index small.

Design only; no code. Nothing was run in Emacs, and the page-anchor syntax, annotation-count semantics, custom metadata field and URL handler are listed in the doc as the first things to verify.
