**** Problem
:PROPERTIES:
:CUSTOM_ID: problem
:END:
- =C-x b= did not offer =*Messages*= right after startup.
- Cause: =tabspaces-use-filtered-buffers-as-default= remapped =switch-to-buffer= to a command listing only the tab's buffers, and =tabspaces-exclude-buffers= removes =*Messages*= from that list.

**** Change
:PROPERTIES:
:CUSTOM_ID: change
:END:
- =tabspaces-use-filtered-buffers-as-default= is now nil.
- =C-x b= runs =sp-tabs-switch-to-buffer=, remapped in =tabspaces-mode-map=.
- Default: the regular =switch-to-buffer= (all buffers, =*Messages*= included).
- Filtered switcher (tab's buffers, then =*Messages*= at the end) applies when:
  - =sp-tabs-filter-buffers= is non-nil (every tab), or
  - the tab name is in =sp-tabs-filtered-tab-names= (default ="Email"=), or
  - the major mode is derived from =sp-tabs-filtered-modes= (mu4e main/headers/view, =message-mode=).
- =sp-tabs-toggle-tab-filter= toggles the current tab by name (=f= in =tabspaces-command-map=), meant for Projectile/project tabs.
- =tabspaces-exclude-buffers= is unchanged.
- Literate doc =docs/tangles/ui/sp-tabs.org= updated in step with the =.el=.
