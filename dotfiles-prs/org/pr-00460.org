**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Request:* copy author, title and BibTeX keywords of an entry into the properties of its DEVONthink record, so they carry over when the record is moved or renamed, and do it from =sp-fetch-inbox=.
- *New module =sp-devonthink-bibsync=* (doc =docs/tangles/academic/sp-devonthink-bibsync.org=, bullet lists):
  - Keywords go to the record's tags (native field). They survive rename, move, re-index and export. Only added, never removed.
  - Author and title go to custom metadata (=bibauthor=, =bibtitle=; options =sp-devonthink-bibsync-author-id= and =-title-id=). Stored in the database with the record, so they also survive those operations. BibTeX wins on each run. Authors joined with =; = instead of =and=.
  - Not used: the record name (it is the citekey) and the comment (your notes); the author/title DEVONthink reads from the PDF are read-only for scripts.
  - Record found by citekey with =sp-devonthink-record=; a crossref parent's record is skipped (a chapter must not tag the whole book).
- *One record and batch:*
  - =sp-devonthink-bibsync= (=C-c k d y=): litnote's citekey, else asked.
  - =sp-devonthink-bibsync-many=: several chosen keys.
  - =sp-devonthink-bibsync-all=: every record in the index that has an entry, after one question. The =.bib= files are read in one pass; the DEVONthink writes are two scripts (one metadata script with a =try= per record, one tag read and one tag write).
  - Embark action =y= on a record of =sp-devonthink-browse=.
  - Lisp: =sp-devonthink-bibsync-keys= and =sp-devonthink-bibsync-entry=.
- *=sp-fetch-inbox=:* after the entry is appended, =sp-fetch-inbox--sync-metadata= calls =sp-devonthink-bibsync-entry= with the final entry text (option =sp-fetch-inbox-sync-metadata=, default t). A failure is a message only; the article is already filed.
- *Not fighting #455:*
  - #455 mirrors tags to BibTeX =keywords= only after the browser tag action. This PR writes tags through =sp-devonthink--set-tags-script= directly, never the browser action, so it never triggers that mirror: no loop.
  - Both directions only add and ignore case, so repeating either changes nothing.
  - The litnote =keywords= line (#443) is not touched here.
- =when-let*= style only; no CHANGELOG edit. =sp-academic= requires the module; README row added.
- *Tested* (Emacs 29.3 batch, DEVONthink faked): 8 new tests in =sp-devonthink-bibsync-test.el=, =sp-fetch-inbox-test.el= 15 pass (1 new), =sp-devonthink-tags= 11 and =sp-devonthink-browse= 9 still pass.
- *Untested:* all AppleScript. In particular (also in the doc):
  - whether =add custom meta data … for "bibauthor"= creates the field or needs it defined first in DEVONthink (Settings > Data > Custom Metadata), and which identifier a hand-defined field gets;
  - whether the tag order is kept; real =.bib= files with unusual LaTeX in authors or titles (only =\&=, braces and line breaks are cleaned).
