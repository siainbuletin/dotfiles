- *Request:* tags added in =sp-devonthink-browse= → =embark-act= → =sp-devonthink-record-tag= are recorded in the litnote (also when it is generated later) and mirrored into the matching BibTeX record.
- *After tagging in the browser* (=sp-devonthink-mirror-record-tags=):
  - Litnote: found by the record's citekey (record name without =.pdf=), =keywords= line rewritten from the record's full tags (same format as #443) and saved. A litnote open with unsaved changes is skipped and named.
  - BibTeX: the /added/ tags go into the entry's =keywords= field, after one =y-or-n-p= listing the entries. Existing keywords are kept, repeats ignored (case), =;= or =,= separator kept, field created if missing. A =.bib= buffer with unsaved changes is skipped and named.
  - Inbox records (name not a citekey: no litnote, no entry) are skipped; the browser says how many, never an error. A failure of the mirror is reported but the tags stay in DEVONthink.
- *Litnote generated later:* new hook =sp-litnotes-meta-fill-functions=; =sp-devonthink--fill-keywords= fills an empty =keywords= line from the record's tags. Skipped in batch fill, off macOS, for a crossref parent's record, and when the line already has a value.
- *Options:* =sp-devonthink-bibtex-keywords= (nil = no BibTeX part), =sp-devonthink-keywords-on-fill= (nil = no fill-time tags), =sp-devonthink-keywords-key= (#443; nil = no litnote part).
