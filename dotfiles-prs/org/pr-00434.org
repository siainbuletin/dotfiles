**** Problem
:PROPERTIES:
:CUSTOM_ID: problem
:END:
- =M-x sp-devonthink-insert-link= never offered a page.
- Cause: the page was read by =sp-devonthink--read-page=, which asks only when a prefix argument is given (=C-u=). A plain =M-x= returned nil, so only a whole-record link could be inserted.

**** Change
:PROPERTIES:
:CUSTOM_ID: change
:END:
- =sp-devonthink-insert-link= now always asks ~Page (empty = whole record):~ after the citekey.
- Accepts a number from 1; an empty answer links the whole record; anything else (text, 0) asks again.
- =sp-devonthink-open-from-note= and =sp-devonthink-citar-open= keep the prefix-argument behaviour (opening is quick, a page is the exception).
- Doc: =sp-devonthink.org= (tangled to =sp-devonthink.el=); 3 new ERT tests (17 pass); tangle check passes.
