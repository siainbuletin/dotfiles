**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
Integrates the pasted =font-cycle.el= into =sp-fonts= (doc section "Font cycling" + tangled module), on top of the existing fontaine presets.

- =M-x sp-font-cycle= opens a transient menu: left/right cycle the installed families, up/down change the size (reusing =font-size-increase=/=-decrease=), =y= copies the =set-face-attribute= form, =r= restores the starting font, =q= quits.
- The family list is =sp-font-cycle-families= (your list) plus the default families of =fontaine-presets=, filtered by =find-font=.
- *=s= saves permanently*: it asks for a fontaine preset (current one by default) and rewrites =:default-family= / =:default-height= of that preset in =docs/tangles/ui/sp-fonts.org= /and/ =libraries/modules/ui/sp-fonts.el= (so the tangle check stays green), updates the preset table row in the doc, then =y-or-n-p= offers to =load= the module and re-apply the preset. It refuses if a buffer visiting either file is modified.
- No key is bound (=C-c f= is taken); bind =sp-font-cycle= where you like.
