**** What changes
:PROPERTIES:
:CUSTOM_ID: what-changes
:END:
- =Caps+Option+1= to =Caps+Option+7= pick the colour directly (1 Red, 2 Green, 3 Blue, 4 Yellow, 5 Orange, 6 Purple, 7 Grey) and start highlighting.
- =Caps+c= cycling stays: it is still handy to step through colours, and it shares the new =setColor= function.
- =Caps+Option+Shift+1..7= only set the colour and do not start highlighting. This is for recolouring highlights selected in the Annotations inspector.
- Keys work only while DEVONthink is in front.
- =aerospace-keys.lua= also opens the Caps layer when Option is already held, so either press order works.

**** Clash check
:PROPERTIES:
:CUSTOM_ID: clash-check
:END:
- Caps+1 to 9 are AeroSpace workspaces, so plain numbers could not be used.
- Caps+Option+anything is unused in the layer, so there is no clash. Option only reaches Hammerspoon, never Emacs, so it does not become Meta.
- Caps+Ctrl+h/j/k/l (join-with) and Caps+Shift+number (move to workspace) are untouched.

**** Recolouring several highlights (unverified)
:PROPERTIES:
:CUSTOM_ID: recolouring-several-highlights-unverified
:END:
- I found no DEVONthink scripting call for annotation colours, so there is no direct way to recolour a selection.
- =Caps+Option+Shift+N= runs the same Format > Highlight Color item. If DEVONthink applies it to the annotations selected in the inspector, it recolours them; if not, it only changes the colour for new highlights.
- Please test it with several selected annotations and tell me what happens.
