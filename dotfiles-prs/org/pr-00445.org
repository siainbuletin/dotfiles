**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Request:* =.org= files should appear in =ibuffer= by their =#+title=.
- *How:* a new display column =sp-name= (copy of the built-in =name= column: mouse map, help text, summary, face) that shows the Org title, else the buffer name.
- *Both format lists* (=ibuffer-formats= and =nerd-icons-ibuffer-formats=) use =sp-name= where they used =name=.
- *Title lookup is cheap:*
  - only Org-mode buffers are looked at, and only the first 4000 characters;
  - the result is cached per buffer on =buffer-chars-modified-tick=, so the text is scanned again only after an edit;
  - narrowing is ignored; a missing or empty =#+title= falls back to the buffer name.
- *Option:* =sp-buffers-org-title-in-ibuffer= (default =t=; =nil= lists buffer names again).
- *Tradeoff, why not rename buffers:*
  - titles change while you type, and two notes can share one, so renaming would fight Uniquify and =switch-to-buffer= completion;
  - the column leaves the real buffer name alone, so Popper, the =name= filters and every =buffer-name= caller keep working.
  - Cost: the title shows only in ibuffer; =C-x b= and the mode line still show the file name.
- *Unchanged:* filter groups (they match by mode and name), sorting (compares real buffer names, so a title does not change the order), the Filename column still shows the path.
- Docs: new section "Org title in the buffer list" in =sp-buffers.org= (bullets); =.el= re-tangled, =tools/check-tangle.sh= clean after tangle.
- Tests: =tests/sp-buffers-test.el=, 12 ERT tests pass on Emacs 29.3 (title found, case/indent, missing, empty, non-Org, narrowing, cache follows edits and is reused, option off, real ibuffer listing, formats and groups still present).
- Not run in a GUI Emacs with =nerd-icons-ibuffer= and the real vault. =when-let*= style only; no CHANGELOG edit (nightly tidy).
