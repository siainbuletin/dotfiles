** Description
/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW27wdcZpy5tWFoUfsGvALeMr][project thread]]/

Before: all 180 literate docs sat flat in =docs/tangles/=, while the modules they produce are grouped in =libraries/modules/= subdirectories.

After: each module doc is in the matching subdirectory of =docs/tangles/= (=academic/=, =base/=, =base/navi/=, =custom/=, =env/=, =funct/=, =media/=, =prog/=, =text/=, =tooling/=, =ui/=), next to its =-old.org= predecessor. The older topic notes that have no module (=org-config.org=, =search.org= and so on, plus =sp-typesetting.org=, =sp-typst.org=, =sp-helper-functions.org=, =sp-appearance-overview.org= and =sp-music-composition.org=) stay at the top of =docs/tangles/=.

How: the 145 docs are moved with =git mv=. Their tangle paths and README links gain the extra =../=, relative links to the older notes are adjusted, the module tree in =docs/main.org= links to the new locations, and the tangle-all block and shell one-liner in =README.org= now search =docs/tangles/= recursively (and avoid backslashes, so the one-liner also works in fish). I ran the new tangle-all command on a copy: it tangles 131 docs and produces the same =.el= files as the old layout on =main=, apart from =sp-org-issues.el= being in =custom/=.

This PR is based on #9, because =sp-org-issues= is moved there. Retarget it to =main= once #9 is merged.
