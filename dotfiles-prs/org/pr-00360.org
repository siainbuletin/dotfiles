- Name forms are the note title plus its =ROAM_ALIASES=. When =sp-bibprocess= is loaded, names with the same surname and compatible given names (the lint matcher from #354) count as possible matches.
- Report is a =sp-batch-report=: no litnote (exact), no litnote (possible), litnote exists but is not linked to the note, then already in the note. =d=/=u= drop and restore, =g= re-reads.
