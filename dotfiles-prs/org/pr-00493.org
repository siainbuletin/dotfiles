**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Problem:* Emacs asks "Symbolic link to Git-controlled source file; follow link?" for every Stow-linked file.
- *Cause:* =vc-follow-symlinks= was set only by =sp-auto-follow-symlinks=, which only =sensible-defaults/use-all-settings= (in =sp-helper-funct=) calls. Nothing calls that function, so the setting never ran.
- *Fix:* =sp-navi= calls =(sp-auto-follow-symlinks)= when it loads, so =vc-follow-symlinks= is =t=. The buffer visits the real file in =~/dotfiles=.
- Docs: =sp-navi.org= section rewritten as bullets; =.el= matches the doc; =sp-vcontrol.org= now says "called when =sp-navi= loads".
- No CHANGELOG edit.
- *Not changed:* the other helpers that only =use-all-settings= would call (for example =sp-open-from-home-dir=) are still never run.
- *Not tested by Claude:* no Emacs in the container; the change is one top-level call.
