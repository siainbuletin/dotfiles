The small form of #254 (removed in #259) that Sia chose after finding the startup hang came from the vterm/fish setup, not =svg-tag-mode=.

- =M-x sp-org-heading-svg-tags-mode= (in =sp-faces=, doc and tangled =.el=) draws the tags at the end of an Org heading as stock =svg-tag-mode= tags, in the current buffer only.
- *Off by default, nothing hooked, nothing runs at start.* It reuses the =svg-tag-mode= already declared in =sp-faces=; no new package, no =load-path=, no theme hook.
- No tag-group colours, palette or emoji. The tag face is =org-tag=.
- =#+filetags:= lines and TODO keywords are untouched: a match only counts inside the tags group of a heading (group 5 of =org-complex-heading-regexp=).
- Stays off with a message in a terminal frame or without SVG.

Checked in headless Emacs 29.3 with the real =svg-tag-mode= and a stub for the image: on =#+filetags: :a:b:= / =* TODO Title: x :p:q_1:= / =body a:b:= only the heading tags get a display. *Not run in a graphic frame.*
