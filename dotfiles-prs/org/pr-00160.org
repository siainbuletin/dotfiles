**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
=M-x sp-load-config-file= is =load-file= rooted at the configuration folder (=sp-load-path=). It lists every =.el= file below it, relative to the folder, and completes on them (category =file=, so Marginalia and Embark work), then loads the chosen one. No need to type the path.

The search is =directory-files-recursively=, not a shell tool, and skips =elpaca=, =eln-cache=, =backups=, =auto-save-list=, =.git=, =var= and =url= (=sp-load-config-file-excluded=).

It lives in =sp-navi= next to =sp-find-file=; the literate doc (=sp-navi.org=) and CHANGELOG are updated. No key binding added.
