/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW23Yd38q22bNvkAAYUumjJrU][project thread]]/

*Before:* the mode line showed nothing. =sp-lambda-line= set =mode-line-format= to a bare ="%_"= when the position is =bottom=, overwriting the status line lambda-line had just installed. lambda-line also never shows minor modes or =global-mode-string= (so no tag emoji).

*After:*

- =sp-lambda-line= is renamed =sp-header-and-modeline=. The divider bug is gone, and the mode line is never a bare divider (no =top= / layout option any more).
- *Both modelines work the same way:* the file name (path, or directory) is in a header line, keycast is at the bottom in the mode line, and =keycast-header-line-mode= is no longer turned on (=sp-frame= has the call commented out).
- *=sp-header-and-modeline=:* lambda-line in the mode line at the bottom; header line = path on the left, project name on the right; keycast is the right-hand (tertiary) part of the line through =lambda-line-default-tertiary-function= (keycast's own mode-line segment is anchored after an empty element and shows nothing); the tag emoji of =sp-tag-emoji= are appended to the middle part of every mode line (advice on =lambda-line-compose=); lambda-line faces are set from the theme (=mode-line=, =mode-line-inactive=, =mode-line-buffer-id=, =success=/=warning=/=error=) at load and after =sp-load-theme=.
- *=sp-prot-modeline=* (renamed from =sp-modeline=, adapted from Prot's =prot-modeline.el=): buffer name, major and minor modes, branch, Flymake, tag emoji (misc info), keycast after the branch with Prot's settings (=sp-prot-modeline-keycast=), and the path in a header line. Not loaded by =init.el=; a commented line beside ='sp-header-and-modeline= loads it instead (load one of the two).
- Docs, docs index and CHANGELOG updated; the docs tangle to the =.el= files.

*Not tested:* nothing was run (no Emacs in the container; the =.el= files were only paren-balanced by script). To check in Emacs 31: header next to the mode line, keys appearing at the right of lambda-line (the =keycast-format= call and the anchor trick are the riskiest part), tag emoji in an Org buffer, colours after =sp-load-theme=.
