**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- Problem: after =make-frame=, =C-x b= in the new frame shows almost nothing.
- Cause (checked in the installed =tabspaces.el=):
  - =tabspaces--local-buffer-p= and =tabspaces--buffer-list= read the =buffer-list= and =buried-buffer-list= frame parameters.
  - =sp-tabs= uses =tabspaces--local-buffer-p= for the "Workspace Buffers" consult source, and hides the full source.
  - A new frame has empty frame parameters.
- Fix: new global minor mode =sp-frame-share-buffers-mode= in =sp-frame=, on by default.
  - On =after-make-frame-functions= it copies =buffer-list= and =buried-buffer-list= into the new frame.
  - =before-make-frame-hook= remembers the previously selected frame as the source.
- Option =sp-frame-share-buffers-scope=:
  - =selected= (default): copy from the previously selected frame, so the same workspace.
  - =all=: every live, non-hidden buffer.
- Command =sp-frame-share-buffers-now= does the same for an existing frame.

**** Synthetic frames
:PROPERTIES:
:CUSTOM_ID: synthetic-frames
:END:
- Frames made by code (the =vulpea-ui-view= frame from #447 calls =make-frame=), =emacsclient= frames and AeroSpace-tiled frames all run the hooks, so they are treated like normal frames.
- Skipped: child frames (=parent-frame= parameter, e.g. posframe) and any frame with the =sp-no-share-buffers= parameter.
- Errors are caught and only print a message, so =make-frame= never fails because of this.
