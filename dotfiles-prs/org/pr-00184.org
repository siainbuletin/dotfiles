*After:* =M-x sp-search= (=C-c s m=) opens a Magit-style =*sp-search*= buffer as the first screen, with the transient =sp-search-menu= shown at the top of the frame over it.

**** Changes (=sp-search= module and doc, CHANGELOG)
:PROPERTIES:
:CUSTOM_ID: changes-sp-search-module-and-doc-changelog
:END:
- *Results buffer* (=sp-search-mode=): header (directory, project, active completion frameworks, =rg= warning), the current ripgrep search grouped by file, and the list of saved views. Keys: =s= search (=C-u= for directory/glob/case/regexp), =g= rerun, =m=/=u=/=M=/=U= marks, =x= export, =RET= visit or run view, =?= menu.
- *Menu at the top:* an advice on =transient--show= uses =sp-search-menu-display-action= (top side window) only while =sp-search-menu= is active, so Magit's menus are untouched.
- *Saved views as Org files* in =sp-search-views-dir= (default =search-views/= in =sp-notes-dir=): a =Parameters= heading with =SEARCH_*= properties and a =Results= list of =file:= links. =sp-search-run-view= re-runs the stored search; nothing goes in =.el=.
- *Consult searches:* =embark-export= to a =grep-mode= buffer, then =E= exports the region or buffer (asks for the query to store).
- Menu: new =/=, =V=, =O= keys; the tab-inbox engine moved to =P= (it clashed with =T= consult-todo); =sp-tab-psearch= is =t=. Other keys/guards as before. Key clash note: =C-c s l=/=C-c s r= are shadowed by easysession in =sp-keys=.
