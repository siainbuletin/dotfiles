**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- New command =sp-notes-trash= in =sp-notes=, bound to *=C-; n d=* (=d= for delete; the free letter in the notes keymap beside =c= create and =o= open; the old Denote =n d= is gone).
- Target: the current buffer's file; with =C-u=, a file picked from =sp-notes-dir=.
- Confirmation shows the note title and path, and warns about unsaved changes.
- Backlinks: other notes linking to any =:ID:= in the file (via =vulpea-db-query-links-to=) are listed (first 5) and a typed =yes= is required.
- After the move succeeded: kills the buffer, drops the ids from =org-id-locations=, and calls =vulpea-db--forget-file= so the note leaves the index and other notes' backlinks.
- Never deletes for good: if the trash fails, nothing else changes.
- Refuses buffers without a file, missing files, protected files (=inbox.org=, =dg-synthesis.org=) and files locked by another Emacs.
- Trash: =move-file-to-trash= with =delete-by-moving-to-trash= on. Emacs with the NS port (Emacs Plus) uses =system-move-file-to-trash=, the Finder trash. A build without it on macOS uses the =trash= command if installed, else =~/.Trash=.
- Docs: new section in =docs/tangles/academic/sp-notes.org=, =sp-keys.org= key list, =global-keymap-namespaces.org= notes row.
- No CHANGELOG edit (nightly tidy).
