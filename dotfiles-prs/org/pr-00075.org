** Description
/Requested by *Sia*/

*Before:* the agendas were rows nested in one narrow "Agenda" box and showed no content.

*After:*

- One box per agenda (=sp-dashboard-agendas=), in a grid of =sp-dashboard-agenda-columns= (fewer if the window is narrow), =sp-dashboard-agenda-box-width= wide, so they grow sideways and down.
- Each lists its 3 most urgent open TODOs, wrapped to 2 lines and cut with an ellipsis. Urgency = priority + near/overdue deadline + scheduled today or earlier + =NEXT=/=PROG=. Deadlines lists the nearest deadlines. Files come from the existing =sp-dashboard-agenda-*-files=, or =org-agenda-files=.
- *Privacy:* private entries (tag =private=, or files matching =sp-dashboard-private-files=) are never inserted while the dashboard is public. =P= cycles auto / public / private; in auto, =sp-dashboard-public-conditions= decides and a check that errors counts as public. The list is empty by default; Wi-Fi and screen-share checks are provided but inert until configured. =g= redraws.
- Doc and CHANGELOG updated; the doc tangles to the =.el=.

*Checked* (Emacs 29.3, headless, sample Org files): ranking, wrapping, grid, public hiding, error → public, =TAB= through the boxes. *Not checked:* a GUI, your real agenda files or speed on a large =org-agenda-files=, and the Wi-Fi / screen-share checks.

*Choices:* TODO lines are not buttons by default (each would add a =TAB= stop); =sp-dashboard-agenda-todos-clickable= turns that on.
