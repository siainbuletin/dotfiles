**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
New option =sp-thesis-dump-trust-local-variables= (default =nil=). When on, =enable-local-variables= is bound to =:all= only in the two places where the module triggers local-variable processing: reading the project's =.dir-locals.el= (=sp-thesis-dump--local-values=) and visiting the task file (=sp-thesis-dump-commit=). Nothing global changes.

**** Risk
:PROPERTIES:
:CUSTOM_ID: risk
:END:
Every variable in those files is applied without a question, including ones that can run code (hooks, =eval= forms where =enable-local-eval= allows). The docstring and the =Trusting local variables= section of the doc say so. The option has no =:safe= predicate, so a =.dir-locals.el= cannot turn it on for itself.
