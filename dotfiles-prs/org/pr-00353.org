**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- Moved these reports onto =sp-batch-report-mode=. Their keys (=d= drop, =u= restore, =A= apply, =g=, =RET=, =n=/=p=) are now the shared ones:
  - author notes report (kept its key filtering and text properties)
  - footnote lint (=a= applies the plan)
  - tag lint (=a= registers a tag)
  - Org normalise report
- The old views stay and are marked obsolete (=make-obsolete=): =sp-author-notes-report-mode=, =sp-org-lint-fn-report-mode=, =sp-org-tag-lint-report-mode=, =sp-org-normalise-report-mode=. New option =sp-batch-report-interface= (=new= by default, =old= brings them back) so both can be compared on the same run.
- The #351 reports gained drop/restore/apply: litnote titles, litnote references, litnote meta fill-all, notes filing and the property conversion preview. A dropped file leaves the list, and =A= converts only the rest.
- =sp-batch-report-key-entries= and =sp-batch-report-without-excluded= let reports built as plain text get keys without changing their text.
- The BibTeX lint already moved in #352 (no old view left), so it is not touched here.
- Not ported: the litnote status table (a table to edit, not a report), the keyword conversion preview (read before a =y-or-n-p=, so no key can be pressed), =sp-author-notes-works-dryrun= (a one-line message).
