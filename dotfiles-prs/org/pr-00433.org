**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Real frame size:* the columns come from the frame Emacs has on the screen (=sp-citations--frame-columns=): the text width of the selected frame in pixels divided by the pixel width of a character of the =default= face (so a font change shows at once, before the frame is resized). While the posframe is on in a graphical frame it takes =sp-posframe-width-fraction= of that, as =sp-posframe-get-size= does. The assumed half-display and AeroSpace gaps are gone.
- *Dynamic:* =sp-citations--apply-layout= runs before =citar-select-ref= and =citar-select-refs= (so before =citar-open=, =citar-insert-citation= and =citar-create-note=). It compares the state (columns, character width, font family and height) with the last one and only then makes the emoji cells and the templates again. A command in an unchanged frame and font costs nothing.
- *Fix for "=sp-citations-fit-layout= does nothing on a font change":* two causes found in citar's source.
  - =citar-refresh= does not exist in current citar, so my guarded call (=(when (fboundp 'citar-refresh) ...)=) never ran, in this module and in the earlier docs.
  - citar keeps every candidate as a pre-formatted string, made when the bibliography is read or when the format string changes. The type emoji cells are in those strings, so with the same templates after a font change nothing made citar format them again. Now, when only the font changed, =sp-citations--repreformat= calls =citar-cache--preformat-bibliography= on the cached bibliographies (no file is read); when the templates change citar does it by itself.
- *Kept:* column order emoji, author, year, title, citekey, keywords; pixel-exact emoji cells; =sp-citations-layout-columns= to override; =M-x sp-citations-fit-layout= to force it.
- *Not done:* no =window-size-change-functions= hook; a resize while the prompt is open applies at the next command.
- *Other places that call =citar-refresh=:* =sp-bibprocess.el= (the long-key fix and =sp-academic.org= lines 2778/2874) also guard it with =fboundp=, so they are harmless no-ops; I did not change them here.
- Tests: =tests/sp-citations-layout-test.el=, 7 pass (columns follow pixel width, character width and posframe mode; the state change makes the templates and, for a font-only change, the re-preformat; plus the layout and emoji-cell tests). Tangle check passes.
- Docs updated in =docs/tangles/academic/sp-academic.org= (bullet lists). No CHANGELOG edit.
