**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- =org-table-widget= only draws a rule where the Org source has an hline, so body rows run together.
- =sp-org-tables= now inserts a rule between every two body rows.

**** How
:PROPERTIES:
:CUSTOM_ID: how
:END:
- The package has no option or hook for row separators, so no fork is needed.
- =:filter-args= advice on =org-table-widget--render= adds an =hline= between body rows before drawing (=sp-org-tables--with-row-dividers=).
- Header rows, existing rules and the outer borders are untouched; the Org source is not modified.
- Turn it off with =sp-org-tables-row-dividers= set to =nil=.
- Literate doc section added in =docs/tangles/text/sp-org-tables.org= (bullet-pointed).
