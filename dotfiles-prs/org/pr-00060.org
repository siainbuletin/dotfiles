**** What it does
:PROPERTIES:
:CUSTOM_ID: what-it-does
:END:
- *=sp-tag-emoji=* (=libraries/modules/custom/=): =sp-tag-emoji-rules= maps a tag, or a list of tags that must all be present, to =:emoji= and/or =:face= (and =:position= prefix/suffix for links). =sp-tag-emoji-mode= shows the tags of the heading at point, or the file's =#+filetags:=, as emoji in the modeline (or header line), and decorates =id:= links with the emoji and face of the tags of their note, read from the vulpea db. A combination rule uses up its tags, so =("@writing" "deep")= replaces the two single emoji. =sp-tag-emoji-check-rules= lists rule tags missing from =org-tag-alist=, so that stays the single tag registry.
- *=sp-emoji-font=* (=libraries/modules/ui/=): prepends the first installed colour emoji family (Apple Color Emoji, then Noto Color Emoji, ...) to the =emoji= fontset. On Linux, =sp-emoji-font-file= or =M-x sp-emoji-font-install= installs an Apple Color Emoji =.ttf= into =~/.local/share/fonts/sp-emoji/=. The font is not bundled (Apple's licence).
- Literate docs in =docs/tangles/custom/sp-tag-emoji.org= and =docs/tangles/ui/sp-emoji-font.org=; =init.el=, =docs/main.org= and CHANGELOG follow.
