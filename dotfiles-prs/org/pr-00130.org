**** Problem
:PROPERTIES:
:CUSTOM_ID: problem
:END:
=M-x sp-split-leave-parents= failed with "Autoloading file .../org/org.elc failed to define function sp-split-leave-parents".

**** Cause
:PROPERTIES:
:CUSTOM_ID: cause
:END:
In =sp-org-base.el=, =(use-package org :bind (:map org-mode-map ("C-x s t" . sp-split-leave-parents)))= makes use-package autoload the command from =org=, which does not define it. Until =sp-split-leave-parents.el= is loaded (it is only required by =sp-vulpea-ext=), the stub points at the wrong file.

**** Fix
:PROPERTIES:
:CUSTOM_ID: fix
:END:
Declare =(autoload 'sp-split-leave-parents "sp-split-leave-parents" nil t)= before the =use-package org= block. use-package only adds its own autoload when the function is not already bound, so the correct one wins and the key binding is unchanged. Doc and CHANGELOG updated.

:PROPERTIES:
:CUSTOM_ID: verification
:END:
Not run in Emacs (none in the sandbox). I read the code only; please check =C-x s t= and =M-x sp-split-leave-parents= in a fresh Emacs. If the error persists, =M-x describe-function sp-split-leave-parents= will show which file the stub names.
