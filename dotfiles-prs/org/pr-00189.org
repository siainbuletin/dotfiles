Extends =sp-org-issues-morning= with two sections, both read through =gh api= (REST, no GraphQL):

- *Notes to self*: your comments (conversation and review comments) on an open PR that start with =Note to self:=, each linking to the comment. These are reminders for you; Claude does not act on or reply to them.
- *Needs further testing*: PRs labelled =needs-further-testing=, open or already merged (the label means merged into main for faster testing, not fully tested yet). Not ranked.

Empty sections are left out. Settings: =sp-org-issues-morning-self=, =sp-org-issues-morning-testing-label=.

Written test first (commit 1 is the failing tests, commit 2 the code). The test header now also stubs =sp-yadm-repo=, =sp-src-dir=, =sp-clones-dir= and =sp-path=, because the suite no longer loaded headless since =sp-org-issues-repos= started using them.
