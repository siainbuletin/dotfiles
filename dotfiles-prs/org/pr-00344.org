**** Problem
:PROPERTIES:
:CUSTOM_ID: problem

**** Change
:PROPERTIES:
:CUSTOM_ID: change
:END:
- Rebind the book table command to =C-c w B= (free; sits next to =C-c w T=/=V=).
- Updated the =.el= and the literate doc (key table, binding block, command text, changelog line).
- GUI-only, no CUA-conflicting keys; no other binding touched.
