First implementation of the design in =docs/architecture/citation-matching-from-selection.org=, macOS only, for testing.

**** What is in it
:PROPERTIES:
:CUSTOM_ID: what-is-in-it
:END:
- =sp-cite-match= (=docs/tangles/academic/sp-cite-match.org=):
  - normalises text and BibTeX fields (accents, casing, ligatures, line-end hyphens);
  - scores surname, year, title and journal, with a DOI shortcut; returns =accept=, =ambiguous= or =none=;
  - splits a selected Bibliography into entries;
  - writes a =Cited works= section between markers (idempotent, shows which works have litnotes);
  - ~org-protocol://sp-cite-match?file=NAME~ handler.
- =sp-reading= (=docs/tangles/academic/sp-reading.org=): citekey to DEVONthink record, open at a page, or index the PDF / open in Preview.
- =hammerspoon/.config/hammerspoon/cite-match.lua=: hotkey (Ctrl+Shift+K) that copies the selection and calls =emacsclient=; loaded from =init.lua= inside a =pcall=.
- ERT tests: =tests/sp-cite-match-test.el= (12), =tests/sp-reading-test.el= (7); all pass on Emacs 29.3 in batch.

**** Not tested (please try on the Mac)

:CUSTOM_ID: not-tested-please-try-on-the-mac

- The litnote lookup through =citar-has-notes= / =citar-get-notes= with =citar-vulpea=.
- =emacsclient= path, =org-protocol= handling and the Hammerspoon file were not run (no Lua or macOS here).
