**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
New module =sp-vulpea-convert-keywords= (section of =docs/tangles/vulpea/sp-vulpea.org=, required by =sp-vulpea-ext=), the sibling of =sp-vulpea-convert-properties= for file-header keywords.

- =M-x sp-vulpea-convert-keywords= lists every =#+key:= in the first section of the current note, with how many notes use it and an example value, and you pick several (=completing-read-multiple=). =C-u= (or =sp-vulpea-convert-keywords-all-notes=) scans every Vulpea note and counts across all of them.
- =#+title:= and =#+date:= are ignored by default (=sp-vulpea-convert-keywords-ignore=).
- A preview buffer shows each note and the =- key :: value= lines it gets; nothing is written until you confirm.
- The meta lines go after the header and drawer, join an existing meta block, repeated keywords become repeated lines, and a re-run adds nothing.
- =sp-vulpea-convert-keywords-remove-original= (default =t=, like the property converter) removes the =#+key:= line.
- The current note is left unsaved (=C-/= undoes); the all-notes run saves each file and skips ones with unsaved changes.
