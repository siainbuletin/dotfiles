*Stacked on #72* (merge #72 first; GitHub then retargets this to =main=). Both touch the =sp-org-ext= require, =docs/main.org= and the CHANGELOG.

*Before:* the table family (PR #43) was named after Vulpea, though it is a personal module for querying a collection of notes.

*After:* files and features are =sp-collection-query-tables= (seven files in =libraries/modules/funct/=, doc =docs/tangles/funct/sp-collection-query-tables.org=); every symbol (function, command, setting, customize group) uses the short prefix *=sp-collec-query-=*. The doc has a section, "Names: why the prefix is =sp-collec-query-=", explaining it: /collec/ is /collection/ (the set of notes a query runs against), /query/ is the spec, and /tables/ is dropped because every renderer shows a table; the long form reached 45 characters. It deliberately breaks the "prefix = feature name" habit, so =sp-collec-query-menu= is the command and =sp-collection-query-tables-menu= the file that defines it.

*User-facing renames* (no aliases for the old =sp-vulpea-table-= names):

- Settings: =sp-vulpea-table-{renderer, install-exc, refresh-delay, link-titles, views-file, exc-column-widths}= → =sp-collec-query-…=.
- Commands: =…-menu=, =-open=, =-open-view=, =-view-save=, =-view-delete=, =-insert-dblock=, =-inline-toggle=, =-inline-mount=, =-inline-unmount=, =-refresh-all= → =sp-collec-query-…=. Key bindings (=C-c w T/v/V/t=) are unchanged. A =setq= of an old setting name in your config must be renamed.
- Dynamic block: =#+BEGIN: collection-query-table= for new blocks; =vulpea-table= still updates in existing notes.
- Saved views file: =sp-collection-query-tables-views.el= in =user-emacs-directory=; while it does not exist the old =sp-vulpea-table-views.el= is read, so saved views carry over.
- Buffer names (=*query-table: …*=) and the mode lighter changed. The feature =sp-vulpea-table= no longer exists; =require 'sp-collection-query-tables=.

Also corrects a line in the table doc left stale by #72, and updates the one use in =sp-vulpea-grouped-backlinks= (=sp-collec-query-select-note=).

*Checked* (Emacs, container): the doc tangles to the seven files, parens check passes. *Not checked:* loading the modules with vulpea/exc/vui/transient, the menu on screen, a real start with Elpaca. Try the menu, a saved view and an old =vulpea-table= block once.
