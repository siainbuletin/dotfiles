Follow-up to #329 and #342: two new columns for the booksection/incollection tables.

**** What changes
:PROPERTIES:
:CUSTOM_ID: what-changes
:END:
- =:bibtex= column ("BibTeX"):
  - lists the citation keys of =ROAM_REFS= as =sp-bib:= links; RET or a click opens the entry in the =.bib= file (=citar-open-entry=);
  - =embark-act= on a key offers the citar actions (entry, files, notes, links, copy reference) through a new embark target finder returning a =citar-key= target; it requires =citar-embark= when embark loads (=sp-citations= already installs it with =:ensure=).
- =:dt-page= column ("DT page"):
  - takes the =crossref= root of each key, its file (=citar-get-files=), and that file's DEVONthink record (same single JXA lookup as =:devonthink=, only when DEVONthink is running);
  - links to ~x-devonthink-item://UUID?page=N~, text "p. 41"; =N= is the first number of =pub-pages= plus an offset, counted from 0 (same convention as =sp-reading= in #343);
  - offset: option =sp-collec-query-dt-page-offset= (default 0), overridden by a =pdf-offset= meta key on the book/collection note;
  - a roman-numeral =pub-pages= links to the PDF ("open").
- Both are now default columns of the book table (=sp-collec-query-book-columns=).
- Literate doc updated in bullets; no CHANGELOG edits.
