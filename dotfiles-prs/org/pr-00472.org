**** What it does
:PROPERTIES:
:CUSTOM_ID: what-it-does
:END:
- Picker of =sp-fetch-inbox= can be sorted:
  - =added=: newest first (DEVONthink addition date, or file modification time in =inbox/=); this is the default
  - =alphabetical=: by name, ignoring case
  - =sp-fetch-inbox-sort= sets the default; =C-c s= in the picker switches (typed input is kept)
- Picker is grouped by the sub-directories that exist in =inbox/= (=sp-fetch-inbox-group=, default on):
  - files directly in =inbox/= are in =(inbox)=
  - DEVONthink sub-groups of the =inbox= group are listed too, as folders of the same name
- Restrict to one folder: =C-c d= in the picker, or =C-u M-x sp-fetch-inbox= before it.
- Vertico/Consult/default UI keep the order: completion metadata sets =display-sort-function=, =cycle-sort-function= and =group-function=.
- Keys are shown in the picker prompt, not the echo area: the echo area is the minibuffer while picking, so =sp-echo-help= hints are suppressed there.
- Duplicate names get the folder appended so each candidate is unique.
- Literate doc updated (=docs/tangles/academic/sp-fetch-inbox.org=, new section "The picker"); the =.el= is the tangled output (checked identical).
