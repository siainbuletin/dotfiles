** Description
Follows #97 (merged).

*Before:* =sp-theme-auto-mode= could only read the macOS appearance (or the time of day); =sp-syswin= and =sp-syslinux= were not loaded, and =sp-syslinux= was empty.

*After:*

- =sp-themes=: =sp-theme-platform= (macos / windows / linux) and three alists naming the function per platform: =sp-theme-system-providers= (reads light/dark), =sp-theme-system-watchers= (calls back on change, returns an unwatch function) and =sp-theme-ambient-providers=. A source with no answer, an error or nonsense falls back to the time of day. Where there is no watcher, the timer polls.
- =sp-macos=: =sp-macos-appearance= (moved from =sp-themes=) and =sp-macos-watch-appearance=.
- =sp-syswin=: =sp-syswin-appearance= reads the registry value =AppsUseLightTheme= with =reg query=; no watcher, so it is polled.
- =sp-syslinux=: =sp-syslinux-appearance= tries the freedesktop portal (=gdbus=), then =gsettings=, then the KDE colour scheme; =sp-syslinux-watch-appearance= listens to the portal's =SettingChanged= signal with Emacs' =dbus=.
- Each of the three modules turns =sp-theme-auto-mode= on for its own platform, and =init.el= now loads =sp-syswin= and =sp-syslinux=.
- *macOS room light:* with =sp-theme-auto-source= set to =ambient=, the lux from =sp-macos-light-sensor-command= picks a family, in this order from the brightest room: =faded-light=, =hard-light=, =faded-dark=, =hard-dark= (=sp-macos-ambient-levels=, default 150 / 60 / 15 / 0 lux), and loads the first theme of that family. =sp-macos-ambient-margin= (25%) keeps it from flickering at a boundary. Checked every 60 s (=sp-theme-ambient-interval=).
- 13 new ERT tests (providers, ambient, watcher, parsers, levels with hysteresis); all 40 tests pass on Emacs 29.3.

*Not checked:* anything on macOS, Windows or a Linux desktop (only the parsing of what they print, and the dispatch, are tested). macOS has no command line tool for the ambient light sensor, so there is no default =sp-macos-light-sensor-command=: it needs a command of your own that prints lux; without one, =ambient= follows the time of day. The default source is still =system=.

*Judgement call:* I read "faded light, hard light, faded dark, hard dark, in this order" as brightest room first. If you meant another order, reorder =sp-macos-ambient-levels=.
