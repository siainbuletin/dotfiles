**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- =vulpea-db-autosync-mode= was already started by an idle timer from =emacs-startup-hook=, but only after 30 idle seconds, and with no guard. Using =sp-find-note= before that left the picker without autosync.
- =sp-vulpea-start-autosync= is now idempotent: cancels the pending timer, does nothing if the mode is already on.
- New =sp-vulpea-schedule-autosync= sets the idle timer; runs at once if init is already over (e.g. module reload).
- =sp-vulpea-autosync-delay= (defcustom, now =number=) defaults to 10 s instead of 30.
- =sp-find-note= calls =sp-vulpea-start-autosync= first.
- Docs updated: =sp-vulpea.org=, =sp-org-tag-groups.org=.

**** Freeze check
:PROPERTIES:
:CUSTOM_ID: freeze-check
:END:
- Enabling the mode only starts the background scan (=vulpea-db-sync-scan-on-enable= = ='background=); the select-cache prewarm stays off (#270). The enable message reports its duration.
- Risk: #270 raised the delay to 30 s while chasing a start-up hang. If 10 s hangs, raise the defcustom.

**** Testing (not run in Emacs; none in the container)
:PROPERTIES:
:CUSTOM_ID: testing-not-run-in-emacs-none-in-the-container
:END:
1. Start Emacs, wait ~10 s idle: =[vulpea] starting autosync...= appears in =*Messages*=; =vulpea-db-autosync-mode= is =t=.
2. Start Emacs and press =M-o f= at once: autosync starts before the picker opens.
3. Edit and save a note's title, =M-o f=: the new title is listed.
4. =M-x sp-vulpea-start-autosync= twice: second call does nothing.
5. =M-x customize-variable sp-vulpea-autosync-delay=, set 3, restart: starts after 3 idle seconds.
