**** Problem
:PROPERTIES:
:CUSTOM_ID: problem
:END:
=C-x t s= reports =vulpea-ui-sidebar-toggle= as undefined. (Separate from #130, which fixed =C-x s t=.)

**** Cause
:PROPERTIES:
:CUSTOM_ID: cause
:END:
=sp-vulpea-ui.el= declared =(use-package vulpea-ui ... :after vulpea)= and bound the key with a plain =global-set-key=. =vulpea= is loaded lazily (its own =:bind=), so the =:after= form never ran and =vulpea-ui= was never loaded; a plain =global-set-key= creates no autoload.

**** Fix
:PROPERTIES:
:CUSTOM_ID: fix
:END:
Drop =:after vulpea= and bind =C-x t s= with =:bind= in the same =use-package=, which autoloads =vulpea-ui-sidebar-toggle= from =vulpea-ui=. =vulpea-ui= requires =vulpea= itself. Doc and CHANGELOG updated.

**** Verification
:PROPERTIES:
:CUSTOM_ID: verification
:END:
Not run in Emacs (none in the sandbox); this is from reading the code. Please check =C-x t s= in a fresh Emacs. If it still says undefined, =M-: (locate-library "vulpea-ui")= shows whether Elpaca installed it.
