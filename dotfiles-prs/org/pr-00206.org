**** What

=consult-omni/:config: Cannot open load file: elfeed=: every consult-omni source requires the package it searches (=elfeed=, =notmuch=, =consult-gh=, =consult-mu=). The loader uses =(require symbol nil t)=, but NOERROR only covers the source file itself, not what it requires in turn, so one missing package aborted the whole =:config=. =sp-consult-omni-load-module= now replaces the loader's =consult-omni-sources--load-module= and skips such a source with a message in =*Messages*=. Install the package to get the source. Doc and CHANGELOG updated.
