**** Cause
:PROPERTIES:
:CUSTOM_ID: cause
:END:
=sp-citations= sets =(note . ,sp-citar-note)= in =citar-templates=, but =sp-citar-note= (in =sp-globals=) defaulted to =nil=. Citar then has no =note= template and signals =No template for "note"= when the note indicator runs, which happens in =jit-lock= during redisplay.

**** Fix
:PROPERTIES:
:CUSTOM_ID: fix
:END:
=sp-citar-note= now defaults to citar's own string, ="Notes on ${author editor:%etal}, ${title}"=, with =:type 'string=. Literate doc and CHANGELOG updated.
