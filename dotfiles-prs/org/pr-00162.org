**** Cause
:PROPERTIES:
:CUSTOM_ID: cause
:END:
=sp-bibliography-dir= was =(sp-paths--dir sp-documents-dir "bibliography/")=, but the first argument of =sp-paths--dir= is an environment variable /name/. =getenv= returned nil, so the folder became =bibliography/= below =default-directory=, which does not exist. =sp-bibtex-files= was then nil and =citar-bibliography= empty, hence =citar-select-refs: No bibliography set=. (=sp-bibtex-dir= no longer exists since #92; =sp-bibliography-dir= is the only option.)

**** Fix
:PROPERTIES:
:CUSTOM_ID: fix
:END:
=(sp-paths--dir "SP_BIBLIOGRAPHY_DIR" (sp-path sp-documents-dir "bibliography/"))=: the env var, else =bibliography/= below =sp-documents-dir=, as the =sp-academic= doc already said. Doc and CHANGELOG updated.

**** Not tested
:PROPERTIES:
:CUSTOM_ID: not-tested
:END:
Nothing was run in Emacs (none in the container). After updating, run =C-c w b r= (=sp-bibtex-register=) or restart; the folder must contain =.bib= files whose names start with a letter or digit.
