**** What changed
:PROPERTIES:
:CUSTOM_ID: what-changed
:END:
- Filter:
  - New =sp-agenda-views-inline-filter= (default =nil= = all keywords, so the unfiltered view stays the default).
  - =M-x sp-agenda-views-inline-filter-set= asks for one keyword (completion over =sp-agenda-views-inline-keywords=), narrows the view and opens it.
  - =M-x sp-agenda-views-inline-filter-clear= shows all keywords again.
  - Transient =sp-agenda-views-inline-menu= on =C-c o X=: =x= open, =f= filter, =c= clear; its title shows the current filter.
  - The view header names the keyword while filtered.
  - The filter is not saved between sessions.
- =SOURCEREFS= added to =sp-agenda-views-inline-keywords=: references made in the PDF being read, for which a litnote is being written. It is separate from =CITE=.
- Docs: bullets in =sp-org-agenda.org= ("Inline keyword view", key table, PR list), =.el= edited by hand to match the blocks.
- Tests: =tests/sp-agenda-views-inline-test.el= covers SOURCEREFS, filter on/off, unknown filter, clear.
