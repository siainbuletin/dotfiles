**** What changes

:CUSTOM_ID: what-changes
:END:
- New module =sp-bibtex-types= (=libraries/modules/academic/=, doc =docs/tangles/academic/sp-bibtex-types.org=): one option, =sp-bibtex-types-tag-alist=, from BibTeX entry type to org tag (case-insensitive), plus =sp-bibtex-types-default-tag= (=text=).
  - booksection → =booksection=, incollection → =incollection=, article → =journalarticle=, book → =book=
  - collection and mvcollection → =collection=
  - phdthesis → =phdthesis=, mastersthesis → =mastersthesis=
  - anything else → =text= (the =base-text= scheme)
  - Functions: =sp-bibtex-types-tag=, =-entry-tag=, =-all-tags=, =-collection-p=.
- =sp-litnotes-meta-create-note= (used by =sp-litnotes-meta-backfill-children=) now tags the new note with =litnote= plus the type tag.
- Reuse in =sp-litnotes-meta--table-view=: the =collection-articles= view is chosen by =sp-bibtex-types-collection-p= instead of its own type list. Behaviour change: =proceedings=/=mvproceedings= now file as =text=, so they get =book-sections=.
- Schema and tag checks:
  - =sp-vulpea-schemas= had no schemas for =book=, =phdthesis=, =mastersthesis=; added (each includes =base-text=).
  - =sp-org-tag-registry=: added =phdthesis=, =mastersthesis= to the literature group.
  - =sp-litnotes-refs= (tag → BibTeX type for stubs): added =mastersthesis=. It stays a separate table, as the reverse direction is not one-to-one.
- Docs updated as bullet lists (=sp-bibtex-types.org=, =sp-litnotes-meta.org=, =sp-vulpea.org=, =sp-org-lint.org=, README module table). No CHANGELOG edits.
