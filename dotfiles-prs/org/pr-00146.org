**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- *Org-sized posframe text.* =sp-minibuffer.el= hooks =sp-text-buffer= on =text-mode-hook=, which scales Org (and all text modes) up 4 =text-scale= steps, so the =default= face alone is smaller than Org text. New =sp-fonts-text-scale-steps= (4) is the single number for both. =sp-posframe--set-text-size= (replaces =sp-posframe--reset-text-scale= from #145) runs first on =minibuffer-setup-hook= (depth -90), drops all face remappings of the minibuffer, whatever buffer you called it from, and sets that scale.
- *Dashboard box text.* =sp-fonts-dashboard-menu-height= (0.85) sets the height of =sp-dashboard-menu-face= relative to =default=. =sp-fonts-ui-faces= applies it when the dashboard loads, after a theme loads and on =fontaine-set-preset-hook=, so it follows the fontaine preset.
- Docs and CHANGELOG updated.
