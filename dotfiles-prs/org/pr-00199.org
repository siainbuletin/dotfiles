**** Why the search failed
:PROPERTIES:
:CUSTOM_ID: why-the-search-failed
:END:
=[]= is the empty vector of enabled sources: =consult-omni--multi-lookup= takes =(aref sources 0)= and there were none. Cause was in the config, not the package: =(require 'consult-omni-sources)= only defines the loader, and the call to =consult-omni-sources-load-modules= sat in a =:tangle no= block, so no source was ever defined and every name in =consult-omni-multi-sources= was silently dropped. (A source is also dropped while its API key, program or package is missing, so a list of only such names fails the same way.)
