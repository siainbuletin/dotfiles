**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
Added to =sp-reading-mode=:

- *Margin glyphs* from Rougier's =draft.org=: =#=, =##=, =###= for heading levels 1-3 and =•= for top-level bullets, in the left margin. A level 4 heading is a run-in paragraph head: =§= (=sp-reading-paragraph-glyph=) in the margin and the line break after the title hidden, so the title leads into the paragraph. Done with font-lock =display= keywords; turning the mode off removes them and unfontifies so nothing stays behind.
- *Frame resizing* (=sp-reading-frame-size=, 81x51 text columns/lines plus margins). Old size kept in a frame parameter and restored; skipped for fullscreen and non-graphical frames; nil disables.
- *Mock pagination* (=sp-reading-paginate=): =C-v=, =M-v=, =<next>=, =<prior>= turn whole pages (next page starts where the last stopped; previous goes back by the current page's screen lines). Prefix argument scrolls as usual. The header's page number follows because point moves to the top of the page. Mouse wheel unchanged.
- *Line spacing* default 1 pixel -> 0.3 of the line height.

Doc, tangled =.el= and CHANGELOG updated.

**** Tested

:END:
Emacs 29.3 batch: display properties on each heading level, bullets and the newline; removal and restore of all saved settings; frame parameter save/restore with =display-graphic-p= stubbed; page turning forward and back with stubbed window functions. =tools/tangle-all.el= writes the same =.el=. *Not tested:* a real GUI frame (frame resizing, real =window-end=, text-scale with margins, interplay with =org-indent= or =org-modern=).
