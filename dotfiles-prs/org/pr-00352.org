**** What
:PROPERTIES:

:END:
- =sp-bibtex-lint-dryrun= (=C-c w b l=) and =sp-bibtex-lint-convert= (=C-c w b L=) now work on one =.bib= file:
  - the file of the current buffer when it is a =.bib= file
  - otherwise, or with a prefix argument, one picked with completion from =sp-bibtex-files=
- The dry run uses the shared =sp-batch-report= buffer from #351 (the =vulpea-doctor=-style report):
  - each entry links to its line (=RET= visits, =n=/=p= move, =g= refreshes)
  - it never changes a file
- =convert= shows the rewrites in batches:
  - batch size is the new =sp-bibtex-lint-batch-size=, default 50
  - for each batch you answer =a= apply, =s= skip or =q= quit; the next batch is shown only after the answer
  - nothing is written without an =a=
  - the file is copied to =sp-bibtex-lint-backup-directory= before the first write, and written again after each applied batch
  - it refuses when the open buffer of the file is unsaved, or when the file changed on disk after the lint
- The rewrite itself is unchanged (names to =Last, First=, field order). Duplicate keys, names near an author note and entries with a comment inside are reported only.
- The old =sp-bibtex-lint-report-mode= and =sp-bibtex-lint-visit= are gone, replaced by the shared mode.
- Literate doc (=docs/tangles/academic/sp-academic.org=) updated as bullet lists; it tangles to the committed =sp-bibprocess.el=.
