- New module =sp-vulpea-meta-order= (docs/tangles/vulpea/sp-vulpea-meta-order.org):
  - =sp-vulpea-meta-order-keys= / =-sorted-p= order any list of meta keys; =-buffer= / =-string= order the first =- key :: value= list of a note.
  - Only that list moves: items keep their continuation lines, repeated keys keep their order, text outside is untouched, a sorted list is not rewritten (idempotent).
  - =sp-vulpea-meta-order-pinned= (default nil) can keep chosen keys first.
  - =M-x sp-vulpea-meta-order-note= for the current note.
  - =M-x sp-vulpea-meta-order-dryrun= / =-convert= for existing Vulpea notes: shared =sp-batch-report-mode= buffer (d/u/A/g), tag and folder filter (options, or prefix arg), time-stamped backups, one confirmation, unsaved buffers skipped. No old-interface view (new commands).
- =sp-litnotes-meta-fill= now orders the meta lines (result lists ="order"=), so the batch =-fill-all-convert= does too. The dry run plans and reports "order the meta lines". =sp-litnotes-meta-order-meta= (default t) turns it off.
- Not changed: meta lists under headings; no CHANGELOG edits.
