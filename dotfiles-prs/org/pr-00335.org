Builds on #332 (=sp-litnotes-meta-backfill-children=) and the =book-sections= / =collection-articles= views from #330.

**** What changes
:PROPERTIES:
:CUSTOM_ID: what-changes
:END:
- =C-u M-x sp-litnotes-meta-backfill-children=, or the new =M-x sp-litnotes-meta-backfill-all-children=, makes the notes of every BibTeX entry that cross-references the book. Nothing is picked. If nothing is missing, the table is still created or refreshed.
- Afterwards, in the book/collection note: the new notes are added to the Vulpea database, a =collection-query-table= block is inserted above the first heading if the note has none (=book-sections=, or =collection-articles= for =collection=/=mvcollection=/=proceedings=/=mvproceedings=), and the block is updated. An existing block is only updated. The note is saved if it had no unsaved changes.
- Literate doc updated (bullets); two new ERT tests.
