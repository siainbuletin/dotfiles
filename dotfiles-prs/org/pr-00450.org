**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Request:* a small command to eval on a heading with an ID, to see whether it is backlinked anywhere in the vault; =embark-act= on the result opens a temporary buffer with the backlink locations.
- *New module* =sp-vulpea-backlink-check= (=libraries/modules/vulpea/=), documented as a bullet-point part in =sp-vulpea.org=; required from =sp-vulpea-ext=.
- =M-x sp-vulpea-backlink-check= (or eval =(sp-vulpea-backlink-check)=) on a heading with an =ID=:
  - Echo area: =3 backlinks from 2 notes= or =not backlinked=.
  - Heading without =ID= or non-Org buffer: a =user-error=.
  - One =vulpea-db-query-links-to= call, no file reads, so it is fast. Headings with an ID are notes in Vulpea, so heading-level links are found. Self-links are not counted.
- *Embark:* the result is a propertized string; target type =sp-vulpea-backlinks=, target = the heading ID.
  - While the message is still in the echo area, =embark-act= acts on it directly (=current-message=); nothing is copied or added to the kill ring.
  - Also offered for =sp-vulpea-backlink-check-timeout= seconds (default 10) after the check, or on the result line in =*Messages*=.
  - =embark-act= then =RET= (or =s=): =*vulpea backlinks: TITLE*=, grouped by source note, each entry with its heading, line number and the line of context. =RET=/click jumps, =n=/=p= move, =g= refreshes, =q= quits. Open buffers are read instead of the file, so unsaved edits count.
  - Embark is configured in =with-eval-after-load=, like =sp-litdb= and =sp-tab-psearch=.
- *If the message is already gone:* =M-x sp-copy-last-message=, then =embark-act=.
  - =sp-copy-last-message= has a new abnormal hook, =sp-copy-last-message-functions=; a function may return the copied text as a propertized string, which the =Copied: ...= message then shows. The kill ring still gets plain text.
  - =sp-vulpea-backlink-check-restore= is on the hook and finds the text among the last 20 results (=sp-vulpea-backlink-check-history-size=). Same text from two headings: the newest wins.
- Tests: =tests/sp-vulpea-backlink-check-test.el=, 21 ERT tests pass on Emacs 29.3 batch (counts, singular, none, self-links, command, no ID, target finder and timeout, restore, the copy hook, locations, buffer, =n=/=p=, visit, open buffer wins). Vulpea is stubbed, sources are real temp files. =.el= files and test are tangled from the docs; the existing grouped-backlinks tests still pass. =when-let*= only, no CHANGELOG edit.
- *Not tested* with real Vulpea, Embark or the GUI: whether =:pos= of a heading-level source matches the file, whether the echo-area message is still there when =C-.= runs, and whether =*Messages*= keeps text properties (the restore path does not depend on it).
