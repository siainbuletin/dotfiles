**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
=org-other-agenda= (yibie's board) hard-codes Tokyo Night hex colours in its 17 faces. They now come from the theme in use.

- Seven accents (=urgent=, =crucial=, =focus=, =positive=, =calm=, =meek=, =mild=), each a list of theme faces: an =sp-*= semantic face first (coloured in the sp themes), then a standard face (=error=, =warning=, =link=, =success=, =shadow=, ...) so Lambda, Ef and Doric themes work too.
- =sp-org-agenda-board-roles= says which accent each board face uses; =sp-org-agenda-board-accents= says what each accent is made of; =sp-org-agenda-board-block-mix= tints the time blocks.
- Text faces inherit, so they follow theme changes. The active tab and time blocks need real colours and are recomputed on =sp-after-load-theme-hook=.
- Docs: new section "org-other-agenda colours" in =docs/tangles/text/sp-org-agenda.org=, including "Changing the accents" (which variables to edit to reorder them). The =.el= is tangled from it. CHANGELOG entry under Themes.
