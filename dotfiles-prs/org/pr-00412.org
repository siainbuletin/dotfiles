- =sp-litnotes-meta-add-all-tables= now puts a =* Sections= heading above the table block, with a blank line before and after the heading.
- The command can be re-run to complete notes: it adds only what is missing.
  - No heading and no block: both go above the first heading.
  - A block above the first heading, no heading: the heading is added above the block.
  - The heading without a block: the block goes under it.
  - A block under another heading: left alone.
- =refresh-all-tables= and =backfill-children= share the same insert function, so they behave the same.
- =C-u= dry run still previews; notes that would only get the heading are listed separately.
