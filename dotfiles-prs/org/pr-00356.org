Follow-up to #355 (it merged before this last commit was pushed). #355 flags crossref chains deeper than two levels and skips them; this adds the individual command to convert one anyway.

- New =M-x sp-litnotes-meta-fill-deep-chain=, run in the flagged note:
  - it refuses a note whose chain is not deep (use =sp-litnotes-meta-fill=)
  - it shows the chain (=ch -> b -> c=) and asks once
  - it fills the note and links or makes its direct parent
  - the parent is filled by the normal rules (=sp-litnotes-meta--allow-chain= is off for it), so a loop is cut there and the grandparent is made only when the parent's chain is no deeper
- No batch version: each deep chain is converted by hand.
- The dry run section "Crossref chains deeper than two levels" now points to the command.
- Literate doc updated as bullet lists; it tangles to the committed =.el=.
