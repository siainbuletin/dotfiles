** Description
**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- =mini-frame-mode= alone hung Emacs on macOS (98% CPU in =M-x=), even in the plain setup of #134 and with =vertico-resize= off, so =sp-mini-frame= now uses =vertico-posframe= instead.
- The minibuffer (prompt and Vertico's candidates) is a centred posframe: =vertico-posframe-poshandler= is =posframe-poshandler-frame-center=, =-min-width= 80, =-border-width= 4 (padding). No fixed height: the frame fits Vertico's own 13 candidates (=vertico-count= in =sp-completion=), so there is no blank box.
- Terminals fall back to =vertico-buffer-mode=.
- The module name and the dimming for =find-file=, =vulpea-find= and =org-node-find= stay (the dimming now checks =vertico-posframe-mode=).
- Docs (=sp-mini-frame.org=, dividers guide, =docs/main.org=) and CHANGELOG updated. The =mini-frame= package is no longer installed; Elpaca installs =vertico-posframe= and =posframe= on the next start.
