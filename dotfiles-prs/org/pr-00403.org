- =- seealso :: [[id:...]]= meta lines (Vulpea) are now a source of mentions in =sp-see-also=, like the =* See also= heading from #388.
- Key matched in any case, any spacing; the =-=/=+= bullet is optional.
- Each =id:= link on the line is one mention with =:where= =section= (weight 1.5), so it shows up in =sp-see-also-show=, the widgets, the =concept-usage= block and =*see-also-concept*=.
- Section-level, not granular: the mention belongs to the heading the line is in (nearest ID'd heading, or the file before the first heading).
- Not counted: lines in source/example/comment blocks, =#=-commented lines, and lines inside a =See also= section (read once, there).
