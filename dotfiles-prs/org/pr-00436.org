**** Change
:PROPERTIES:
:CUSTOM_ID: change
:END:
- =D= on an entry with no record of its own follows =crossref= (or =xref=) to the parent and opens the parent's record at the entry's first page.
- =sp-devonthink-first-page=: =45--67=, =45-67=, =45 – 67=, =12,15=, =e123= give 45, 45, 45, 12, 123. Roman numerals (=xii--xv=), =0= and empty give no page; the parent then opens at the start with a message.
- The echo area says what happened, e.g. =child is in parent: opening PDF page 53 (printed page 45, offset +8)=.
- No record for the entry or the parent: old behaviour (offer to index the entry's own PDF), plus a message when a crossref exists but has no record.
- A prefix argument (=C-u D=) still asks for a page and wins over =pages=; it is used as given, without the offset.
- Own record exists: unchanged.

**** Page offset
:PROPERTIES:
:CUSTOM_ID: page-offset
:END:
- Printed page and PDF page often differ (front matter). The design had no offset for this case, so I added:
  - =sp-devonthink-page-offset= (default 0): PDF page minus printed page.
  - =sp-devonthink-parent-page-offsets=: alist =(PARENT-CITEKEY . OFFSET)= for one book. Example: =(("smith-2000-handbook" . 8))= when the first numbered page is the 9th PDF page.
- Default 0 is a guess; test on a real book and set the alist.
