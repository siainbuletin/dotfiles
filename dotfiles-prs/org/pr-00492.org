**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Problem (after #487):* the author works report takes about 10 s before its tables show.
- *Cause:* not Org tables. Building the report text is fast; the slow part is =org-table-widget-mode=, which =sp-textui= turns on for every Org buffer (=org-mode-hook=). It lays out each table as its own widget (overlays, pixel measuring), about 10 to 20 ms per table, and the report has one table per author.
- *Fix:* batch reports keep plain Org tables. =sp-batch-report--quiet-table-widget= on =sp-batch-report-mode-hook= turns the widget off; it runs while the buffer is still empty, so it costs nothing. The tables are already padded in Lisp (#487), so they look aligned without it.
- *Opt back in:* =sp-batch-report-table-widgets= non-nil (slow for many tables).
- Docs are bullet lists (=sp-batch-report.org=); =.el= matches. =when-let*= only; no CHANGELOG edit.
