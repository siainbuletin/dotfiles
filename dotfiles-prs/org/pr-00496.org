**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- Adds step 4 to =sp-bibtex-lint-fix-authors=, also =M-x sp-bibtex-lint-fix-merge= and "merge author names" in =sp-bibtex-lint-convert=.
- Finds variants of one person in the =.bib= file: same surname (accents, case, braces, dots ignored) and given names that fit name by name (=Hegel, G. W. F.= / =Hegel, Georg Wilhelm Friedrich=, =Müller= / =Muller=), using the matching of the litnote autofill.
- A name that fits two names that do not fit each other (=Hegel, G.= for Georg and Gottfried) is never merged, only listed.
- Proposed name: an author-note name if a variant is one, else most spelled-out given names, then most used.
- Dry run: =sp-bibtex-lint-dryrun= has a new section "Variants of one author" with the groups, counts and proposed name; nothing is written.
- Fix: shows the groups, asks for each (RET proposed, edit, =-= skip, =C-g= stop), one yes-or-no question, backup, one write.
- Only names are replaced in =author= and =editor=: order, =and= separators, quotes or braces and other names stay. Entries with a comment inside are left alone.
- Author notes and litnotes are not touched (separate optional step).
