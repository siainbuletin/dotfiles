Emacs 31.1 marks =when-let= and =if-let= obsolete. This renames all 34 uses in =libraries/modules/= and the matching code in =docs/tangles/= (the canonical =.org= files) to =when-let*= / =if-let*=, plus the one prose mention in =sp-graphs.org=. There were no =and-let= uses.

Every site already used the double-parenthesis binding list =((VAR EXPR))=, which the starred macros accept unchanged, so no binding lists needed rewrapping. The only change per site is the added =*=. =.el= and =.org= were edited identically, so the tangled output stays in sync. =libraries/themes/= and =cloned/= were not touched (they had no uses). =CHANGELOG.org= has a line under "Startup, load order and configuration hygiene".
