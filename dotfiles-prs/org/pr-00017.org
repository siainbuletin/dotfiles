/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW2ApjJf3fNB4nmVud6MqNpBi][project thread]]/

Stacked on #16 (base is its branch); merge #16 first and GitHub will retarget this one to =main=.

*Before:* every box in the browser graph and the SVG export had the same colour, and a click on a box folded it. The page only knew the part of the tree that Emacs had cut, so it could not move to another note.

*After:* =vulpea-hierarchy-tag-colors= maps a file tag to a colour (defaults for =root=, =idea=, =question=, =claim=, =evidence=, =source=). A note takes the colour of the first of its tags that is listed, drawn as a tint, and the legend lists the tags in view. In the browser, a click on a box recentres the graph on it and remakes the nodes from there. A small ▾ marker folds a branch, =−= and =+= change the depth, and =←= or Backspace goes back to the previous centre. The SVG export uses the same colours.

*How:* the page now embeds the whole tree and runs the depth cut itself (the same breadth-first walk as =vulpea-hierarchy--scope=), so recentring needs no Emacs round trip. For a very large vault this makes the page bigger, since it holds every note of the hierarchy (ids, titles, tags and paths). Tested on mock notes in headless Chromium: tint colours, legend, a recentre, a depth change, back, and a JavaScript syntax check; =dot= accepts the tinted Graphviz source. Not run against your real vault. The literate doc is regenerated and tangles back byte for byte.

The fold marker can never be clicked. It is a ~<text class="fold">~ inside =g.node=, so the later rule =.node text{pointer-events:none}= applies to it. That selector is more specific than =.fold=, and =.fold= sets no =pointer-events= of its own. The marker's click handler never fires, and the click lands on the box instead, which recentres the graph on that box. The fold feature (▾/▸) is therefore dead, and clicking the marker recentres.

Fix by re-enabling pointer events with a selector at least as specific:

#+begin_src css
.node text.fold{pointer-events:all;font:12px system-ui,sans-serif;fill:var(--muted);cursor:pointer}
#+end_src
