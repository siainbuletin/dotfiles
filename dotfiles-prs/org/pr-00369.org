**** What
:PROPERTIES:

:END:
- =citar-create-note= (so also =citar-embark= opening a =[cite:]= link with no note) now makes the note with =sp-litnotes-meta-create-function=, the same path as the backfill, instead of citar-vulpea.
  - The note is born compliant: title from =sp-litnotes-meta-new-title=, file named by the key, ID, =:CREATED:=, =litnote= and BibTeX type tags, ROAM_REFS.
  - It is then filled from BibTeX (when =sp-litnotes-meta-auto=) and visited.
- The advice is now =:around=. A key that already has a note, has no BibTeX entry, or fails to be made goes to citar as before (with the old fill afterwards).
- New =sp-litnotes-meta-citar-create= (default t) turns the new route off.
- =sp-litnotes-meta-new-title= already defaulted to =standard= on main; unchanged.
- Doc: =docs/tangles/academic/sp-litnotes-meta.org= (bullet list) and tangled =.el=; one ERT test added.
