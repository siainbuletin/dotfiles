**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- =sp-devonthink-highlights-import= (=C-c k d h=) in a litnote copies the highlights of its PDF under a =* Highlights= heading: one list item each, the text plus a =devonthink:= link to its page (=key p. 6=).
- One way only (DEVONthink to Emacs): it only appends list items under that heading and adds only highlights not already there (whitespace and case ignored), so your edits survive a second run. The buffer is left unsaved.
- =tools/devonthink-highlights.py FILE.pdf= prints the highlights as JSON by page (from 1), reusing the reader of =devonthink-to-litdb.py=; Emacs runs it with =sp-litdb-python=.
- Literate doc =docs/tangles/academic/sp-devonthink-highlights.org=; README row.
