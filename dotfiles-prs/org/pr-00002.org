** Description
/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW2GSdfx2LDjjW1ejiT3SruTH][project thread]]/

Before: the modules in =.config/emacs-modular/libraries/modules/= existed only as =.el= files, and most had no documentation.

After: =docs/tangles/= has a canonical =sp-*.org= file for each of the 127 modules. Each one holds the module's full source, in order, in =emacs-lisp= blocks, with headings and prose explaining every block. Tangling a doc (=C-c C-v t=) regenerates its module.

*How*

- Each file sets =#+PROPERTY: header-args:emacs-lisp :tangle ../../libraries/modules/<category>/<module>.el :comments no :padline yes :noweb no=, so tangling rewrites the real module file. Nothing tangles unless you run it, because no file sets =auto_tangle=.

- The code was copied by a script, not retyped. Blocks are split only at single blank lines, so =:padline yes= restores each original blank line. Lines starting with =*= or =#+= are comma-escaped. Blocks use =-i= and start at column 0, so indentation survives whatever =org-src-preserve-indentation= is set to.

- 14 modules already had an older doc under the same name, for example =sp-faces.org=. Those older docs are renamed to =<name>-old.org= with their contents unchanged, and the new docs take the plain name.

- =lem-dashboard.el= gets =sp-lem-dashboard.org=.

- Third-party code under =libraries/modules/cloned/= is not included.

- Five modules are empty .el files: =sp-syslinux=, =sp-instant-messenger=, =sp-mail=, =sp-music-comp= and =sp-vulpea-ext-back=. Their docs are literate skeletons with these parts:

  - a file header
  - a Configuration section to fill in
  - a =:tangle no= Sandbox for trying settings
  - a =provide= form

  Tangling one of these writes a valid module that loads, replacing the empty file.

- Commits: there is one commit per module category, then one for the =-old= renames and one for the empty-module skeletons.

*Round-trip check* (Emacs 29.3 / Org 9.6, tangled into a scratch copy and compared with =cmp=)

- 44 modules come back byte-for-byte identical.
- 78 differ only by a final newline. Their =.el= files have no newline at the end, and Org always ends a tangled file with one.
- =sp-org-archive.el= also loses two trailing spaces on its last line.
- All five skeletons tangle to modules that load in =emacs -Q=.

No =.el= file is changed by this PR. Against =main=, 127 files are added and 14 are modified; the modified ones are the canonical names that now hold the new docs.
