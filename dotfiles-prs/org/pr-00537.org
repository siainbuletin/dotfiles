**** What changed
:PROPERTIES:
:CUSTOM_ID: what-changed
:END:
- New option =sp-split-notes= for =sp-split-leave-parents= (in =sp-refile=), default =move=:
  - the footnotes, see-also notes (=see-N=) and endnotes (=end-N=) that the split heading cites are written in the =Notes / Appendix= section of the new note, renumbered in its order (end notes, see-also notes, then footnotes)
  - =move=: the source also loses the definitions that nothing left there cites any more, and is renumbered; the copy in the new note keeps the context
  - =copy=: the source keeps everything
  - =nil=: the older behaviour, a copy under each citing heading
- A note that the remaining part of the source still cites stays in the source.
- A note cited but defined nowhere is reported as before and left alone.
- =sp-note--ordered= now keeps plain footnotes after the end/see notes.
- Default changed for plain footnotes too: with =sp-split-notes= non-nil they go to the notes section instead of under each citing heading.
