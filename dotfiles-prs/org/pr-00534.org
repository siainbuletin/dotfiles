**** What and why
:PROPERTIES:
:CUSTOM_ID: what-and-why
:END:
- =citar-open-entry= on a =.bib= file printed dozens of =Wrote ...~undo-tree~= lines, one per bibliography file, and slowed Emacs.
- Likely writer: =lem-full-auto-save= in =sp-backups= runs =basic-save-buffer= on every modified file buffer after 5 idle seconds; =undo-tree= writes a history file on each save.
- New =sp-undo-tree-skip-history-for-bib= sets =undo-tree-auto-save-history= to nil buffer-locally for =.bib= buffers.
- It runs from =bibtex-mode-hook= and =find-file-hook=, so late mode setting is covered.
- History for other files is unchanged.
- Doc updated in =docs/tangles/base/sp-base-libraries.org= (bullets).
- Not verified: =tools/check-tangle.sh= could not run in the cloud container (no Emacs). The =.el= block matches the doc block by hand.
- Not done: finding why those =.bib= buffers are modified at all; this PR removes the cost, not that cause.
