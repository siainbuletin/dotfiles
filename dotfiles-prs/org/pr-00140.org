In =sp-posframe= (and its literate doc):

- The =vertico-posframe-border= face takes the background of the posframe, so the 4 pixel border (=vertico-posframe-border-width=) reads as padding. It is re-applied on =enable-theme-functions=, so it follows theme changes.
- New =sp-posframe-dim-always= (default =t=): every posframe prompt dims the frame behind it, removed on exit by the existing undim hook. Set to =nil= to keep the old per-command lists.
