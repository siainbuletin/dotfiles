** Description
Reported: every PDF opened in Preview (the hard-coded fallback) instead of the previous viewer (Highlights), and never in DEVONthink.

- Fallback: =DT_OPEN_FALLBACK= unset now means the viewer that was the default before =dt-open-install= (recorded when =duti= is installed), then Preview. Set ~DT_OPEN_FALLBACK=Highlights~ to be explicit. The shipped config no longer sets it.
- Visibility: ~DT_OPEN_DEBUG=1~ logs paths tried, databases asked and errors to =~/Library/Logs/DT Open PDF.log=; the Automation error (-1743) shows an alert; a non-list lookup result counts as no match.
- README.org: new section "When every PDF opens in the fallback viewer" (Automation permission, is the PDF indexed, a Terminal test of the lookup, the log).
- Tangled files regenerated the way Emacs does it (blank lines at block ends trimmed).
- Not run on a Mac; the cause of the failed lookup is not known yet. Most likely the Automation permission or the PDFs not being indexed.
