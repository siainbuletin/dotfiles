**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
=org-other-agenda= (yibie's board, installed by =sp-org-agenda=) showed links in row titles unfolded as =[[id:...][title]]=. Rows now show only the description in =org-link= face.

**** How
:PROPERTIES:
:CUSTOM_ID: how
:END:
- The link rendering of the query tables (vui/exc cells) moved from =sp-collection-query-tables-core= to =sp-org-id-link= as =sp-org-link-linkify=, =-has-link-p=, =-open=, =-map= (renamed from =sp-collec-query-*=, no aliases). The query tables now call these.
- =sp-org-agenda= adds =:filter-return= advice on the package's private =org-other-agenda--clean-title= that calls =sp-org-link-linkify=. If the package renames that function, links show unfolded again.
- Docs (=sp-org-id-link=, =sp-org-agenda=, =sp-collection-query-tables=) and CHANGELOG updated.
