**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- =sp-vulpea-grouped-backlinks-sidebar=: toggles a pop-up side window with the grouped backlinks of the note in the main window.
  - Sits on the right in slot 1, next to the =vulpea-ui= sidebar (slot 0); side, slot and size are options.
  - Redraws when the main window shows another note, including when you move through mentions.
  - Buttons open a note in the main window (=vulpea-ui-visit-note=). Keys: =f= toggle follow, =g= redraw, =q= close.
- =sp-vulpea-grouped-backlinks-sidebar-toggle-follow= flips =sp-vulpea-grouped-backlinks-sidebar-follow=. It applies only to this sidebar; the widget (next PR) always follows.
- How it follows: same hooks as =vulpea-ui= (=window-buffer-change-functions=, =window-selection-change-functions=) arming a zero-second timer, and =vulpea-ui--get-main-window= plus =vulpea-ui--get-note-from-buffer=, so both sidebars show the same note. Those two are private to =vulpea-ui=, so an update that renames them would break following (documented in the doc).
- New shared helper =sp-vulpea-grouped-backlinks-sorted=, also used by the Org view.
- Literate doc updated in bullets; =.el= re-tangled from it. No key is bound yet.
