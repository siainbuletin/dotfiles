Adds =.config/listening/PLAN.org=, the plan for a listening list built from vulpea album notes and Last.fm history, and links it from =README.org=. This replaces #170, which was closed because its branch name did not match its PR number.

The plan covers:

- Importing the RYM/Bandcamp =.md= wishlists into =album= notes.
- A small Python script that caches scrobbles and finds fully listened albums (every track in one session) and partial listens.
- An =sp-listening= Emacs module that writes =first-listened=, prompts for ratings on partial listens, and shuffles the queue.
- A =sync= command with a beets source now and a Navidrome source later. It uses a =beets-alternatives= target, then libgpod on Linux or Music/Finder on macOS for the stock-OS iPod.

Docs only, nothing is built yet. The plan is a draft for review before step 1 starts.
