**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
=sp-minibuffer= (sp-fonts) scales every minibuffer up two =text-scale= steps from =minibuffer-mode-hook=. The posframe shows that buffer, so its text size came from that scale. New =sp-posframe--reset-text-scale= runs later on =minibuffer-setup-hook= (depth 90) and sets the scale to 0 when =vertico-posframe-mode= is on, so every posframe prompt uses the size of the =default= face. Prompts outside the posframe (=read-string=, =y-or-n-p=) keep the larger size. Doc and CHANGELOG updated.
