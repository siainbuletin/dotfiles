**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- Query table specs get =:fold-tag= and =:fold-prop= (default =bib-parent=) and a new =:sections= column. Notes with the tag leave the table and are counted on the note their =bib-parent= link points at; that book is added if it is not a result itself.
- The =Works= spec of =sp-author-notes= uses it: =:fold-tag "booksection"=, column =:sections= after =:title=.
- Title decoration: the exc and vui renderers show the emoji of the note's tags (=sp-org-tag-groups=) in the title. The Org dblock title is an =id:= link, which =sp-org-tag-groups= already decorates in Org buffers, so no extra column or text is needed.

**** How booksections link to the book
:PROPERTIES:
:CUSTOM_ID: how-booksections-link-to-the-book
:END:
Through the meta key =bib-parent= (=- bib-parent :: [[id:...]]=), required by the =booksection= schema, target tag =book=.

**** Not changed
:PROPERTIES:
:CUSTOM_ID: not-changed
:END:
=Works= blocks that already exist keep their old spec. Add =:fold-tag "booksection" :fold-prop "bib-parent"= and the =:sections= column by hand.
