** Description
/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW25gNRrBAMuP7KHa4qEqWBeG][project thread]]/

*Before:* =sp-clean-whitespace= (the command asked about as =sp-remove-whitespace=) ran from the global =before-save-hook=. =sp-backups= saves modified buffers after 5 s idle (=lem-full-auto-save=, plus =auto-save-visited-mode=), and those saves run the same hook. In the middle of writing, the cleanup stripped the space just typed at the end of a line and collapsed blank lines around point, which in Org moved text and broke words.

*After:* the hook calls =sp-clean-whitespace-before-save=, which skips the cleanup in the modes of the new option =sp-clean-whitespace-autosave-skip-modes= (default =(org-mode)=, derived modes included) unless the save was explicit (=this-command= is =save-buffer=, =save-some-buffers= or =write-file=). Set it to =nil= to restore the old behaviour. =M-x sp-clean-whitespace= is unchanged. Module doc and CHANGELOG updated.

*Not tested:* nothing was run (no Emacs in the container). Saves from other commands (e.g. Magit's save prompt) count as non-explicit in Org buffers.
