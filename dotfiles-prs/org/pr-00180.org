**** Changes (=sp-org-babel= doc and module, README)
:PROPERTIES:
:CUSTOM_ID: changes-sp-org-babel-doc-and-module-readme
:END:
- =sp-tangle-changed=: tangles only docs whose text changed since they were last tangled. It compares a SHA-1 of each doc with the one in =tangle-hashes.eld= in =sp-cache-dir=, written after a successful tangle. No git is needed, so it works with yadm and uncommitted edits. A doc is also tangled when it has no entry or an =.el= it wrote is missing. =C-u= forces all.
- Changed =:tangle= path: the path is part of the doc text, so the doc is tangled to the new file; the old file is left in place and a message says so.
- A failing doc is reported, keeps its old entry and is retried next time; deleted docs are dropped from the cache.
- =sp-tangle-changed-and-reload=: also reloads the written modules that are loaded (via =sp-reload--run= if present, else =load=).
- =sp-tangle-on-save-mode=: opt-in, tangles the saved doc if it changed.
- =sp-tangle-all= now tangles every module doc; =sp-literate-files= is removed.
- README: new "Tangling only what changed" section (Emacs and shell).

Not done: a git-diff mode (the hash cache covers the same need without requiring commits).
