Adds =sp-author-notes= (=M-x sp-author-notes=, =sp-author-notes-preview=), documented in =docs/tangles/funct/sp-author-notes.org=.

What it does:

- Reads =litnotes/= (file-level meta only) and fixes typos of =pub-author= (=pub-authro=, =Pub_Author=; two edits away is only reported).
- Creates a =:person:= note for each plain author name with no note, via =sp-org--write-note=, and turns the name into an =[[id:...]]= link. (=sp-org--create-note= does not exist; this is the function behind =sp-org-create-note-and-link=.)
- In each =:person:= author note: ensures =* Basics=, then =* Works= after it, then a =collection-query-table= block (=:parent-of "self" :parent-prop "pub-author"=, columns title, read-status, read-priority, pub-year, relevance-factor, sorted by pub-year) unless one exists.
- Report buffer of fixed / created / converted / updated notes, plus things left alone.

Safety: preview first, asks before writing; idempotent; insert-only; backups in =author-notes-backups/=; skips files with unsaved buffers; ambiguous or conflicting titles are reported, not touched.

Tested: 8 ERT tests in Emacs 29.3 batch with a temporary vault (=sp-org--write-note= stubbed). Not tested: the real =~/notes=, vulpea DB, filling the dblocks, the report buffer on screen.
