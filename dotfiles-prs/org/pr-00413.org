**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- =sp-litnotes-titles= falls back to =pub-editor= when a note has no =pub-author= (collections, proceedings, but not only).
  - =pub-author= always wins; an ambiguous =pub-author= does not fall back.
  - Several editors are read and shortened like authors (=A and B=, =A, B and C=, =A, B et al.=).
  - Title looks the same as for authors: =Lee and Roe (2014) Essays=. There was no existing marker convention, so no =(ed.)= by default.
  - New option =sp-litnotes-titles-editor-suffix= (e.g. =" (ed.)"=) adds a marker for editor-based titles only.
  - With BibTeX on (=missing=/=always=), the entry's =editor= field is used when neither the note nor the entry has authors.
- Reports: the "no author" reason now mentions =pub-editor=; failed rows show the =pub-editor= value; BibTeX-derived editors are listed as "editors".
- Docs (bullets) updated in =docs/tangles/funct/sp-org-lint.org=, =.el= kept in sync. No CHANGELOG edit.
