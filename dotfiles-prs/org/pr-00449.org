**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- Opening a PDF with DT Open ended with =activate=, which brings every DEVONthink window forward, including the main (database) window.
- Now =open window for record= is followed by a System Events =AXRaise= of only that window.
- New setting =DT_OPEN_RAISE= in =~/.config/dt-open/config=:
  - =window= (default): raise only the PDF window.
  - =app=: plain =activate= (old behaviour).
  - =none=: never activate.
- If raising fails (e.g. no Accessibility permission), the error goes to the log and the app falls back to =activate=.
- =README.org= (literate source) and the tangled =open-handler.applescript= and =config= are updated together. Emacs was not available in the container, so the tangled files were edited by hand to match.

**** Not verified

- If DEVONthink is closed, it opens its own main window when it starts; this PR cannot prevent that.
- AeroSpace (#444) may move focus to the workspace of whichever DEVONthink window is raised; check this when the main window sits on another workspace.
