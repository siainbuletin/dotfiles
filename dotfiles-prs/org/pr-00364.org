**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- New module =sp-backup-lookup= (doc =docs/tangles/funct/sp-backup-lookup.org=, tests tangled from it).
- =sp-backup-lookup-list FILE=: finds the backups of a file in every module's backup folder, newest first.
- =M-x sp-backup-open=: pick a backup of the current file and open it read-only.
- =M-x sp-backup-diff=: diff a backup against the file (prefix: Ediff).
- In batch reports: =b= opens and =D= diffs a backup of the file linked on the line at point.

**** Why one lookup
:PROPERTIES:
:CUSTOM_ID: why-one-lookup
:END:
- Each module keeps its own backup folder and layout (=STAMP/name=, =name.STAMP=, =STAMP/full/path=, =STAMP/files/...=).
- Modules are unchanged; the lookup reads all of them through =sp-backup-lookup-directories= (BibTeX lint, litnote titles/meta/refs, meta order, footnote lint, author notes, notes filing).
- Backups with only a name (=STAMP/name=) cannot be told apart by folder, so same-named notes are all listed.
