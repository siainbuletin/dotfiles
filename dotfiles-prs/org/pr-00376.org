**** Changes
:PROPERTIES:
:CUSTOM_ID: changes
:END:
- =sp-find-note= (=M-o f=) shows the notes in groups, with a heading per group like the sources in consult-omni:
  - "Notes": below =sp-notes-dir=.
  - "Writing: NAME": one group per Projectile project below =sp-writing-projects=.
  - "Writing": below =sp-writing-projects=, but in no known project.
  - "Config": below =user-emacs-directory=.
  - "Other": anywhere else.
- New =sp-note-origin= classifies a file from =projectile-known-projects= (deepest project wins, no disk lookups, cached per file).
- =sp-note-origin-group= (=group-function=) and =sp-note-origin-sort= (=display-sort-function=) are set through =completion-category-overrides= for the =vulpea-note= category, only while =sp-find-note= runs. =sp-insert-note= and =sp-select-note= stay flat.
- Doc =sp-org-tag-groups.org= has a new section "Where a note lives"; tests added to =sp-org-tag-groups-test.el=.
