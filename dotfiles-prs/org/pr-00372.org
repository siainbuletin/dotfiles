**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
A separate fix in =sp-bibtex-lint= for attachment paths: =M-x sp-bibtex-lint-fix-files=, a button in =sp-bibtex-lint-dryrun= (section "Attachment paths") and an entry in =sp-bibtex-lint-convert=.

- BibDesk =bdsk-file-N= fields (base64 bookmark) become one ~file = {...}~ field; several files are joined with =;=, an existing plain =file= field is extended.
  - The bookmark's old relative path gives a file name, looked up anywhere below =sp-literature-dir= (case and accents ignored); it must match exactly one file.
  - Otherwise the only PDF whose name, minus BibDesk's trailing digit, equals the citekey is used.
  - Entries that cannot be resolved keep their fields and are listed as problems.
- Absolute =~/Documents/literature/...= paths (typos of =Documents= accepted) become relative to =sp-literature-dir=; a path whose file is elsewhere in the library is pointed at it.
- Same pattern as the other fixes: whole file, one question, backup first, only the attachment fields change.
- =sp-bibtex-files-flatten= (default nil) also moves the files to the top of the library and writes the bare name.
- =sp-bibtex-files-devonthink-tool= (default nil): path of the new =tools/devonthink-move.py=. With it, the move goes through DEVONthink (one call per fix), so records keep their UUID, tags and annotations and =x-devonthink-item://= / =#+devonthink:= links keep working. If the tool stops, the =.bib= file is not written.

**** New: tools/devonthink-move.py
:PROPERTIES:
:CUSTOM_ID: new-toolsdevonthink-movepy
:END:
- =move= (dry run unless =--apply=): =--library DIR --flatten SUBDIR...= or =--moves FILE= (FROMTO pairs, the format =sp-bibtex-files= logs). Each file is moved with DEVONthink's own =move=; afterwards the record is read back and the run stops at the first one whose UUID or path is not as expected. Files DEVONthink does not index are left alone, or renamed with =--plain-rename=. A manifest of the moves goes to =~/.local/state/devonthink-move/=.
- =check NOTES_DIR...=: lists the UUIDs in notes (=x-devonthink-item://=, =devonthink:=, =#+devonthink:=) that DEVONthink does not know; run it before and after.
- Literate doc =docs/tangles/academic/devonthink-move.org= (bullet lists), tangled to the tool and =tests/test_devonthink_move.py=.
