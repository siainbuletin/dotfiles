**** What
:PROPERTIES:

:END:
- New =sp-litnotes-meta-fill-all-dryrun=: report for every note tagged =litnote=; writes nothing.
- New =sp-litnotes-meta-fill-all-convert=: asks once, backs up each note (=litnote-meta-backups/<time>/=), fills it.
- =sp-litnotes-meta-fill= now also adds the BibTeX type tag (from =sp-bibtex-types=, #347) when the note has no type tag, so the single and batch commands both do it.
- Prefix arg replaces pub-author/editor/title/year values; without it existing values are never changed. bib-parent is never replaced.
- Notes without a citekey, or whose key is not in the .bib files, are skipped and listed.
- No per-note prompts: bib-project, read-status, relevance-factor and read-priority are asked once (empty = leave empty); missing parent notes are not offered.
