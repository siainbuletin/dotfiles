**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
=org-insert-link= completes the path of a link type that has a =:complete= parameter. =sp-org-id-link= now sets one for three types, once Org is loaded:

- =help:= reads a function, variable or face (=completing-read= over =obarray=).
- =info:= reads a manual and node with =Info-read-node-name= and inserts Org's =MANUAL#NODE= form (=Top= when only a manual is given).
- =man:= reads a page with =Man-completion-table=. It also gets a follow function (=man=), but only when Org has none for =man:=.

The literate doc has a new section, and =CHANGELOG.org= has the entry.
