**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Request:* the help header of the side-by-side BibTeX view in =sp-fetch-inbox= does not wrap; show the commands as echo-area hints like nano-emacs' =nano-help.el=.
- *New reusable helper* in =sp-interaction= (an existing module, loaded early; no new module and no new package):
  - =(sp-echo-help-set HINTS &optional NOTE)=: call it in a buffer; =HINTS= is a list of =(KEY DESCRIPTION [STRONG])=. =nil= turns the hints off.
  - =sp-echo-help-format=: pure function that builds the text (testable without a display).
  - =sp-echo-help-mode=: buffer-local =post-command-hook= that re-shows the hints when no other message is showing.
  - Faces =sp-echo-help-face= (inherits =shadow=, faded) and =sp-echo-help-strong-face= (inherits =bold=); option =sp-echo-help-rows= (default 2).
- *Look (as in the nano-emacs screenshot):* a grid of =[KEY] Description= cells, two rows, faded, with the finishing keys bold. Example in =sp-fetch-inbox=:

#+begin_example
 DOI 10.1/x
 [C-c C-c] File it   [C-c C-r] New key
 [C-c C-k] Abort     [C-c C-d] Fetch DOI
#+end_example

- *Does it break the UI?* It only uses =message=, so no window, frame, mode line or face of your theme is changed. Differences from nano: no thin spacer lines and no ruler above the hints (those come from nano's own theme), and no =sit-for= loop; the hints return after the next command instead. The echo area grows to 2-3 lines while they show, which can shift the bottom of the frame by that much (Emacs default =resize-mini-windows=).
- *=sp-fetch-inbox=:* the header line is gone; the DOI note ("DOI ...", "no DOI found ...") is the first line of the hints. =sp-fetch-inbox--set-header= is renamed =sp-fetch-inbox--set-hints=.
- Docs (bullet lists): new section "Echo-area help hints" in =sp-interaction.org=, a "Key hints in the echo area" part in =sp-fetch-inbox.org=; both =.el= files re-tangled from the =.org=.
- Tests (Emacs 29.3 batch): 4 new in =tests/sp-echo-help-test.el= (grid, faces, note, set/off), 1 new in =sp-fetch-inbox-test.el=; 15 of 15 and 4 of 4 pass. =when-let*= style only (no =when-let= used). No CHANGELOG edit.
- *Untested by Claude:* the look in the real GUI Emacs on the Mac with your theme (only the text was checked in batch), the interaction with other packages that write to the echo area (eldoc, Embark, vertico), and the hints with =emureader= in the left window.
