After #155, clicking a =help:= link raised =Wrong type argument: stringp, nil=.

Cause, from the backtrace: =describe-function= mentions the shortdoc groups of a function, which loads =shortdoc=. =taxy= has registered its group with a nil section name, so =shortdoc-add-function= fails as soon as =shortdoc= loads. =C-h f= on the same function fails the same way, so it is not specific to the links.

- =sp-help=: advice on =shortdoc-add-function= turns a nil section into an empty string. Remove it once =taxy= is fixed.
- =sp-org-id-link=: =help:= also gets its own follow function (=sp-org-link-follow-help=) that opens faces, which the completer offers and Org's follow function rejects.
- Docs and CHANGELOG updated.
