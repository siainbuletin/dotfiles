** Description
/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW21jZfxe5AmskoMP3AYBnVbr][project thread]]/

Before: the graphical splash (=sp-splash.el=, the screen with Agenda / Config / Mail / Notes / Projects) showed =lambda-logo-white.png= or =-black.png= above the title. =lambda-splash.txt= was only used by the terminal splash.

After: the splash draws =libraries/lambda-splash.txt= behind the menu, in both dark and light themes, a little left of centre. The art only fills blank cells, so the title and buttons stay on top. The new face =sp-splash-art-face= is dim grey on a dark background and pale grey on a light one, so it follows the theme.

Position: =sp-splash-art-x-offset= (default -12 columns) and =sp-splash-art-y-offset= (default 0), measured from the art centred on the menu. In the splash, =S-<arrow>= nudges the art (steps set by =sp-splash-art-x-step= / =-y-step=), =0= resets it and =s= shows and copies the =setq= form for the current offsets. Nudges last until Emacs exits. Set =sp-splash-art-file= to nil to get the PNG logo back.

Also: the literate doc =docs/tangles/tooling/sp-splash.org= has a new "Lambda art" section (its blocks tangle to exactly the new =.el=, checked by script), and =CHANGELOG.org= has an entry.

*Not tested:* the container has no Emacs, so nothing was run or byte-compiled. Please load the module and run =M-x sp-splash-screen=. Things to check: the art lines up behind the menu, the grey is visible but quiet on your themes, =S-<arrow>= works in your terminal/GUI, and the layout looks right in a small window.
