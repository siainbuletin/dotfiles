** Description
/Requested by *Sia*/

*Mode line (bottom), new =sp-modeline-parts= shared by =sp-lambda-modeline= and =sp-prot-modeline=*

- Order: window number, major mode (nerd-icons, boxed), word count (text buffers) or line:column (code), keycast (key boxed, command next to it, last command kept, fixed width), minor-mode count (button: click for menu, right-click for =describe-mode=). Tags and branch stay at the right.
- Boxes are as tall as the mode line and take =sp-themes= accent colours (font-lock colours with other themes). Which segments are boxed, their order, hiding in narrow windows and a Doom-style bar are options (=sp-modeline-parts-boxed=, =-left=, =-right=, =-narrow-width=, =-bar=).
- Lambda uses the layout only in text and prog buffers (via advice on =lambda-line-compose=); Prot loses its own buffer-name, major-mode, minor-modes and keycast segments in favour of the shared ones.

*Header line (=sp-nano-style=)*: buffer name (Org =#+title:=, in =org-document-title= face) and an =hh:mm= clock at the right (Prot's =display-time= settings; clock removed from the mode line). New options =sp-nano-style-divider-opacity=, =-divider-color=, =-header-divider=, and a doc section on making the lines fainter.

*=sp-mini-frame=*: =M-x= is centred like every other prompt. From nano only the text styling and boxes: inverted bold prompt with a box, one-pixel border, and a dotted line (=sp-mini-frame-divider-char=) under the input in the divider colour. Dimming now also applies to =sp-select-note=, =sp-insert-note= and =sp-collec-query-select-note= (=sp-mini-frame-dim-functions=).

*Interpretations:* "dotted line" in the mode line is not possible with an overline, so it is a fainter solid line; the dotted row is only under =M-x=. "Otherwise" in the mini-frame item was read as "use the same divider style". Window number box is on by default.

*Not tested* (nothing run, no Emacs in the container; =.el= files only paren-checked): keycast anchor inside lambda-line, =:position t= underline under the header, the dotted line vs Vertico's candidate overlay (=sp-mini-frame-divider-priority=), word-count caching, window number from =selected-window=, accent colours, =mini-frame-internal-border-color=.
