**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- Follow-up to #541: =sp-see-also-show= listed nothing for Sia's litnotes.
- Cause (likely, not confirmed on the real vault): the citekey was read from =#+reference:=, but Sia's litnotes keep it in =:ROAM_REFS:=, so no =[cite:]= was searched.
- Fix, in =sp-see-also=:
  - new =sp-see-also--citekeys=: reads the =:ROAM_REFS:= property (Sia's choice); all keys, forms =@key=, =key=, =cite:key=, =[cite:@a;@b]=; URLs and DOIs skipped. =#+reference:= is no longer read.
  - *Fallback, only for files below =litnotes/=* (=sp-see-also-directory=) with no =ROAM_REFS= key: the =#+title:= is the key when it is a single key word, otherwise the file name is. Temporary, for litnotes whose title is still the key; files outside =litnotes/= get no fallback.
  - the cite regexp and the ripgrep search take a list of keys; ripgrep follows symlinks (=-L=).
  - the view ends with a line when the note has no key.
- Applies to every litnote with a key, whether or not other notes already link it by =id:=.
- Tests (Emacs 29.3): 52 of 52 pass; =tools/check-tangle.sh=: only this doc. =CHANGELOG.org= not edited.
