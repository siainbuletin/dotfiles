**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
=sp-insert-note= / =sp-select-note= took seconds to open with the coloured tag column. =sp-org-tag-groups--with-tag-column= binds =vulpea-select-cache= to nil (the column width depends on the frame), so vulpea rebuilds the title and tag column of every note on each call. Per note that meant: sorting a copy of the rules, matching them, looking up the tag group with =mapcar=/=member= over the whole group alist, an =assoc=/=assq= for the colour, =frame-parameter= and =face-attribute=, and building the propertized chips again.

**** Change
:PROPERTIES:
:CUSTOM_ID: change
:END:
=sp-org-tag-groups--memoize= keeps a hash table of results for the chip face of a tag, the emoji of a tag list, and the chips of a tag list and width. The table is cleared when the rules, groups, colours, palette, tag face height, =combo-consumes=, link position or the light/dark background mode change (compared with =eq=). Notes with the same tags now cost one hash lookup. Both the =.el= and the literate doc are updated, with a CHANGELOG entry.
