Before: the bespoke modules =sp-trails=, =sp-vc-ai-workbench= and =sp-vulpea-hierarchy= were spread over =academic/=, =prog/= and =text/=, next to modules that only configure other people's packages.

After: they live in a new =libraries/modules/custom/= directory for custom, bespoke functionality. The tangle paths of the workbench and hierarchy docs point there, and the module tree in =docs/main.org= has a =custom/= section that says what the directory is for.

How: the =.el= files are moved with =git mv= and unchanged. =init.el= loads modules by name and the whole =modules/= tree is on the =load-path=, so nothing else needs to change. =sp-org-issues= is not included: it is not on main yet (it is in draft #3), so it needs the same move there.
