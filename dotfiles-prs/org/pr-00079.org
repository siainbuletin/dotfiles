** Description
/Requested by *Sia* · [[https://claude.ai/code/project/chan_01KaQfLZaF43QUMN3kcT7pW2?thread=cmsg_01KaQfLZaF43QUMN3kcT7pW2DwHqEdSiUqx4vzZ6ZcBaw5][project thread]]/

*Before:* no way to get the literate docs as a PDF. =docs/tangles/sp-typst.org= was an empty file, and the only Typst line was =(use-package ox-typst :after org)= in =sp-typesetting.org=.

*After:* new module =sp-typst= (=libraries/modules/text/=, in =sp-late-modules= of =init.el=, and in the late group of =load-order.org=) and a skeleton for a Typst typesetting environment that works from Org. Reasons and alternatives are in ADR 0021.

- =M-x sp-typst-export-book= assembles =docs/main.org=, the README, the architecture notes and every module doc into one Org text (one heading per doc, file keywords dropped, links between docs turned into internal links, footnote labels made unique) and exports it with =ox-typst=. =M-x sp-typst-export-file= does one file.
- =docs/typst/=: =template.typ=, =Makefile= (=make -C docs/typst pdf=, ~make file FILE=...~, ~SVGS=1~ to run =docs/Makefile= first) and =export.el= (batch driver), separate from the SVG Makefile. All are tangled from =docs/tangles/text/sp-typst.org=, which replaces the empty =docs/tangles/sp-typst.org= and has a "Changes by pull request" section.
- Packages by Elpaca =:ensure=: =ox-typst= (git recipe) and =typst-ts-mode=; a =tinymist= eglot entry only when the binary exists.
- ADR 0021 (pandoc and LaTeX compared; renumbered from 0014, which =main= now uses), the #79 line of the new =CHANGELOG.org= with its Details link, entry in =docs/main.org=.

*Checked* (container: Emacs 29.3, Org 9.7.11, Typst 0.15.1): the doc tangles; =make pdf= built the whole book (about 180 docs, 796 pages) on an earlier =main=; one-file export works. Pandoc 3.1.3 fails with Typst 0.15. After the latest merge of =main= I only re-tangled; the full book was not rebuilt.

*Not checked:* Elpaca installing the packages, =typst-ts-mode= and =tinymist=, macOS, running the commands in your own Emacs. =ox-typst= declares Emacs 30.1 and Org 9.7; Elpaca may refuse it on an older Emacs, and Emacs 29's Org 9.6 does not work with it.
