Column width and word wrap of the exc table are now part of the spec, so a saved view keeps them with its columns.

- New spec keys =:column-widths= (alist =(COLUMN . WIDTH)=, =t= for the columns not listed) and =:wrap= (=wrap= or =fit=). Views, the dynamic block and the menu carry them like any other key; vui and Org ignore them.
- =wrap= keeps the widths and wraps long text onto more lines. =fit= sizes each column to its longest text, up to =sp-collec-query-exc-max-width= (80). An explicit width always wins.
- New options =sp-collec-query-exc-wrap= and =sp-collec-query-exc-max-width=; =sp-collec-query-exc-column-widths= stays the default. A width in the spec overrides them.
- Menu: =w= sets the width of one column (or =other=), =W= cycles the wrap between default, =wrap= and =fit=.
- Docs and CHANGELOG updated.
