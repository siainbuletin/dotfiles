**** Why the hints never appeared
:PROPERTIES:
:CUSTOM_ID: why-the-hints-never-appeared
:END:
- *Main cause:* #459 was stacked on =457-echo-area-help-hints=. #457 had already been merged into =main=, so #459 was merged into that old branch only. Its 15 changed files never reached =main=: no report buffer called =sp-echo-help-set=, and the key lines stayed in the header, the buffers and the footers.
- *Second cause (found while testing):* even with #459 applied, the hints could stay hidden.
  - =sp-batch-report-open= set them before =pop-to-buffer=, so the buffer was not yet in the selected window and nothing was shown at once.
  - =sp-echo-help-show= is polite and skips when a message is in the echo area. The last message of a job ("done", "cancelled") stays there, so neither the post-command nor the idle show ever fired.
