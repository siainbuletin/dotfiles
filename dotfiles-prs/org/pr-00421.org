**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- =sp-devonthink-sync= (=docs/tangles/academic/sp-devonthink-sync.org=; ADR 0030). A report first, writers second; nothing is written without a plan on screen and a yes.
- =sp-devonthink-sync-report= (=C-c k d y=) compares litnotes, the PDF records and the registered =.bib= files by citekey: PDFs with no litnote, litnotes with no PDF, PDFs not in any =.bib=, litnotes with a dead =#+devonthink:= UUID, litnotes whose UUID differs from the record named after the key, and notes to backfill. Read-only.
- =sp-devonthink-sync-backfill= writes =#+devonthink: UUID= into the notes that lack it. It shows the plan, asks, copies each changed note first to =<sp-var-dir>/devonthink-backups/<timestamp>/=, skips notes open with unsaved changes, and reverts open unchanged ones. A prefix argument is a limit (=C-u 1=).
- Record side (ADR 0030, proposed): =sp-devonthink-sync-probe-field= tests the custom metadata field =litnote= on one record (set, read back, clear); =sp-devonthink-sync-record-links= writes ~org-protocol://devonthink-note?id=<note ID>~ into the records of notes with a live keyword (plan and a yes first, =C-u N= limit); =sp-devonthink-protocol-note= opens a note from such a URL with =org-id-open=.
- The "Status" table and "Open questions" in =sp-devonthink.org= now name this series' PRs.
