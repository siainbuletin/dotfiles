**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Symptom:* the citekey is not in italics (it should be the faded grey italic =sp-citar-key= face: =shadow=, italic).
- *Cause (found in citar's source and checked in Emacs):* =citar-templates= has no =completion= entry, so citar builds that template itself as =(concat (propertize main 'face 'citar-highlight) (propertize suffix 'face 'citar))=. =propertize= replaces every =face= of the suffix, including the one on the citekey field, with =citar=. citar then reads each field's face from the template at the field's place (=text-properties-at= in =citar-format--parse=), so the key is drawn in =citar=, not =sp-citar-key=. Shown by =sp-citations-citar-default-template-loses-the-face=.
- *Why it showed up now, not known:* the face was already set this way in #411 and earlier. I could not find a change in #432/#433 that removed it (the pixel cells and the re-formatting do not touch the key's face), so it may have been lost since the =sp-citar-key= suffix was introduced, or it depends on your citar version. I could not run citar here.
- *Fix:* =sp-citations--completion-template= builds the =completion= entry of =citar-templates= itself: main in =citar-highlight=, as citar does, and the =citar= face added after the faces the suffix has (=add-face-text-property= with append), so the key is =(sp-citar-key citar)=. =sp-citations--layout-templates= now returns =main=, =suffix= and =completion=, and =sp-citations--apply-layout= replaces all three.
- Tests (=tests/sp-citations-layout-test.el=, 10 pass): the face at the key field of the completion template starts with =sp-citar-key=; the text is main then suffix; citar's default behaviour loses the face; applying the layout keeps one =completion= entry. Tangle check passes.
- Docs updated in =docs/tangles/academic/sp-academic.org= (bullet lists). No CHANGELOG edit.
