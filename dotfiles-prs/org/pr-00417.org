**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- =sp-devonthink-search= (=C-c k d f=): one front end over two engines.
  - DEVONthink search by default: the query goes to DEVONthink as typed, so =name:=, =kind:=, =tags:=, quotes, =AND=/=OR=/=NOT= work. It lists the first 50 hits (=sp-devonthink-search-limit=) with kind and page count.
  - =C-u= asks for the engine: =devonthink=, =litdb: meaning=, =litdb: words=, =litdb: both= (the last three run the existing =sp-litdb-search= with that mode).
- Hits have the same completion category as the browser, so all browser Embark actions work on them (open, PDF, litnote, link, tags), plus:
  - =s= similar records (DEVONthink's "see also", =compare=);
  - =v= preview of the first 3000 characters of the text (cut inside DEVONthink).
- =sp-devonthink-similar-to-note= (=C-c k d a=): similar records for the record of the current litnote.
- The browser's record parser now accepts two optional extra fields (kind, pages). Literate doc =docs/tangles/academic/sp-devonthink-search.org=; README table row added.
- The concordance is not in the scripting dictionary, so it is not offered (as in the design); open the record in DEVONthink for it.

1. Check out the branch (=cd ~/dotfiles; git fetch origin 416-devonthink-search; git checkout 416-devonthink-search=), restart Emacs.
2. Unit tests: =cd ~/.config/emacs-modular; for f in browse search; do emacs -Q --batch -L libraries/modules/academic -l ert -l tests/sp-devonthink-$f-test.el -f ert-run-tests-batch-and-exit; done= → 6 and 7 tests pass.
3. DEVONthink open on =literature=. =C-c k d f=, type a word you know occurs (e.g. =Therborn=), =RET=-less: the hits list appears in DEVONthink's rank order, each with e.g. =PDF Document, 212 pages=. Time it (the design measured about 0.5 s for 1,455 hits). Choose a hit → it opens in DEVONthink.
4. Operators: =C-c k d f=, query ="value form" kind:pdf= → only PDFs with the phrase. Query =name:okane= → records by file name.
5. Embark on a hit (=C-.=): =v= shows a =*devonthink preview*= buffer with the start of the text; =n= goes to its litnote; =t= tags it (see #415).
6. Similar records: on a hit press =s= → a new list "Similar to KEY.pdf:" of related records; choose one to open. In a litnote with a =#+devonthink:= keyword (or a citekey), =C-c k d a= does the same.
7. litdb: =C-u C-c k d f= → choose =litdb: meaning= and a query such as =exchange abstraction=. Expect the same results as =C-c k l= (=sp-litdb-search=) with the vector mode: page hits with scores; choosing one opens DEVONthink at that page. (This needs the litdb index: =C-c k I= if you never ran it.) Also try =litdb: words= and =litdb: both=.
8. Empty search: query =zzzzzzqq= → "No records found" and nothing else happens.
