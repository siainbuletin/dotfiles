**** What
:PROPERTIES:
:CUSTOM_ID: what
:END:
- In DEVONthink, select a citation and press =Caps Lock + r=: the record of the cited work opens.
- Builds on the existing design (=docs/architecture/citation-matching-from-selection.org=) and on =sp-cite-match=; no new matcher.
- Lookup order:
  - the reference list at the end of the same document (numeric =[12]= or author-year =(Smith 2017)=);
  - the BibTeX files, with the =sp-cite-match= scoring and thresholds;
  - litdb, as a list to choose from (never automatic).
- A BibTeX match opens through =sp-reading-open=, so the record-lookup code of =sp-devonthink-browse=/=sp-reading= (crossref parent, index-if-missing) is unchanged.

**** Files
:PROPERTIES:
:CUSTOM_ID: files
:END:
- =sp-cite-open.el= (+ literate doc =docs/tangles/academic/sp-cite-open.org=) and 9 ERT tests (pass in batch on Emacs 29.3).
- =hammerspoon/cite-match.lua=: =M.send= takes a protocol; new =M.open=.
- =hammerspoon/devonthink.lua=: =Caps+r=, DEVONthink only. No clash with Caps+x/c or Caps+Option+1-7 (#512); =r= is not a workspace key.
- =README.org= module table and design doc updated. No CHANGELOG edit.

**** Not done / doubtful
:PROPERTIES:
:CUSTOM_ID: not-done--doubtful
:END:
- Citations in running prose are only parsed as surnames plus a year. =Ibid.= and =op. cit.= match nothing.
- No page jump inside the cited work; the record opens at its start.
- A PDF without a text layer has no reference list; the selection itself is matched.
- Not run on the Mac: the DEVONthink AppleScript (=plain text of record=), the hotkey with Caps held, org-protocol.
