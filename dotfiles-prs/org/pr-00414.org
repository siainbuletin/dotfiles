**** What

- New module =sp-devonthink= (literate doc =docs/tangles/academic/sp-devonthink.org=, required from =sp-academic=, README row). It builds on =sp-reading= (citekey→UUID cache, item URLs, =osascript=).
- =devonthink:UUID::PAGE= Org link: follow opens the record at the page (page counted from 1 in the link, ~?page=N-1~ in the URL); export writes the description (=key p. 6=).
- =#+devonthink: UUID= litnote keyword: =sp-devonthink-set-keyword= writes it (asks before replacing a different value); =sp-devonthink-open-from-note= opens the record from the keyword, or by citekey when it is missing.
- =sp-devonthink-insert-link=, =sp-devonthink-store-link= (record, page and selection shown in DEVONthink, for =org-insert-link=), and a =citar= Embark action =D=.
- Keys under =C-c k d=: =o= open from note, =l= insert link, =s= store link, =k= set keyword, =r= refresh cache.
