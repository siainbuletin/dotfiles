**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- *Request:* long lines in each widget section of the =vulpea-ui-view= (=M-o v=) are cut at the window edge; wrap them so the whole content is readable.
- *New options* (group =sp-vulpea-ui-view=):
  - =sp-vulpea-ui-view-wrap-lines= (default =t=): wrap at word boundaries in the view buffer only (=visual-line-mode=, =truncate-lines= nil). Nil gives the old look.
  - =sp-vulpea-ui-view-wrap-indent= (default =t=): indent the wrapped part like the line start (=visual-wrap-prefix-mode=, Emacs 30+; older Emacs wraps without the indent).
- *Where it applies:* in the mode body, after the first mount, and after a =g= refresh (so a changed option takes effect on refresh). The sidebar and other buffers are not touched.
- Docs: new bullet-point part "Line wrapping" and "Wrapping the lines" in =sp-vulpea.org=; =.el= and tests re-tangled.
- Tests: 3 new ERT tests (13 in total pass on Emacs 29.3 batch). =when-let*= only, no CHANGELOG edit.
- *Untested by Claude:* real =vulpea-ui=/=vui= and the GUI (stubbed in tests). Not known whether =vui= sets its own =line-prefix=/=wrap-prefix= on widget text, or resets =truncate-lines= after mount; if wrapping does not show, tell me.
