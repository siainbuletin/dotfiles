**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- The author column now shows the last name first, then the first names: =Smith, John; Doe, Jane=. New =sp-citations--last-first=, the =lastfirst= transform of =citar-display-transform-functions=, used as =${author editor:N%lastfirst}= in the =main= template.
- BibTeX names are =Last, First= or =First Last=, whichever way they were typed, and citar showed them raw. Now:
  - =Last, First= stays; =Jane Q. Doe= becomes =Doe, Jane Q.=.
  - Particles stay with the last name (=Ludwig van Beethoven= becomes =van Beethoven, Ludwig=); so does a suffix (=Martin Luther King Jr.= becomes =King Jr., Martin Luther=; =Smith, Jr., John= becomes =Smith Jr., John=).
  - Names in braces (organisations) and single words are left as they are; =others= becomes =et al.=
  - Several names are joined with =; = (a comma would clash with the one inside each name). Editors are shown the same way when there is no author.
- The value is cut to the column width like any other, and the cut part stays hidden in the candidate, so searching still finds every author. The =preview= template is unchanged. The citekey styling from #439 is untouched.
- Limits: the particle list is a fixed set of common ones (von, van, de, der, di, la, le, ...); a particle typed with a capital is taken as part of the first names. LaTeX accents are not converted.
- Tests: =tests/sp-citations-layout-test.el=, 13 pass (17 name cases, nil, the template uses the transform, plus the earlier ones). Tangle check passes.
- Docs updated in =docs/tangles/academic/sp-academic.org= (bullet lists). No CHANGELOG edit.
