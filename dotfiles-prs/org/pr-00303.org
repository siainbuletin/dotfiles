- The "Module tree" in =README.org= is now one Org table per directory (same headings as before).
- Columns: Module, What it does, Literate doc, Tangled file, Part of.
- "Part of" comes from the =:tangle= targets of each doc in =docs/tangles/=:
  - A doc that tangles several modules is a system. Its main module is marked "hub".
  - The smaller modules name that doc, e.g. =sp-bibprocess=, =sp-citations=, =sp-litnotes=, =sp-pdfprocess= are part of =sp-academic=.
  - Others: the =sp-collection-query-tables-*= family, =sp-org-lint= (with =sp-author-notes*=, =sp-litnotes-refs/titles=), =sp-org-agenda=.
  - Docs without a module of their own name are "shared doc": =sp-vulpea=, =sp-search-browsing-trails=.
- Rows now follow the disk: added =sp-litdb=, =sp-litnotes-meta=, =sp-vault-perf=, =sp-vulpea-convert-keywords=, =sp-vulpea-ui=, =sp-magit-style=, =sp-merge-pick=, =sp-org-tag-registry= and the lint submodules. Dropped the merged =sp-dgraphs=, =sp-dyn-graph= and relationship-annotator rows (now =sp-graphs=).
