Before: =emacsclient -c= against the daemon opens a frame that disappears almost immediately.

After: the client frame stays open and is centered on screen.

=sp-frame.el= adds =sp-frame-recenter= to =after-make-frame-functions= but nothing defines it. The function got lost when =lem-frame-recenter= from lambda-emacs was renamed to the =sp-= prefix. Every frame made through =make-frame= (which is every =emacsclient -c= frame) signals a void-function error. The server then returns the error to the client and deletes the frame it just created. A plain GUI launch never hits this because its initial frame doesn't run that hook.

How: restore the function under its =sp-= name, with the same body as =lem-frame-recenter= in =lambda-emacs-modified/.../lem-setup-frames.el=.
