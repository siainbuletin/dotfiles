/Requested by *Sia*/

**** Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:
- =sp-litnotes= now uses =citar-vulpea= only; =citar-denote= is removed. Citation keys live in the =ROAM_REFS= property (=@key=), and =citar-vulpea-mode= is switched on (it was never enabled before).
- New =sp-litnotes-refs=: =M-x sp-litnotes-refs-report= (dry run, writes nothing) and =M-x sp-litnotes-refs-convert=. It asks up to three questions: move =#+reference:= to =:ROAM_REFS: @key=; create an =:ID:= for notes that have none; add a stub entry to =master.bib= (the inbox) for each key no registered =.bib= has. Every changed note and =master.bib= are backed up first; safe to rerun.
- The report lists keys that no registered =.bib= has, keys used by several notes, and for each key whether a PDF exists under its own name or only under its =crossref= parent (needed by the DEVONthink link in #209).

Follows #209 (design).
