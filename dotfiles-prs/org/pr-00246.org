Implements the "Harmonize the highlight with the accent colors used in different themes" task from c325001.

- =sp-themes=: new =sp-theme-update-lazy-highlight= (on =sp-after-load-theme-hook=, and re-run by =sp-load-theme= after it disables old themes). The =sp-dark=/=sp-light= themes already set =lazy-highlight= from the =bg-search-lazy= role, so they are left alone. For Lambda, Ef and Doric themes the background is the foreground of =sp-theme-lazy-highlight-source= (default keyword face) blended into the default background (0.32 dark, 0.22 light), foreground is the default one. Uses =sp-theme-blend= from the engine; nothing hardcoded.
- =sp-org-custom-highlight=: =my-org-inline-comment= now inherits =lazy-highlight= instead of fixed yellow.
- Docs (=.org=) and tangled =.el= edited together; one ERT test added.

=isearch= is not touched.

Not run: no Emacs in the cloud container, so the tangle was done by hand and the test and the look in each theme are untested.
