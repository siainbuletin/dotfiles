**** What it does
:PROPERTIES:
:CUSTOM_ID: what-it-does
:END:
- Entries in =*see-also*= and =*see-also-concept*= show the Org tags of the heading they come from as =:a:b:= at the right edge of the entry's heading line.
- Face =sp-see-also-tags= inherits =org-tag=, so it follows the Modus theme.
- The tags are a =display= space with =:align-to (- right WIDTH)=, so they stay at the edge when the window is resized.
- A long title is cut with an ellipsis; the tags never are.
- =window-configuration-change-hook= redraws the view when the window width changes (folds are lost then).
- Parser: =sp-see-also--headings= returns =:tags=; mentions carry =:heading-tags=. Cache version 4 to 5, so files are read again once.
- Only tags written on the heading line; inherited tags and =#+filetags:= are not shown.
- Literate doc =docs/tangles/academic/sp-see-also.org= updated (bullets); =.el= and tests tangled from it.
- 4 new ERT tests; all 36 pass in Emacs 29.3. The real GUI was not run.
