#+title: Changelog
#+startup: overview

Changes to the Emacs configuration, grouped by the feature they build or fix. Within a set the pull requests follow the order they depend on each other, the base first. For the reason behind a change, open the pull request or the decision record linked from the set. Paths are relative to this folder. Each line starts with its pull request number, then the author, then what happened: ✨ Added, 🔧 Changed, 🐛 Fixed, 🔥 Removed, 💡 Proposed; the category headings are not repeated.
