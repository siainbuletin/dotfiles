* Structure of the Emacs config

- =early-init.el= :: Optimisations for starting up Emacs
- =init.el= :: Contains only the foundations for the functioning of our config. Also, it contains Lisp macros. It will load the different configuration modules that we've defined.
- =sia-modules/= directory :: These are the configuration modules. They don't introduce new bits of Emacs Lisp code, instead they just tweak some configuration for packages.
- =sia-lisp/= directory :: This actually loads custom Emacs Lisp code.
- =sia-ews-functions.el= :: temporary file from where I load helped functions inspired by Emacs Writing Studio.
- =literate-config.org= :: is the current file, which describes the entire architecture.

To load personal modules (which are configurations of existing packages), as well as custom Lisp functions, I have to define two different locations on the =load-path=:

- =sia-modules= directory :: This is a subdirectory of the parent for emacs configuration. If I weren't using =chemacs2= for configuring my setup, then this would be =~/.emacs.d=. Right now, this directory is =~/.config/emacs=.

  File names are pretty simple: =keybindings.el= defines all specific keybindings, the =academic.el= submodule deals with my academic setup, with all the weeds it might bring with it. *(The academic package may actually be split further, or have other submodules call to it, because it's actually too massive as a usecase.)*

  These modules contain ordinary Emacs Lisp code. At the end of the file there's a call to =provide=, which makes sure that the configurations made are made available to the =init.el= file through =require=.

  A _feature_, in Emacs lingo, is a *variable* whose value is the *entirety* of the file that has the =provide= call within it. Features are *symbols* which are named after the file name (dropping the file extension). For example, if we have a module file called =sia-dark-theme.el=, then the feature it _provides_ for Emacs will be called =sia-dark-theme= and it can be called via =require= within the =init.el= file.

- =sia-lisp= directory :: This where something more traditionally understood as "packages" may reside.

Adding them to the path is done through:

#+begin_src emacs-lisp :tangle no
  (mapc
   (lambda (string)
    (add-to-list 'load-path (locate-user-emacs-file string)))
  '("sia-lisp" "sia-modules"))
#+end_src

* File backup settings

We'll be installing a utility package called =vc-backup= which creates a versioned backup backend

#+begin_src emacs-lisp :tangle "init.el"

#+end_src

Before actually saving a file, what Emacs does is that it takes the contents of the old file and creates a "backup" file for it. These will usually have a =~= attached at the end. As long as you have the file open in the current buffer, the backup will stay at the point _before_ you first opened it. Basically, the backups are done *session by session*.[fn:6]

After you kill a buffer, if you visit the file again, it will create a new backup file, since what you're doing is effectively *starting a new session*.

This code snippet will also make sure that the autosaved files are offloaded to a different folder (for peace of mind). It makes use of the =backup-directory-alist= variable, which can set up file name patterns and backup directory names.

#+begin_src emacs-lisp :tangle "init.el"
  (setq backup-directory-alist
      `(("." . ,(expand-file-name "backups" user-emacs-directory)))
        make-backup-files t
        vc-make-backup-files t ; Won't create backup of files that are already under version control
        backup-by-copying t ; Avoid symlinks
        delete-old-versions t
        delete-by-moving-to-trash t ; This makes sure that the files aren't permanently deleted
        kept-new-versions 6
        kept-old-versions 3
        version-control t)
#+end_src

**** Adding the most recently downloaded PDF to the current entry

#+begin_src emacs-lisp :tangle "init.el"
(defun do.refs/ebib-add-newest-from-downloads (&optional file-extension)
    "Add the most recent file from `do.refs/pdf-download-dir' to the ebib entry at point."
    (interactive)
    ;; pull out the most recent file from ~/Downloads with the .pdf extension.
    (let ((newest-file (let ((dir-files (directory-files-and-attributes do.refs/pdf-download-dir)))
                         (caar (sort
                                (if (not file-extension)
                                    ;; the newest file from the download directory
                                    (mapcan (lambda (x)
                                              (let ((file-name (concat (file-name-as-directory do.refs/pdf-download-dir) (car x))))
                                                (when (file-regular-p file-name) (cons x nil))))
                                            dir-files)
                                  ;; all files with a certain extension
                                  (mapcan (lambda (x) (when (string-equal (file-name-extension (nth 0 x)) file-extension) (cons x nil)))
                                          dir-files))
                                ;; sort by date
                                (lambda (x y) (not (time-less-p (nth 6 x) (nth 6 y)))))))))
      (if newest-file
          ;; https://nullprogram.com/blog/2017/10/27/
          ;; need to override `read-file-name' because ebib normally prompts us for the file to import
          (let ((fpath (concat (file-name-as-directory do.refs/pdf-download-dir) newest-file))
                (bibkey (ebib--get-key-at-point)))
            (cl-letf (((symbol-function 'read-file-name) (lambda (&rest _) fpath)))
              (let ((current-prefix-arg '(4))) ;; C-u (to keep from removing original file)
                (call-interactively #'ebib-import-file)))
            (message "[Ebib] [Dennis] Imported %s for %s" fpath bibkey))
        (message "[Ebib] [Dennis] No files from %s imported." do.refs/pdf-download-dir))))
#+end_src

(defun do.refs/ebib-add-newest-from-downloads (&optional file-extension)
    "Add the most recent file from `do.refs/pdf-download-dir' to the ebib entry at point."
    (interactive)
    ;; pull out the most recent file from ~/Downloads with the .pdf extension.
    (let ((newest-file (let ((dir-files (directory-files-and-attributes do.refs/pdf-download-dir)))
                         (caar (sort
                                (if (not file-extension)
                                    ;; the newest file from the download directory
                                    (mapcan (lambda (x)
                                              (let ((file-name (concat (file-name-as-directory do.refs/pdf-download-dir) (car x))))
                                                (when (file-regular-p file-name) (cons x nil))))
                                            dir-files)
                                  ;; all files with a certain extension
                                  (mapcan (lambda (x) (when (string-equal (file-name-extension (nth 0 x)) file-extension) (cons x nil)))
                                          dir-files))
                                ;; sort by date
                                (lambda (x y) (not (time-less-p (nth 6 x) (nth 6 y)))))))))
      (if newest-file
          ;; https://nullprogram.com/blog/2017/10/27/
          ;; need to override `read-file-name' because ebib normally prompts us for the file to import
          (let ((fpath (concat (file-name-as-directory do.refs/pdf-download-dir) newest-file))
                (bibkey (ebib--get-key-at-point)))
            (cl-letf (((symbol-function 'read-file-name) (lambda (&rest _) fpath)))
              (let ((current-prefix-arg '(4))) ;; C-u (to keep from removing original file)
                (call-interactively #'ebib-import-file)))
            (message "[Ebib] [Dennis] Imported %s for %s" fpath bibkey))
        (message "[Ebib] [Dennis] No files from %s imported." do.refs/pdf-download-dir))))
