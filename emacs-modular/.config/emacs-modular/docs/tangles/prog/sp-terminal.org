- To tangle, see [[file:../../tangling-instructions.org][Tangling instructions]].

This module installs =eat=, a terminal emulator written in Emacs Lisp, which =claude-code= in =sp-ai= waits for.

- =vterm= is not installed (removed in the PR that follows #259): it needs a native module compiled with CMake, and with =vterm-always-compile-module= that build ran from the Elpaca queue and could block Emacs. See [[file:../../CHANGELOG.org][CHANGELOG]].
- For scripts that do not need a terminal, use =M-x compile= or =M-x async-shell-command=.

* EAT

** The eat package

Installs =eat= (Emulate A Terminal) with default settings. It needs no native module, so it also works where vterm cannot be built. Nothing is bound to it here; =claude-code= is declared =:after= it.

#+begin_src emacs-lisp -i
;;;; EAT
(use-package eat
  :ensure t)
#+end_src
