The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module collects helpers for working with Org tables. It has three parts:

- an experimental attempt to render a table as an image overlay via LaTeX,
- a command that wraps a long table column to a fixed width by spreading text across extra rows,
- a minor mode from alphapapa's /unpackaged.el/ that forces table text into the monospace =org-table= face, so alignment survives in variable-pitch buffers,
- an Obsidian-style look: quiet borders and header for =org-table-widget=, and dimmed pipes for the plain-text table.

Dependencies and use:

- Depends only on Org itself (=org-element=, =org-table= and, for the rendering experiment, the LaTeX preview machinery) and =cl-lib=.
- The rendering, wrapping and monospace features are not enabled automatically: use them through =M-x=, or add the minor mode to a hook by hand. The Obsidian-style look is on by default.
- The author's comment notes the wish for Obsidian Dataview style table rendering and suggests watching the =textui= package for that.

The commentary at the top of the module says:

* Rendering tables as images

An experiment in replacing a table with a rendered picture of itself. It looks unfinished and may not work on current Org.

** Render the table at point

=sia-render-org-table-at-point= toggles a rendered view of the table under point.

- If there is an overlay at the start of the line, it deletes it (the comment admits this may remove an unrelated overlay).
- Otherwise it checks that point is in a table or table row, walks up to the table element, and passes it to =sia-render-org-table=.

#+begin_src emacs-lisp -i
(defun sia-render-org-table-at-point ()
  (interactive)
  (save-excursion
    (beginning-of-line)
    (if (overlays-at (point))
        ;; this is a rough solution, because there can
        ;; be other overlays at point
        (delete-overlay (car (overlays-at (point))))

      (let* ((element-type (org-element-type (org-element-at-point))))
        (if (and (not (eq element-type 'table))
                 (not (eq element-type 'table-row)))
            (error "not at an org table")

          (while (not (eq 'table (org-element-type (org-element-at-point))))
            (forward-line -1))

          (sia-render-org-table (org-element-at-point)))))))
#+end_src

** Render one table

=sia-render-org-table= takes an Org table element and:

- trims trailing blank lines from its end,
- copies the text into a temporary buffer,
- converts it to LaTeX with =org-latex-convert-region-to-latex=,
- generates a preview with =org-preview-latex-fragment=,
- takes the resulting image from the preview overlay and shows it over the original table with a new =display= overlay.

The temporary buffer is not in Org mode, and =org-preview-latex-fragment= is an obsolete name. So this probably fails on recent Org versions; treat it as a sketch.

#+begin_src emacs-lisp -i
(defun sia-render-org-table (table)
  (interactive)
  (let* ((begin (org-element-property :begin table))
         (end (let ((pos (org-element-property :end table)))
                (goto-char pos)
                (beginning-of-line)
                ;; skip possible space after table
                (while (not (looking-at " *[|#]"))
                  (setq pos (point))
                  (forward-line -1))
                pos))
         (tabletxt (buffer-substring-no-properties begin end))
         (img (with-temp-buffer
                (insert tabletxt)
                (mark-whole-buffer)
                (org-latex-convert-region-to-latex)
                (org-preview-latex-fragment)
                (goto-char (point-min))
                (overlay-get  (car (overlays-at (point))) 'display)))
         (overlay (make-overlay begin end)))
    (overlay-put overlay 'display img)
    (forward-line -1)))
#+end_src

* Wrapping table columns

** Render all tables, and wrap a column

This block holds two unrelated forms. =sia-render-org-tables-in-buffer= maps =sia-render-org-table= over every table in the buffer; it is not interactive.

=org-table-wrap-to-width=, adapted from an Emacs StackExchange answer, wraps the current column to WIDTH characters.

- Starting at the top row, it cuts each field and re-wraps its text with =org-wrap=.
- It inserts enough empty rows below to hold the extra lines.
- It pastes the wrapped pieces back down the column.
- The result is a table where long cells become several shorter rows.

#+begin_src emacs-lisp -i
(defun sia-render-org-tables-in-buffer ()
  (save-excursion
    (org-element-map (org-element-parse-buffer) 'table 'sia-render-org-table)))
    
;;;; Org Table Wrap
;; see https://emacs.stackexchange.com/a/30871/11934
(defun org-table-wrap-to-width (width)
  "Wrap current column to WIDTH."
  (interactive (list (read-number "Enter column width: ")))
  (org-table-check-inside-data-field)
  (org-table-align)

  (let (cline (ccol (org-table-current-column)) new-row-count (more t))
    (org-table-goto-line 1)
    (org-table-goto-column ccol)

    (while more
      (setq cline (org-table-current-line))

      ;; Cut current field
      (org-table-copy-region (point) (point) 'cut)

      ;; Justify for width
      (setq org-table-clip
            (mapcar 'list (org-wrap (caar org-table-clip) width nil)))

      ;; Add new lines and fill
      (setq new-row-count (1- (length org-table-clip)))
      (if (> new-row-count 0)
          (org-table-insert-n-row-below new-row-count))
      (org-table-goto-line cline)
      (org-table-goto-column ccol)
      (org-table-paste-rectangle)
      (org-table-goto-line (+ cline new-row-count))

      ;; Move to next line
      (setq more (org-table-goto-line (+ cline new-row-count 1)))
      (org-table-goto-column ccol))

    (org-table-goto-line 1)
    (org-table-goto-column ccol)))
#+end_src

** Insert several rows

=org-table-insert-n-row-below= is the helper used by the wrapper.

- Builds an empty row matching the current one (keeping a special marker in the first field if present).
- Inserts N copies below.
- Realigns the table if Org thinks it needs it.
- Shifts formula references with =org-table-fix-formulas=, so existing formulas still point at the right rows.
- The "remove?" comments mark lines the author was unsure about.
- =point-at-bol= and =point-at-eol= are obsolete aliases in recent Emacs but still work.

#+begin_src emacs-lisp -i
(defun org-table-insert-n-row-below (n)
  "Insert N new lines below the current."
  (let* ((line (buffer-substring (point-at-bol) (point-at-eol)))
         (new (org-table-clean-line line)))
    ;; Fix the first field if necessary
    (if (string-match "^[ \t]*| *[#$] *|" line)
        (setq new (replace-match (match-string 0 line) t t new)))
    (beginning-of-line 2)
    (setq new
          (apply 'concat (make-list n (concat new "\n"))))
    (let (org-table-may-need-update) (insert-before-markers new))  ;;; remove?
    (beginning-of-line 0)
    (re-search-forward "| ?" (point-at-eol) t)
    (and (or org-table-may-need-update org-table-overlay-coordinates) ;;; remove?
         (org-table-align))
    (org-table-fix-formulas "@" nil (1- (org-table-current-dline)) n)))
#+end_src

* Monospace tables in variable-pitch buffers

From alphapapa's unpackaged.el.

- When Org buffers use proportional fonts, links or timestamps inside tables may keep a variable-pitch face and break alignment.
- This code reapplies the =org-table= font family to the whole table line.

** The minor mode

=unpackaged/org-table-face-mode= is a buffer-local minor mode.

- When enabled, it adds a font-lock keyword whose matcher is =unpackaged/org-table-face-matcher= and that applies =org-table=. When disabled, it removes it. In both cases it refontifies the buffer.
- The commentary suggests adding it to =org-mode-hook=, which this config does not do.

#+begin_src emacs-lisp -i
;;;; Force monospace font in org tables
;; If you use variable-pitch (a.k.a. “proportional”) fonts in Org buffers (e.g. using
;; org-variable-pitch), you probably use monospace fonts for Org tables, so they align 
;; properly. However, other elements in a table (such as links, or perhaps timestamps) 
;; may still use variable-pitch fonts, which breaks alignment. This code fixes that by 
;; forcibly applying the org-table face family to entire Org tables (which are detected 
;; by finding existing text with the org-table face, which makes use of Org’s built-in 
;; fontification).
;; 
;; To use, activate unpackaged/org-table-face-mode. You may want to add it to org-mode-hook.
;; 
;; source: https://github.com/alphapapa/unpackaged.el#force-monospace-face-in-tables

;;;###autoload
(define-minor-mode unpackaged/org-table-face-mode
  "Apply `org-table' face family to all text in Org tables.
Useful for forcibly applying the face to portions of table data
that might have a different face, which could affect alignment."
  :global nil
  (let ((keywords '((unpackaged/org-table-face-matcher 0 'org-table))))
    (if unpackaged/org-table-face-mode
        (font-lock-add-keywords nil keywords 'append)
      (font-lock-remove-keywords nil keywords))
    (font-lock-flush)))
#+end_src

** The font-lock matcher

=unpackaged/org-table-face-matcher= is called by font-lock with a search LIMIT.

- Using two local helpers, it finds the next text that already has the =org-table= face (which Org's own fontification puts on table lines).
- Then it adds FACE from there to the end of the line. By default FACE is just the =org-table= font family.
- It repeats until no more table text is found.
- It returns whether anything was changed, as font-lock expects.

#+begin_src emacs-lisp -i
(cl-defun unpackaged/org-table-face-matcher
    (limit &optional (face `(:family ,(face-attribute 'org-table :family))))
  "Apply FACE to entire Org tables.
A `font-lock-keywords' function that searches up to LIMIT."
  (cl-flet* ((find-face (face &optional limit not)
                        ;; Return next position up to LIMIT that has FACE, or doesn't if NOT.
                        (cl-loop with prev-pos
                                 with pos = (point)
                                 while (not (eobp))
                                 do (setf pos (next-single-property-change pos 'face nil limit))
                                 while (and pos (not (equal pos prev-pos)))
                                 for face-at = (get-text-property pos 'face)
                                 for face-matches-p = (or (eq face-at face)
                                                          (when (listp face-at)
                                                            (member face face-at)))
                                 when (or (and not (not face-matches-p))
                                          face-matches-p)
                                 return pos
                                 do (setf prev-pos pos)))
             (apply-face-from (pos face)
                              (unless (eobp)
                                (let* ((property-at-start (get-text-property pos 'face))
                                       (table-face-start (if (or (eq property-at-start 'org-table)
                                                                 (when (listp property-at-start)
                                                                   (member 'org-table property-at-start)))
                                                             (point)
                                                           (find-face 'org-table limit)))
                                       table-face-end)
                                  (when table-face-start
                                    (goto-char table-face-start)
                                    (setf table-face-end (line-end-position))
                                    (add-face-text-property table-face-start table-face-end face)
                                    (goto-char table-face-end))))))
    (cl-loop with applied-p
             for applied = (apply-face-from (point) face)
             when applied
             do (setf applied-p t)
             while applied
             finally return applied-p)))
#+end_src

* Obsidian-style tables

Can an Org table look like a table rendered in Obsidian (the Dataview look: no heavy grid, padded cells, a quiet header)? In a graphical Emacs, yes, nearly. In plain text, only part of the way.

- *Graphical frame.* =org-table-widget= (installed in [[file:../ui/sp-textui.org][sp-textui]]) already covers the source table with a pixel-aligned widget: padded cells, wrapping, a styled header, a sticky header. Its defaults are the part that does not look like Obsidian: zebra stripes, a loud grid, and =org-modern= drawing its own table borders over the same table (the widget's README says to switch =org-modern-table= off). The widget always draws a full grid (outer box, a vertical bar between columns), so the borders cannot be removed; they can be made so faint that the eye reads them as thin dividers. This module does that.
- *Terminal, or a table revealed for editing.* The widget is skipped there (it needs a graphical frame), so the source shows. Org cannot hide the pipes without breaking editing, so =sp-org-tables-quiet-pipes-mode= dims the =|= separators and rule lines instead, which leaves the cell text standing out.

** The theme-following faces

=org-modern-table= is set to nil. The border face is the theme foreground blended into the background by =sp-org-tables-border-strength= (0.22 by default), and the header row gets a background blended by =sp-org-tables-header-strength= (0.07). The blend is recomputed whenever a theme is enabled (=enable-theme-functions=), so it works with any theme. Zebra stripes are off. Nothing is changed until =org-table-widget= loads, because its faces do not exist before then. If the colours are unknown (a terminal without colours), the faces are left alone.

#+begin_src emacs-lisp -i
;;;; Obsidian-style tables
;; `org-table-widget' (see `sp-textui') already draws a table as a clean widget.
;; These settings keep it from fighting `org-modern', switch off the zebra
;; stripes and make the borders and the header quiet, as in Obsidian.  The
;; borders are blended from the theme colours, so they follow every theme.

(defgroup sp-org-tables nil
  "Quiet, Obsidian-like Org tables."
  :group 'org
  :prefix "sp-org-tables-")

(defcustom sp-org-tables-border-strength 0.22
  "How visible table borders are, from 0 (invisible) to 1 (text colour)."
  :type 'number)

(defcustom sp-org-tables-header-strength 0.07
  "How strongly the header row background differs from the buffer background."
  :type 'number)

;; `org-modern' draws its own table borders; the widget must be the only one.
(setq org-modern-table nil)

(defun sp-org-tables--blend (strength)
  "The theme foreground mixed into the background by STRENGTH, as #rrggbb.
Return nil when either colour is unknown (a terminal without colours)."
  (and-let* ((fg (color-name-to-rgb (face-attribute 'default :foreground nil 'default)))
             (bg (color-name-to-rgb (face-attribute 'default :background nil 'default))))
    (apply #'color-rgb-to-hex
           (append (cl-mapcar (lambda (f b) (+ (* strength f) (* (- 1 strength) b)))
                              fg bg)
                   '(2)))))

(defun sp-org-tables-update-faces (&rest _)
  "Make the table widget faces quiet, from the colours of the current theme."
  (when (facep 'org-table-widget-border)
    (when-let* ((border (sp-org-tables--blend sp-org-tables-border-strength)))
      (set-face-attribute 'org-table-widget-border nil
                          :inherit 'unspecified :foreground border))
    (set-face-attribute 'org-table-widget-header nil
                        :inherit 'bold
                        :background (or (sp-org-tables--blend sp-org-tables-header-strength)
                                        'unspecified))))

(with-eval-after-load 'org-table-widget
  (setq org-table-widget-zebra-stripe nil
        org-table-widget-use-unicode-borders t)
  (sp-org-tables-update-faces))

(add-hook 'enable-theme-functions #'sp-org-tables-update-faces)
#+end_src

** Quiet pipes in the plain-text table

=sp-org-tables-quiet-pipes-mode= adds a font-lock keyword that puts =sp-org-tables-pipe= (inherits =shadow=) on every =|= that Org already fontified as a table, and on rule lines like =|---+---|=. A =|= outside a table is left alone. The mode is added to =org-mode-hook=; switch it off in a buffer with =M-x sp-org-tables-quiet-pipes-mode=.

#+begin_src emacs-lisp -i
;;;; Quiet pipes in the plain-text table
;; In a terminal, or while a table is revealed for editing, the source shows.
;; This mode dims its `|' separators and rule lines, so the cell text stands out.

(defface sp-org-tables-pipe
  '((t :inherit shadow))
  "Face for the separators and rule lines of a plain-text Org table.")

(defun sp-org-tables--pipe-matcher (limit)
  "Find the next table `|' or rule line up to LIMIT, for font-lock."
  (catch 'found
    (while (re-search-forward "^[ \t]*|[-+|]*$\\||" limit t)
      (when (memq 'org-table (ensure-list (get-text-property (match-beginning 0) 'face)))
        (throw 'found t)))))

(defvar sp-org-tables--pipe-keywords
  '((sp-org-tables--pipe-matcher 0 'sp-org-tables-pipe prepend)))

;;;###autoload
(define-minor-mode sp-org-tables-quiet-pipes-mode
  "Dim the `|' separators and rule lines of plain-text Org tables."
  :global nil
  (if sp-org-tables-quiet-pipes-mode
      (font-lock-add-keywords nil sp-org-tables--pipe-keywords 'append)
    (font-lock-remove-keywords nil sp-org-tables--pipe-keywords))
  (font-lock-flush))

(add-hook 'org-mode-hook #'sp-org-tables-quiet-pipes-mode)
#+end_src


** Dividers between table rows

=org-table-widget= draws a rule only where the Org source has an =|---+---|= line, so body rows run together. The package has no option for row separators, so the module changes the table just before it is drawn.

- *Where*: =:filter-args= advice on =org-table-widget--render=, which receives the parsed table (a plist of =:rows=, =:lines=, =:header-rows=).
- *What*: =sp-org-tables--with-row-dividers= puts an =hline= between every two body rows; the widget then draws it like any rule.
- *Left alone*: header rows (before the first =hline=), rules already in the source, and the top and bottom borders.
- *=:lines=*: a divider takes the source line of the row above it, so mapping point to a row is unchanged.
- *Switch*: =sp-org-tables-row-dividers= (default =t=); set it to =nil= to get the old look.
- *Source file*: the Org source is not touched, only the drawn table.

#+begin_src emacs-lisp -i
;;;; Dividers between table rows
;; `org-table-widget' draws a rule only where the source has an hline, so rows
;; run together.  It has no option for this, so the table is changed just
;; before it is drawn: an hline goes between every two body rows.

(defcustom sp-org-tables-row-dividers t
  "Whether table widgets draw a rule between every two body rows."
  :type 'boolean)

(defun sp-org-tables--with-row-dividers (table)
  "A copy of the widget TABLE plist with an `hline' between every two body rows.
Header rows (those before the first `hline') and existing rules are left alone.
A divider takes the source line of the row above it."
  (let ((rows (plist-get table :rows))
        (lines (plist-get table :lines))
        (header-rows (or (plist-get table :header-rows) 0))
        (index 0)
        new-rows new-lines)
    (while rows
      (let ((row (pop rows))
            (line (pop lines)))
        (push row new-rows)
        (push line new-lines)
        (setq index (1+ index))
        (when (and (listp row) rows (listp (car rows)) (> index header-rows))
          (push 'hline new-rows)
          (push line new-lines))))
    (let ((new (plist-put (copy-sequence table) :rows (nreverse new-rows))))
      (if (plist-get table :lines)
          (plist-put new :lines (nreverse new-lines))
        new))))

(define-advice org-table-widget--render
    (:filter-args (args) sp-org-tables-row-dividers)
  "Draw a rule between body rows when `sp-org-tables-row-dividers' is set."
  (if sp-org-tables-row-dividers
      (cons (sp-org-tables--with-row-dividers (car args)) (cdr args))
    args))
#+end_src

** Following links in a table widget

In a table widget a click on a link, or =RET= on its row, opened a menu of every link in the entry before going anywhere. The cause: the widget draws each row as the =before-string= of an overlay and hides the source underneath, so the click or =RET= is delivered to the source (the start of the row). =org-open-at-point= finds no link there, goes up to the headline and offers every link of the entry. The drawn link text still carries the =htmlize-link= property Org gave it, with the link target, so the module reads the target from there:

- *Click* (=org-open-at-mouse=, advised): the link under the pointer is followed directly. A click elsewhere in a table, or anywhere else, behaves as before.
- *=RET=* (bound in =org-table-widget-map=) and *=C-c C-o=* (=org-open-at-point-functions=): the row has no pointed link, so a row with one link follows it at once, and a row with several asks which one. Without links =RET= does what it did (=org-return=).

Links are followed with =org-link-open-from-string=, so =id:=, =file:=, =https:= and the rest work as in the buffer.

#+begin_src emacs-lisp -i
;;;; Following links in table widgets
;; The widget draws a row as an overlay `before-string'; the source of the row
;; stays hidden underneath.  A click or RET therefore lands on the source, not
;; on the link that was drawn, and `org-open-at-point' then offers every link of
;; the entry.  These functions read the link from the drawn text instead.

(defun sp-org-tables--string-links (string)
  "The links drawn in STRING, as a list of (URI . TEXT) in order, without repeats.
URI comes from the `htmlize-link' property that Org puts on a link, which the
widget keeps in its cells."
  (let ((pos 0) (len (length string)) links)
    (while (< pos len)
      (let* ((next (or (next-single-property-change pos 'htmlize-link string) len))
             (uri (plist-get (get-text-property pos 'htmlize-link string) :uri)))
        (when (stringp uri)
          (let ((text (string-trim
                       (apply #'concat
                              (cl-loop for i from pos below next
                                       unless (get-text-property i 'invisible string)
                                       collect (string (aref string i)))))))
            (if-let* ((old (assoc uri links)))
                (when (string-empty-p (cdr old)) (setcdr old text))
              (push (cons uri text) links))))
        (setq pos next)))
    (nreverse links)))

(defun sp-org-tables--widget-overlay (&optional position)
  "The table widget row overlay at POSITION (point by default), or nil."
  (seq-find (lambda (overlay) (overlay-get overlay 'org-table-widget))
            (overlays-at (or position (point)))))

(defun sp-org-tables--open-uri (uri)
  "Follow the Org link target URI, as `org-open-at-point' does on a link."
  (org-link-open-from-string (format "[[%s]]" uri)))

(defun sp-org-tables--choose-link (links)
  "Follow the only link in LINKS, or ask which of them to follow."
  (sp-org-tables--open-uri
   (if (null (cdr links))
       (caar links)
     (let* ((choices (mapcar (lambda (link)
                               (cons (format "%s  (%s)" (cdr link) (car link))
                                     (car link)))
                             links))
            (choice (completing-read "Follow link: " (mapcar #'car choices) nil t)))
       (cdr (assoc choice choices))))))

(defun sp-org-tables-open-row-link ()
  "Follow a link of the table widget row at point; return nil if there is none.
One link is followed at once.  The choice menu only appears when the row has
several links, because RET cannot tell which one was meant (a click can)."
  (when-let* ((overlay (sp-org-tables--widget-overlay))
              (links (sp-org-tables--string-links
                      (or (overlay-get overlay 'before-string) ""))))
    (sp-org-tables--choose-link links)
    t))

(defun sp-org-tables-follow-link ()
  "Follow the link of the table widget row at point, or do what RET did before."
  (interactive)
  (unless (sp-org-tables-open-row-link)
    (call-interactively #'org-return)))

(defun sp-org-tables--clicked-uri (event)
  "The link target drawn at the position of mouse EVENT in a table widget, or nil."
  (let* ((posn (event-start event))
         (hit (posn-string posn)))
    (and (consp hit) (stringp (car hit))
         (bound-and-true-p org-table-widget-mode)
         (sp-org-tables--widget-overlay (posn-point posn))
         (plist-get (get-text-property (cdr hit) 'htmlize-link (car hit)) :uri))))

(define-advice org-open-at-mouse (:around (orig event) sp-org-tables-widget-link)
  "Follow the link that was clicked in a table widget, with no menu."
  (if-let* ((uri (sp-org-tables--clicked-uri event)))
      (progn (select-window (posn-window (event-start event)))
             (sp-org-tables--open-uri uri))
