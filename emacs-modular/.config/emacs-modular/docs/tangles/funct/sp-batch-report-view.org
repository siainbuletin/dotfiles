- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../tangling-instructions.org][Tangling instructions]].

* Why this exists

- The batch reports were Org text in a read-only Org buffer.
- Problems:
  - dropping an entry made the report again, so with hundreds of sections and thousands of rows it hung the buffer
  - =org-table-widget-mode= made it worse (PR #492 turned it off for reports)
  - each option (which key does what, which row is dropped) had to be encoded in Org text and read back from it
- The model: the =vulpea-ui-schema-dashboard= of =vulpea-ui=.
  - a read-only buffer with a title and a summary
  - collapsible sections with a count at the right edge
  - one row per entry, with a button for the action
- What was taken: the look and the structure.
- What was not taken: =vui.el= itself.
  - A virtual DOM re-renders the tree on every change; here a drop must touch one row.
  - No new package: the report needs =special-mode=, text properties and a few overlays.
  - The data (=sp-batch-report-section=, =-item=, =-table-section=) is the same for both views, so a =vui= renderer could still be added behind =sp-batch-report-open=.

* What the view looks like

#+begin_example
Works in BibTeX files without a literature note: 3 author notes
intro line

▼ Adorno, Theodor W.                                       12 entries
  • one            ...
▶ Arendt, Hannah                                            4 of 9
#+end_example

- Header line: =3 sections · 25 entries · 2 dropped=.
- =▶= is a folded section.
- =N of M= says that some entries of the section are dropped.

* The same keys in every report

- =RET= visit or run the action; =TAB= fold; =S-TAB= fold all; =n= / =p= next and previous entry.
- =d= drop the entry at point; =u= bring it back; =A= (or =C-c C-c=) apply what is left; =g= refresh.
- =b= open a backup of the file of the entry; =D= diff it; =k= stop the running job; =q= quit.
- =C-c ?= shows the hints again (=sp-interaction=).
- Letters a mode adds: lower case acts on the entry, upper case on the whole list.

* Which reports use it

- Every report made with =sp-batch-report-text=: the author works report, Org normalise, the footnote and tag lint, the BibTeX Zotero dry run, and the report of every =sp-bibtex-lint-fix-*= command.
- Not yet: reports that are still built as Org text (the BibTeX lint report itself, the litnote titles, references and meta reports, notes filing, property preview).
  - They open in the Org view (=sp-batch-report-org-mode=) and keep working.
  - They move to sections of items one by one.
- =sp-batch-report-display= set to =org= shows every report in the Org view, to compare the two.

;; The default view of `sp-batch-report': a read-only `special-mode' buffer in

* Text

- A report is drawn from data, not parsed from Org text.
- An item can still carry Org links in its text (the commands build them with =sp-batch-report-file-link=).
  - =sp-batch-report-view--linkify= turns each into a label with a =sp-batch-report-link= property; the property holds the link target.
  - =RET= hands the target to =org-link-open-from-string=, so =file:=, =id:= and the custom link types of the modules keep working.
- An item with a =:file= gets a link label (name, and =:LINE= when there is one) in front of its text.
- Children are indented under the entry, with a =·= bullet.
- A table cell is one line; columns are padded to the widest cell of the section, so they stay aligned in a monospace font.

#+begin_src emacs-lisp -i
(defun sp-batch-report-view--linkify (text)
  "TEXT with each Org link in it turned into a button-like label."
  (if (not (string-search "[[" text))
      text
    (let ((pos 0) parts)
      (while (string-match sp-batch-report-view--link-regexp text pos)
        (let ((target (org-link-unescape (match-string 1 text)))
              (label (org-link-unescape (or (match-string 2 text) (match-string 1 text)))))
          (push (substring text pos (match-beginning 0)) parts)
          (push (propertize label 'face 'sp-batch-report-link 'mouse-face 'highlight
                            'help-echo "RET: visit" 'sp-batch-report-link target)
                parts)
          (setq pos (match-end 0))))
      (push (substring text pos) parts)
      (apply #'concat (nreverse parts)))))

(defun sp-batch-report-view--file-target (file &optional line)
  "The Org link target that visits FILE, at LINE when it is given."
  (concat "file:" (expand-file-name file)
          (cond ((integerp line) (format "::%d" line))
                ((stringp line) (concat "::" line)))))

(defun sp-batch-report-view--head (item)
  "The label of ITEM that visits its file, or nil when it has no file."
  (when-let* ((file (plist-get item :file)))
    (let ((line (plist-get item :line)))
      (propertize (or (plist-get item :label)
                      (concat (file-name-nondirectory (directory-file-name file))
                              (and (integerp line) (format ":%d" line))))
                  'face 'sp-batch-report-link 'mouse-face 'highlight
                  'help-echo "RET: visit"
                  'sp-batch-report-link (sp-batch-report-view--file-target file line)))))

(defun sp-batch-report-view--list-row (item)
  "The text of the list ITEM: a bullet, the file, the text, then the children."
  (let* ((head (sp-batch-report-view--head item))
         (text (plist-get item :text))
         (text (and text (sp-batch-report-view--linkify
                          (sp-batch-report--indent text "      ")))))
    (when (and (plist-get item :action) (not head) text)
      (setq text (propertize text 'face 'sp-batch-report-action 'mouse-face 'highlight)))
    (concat "  • " head (and head text "  ") text "\n"
            (mapconcat (lambda (child)
                         (concat "      · "
                                 (sp-batch-report-view--linkify
                                  (sp-batch-report--indent child "        "))
                                 "\n"))
                       (plist-get item :children) ""))))

(defun sp-batch-report-view--cell (cell)
  "CELL as one line of text, its links turned into labels."
  (sp-batch-report-view--linkify
   (replace-regexp-in-string "[\n\r]+" " " (format "%s" (or cell "")))))

(defcustom sp-batch-report-column-max-width 40
  "The widest a column of a table in a report gets, in characters.
The rest of a longer cell is wrapped under it, inside the column."
  :type 'integer
  :group 'sp-batch-report)

(defcustom sp-batch-report-column-min-width 8
  "The narrowest a column is made to fit the window, in characters."
  :type 'integer
  :group 'sp-batch-report)

(defun sp-batch-report-view--window-width ()
  "The width of the window of this buffer, in characters of its own text size.
The characters are those of the default face of the buffer, so zooming the text
(`text-scale-adjust') changes the width as well.  Without a window it is
`fill-column'."
  (if-let* ((window (get-buffer-window (current-buffer) t)))
      (let ((char (window-font-width window)))
        (if (> char 0)
            (floor (window-body-width window t) char)
          (window-body-width window)))
    fill-column))

(defun sp-batch-report-view--column-widths (header cells)
  "The widths of the columns named HEADER, with the rows CELLS, for this window.
Each column is as wide as its widest cell, at most `sp-batch-report-column-max-width'.
When the columns do not fit the window, the widest are made narrower, one
character at a time, down to `sp-batch-report-column-min-width' (or the name of
the column when that is shorter)."
  (let* ((n (length header))
         (widths (apply #'cl-mapcar
                        (lambda (&rest column)
                          (min sp-batch-report-column-max-width
                               (apply #'max (mapcar #'string-width column))))
                        header cells))
         (minimum (mapcar (lambda (name)
                            (min (string-width name) sp-batch-report-column-min-width))
                          header))
         (room (- (sp-batch-report-view--window-width) 2 (* 2 (1- n)) 1))
         (excess (- (apply #'+ widths) room)))
    (while (and (> excess 0)
                (let ((best nil) (i 0))
                  (dolist (width widths)
                    (when (and (> width (nth i minimum))
                               (or (null best) (> width (nth best widths))))
                      (setq best i))
                    (setq i (1+ i)))
                  (when best
                    (setcar (nthcdr best widths) (1- (nth best widths)))
                    (setq excess (1- excess))
                    t))))
    widths))

(defun sp-batch-report-view--wrap (cell width)
  "The lines of CELL wrapped to WIDTH characters, at spaces when it can.
A word longer than WIDTH is cut.  The text properties of CELL are kept."
  (let ((rest (string-trim cell)) lines)
    (while (> (string-width rest) width)
      (let* ((head (truncate-string-to-width rest width))
             (limit (length head))
             (space (and (< limit (length rest))
                         (= (aref rest limit) ?\s)
                         limit))
             (space (or space
                        (let ((found nil) (k (1- limit)))
                          (while (and (> k 0) (not found))
                            (when (= (aref head k) ?\s) (setq found k))
                            (setq k (1- k)))
                          found)))
             (cut (or space (max limit 1))))
        (push (string-trim-right (substring rest 0 cut)) lines)
        (setq rest (string-trim-left (substring rest cut)))))
    (nreverse (cons rest lines))))

(defun sp-batch-report-view--table-line (cells widths face)
  "The lines of the row CELLS, each wrapped to its column in WIDTHS.
FACE, when given, is the face of the row.  The row ends with a newline."
  (let* ((columns (cl-mapcar
                   (lambda (cell width)
                     (sp-batch-report-view--wrap
                      (if face (propertize (substring-no-properties cell) 'face face) cell)
                      width))
                   cells widths))
         (height (apply #'max (mapcar #'length columns)))
         (n (length columns)))
    (mapconcat
     (lambda (line)
       (let ((i -1))
         (concat "  "
                 (mapconcat
                  (lambda (column)
                    (setq i (1+ i))
                    (let ((text (or (nth line column) "")))
                      (if (= i (1- n))
                          text
                        (concat text (make-string (max 0 (- (nth i widths) (string-width text)))
                                                  ?\s)))))
                  columns "  ")
                 "\n")))
     (number-sequence 0 (1- height)) "")))

(defun sp-batch-report-view--count-string (kept total)
  "The count of a section, KEPT of TOTAL, padded to the fixed width."
  (propertize (string-pad (if (= kept total)
                              (format "%d %s" total (if (= total 1) "entry" "entries"))
                            (format "%d of %d" kept total))
                          sp-batch-report-view--count-width nil t)
              'face 'sp-batch-report-count))
#+end_src

* Drawing

- =sp-batch-report-view--render= draws the whole report in one pass, with plain =insert=: no widget, no overlay per row.
- One section is: a header line, the column names when it is a table, then a row for each item.
  - The header is =▼ Title=, then the count at the right edge of the window.
  - The right edge comes from a =display= property =(space :align-to (- right N))=, so it stays aligned when the window is resized and nothing is drawn again.
  - The count has a fixed width (=sp-batch-report-view--count-width=), so a drop rewrites it in place and no position after it moves.
- Every row has text properties: =sp-batch-report-row= (its index), =sp-batch-report-section=, the key, the file and line, and what the item brings in =:props=.
  - Commands of derived modes read =sp-file=, =sp-person= and the like from any character of the row, as before.
- The buffer-local data for fast edits:
  - =sp-batch-report-view--rows=: a vector of =(BEG END SECTION)=, in buffer order.
  - =sp-batch-report-view--sections=: a vector with the body bounds, the counts and the fold overlay of each section.
  - =sp-batch-report-view--by-key=: a hash table from a key to the rows that have it (an entry can be in two sections).
- Keys that were dropped earlier and are not in the report any more go to a last section, "Dropped earlier, not in this report"; =u= brings one back.

#+begin_src emacs-lisp -i
(defun sp-batch-report-view--render (model)
  "Draw the report MODEL in the current buffer.
MODEL is a plist with :title, :intro, :sections, :excluded and :key-label."
  (let* ((inhibit-read-only t)
         (excluded (plist-get model :excluded))
         (folded (if sp-batch-report-view--sections
                     (cl-loop for s across sp-batch-report-view--sections
                              when (aref s 4) collect (aref s 8))
                   sp-batch-report-view--folded))
         (by-key (make-hash-table :test #'equal))
         (rows nil) (nrows 0) (sections nil) (nsections 0) (ndropped 0)
         (known (make-hash-table :test #'equal))
         (all (plist-get model :sections)))
    (when-let* ((key-label (plist-get model :key-label))
                (_ excluded))
      (ignore key-label))
    (dolist (section all)
      (dolist (item (plist-get section :items))
        (when-let* ((key (sp-batch-report--item-key item)))
          (puthash key t known))))
    ;; Keys dropped earlier that this report no longer has go to a section of their own.
    (when-let* ((stale (seq-remove (lambda (key) (gethash key known)) excluded)))
      (setq all (append all
                        (list (sp-batch-report-section
                               "Dropped earlier, not in this report"
                               (mapcar (lambda (key)
                                         (sp-batch-report-item
                                          (funcall (or (plist-get model :key-label)
                                                       #'sp-batch-report--key-label)
                                                   key)
                                          :key key))
                                       stale))))))
    (erase-buffer)
    (remove-overlays)
    (insert (propertize (or (plist-get model :title) "Report") 'face 'sp-batch-report-title) "\n")
    (when-let* ((intro (plist-get model :intro)))
      (insert (sp-batch-report-view--linkify intro) "\n"))
    (insert "\n")
    (dolist (section all)
      (let* ((sec nsections)
             (header (plist-get section :header))
             (items (plist-get section :items))
             (hs (point))
             arrow count-pos body-beg (total 0) (dropped 0) widths cells)
        (setq arrow (point))
        (insert (propertize "▼" 'face 'sp-batch-report-section) " "
                (propertize (plist-get section :title) 'face 'sp-batch-report-section)
                (propertize " " 'display
                            `(space :align-to (- right ,(1+ sp-batch-report-view--count-width)))))
        (setq count-pos (point))
        (insert (sp-batch-report-view--count-string (length items) (length items)) "\n")
        (add-text-properties hs (point) (list 'sp-batch-report-section sec 'sp-batch-report-header t))
        (setq body-beg (point))
        (when header
          (setq cells (mapcar (lambda (item) (mapcar #'sp-batch-report-view--cell (plist-get item :row)))
                              items))
          (setq widths (sp-batch-report-view--column-widths header cells))
          (let ((line-start (point)))
            (insert (sp-batch-report-view--table-line header widths 'sp-batch-report-column))
            (put-text-property line-start (point) 'sp-batch-report-section sec)))
        (if (null items)
            (let ((start (point)))
              (insert "  " (or (plist-get section :empty) "none") "\n")
              (add-text-properties start (point) (list 'face 'shadow 'sp-batch-report-section sec)))
          (dolist (item items)
            (let* ((key (sp-batch-report--item-key item))
                   (drop (and key (member key excluded) t))
                   (beg (point))
                   (action (plist-get item :action)))
              (insert (if header
                          (sp-batch-report-view--table-line (pop cells) widths nil)
                        (sp-batch-report-view--list-row item)))
              (add-text-properties
               beg (point)
               (append (sp-batch-report--item-props item drop)
                       (and action (list 'sp-batch-report-action action))
                       (list 'sp-batch-report-row nrows 'sp-batch-report-section sec
                             'wrap-prefix "      ")))
              (when drop
                (add-face-text-property beg (point) 'sp-batch-report-dropped)
                (cl-incf dropped) (cl-incf ndropped))
              (push (list beg (point) sec) rows)
              (when key (puthash key (cons nrows (gethash key by-key)) by-key))
              (cl-incf nrows) (cl-incf total))))
        (let ((inhibit-modification-hooks t))
          (save-excursion
            (goto-char count-pos)
            (delete-region count-pos (+ count-pos sp-batch-report-view--count-width))
            (insert (sp-batch-report-view--count-string (- total dropped) total))))
        (push (vector body-beg (point) (- total dropped) total nil hs arrow count-pos
                      (plist-get section :title))
              sections)
        (cl-incf nsections)))
    (setq sp-batch-report-view--rows (vconcat (nreverse rows))
          sp-batch-report-view--sections (vconcat (nreverse sections))
          sp-batch-report-view--by-key by-key
          sp-batch-report-view--dropped ndropped
          sp-batch-report-view--folded nil
          sp-batch-report-view--model model
          sp-batch-report-view--width (sp-batch-report-view--window-width)
          sp-batch-report-view--has-tables (and (seq-some (lambda (s) (plist-get s :header)) all) t))
    (dotimes (i nsections)
      (when (member (aref (aref sp-batch-report-view--sections i) 8) folded)
        (sp-batch-report-view--fold i t)))
    (set-buffer-modified-p nil)
    (goto-char (point-min))))
#+end_src

* Folding

- =TAB= folds the section at point, =S-TAB= folds all of them, or opens all when all are folded.
- A fold is one overlay with =invisible=, made when needed; the arrow is a =display= property on one character.
- A refresh keeps the folds: the titles of the folded sections are read before the buffer is cleared (=sp-batch-report-view--sections= is =permanent-local=).

#+begin_src emacs-lisp -i
(defun sp-batch-report-view--fold (sec folded)
  "Fold the section number SEC when FOLDED is non-nil, else unfold it."
  (let* ((s (aref sp-batch-report-view--sections sec))
         (overlay (aref s 4))
         (inhibit-read-only t))
    (if folded
        (unless overlay
          (setq overlay (make-overlay (aref s 0) (aref s 1) nil t))
          (overlay-put overlay 'invisible 'sp-batch-report)
          (aset s 4 overlay))
      (when overlay
        (delete-overlay overlay)
        (aset s 4 nil)))
    (put-text-property (aref s 6) (1+ (aref s 6)) 'display (and folded "▶"))
    (set-buffer-modified-p nil)))

(defun sp-batch-report-toggle-section ()
  "Fold or unfold the section at point."
  (interactive)
  (if (derived-mode-p 'org-mode)
      (org-cycle)
    (let ((sec (get-text-property (point) 'sp-batch-report-section)))
      (unless sec (user-error "No section here"))
      (let ((folded (not (aref (aref sp-batch-report-view--sections sec) 4))))
        (sp-batch-report-view--fold sec folded)
        (when folded
          (goto-char (aref (aref sp-batch-report-view--sections sec) 5)))))))

(defun sp-batch-report-toggle-all ()
  "Fold every section, or unfold them all when every one is folded."
  (interactive)
  (if (derived-mode-p 'org-mode)
      (org-shifttab)
    (let* ((n (length sp-batch-report-view--sections))
           (fold (cl-some (lambda (s) (not (aref s 4))) sp-batch-report-view--sections)))
      (dotimes (i n) (sp-batch-report-view--fold i fold))
      (goto-char (point-min)))))
#+end_src

* Moving

- =n= and =p= go to the next and previous entry, not the next link; they skip rows that are folded away.
- The row is found with a binary search on the vector of rows, so moving costs the same in a long report.

#+begin_src emacs-lisp -i
(defun sp-batch-report-view--first-row-after (pos)
  "The index of the first row that starts after POS, or the number of rows."
  (let ((lo 0) (hi (length sp-batch-report-view--rows)))
    (while (< lo hi)
      (let ((mid (/ (+ lo hi) 2)))
        (if (> (car (aref sp-batch-report-view--rows mid)) pos)
            (setq hi mid)
          (setq lo (1+ mid)))))
    lo))

(defun sp-batch-report-view--goto-row (index step)
  "Go to the row INDEX or the next visible one in the direction of STEP."
  (let ((n (length sp-batch-report-view--rows)))
    (while (and (>= index 0) (< index n)
                (invisible-p (car (aref sp-batch-report-view--rows index))))
      (setq index (+ index step)))
    (when (and (>= index 0) (< index n))
      (goto-char (car (aref sp-batch-report-view--rows index)))
      t)))

(defun sp-batch-report-next ()
  "Go to the next entry."
  (interactive)
  (if (derived-mode-p 'org-mode)
      (org-next-link)
    (unless (sp-batch-report-view--goto-row (sp-batch-report-view--first-row-after (point)) 1)
      (user-error "No next entry"))))

(defun sp-batch-report-previous ()
  "Go to the previous entry."
  (interactive)
  (if (derived-mode-p 'org-mode)
      (org-previous-link)

* Dropping

- =d= and =u= change only the text properties of the rows with that key.
  - A dropped row gets the face =sp-batch-report-dropped= (shadow, struck through) and the property =sp-batch-report-dropped=.
  - The counts of the sections it is in are written again, in place.
  - The size of the buffer does not change, so no row position is stale.
- The report is not made again.
  - =d= used to call the function that made the report again, which for a long report took seconds and froze the buffer.
  - =sp-batch-report-excluded= is kept up to date, and =A= and =g= get it as before.
- After =d= the point goes to the next entry, so you can drop a run of them with =d d d=.
- =remove-face-text-property= only exists from Emacs 30; =sp-batch-report-view--remove-face= does the same without it.

#+begin_src emacs-lisp -i
(defun sp-batch-report-view--update-count (sec)
  "Write the count of the section SEC again, in place."
  (let* ((s (aref sp-batch-report-view--sections sec))
         (pos (aref s 7))
         (inhibit-read-only t)
         (inhibit-modification-hooks t))
    (save-excursion
      (goto-char pos)
      (delete-region pos (+ pos sp-batch-report-view--count-width))
      (insert (sp-batch-report-view--count-string (aref s 2) (aref s 3))))))

(defun sp-batch-report-view--remove-face (beg end face)
  "Take FACE out of the faces of the text between BEG and END.
`remove-face-text-property' only exists from Emacs 30."
  (let ((pos beg))
    (while (< pos end)
      (let ((next (min end (next-single-property-change pos 'face nil end)))
            (current (get-text-property pos 'face)))
        (when (and (consp current) (not (keywordp (car current))))
          (setq current (remq face current))
          (when (null (cdr current)) (setq current (car current))))
        (when (eq current face) (setq current nil))
        (put-text-property pos next 'face current)
        (setq pos next)))))

(defun sp-batch-report-view--mark (key dropped)
  "Style every row with the KEY as dropped, or as kept when DROPPED is nil.
Only text properties of those rows and the count of their sections change, so
the cost does not depend on the size of the report."
  (let ((inhibit-read-only t)
        (inhibit-modification-hooks t)
        touched)
    (dolist (index (gethash key sp-batch-report-view--by-key))
      (pcase-let ((`(,beg ,end ,sec) (aref sp-batch-report-view--rows index)))
        (unless (eq (and (get-text-property beg 'sp-batch-report-dropped) t) dropped)
          (if dropped
              (progn (put-text-property beg end 'sp-batch-report-dropped t)
                     (add-face-text-property beg end 'sp-batch-report-dropped))
            (remove-text-properties beg end '(sp-batch-report-dropped nil))
            (sp-batch-report-view--remove-face beg end 'sp-batch-report-dropped))
          (cl-incf (aref (aref sp-batch-report-view--sections sec) 2) (if dropped -1 1))
          (cl-incf sp-batch-report-view--dropped (if dropped 1 -1))
          (push sec touched))))
    (dolist (sec (delete-dups touched))
      (sp-batch-report-view--update-count sec))
    (set-buffer-modified-p nil)))
#+end_src

(defun sp-batch-report-visit ()

* Fitting tables to the window

- A table has fixed column widths: each column is as wide as its widest cell, at most =sp-batch-report-column-max-width= (40).
  - What does not fit is wrapped inside the cell, on the lines under it (=sp-batch-report-view--wrap=): at spaces, a long word is cut.
  - Links and faces of a cell stay on the wrapped text.
- When the columns together are wider than the window, the widest ones are narrowed first, down to =sp-batch-report-column-min-width= (8), so the row always fits and no line runs off the window.
- The width is counted in characters of the buffer's own text size (=window-body-width= in pixels over =window-font-width=), so zooming the text changes it too.
- The tables are laid out again by themselves, with nothing to press:
  - =window-size-change-functions= (frame resize, window split) and =window-configuration-change-hook= and =text-scale-mode-hook= (zoom) call =sp-batch-report-view--schedule=.
  - It waits for 0.2 s of idle time, so dragging a frame edge draws once, and does nothing when the width is the same or the report has no table.
- Drawing again keeps what you did:
  - the folded sections and the dropped entries (the dropped keys are copied into the model first)
  - the point (on the same row, same offset) and the top line of every window that shows the report

#+begin_src emacs-lisp -i
(defun sp-batch-report-view--relayout ()
  "Draw the report again for the width of its window; keep the folds, drops and point."
  (when (and sp-batch-report-view--model (derived-mode-p 'sp-batch-report-mode))
    (let* ((rows sp-batch-report-view--rows)
           (row-of (lambda (pos)
                     (when-let* ((index (get-text-property (min pos (point-max)) 'sp-batch-report-row)))
                       (cons index (- pos (car (aref rows index)))))))
           (point-row (funcall row-of (point)))
           (windows (mapcar (lambda (w) (cons w (funcall row-of (window-start w))))
                            (get-buffer-window-list (current-buffer) nil t)))
           (model (copy-sequence sp-batch-report-view--model)))
      (setq model (plist-put model :excluded sp-batch-report-excluded))
      (sp-batch-report-view--render model)
      (let ((place (lambda (row)
                     (when row
                       (let* ((range (aref sp-batch-report-view--rows (car row))))
                         (min (+ (car range) (cdr row)) (1- (nth 1 range))))))))
        (when-let* ((pos (funcall place point-row)))
          (goto-char pos))
        (dolist (entry windows)
          (when (window-live-p (car entry))
            (when-let* ((start (funcall place (cdr entry))))
              (set-window-start (car entry) start t))
            (set-window-point (car entry) (point))))))))

(defun sp-batch-report-view--schedule (&rest _)
  "Draw the tables of this report again, when the window width changed, once idle."
  (when (and sp-batch-report-view--has-tables
             (not sp-batch-report-view--timer)
             (not (eql sp-batch-report-view--width (sp-batch-report-view--window-width))))
    (let ((buffer (current-buffer)))
      (setq sp-batch-report-view--timer
            (run-with-idle-timer
             0.2 nil
             (lambda ()
               (when (buffer-live-p buffer)
                 (with-current-buffer buffer
                   (setq sp-batch-report-view--timer nil)
                   (unless (eql sp-batch-report-view--width (sp-batch-report-view--window-width))
                     (sp-batch-report-view--relayout))))))))))

(defun sp-batch-report-view--frame-resized (frame)
  "Schedule a new layout of the reports shown in FRAME."
  (dolist (window (window-list frame))
    (with-current-buffer (window-buffer window)
      (when (derived-mode-p 'sp-batch-report-mode)
        (sp-batch-report-view--schedule)))))

(add-hook 'window-size-change-functions #'sp-batch-report-view--frame-resized)

(ert-deftest sp-batch-report-view-wraps-at-spaces ()

                 '("one two" "three" "four")))
  (should (equal (sp-batch-report-view--wrap "short" 9) '("short")))

  ;; the text properties stay
  (let ((lines (sp-batch-report-view--wrap (propertize "aaa bbb ccc" 'face 'bold) 4)))

    (should (cl-every (lambda (l) (eq (get-text-property 0 'face l) 'bold)) lines))))

(ert-deftest sp-batch-report-view-column-widths-fit-the-window ()
  (let ((header '("Key" "Title" "File"))
        (cells '(("k" "a title that is rather long indeed" "file.bib")
                 ("kkkkkkkk" "short" "another-file.bib"))))
    (sp-batch-report-view-test--with-width 200
      (should (equal (sp-batch-report-view--column-widths header cells) '(8 34 16))))
    ;; a column is never wider than the maximum
    (sp-batch-report-view-test--with-width 200
      (let ((sp-batch-report-column-max-width 12))
        (should (equal (sp-batch-report-view--column-widths header cells) '(8 12 12)))))
    ;; in a narrow window the widest columns give way first, down to the minimum
    (sp-batch-report-view-test--with-width 40
      (let ((widths (sp-batch-report-view--column-widths header cells)))
        (should (<= (+ (apply #'+ widths) 2 4) 40))
        (should (cl-every (lambda (w) (>= w 3)) widths))
        (should (> (nth 1 widths) (nth 0 widths)))))
    (sp-batch-report-view-test--with-width 5
      (should (equal (sp-batch-report-view--column-widths header cells) '(3 5 4))))))

(ert-deftest sp-batch-report-view-schedules-a-layout-when-the-width-changes ()
  (let ((sp-batch-report-display 'special) scheduled)
    (unwind-protect
        (cl-letf (((symbol-function 'pop-to-buffer) #'ignore)
                  ((symbol-function 'run-with-idle-timer)
                   (lambda (_secs _repeat function &rest _) (push function scheduled) 'timer)))
          (with-current-buffer (sp-batch-report-view-test--table-report 80)
            ;; the same width: nothing to do
            (sp-batch-report-view-test--with-width 80 (sp-batch-report-view--schedule))
            (should-not scheduled)
            (sp-batch-report-view-test--with-width 50
              (sp-batch-report-view--schedule)
              (sp-batch-report-view--schedule)
              (should (= 1 (length scheduled)))
              (funcall (car scheduled)))
            (should (= 50 sp-batch-report-view--width))
            (should-not sp-batch-report-view--timer)
            ;; the frame hook and the buffer hooks are in place
            (should (memq 'sp-batch-report-view--frame-resized window-size-change-functions))
            (should (memq 'sp-batch-report-view--schedule window-configuration-change-hook))
            (should (memq 'sp-batch-report-view--schedule text-scale-mode-hook))))
      (when (get-buffer sp-batch-report-view-test--name)
        (kill-buffer sp-batch-report-view-test--name)))))
