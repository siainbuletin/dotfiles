This module provides two commands for tidying plain lists in Org buffers, aimed at lists of links such as reading or resource lists.

- =sp-org-lint-list=:
  - turns stray paragraph lines into list items,
  - removes blank lines between items,
  - drops items whose https link already appeared earlier.
- =sp-org-lint-resources= does the same, then sorts each top level list alphabetically by its displayed text.
- =sp-org-mark-list= is a helper that marks the region the commands would act on.

The heading splitter =sp-split-leave-parents= used to be a section of this document; it is now part of [[file:sp-refile.org][sp-refile]].

This document is also the home of the lint and tidy commands for authors and literature notes. Each is its own section and tangles to its own file, so the headless footnote worker below loads only =sp-org-lint-footnotes.el=:

Command names follow [[file:../../../../../../adr/0025-dryrun-and-convert-command-names.org][ADR 0025]]:

- =-dryrun= previews what would change and writes nothing.
- =-convert= applies the change, after the confirmation the command already asks for.

They used to have their own docs (=sp-author-notes.org=, =sp-author-notes-bibtex.org=) or sit in [[file:../academic/sp-academic.org][sp-academic.org]]; the code is unchanged, and =sp-litnotes= still requires the two litnote modules. A third command, =sp-org-lint-footnotes-dryrun=, is unrelated to lists: it lints the footnotes of the vulpea vault in the background, see [[*Sectional footnotes][Sectional footnotes]]. It also uses =seq=, =cl-lib= and, when present, =sp-globals=, and starts a second Emacs, so this file must be loadable on its own.

Dependencies and behaviour:

- Depends only on built-in libraries: =org=, =org-list=, =org-element= and =subr-x=.
- The commands work on the active region. With none, they use the list at or near point, falling back to the block of consecutive non-blank lines.
- All edits run inside one =atomic-change-group=, so a single undo reverts a whole lint pass.
- Loaded in the Functions block of =init.el=.
- No key bindings are set for the commands anywhere in the configuration, so run them with =M-x=.

** List item pattern

=sp-org--item-re= matches the start of a plain list item line: a dash or plus bullet, a number followed by a period or parenthesis, or an asterisk that is indented. Requiring indentation for the asterisk keeps headings from being treated as items.

#+begin_src emacs-lisp -i
(defconst sp-org--item-re
  "^\\(?:[ \t]+\\*\\|[ \t]*[-+]\\|[ \t]*[0-9]+[.)]\\)[ \t]"
  "Match the start of a plain list item line.
A bare `*' only counts when indented, so headings are not mistaken for items.")
#+end_src

** URL pattern

=sp-org--url-re= matches an https URL up to whitespace, brackets, angle brackets or a quote, so it stops cleanly at the end of an Org bracket link. Plain http links are deliberately ignored; the docstring explains how to widen it.

#+begin_src emacs-lisp -i
(defconst sp-org--url-re "https://[^] \t\n\r<>\"[]+"
  "Match an https:// URL.
Change `https://' to `https?://' to also treat http links as links.")
#+end_src

* Finding what to act on

These helpers decide which part of the buffer a command works on when no region is active.

** Item near point

=sp-org--item-near-point= returns the start of the list item at point.

- On a blank line, it looks at the nearest non-blank text above, then below. So running a command from a gap between items still finds the list.
- On any other non-list line, it returns nil.

#+begin_src emacs-lisp -i
;;;; Region detection

(defun sp-org--item-near-point ()
  "Return the start of the list item at or near point, or nil.
On a list line (item or continuation text) that is the item itself.
On a blank line, the nearest list above, then below, is used.
On any other line nil is returned."
  (save-excursion
    (beginning-of-line)
    (cond
     ((org-in-item-p))
     ((looking-at-p "[ \t]*$")
      (or (progn (skip-chars-backward " \t\n")
                 (and (not (bobp)) (org-in-item-p)))
          (progn (skip-chars-forward " \t\n")
                 (beginning-of-line)
                 (and (not (eobp)) (org-in-item-p))))))))
#+end_src

** Whole list bounds

=sp-org--list-bounds= expands from that item to the outermost list containing it, using Org's list structure, and returns its start and the end of its last non-blank line.

#+begin_src emacs-lisp -i
(defun sp-org--list-bounds ()
  "Return (BEG . END) of the whole plain list at or near point, or nil.
BEG is the start of the first item of the outermost list; END is the
end of the last non-blank line belonging to it."
  (let ((item (sp-org--item-near-point)))
    (when item
      (save-excursion
        (goto-char item)
        (let* ((struct (org-list-struct))
               (beg (org-list-get-top-point struct))
               (end (org-list-get-bottom-point struct)))
          (goto-char end)
          (skip-chars-backward " \t\n")
          (cons beg (point)))))))
#+end_src

** Text block bounds

=sp-org--block-bounds= is the fallback: the run of consecutive non-blank lines around point, delimited by blank lines or the buffer edges.

#+begin_src emacs-lisp -i
(defun sp-org--block-bounds ()
  "Return (BEG . END) of the consecutive non-blank lines around point, or nil."
  (save-excursion
    (beginning-of-line)
    (unless (looking-at-p "[ \t]*$")
      (let ((beg (save-excursion
                   (if (re-search-backward "^[ \t]*$" nil t)
                       (progn (forward-line 1) (point))
                     (point-min))))
            (end (save-excursion
                   (if (re-search-forward "^[ \t]*$" nil t)
                       (progn (forward-line -1) (line-end-position))
                     (point-max)))))
        (cons beg end)))))
#+end_src

** Automatic bounds

=sp-org--auto-bounds= checks that the buffer is in Org mode and returns the list bounds, else the block bounds, else signals a user error.

#+begin_src emacs-lisp -i
(defun sp-org--auto-bounds ()
  "Return (BEG . END) of the list at point, else of the text block at point."
  (unless (derived-mode-p 'org-mode)
    (user-error "Not in an org-mode buffer"))
  (or (sp-org--list-bounds)
      (sp-org--block-bounds)
      (user-error "No list or text block found at point")))
#+end_src

* Step 1: plain lines into items

** Which lines are convertible

=sp-org--convertible-line-p= accepts a line only if it is non-blank, not already part of a list item, and parsed by =org-element= as a paragraph. Headings, keywords, drawers, tables, blocks and continuation lines of items are left alone.

#+begin_src emacs-lisp -i
;;;; Step 1: turn plain lines into items

(defun sp-org--convertible-line-p ()
  "Non-nil if the line at point is plain paragraph text outside any list.
Blank lines, headings, keywords, drawers, tables, blocks and text
belonging to a list item (including indented continuation lines)
are not convertible."
  (and (not (looking-at-p "[ \t]*$"))
       (not (org-in-item-p))
       (eq (org-element-type (org-element-at-point)) 'paragraph)))
#+end_src

** Converting lines

=sp-org--convert-lines-to-items= walks the target line by line and calls =org-toggle-item= on each convertible line, returning how many it changed.

- =mark-active= is bound to nil around the call, so =org-toggle-item= acts on the single line rather than on the whole region.
- A marker for the next line keeps the walk correct as text is inserted.

#+begin_src emacs-lisp -i
(defun sp-org--convert-lines-to-items (beg end-marker)
  "Run `org-toggle-item' on each plain line between BEG and END-MARKER.
Return the number of lines converted."
  (let ((count 0))
    (save-excursion
      (goto-char beg)
      (while (< (point) end-marker)
        (let ((next (copy-marker (line-beginning-position 2))))
          (when (sp-org--convertible-line-p)
            ;; Hide the region so `org-toggle-item' only handles this line.
            (let ((mark-active nil))
              (org-toggle-item nil))
            (setq count (1+ count)))
          (goto-char next)
          (set-marker next nil))))
    count))
#+end_src

* Step 2: blank lines between items

** Removing blank lines

=sp-org--remove-blank-lines-between-items= finds runs of blank lines and collapses them to a single newline only when the next line starts an item and the previous line belongs to a list (an item or an indented continuation). Blank lines that separate a list from ordinary text are kept.

#+begin_src emacs-lisp -i
;;;; Step 2: remove blank lines between items

(defun sp-org--remove-blank-lines-between-items (beg end-marker)
  "Delete blank lines between list items from BEG to END-MARKER."
  (save-excursion
    (goto-char beg)
    (while (re-search-forward "\n\\(?:[ \t]*\n\\)+" end-marker t)
      (let ((blank-beg (match-beginning 0))
            (blank-end (match-end 0)))
        (when (and
               ;; the next non-blank line starts a list item...
               (save-excursion
                 (goto-char blank-end)
                 (looking-at-p sp-org--item-re))
               ;; ...and the previous line belongs to a list
               ;; (an item itself, or an indented continuation line).
               (save-excursion
                 (goto-char blank-beg)
                 (beginning-of-line)
                 (or (looking-at-p sp-org--item-re)
                     (looking-at-p "[ \t]+[^ \t\n]"))))
          (replace-match "\n"))))))
#+end_src

* Step 3: duplicate links

** Normalising URLs

=sp-org--normalize-url= makes URLs comparable: it strips trailing punctuation, an unmatched closing parenthesis and trailing slashes, and lower-cases the scheme and host while keeping the path's case.

#+begin_src emacs-lisp -i
;;;; Step 3: remove duplicate links

(defun sp-org--normalize-url (url)
  "Return URL in a canonical form for comparison.
Trailing punctuation, an unbalanced closing parenthesis and trailing
slashes are dropped, and the host is lower-cased."
  (setq url (replace-regexp-in-string "[.,;:!?]+\\'" "" url))
  (when (and (string-suffix-p ")" url) (not (string-match-p "(" url)))
    (setq url (substring url 0 -1)))
  (setq url (replace-regexp-in-string "/+\\'" "" url))
  (if (string-match "\\`\\(https://[^/?#]*\\)" url)
      (concat (downcase (match-string 1 url)) (substring url (match-end 1)))
    url))
#+end_src

** The URL of one item

=sp-org--item-url= returns the normalised first https URL in an item's own text. It stops at the first nested item line so a link in a child item is not attributed to its parent.

#+begin_src emacs-lisp -i
(defun sp-org--item-url (item-beg item-end)
  "Return the normalized https:// URL of the item from ITEM-BEG to ITEM-END.
ITEM-END is the end of the item's last line.  Only the item's own
text is searched, not its nested items.  Return nil if the item has
no such link."
  (save-excursion
    (goto-char item-beg)
    (end-of-line)
    (let ((own-end (save-excursion
                     ;; A nested item line, if any, ends the item's own text.
                     (if (re-search-forward sp-org--item-re item-end t)
                         (line-beginning-position)
                       item-end))))
      (goto-char item-beg)
      (when (re-search-forward sp-org--url-re own-end t)
        (sp-org--normalize-url (match-string 0))))))
#+end_src

** Removing duplicate items

=sp-org--remove-duplicate-links= scans items in order, remembering each URL in a hash table.

- A later item with an already seen URL is deleted, lines and all.
- The exception: if it has nested children, it is kept and counted so the user can deal with it.
- Items without links are never removed.
- It returns the counts of removed and kept duplicates.

#+begin_src emacs-lisp -i
(defun sp-org--remove-duplicate-links (beg end-marker)
  "Remove list items whose https:// link already appeared earlier.
The first occurrence is kept.  Items without a link are never removed,
and neither are duplicates that have nested items.
Return (REMOVED . KEPT-BECAUSE-NESTED)."
  (let ((seen (make-hash-table :test #'equal))
        (removed 0)
        (kept 0))
    (save-excursion
      (goto-char beg)
      (while (and (< (point) end-marker)
                  (re-search-forward sp-org--item-re end-marker t))
        (beginning-of-line)
        (if (not (org-in-item-p))
            (end-of-line)
          (let* ((pos (point))
                 (struct (org-list-struct))
                 ;; End of the item's last line, before any trailing blank lines.
                 (item-end (org-list-get-item-end-before-blank pos struct))
                 (url (sp-org--item-url pos item-end)))
            (cond
             ((or (null url) (not (gethash url seen)))
              (when url (puthash url t seen))
              (end-of-line))
             ((org-list-has-child-p pos struct)
              (setq kept (1+ kept))
              (end-of-line))
             (t
              ;; Delete the whole line(s), including the final newline.
              (delete-region pos (min (1+ item-end) (point-max)))
              (setq removed (1+ removed))))))))
    (cons removed kept)))
#+end_src

* Step 4: sorting

** Sort key

=sp-org--sort-key= produces the text an item is sorted by: the first line without its bullet or checkbox, with links replaced by their descriptions via =org-link-display-format=, trimmed and lower-cased.

#+begin_src emacs-lisp -i
;;;; Step 4: sort

(defun sp-org--sort-key ()
  "Sort key for the list item at point.
This is the item text as displayed (links replaced by their
description, or their target when they have none), lower-cased."
  (let* ((line (buffer-substring-no-properties
                (line-beginning-position) (line-end-position)))
         (text (replace-regexp-in-string
                "\\`[ \t]*\\(?:[-+*]\\|[0-9]+[.)]\\)[ \t]+\\(?:\\[[- X]\\][ \t]+\\)?"
                "" line)))
    (downcase (string-trim (org-link-display-format text)))))
#+end_src

** Sorting each list

=sp-org--sort-lists= finds each top level list in the target and runs =org-sort-list= with that key function and =string<=.

- A marker at the list's bottom lets the loop continue after sorting.
- Nested sublists move with their parent but are not sorted themselves.

#+begin_src emacs-lisp -i
(defun sp-org--sort-lists (beg end-marker)
  "Sort each top-level list between BEG and END-MARKER alphabetically."
  (save-excursion
    (goto-char beg)
    (while (and (< (point) end-marker)
                (re-search-forward sp-org--item-re end-marker t))
      (beginning-of-line)
      (if (not (org-in-item-p))
          (end-of-line)
        (let ((bottom (copy-marker
                       (org-list-get-bottom-point (org-list-struct)))))
          (org-sort-list nil ?f #'sp-org--sort-key #'string<)
          (goto-char bottom)
          (set-marker bottom nil))))))
#+end_src

** The lint pipeline

=sp-org--lint= runs the steps in order:

1. convert lines,
2. remove blank lines,
3. remove duplicates,
4. optionally sort.

Details:

- Markers track the start and end of the target as it changes.
- The whole pass is wrapped in =atomic-change-group=, so an error rolls everything back and undo treats it as one change.
- It finishes with a summary message: the number of lines converted and duplicates removed, plus any duplicates kept because they had children.

#+begin_src emacs-lisp -i
(defun sp-org--lint (beg end sort)
  "Lint the lines from BEG to END; also sort the lists when SORT is non-nil."
  (sp-org--check-region beg end)
  (let ((beg-marker (copy-marker (save-excursion
                                   (goto-char beg)
                                   (line-beginning-position))))
        (end-marker (copy-marker end))
        (converted 0)
        (dupes '(0 . 0)))
    (unwind-protect
        (atomic-change-group
          (setq converted (sp-org--convert-lines-to-items beg-marker end-marker))
          (sp-org--remove-blank-lines-between-items beg-marker end-marker)
          (setq dupes (sp-org--remove-duplicate-links beg-marker end-marker))
          (when sort
            (sp-org--sort-lists beg-marker end-marker)))
      (set-marker beg-marker nil)
      (set-marker end-marker nil))
    (message "sp-org-lint: %d line(s) converted to items, %d duplicate link(s) removed%s"
             converted (car dupes)
             (if (> (cdr dupes) 0)
                 (format " (%d duplicate(s) with nested items kept)" (cdr dupes))
               ""))))
#+end_src

* Sectional footnotes
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/funct/sp-org-lint-footnotes.el
:END:

A second feature of the module lints the footnotes of the whole vault.

- With =org-footnote-section= set to nil (see =sp-org-base=) and the per-heading footnotes of =sp-split-leave-parents=, a footnote definition lives at the end of the text of the heading that cites it.
- Notes written with Org's default behaviour have a =Footnotes= heading at the end instead.
- =sp-org-lint-footnotes-dryrun= finds those and moves each definition to the heading that contains its reference.

*Nothing is written without a preview, and nothing blocks Emacs.* The command lists the Org files of the vulpea database, hands them to a second, headless Emacs that reads them one at a time, and shows what it finds in a report buffer while it works. Applying the changes is a separate key in that buffer; it runs in the headless Emacs too, after copying every file to a backup folder.

** File header

This section tangles to =sp-org-lint-footnotes.el=, so the headless worker can load it alone. It needs =seq=, =cl-lib= and, when present, =sp-globals= for the notes folder.

** What moves where

- A section is the text of a heading from the heading to the next heading of any level, children excluded. This is the same meaning as in =sp-split-leave-parents= (=sp-split--fn-section=), so a note that was linted and one that was split look alike.
- A definition in a =Footnotes= heading moves to the end of the section of its reference. When it is cited from several sections, every section gets a copy; the first keeps the label and the others get a suffixed label (=smith-2=, =smith-3=), with the references in those sections renamed, as the split does (=sp-split--fn-fresh=). Org labels are unique per file.
- A =Footnotes= heading left with nothing but whitespace, and with no children, is removed (=sp-org-lint-fn-remove-empty-section=). If it holds anything else, such as a property drawer, it stays.
- Orphan definitions (never cited) and dangling references (cited, defined nowhere) are reported and never deleted. A definition that cannot be placed safely stays where it is and is listed as a conflict: its label is defined more than once, it is cited from the =Footnotes= heading itself, or it is cited only from another footnote.
- Inline footnotes (=[fn:label:text]=) and anonymous ones are already in place and are never moved.
- Before a file is written, the new text is re-read and checked: the number of references is unchanged, the dangling references are the same, and the number of definitions is the old number plus the copies. A file that fails the check is reported and left alone.

** Scanning a buffer

=sp-org-lint-fn--scan= parses the buffer once and returns the headings (with where their own text ends), the standard references and the definitions. The functions after it answer which section a position is in, where that section ends and whether it is a footnotes heading.

#+begin_src emacs-lisp -i
(defun sp-org-lint-fn--scan ()
  "Scan the current Org buffer for headings and footnotes.
Return (HEADS REFS DEFS).  HEADS lists plists (:begin :title :end
:own-end) sorted by position: :end is the end of the subtree and
:own-end the start of the next heading of any level.  REFS lists
\(LABEL BEGIN) for the standard references `[fn:LABEL]'.  DEFS lists
plists (:label :begin :end :text :inline); a labelled inline
footnote counts as a definition that is already in place."
  (let ((tree (org-element-parse-buffer))
        heads refs defs)
    (org-element-map tree 'headline
      (lambda (h)
        (push (list :begin (org-element-property :begin h)
                    :title (org-element-property :raw-value h)
                    :end (org-element-property :end h)
                    :own-end nil)
              heads)))
    (setq heads (sort heads (lambda (a b)
                              (< (plist-get a :begin) (plist-get b :begin)))))
    (let ((tail heads))
      (while tail
        (plist-put (car tail) :own-end
                   (if (cdr tail) (plist-get (cadr tail) :begin) (point-max)))
        (setq tail (cdr tail))))
    (org-element-map tree '(footnote-reference footnote-definition)
      (lambda (el)
        (let ((label (org-element-property :label el))
              (begin (org-element-property :begin el))
              (end (org-element-property :end el)))
          (when label
            (cond
             ((eq (org-element-type el) 'footnote-definition)
              (push (list :label label :begin begin :end end
                          :text (string-trim-right
                                 (buffer-substring-no-properties begin end)))
                    defs))
             ((eq (org-element-property :type el) 'inline)
              (let ((cb (org-element-property :contents-begin el))
                    (ce (org-element-property :contents-end el)))
                (when (and cb ce)
                  (push (list :label label :begin begin :end end :inline t
                              :text (format "[fn:%s] %s" label
                                            (string-trim
                                             (buffer-substring-no-properties
                                              cb ce))))
                        defs))))
             (t (push (list label begin) refs)))))))
    (list heads (nreverse refs) (nreverse defs))))

(defun sp-org-lint-fn--section (pos heads)
  "Return the start of the section containing POS, given sorted HEADS.
Text before the first heading is section 0."
  (let ((sec 0))
    (dolist (h heads sec)
      (when (<= (plist-get h :begin) pos)
        (setq sec (plist-get h :begin))))))

(defun sp-org-lint-fn--head (sec heads)
  "Return the heading plist of section SEC, or nil for section 0."
  (seq-find (lambda (h) (= (plist-get h :begin) sec)) heads))

(defun sp-org-lint-fn--section-end (sec heads)
  "Return the end of section SEC: the next heading, or the end of buffer."
  (if (zerop sec)
      (if heads (plist-get (car heads) :begin) (point-max))
    (plist-get (sp-org-lint-fn--head sec heads) :own-end)))

(defun sp-org-lint-fn--section-title (sec heads)
  "Return a title for section SEC."
  (if (zerop sec)
      "(before the first heading)"
    (string-trim (plist-get (sp-org-lint-fn--head sec heads) :title))))

(defun sp-org-lint-fn--footnotes-section-p (sec heads)
  "Non-nil when section SEC is a heading titled `sp-org-lint-fn-section-title'."
  (when-let* ((h (sp-org-lint-fn--head sec heads)))
    (string= (downcase (string-trim (plist-get h :title)))
             (downcase sp-org-lint-fn-section-title))))

** Planning the moves

=sp-org-lint-fn--plan= decides everything and changes nothing.

- For each definition in a footnotes section, it finds the sections that cite it.
- It returns:
  - the moves for the report,
  - the orphans, dangling labels and conflicts,
  - the edits to apply: (POSITION LENGTH STRING) replacements, positioned against the buffer as it is now, plus the definitions to add at the end of each section.

A footnotes heading is removed when what remains of its text, once the moved definitions are taken out, is blank and it has no children. The removal replaces the deletions of its definitions.

#+begin_src emacs-lisp -i
(defun sp-org-lint-fn--only-deleted-p (head deletions)
  "Non-nil when HEAD's own text is blank once DELETIONS are taken out."
  (let ((pos (save-excursion
               (goto-char (plist-get head :begin))
               (line-end-position)))
        (rest ""))
    (dolist (e (sort (copy-sequence deletions)
                     (lambda (x y) (< (car x) (car y)))))
      (setq rest (concat rest (buffer-substring-no-properties pos (car e)))
            pos (+ (car e) (cadr e))))
    (string-blank-p
     (concat rest (buffer-substring-no-properties pos (plist-get head :own-end))))))

(defun sp-org-lint-fn--plan ()
  "Plan the footnote moves in the current Org buffer; change nothing.
Return a plist: :moves, :orphans, :dangling, :conflicts, :removed (titles
of footnotes headings to remove), and for `sp-org-lint-fn--apply-edits'
:heads, :adds and :edits, with :n-defs, :n-refs and :n-deleted for the
check afterwards."
  (let* ((scan (sp-org-lint-fn--scan))
         (heads (nth 0 scan))
         (refs (nth 1 scan))
         (defs (nth 2 scan))
         (fn-defs (seq-filter
                   (lambda (d)
                     (and (not (plist-get d :inline))
                          (sp-org-lint-fn--footnotes-section-p
                           (sp-org-lint-fn--section (plist-get d :begin)
                                                    heads)
                           heads)))
                   defs))
         (nested-p (lambda (r)
                     (seq-some (lambda (d)
                                 (and (>= (cadr r) (plist-get d :begin))
                                      (< (cadr r) (plist-get d :end))))
                               fn-defs)))
         (cited (seq-remove nested-p refs))
         (def-labels (mapcar (lambda (d) (plist-get d :label)) defs))
         (ref-labels (mapcar #'car refs))
         (used (seq-uniq (append def-labels ref-labels)))
         moves conflicts edits adds removed)
    (dolist (d fn-defs)
      (let* ((label (plist-get d :label))
             (mine (seq-filter (lambda (r) (equal (car r) label)) cited))
             (secs (seq-uniq (mapcar (lambda (r)
                                       (sp-org-lint-fn--section (cadr r) heads))
                                     mine)))
             (from (sp-org-lint-fn--section-title
                    (sp-org-lint-fn--section (plist-get d :begin) heads) heads))
             (line (line-number-at-pos (plist-get d :begin))))
        (cond
         ((> (seq-count (lambda (l) (equal l label)) def-labels) 1)
          (push (cons label "defined more than once") conflicts))
         ((null mine)
          (when (member label (mapcar #'car (seq-filter nested-p refs)))
            (push (cons label "cited only from another footnote") conflicts)))
         ((seq-some (lambda (s) (sp-org-lint-fn--footnotes-section-p s heads))
                    secs)
          (push (cons label "cited from the footnotes section itself")
                conflicts))
         (t
          (let ((first t))
            (dolist (sec secs)
              (let ((new (if first label (sp-org-lint-fn--fresh label used))))
                (push new used)
                (unless (equal new label)
                  (dolist (r (seq-filter
                              (lambda (r)
                                (eql (sp-org-lint-fn--section (cadr r) heads)
                                     sec))
                              mine))
                    ;; Skip `[fn:' to reach the label itself.
                    (push (list (+ (cadr r) 4) (length label) new) edits)))
                (push (sp-org-lint-fn--def-with-label (plist-get d :text) new)
                      (alist-get sec adds nil nil #'eql))
                (push (list :label label :new new :from from
                            :to (sp-org-lint-fn--section-title sec heads)
                            :line line)
                      moves)
                (setq first nil))))
          (push (list (plist-get d :begin)
                      (- (plist-get d :end) (plist-get d :begin))
                      "")
                edits)))))
    (let ((n-deleted (seq-count (lambda (e) (equal (nth 2 e) "")) edits)))
      (when sp-org-lint-fn-remove-empty-section
        (dolist (h heads)
          (let* ((b (plist-get h :begin))
                 (own-end (plist-get h :own-end))
                 (dels (seq-filter (lambda (e)
                                     (and (equal (nth 2 e) "")
                                          (> (car e) b)
                                          (<= (+ (car e) (cadr e)) own-end)))
                                   edits)))
            (when (and dels
                       (>= own-end (plist-get h :end))
                       (sp-org-lint-fn--only-deleted-p h dels))
              (setq edits (cons (list b (- (plist-get h :end) b) "")
                                (seq-difference edits dels))
                    removed (cons (list (string-trim (plist-get h :title))
                                        (= (plist-get h :end) (point-max)))
                                  removed))))))
      (list :moves (nreverse moves)
            :orphans (seq-uniq
                      (mapcar (lambda (d) (plist-get d :label))
                              (seq-filter
                               (lambda (d)
                                 (and (not (plist-get d :inline))
                                      (not (member (plist-get d :label)
                                                   ref-labels))))
                               defs)))
            :dangling (seq-uniq (seq-remove (lambda (l) (member l def-labels))
                                            ref-labels))
            :conflicts (nreverse conflicts)
            :removed removed
            :heads heads :adds adds :edits edits
            :n-defs (length defs) :n-refs (length refs)
            :n-deleted n-deleted))))
#+end_src

** Applying the edits to a buffer

This is the edit step of =sp-split--fn-apply=.

- Definitions are added at the end of their section, with a blank line before and after.
- Everything is applied from the end of the buffer, so earlier positions stay valid.
- When a deletion and an insertion start at the same place (a section ending where a removed heading starts), the deletion goes first. Otherwise the insertion would be deleted.

#+begin_src emacs-lisp -i
(defun sp-org-lint-fn--apply-edits (heads adds edits)
  "Apply footnote changes to the current buffer.
ADDS maps a section to the definition texts to put at the end of it
\(newest first).  EDITS is a list of (POS LENGTH STRING) replacements.
Everything is positioned against the buffer as it is now."
  (dolist (a adds)
    (let* ((pos (sp-org-lint-fn--section-end (car a) heads))
           (prefix (cond ((= pos (point-min)) "")
                         ((and (>= (- pos (point-min)) 2)
                               (string= (buffer-substring-no-properties
                                         (- pos 2) pos)
                                        "\n\n"))
                          "")
                         ((save-excursion (goto-char pos) (bolp)) "\n")
                         (t "\n\n")))
           (suffix (if (= pos (point-max)) "\n" "\n\n")))
      (push (list pos 0 (concat prefix
                                (mapconcat #'identity (reverse (cdr a)) "\n\n")
                                suffix))
            edits)))
  (dolist (e (sort edits (lambda (x y)
                           (or (> (car x) (car y))
                               (and (= (car x) (car y)) (> (cadr x) (cadr y)))))))
    (goto-char (car e))
    (delete-region (car e) (+ (car e) (cadr e)))
    (insert (nth 2 e))))
#+end_src

** Planning a text

=sp-org-lint-fn-plan-text= is the pure entry point: text in, plist out, nothing read or written.

- It plans, applies the edits to a copy in a temp buffer and checks the result as described above.
- =:text= is the new text and =:changed= says whether it differs.
- This is what the tests and the headless Emacs use.

#+begin_src emacs-lisp -i
(defun sp-org-lint-fn--counts (text)
  "Return (N-DEFS N-REFS DANGLING) for the footnotes in TEXT."
  (with-temp-buffer
    (delay-mode-hooks (org-mode))
    (insert text)
    (pcase-let* ((`(,_ ,refs ,defs) (sp-org-lint-fn--scan))
                 (def-labels (mapcar (lambda (d) (plist-get d :label)) defs)))
      (list (length defs) (length refs)
            (sort (seq-uniq (seq-remove (lambda (l) (member l def-labels))
                                        (mapcar #'car refs)))
                  #'string<)))))

(defun sp-org-lint-fn-plan-text (text)
  "Plan the footnote moves for the Org TEXT.
Return a plist: :moves, :orphans, :dangling, :conflicts, :removed, and
when something moves :changed t and :text, the new text.  A text whose
result fails the check gets :error instead."
  (with-temp-buffer
    (delay-mode-hooks (org-mode))
    (insert text)
    (let* ((plan (sp-org-lint-fn--plan))
           (result (list :moves (plist-get plan :moves)
                         :orphans (plist-get plan :orphans)
                         :dangling (plist-get plan :dangling)
                         :conflicts (plist-get plan :conflicts)
                         :removed (mapcar #'car (plist-get plan :removed)))))
      (if (null (plist-get plan :moves))
          result
        (sp-org-lint-fn--apply-edits (plist-get plan :heads)
                                     (plist-get plan :adds)
                                     (plist-get plan :edits))
        ;; A footnotes heading removed from the end of the file would
        ;; leave blank lines behind.
        (when (seq-some #'cadr (plist-get plan :removed))
          (goto-char (point-max))
          (skip-chars-backward " \t\n")
          (delete-region (point) (point-max))
          (insert "\n"))
        (let* ((new (buffer-string))
               (after (sp-org-lint-fn--counts new))
               (want-defs (+ (plist-get plan :n-defs)
                             (length (plist-get plan :moves))
                             (- (plist-get plan :n-deleted)))))
          (if (and (= (nth 0 after) want-defs)
                   (= (nth 1 after) (plist-get plan :n-refs))
                   (equal (nth 2 after) (sort (copy-sequence
                                               (plist-get plan :dangling))
                                              #'string<)))
              (append result (list :changed t :text new))
            (append result
                    (list :error "the result failed the footnote check; file left alone"))))))))
#+end_src

** Reading and writing files

File safety:

- Files are read as UTF-8 and written back as UTF-8.
- A file with carriage returns is refused rather than rewritten.
- The text of a file is identified by its SHA-1. The preview records it and the apply step compares it, so a file edited after the preview is skipped.
- The backup is a copy under =sp-org-lint-fn-backup-directory= (=org-lint-backups/= in =sp-var-dir=, which Git ignores). If it cannot be made, the file is not written.
- The new text goes to a temporary file in the same folder and is renamed over the original.

Another Emacs (the one you work in) may have the same files open, so the apply step is careful in these ways:

- The scan never writes. Only the apply step does, and only to files whose text still has the SHA-1 of the preview.
- Files that the main Emacs has open with unsaved changes are left out before the worker starts; the worker also skips any file with an Emacs lock file (=.#name=), which Emacs creates as soon as a buffer is modified, so edits started after the apply began are covered too.
- The SHA-1 is checked twice: when the file is read, and again just before the write, after the backup. Whatever happens in the milliseconds between that check and the rename cannot be excluded, but the pre-change copy is in the backup folder, and Emacs itself asks before saving a buffer whose file changed on disk.
- A file that is a symbolic link is written through the link (the link stays), and its target is what is backed up. A file that is not valid UTF-8, or has carriage returns, is never rewritten.
- The worker is =emacs -Q=, so it loads the Org that ships with Emacs, not the one Elpaca installed. The check after planning (references, dangling labels, number of definitions) is there so that a difference in parsing cannot change a file silently.
- Buffers visiting a written file, and without unsaved changes, are reverted afterwards, so a later save cannot write the old text back.

#+begin_src emacs-lisp -i
(defun sp-org-lint-fn--read (file)
  "Return the text of FILE, read as UTF-8.
Signal an error for a file that is not clean UTF-8 or has carriage returns,
since writing it back could change it."
  (with-temp-buffer
    (let ((coding-system-for-read 'utf-8))
      (insert-file-contents file))
    (when (search-forward "\r" nil t)
      (error "carriage returns in the file; not touched"))
    (when (memq 'eight-bit (find-charset-region (point-min) (point-max)))
      (error "the file is not valid UTF-8; not touched"))
    (buffer-string)))

(defun sp-org-lint-fn-plan-file (file)
  "Plan FILE: the plist of `sp-org-lint-fn-plan-text' with :file and :sha."
  (condition-case err
      (let ((text (sp-org-lint-fn--read file)))
        (append (list :file file :sha (secure-hash 'sha1 text))
                (sp-org-lint-fn-plan-text text)))
    (error (list :file file :error (error-message-string err)))))

(defun sp-org-lint-fn--backup (file root)
  "Copy FILE below the folder ROOT, keeping its path.  Return the copy."
  (let* ((file (file-truename file))
         (dest (expand-file-name
               (replace-regexp-in-string "\\`\\(?:[A-Za-z]:\\)?[/\\\\]*" ""
                                         file)
               root)))
    (make-directory (file-name-directory dest) t)
    (copy-file file dest t t)
    (unless (= (file-attribute-size (file-attributes file))
               (file-attribute-size (file-attributes dest)))
      (error "backup of the file is incomplete"))
    dest))

(defun sp-org-lint-fn--write (file text)
  "Replace the contents of FILE with TEXT, through a temporary file.
When FILE is a symbolic link the file it points to is replaced, so the link
stays a link."
  (let* ((file (file-truename file))
         (tmp (make-temp-file (concat file ".sp-lint-")))
         (modes (file-modes file)))
    (condition-case err
        (progn
          (let ((coding-system-for-write 'utf-8-unix))
            (write-region text nil tmp nil 'silent))
          (when modes (set-file-modes tmp modes))
          (rename-file tmp file t))
      (error (ignore-errors (delete-file tmp))
             (signal (car err) (cdr err))))))

(defun sp-org-lint-fn-apply-file (file sha backup-root)
  "Apply the plan to FILE if its text still has the SHA-1 SHA.
The file is copied below BACKUP-ROOT first.  Return a plist with :file
and :status, `written' (with :backup and :moves) or `skipped' (with
:reason)."
  (condition-case err
      (let ((text (sp-org-lint-fn--read file)))
        (if (not (equal (secure-hash 'sha1 text) sha))
            (list :file file :status 'skipped
                  :reason "changed since the preview")
          (let ((plan (sp-org-lint-fn-plan-text text)))
            (cond
             ((plist-get plan :error)
              (list :file file :status 'skipped :reason (plist-get plan :error)))
             ((not (plist-get plan :changed))
              (list :file file :status 'skipped :reason "nothing to move"))
             (t
              (let ((backup (sp-org-lint-fn--backup file backup-root)))
                ;; The last look, just before the write: it leaves a gap
                ;; of milliseconds for someone else to save the file.
                (cond
                 ((file-locked-p file)
                  (list :file file :status 'skipped
                        :reason "open with unsaved changes in another Emacs"))
                 ((not (equal (secure-hash 'sha1 (sp-org-lint-fn--read file))
                              sha))
                  (list :file file :status 'skipped
                        :reason "changed while it was being linted"))
                 (t
                  (sp-org-lint-fn--write file (plist-get plan :text))
                  (list :file file :status 'written :backup backup
                        :moves (length (plist-get plan :moves)))))))))))
    (error (list :file file :status 'skipped
                 :reason (error-message-string err)))))
#+end_src

** The headless worker

The headless worker:

- The main Emacs starts =emacs -Q --batch -l sp-org-lint-footnotes.el --eval (sp-org-lint-fn--batch CONTROL-FILE)=.
- The control file holds a plist with =:mode= (=plan= or =apply=) and =:files=.
- For =apply=, the files are (FILE . SHA) pairs and =:backup-root= is set.
- The worker prints one line per file, prefixed with =SPLINT = and written with every non-ASCII character escaped, so the output is the same in any locale.
- A last line =(:done t)= ends the output.
- The plan lines do not carry the new text.

#+begin_src emacs-lisp -i
(defvar sp-org-lint--library (or load-file-name (locate-library "sp-org-lint-footnotes"))
  "File this library was loaded from; the headless Emacs loads the same one.")

(defun sp-org-lint-fn--emit (object)
  "Print OBJECT as one line for the main Emacs to read."
  (let ((print-length nil) (print-level nil)
        (print-escape-newlines t) (print-escape-multibyte t)
        (print-escape-nonascii t))
    (princ (concat "SPLINT " (prin1-to-string object) "\n"))))

(defun sp-org-lint-fn--batch (control-file)
  "Run the job described in CONTROL-FILE and print one result per file."
  (let* ((ctl (with-temp-buffer
                (insert-file-contents control-file)
                (read (current-buffer))))
         (files (plist-get ctl :files)))
    (if (eq (plist-get ctl :mode) 'apply)
        (dolist (f files)
          (sp-org-lint-fn--emit
           (sp-org-lint-fn-apply-file (car f) (cdr f)
                                      (plist-get ctl :backup-root))))
      (dolist (f files)
        (let ((plan (sp-org-lint-fn-plan-file f)))
          (sp-org-lint-fn--emit (if (plist-get plan :changed)
                                    (plist-put plan :text nil)
                                  plan)))))
    (sp-org-lint-fn--emit '(:done t))))
#+end_src

** Finding the files

Which files are linted:

- The paths of the notes in the vulpea database (a note is a file or a heading with an ID, so the paths are de-duplicated).
- If vulpea is not loaded, or the query fails, the Org files under =sp-org-lint-fn-directory= are used.
- Only existing =.org= files that do not match the exclude regexp are kept.

(defun sp-org-lint-fn--org-files (candidates root)
  "Return the existing Org files in CANDIDATES, sorted, minus the excluded ones.
Paths inside ROOT are matched against `sp-org-lint-fn-exclude-regexp'
relative to it."
  (let ((root (file-name-as-directory (expand-file-name root))))
    (sort
     (seq-uniq
      (seq-filter
       (lambda (f)
         (and (string-suffix-p ".org" f)
              (file-regular-p f)
              (not (string-match-p
                    sp-org-lint-fn-exclude-regexp
                    (if (string-prefix-p root f) (substring f (length root)) f)))))
       (mapcar #'expand-file-name candidates)))
     #'string<)))

                 (ignore-errors (mapcar #'vulpea-note-path (vulpea-db-query))))))
    (sp-org-lint-fn--org-files

         (directory-files-recursively sp-org-lint-fn-directory "\\.org\\'"))

** The report buffer

All the state of a run is kept in a buffer-local plist in the report buffer: the process, the mode (=scan= or =apply=), the files and how many are done, the plans, and the apply results. Each line about a change carries the file and line as text properties, so =RET= visits it.

        (line (get-text-property (line-beginning-position) 'sp-line)))

(defun sp-org-lint-fn--insert-plan (plan)
  "Insert the report of PLAN at the end of the buffer."
  (let ((file (plist-get plan :file))
        (inhibit-read-only t))
    (save-excursion
      (goto-char (point-max))
      (cl-flet ((line (line text)
                  (insert (propertize (concat "  " text "\n")
                                      'sp-file file 'sp-line line))))
        (insert (propertize (format "* %s\n" (abbreviate-file-name file))
                            'sp-file file 'sp-line 1 'face 'bold))
        (when-let* ((err (plist-get plan :error)))
          (line 1 (format "error: %s" err)))
        (dolist (m (plist-get plan :moves))
          (line (plist-get m :line)

                        (plist-get m :label) (plist-get m :from) (plist-get m :to)
                        (if (equal (plist-get m :new) (plist-get m :label))
                            ""

        (dolist (l (plist-get plan :orphans))
          (line 1 (format "orphan: [fn:%s] is defined and never cited" l)))
        (dolist (l (plist-get plan :dangling))
          (line 1 (format "dangling: [fn:%s] is cited and never defined" l)))
        (dolist (c (plist-get plan :conflicts))
          (line 1 (format "left alone: [fn:%s] is %s" (car c) (cdr c))))
        (dolist (title (plist-get plan :removed))
          (line 1 (format "the empty \"%s\" heading would be removed" title)))
        (insert "\n")))))

(defun sp-org-lint-fn--summary ()
  "Return the summary line of a finished scan."
  (let ((plans (sp-org-lint-fn--get :plans)))
    (format "%d file(s) scanned: %d with footnotes to move (%d move(s)), %d orphan definition(s), %d dangling reference(s), %d error(s).\n"
            (or (sp-org-lint-fn--get :scanned) 0)
            (seq-count (lambda (p) (plist-get p :changed)) plans)
            (apply #'+ (mapcar (lambda (p) (length (plist-get p :moves))) plans))
            (apply #'+ (mapcar (lambda (p) (length (plist-get p :orphans))) plans))
            (apply #'+ (mapcar (lambda (p) (length (plist-get p :dangling))) plans))
            (seq-count (lambda (p) (plist-get p :error)) plans))))

(defun sp-org-lint-fn--render ()
  "Draw the whole report, from the state of the run."
  (let ((inhibit-read-only t)
        (plans (reverse (sp-org-lint-fn--get :plans)))
        (results (reverse (sp-org-lint-fn--get :results))))
    (erase-buffer)
    (insert (propertize "Footnote lint\n" 'face 'bold)
            (sp-org-lint-fn--summary) "\n")
    (when results
      (insert (propertize "Applied\n" 'face 'bold)
              (format "Backups are in %s\n\n"
                      (abbreviate-file-name (sp-org-lint-fn--get :backup-root))))
      (dolist (r results)
        (insert (propertize
                 (if (eq (plist-get r :status) 'written)
                     (format "  written: %s (%d move(s)); backup %s\n"
                             (abbreviate-file-name (plist-get r :file))
                             (plist-get r :moves)
                             (abbreviate-file-name (plist-get r :backup)))
                   (format "  skipped: %s (%s)\n"
                           (abbreviate-file-name (plist-get r :file))
                           (plist-get r :reason)))
                 'sp-file (plist-get r :file) 'sp-line 1)))
      (insert "\n"))
    (dolist (p plans)
      ;; What was applied is no longer pending.
      (when (seq-some (lambda (r) (and (eq (plist-get r :status) 'written)
                                       (equal (plist-get r :file) (plist-get p :file))))
                      results)
        (setq p (plist-put (plist-put (copy-sequence p) :moves nil) :removed nil)))
      (when (sp-org-lint-fn--shown-p p)
        (sp-org-lint-fn--insert-plan p)))
    (goto-char (point-min))))

** Running the worker

=sp-org-lint-fn--start= writes the control file, starts the headless Emacs with =make-process= and returns at once.

- The filter collects the output, cuts it into lines and handles each =SPLINT= line. It only touches the report buffer, so Emacs stays free for other work.
- A scan result is added to the buffer if it has anything to report. The header line shows the progress.
- When the process ends, the sentinel finishes the run:
  - a scan gets its summary,
  - an apply reverts the buffers visiting the changed files that have no unsaved edits, and asks vulpea to update those files one at a time while Emacs is idle.

#+begin_src emacs-lisp -i
(defun sp-org-lint-fn--handle (item)
  "Handle one result ITEM from the worker."
  (unless (plist-get item :done)
    (sp-org-lint-fn--set :done (1+ (or (sp-org-lint-fn--get :done) 0)))
    (if (eq (sp-org-lint-fn--get :phase) 'scan)
        (progn
          (sp-org-lint-fn--set :plans (cons item (sp-org-lint-fn--get :plans)))
          (when (sp-org-lint-fn--shown-p item)
            (sp-org-lint-fn--insert-plan item)))
      (sp-org-lint-fn--set :results (cons item (sp-org-lint-fn--get :results))))
    (force-mode-line-update)))

(defun sp-org-lint-fn--filter (buffer proc string)
  "Process filter: handle the complete lines of STRING in BUFFER."
  (if (not (buffer-live-p buffer))
      (delete-process proc)
    (with-current-buffer buffer
      (let ((data (concat (sp-org-lint-fn--get :partial) string))
            (start 0))
        (while (string-match "\n" data start)
          (let ((line (substring data start (match-beginning 0))))
            (setq start (match-end 0))
            (when (string-prefix-p "SPLINT " line)
              (sp-org-lint-fn--handle
               (car (read-from-string (substring line 7)))))))
        (sp-org-lint-fn--set :partial (substring data start))))))

(defun sp-org-lint-fn--sync-vulpea (files)
  "Ask vulpea to re-read FILES, one per idle moment."
  (when (and files (fboundp 'vulpea-db-update-file))
    (ignore-errors (vulpea-db-update-file (car files)))
    (when (cdr files)
      (run-with-idle-timer 0.2 nil #'sp-org-lint-fn--sync-vulpea (cdr files)))))

(defun sp-org-lint-fn--finish-apply ()
  "After an apply: refresh the buffers and the database for the written files."
  (let ((written (mapcar (lambda (r) (plist-get r :file))
                         (seq-filter (lambda (r) (eq (plist-get r :status) 'written))
                                     (sp-org-lint-fn--get :results)))))
    (dolist (f written)
      (when-let* ((b (find-buffer-visiting f)))
        (unless (buffer-modified-p b)
          (with-current-buffer b (revert-buffer t t t)))))
    (sp-org-lint-fn--sync-vulpea written)))

(defun sp-org-lint-fn--sentinel (buffer proc _event)
  "Process sentinel: finish the run in BUFFER when PROC has exited."
  (unless (process-live-p proc)
    (let ((err (process-get proc 'stderr))
          (ctl (process-get proc 'control-file)))
      (when ctl (ignore-errors (delete-file ctl)))
      (when (buffer-live-p buffer)
        (with-current-buffer buffer
          (let ((failed (not (zerop (process-exit-status proc)))))
            (when (eq (sp-org-lint-fn--get :phase) 'apply)
              (sp-org-lint-fn--finish-apply))
            (sp-org-lint-fn--set :phase (cond (failed 'failed)
                                              ((eq (sp-org-lint-fn--get :phase) 'apply) 'applied)
                                              (t 'ready)))
            (sp-org-lint-fn--render)
            (when failed
              (let ((inhibit-read-only t))
                (goto-char (point-max))
                (insert "The worker Emacs failed:\n"
                        (if (buffer-live-p err)
                            (with-current-buffer err (buffer-string))
                          "")))))))
      (when (buffer-live-p err) (kill-buffer err)))))

(defun sp-org-lint-fn--start (phase files extra)
  "Start the worker for PHASE (`scan' or `apply') on FILES in this buffer.
EXTRA is a plist merged into the control file."
  (unless (and sp-org-lint--library (file-exists-p sp-org-lint--library))
    (user-error "Cannot find sp-org-lint-footnotes.el to load in the worker Emacs"))
  (let* ((buffer (current-buffer))
         (ctl (make-temp-file "sp-org-lint-" nil ".eld"))
         (err (generate-new-buffer " *sp-org-lint stderr*"))
         proc)
    (with-temp-file ctl
      (let ((print-length nil) (print-level nil))
        (prin1 (append (list :mode (if (eq phase 'scan) 'plan 'apply)
                             :files files)
                       extra)
               (current-buffer))))
    (setq proc (make-process
                :name "sp-org-lint-footnotes"
                :buffer nil
                :command (list (expand-file-name invocation-name
                                                 invocation-directory)
                               "-Q" "--batch" "-l" sp-org-lint--library
                               "--eval"
                               (format "(sp-org-lint-fn--batch %S)" ctl))
                :connection-type 'pipe
                :coding 'utf-8-unix
                :noquery t
                :stderr err
                :filter (lambda (p s) (sp-org-lint-fn--filter buffer p s))
                :sentinel (lambda (p e) (sp-org-lint-fn--sentinel buffer p e))))
    (process-put proc 'control-file ctl)
    (process-put proc 'stderr err)
    (sp-org-lint-fn--set :process proc)
    (sp-org-lint-fn--set :phase phase)
    (when (eq phase 'scan)
      (sp-org-lint-fn--set :scanned (length files)))
    (sp-org-lint-fn--set :total (length files))
    (sp-org-lint-fn--set :done 0)
    (sp-org-lint-fn--set :partial "")))
#+end_src

(defun sp-org-lint-footnotes-convert ()
  "Apply the moves of the footnote lint shown in this report buffer.
Every file is copied to `sp-org-lint-fn-backup-directory' first.  Files
that are open with unsaved changes, or that changed since the scan,
are skipped.  The work is done by a second Emacs."

                                       (cons (plist-get p :file) (plist-get p :sha)))

* sp-author-notes.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/funct/sp-author-notes.el
:END:

Literature notes in =litnotes/= list their authors under the meta key =pub-author=. This module turns those authors into notes of their own and gives each one a list of the works it wrote.

=M-x sp-author-notes= does, in this order:

1. Reads every note in =litnotes/= (the file-level meta list only) and *fixes typos of the key*: =pub-authro=, =pub-autor= and =Pub_Author= become =pub-author=. A key two edits away is only reported.
2. Collects the authors. A value is made of ID links (=[[id:...][Name]]=, what the =base-text= schema in =sp-vulpea-schemas= asks for), Denote links (=[[denote:20251213T235944][Name]]=, turned into ID links when a note with that identifier and an =:ID:= exists) and names. Quoted names (="Ann Lee", "Bo Roe"= or ="Ann Lee" "Bo Roe"=) are separated by what is between the quotes; a quote mark with no partner (="Tim Wildschut=) is dropped. Unquoted names may be separated by =;= or =and= (as BibTeX writes them; =Ann Lee, Bo Roe, and Cy Poe= is a list with commas, see below), but not by a single comma because =Smith, John= is one name; more than one comma is a case for disambiguation, see below. Each name gets its own note.
3. *Creates a note tagged =:person:=* for every plain name that has no note, with =sp-org--write-note= (the function behind =sp-org-create-note-and-link=; there is no function called =sp-org--create-note=), and replaces the plain name in the litnote by an ID link to it. An existing note is found by its title, ignoring case; if it is not tagged =person= it is given that tag in its =#+filetags:=.
4. In every author note that is tagged =:person:=, makes sure a level-1 =Basics= heading exists, then a =Works= heading after it, and puts a =collection-query-table= dynamic block in =Works= unless the note already has one for =pub-author=.
5. Fills the tables from the Vulpea database, so they are not left for =C-c C-c=.
6. Shows a report buffer with everything above, and the same list as a preview before anything is written.

*Runs in the background.* The notes are read and written in slices (see [[file:sp-async-work.org][sp-async-work]]), so Emacs stays usable: the progress is in the mode line, =M-x sp-async-work-cancel= stops the job, and the report opens when the reading is done. The preview and the write are separate jobs. The questions about ambiguous names are asked in this Emacs, in the middle of a slice. As before, a note with unsaved changes in its buffer is saved first when you apply, and the files are copied to the backup folder before they are written.

The block is a query table (see [[file:sp-collection-query-tables.org][sp-collection-query-tables]]) with =:parent-of "self"= and =:parent-prop "pub-author"=: it lists the notes whose =pub-author= links point at the note the block is in. =:parent-of= compares IDs, which is why plain names are converted to links first.

Notes tagged =booksection= are not listed. Their =bib-parent= link points at the =book= note (the schema in =sp-vulpea.org= requires it), and =:fold-tag "booksection"= counts them in the =Sections= column of that book's row, adding the book if it has no =pub-author= of its own. The title links get the emoji of the note's tags from =sp-org-tag-groups= (the Org buffer decorates =id:= links itself), so a =filetags= column is not needed. Blocks that already exist are not changed; add =:fold-tag "booksection" :fold-prop "bib-parent"= and the =:sections= column to them by hand.

,#+BEGIN: collection-query-table :parent-of "self" :parent-prop "pub-author" :fold-tag "booksection" :fold-prop "bib-parent" :columns (:title :sections "read-status" "read-priority" "pub-year" "relevance-factor") :sort-by "pub-year"
,#+END:
#+end_example

Safety:

- =sp-author-notes= first *shows the plan* (nothing is written), then asks before writing. =sp-author-notes-dryrun= only shows the plan. In the report, =A= applies it and =g= runs the preview again.
- It is idempotent: a second run finds nothing to do.
- It adds text, and changes only: the key text of a typo, the value of a =pub-author= line that had plain names, the =#+filetags:= line of a note that gets the tag, and the position of a =Works= heading that is above =Basics= (its whole subtree moves below =Basics=). Nothing is deleted.
- Before a file is changed it is copied to =sp-author-notes-backup-directory= (a folder per run).
- A file with unsaved changes in a buffer is saved first, and the report lists it. The preview lists the buffers it will save.
- A link to an ID that no note has (an orphan) is listed with the suggestion of the person note of that name. When the changes are written you are asked where it should point (=sp-author-notes-redirect-function=; an empty answer leaves it). A linked note that is not a =person= is only reported.
- A list of unquoted names with more than one comma (=Francisco López-Muñoz, Gabriel Rubio, Juan D. Molina=) can be one author or several, so it is its own case: the report shows how it would be split (each piece a name, or =Last, First= pairs when the first piece is a single word) and, when the changes are written, you are asked whether to split it (=sp-author-notes-disambiguate-function=). Left as it is otherwise.
- In the report, =d= drops the candidate on the line from the plan and shows the preview again, =u= brings it back, =A= writes what is left. A note (a litnote, an author note, a note to tag) is dropped as a file: it is not read or changed. An author to create is dropped by name: no note is made and the name stays plain. The command asks =y= (write all), =r= (review in the report) or =q=.
- Left alone and reported: two notes with one title, a note without an ID, and a value that mixes links with other text.

What it does not do: it reads =litnotes/= only, so works that exist only as BibTeX entries have no note and do not appear in a =Works= table until they get a literature note. Only people who appear under =pub-author= get a =Works= section, not every =person= note.

(defconst sp-author-notes--fold-letters
  '((?ø . "o") (?Ø . "O") (?đ . "d") (?Đ . "D") (?ð . "d") (?Ð . "D") (?ł . "l") (?Ł . "L")
    (?ß . "ss") (?æ . "ae") (?Æ . "AE") (?œ . "oe") (?Œ . "OE") (?ı . "i") (?þ . "th")
    (?Þ . "Th"))
  "Letters with no decomposition and the ASCII they are folded to.")

(defun sp-author-notes--comma-below (string)
  "STRING in NFC with the cedilla s and t of Romanian written with a comma below."
  (let ((s (ucs-normalize-NFC-string string)))
    (dolist (pair '((#x15F . #x219) (#x15E . #x218) (#x163 . #x21B) (#x162 . #x21A)))
      (setq s (subst-char-in-string (car pair) (cdr pair) s)))
    s))

(defun sp-author-notes-fold-diacritics (string)
  "STRING with its accents removed: Søren Bulată and Soren Bulata fold alike.
Ø, đ, ł, ß, æ and œ become o, d, l, ss, ae and oe; combining marks (also the
comma below of ș and ț and the cedilla of ş and ţ) are dropped."
  (let ((plain (mapconcat (lambda (c) (or (cdr (assq c sp-author-notes--fold-letters))
                                          (string c)))
                          string "")))
    (replace-regexp-in-string (format "[%c-%c]" #x300 #x36f) ""
                              (ucs-normalize-NFD-string plain))))

    (?r . #x30A))

  '(("oe" . "œ") ("OE" . "Œ") ("ae" . "æ") ("AE" . "Æ") ("aa" . "å") ("AA" . "Å")
    ("ss" . "ß") ("o" . "ø") ("O" . "Ø") ("l" . "ł") ("L" . "Ł") ("i" . "i") ("j" . "j"))

(defun sp-author-notes-latex-to-unicode (string)
  "STRING with BibTeX accents written as Unicode: S{\\o}ren is Søren, Bulat{\\u a} Bulată.
Handles `{\\o}', `\\aa', `\\\"o', `\\'{e}', `\\u{a}', `\\v s', `\\c{s}' and the like, then
writes the cedilla s and t as the Romanian comma-below ones."
  (let ((s string))
    (when (string-match-p "\\\\" s)
      (setq s (replace-regexp-in-string
               "\\\\\\(oe\\|OE\\|ae\\|AE\\|aa\\|AA\\|ss\\|o\\|O\\|l\\|L\\|i\\|j\\)\\_>\\(?: \\)?"
               (lambda (m) (save-match-data
                             (string-match "\\\\\\([a-zA-Z]+\\)" m)
                             (cdr (assoc (match-string 1 m) sp-author-notes--latex-letters))))
               s t t))
      (setq s (replace-regexp-in-string
               "\\\\\\(['`^\"~=.]\\)[ ]*\\(?:{\\([[:alpha:]]\\)}\\|\\([[:alpha:]]\\)\\)"
               (lambda (m)
                 (save-match-data
                   (string-match "\\\\\\(.\\)[ ]*{?\\([[:alpha:]]\\)" m)
                   (concat (match-string 2 m)
                           (string (cdr (assq (aref (match-string 1 m) 0)
                                              sp-author-notes--latex-accents))))))
               s t t))
      (setq s (replace-regexp-in-string
               "\\\\\\([uvcHkr]\\)\\(?:{\\([[:alpha:]]\\)}\\|[ ]+\\([[:alpha:]]\\)\\)"
               (lambda (m)
                 (save-match-data
                   (string-match "\\\\\\(.\\)[ {]*\\([[:alpha:]]\\)" m)
                   (concat (match-string 2 m)
                           (string (cdr (assq (aref (match-string 1 m) 0)
                                              sp-author-notes--latex-accents))))))
               s t t)))
    (sp-author-notes--comma-below s)))

(defun sp-author-notes--osa-distance (a b)
  "The edit distance of strings A and B, a swap of two letters counting as one."
  (let* ((la (length a)) (lb (length b))
         (d (make-vector (* (1+ la) (1+ lb)) 0)))
    (cl-flet ((ref (i j) (aref d (+ (* i (1+ lb)) j))))
      (dotimes (i (1+ la)) (aset d (* i (1+ lb)) i))
      (dotimes (j (1+ lb)) (aset d j j))
      (cl-loop for i from 1 to la do
               (cl-loop for j from 1 to lb do
                        (let* ((cost (if (eq (aref a (1- i)) (aref b (1- j))) 0 1))
                               (best (min (1+ (ref (1- i) j))
                                          (1+ (ref i (1- j)))
                                          (+ (ref (1- i) (1- j)) cost))))
                          (when (and (> i 1) (> j 1)
                                     (eq (aref a (1- i)) (aref b (- j 2)))
                                     (eq (aref a (- i 2)) (aref b (1- j))))
                            (setq best (min best (1+ (ref (- i 2) (- j 2))))))
                          (aset d (+ (* i (1+ lb)) j) best))))
      (ref la lb))))

(defun sp-author-notes--key-state-1 (key canon)
  "Say whether the meta KEY is a typo of the person key CANON.
Return nil for a key that is fine or unrelated, (fix . CANONICAL) for a
key one edit away (a swap of two letters is one edit) or only differing
in case, `_' or space, and (suspect . CANONICAL) for a key two edits
away, which is reported but not changed.  A key that is more like another
known key is never a typo."
  (let* ((n (replace-regexp-in-string "[_ ]" "-" (downcase key))))
    (cond
     ((string= key canon) nil)
     ((member key sp-author-notes-known-keys) nil)
     ((string= n canon) (cons 'fix canon))
     (t
      (let ((d (sp-author-notes--osa-distance n canon))
            (other (apply #'min 99 (mapcar (lambda (k) (sp-author-notes--osa-distance n k))
                                           (remove canon sp-author-notes-known-keys)))))
        (cond ((and (<= d 1) (< d other)) (cons 'fix canon))
              ((and (<= d 2) (< d other)) (cons 'suspect canon))))))))

*** Author values

A value without links is split at =;= and at =and= into plain names. A value of links only (commas between them are fine) gives its links. A value that has links and other words is not touched.

(defun sp-author-notes--key-state (key)
  "Say whether the meta KEY is a typo of one of `sp-author-notes-person-keys'.
Return nil, (fix . CANONICAL) or (suspect . CANONICAL); see `sp-author-notes--key-state-1'."
  (seq-some (lambda (canon) (sp-author-notes--key-state-1 key canon))

(defconst sp-author-notes--id-link-re
  "\\[\\[id:\\([^]]+\\)\\]\\(?:\\[\\([^]]*\\)\\]\\)?\\]"
  "An ID link; group 1 is the ID and group 2 the description, if any.")

(defconst sp-author-notes--denote-link-re
  "\\[\\[denote:\\([^]]+\\)\\]\\(?:\\[\\([^]]*\\)\\]\\)?\\]"
  "A Denote link; group 1 is the identifier and group 2 the description, if any.")

(defconst sp-author-notes--token-re
  (concat sp-author-notes--id-link-re "\\|" "\\[\\[denote:\\([^]]+\\)\\]\\(?:\\[[^]]*\\]\\)?\\]"
          "\\|[\"“]\\([^\"“”]*\\)[\"”]")
  "A link or a quoted name in a value; group 1 is an ID, 3 a Denote identifier, 4 a quoted name.")

(defun sp-author-notes--clean-name (name)
  "NAME without quote marks, BibTeX braces and extra white space, flipped when asked for."
  (let* ((name (string-trim (replace-regexp-in-string
                             "[ \t\n]+" " " (replace-regexp-in-string
                                              "[{}\"“”]" "" (sp-author-notes-latex-to-unicode name)))))
         (parts (split-string name "," t "[ \t]+")))
    (if (and sp-author-notes-flip-names
             (= (length parts) 2)
             (string-match-p "[[:alpha:]]" (car parts))
             (string-match-p "[[:alpha:]]" (cadr parts)))
        (concat (cadr parts) " " (car parts))
      name)))

(defun sp-author-notes--comma-proposal (segment)
  "Propose the authors of SEGMENT, a list with more than one comma, as a list of names.
When the text before the first comma has two words or more, every
comma-separated piece is a name: \"Ann Lee, Bo Roe, Cy Poe\".  Otherwise
the pieces are \"Last, First\" pairs, flipped when
`sp-author-notes-flip-names' is set.  Nil when the pieces cannot be paired."
  (let ((pieces (split-string segment "," t "[ \t]+")))
    (if (string-match-p "[ \t]" (car pieces))
        (mapcar #'sp-author-notes--clean-name pieces)
      (when (cl-evenp (length pieces))
        (cl-loop for (last first) on pieces by #'cddr
                 collect (sp-author-notes--clean-name (concat last ", " first)))))))

(defun sp-author-notes-read-disambiguation (raw names)
  "Ask whether RAW is the authors NAMES.  Return NAMES when it is, else nil."
  (when (y-or-n-p (format "\"%s\" may be %d authors: %s.  Make one author each? "
                          raw (length names) (string-join names " | ")))
    names))

(defun sp-author-notes--accent-score (title)
  "How many characters of TITLE the folding changes: more means better spelled."
  (length (seq-filter (lambda (c) (not (equal (string c) (sp-author-notes-fold-diacritics (string c)))))
                      title)))

(defun sp-author-notes-read-duplicate (entries)
  "Ask which of the person notes ENTRIES, spelled alike, to use; return its entry.
The default is the spelling with the most accents."
  (let* ((sorted (sort (copy-sequence entries)
                       (lambda (a b) (> (sp-author-notes--accent-score (plist-get a :title))
                                        (sp-author-notes--accent-score (plist-get b :title))))))
         (alist (mapcar (lambda (e) (cons (format "%s [%s]" (plist-get e :title)
                                                  (file-name-nondirectory (plist-get e :file)))
                                          e))
                        sorted))
         (choice (completing-read
                  (format "%d notes spell \"%s\" alike; use which? "
                          (length entries) (plist-get (car sorted) :title))
                  (mapcar #'car alist) nil t nil nil (caar alist))))
    (cdr (assoc choice alist))))

(defun sp-author-notes--and-list-p (pieces)
  "Non-nil if PIECES, a text split at `and', is one list of names with commas.
That is so when the last piece has no comma and an earlier one has a
comma after two words or more: `Ann Lee, Bo Roe, and Cy Poe'.  BibTeX's
`Lee, Ann and Roe, Bo' is not one, nor is `Lee, Ann and Bo Roe'."
  (and (cdr pieces)
       (not (string-match-p "," (car (last pieces))))
       (seq-some (lambda (piece)
                   (and (string-match-p "," piece)
                        (string-match-p "[ \t]" (string-trim (car (split-string piece ","))))))
                 pieces)))

(defun sp-author-notes--plain-names (text)
  "The names in TEXT, which has no links or quoted names.
A stray quote mark is dropped.  Names are separated by `;' or `and' (as
BibTeX writes them).  Each element is a name, or (:ambiguous RAW NAMES)
for a piece with more than one comma, or a list with commas that ends in
`and', which may be one author or several: RAW is the text and NAMES the
split proposed by `sp-author-notes--comma-proposal'."
  (let (out)
    (dolist (semi (split-string (replace-regexp-in-string "[\"“”]" "" text) "[ \t]*;[ \t]*" t))
      (let ((pieces (split-string semi "[ \t]+and[ \t]+" t)))
        (if (sp-author-notes--and-list-p pieces)
            (push (list :ambiguous (string-trim semi "[ \t,]+" "[ \t,]+")
                        (mapcar #'sp-author-notes--clean-name
                                (seq-mapcat (lambda (piece) (split-string piece "," t "[ \t]+"))
                                            pieces)))
                  out)
          (dolist (segment pieces)
            (let ((segment (string-trim segment "[ \t,]+" "[ \t,]+")))
              (cond ((string-empty-p segment))
                    ((> (length (split-string segment "," t "[ \t]+")) 2)
                     (push (list :ambiguous segment (sp-author-notes--comma-proposal segment)) out))
                    (t (push (sp-author-notes--clean-name segment) out))))))))
    (seq-remove (lambda (x) (and (stringp x) (string-empty-p x))) (nreverse out))))

(defun sp-author-notes--parse-value (value)
  "Split the meta VALUE into authors.
Return a list of (:link ID RAW), (:denote IDENTIFIER RAW), (:name NAME) and
\(:ambiguous RAW NAMES) items, in order, or `unparsed' when links are mixed with other words.
A name can be quoted (\"Ann Lee\", \"Bo Roe\" or \"Ann Lee\" \"Bo Roe\"), so the
comma between quoted names separates them; a quote mark with no partner
is dropped."
  (let ((pos 0) items loose linked)
    (while (string-match sp-author-notes--token-re value pos)
      (let* ((beg (match-beginning 0)) (end (match-end 0))
             (token (cond ((match-string 1 value)
                           (list :link (match-string 1 value) (match-string 0 value)))
                          ((match-string 3 value)
                           (list :denote (match-string 3 value) (match-string 0 value)))
                          (t (list :quoted (match-string 4 value)))))
             (before (substring value pos beg)))
        (dolist (name (sp-author-notes--plain-names before))
          (push (if (stringp name) (list :name name) name) items)
          (push name loose))
        (if (eq (car token) :quoted)
            (let ((name (sp-author-notes--clean-name (cadr token))))
              (unless (string-empty-p name) (push (list :name name) items)))
          (setq linked t)
          (push token items))
        (setq pos end)))
    (dolist (name (sp-author-notes--plain-names (substring value pos)))
      (push (if (stringp name) (list :name name) name) items)
      (push name loose))
    (if (and linked loose) 'unparsed (nreverse items))))

** The run

A run holds what it found and did. It is the same code for the preview and for the real thing: every pass edits a temporary buffer, and the buffer is only written to the file when =apply= is set. That keeps the preview from drifting away from what is later done.

#+begin_src emacs-lisp -i

(cl-defstruct (sp-author-notes--run (:constructor sp-author-notes--make-run)
                                    (:copier nil))

  by-title       ; hash: title key -> list of index entries

changed, and dropped names get no note.")

(defun sp-author-notes--problem (run file line text)

(defun sp-author-notes--index-start (run)

(defun sp-author-notes--index-file (run file)

*** Finding or creating the note of a name

The result for each name is remembered, so a name that occurs in fifty litnotes is looked up (and created) once. =sp-author-notes--resolve= returns the ID to link to, =:pending= when only the real run would create the note, or nil when the name is left alone (the reason is a problem in the report).

#+begin_src emacs-lisp -i

(defun sp-author-notes--create (run name)
  "Create the author note NAME and register it in RUN.  Return its ID."
  (require 'sp-org-link-conversion)
  (let* ((id (sp-org--write-note name (list sp-author-notes-person-tag)))
         (file (car (org-id-find id))))
    (unless file (error "The new note %s has no file" name))
    (let ((entry (list :file file :id id :title name
                       :tags (list sp-author-notes-person-tag))))
      (puthash id entry (sp-author-notes--run-by-id run))
      (push entry (gethash (sp-author-notes--title-key name)
                           (sp-author-notes--run-by-title run))))
    (push (list name id file) (sp-author-notes--run-created run))
    id))

(defun sp-author-notes--tag-pass ()
  "Add `sp-author-notes-person-tag' to the #+filetags: of the buffer.
A note that has none gets the line after its #+title:, or after its
property drawer.  Return t."
  (let ((case-fold-search t)
        (limit (sp-author-notes--first-heading)))
    (goto-char (point-min))
    (cond
     ((re-search-forward "^#\\+filetags:[ \t]*\\(.*?\\)[ \t]*$" limit t)
      (let* ((old (match-string-no-properties 1))
             (new (cond ((string-empty-p old) (format ":%s:" sp-author-notes-person-tag))
                        ((string-match-p ":" old)
                         (concat old (if (string-suffix-p ":" old) "" ":")
                                 sp-author-notes-person-tag ":"))
                        (t (concat old " " sp-author-notes-person-tag)))))
        (sp-author-notes--replace (match-beginning 1) (match-end 1) new)))
     ((re-search-forward "^#\\+title:.*$" limit t)
      (insert (format "\n#+filetags: :%s:" sp-author-notes-person-tag)))
     (t
      (goto-char (point-min))
      (when (looking-at "[ \t]*:PROPERTIES:")
        (re-search-forward "^[ \t]*:END:[ \t]*$" limit t)
        (forward-line 1))
      (insert (format "#+filetags: :%s:\n" sp-author-notes-person-tag))))
    t))

(defun sp-author-notes--resolve-1 (run name file line)
  "Work out what to do for NAME, found at FILE and LINE.
Return (id ID), (pending) or (skip)."
  (let* ((matches (gethash (sp-author-notes--title-key name)
                           (sp-author-notes--run-by-title run)))
         (persons (seq-filter #'sp-author-notes--person-p matches))
         (others (seq-remove #'sp-author-notes--person-p matches)))
    (cond
     ((cdr persons)
      (let ((chosen (and (sp-author-notes--run-apply run)
                         (funcall sp-author-notes-duplicate-function persons))))
        (cond
         ((and chosen (plist-get chosen :id)) (list 'id (plist-get chosen :id)))
         (t (sp-author-notes--problem
             run file line
             (format "%d notes tagged %s are titled alike (%s); %s"
                     (length persons) sp-author-notes-person-tag
                     (mapconcat (lambda (e) (format "\"%s\"" (plist-get e :title))) persons ", ")
                     (if (sp-author-notes--run-apply run)
                         "left as it is"
                       "apply will ask which one to use")))
            '(skip)))))
     (persons
      (if-let* ((id (plist-get (car persons) :id)))
          (list 'id id)
        (sp-author-notes--problem
         run (plist-get (car persons) :file) nil
         (format "The note \"%s\" has no :ID:; left as it is" name))
        '(skip)))
     ((cdr others)
      (sp-author-notes--problem
       run file line (format "%d notes are titled \"%s\" and none is tagged %s; left as they are"
                             (length others) name sp-author-notes-person-tag))
      '(skip))
     ((and others (member (plist-get (car others) :file) sp-author-notes--excluded))
      '(skip))
     (others
      (let ((entry (car others)))
        (if (not (plist-get entry :id))
            (progn (sp-author-notes--problem
                    run (plist-get entry :file) nil
                    (format "The note \"%s\" is not tagged %s and has no :ID:; left as it is"
                            name sp-author-notes-person-tag))
                   '(skip))
          (when (sp-author-notes--process-file
                 run (plist-get entry :file) #'sp-author-notes--tag-pass)
            (plist-put entry :tags (append (plist-get entry :tags)
                                           (list sp-author-notes-person-tag)))
            (push (list name (plist-get entry :id) (plist-get entry :file))
                  (sp-author-notes--run-tagged run)))
          (list 'id (plist-get entry :id)))))
     ((sp-author-notes--run-apply run)
      (list 'id (sp-author-notes--create run name)))
     (t
      (push name (sp-author-notes--run-pending run))
      '(pending)))))

(defun sp-author-notes--resolve (run name file line)
  "The ID of the author note for NAME, :pending, or nil.  See above."
  (let* ((key (sp-author-notes--title-key name))
         (table (sp-author-notes--run-names run))
         (found (or (gethash key table)
                    (and (member (concat "name:" key) sp-author-notes--excluded)
                         (puthash key '(skip) table))
                    (puthash key (sp-author-notes--resolve-1 run name file line) table))))
    (pcase found
      (`(id ,id) id)
      (`(pending) :pending)
      (_ nil))))
#+end_src

*** The litnote pass

This runs in a buffer that holds one litnote. It goes through the meta lines from the last to the first, so editing a line does not move the ones still to do. It returns a plist: =:fixes= (KEY . LINE), =:suspects= (KEY . LINE), =:converted= (NAME ID LINE), =:authors= (ID . NAME) and =:unparsed=.

#+begin_src emacs-lisp -i

(defun sp-author-notes--replace (beg end text)
  "Replace the text from BEG to END by TEXT."
  (save-excursion
    (goto-char beg)
    (delete-region beg end)
    (insert text)))

(defun sp-author-notes--link-description (raw)
  "The description of the ID link RAW, or nil."
  (when (string-match sp-author-notes--id-link-re raw)
    (match-string 2 raw)))

(defun sp-author-notes--person-candidates (run)
  "An alist (TITLE . ID) of every person note in RUN's vault."
  (let (out)
    (maphash (lambda (id entry)
               (when (and (sp-author-notes--person-p entry) (plist-get entry :title))
                 (push (cons (plist-get entry :title) id) out)))
             (sp-author-notes--run-by-id run))
    (sort out (lambda (a b) (string-collate-lessp (car a) (car b) nil t)))))

(defun sp-author-notes-read-redirect (id description suggestion candidates)
  "Ask which person note a link to the orphan ID should point to.
DESCRIPTION is the text of the link, SUGGESTION the title of the person
note with that name or nil, CANDIDATES an alist (TITLE . ID).  Return an
ID, or nil when the answer is empty."
  (let ((choice (completing-read
                 (format "No note has the ID %s (\"%s\").  Point the link to (empty: leave it): "
                         id (or description ""))
                 (mapcar #'car candidates) nil t suggestion)))
    (cdr (assoc choice candidates))))

(defun sp-author-notes--check-link (run id raw file line)
  "Check the ID link RAW found at FILE and LINE.
Return (ID . RAW) to use: the same, unless the ID is an orphan that the
user redirected to another person note.  An orphan is recorded for the
report, with the person note of the same name as a suggestion."
  (if (gethash id (sp-author-notes--run-by-id run))
      (cons id raw)
    (let* ((description (sp-author-notes--link-description raw))
           (suggestion (when description
                         (let ((m (seq-filter #'sp-author-notes--person-p
                                              (gethash (sp-author-notes--title-key description)
                                                       (sp-author-notes--run-by-title run)))))
                           (and m (null (cdr m)) (plist-get (car m) :title)))))
           (choices (sp-author-notes--run-orphan-choices run))
           (choice (gethash id choices 'unasked)))
      (when (and (eq choice 'unasked) (sp-author-notes--run-apply run))
        (setq choice (or (funcall sp-author-notes-redirect-function
                                  id description suggestion
                                  (sp-author-notes--person-candidates run))
                         'none))
        (puthash id choice choices))
      (let ((new (and (stringp choice) choice)))
        (push (list file line id description new suggestion)
              (sp-author-notes--run-orphans run))
        (if new
            (cons new (format "[[id:%s][%s]]" new
                              (plist-get (gethash new (sp-author-notes--run-by-id run)) :title)))
          (cons id raw))))))

(defun sp-author-notes--denote-to-id (run identifier raw file line)
  "Turn the Denote link RAW, to IDENTIFIER, into an ID link.
Return (ID . NEW-RAW), or nil, recording a problem, when no note in the
vault has that identifier and an :ID:."
  (let* ((entry (gethash identifier (sp-author-notes--run-by-denote run)))
         (id (and entry (plist-get entry :id))))
    (cond
     (id (cons id (format "[[id:%s][%s]]" id
                          (or (and (string-match sp-author-notes--denote-link-re raw)
                                   (match-string 2 raw))
                              (plist-get entry :title)))))
     (t (sp-author-notes--problem
         run file line
         (if entry
             (format "The Denote link %s points at a note with no :ID:; left as it is" identifier)
           (format "No note has the Denote identifier %s; link left as it is" identifier)))
        nil))))

(defun sp-author-notes--litnote-pass (run file)
  "Fix the key typos and link the plain authors in the buffer, a note from FILE."
  (let (fixes suspects converted authors unparsed denoted ambiguous)
    (dolist (entry (sp-author-notes--meta-entries))
      (let* ((key (plist-get entry :key))
             (line (plist-get entry :line))
             (state (sp-author-notes--key-state key))
             (is-author (or (member key sp-author-notes-person-keys) (eq (car state) 'fix)))
             (value (plist-get entry :value)))
        (when (and is-author value (not (string-empty-p value)))
          (let ((items (sp-author-notes--parse-value value)))
            (if (eq items 'unparsed)
                (push (cons value line) unparsed)
              (let (parts changed)
                (cl-flet ((do-name (name line)
                            (let ((id (sp-author-notes--resolve run name file line)))
                              (cond
                               ((stringp id)
                                (push (cons id name) authors)
                                (push (format "[[id:%s][%s]]" id name) parts)
                                (push (list name id line) converted)
                                (setq changed t))
                               ((eq id :pending)
                                (push (cons nil name) authors)
                                (push (list name nil line) converted)
                                (push name parts))
                               (t (push name parts))))))
                (dolist (item items)
                  (pcase item
                    (`(:link ,id ,raw)
                     (let* ((new (sp-author-notes--check-link run id raw file line))
                            (id (car new)) (raw (cdr new)))
                       (when (and (not (equal (cdr new) (nth 2 item)))) (setq changed t))
                       (push (cons id nil) authors)
                       (push raw parts)))
                    (`(:denote ,identifier ,raw)
                     (if-let* ((conv (sp-author-notes--denote-to-id run identifier raw file line)))
                         (let ((new (sp-author-notes--check-link
                                     run (car conv) (cdr conv) file line)))
                           (push (list identifier (car new) line) denoted)
                           (push (cons (car new) nil) authors)
                           (push (cdr new) parts)
                           (setq changed t))
                       (push raw parts)))
                    (`(:name ,name) (do-name name line))
                    (`(:ambiguous ,raw ,names)
                     (let ((chosen (and names (sp-author-notes--run-apply run)
                                        (funcall sp-author-notes-disambiguate-function raw names))))
                       (push (list raw names line chosen) ambiguous)
                       (if chosen
                           (dolist (name chosen) (do-name name line))
                         (push raw parts)))))))
                (when changed
                  (sp-author-notes--replace
                   (plist-get entry :value-beg) (plist-get entry :value-end)
                   (mapconcat #'identity (nreverse parts) ", ")))))))
        (when state
          (if (eq (car state) 'fix)
              (progn
                (push (cons key line) fixes)
                (sp-author-notes--replace (plist-get entry :key-beg)
                                          (plist-get entry :key-end) (cdr state)))
            (push (cons key line) suspects)))))
    (list :fixes fixes :suspects suspects :converted converted
          :authors authors :unparsed unparsed :denoted denoted
          :ambiguous ambiguous)))

*** The person pass

The buffer holds an author note. The pass adds what is missing and returns what it added, a list of =basics=, =works= and =table=.

- =Basics= is put before the first heading of the note, or at the end if there is none.
- =Works= is put after the whole =Basics= subtree, as a heading of the same level.
- The block is put at the end of the text of =Works=, before its first sub-heading.
- A =Works= heading that already exists is used; if it is above =Basics= its whole subtree is moved below =Basics=.
- A block for the key already anywhere in the note (also the old =vulpea-table= name) counts as there.

#+begin_src emacs-lisp -i

(defun sp-author-notes--dblock-text ()
  "The text of the query table block for `sp-author-notes-works-spec'."
  (let ((spec sp-author-notes-works-spec) pairs)
    (while spec
      (push (format "%s %S" (car spec) (cadr spec)) pairs)
      (setq spec (cddr spec)))
    (format "#+BEGIN: collection-query-table %s\n#+END:\n"
            (mapconcat #'identity (nreverse pairs) " "))))

(defun sp-author-notes--find-heading (title)
  "The position and level of the heading TITLE, as (POS . LEVEL), or nil."
  (save-excursion
    (goto-char (point-min))
    (let ((case-fold-search nil))
      (when (re-search-forward
             (format "^\\(\\*+\\)[ \t]+%s\\(?:[ \t]+:[[:alnum:]_@#%%:]+:\\)?[ \t]*$"
                     (regexp-quote title))
             nil t)
        (cons (match-beginning 0) (length (match-string 1)))))))

(defun sp-author-notes--subtree-end (pos level)
  "The end of the subtree of the heading of LEVEL at POS."
  (save-excursion
    (goto-char pos)
    (end-of-line)
    (if (re-search-forward (format "^\\*\\{1,%d\\}[ \t]" level) nil t)
        (match-beginning 0)
      (point-max))))

(defun sp-author-notes--body-end (pos)
  "The end of the text directly under the heading at POS, before any sub-heading."
  (save-excursion
    (goto-char pos)
    (end-of-line)
    (if (re-search-forward "^\\*+[ \t]" nil t)
        (match-beginning 0)
      (point-max))))

(defun sp-author-notes--insert-at (pos text)
  "Insert TEXT at POS as a paragraph of its own, with a blank line around it."
  (save-excursion
    (goto-char pos)
    (unless (or (bobp) (bolp)) (insert "\n"))
    (unless (or (bobp) (and (> (point) 2) (eq (char-before (1- (point))) ?\n)))
      (insert "\n"))
    (insert text)
    (unless (or (eobp) (eq (char-after) ?\n)) (insert "\n"))))

(defun sp-author-notes--has-table-p ()
  "Non-nil if the buffer has a query table block for `sp-author-notes-key'."
  (save-excursion
    (goto-char (point-min))
    (let ((case-fold-search t))
      (re-search-forward
       (format "^[ \t]*#\\+begin:[ \t]*\\(?:collection-query-table\\|vulpea-table\\)\\_>.*:parent-prop[ \t]+\"%s\""
               (regexp-quote sp-author-notes-key))
       nil t))))

(defun sp-author-notes--person-pass ()
  "Add the Basics heading, the Works heading and the table to the buffer."
  (let (added)
    (unless (sp-author-notes--find-heading sp-author-notes-basics-heading)
      (sp-author-notes--insert-at (sp-author-notes--first-heading)
                                  (format "* %s\n" sp-author-notes-basics-heading))
      (push 'basics added))
    (let ((basics (sp-author-notes--find-heading sp-author-notes-basics-heading))
          (works (sp-author-notes--find-heading sp-author-notes-works-heading)))
      (when (and works (< (car works) (car basics)))
        (let* ((beg (car works))
               (text (buffer-substring beg (sp-author-notes--subtree-end beg (cdr works)))))
          (delete-region beg (sp-author-notes--subtree-end beg (cdr works)))
          (let ((basics (sp-author-notes--find-heading sp-author-notes-basics-heading)))
            (sp-author-notes--insert-at
             (sp-author-notes--subtree-end (car basics) (cdr basics))
             (if (string-suffix-p "\n" text) text (concat text "\n"))))
          (push 'moved-works added))))
    (unless (sp-author-notes--find-heading sp-author-notes-works-heading)
      (let ((basics (sp-author-notes--find-heading sp-author-notes-basics-heading)))
        (sp-author-notes--insert-at
         (sp-author-notes--subtree-end (car basics) (cdr basics))
         (format "* %s\n" sp-author-notes-works-heading)))
      (push 'works added))
    (unless (sp-author-notes--has-table-p)
      (let ((works (sp-author-notes--find-heading sp-author-notes-works-heading)))
        (sp-author-notes--insert-at (sp-author-notes--body-end (car works))
                                    (sp-author-notes--dblock-text)))
      (push 'table added))
    (nreverse added)))

** Files and the whole run

*** Changing a file

The file is read into a temporary buffer, the pass edits that, and only if it changed and this is a real run it is copied to the backup folder and written. The Vulpea database is told if it has =vulpea-db-update-file=; otherwise it catches up by itself, and the tables will show the new links after that.

#+begin_src emacs-lisp -i

(defun sp-author-notes--backup (run file)
  "Copy FILE to the backup folder of RUN."
  (when (and sp-author-notes-backup-directory
             (not (gethash file (sp-author-notes--run-backed-up run))))
    (puthash file t (sp-author-notes--run-backed-up run))
    (let* ((root (file-name-as-directory (expand-file-name sp-author-notes-directory)))
           (rel (if (string-prefix-p root file)
                    (substring file (length root))
                  (file-name-nondirectory file)))
           (dest (expand-file-name
                  rel (expand-file-name (sp-author-notes--run-stamp run)
                                        sp-author-notes-backup-directory))))
      (make-directory (file-name-directory dest) t)
      (copy-file file dest t))))

(defun sp-author-notes--process-file (run file pass)
  "Run PASS in a temporary buffer with the text of FILE, and write it when RUN applies.
PASS is called with no arguments.  Return its value in a list, or nil
when FILE was dropped from the report (`sp-author-notes--excluded').  A buffer
of FILE with unsaved changes is saved first (and FILE is recorded in
`sp-author-notes--run-saved'); a preview reads the text of the buffer."
  (let* ((visiting (find-buffer-visiting file))
         (dirty (and visiting (buffer-modified-p visiting)))
         (apply (sp-author-notes--run-apply run)))
    (unless (member file sp-author-notes--excluded)
      (when dirty
        (cl-pushnew file (sp-author-notes--run-saved run) :test #'string=)
        (when apply (with-current-buffer visiting (save-buffer))))
      (with-temp-buffer
        (if (and dirty (not apply))
            (insert (with-current-buffer visiting
                      (buffer-substring-no-properties (point-min) (point-max))))
          (sp-author-notes--insert-file file))
        (let ((before (buffer-string))
              (result (funcall pass)))
          (when (and apply (not (string= before (buffer-string))))
            (sp-author-notes--backup run file)
            (let ((coding-system-for-write 'utf-8))
              (write-region (point-min) (point-max) file nil 'silent))
            (when visiting
              (with-current-buffer visiting (revert-buffer t t t)))
            (when (fboundp 'vulpea-db-update-file)
              (ignore-errors (vulpea-db-update-file file))))
          (list result))))))

*** Doing the run

The order is fixed: litnotes first (this creates the notes of plain names), then the author notes, which now include the new ones. A new note that does not exist yet in a preview is shown with what it would get.

#+begin_src emacs-lisp -i

(defun sp-author-notes--new-note-additions ()
  "What the person pass adds to a note that has only the title and the tag."
  (with-temp-buffer
    (insert ":PROPERTIES:\n:ID: x\n:END:\n#+title: x\n\n")
    (sp-author-notes--person-pass)))

(defun sp-author-notes--populate (run file)
  "Fill the query table blocks for `sp-author-notes-key' in FILE.
The note is saved when that changed it, after a copy to the backup
folder.  A failure is recorded as a problem."
  (condition-case err
      (let* ((visiting (find-buffer-visiting file))
             (buffer (or visiting (find-file-noselect file))))
        (unwind-protect
            (with-current-buffer buffer
              (let ((modified (buffer-modified-p))
                    (before (buffer-string))
                    (case-fold-search t))
                (save-excursion
                  (goto-char (point-min))
                  (while (re-search-forward
                          (format "^[ \t]*#\\+begin:[ \t]*collection-query-table\\_>.*:parent-prop[ \t]+\"%s\""
                                  (regexp-quote sp-author-notes-key))
                          nil t)
                    (beginning-of-line)
                    (org-update-dblock)
                    (forward-line 1)))
                (unless (string= before (buffer-string))
                  (when modified (error "Buffer has unsaved changes"))
                  (sp-author-notes--backup run file)
                  (save-buffer))
                (push file (sp-author-notes--run-filled run))))
          (unless visiting (kill-buffer buffer))))
    (error (sp-author-notes--problem
            run file nil (format "The table was not filled: %s" (error-message-string err))))))

(defun sp-author-notes--litnote-step (run seen file)
  "Check the litnote FILE for RUN; SEEN is the table of the authors found so far."
  (when-let* ((wrapped (sp-author-notes--process-file
                        run file (lambda () (sp-author-notes--litnote-pass run file))))
              (result (car wrapped)))
    (when (or (plist-get result :fixes) (plist-get result :suspects)
              (plist-get result :denoted) (plist-get result :ambiguous)
              (plist-get result :converted) (plist-get result :unparsed))
      (push (cons file result) (sp-author-notes--run-litnotes run)))
    (dolist (author (plist-get result :authors))
      (let ((key (or (car author) (concat "name:" (sp-author-notes--title-key (cdr author))))))
        (unless (gethash key seen)
          (puthash key t seen)
          (push author (sp-author-notes--run-authors run)))))))

(defun sp-author-notes--author-step (run author)
  "Plan the note of AUTHOR, an (ID . NAME) pair, for RUN."
  (pcase-let ((`(,id . ,name) author))
    (if (null id)
        (push (list name nil nil (sp-author-notes--new-note-additions))
              (sp-author-notes--run-people run))
      (let ((entry (gethash id (sp-author-notes--run-by-id run))))
        (cond
         ((null entry))                 ; an orphan ID, in the orphan section
         ((not (sp-author-notes--person-p entry))
          (sp-author-notes--problem
           run (plist-get entry :file) nil
           (format "\"%s\" is linked as an author or editor but is not tagged %s; nothing changed"
                   (plist-get entry :title) sp-author-notes-person-tag)))
         (t
          (when-let* ((wrapped (sp-author-notes--process-file
                                run (plist-get entry :file) #'sp-author-notes--person-pass)))
            (push (list (plist-get entry :title) id (plist-get entry :file)
                        (car wrapped))
                  (sp-author-notes--run-people run)))))))))

(defun sp-author-notes--table-items (run)
  "The author notes of RUN whose tables are to be filled; nil when that cannot be done."
  (if (not (and (fboundp 'vulpea-db-query) (require 'sp-collection-query-tables nil t)))
      (progn
        (sp-author-notes--problem
         run nil nil "Tables not filled: the query tables and vulpea are not loaded")
        nil)
    (seq-filter #'identity (mapcar (lambda (p) (nth 2 p)) (sp-author-notes--run-people run)))))

(defun sp-author-notes--finish-run (run)
  "Put the lists of RUN, which were built back to front, in reading order."
  (setf (sp-author-notes--run-people run) (nreverse (sp-author-notes--run-people run))
        (sp-author-notes--run-orphans run) (nreverse (sp-author-notes--run-orphans run))
        (sp-author-notes--run-tagged run) (nreverse (sp-author-notes--run-tagged run))
        (sp-author-notes--run-saved run) (nreverse (sp-author-notes--run-saved run))
        (sp-author-notes--run-filled run) (nreverse (sp-author-notes--run-filled run))
        (sp-author-notes--run-problems run) (nreverse (sp-author-notes--run-problems run))
        (sp-author-notes--run-created run) (nreverse (sp-author-notes--run-created run))
        (sp-author-notes--run-pending run) (nreverse (sp-author-notes--run-pending run))))

(defun sp-author-notes--run-job (apply callback)
  "Do the whole job in slices, writing files only when APPLY is non-nil.
Call CALLBACK with the run when it is done; return the job.  The stages are
the reading of the author notes, of the litnotes, the planning of each
author note and, when APPLY, the filling of the tables.  Questions are asked
in the middle of a slice, in this Emacs, as they always were."
  (let ((run (sp-author-notes--make-run
              :apply apply
              :stamp (format-time-string "%Y%m%dT%H%M%S")
              :names (make-hash-table :test #'equal)
              :orphan-choices (make-hash-table :test #'equal)
              :backed-up (make-hash-table :test #'equal)))
        (seen (make-hash-table :test #'equal)))
    (sp-async-work-run
     "Author notes"
     (list (list "reading the vault"
                 (lambda ()
                   (sp-author-notes--index-start run)
                   (sp-author-notes--org-files sp-author-notes-directory))
                 (lambda (file _job) (sp-author-notes--index-file run file)))
           (list "checking litnotes"
                 (lambda ()
                   (let ((files (sp-author-notes--org-files
                                 sp-author-notes-litnotes-directory)))
                     (setf (sp-author-notes--run-litnote-count run) (length files))
                     files))
                 (lambda (file _job) (sp-author-notes--litnote-step run seen file)))
           (list "author notes"
                 (lambda ()
                   (setf (sp-author-notes--run-litnotes run)
                         (nreverse (sp-author-notes--run-litnotes run))
                         (sp-author-notes--run-authors run)
                         (nreverse (sp-author-notes--run-authors run)))
                   (sp-author-notes--run-authors run))
                 (lambda (author _job) (sp-author-notes--author-step run author)))
           (list "filling tables"
                 (lambda () (and apply (sp-author-notes--table-items run)))
                 (lambda (file _job) (sp-author-notes--populate run file))))
     :done (lambda (_job)
             (sp-author-notes--finish-run run)
             (funcall callback run)))))

(defun sp-author-notes--run (apply)
  "Do the whole job at once, writing files only when APPLY is non-nil.  Return the run.
The commands use `sp-author-notes--run-job', which does it in slices."
  (let ((sp-async-work-synchronous t) result)
    (sp-author-notes--run-job apply (lambda (run) (setq result run)))
    result))

(defun sp-author-notes--short (file)

  (let ((root (file-name-as-directory (expand-file-name sp-author-notes-directory))))

`d' drops KEY from the plan, by default FILE."
  (insert (if (or file key)
              (propertize text 'sp-author-file file 'sp-author-line line
                          'sp-author-key (or key file))
            text)
          "\n"))

(defun sp-author-notes--heading (title count)
  "Insert a section heading TITLE with COUNT."
  (insert "\n" (propertize (format "%s (%d)" title count) 'face 'bold) "\n"))

(defun sp-author-notes--change-count (run)
  "The number of changes RUN made or would make."
  (+ (apply #'+ (mapcar (lambda (e) (+ (length (plist-get (cdr e) :fixes))
                                       (length (plist-get (cdr e) :converted))))
                        (sp-author-notes--run-litnotes run)))
     (apply #'+ (mapcar (lambda (e) (length (plist-get (cdr e) :denoted)))
                        (sp-author-notes--run-litnotes run)))

     (length (sp-author-notes--run-pending run))

     (length (sp-author-notes--run-saved run))
     (length (seq-filter (lambda (o) (nth 4 o)) (sp-author-notes--run-orphans run)))

(defun sp-author-notes--render (run)
  "Insert the report of RUN in the current buffer."
  (let ((apply (sp-author-notes--run-apply run))
        (lits (sp-author-notes--run-litnotes run))
        (people (sp-author-notes--run-people run)))
    (insert (propertize (if apply "Author notes: DONE" "Author notes: PREVIEW, nothing has been written")
                        'face 'bold)
            (format "\n%d literature notes read in %s; %d author%s; %d change%s\n"
                    (sp-author-notes--run-litnote-count run)
                    (abbreviate-file-name sp-author-notes-litnotes-directory)
                    (length (sp-author-notes--run-authors run))
                    (if (= 1 (length (sp-author-notes--run-authors run))) "" "s")
                    (sp-author-notes--change-count run)
                    (if (= 1 (sp-author-notes--change-count run)) "" "s")))
    (when (and apply sp-author-notes-backup-directory (> (sp-author-notes--change-count run) 0))
      (insert (format "Originals copied to %s%s/\n"
                      (abbreviate-file-name sp-author-notes-backup-directory)
                      (sp-author-notes--run-stamp run))))
    ;; Typos
    (let ((fixes (cl-loop for (file . r) in lits
                          append (mapcar (lambda (f) (cons file f)) (plist-get r :fixes))))
          (suspects (cl-loop for (file . r) in lits
                             append (mapcar (lambda (f) (cons file f)) (plist-get r :suspects)))))
      (sp-author-notes--heading (if apply "Meta key typos fixed" "Meta key typos to fix") (length fixes))
      (if (null fixes) (insert "  none\n")
        (dolist (f fixes)
          (sp-author-notes--insert-line
           (format "  %s:%d  %s -> %s" (sp-author-notes--short (car f)) (cddr f)
                   (cadr f) (or (cdr (sp-author-notes--key-state (cadr f))) sp-author-notes-key))
           (car f) (cddr f))))
      (when suspects
        (sp-author-notes--heading "Possible typos, not changed" (length suspects))
        (dolist (f suspects)
          (sp-author-notes--insert-line
           (format "  %s:%d  %s" (sp-author-notes--short (car f)) (cddr f) (cadr f))
           (car f) (cddr f)))))
    ;; Created
    (let ((made (if apply
                    (mapcar (lambda (c) (list (nth 0 c) (nth 2 c)))
                            (sp-author-notes--run-created run))
                  (mapcar #'list (sp-author-notes--run-pending run)))))
      (sp-author-notes--heading (if apply "Author notes created" "Author notes to create") (length made))
      (if (null made) (insert "  none\n")
        (dolist (m made)
          (sp-author-notes--insert-line
           (format "  %s%s" (car m) (if (cadr m) (format "  (%s)" (sp-author-notes--short (cadr m))) ""))
           (cadr m) nil (concat "name:" (sp-author-notes--title-key (car m)))))))
    ;; Converted
    (let ((conv (cl-loop for (file . r) in lits
                         append (mapcar (lambda (c) (cons file c)) (plist-get r :converted)))))
      (sp-author-notes--heading (if apply "Plain names turned into links" "Plain names to turn into links") (length conv))
      (if (null conv) (insert "  none\n")
        (dolist (c conv)
          (sp-author-notes--insert-line
           (format "  %s:%d  %s" (sp-author-notes--short (car c)) (nth 3 c) (nth 1 c))
           (car c) (nth 3 c)))))
    ;; Disambiguation
    (let ((amb (cl-loop for (file . r) in lits
                        append (mapcar (lambda (a) (cons file a)) (plist-get r :ambiguous)))))
      (sp-author-notes--heading "Lists of names with commas, to disambiguate" (length amb))
      (if (null amb) (insert "  none\n")
        (dolist (a amb)
          (pcase-let ((`(,file ,raw ,names ,line ,chosen) (list (car a) (nth 1 a) (nth 2 a) (nth 3 a) (nth 4 a))))
            (sp-author-notes--insert-line
             (format "  %s:%d  \"%s\"\n      as %d: %s\n      %s"
                     (sp-author-notes--short file) line raw (length names)
                     (string-join names " | ")
                     (cond (chosen "split into these authors")
                           (apply "left as it is")
                           (t "will ask whether to split it")))
             file line)))))
    ;; Denote links
    (let ((den (cl-loop for (file . r) in lits
                        append (mapcar (lambda (d) (cons file d)) (plist-get r :denoted)))))
      (sp-author-notes--heading (if apply "Denote links turned into ID links"
                                  "Denote links to turn into ID links")
                                (length den))
      (if (null den) (insert "  none\n")
        (dolist (d den)
          (sp-author-notes--insert-line
           (format "  %s:%d  denote:%s -> id:%s" (sp-author-notes--short (car d)) (nth 3 d)
                   (nth 1 d) (nth 2 d))
           (car d) (nth 3 d)))))
    ;; Tagged
    (let ((tagged (sp-author-notes--run-tagged run)))
      (sp-author-notes--heading (if apply "Notes tagged for authors" "Notes to tag as authors") (length tagged))
      (if (null tagged) (insert "  none\n")
        (dolist (tg tagged)
          (sp-author-notes--insert-line
           (format "  %s  + :%s:" (nth 0 tg) sp-author-notes-person-tag) (nth 2 tg)))))
    ;; Saved buffers
    (let ((saved (sp-author-notes--run-saved run)))
      (sp-author-notes--heading (if apply "Buffers saved first (they had unsaved changes)"
                                  "Buffers that will be saved first (unsaved changes)")
                                (length saved))
      (if (null saved) (insert "  none\n")
        (dolist (f saved)
          (sp-author-notes--insert-line (format "  %s" (sp-author-notes--short f)) f))))
    ;; Orphan IDs
    (let ((orphans (sp-author-notes--run-orphans run)))
      (sp-author-notes--heading "Links to an ID that no note has" (length orphans))
      (if (null orphans) (insert "  none\n")
        (dolist (o orphans)
          (pcase-let ((`(,file ,line ,id ,desc ,new ,suggestion) o))
            (sp-author-notes--insert-line
             (format "  %s:%d  %s (\"%s\")  %s" (sp-author-notes--short file) line id (or desc "")
                     (cond (new (format "-> redirected to %s"
                                        (plist-get (gethash new (sp-author-notes--run-by-id run)) :title)))
                           (apply "left as it is")
                           (suggestion (format "will ask; suggestion: %s" suggestion))
                           (t "will ask where it should point")))
             file line)))))
    ;; Author notes
    (let ((changed (seq-filter (lambda (p) (nth 3 p)) people))
          (same (seq-remove (lambda (p) (nth 3 p)) people)))
      (sp-author-notes--heading (if apply "Author notes updated" "Author notes to update") (length changed))
      (if (null changed) (insert "  none\n")
        (dolist (p changed)
          (sp-author-notes--insert-line
           (format "  %s  + %s" (nth 0 p) (mapconcat #'symbol-name (nth 3 p) ", "))
           (nth 2 p))))
      (sp-author-notes--heading "Author notes already complete" (length same))
      (dolist (p same)
        (sp-author-notes--insert-line (format "  %s" (nth 0 p)) (nth 2 p)))
      (when apply
        (sp-author-notes--heading "Tables filled" (length (sp-author-notes--run-filled run)))
        (insert (format "  %d, from the vulpea database; if the links were only just written and the database\n  has not caught up, update a table with C-c C-c\n"
                        (length (sp-author-notes--run-filled run))))))
    ;; Problems
    (let ((unparsed (cl-loop for (file . r) in lits
                             append (mapcar (lambda (u) (cons file u)) (plist-get r :unparsed))))
          (problems (sp-author-notes--run-problems run)))
      (sp-author-notes--heading "Left alone, needs you" (+ (length problems) (length unparsed)))
      (if (and (null problems) (null unparsed)) (insert "  none\n")
        (dolist (u unparsed)
          (sp-author-notes--insert-line
           (format "  %s:%d  value mixes links and other text: %s"
                   (sp-author-notes--short (car u)) (cddr u) (cadr u))
           (car u) (cddr u)))
        (dolist (p problems)
          (sp-author-notes--insert-line
           (format "  %s%s  %s" (sp-author-notes--short (nth 0 p))
                   (if (nth 1 p) (format ":%d" (nth 1 p)) "") (nth 2 p))
           (nth 0 p) (nth 1 p)))))
    ;; Dropped
    (when sp-author-notes--excluded
      (sp-author-notes--heading "Dropped from the list (u brings one back)"
                                (length sp-author-notes--excluded))
      (dolist (key sp-author-notes--excluded)
        (sp-author-notes--insert-line
         (format "  %s" (if (string-prefix-p "name:" key)
                           (format "author %s" (substring key 5))
                         (sp-author-notes--short key)))
         nil nil key)))
    (insert (if apply
                "\nRET visit   g preview again\n"
              "\nRET visit   d drop the candidate on the line   u restore   A write what is left   g refresh\n"))))

(defun sp-author-notes--show (run)

  (with-current-buffer (get-buffer-create sp-author-notes--buffer-name)
    (sp-author-notes-report-mode)
    (let ((inhibit-read-only t))
      (erase-buffer)
      (sp-author-notes--render run)
      (goto-char (point-min)))
    (pop-to-buffer (current-buffer)))
  run)

(defun sp-author-notes-visit ()

    (unless file (user-error "No file on this line"))
    (find-file-other-window file)
    (when line
      (goto-char (point-min))
      (forward-line (1- line)))))

(defun sp-author-notes--duplicate-groups (run)
  "The groups of person notes in RUN that share a title key: lists of index entries."
  (let (groups)
    (maphash
     (lambda (_key entries)
       (let ((people (seq-uniq
                      (seq-filter (lambda (e) (and (sp-author-notes--person-p e) (plist-get e :id)))
                                  entries)
                      (lambda (a b) (equal (plist-get a :id) (plist-get b :id))))))
         (when (cdr people) (push people groups))))
     (sp-author-notes--run-by-title run))
    groups))

(defun sp-author-notes--relink-pass (table)
  "Point the person links of the buffer at other notes; return how many changed.
TABLE maps an ID to (NEW-ID . NEW-TITLE)."
  (let ((count 0))
    (dolist (entry (sp-author-notes--meta-entries))
      (when (and (member (plist-get entry :key) sp-author-notes-person-keys)
                 (plist-get entry :value))
        (let* ((value (plist-get entry :value))
               (new (replace-regexp-in-string
                     sp-author-notes--id-link-re
                     (lambda (m)
                       (save-match-data
                         (string-match sp-author-notes--id-link-re m)
                         (if-let* ((to (gethash (match-string 1 m) table)))
                             (progn (cl-incf count) (format "[[id:%s][%s]]" (car to) (cdr to)))
                           m)))
                     value t t)))
          (unless (equal new value)
            (sp-author-notes--replace (plist-get entry :value-beg) (plist-get entry :value-end) new)))))
    count))

(defun sp-author-notes-normalize-duplicates ()
  "Offer to use one note for each person that has several notes spelled alike.
Notes whose titles differ only in accents or case (Søren and Soren Kierkegaard)
form a group.  For each group you pick the note to keep; then, after one question,
the author and editor links of the litnotes that point at the other notes are
pointed at the kept one, with backups.  The other notes are not merged or
deleted: they are listed, so you can merge them."
  (interactive)
  (let* ((sp-async-work-synchronous t)
         (run (sp-author-notes--make-run
               :apply t :stamp (format-time-string "%Y%m%dT%H%M%S")
               :names (make-hash-table :test #'equal)
               :orphan-choices (make-hash-table :test #'equal)
               :backed-up (make-hash-table :test #'equal)))
         (table (make-hash-table :test #'equal))
         losers)
    (sp-author-notes--index-start run)
    (dolist (file (sp-author-notes--org-files sp-author-notes-directory))
      (sp-author-notes--index-file run file))
    (let ((groups (sp-author-notes--duplicate-groups run)))
      (if (null groups)
          (message "No person notes spell a name alike")
        (dolist (group groups)
          (when-let* ((keep (funcall sp-author-notes-duplicate-function group)))
            (dolist (e group)
              (unless (equal (plist-get e :id) (plist-get keep :id))

* sp-author-notes-bibtex.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/funct/sp-author-notes-bibtex.el
:END:

The =Works= table that [[*sp-author-notes.el][sp-author-notes]] puts in an author note lists the literature notes that name the author. A work that is only a BibTeX entry, with no literature note yet, is not in it. =M-x sp-author-notes-bibtex= adds that second view, the /additional/ works:

1. Reads every =.bib= file of =sp-bibtex-files= (the list =sp-bibtex-register= keeps, from =sp-bibliography-dir=), keys like =smith2020attention=.
2. Takes every =:person:= note of the vault and compares its title with the =author= field of each entry. A name matches /exactly/ when both read the same after flipping =Last, First= to =First Last=; it is a /possible/ match when the last name and the first initial agree (=J. Smith= and =John Smith=).
3. Leaves out the entries that already have a literature note: a note in =litnotes/= whose head (the property drawer and the =#+= lines) or file name holds the key, as in =REFERENCES=, =ROAM_REFS=, =#+reference:= or =@key=.
4. Shows the rest in a report buffer, one section per author note, with the key, year, title, =.bib= file and how sure the match is.

The people are not compared with every entry: the entries without a litnote are indexed once by the full name and by the last name with the first initial of each author, and a person looks up only the entries under their own keys. (Comparing everyone with everything took seconds per person with a 40,000-entry =master.bib=, so the command seemed to hang even in slices.) A file that is missing from =sp-bibtex-files= is reported in the echo area and skipped; if none can be read, or there is none, the command stops with a =user-error= that names the files and suggests =sp-bibtex-register=.

*Runs in the background.* The =.bib= files (200 entries per slice, so a big file does not hold Emacs), the litnotes and the author notes are read in slices (see [[file:sp-async-work.org][sp-async-work]]); the progress is in the mode line and the report opens, or refreshes, when the reading is done.

In the report buffer:

- =c= offers to create a literature note for the entry at point; =C= offers it for every /exact/ entry in the section at point (possible matches are only made one at a time). Both ask first.
- =RET= visits the BibTeX entry; =o= visits the author note; =g= reads everything again.

The note itself is made by =sp-author-notes-bibtex-create-function=, =citar-create-note= by default, which follows the =citar-denote= / =citar-vulpea= settings of [[file:../academic/sp-academic.org::*sp-litnotes.el][sp-litnotes]] (so the title template and the =litnotes/= folder are theirs). Because those templates do not know the author note, the new note gets a =- pub-author :: [[id:...][Name]]= line afterwards (=sp-author-notes-bibtex-link-author=), which is what puts it in the =Works= table of the author. If the match was only "possible" the line is added too, as you chose to create the note under that author.

The module changes nothing but that: it never edits a =.bib= file or an author note, and it writes the line into the new note only. A new note whose buffer has unsaved changes is left alone and reported in the echo area.

Not done: a BibTeX entry with several authors is listed under each author note it matches; names are compared as plain text, so spelling variants (=Müller=, =Mueller=) are not matched.

(defun sp-author-notes-bibtex--files ()
  "The readable .bib files: `sp-bibtex-files', else those of `sp-bibliography-dir'.
Signal a `user-error' that says what is wrong when there is none.  A file
of the list that is missing is reported with `message' and skipped."
  (let* ((listed (cond ((and (boundp 'sp-bibtex-files) sp-bibtex-files) sp-bibtex-files)
                       ((and (boundp 'sp-bibliography-dir) sp-bibliography-dir
                             (file-directory-p sp-bibliography-dir))
                        (directory-files sp-bibliography-dir t "\\`[[:alnum:]].*\\.bib\\'"))))
         (readable (seq-filter #'file-readable-p listed))
         (missing (seq-remove #'file-readable-p listed)))
    (cond
     ((null listed)
      (user-error "No BibTeX files: `sp-bibtex-files' is empty and `sp-bibliography-dir' (%s) has no .bib file; run `sp-bibtex-register'"
                  (if (boundp 'sp-bibliography-dir) sp-bibliography-dir "unset")))
     ((null readable)
      (user-error "None of the BibTeX files can be read: %s" (string-join missing ", ")))
     (t (when missing
          (message "sp-author-notes-bibtex: skipping unreadable BibTeX file%s: %s"
                   (if (cdr missing) "s" "") (string-join missing ", ")))
        readable))))

(defun sp-author-notes-bibtex--split-authors (field)
  "The names in the BibTeX author FIELD, flipped to First Last, braces removed."
  (mapcar #'sp-author-notes--clean-name
          (split-string (replace-regexp-in-string "[ \t\n]+" " " field)
                        "[ \t]+and[ \t]+" t "[ \t]+")))

(defun sp-author-notes-bibtex--parse-some (file limit)
  "Parse the entries of FILE from point in the current buffer, at most LIMIT of them.
LIMIT nil means all.  Return (ENTRIES . MORE); MORE is non-nil when LIMIT
was reached, so that the end of the buffer may not be."
  (let ((count 0) entries)
    (while (and (or (null limit) (< count limit))
                (re-search-forward "^[ \t]*@[[:alpha:]]+[ \t]*[{(]" nil t))
      (cl-incf count)
      (let ((beg (match-beginning 0)))
        (goto-char beg)
        (when-let* ((entry (ignore-errors (bibtex-parse-entry t)))
                    (key (cdr (assoc "=key=" entry)))
                    (author (cdr (assoc "author" entry))))
          (push (list :key key
                      :title (replace-regexp-in-string
                              "[{}]" "" (or (cdr (assoc "title" entry)) ""))
                      :year (or (cdr (assoc "year" entry)) "")
                      :authors (sp-author-notes-bibtex--split-authors author)
                      :file file :pos beg)
                entries))
        (goto-char (min (point-max) (1+ beg)))))
    (cons (nreverse entries) (and limit (>= count limit)))))

(defun sp-author-notes-bibtex--entries (files)
  "The entries of the .bib FILES as plists (:key :title :year :authors :file :pos)."
  (let (entries)
    (dolist (file files)
      (when (file-readable-p file)
        (with-temp-buffer
          (insert-file-contents file)
          (delay-mode-hooks (bibtex-mode))
          (goto-char (point-min))
          (setq entries (append entries (car (sp-author-notes-bibtex--parse-some file nil)))))))
    entries))

(defun sp-author-notes-bibtex--match (person author)
  "How the name AUTHOR matches the title PERSON: `exact', `possible' or nil."
  (let ((p (sp-author-notes--title-key (sp-author-notes--clean-name person)))
        (a (sp-author-notes--title-key author)))
    (if (equal p a)
        'exact
      (let ((pw (split-string p "[ .]+" t))
            (aw (split-string a "[ .]+" t)))
        (when (and (cdr pw) (cdr aw)
                   (equal (car (last pw)) (car (last aw)))
                   (eq (aref (car pw) 0) (aref (car aw) 0)))
          'possible)))))

(defun sp-author-notes-bibtex--cover-file (table file)

(defun sp-author-notes-bibtex--covered ()
  "A hash table: every word in the head or the file name of a litnote to its file.
A BibTeX key is covered when it is such a word, which holds for
REFERENCES, ROAM_REFS, #+reference: and @key alike."
  (let ((table (make-hash-table :test #'equal)))
    (dolist (file (sp-author-notes--org-files sp-author-notes-litnotes-directory))
      (sp-author-notes-bibtex--cover-file table file))

(defun sp-author-notes-bibtex--possible-key (name)
  "The key under which the author NAME can be a possible match, or nil.
It is the last word and the first letter of the first word, as
`sp-author-notes-bibtex--match' compares them."
  (let ((words (split-string (sp-author-notes--title-key
                              (sp-author-notes--clean-name name))
                             "[ .]+" t)))
    (when (cdr words)
      (cons (car (last words)) (aref (car words) 0)))))

(defun sp-author-notes-bibtex--index-entry (index entry covered)
  "Add ENTRY to INDEX unless its key is in COVERED.
INDEX is (EXACT POSSIBLE . ORDER): two hash tables from the name key and
from the possible key of an author to the entries, and a hash table from an
entry to its number.  Looking a person up in them replaces comparing the
person with every author of every entry, which took hours with thousands of
people and tens of thousands of entries."
  (let ((exact (car index)) (possible (cadr index)) (order (cddr index)))
    (puthash entry (hash-table-count order) order)
    (unless (gethash (plist-get entry :key) covered)
      (dolist (author (plist-get entry :authors))
        (push entry (gethash (sp-author-notes--title-key author) exact))
        (when-let* ((key (sp-author-notes-bibtex--possible-key author)))
          (push entry (gethash key possible)))))))

(defun sp-author-notes-bibtex--make-index ()
  "An empty index for `sp-author-notes-bibtex--index-entry'."
  (cl-list* (make-hash-table :test #'equal :size 4096)
         (make-hash-table :test #'equal :size 4096)
         (make-hash-table :test #'eq :size 4096)))

(defun sp-author-notes-bibtex--matches (person index)
  "The matches of PERSON in INDEX: a list of (ENTRY . CONFIDENCE).
INDEX is the one `sp-author-notes-bibtex--index-entry' fills with the entries
that have no litnote.  Only the entries that share the name or the last name
and initial with PERSON are compared."
  (let ((title (plist-get person :title))
        (candidates (make-hash-table :test #'eq))
        (order (cddr index))
        matches)
    (dolist (entry (gethash (sp-author-notes--title-key
                             (sp-author-notes--clean-name title))
                            (car index)))
      (puthash entry t candidates))
    (when-let* ((key (sp-author-notes-bibtex--possible-key title)))
      (dolist (entry (gethash key (cadr index)))
        (puthash entry t candidates)))
    (maphash
     (lambda (entry _)
       (when-let* ((conf (cl-loop for a in (plist-get entry :authors)
                                  for m = (sp-author-notes-bibtex--match title a)
                                  when (eq m 'exact) return 'exact
                                  when m collect m into found
                                  finally return (car found))))
         (push (cons entry conf) matches)))
     candidates)
    (when matches
      ;; In the order of the files, then by year (`sort' is stable).
      (setq matches (sort matches (lambda (a b) (< (gethash (car a) order)
                                                   (gethash (car b) order)))))
      (sort matches
            (lambda (a b)
              (string< (or (plist-get (car a) :year) "")
                       (or (plist-get (car b) :year) "")))))))

(defun sp-author-notes-bibtex--bib-step (item job add)
  "Read some entries of the .bib file ITEM, and call ADD with them.
ITEM is a file name, or (FILE . BUFFER) for one that is half read; the rest
of a big file is pushed to JOB, so that no slice parses it all."
  (let* ((file (if (consp item) (car item) item))
         (buffer (if (consp item)
                     (cdr item)
                   (when (file-readable-p file)
                     (let ((b (generate-new-buffer " *sp-author-works bib*")))
                       (sp-async-work-on-cleanup job (lambda () (kill-buffer b)))
                       (with-current-buffer b
                         (insert-file-contents file)
                         (delay-mode-hooks (bibtex-mode))
                         (goto-char (point-min)))
                       b)))))
    (when buffer
      (let ((result (with-current-buffer buffer
                      (sp-author-notes-bibtex--parse-some file 200))))
        (funcall add (car result))
        (if (cdr result)
            (sp-async-work-push job (cons file buffer))
          (kill-buffer buffer))))))

(defun sp-author-notes-bibtex--compute-job (callback)
  "Find the additional works in slices and call CALLBACK with the list.
The list is the one `sp-author-notes-bibtex--compute' returns.  Return the job."
  (let ((files (sp-author-notes-bibtex--files)) ; a user-error here reaches the command
        (index (sp-author-notes-bibtex--make-index))
        entries people result
        (covered (make-hash-table :test #'equal)))
    (sp-async-work-run
     "Author works"
     (list (list "reading BibTeX" (lambda () files)
                 (lambda (item job)
                   (sp-author-notes-bibtex--bib-step
                    item job (lambda (found) (dolist (e found) (push e entries))))))
           (list "reading litnotes"
                 (lambda () (sp-author-notes--org-files sp-author-notes-litnotes-directory))
                 (lambda (file _job) (sp-author-notes-bibtex--cover-file covered file)))
           (list "reading authors"
                 (lambda () (sp-author-notes--org-files sp-author-notes-directory))
                 (lambda (file _job)
                   (let ((head (sp-author-notes--file-head file)))
                     (when (sp-author-notes-bibtex--person-p head) (push head people)))))
           (list "indexing"
                 (lambda () (nreverse entries))
                 (lambda (entry _job)
                   (sp-author-notes-bibtex--index-entry index entry covered)))
           (list "matching"
                 (lambda () (nreverse people))
                 (lambda (person _job)
                   (when-let* ((matches (sp-author-notes-bibtex--matches person index)))
                     (push (cons person matches) result)))))
     :done (lambda (_job) (funcall callback (nreverse result))))))

MATCHES is a list of (ENTRY . CONFIDENCE).  Only people with at least one entry that has no literature note are listed.  `sp-author-notes-bibtex' finds them in slices instead."
  (let ((sp-async-work-synchronous t) groups)
    (sp-author-notes-bibtex--compute-job (lambda (found) (setq groups found)))
    groups))

(defun sp-author-notes-bibtex--add-author (file person)
  "Add a pub-author line for the PERSON plist to the litnote FILE, if it has none.
Return non-nil when the line was added."
  (let ((buf (find-buffer-visiting file)))
    (unless (and buf (buffer-modified-p buf))
      (with-current-buffer (or buf (find-file-noselect file))
        (save-excursion
          (save-restriction
            (widen)
            (goto-char (point-min))
            (let ((limit (sp-author-notes--first-heading))
                  (case-fold-search t))
              (unless (re-search-forward
                       (format "^-[ \t]+%s[ \t]+::" (regexp-quote sp-author-notes-key)) limit t)
                (goto-char (point-min))
                (if (re-search-forward "^-[ \t]+[^ \t\n:]+[ \t]+::.*$" limit t)
                    (progn (while (re-search-forward "^-[ \t]+[^ \t\n:]+[ \t]+::.*$" limit t))
                           (end-of-line)
                           (insert "\n"))
                  (goto-char limit)
                  (unless (bolp) (insert "\n"))
                  (insert "\n"))
                (insert (format "- %s :: [[id:%s][%s]]"
                                sp-author-notes-key (plist-get person :id)
                                (plist-get person :title)))
                (unless (eq (char-after) ?\n) (insert "\n"))
                (save-buffer)
                (unless buf (kill-buffer))
                t))))))))

- [[https://github.com/siainbuletin/dotfiles/pull/194][#194]] ✨ Added the module. Follows #193. Not run in the real vault, with =citar= or in a GUI.

* sp-litnotes-refs.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/academic/sp-litnotes-refs.el
:END:

Moves the reference of each literature note from the =#+reference:= keyword of =citar-denote= to the =ROAM_REFS= property that =citar-vulpea= reads. Required by =sp-litnotes=.

*Runs in the background.* The notes are read and written in slices (see [[file:sp-async-work.org][sp-async-work]]), so Emacs stays usable: the progress is in the mode line, =M-x sp-async-work-cancel= stops the job, and the report opens when the reading is done. =sp-litnotes-refs-convert= asks its (up to three) questions as soon as the report is open, before any writing, so nothing asks you anything while you work on something else. A note is written only if it still reads as it did in the report; a note with unsaved changes in its buffer is skipped, and an open buffer without changes is reverted.

- =M-x sp-litnotes-refs-dryrun= is a dry run: it writes nothing and shows a report in =*litnote refs*=.
- =M-x sp-litnotes-refs-convert= shows the same report and then asks up to three questions, each only when there is something to do: move the references of the notes that have an ID; create an ID for the notes that have none; add stub entries to the inbox BibTeX file. Every note it changes, and the inbox file, is copied to =litnote-refs-backups/= under =sp-var-dir= first. It is safe to run again.
- What it does to a note in =sp-litnotes-refs-directory= (default =~/notes/litnotes/=):
  - =convert=: no =ROAM_REFS=, has =#+reference: key=. It adds =:ROAM_REFS: @key= to the top property drawer and removes the keyword.
  - =merge=: has both. The keys are joined (no key twice) and the keyword is removed.
  - =normalise=: =ROAM_REFS= holds the key as =key=, =cite:key= or =[cite:@key]=. It is rewritten as =@key=; URLs and DOIs in the value are kept as they are. =citar-vulpea= only reads =@key=, so a bare key is invisible to it.
  - =ok= and =no-reference= notes are not touched.
  - =no-id=: the note has no top-level property drawer with an =:ID:=, so it is not a file-level Vulpea node. If you agree to the second question, the note gets a property drawer with a new =:ID:= (an =org-id= UUID) and its =ROAM_REFS=, and loses its =#+reference:= keyword. Otherwise it is listed and skipped.
- The report also shows:
  - keys that no registered =.bib= file has (=sp-bibtex-files=),
  - keys used by more than one note,
  - for every key whether a PDF named after it is in =sp-literature-dir=, or only one named after its =crossref= parent (a book section whose PDF is the book). The later DEVONthink link needs this: see [[file:../../architecture/devonthink-emacs-integration.org][DEVONthink and Emacs]].
- Stub entries: a key (from any note, with or without an ID) that no registered =.bib= file has gets a stub in =sp-litnotes-refs-inbox-bib= (default =master.bib= in =sp-bibliography-dir=), which is the inbox of the bibliography. The entry type comes from the file tag of the note (=journalarticle= is =article=, =booksection= is =incollection=, =book=, =collection=, =inreference=, =phdthesis=; anything else =misc=); the title is =pub-title= or, if that is missing or equals the key, the note title; =author=, =year= and =pages= come from =pub-author=, =pub-year= and =pub-pages=, with links reduced to their text; =file= is added only when =KEY.pdf= exists in =sp-literature-dir=; a =note= field says which litnote the stub came from, and =DATE_ADDED= is the time. A key used by several notes gets one stub. The old keys of Denote-era notes (such as =kant2009ideea=) have no entry, so each gets a stub under that old key; renaming them to the new scheme is a separate job.
- BibTeX files are read with a small scanner (entry key and =crossref= field only), not a full parser.
- The =#+reference:= keyword is deleted from converted notes, so the Denote-based commands no longer find the key. The backup folder has the old files.

;;; Commentary:

;; `citar-denote' stored a note's citation key in a `#+reference:' keyword.
;; `citar-vulpea' reads `@key' values from a property, `ROAM_REFS'.  This module
;; reports what would change (`sp-litnotes-refs-dryrun') and then converts the
;; notes (`sp-litnotes-refs-convert').  Nothing is written by the report.

;;; Code:

(require 'cl-lib)
(require 'subr-x)
(require 'sp-async-work)

(defvar sp-notes-dir)
(defvar sp-var-dir)
(defvar sp-literature-dir)
(defvar sp-bibtex-files)
(defvar sp-bibliography-dir)

(defgroup sp-litnotes-refs nil
  "Convert literature note references to ROAM_REFS."
  :group 'sp-academic)

(defcustom sp-litnotes-refs-directory
  (expand-file-name "litnotes/" (if (boundp 'sp-notes-dir) sp-notes-dir "~/notes"))
  "Folder with the literature notes."
  :type 'directory)

(defcustom sp-litnotes-refs-backup-directory
  (expand-file-name "litnote-refs-backups/"
                    (if (boundp 'sp-var-dir) sp-var-dir user-emacs-directory))
  "Folder where `sp-litnotes-refs-convert' copies each note before changing it."
  :type 'directory)

(defcustom sp-litnotes-refs-inbox-bib
  (expand-file-name "master.bib"
                    (if (boundp 'sp-bibliography-dir) sp-bibliography-dir "~/Documents/bibliography/"))
  "BibTeX file, the inbox, where stub entries are added for keys that no .bib has."
  :type 'file)

(defconst sp-litnotes-refs--key-regexp "\\`[[:alnum:]_:-]+\\'"
  "Regexp for a citation key; the same characters `citar-vulpea' accepts.")

;;;; Reading references

(defun sp-litnotes-refs--tokens (string)
  "Split the reference STRING into (KEYS . OTHERS).
KEYS are citation keys without a prefix; OTHERS are values that are not keys
(URLs, DOIs) and are kept as they are.  `@key', `key', `cite:key' and
`[cite:@a;@b]' are all read."
  (let ((clean (replace-regexp-in-string "\\[cite[^:]*:\\|\\]" "" (or string "")))
        keys others)
    (dolist (token (split-string clean "[ \t;,]+" t))
      (let ((bare (replace-regexp-in-string "\\`\\(cite:\\)?@?" "" token)))
        (cond ((string-match-p "\\`https?:\\|\\`doi:\\|/" token) (push token others))
              ((string-match-p sp-litnotes-refs--key-regexp bare) (push bare keys))
              (t (push token others)))))
    (cons (nreverse keys) (nreverse others))))

(defconst sp-litnotes-refs--meta-keys '("pub-title" "pub-author" "pub-year" "pub-pages")
  "Metadata of a litnote that a stub BibTeX entry takes over.")

(defun sp-litnotes-refs--clean-value (value)
  "VALUE without quotes, and with Org links reduced to their text."
  (let* ((v (string-trim value))
         (v (replace-regexp-in-string "\\[\\[[^]]*\\]\\[\\([^]]*\\)\\]\\]" "\\1" v))
         (v (replace-regexp-in-string "\\[\\[[^]]*\\]\\]" "" v))
         (v (replace-regexp-in-string "\\`\"\\(.*\\)\"\\'" "\\1" v)))
    (string-trim v)))

(defun sp-litnotes-refs--parse (file)
  "Read the reference data of the note FILE as a plist.
The keys are :file, :id, :roam (the =ROAM_REFS= value), :keyword (the
=#+reference:= value) and :drawer (non-nil when the note starts with a
property drawer, which a file-level Vulpea node needs)."
  (with-temp-buffer
    (insert-file-contents file)
    (let (id roam keyword title tags meta drawer-end (case-fold-search t))
      (goto-char (point-min))
      (when (looking-at ":PROPERTIES:[ \t]*$")
        (when (re-search-forward "^:END:[ \t]*$" nil t)
          (setq drawer-end (line-beginning-position))
          (goto-char (point-min))
          (when (re-search-forward "^:ID:[ \t]+\\(.+\\)$" drawer-end t)
            (setq id (match-string 1)))
          (goto-char (point-min))
          (when (re-search-forward "^:ROAM_REFS:[ \t]*\\(.*\\)$" drawer-end t)
            (setq roam (string-trim (match-string 1))))))
      (goto-char (point-min))
      (when (re-search-forward "^#\\+reference:[ \t]*\\(.*\\)$" nil t)
        (setq keyword (string-trim (match-string 1))))
      (goto-char (point-min))
      (when (re-search-forward "^#\\+title:[ \t]*\\(.*\\)$" nil t)
        (setq title (string-trim (match-string 1))))
      (goto-char (point-min))
      (when (re-search-forward "^#\\+filetags:[ \t]*\\(.*\\)$" nil t)
        (setq tags (split-string (match-string 1) "[: \t]+" t)))
      (dolist (key sp-litnotes-refs--meta-keys)
        (goto-char (point-min))
        (when (re-search-forward
               (format "^\\(?:- +\\|:\\)%s\\(?: ?::\\|:\\)[ \t]*\\(.+\\)$" (regexp-quote key)) nil t)
          (push (cons key (sp-litnotes-refs--clean-value (match-string 1))) meta)))
      (list :file file :id id :roam roam :keyword keyword :title title :tags tags
            :meta meta :drawer (and drawer-end t)))))

;;;; Planning

(defun sp-litnotes-refs--plan (parsed)
  "Say what to do with the note PARSED (see `sp-litnotes-refs--parse').
Returns PARSED plus :status and :refs, the new =ROAM_REFS= value.  The status is
one of `no-id', `no-reference', `ok', `normalise', `convert' and `merge'."
  (let* ((roam (and parsed (plist-get parsed :roam)))
         (roam (and roam (not (string-empty-p roam)) roam))
         (keyword (let ((k (plist-get parsed :keyword)))
                    (and k (not (string-empty-p k)) k)))
         (from-roam (sp-litnotes-refs--tokens roam))
         (from-key (sp-litnotes-refs--tokens keyword))
         (keys (delete-dups (append (car from-roam) (car from-key))))
         (others (delete-dups (append (cdr from-roam) (cdr from-key))))
         (refs (string-join (append (mapcar (lambda (k) (concat "@" k)) keys) others) " "))
         (status (cond ((not (and (plist-get parsed :drawer) (plist-get parsed :id))) 'no-id)
                       ((and (not roam) (not keyword)) 'no-reference)
                       ((not keyword) (if (equal roam refs) 'ok 'normalise))
                       (roam 'merge)
                       (t 'convert))))
    (append parsed (list :status status :keys keys :refs refs))))

(defun sp-litnotes-refs--bib-index-file (file table)
  "Add the keys of the BibTeX FILE to the hash table TABLE (key to crossref or :none)."
  (when (file-readable-p file)
    (with-temp-buffer
      (insert-file-contents file)
      (goto-char (point-min))
      (while (re-search-forward
              "^@\\([[:alpha:]]+\\)[ \t]*[{(][ \t]*\\([^, \t\n]+\\)[ \t]*," nil t)
        (unless (member (downcase (match-string 1)) '("comment" "string" "preamble"))
          (let ((key (match-string 2))
                (end (save-excursion (or (and (re-search-forward "^@" nil t)
                                              (line-beginning-position))
                                         (point-max))))
                crossref)
            (save-excursion
              (when (re-search-forward
                     "^[ \t]*crossref[ \t]*=[ \t]*[{\"]\\([^}\"]+\\)" end t)
                (setq crossref (match-string 1))))
            (puthash key (or crossref :none) table)))))))

(defun sp-litnotes-refs--bib-index (files)
  "Read the BibTeX FILES into a hash table of key to crossref (or :none)."
  (let ((table (make-hash-table :test 'equal)))
    (dolist (file files)
      (sp-litnotes-refs--bib-index-file file table))
    table))

(defun sp-litnotes-refs--pdf (key index)
  "Return how the PDF for KEY is found: `own', `crossref' or nil.
A book section often has no PDF of its own; its crossref entry (the book) does."
  (let ((dir (if (boundp 'sp-literature-dir) sp-literature-dir "~/Documents/literature/"))
        (parent (gethash key index)))
    (cond ((file-exists-p (expand-file-name (concat key ".pdf") dir)) 'own)
          ((and (stringp parent)
                (file-exists-p (expand-file-name (concat parent ".pdf") dir)))
           'crossref))))

(defconst sp-litnotes-refs--entry-types

(defun sp-litnotes-refs--entry-type (tags)
  "The BibTeX entry type for the file TAGS of a litnote."
  (or (cl-some (lambda (tag) (cdr (assoc (downcase tag) sp-litnotes-refs--entry-types))) tags)
      "misc"))

(defun sp-litnotes-refs--braced (value)
  "VALUE as a BibTeX field value, with no braces of its own."
  (concat "{" (replace-regexp-in-string "[{}]" "" value) "}"))

(defun sp-litnotes-refs--stub (plan key)
  "A stub BibTeX entry for KEY, from the litnote of PLAN."
  (let* ((meta (plist-get plan :meta))
         (title (or (cdr (assoc "pub-title" meta))
                    (let ((note-title (plist-get plan :title)))
                      (and note-title (not (equal note-title key)) note-title))))
         (dir (if (boundp 'sp-literature-dir) sp-literature-dir "~/Documents/literature/"))
         (fields
          (delq nil
                (list (and title (cons "title" title))
                      (and (assoc "pub-author" meta) (cons "author" (cdr (assoc "pub-author" meta))))
                      (and (assoc "pub-year" meta) (cons "year" (cdr (assoc "pub-year" meta))))
                      (and (assoc "pub-pages" meta) (cons "pages" (cdr (assoc "pub-pages" meta))))
                      (and (file-exists-p (expand-file-name (concat key ".pdf") dir))
                           (cons "file" (format "~/Documents/literature/%s.pdf" key)))
                      (cons "note" (format "Stub made from the litnote %s; complete it"
                                           (file-name-nondirectory (plist-get plan :file))))
                      (cons "DATE_ADDED" (current-time-string))))))
    (concat (format "@%s{%s,\n" (sp-litnotes-refs--entry-type (plist-get plan :tags)) key)
            (mapconcat (lambda (f) (format "  %-12s = %s,\n" (car f) (sp-litnotes-refs--braced (cdr f))))
                       fields "")
            "}\n")))

(defun sp-litnotes-refs--stubs (plans index)
  "Stub entries, as (KEY . TEXT), for the keys of PLANS that INDEX does not have.
A key used by several notes gets one entry, from the first note."
  (let (stubs seen)
    (dolist (plan plans)
      (dolist (key (plist-get plan :keys))
        (unless (or (gethash key index) (member key seen))
          (push key seen)
          (push (cons key (sp-litnotes-refs--stub plan key)) stubs))))
    (nreverse stubs)))

(defun sp-litnotes-refs--report-text (plans index)
  "Return the dry-run report for PLANS, looking keys up in INDEX."
  (let ((by-status (make-hash-table :test 'eq))
        (by-key (make-hash-table :test 'equal))
        (pdf-counts (list (cons 'own 0) (cons 'crossref 0) (cons nil 0)))
        unknown)
    (dolist (plan plans)
      (push plan (gethash (plist-get plan :status) by-status))
      (dolist (key (plist-get plan :keys))
        (push plan (gethash key by-key))
        (unless (gethash key index) (push (cons key plan) unknown))
        (cl-incf (alist-get (sp-litnotes-refs--pdf key index) pdf-counts nil nil #'eq))))
    (with-temp-buffer
      (insert (format "#+title: Litnote references: dry run\n\nFolder: =%s=\nNotes: %d\n\n"
                      sp-litnotes-refs-directory (length plans)))
      (insert "* Counts\n")
      (dolist (status '(convert merge normalise ok no-reference no-id))
        (insert (format "- %s: %d\n" status (length (gethash status by-status)))))
      (insert (format "- keys not in any registered .bib: %d\n" (length unknown)))
      (insert (format "- keys with a PDF of their own: %d; through crossref: %d; none: %d\n\n"
                      (alist-get 'own pdf-counts) (alist-get 'crossref pdf-counts)
                      (alist-get nil pdf-counts nil nil #'eq)))
      (let ((stubs (sp-litnotes-refs--stubs plans index)))
        (when stubs
          (insert (format "* Would add to %s (%d stub entries)\n"
                          (file-name-nondirectory sp-litnotes-refs-inbox-bib) (length stubs)))
          (dolist (stub stubs)
            (insert (format "- %s: %s\n" (car stub)
                            (if (string-match "^@\\([[:alpha:]]+\\)" (cdr stub))
                                (match-string 1 (cdr stub)) ""))))
          (insert "\n")))
      (dolist (spec '((convert "Would add ROAM_REFS and drop #+reference:")
                      (merge "Has both: would merge into ROAM_REFS and drop #+reference:")
                      (normalise "ROAM_REFS in another format: would rewrite as @key")
                      (no-id "No top-level :ID: drawer: would get a new ID (and ROAM_REFS) if you agree; otherwise skipped")))
        (when-let* ((items (reverse (gethash (car spec) by-status))))
          (insert (format "* %s (%d)\n" (cadr spec) (length items)))
          (dolist (plan items)
            (insert (format "- =%s=: %s -> %s\n"
                            (file-name-nondirectory (plist-get plan :file))
                            (or (plist-get plan :keyword) (plist-get plan :roam) "")
                            (plist-get plan :refs))))
          (insert "\n")))
      (when unknown
        (insert (format "* Keys that no registered .bib has (%d)\n" (length unknown)))
        (dolist (item (reverse unknown))
          (insert (format "- %s in =%s=\n" (car item)
                          (file-name-nondirectory (plist-get (cdr item) :file)))))
        (insert "\n"))
      (let (dups)
        (maphash (lambda (key notes) (when (cdr notes) (push (cons key notes) dups))) by-key)
        (when dups
          (insert (format "* Keys used by more than one note (%d)\n" (length dups)))
          (dolist (dup (sort dups (lambda (a b) (string< (car a) (car b)))))
            (insert (format "- %s: %s\n" (car dup)
                            (mapconcat (lambda (p) (file-name-nondirectory (plist-get p :file)))
                                       (cdr dup) ", "))))))
      (buffer-string))))

(defun sp-litnotes-refs--apply (file refs &optional create-id)
  "Set =ROAM_REFS= to REFS in the property drawer of FILE and drop =#+reference:=.
With CREATE-ID the note gets an =:ID:= (and a property drawer, when it has none).
An empty REFS leaves =ROAM_REFS= alone."
  (with-temp-buffer
    (insert-file-contents file)
    (goto-char (point-min))
    (when (and create-id (not (looking-at ":PROPERTIES:[ \t]*$")))
      (insert ":PROPERTIES:\n:END:\n"))
    (goto-char (point-min))
    (re-search-forward "^:END:[ \t]*$")
    (let ((end (copy-marker (line-beginning-position) t)))
      (when create-id
        (goto-char (point-min))
        (unless (re-search-forward "^:ID:" end t)
          (goto-char end)
          (insert ":ID:       " (org-id-uuid) "\n")))
      (unless (string-empty-p refs)
        (goto-char (point-min))
        (if (re-search-forward "^:ROAM_REFS:.*$" end t)
            (replace-match (concat ":ROAM_REFS: " refs) t t)
          (goto-char end)
          (insert ":ROAM_REFS: " refs "\n"))))
    (goto-char (point-min))
    (let ((case-fold-search t))
      (while (re-search-forward "^#\\+reference:.*\n" nil t)
        (replace-match "" t t)))
    (write-region nil nil file nil 'silent)))

(defun sp-litnotes-refs--write-note (plan create-id)
  "Write PLAN after a backup.  Return `written' or the reason it was skipped.
A note whose buffer has unsaved changes, or that changed since the report,
is left alone.  An open buffer without changes is reverted."
  (let* ((file (plist-get plan :file))
         (buffer (find-buffer-visiting file)))
    (cond
     ((and buffer (buffer-modified-p buffer)) "unsaved changes in its buffer")
     ((not (sp-litnotes-refs--current-p plan)) "changed since the report")
     (t (sp-litnotes-refs--backup file)
        (sp-litnotes-refs--apply file (plist-get plan :refs) create-id)
        (when buffer (with-current-buffer buffer (revert-buffer t t t)))
        'written))))

(defun sp-litnotes-refs-convert ()
  "Convert the notes of the report, after showing it and asking three times.
1. Move =#+reference:= to =ROAM_REFS= in the notes that have an ID.
2. Create an ID (and move the reference) in the notes that have none.
3. Add stub entries to `sp-litnotes-refs-inbox-bib' for the keys that no

The notes are read in slices and the report opens; the three questions

(defun sp-litnotes-refs--convert-plans (plans index)
  "Show the report of PLANS and INDEX, ask the questions and write what was agreed."
  (sp-litnotes-refs--show-report plans index)
  (let* ((todo (cl-remove-if-not
                (lambda (p) (memq (plist-get p :status) '(convert merge normalise)))
                plans))
         (no-id (cl-remove-if-not (lambda (p) (eq (plist-get p :status) 'no-id)) plans))
         (stubs (sp-litnotes-refs--stubs plans index))
         (todo (and todo (yes-or-no-p (format "Move the reference of %d notes to ROAM_REFS (backups in %s)? "
                                              (length todo) sp-litnotes-refs-backup-directory))
                    todo))
         (no-id (and no-id (yes-or-no-p (format "Create an ID for %d notes that have none? " (length no-id)))
                     no-id))
         (stubs (and stubs (yes-or-no-p (format "Add %d stub entries to %s? " (length stubs)
                                                (file-name-nondirectory sp-litnotes-refs-inbox-bib)))
                     stubs))
         (written 0) (ids 0) (added 0) skipped)
    (cl-flet ((write-note (plan create-id)
                (let ((result (sp-litnotes-refs--write-note plan create-id)))
                  (cond ((not (eq result 'written))
                         (push (format "%s (%s)" (file-name-nondirectory (plist-get plan :file))
                                       result)
                               skipped))
                        (create-id (cl-incf ids))
                        (t (cl-incf written))))))
      (when (or todo no-id stubs)
        (sp-async-work-run
         "Litnote refs"
         (list (list "writing notes" (lambda () todo)
                     (lambda (plan _job) (write-note plan nil)))
               (list "creating IDs" (lambda () no-id)

                       (sp-litnotes-refs--append-stubs list)
                       (setq added (length list)))))
         :done (lambda (_job)
                 (message "Converted %d notes, created %d IDs, added %d stub entries%s."
                          written ids added
                          (if skipped
                              (format "; skipped %s" (string-join (nreverse skipped) ", "))
                            ""))))))))

* sp-litnotes-titles.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/academic/sp-litnotes-titles.el
:END:

Sets the title of each literature note to a short reference built from =pub-author=, =pub-year= and =pub-title= (=Reuten (2014) The value form as a social form=), and renames the file to the citation key alone, keeping the =:ID:=. Since the citation key is in =ROAM_REFS= (see =sp-litnotes-refs=), the title no longer has to be the key. Required by =sp-litnotes=; it works before or after the =ROAM_REFS= conversion.

*Runs in the background.* The notes are read and written in slices (see [[file:sp-async-work.org][sp-async-work]]), so Emacs stays usable: the progress is in the mode line, =M-x sp-async-work-cancel= stops the job, and the report opens when the reading is done. A note that changed between the report and the write, or that has unsaved changes in its buffer, is skipped and named in the summary. The questions for missing values are asked in this Emacs, between slices.

- =M-x sp-litnotes-titles-dryrun= is a dry run: it writes nothing and shows =*litnote titles*=, with a =Failed:= section for every note that cannot be done.
- =M-x sp-litnotes-titles-convert= shows the same report, offers to ask for the missing titles, authors and years, asks once, copies every note to =litnote-title-backups/<time>/= under =sp-var-dir=, then writes the titles, renames the files (=sp-litnotes-titles-rename-files=) and updates the Vulpea database. Running it again changes nothing.
- Failed and left alone: notes without an =:ID:= drawer; without =pub-title=, without =pub-author= or with an ambiguous one, without =pub-year= (the title); with no citation key, a key whose file exists, or a key two notes share (the rename only).

** Reading a note

Reads the =#+title:=, the =:ID:=, the citation keys (=ROAM_REFS=, or =#+reference:= when the note has not been converted by =sp-litnotes-refs=) and the =pub-title=, =pub-author= and =pub-year= meta lines (before the first heading). Links and quotes are removed from =pub-title= and =pub-year=; =pub-author= is kept raw for the author reader.

#+begin_src emacs-lisp -i
;;;; Reading a note

(defun sp-litnotes-titles--clean (value)
  "VALUE without quotes and Org links, and with spaces collapsed."
  (let* ((v (replace-regexp-in-string "\\[\\[[^]]*\\]\\[\\([^]]*\\)\\]\\]" "\\1" value))
         (v (replace-regexp-in-string "\\[\\[[^]]*\\]\\]" "" v))
         (v (string-trim v))
         (v (replace-regexp-in-string "\\`\"\\(.*\\)\"\\'" "\\1" v))
         (v (replace-regexp-in-string "[ \t\n]+" " " v)))
    (string-trim v)))

(defun sp-litnotes-titles--meta (key limit)
  "The raw value of the meta line KEY before LIMIT, searching from the top, or nil."
  (goto-char (point-min))
  (when (re-search-forward
         (format "^\\(?:- +\\|:\\)%s\\(?: ?::\\|:\\)[ \t]*\\(.*\\)$" (regexp-quote key))
         limit t)
    (string-trim (match-string 1))))

(defun sp-litnotes-titles--parse (file)
  "Read FILE as a plist.
The keys are :file, :id, :title (the =#+title:=), :pub (the cleaned pub-title),
:author and :year (raw and cleaned values) and :keys (the citation keys of
=ROAM_REFS=, or of =#+reference:= when there is none).  A meta value is nil when
the note has no such line before its first heading."
  (with-temp-buffer
    (insert-file-contents file)
    (let ((case-fold-search t) id title refs keyword drawer-end
          (limit (save-excursion
                   (goto-char (point-min))
                   (or (and (re-search-forward "^\\*+ " nil t) (line-beginning-position))
                       (point-max)))))
      (goto-char (point-min))
      (when (looking-at ":PROPERTIES:[ \t]*$")
        (when (re-search-forward "^:END:[ \t]*$" nil t)
          (setq drawer-end (line-beginning-position))
          (goto-char (point-min))
          (when (re-search-forward "^:ID:[ \t]+\\(.+\\)$" drawer-end t)
            (setq id (string-trim (match-string 1))))
          (goto-char (point-min))
          (when (re-search-forward "^:ROAM_REFS:[ \t]*\\(.*\\)$" drawer-end t)
            (setq refs (string-trim (match-string 1))))))
      (goto-char (point-min))
      (when (re-search-forward "^#\\+title:[ \t]*\\(.*\\)$" limit t)
        (setq title (string-trim (match-string 1))))
      (goto-char (point-min))
      (when (re-search-forward "^#\\+reference:[ \t]*\\(.*\\)$" limit t)
        (setq keyword (string-trim (match-string 1))))
      (let ((pub (sp-litnotes-titles--meta "pub-title" limit))
            (author (sp-litnotes-titles--meta "pub-author" limit))
            (year (sp-litnotes-titles--meta "pub-year" limit)))
        (list :file file :id (and drawer-end id) :title title
              :pub (and pub (sp-litnotes-titles--clean pub))
              :author author
              :year (and year (sp-litnotes-titles--clean year))
              :keys (sp-litnotes-titles--keys (if (and refs (not (string-empty-p refs)))
                                                  refs keyword)))))))

(defun sp-litnotes-titles--keys (string)
  "The citation keys in STRING (=@key=, =key=, =cite:key= or =[cite:@a;@b]=)."
  (let ((clean (replace-regexp-in-string "\\[cite[^:]*:\\|\\]" "" (or string ""))) keys)
    (dolist (token (split-string clean "[ \t;,]+" t))
      (let ((bare (replace-regexp-in-string "\\`\\(cite:\\)?@?" "" token)))
        (when (and (not (string-match-p "\\`https?:\\|\\`doi:\\|/" token))
                   (string-match-p "\\`[[:alnum:]_:-]+\\'" bare))
          (push bare keys))))
    (delete-dups (nreverse keys))))
#+end_src

** Authors and the title

=pub-author= is read as =Last, First=, =First Last= (the surname is the last word with lower-case particles such as =van=), =[[id:..][First Last]]= links and quoted names, separated by =;=, =and= or between links. A plain piece with more than one comma could be one author or several, so the note is flagged =ambiguous-author=. The title uses last names only: =Reuten (2014) The value form as a social form=; two authors =A and B=, three =A, B and C=, and with =sp-litnotes-titles-et-al-from= (4) authors or more the first two and =et al.= (=A, B et al.=). =sp-litnotes-titles-format-function= replaces the formatting.

#+begin_src emacs-lisp -i
;;;; Authors and the title

(defun sp-litnotes-titles--split-name (name)
  "NAME, \"Last, First\" or \"First Last\", as (LAST . FIRST).
In the second form the surname is the last word with the lower-case particles
before it (\"van der Berg\")."
  (let ((name (string-trim name)))
    (if (string-match "\\`\\([^,]+\\),[ \t]*\\(.*\\)\\'" name)
        (cons (string-trim (match-string 1 name)) (string-trim (match-string 2 name)))
      (let* ((words (split-string name "[ \t]+" t))
             (n (length words)) (i (1- n)))
        (while (and (> i 1) (string-match-p "\\`[[:lower:]]" (nth (1- i) words)))
          (cl-decf i))
        (cons (string-join (nthcdr i words) " ")
              (string-join (cl-subseq words 0 i) " "))))))

(defun sp-litnotes-titles--authors (raw)
  "The authors in the pub-author value RAW as a list of (LAST . FIRST), or `ambiguous'.
Links give their text, quoted names are one name each, and the rest is split at
`;' and `and'.  A plain piece with more than one comma (\"A B, C D, E F\") may
be one author or several, so it makes the whole value `ambiguous'."
  (let ((pos 0) names ambiguous)
    (cl-flet ((plain (text)
                (dolist (seg (split-string (replace-regexp-in-string "[\"“”]" "" text)
                                           "\\(?:[ \t]*;[ \t]*\\|[ \t]+and[ \t]+\\)" t))
                  (let ((seg (string-trim seg "[ \t,]+" "[ \t,]+")))
                    (cond ((string-empty-p seg))
                          ((> (length (split-string seg "," t "[ \t]+")) 2)
                           (setq ambiguous t))
                          (t (push (sp-litnotes-titles--split-name seg) names)))))))
      (while (string-match
              "\\[\\[[^]]*\\]\\[\\([^]]*\\)\\]\\]\\|\\[\\[[^]]*\\]\\]\\|[\"“]\\([^\"“”]*\\)[\"”]"
              raw pos)
        (let ((beg (match-beginning 0)) (end (match-end 0))
              (name (or (match-string 1 raw) (match-string 2 raw))))
          (plain (substring raw pos beg))
          (when (and name (not (string-empty-p (string-trim name))))
            (push (sp-litnotes-titles--split-name name) names))
          (setq pos end)))
      (plain (substring raw pos)))
    (if ambiguous 'ambiguous (nreverse names))))

(defun sp-litnotes-titles-format (names year title)
  "A reference with last names only: \"Last (YEAR) TITLE\".
Two authors are \"A and B\", three \"A, B and C\"; with
`sp-litnotes-titles-et-al-from' authors or more the first two and `et al.':
\"A, B et al.\"."
  (let* ((last (mapcar #'car names))
         (authors (cond ((>= (length last) sp-litnotes-titles-et-al-from)
                         (format "%s, %s et al." (nth 0 last) (nth 1 last)))
                        ((null (cdr last)) (car last))
                        (t (format "%s and %s" (string-join (butlast last) ", ")
                                   (car (last last)))))))
    (format "%s (%s) %s" authors year title)))
#+end_src

** Planning

Each note gets a title status (=no-id=, =no-pub-title=, =empty-title=, =no-author=, =ambiguous-author=, =no-year=, =same=, =change=) and a name status (=rename=, =same-name=, =no-citekey=, =exists=, =key-clash=, =case-only=). A missing year is a failure, not =n.d.=. The new file name is the first citation key and =.org= (nothing else: no identifier, no keywords). A name that cannot be used leaves the title change in place and only the rename is skipped. Values typed in by the user (next section) replace what the note has, for the title only.

#+begin_src emacs-lisp -i
;;;; Planning

(defun sp-litnotes-titles--plan (parsed)
  "Add to PARSED, from `sp-litnotes-titles--parse', what to do with the note.
The result has :title-status (`no-id', `no-pub-title', `empty-title',
`no-author', `ambiguous-author', `no-year', `same' or `change'), :new-title, :new-name and
:name-status (`rename', `same-name', `no-citekey', or later `exists',
`key-clash', `case-only').  The new name is the first citation key and
=.org=; :keys has all of them."
  (let* ((pub (plist-get parsed :pub))
         (raw (plist-get parsed :author))
         (authors (and raw (sp-litnotes-titles--authors raw)))
         (title (plist-get parsed :title))
         (old-name (file-name-nondirectory (plist-get parsed :file)))
         (year (let ((y (plist-get parsed :year))) (and y (not (string-empty-p y)) y)))
         (new-title (and (consp authors) year
                         pub (not (string-empty-p pub))
                         (funcall sp-litnotes-titles-format-function authors year pub)))
         (title-status (cond ((not (plist-get parsed :id)) 'no-id)
                             ((null pub) 'no-pub-title)
                             ((string-empty-p pub) 'empty-title)
                             ((eq authors 'ambiguous) 'ambiguous-author)
                             ((null authors) 'no-author)
                             ((null year) 'no-year)
                             ((equal new-title title) 'same)
                             (t 'change)))
         (usable (plist-get parsed :id))
         (key (car (plist-get parsed :keys)))
         (new-name (and key (concat key ".org")))
         (name-status (cond ((not usable) nil)
                            ((null new-name) 'no-citekey)
                            ((string= new-name old-name) 'same-name)
                            ((string= (downcase new-name) (downcase old-name)) 'case-only)
                            (t 'rename))))
    (append parsed (list :title-status title-status
                         :new-title (and (memq title-status '(same change)) new-title)
                         :new-name (and (memq name-status '(rename case-only)) new-name)
                         :name-status name-status))))

(defun sp-litnotes-titles--mark-collisions (plans directory)
  "Change :name-status of PLANS to `exists' or `key-clash' where names collide.
DIRECTORY is the folder of the notes; names are compared without case."
  (let ((targets (make-hash-table :test 'equal))
        (present (make-hash-table :test 'equal)))
    (dolist (name (directory-files directory nil "\\`[^.]"))
      (puthash (downcase name) t present))
    (dolist (plan plans)
      (when (eq (plist-get plan :name-status) 'rename)
        (push plan (gethash (downcase (plist-get plan :new-name)) targets))))
    (maphash
     (lambda (target group)
       (cond ((cdr group)
              (dolist (plan group) (plist-put plan :name-status 'key-clash)))
             ((gethash target present)
              (plist-put (car group) :name-status 'exists))))
     targets)
    plans))

(defvar sp-litnotes-titles--overrides (make-hash-table :test 'equal)
  "Values typed in by `sp-litnotes-titles--resolve', by file: a plist of
:pub, :author and :year that replaces what the note has.")

(defun sp-litnotes-titles--parse-with-overrides (file)
  "`sp-litnotes-titles--parse' of FILE, with the values typed in for it."
  (let ((parsed (sp-litnotes-titles--parse file)))
    (cl-loop for (key value) on (gethash file sp-litnotes-titles--overrides) by #'cddr
             do (setq parsed (plist-put parsed key value)))
    parsed))

(defun sp-litnotes-titles--plans (&optional directory)
  "Plans for every note in DIRECTORY (default `sp-litnotes-titles-directory')."
  (let ((dir (file-name-as-directory (or directory sp-litnotes-titles-directory))))
    (sp-litnotes-titles--mark-collisions
     (mapcar (lambda (file)
               (sp-litnotes-titles--plan (sp-litnotes-titles--parse-with-overrides file)))
             (directory-files dir t "\\`[^.#].*\\.org\\'"))
     dir)))

(defun sp-litnotes-titles--changes-p (plan)
  "Non-nil when applying PLAN would write the title or rename the file."
  (or (eq (plist-get plan :title-status) 'change)
      (and sp-litnotes-titles-rename-files
           (eq (plist-get plan :name-status) 'rename))))

** Links to the old names

#+begin_src emacs-lisp -i
;;;; Links to the old names

(defun sp-litnotes-titles--old-names (plans)

    (dolist (plan plans)

    old))

(defun sp-litnotes-titles--link-files (old)

             (file-directory-p sp-litnotes-titles-link-directory))

     sp-litnotes-titles-link-directory "\\`[^.#].*\\.org\\'")))

(defun sp-litnotes-titles--scan-links (file old found)
  "Add the old names of OLD that =file:= links in FILE name to the alist cell FOUND.
FOUND is a cons whose car is the alist (OLD-NAME . FILES)."
  (when (file-readable-p file)
    (with-temp-buffer
      (insert-file-contents file)
      (while (re-search-forward "\\[\\[file:\\([^]]+\\.org\\)" nil t)
        (let ((name (file-name-nondirectory (match-string 1))))
          (when (gethash name old)
            (cl-pushnew file (alist-get name (car found) nil nil #'equal)
                        :test #'equal)))))))

(defun sp-litnotes-titles--file-links (plans)
  "Alist of (OLD-NAME . FILES) for the renamed PLANS that =file:= links name.
Searches `sp-litnotes-titles-link-directory'; =id:= links need no change."
  (let* ((old (sp-litnotes-titles--old-names plans))
         (found (list nil)))
    (dolist (file (sp-litnotes-titles--link-files old))
      (sp-litnotes-titles--scan-links file old found))
    (car found)))

(defun sp-litnotes-titles--scan (callback)
  "Read the notes in slices and call CALLBACK with PLANS and LINKS.
LINKS is the alist of `sp-litnotes-titles--file-links'.  The folder of the
links is searched in slices too, file by file.  Nothing is written.
Return the job."
  (let* ((dir (file-name-as-directory sp-litnotes-titles-directory))
         plans old (found (list nil)))
    (sp-async-work-run
     "Litnote titles"
     (list (list "reading notes"
                 (lambda () (directory-files dir t "\\`[^.#].*\\.org\\'"))
                 (lambda (file _job)
                   (push (sp-litnotes-titles--plan
                          (sp-litnotes-titles--parse-with-overrides file))
                         plans)))
           (list "looking for links"
                 (lambda ()
                   (setq plans (sp-litnotes-titles--mark-collisions (nreverse plans) dir)
                         old (sp-litnotes-titles--old-names plans))
                   (sp-litnotes-titles--link-files old))
                 (lambda (file _job)
                   (sp-litnotes-titles--scan-links file old found))))
     :done (lambda (_job) (funcall callback plans (car found))))))

(defun sp-litnotes-titles--report-text (plans links)
  "Return the dry-run report for PLANS; LINKS is from `sp-litnotes-titles--file-links'."
  (let ((counts (make-hash-table :test 'eq))
        (changing (cl-remove-if-not #'sp-litnotes-titles--changes-p plans)))
    (dolist (plan plans)
      (cl-incf (gethash (plist-get plan :title-status) counts 0))
      (when-let* ((s (plist-get plan :name-status)))
        (cl-incf (gethash s counts 0))))
    (with-temp-buffer
      (insert (format "#+title: Litnote titles: dry run\n\nFolder: =%s=\nNotes: %d\nRenaming files: %s\n\n"
                      sp-litnotes-titles-directory (length plans)
                      (if sp-litnotes-titles-rename-files "yes" "no")))
      (insert "* Counts\n")
      (dolist (item '((change . "title would change") (same . "title already right")
                      (rename . "file would be renamed") (same-name . "file name already the citekey")))
        (insert (format "- %s: %d\n" (cdr item) (gethash (car item) counts 0))))
      (dolist (item sp-litnotes-titles--reasons)
        (when (> (gethash (car item) counts 0) 0)
          (insert (format "- %s: %d\n" (cdr item) (gethash (car item) counts 0)))))
      (insert (format "- failed items (apply asks you for the values that are missing): %d\n"
                      (cl-count-if (lambda (p) (memq (plist-get p :title-status)
                                                     sp-litnotes-titles--promptable))
                                   plans)))
      (insert (format "- notes written by apply: %d\n\n" (length changing)))
      (when changing
        (insert (format "* Would change (%d)\n" (length changing)))
        (dolist (plan changing)
          (let ((old-name (file-name-nondirectory (plist-get plan :file)))
                (renamed (and sp-litnotes-titles-rename-files
                              (eq (plist-get plan :name-status) 'rename))))
            (insert (format "** =%s=\n" old-name))
            (when (cdr (plist-get plan :keys))
              (insert (format "- several citekeys: %s (the first names the file)\n"
                              (string-join (plist-get plan :keys) " "))))
            (if (eq (plist-get plan :title-status) 'change)
                (insert (format "- title: %s -> %s\n"
                                (or (plist-get plan :title) "(none)") (plist-get plan :new-title)))
              (insert "- title: unchanged\n"))
            (if renamed
                (insert (format "- file: %s -> =%s=\n" old-name (plist-get plan :new-name)))
              (insert "- file: unchanged\n"))
            (when-let* ((files (cdr (assoc old-name links))))
              (insert (format "- file: links to the old name in: %s\n"
                              (mapconcat (lambda (f) (format "=%s=" (file-name-nondirectory f)))
                                         files ", ")))))))
      (dolist (item sp-litnotes-titles--reasons)
        (let ((group (cl-remove-if-not
                      (lambda (p) (or (eq (plist-get p :title-status) (car item))
                                      (eq (plist-get p :name-status) (car item))))
                      plans)))
          (when group
            (insert (format "\n* Failed: %s (%d)\n" (cdr item) (length group)))
            (dolist (plan group)
              (insert (format "- =%s=: title %s; pub-author %s; pub-title %s%s\n"
                              (file-name-nondirectory (plist-get plan :file))
                              (or (plist-get plan :title) "(none)")
                              (or (plist-get plan :author) "(none)")
                              (or (plist-get plan :pub) "(none)")
                              (if (plist-get plan :new-name)
                                  (format "; would be =%s=" (plist-get plan :new-name))
                                "")))))))
      (let ((by-title (make-hash-table :test 'equal)) dups)
        (dolist (plan plans)
          (when-let* ((title (plist-get plan :new-title)))
            (push plan (gethash (downcase title) by-title))))
        (maphash (lambda (_ group) (when (cdr group) (push (reverse group) dups))) by-title)
        (when dups
          (insert (format "\n* Notes that would get the same title (%d titles)\n" (length dups)))
          (dolist (group dups)
            (insert (format "- %s: %s\n" (plist-get (car group) :new-title)
                            (mapconcat (lambda (p) (format "=%s=" (file-name-nondirectory (plist-get p :file))))
                                       group ", "))))))
      (buffer-string))))

(defun sp-litnotes-titles--backup (file stamp)
  "Copy FILE to the STAMP sub-folder of `sp-litnotes-titles-backup-directory'."
  (let ((dir (expand-file-name (concat stamp "/") sp-litnotes-titles-backup-directory)))
    (make-directory dir t)

(defun sp-litnotes-titles--write-title (file title)
  "Set the =#+title:= of FILE to TITLE, after its property drawer when it has none."
  (with-temp-buffer
    (insert-file-contents file)
    (goto-char (point-min))
    (let ((case-fold-search t))
      (if (re-search-forward "^#\\+title:.*$" nil t)
          (replace-match (concat "#+title: " title) t t)
        (re-search-forward "^:END:[ \t]*$")
        (end-of-line)
        (insert "\n#+title: " title)))
    (write-region nil nil file nil 'silent)))

(defun sp-litnotes-titles--apply-plan (plan stamp)
  "Write PLAN, after a backup in STAMP.  Return a plist for the summary."
  (let* ((file (plist-get plan :file))
         (buffer (find-buffer-visiting file))
         (id (plist-get plan :id)))
    (cond
     ((stringp (file-locked-p file)) (list :file file :status 'skipped :why "locked by another Emacs"))
     ((and buffer (buffer-modified-p buffer))
      (list :file file :status 'skipped :why "unsaved changes in its buffer"))
     (t
      (condition-case err
          (let ((new file))
            (sp-litnotes-titles--backup file stamp)
            (when buffer (kill-buffer buffer))
            (when (eq (plist-get plan :title-status) 'change)
              (sp-litnotes-titles--write-title file (plist-get plan :new-title))
              (unless (equal id (plist-get (sp-litnotes-titles--parse file) :id))
                (error "the :ID: changed; restore from the backup")))
            (when (and sp-litnotes-titles-rename-files
                       (eq (plist-get plan :name-status) 'rename))
              (setq new (expand-file-name (plist-get plan :new-name)
                                          (file-name-directory file)))
              (when (file-exists-p new) (error "%s exists" new))
              (rename-file file new nil)
              (when (fboundp 'vulpea-db--forget-file)
                (ignore-errors (vulpea-db--forget-file file)))
              (when (fboundp 'org-id-add-location)
                (ignore-errors (org-id-add-location id new))))
            (when (fboundp 'vulpea-db-update-file)
              (ignore-errors (vulpea-db-update-file new)))
            (list :file file :status 'written :new new))
        (error (list :file file :status 'failed :why (error-message-string err))))))))

** Asking for what is missing

The notes that failed for a missing or ambiguous title, author or year can be fixed by answering a question for each (the question shows what the note has). An empty answer skips the note or leaves it failed. The answers are used for the title only and are not written to the note's meta lines. =sp-litnotes-titles-convert= asks whether to do this after showing the report, shows the report again, and then asks once before writing.

#+begin_src emacs-lisp -i
;;;; Asking for what is missing

(defun sp-litnotes-titles--prompt (plan status)
  "The question for the failed PLAN of title STATUS, and the field it fills."
  (let ((name (file-name-nondirectory (plist-get plan :file)))
        (context (format "author %s, year %s, title %s"
                         (or (plist-get plan :author) "-") (or (plist-get plan :year) "-")
                         (or (plist-get plan :pub) "-"))))
    (pcase status
      ((or 'no-pub-title 'empty-title)
       (cons :pub (format "%s (%s)\nTitle (empty skips): " name context)))
      ((or 'no-author 'ambiguous-author)
       (cons :author (format "%s (%s)\nAuthors as \"Last, First; Last, First\" (empty skips): "
                             name context)))
      ('no-year (cons :year (format "%s (%s)\nYear (empty skips): " name context))))))

(defun sp-litnotes-titles--resolve (plans)
  "Ask for the missing values of the failed PLANS; return how many were typed.
An empty answer leaves the note as it is.  The values are used for the title
only and kept in `sp-litnotes-titles--overrides'; the note's meta lines are not
changed."
  (let ((typed 0))
    (dolist (plan plans)
      (when (memq (plist-get plan :title-status) sp-litnotes-titles--promptable)
        (let ((file (plist-get plan :file)) (go t))
          (while go
            (let* ((current (sp-litnotes-titles--plan
                             (sp-litnotes-titles--parse-with-overrides file)))
                   (status (plist-get current :title-status))
                   (ask (and (memq status sp-litnotes-titles--promptable)
                             (sp-litnotes-titles--prompt current status)))
                   (answer (and ask (string-trim (read-string (cdr ask))))))
              (cond ((or (null ask) (string-empty-p answer)) (setq go nil))
                    ((and (eq (car ask) :author)
                          (not (consp (sp-litnotes-titles--authors answer))))
                     (message "Could not read authors from \"%s\"; skipping %s"
                              answer (file-name-nondirectory file))
                     (setq go nil))
                    (t (puthash file (plist-put (gethash file sp-litnotes-titles--overrides)
                                                (car ask) answer)
                                sp-litnotes-titles--overrides)
                       (cl-incf typed))))))))
    typed))

;; A note is written only if it still gets the title and name of the report.
(defun sp-litnotes-titles--current-p (plan)
  "Non-nil when the note of PLAN would still get the title and name PLAN has."
  (let ((now (ignore-errors
               (sp-litnotes-titles--plan
                (sp-litnotes-titles--parse-with-overrides (plist-get plan :file))))))
    (and now
         (equal (plist-get now :id) (plist-get plan :id))
         (equal (plist-get now :new-title) (plist-get plan :new-title))
         (equal (plist-get now :new-name) (plist-get plan :new-name)))))

(defvar sp-litnotes-titles--last-results nil
  "What the last `sp-litnotes-titles-convert' wrote: a plist per note.")

(defun sp-litnotes-titles--write-all (todo)
  "Write the plans TODO in slices, after a backup of each, and report at the end."
  (let* ((stamp (format-time-string "%Y%m%dT%H%M%S"))
         results)
    (sp-async-work-run
     "Litnote titles"
     (list (list "writing"
                 (lambda () todo)
                 (lambda (plan _job)
                   (push (if (sp-litnotes-titles--current-p plan)
                             (sp-litnotes-titles--apply-plan plan stamp)
                           (list :file (plist-get plan :file) :status 'skipped
                                 :why "changed since the report"))
                         results))))
     :done (lambda (_job)
             (setq results (nreverse results))
             (let ((bad (cl-remove-if (lambda (r) (eq (plist-get r :status) 'written))
                                      results)))
               (message "Wrote %d of %d litnotes; backups in %s%s"
                        (- (length results) (length bad)) (length results)
                        (expand-file-name (concat stamp "/") sp-litnotes-titles-backup-directory)
                        (if bad
                            (format "; %s" (mapconcat
                                            (lambda (r) (format "%s %s (%s)"
                                                                (plist-get r :status)
                                                                (file-name-nondirectory (plist-get r :file))
                                                                (plist-get r :why)))
                                            bad ", "))
                          "")))
             (setq sp-litnotes-titles--last-results results)))))

(defun sp-litnotes-titles--confirm-and-write (plans)
  "Ask once about the changes in PLANS, then write them."
  (let ((todo (cl-remove-if-not #'sp-litnotes-titles--changes-p plans)))
    (if (null todo)
        (message "Nothing to change.")
      (when (yes-or-no-p (format "Write %d litnotes (backups in %s)? "
                                 (length todo) sp-litnotes-titles-backup-directory))
        (sp-litnotes-titles--write-all todo)))))

(defun sp-litnotes-titles--after-report (plans)
  "Offer to ask for what the failed PLANS lack, then go on to write."
  (let ((failed (cl-remove-if-not
                 (lambda (p) (memq (plist-get p :title-status) sp-litnotes-titles--promptable))
                 plans)))
    (if (and failed
             (y-or-n-p (format "%d notes failed for a missing title, author or year.  Fill them in now? "
                               (length failed)))
             (> (sp-litnotes-titles--resolve failed) 0))
        (sp-litnotes-titles--show-report #'sp-litnotes-titles--confirm-and-write)
      (sp-litnotes-titles--confirm-and-write plans))))
