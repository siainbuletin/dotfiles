* Why this exists

The batch conversions and lints copy each file to a backup folder before they write it.

- *Problem*: to see the older version of a note, you had to find the right run folder by hand.
- *Cause*: every module keeps its backups in its own folder, and not all of them in the same layout.
- *Fix*: one lookup that knows all the folders and the layouts, so you start from the file you are visiting.

** What it offers

- =sp-backup-lookup-list=: the backups of a file, newest first (a function, for other code).
- =sp-backup-open=: pick one of the backups of the current file and open it, read-only.
- =sp-backup-diff=: pick one and diff it against the current file; with a prefix, use Ediff.
- In a report buffer, =b= opens and =D= diffs the backups of the file on the line at point.

** Where the backups are

Each module has its own folder variable, kept as it was.

| Module                | Variable                                | Layout of a backup                  |
|-----------------------+-----------------------------------------+-------------------------------------|
| BibTeX lint           | =sp-bibtex-lint-backup-directory=       | =STAMP/name=                        |
| Litnote titles        | =sp-litnotes-titles-backup-directory=   | =STAMP/name=                        |
| Litnote meta          | =sp-litnotes-meta-backup-directory=     | =STAMP/name=                        |
| Meta order            | =sp-vulpea-meta-order-backup-directory= | =STAMP/name=                        |
| Litnote references    | =sp-litnotes-refs-backup-directory=     | =name= or =name.STAMP=              |
| Footnote lint         | =sp-org-lint-fn-backup-directory=       | =STAMP/full/path/of/the/file=       |
| Author notes          | =sp-author-notes-backup-directory=      | =STAMP/path/in/the/author/folder=   |
| Notes filing          | =sp-notes-filing-backup-dir=            | =STAMP/files/path/in/the/notes/root= |

- The lookup reads the layouts above; it does not change where the modules write.
- A module that gets a new backup folder is added to =sp-backup-lookup-directories=.

** How a backup is matched to a file

- The name of the backup (without a =.STAMP= suffix) must equal the name of the file.
- When the backup keeps a folder path, that path must also end the path of the file.
  - This tells apart two notes with the same name in different folders.
  - A backup with only a name (=STAMP/name=) cannot be told apart, so every note of that name is listed.
- The time comes from the =STAMP= folder (or the suffix), because a copy that keeps the time of the original would sort wrongly.

;;; sp-backup-lookup.el --- Open or diff the backups of the file you are visiting -*- lexical-binding: t; -*-

;;; Commentary:

;; The batch conversions and lints copy each file to a backup folder before they
;; write it.  `sp-backup-lookup-list' finds the backups of one file in all those
;; folders; `sp-backup-open' and `sp-backup-diff' use it from the file's buffer,
;; or from a batch report (keys `b' and `D').
;; See docs/tangles/funct/sp-backup-lookup.org.

;;; Code:

(require 'cl-lib)
(require 'seq)
(require 'subr-x)

(defgroup sp-backup-lookup nil
  "Find the backups the batch commands made of a file."
  :group 'files)

(defcustom sp-backup-lookup-directories
  '(("BibTeX lint" . sp-bibtex-lint-backup-directory)
    ("Litnote titles" . sp-litnotes-titles-backup-directory)
    ("Litnote meta" . sp-litnotes-meta-backup-directory)
    ("Meta order" . sp-vulpea-meta-order-backup-directory)
    ("Litnote references" . sp-litnotes-refs-backup-directory)
    ("Footnote lint" . sp-org-lint-fn-backup-directory)
    ("Author notes" . sp-author-notes-backup-directory)
    ("Notes filing" . sp-notes-filing-backup-dir))
  "The backup folders to search, as (LABEL . VARIABLE) or (LABEL . DIRECTORY).
VARIABLE is a symbol whose value is the folder; one that is unbound or nil
is skipped, so a module that is not loaded costs nothing."
  :type '(alist :key-type string :value-type (choice symbol directory))
  :group 'sp-backup-lookup)
#+end_src

* Finding the backups

- A backup is one file below a backup folder; its path below that folder is the /relative path/.
- The relative path is split into its parts:
  - one part: =name= or =name.STAMP= (the references layout), the stamp is the suffix;
  - more parts: the first is the =STAMP= folder, the rest is what the module kept of the file's path.
- The walk only keeps files whose name starts with the name of the file, so a big folder is cheap to scan.

#+begin_src emacs-lisp
(defconst sp-backup-lookup--stamp-regexp
  "\\([0-9]\\{4\\}\\)\\([0-9]\\{2\\}\\)\\([0-9]\\{2\\}\\)[-T]?\\([0-9]\\{2\\}\\)\\([0-9]\\{2\\}\\)\\([0-9]\\{2\\}\\)"
  "A time stamp as the batch commands write it: 20261109T225317 or 20261109-225317.")

(defun sp-backup-lookup--stamp-time (stamp)
  "The time of STAMP, or nil when it is not a time stamp."
  (when (and stamp (string-match (concat "\\`" sp-backup-lookup--stamp-regexp "\\'") stamp))
    (let ((n (lambda (i) (string-to-number (match-string i stamp)))))
      (encode-time (list (funcall n 6) (funcall n 5) (funcall n 4)
                         (funcall n 3) (funcall n 2) (funcall n 1)
                         nil -1 nil)))))

(defun sp-backup-lookup--directory (spec)
  "The backup folder named by SPEC, a variable or a folder, or nil."
  (let ((value (cond ((and (symbolp spec) (boundp spec)) (symbol-value spec))
                     ((stringp spec) spec))))
    (and (stringp value) (file-directory-p value)
         (file-name-as-directory (expand-file-name value)))))

(defun sp-backup-lookup--tail-p (parts file)
  "Non-nil when the path PARTS (a list of names) ends the path of FILE.
A leading \"files\" part, the notes filing layout, is not counted."
  (let* ((parts (if (equal (car parts) "files") (cdr parts) parts))
         (mine (split-string (file-truename file) "/" t)))
    (and (<= (length parts) (length mine))
         (equal parts (last mine (length parts))))))

(defun sp-backup-lookup--entry (label root path file)
  "The backup entry for PATH below ROOT when it is a backup of FILE, else nil.
The entry is a plist: :path :label :stamp :time."
  (let* ((rel (file-relative-name path root))
         (parts (split-string rel "/" t))
         (name (file-name-nondirectory file))
         (base (car (last parts)))
         (suffix (and (string-prefix-p (concat name ".") base)
                      (substring base (1+ (length name)))))
         (matches (or (equal base name)
                      (and suffix (sp-backup-lookup--stamp-time suffix)))))
    (when matches
      (let* ((stamp (if (cdr parts) (car parts) suffix))
             (kept (and (cdr parts) (cdr (butlast parts)))))
        (when (or (null kept)
                  (sp-backup-lookup--tail-p (append kept (list name)) file))
          (list :path path :label label :stamp stamp
                :time (or (sp-backup-lookup--stamp-time stamp)
                          (file-attribute-modification-time (file-attributes path)))))))))

(defun sp-backup-lookup-list (file)
  "The backups of FILE in every folder of `sp-backup-lookup-directories'.
Newest first.  Each element is a plist with :path :label :stamp :time."
  (let ((file (expand-file-name file))
        (found nil))
    (pcase-dolist (`(,label . ,spec) sp-backup-lookup-directories)
      (when-let* ((root (sp-backup-lookup--directory spec)))
        (dolist (path (directory-files-recursively
                       root (concat "\\`" (regexp-quote (file-name-nondirectory file)))))
          (when-let* ((entry (sp-backup-lookup--entry label root path file)))
            (push entry found)))))
    (sort found (lambda (a b) (time-less-p (plist-get b :time) (plist-get a :time))))))
#+end_src

* Choosing a file

- In a file buffer, the file is the one visited.
- In a batch report, the file is the link on the line at point, so the key works wherever on the entry you are.
- When there is neither, you are asked for a file.

#+begin_src emacs-lisp
(defun sp-backup-lookup--link-file ()
  "The file of the first Org file link on this line, or nil."
  (save-excursion
    (let ((end (line-end-position)))
      (beginning-of-line)
      (when (re-search-forward "\\[\\[file:\\([^]]+?\\)\\(?:::[^]]*\\)?\\]" end t)
        (expand-file-name (match-string-no-properties 1))))))

(defun sp-backup-lookup--file (prompt)
  "The file to look up: the visited one, the report line's one, or ask with PROMPT."
  (cond (buffer-file-name)
        ((sp-backup-lookup--link-file))
        (t (read-file-name prompt nil nil t))))

(defun sp-backup-lookup--annotate (entries)
  "A completion annotation function for ENTRIES."
  (lambda (candidate)
    (when-let* ((e (cdr (assoc candidate entries))))
      (format "  %s  %s" (plist-get e :label)
              (file-size-human-readable
               (file-attribute-size (file-attributes (plist-get e :path))))))))

(defun sp-backup-lookup--read (file)
  "Ask which backup of FILE; return its path.  Signal an error when there is none."
  (let ((entries
         (mapcar (lambda (e)
                   (cons (format-time-string "%Y-%m-%d %H:%M:%S" (plist-get e :time)) e))
                 (or (sp-backup-lookup-list file)
                     (user-error "No backup of %s in any backup folder"
                                 (file-name-nondirectory file))))))
    (let ((table (lambda (string pred action)
                   (if (eq action 'metadata)
                       `(metadata (display-sort-function . identity)
                                  (annotation-function . ,(sp-backup-lookup--annotate entries)))
                     (complete-with-action action entries string pred)))))
      (plist-get (cdr (assoc (completing-read
                              (format "Backup of %s: " (file-name-nondirectory file))
                              table nil t nil nil (caar entries))
                             entries))
                 :path))))
#+end_src

* The commands

- =sp-backup-open= shows the backup in a read-only buffer, so it cannot be changed by accident.
- =sp-backup-diff= puts the backup first, so a removed line is a line the batch command took out.
- Ediff is for when the diff is long; it needs the current file on disk.

#+begin_src emacs-lisp
;;;###autoload
(defun sp-backup-open ()
  "Open one of the backups of the current file, read-only.
In a batch report, the file is the one linked on the current line."
  (interactive)
  (let* ((file (sp-backup-lookup--file "File: "))
         (backup (sp-backup-lookup--read file)))
    (find-file-other-window backup)
    (setq buffer-read-only t)
    (message "Backup of %s" (abbreviate-file-name file))))

;;;###autoload
(defun sp-backup-diff ()
  "Diff one of the backups of the current file against the file.
In a batch report, the file is the one linked on the current line.  With a
prefix argument, use Ediff instead of a diff buffer."
  (interactive)
  (let* ((ediff current-prefix-arg)
         (file (sp-backup-lookup--file "File: "))
         (backup (sp-backup-lookup--read file)))
    (if ediff
        (ediff-files backup file)
      (diff backup file))))
#+end_src

#+begin_src emacs-lisp -i
;;; sp-backup-lookup-test.el --- Tests for sp-backup-lookup -*- lexical-binding: t; -*-

(require 'ert)
(require 'sp-backup-lookup)

(defmacro sp-backup-lookup-test--with-folder (var &rest body)
  "Run BODY with VAR bound to a fresh temporary folder."
  (declare (indent 1))
  `(let ((,var (file-name-as-directory (make-temp-file "sp-backup-lookup" t))))
     (unwind-protect (progn ,@body)
       (delete-directory ,var t))))

(defun sp-backup-lookup-test--touch (root &rest parts)
  "Create the file made of the PARTS below ROOT and return its path."
  (let ((path (expand-file-name (mapconcat #'identity parts "/") root)))
    (make-directory (file-name-directory path) t)
    (write-region "backup\n" nil path)
    path))

(ert-deftest sp-backup-lookup-stamp-time ()
  (should (equal (sp-backup-lookup--stamp-time "20261109T225317")
                 (sp-backup-lookup--stamp-time "20261109-225317")))
  (should (equal (format-time-string "%F %T" (sp-backup-lookup--stamp-time "20261109T225317"))
                 "2026-11-09 22:53:17"))
  (should-not (sp-backup-lookup--stamp-time "files"))
  (should-not (sp-backup-lookup--stamp-time nil)))

(ert-deftest sp-backup-lookup-stamp-folder-layout ()
  "STAMP/name, as the titles, meta, meta-order and BibTeX commands write it."
  (sp-backup-lookup-test--with-folder root
    (let* ((old (sp-backup-lookup-test--touch root "20261101T100000" "kant.org"))
           (new (sp-backup-lookup-test--touch root "20261105T100000" "kant.org"))
           (sp-backup-lookup-directories `(("Titles" . ,root))))
      (sp-backup-lookup-test--touch root "20261105T100000" "hegel.org")
      (should (equal (mapcar (lambda (e) (plist-get e :path))
                             (sp-backup-lookup-list "/notes/kant.org"))
                     (list new old))))))

(ert-deftest sp-backup-lookup-suffix-layout ()
  "name and name.STAMP, as the references command writes it."
  (sp-backup-lookup-test--with-folder root
    (let* ((first (sp-backup-lookup-test--touch root "kant.org"))
           (second (sp-backup-lookup-test--touch root "kant.org.20261105T100000"))
           (_ (set-file-times first (encode-time 0 0 0 1 11 2026)))
           (sp-backup-lookup-directories `(("Refs" . ,root)))
           (found (sp-backup-lookup-list "/notes/kant.org")))
      (should (equal (mapcar (lambda (e) (plist-get e :path)) found)
                     (list second first)))
      (should (equal (plist-get (car found) :stamp) "20261105T100000"))
      (should-not (plist-get (cadr found) :stamp)))))

(ert-deftest sp-backup-lookup-path-layout ()
  "STAMP/path/of/the/file: only the backup of that very path matches."
  (sp-backup-lookup-test--with-folder root
    (let* ((file (sp-backup-lookup-test--touch root "notes" "a" "kant.org"))
           (mine (sp-backup-lookup-test--touch
                  root "20261105-100000"
                  (string-remove-prefix "/" (file-truename file))))
           (other (sp-backup-lookup-test--touch root "20261105-100000" "elsewhere" "kant.org"))
           (sp-backup-lookup-directories `(("Footnotes" . ,root)))
           (paths (mapcar (lambda (e) (plist-get e :path)) (sp-backup-lookup-list file))))
      (should (member mine paths))
      (should-not (member other paths)))))

(ert-deftest sp-backup-lookup-notes-filing-layout ()
  "STAMP/files/path-in-root, written by the notes filing."
  (sp-backup-lookup-test--with-folder root
    (let* ((backup (sp-backup-lookup-test--touch root "20261105-100000" "files" "sub" "kant.org"))
           (sp-backup-lookup-directories `(("Filing" . ,root))))
      (should (equal (mapcar (lambda (e) (plist-get e :path))
                             (sp-backup-lookup-list "/notes/sub/kant.org"))
                     (list backup)))
      (should-not (sp-backup-lookup-list "/notes/other/kant.org")))))

(ert-deftest sp-backup-lookup-skips-unbound-and-missing ()
  (let ((sp-backup-lookup-directories
         '(("Nothing" . sp-backup-lookup-test--unbound-variable)
           ("Missing" . "/nonexistent/backups/"))))
    (should-not (sp-backup-lookup-list "/notes/kant.org"))))

(ert-deftest sp-backup-lookup-link-file ()
  "The file of a report line is read from its Org link."
  (with-temp-buffer
    (insert "- [[file:/notes/kant.org::12][kant.org]] changed\n")
    (goto-char (point-min))
    (should (equal (sp-backup-lookup--link-file) "/notes/kant.org")))
  (with-temp-buffer
    (insert "- no link here\n")
    (should-not (sp-backup-lookup--link-file))))
