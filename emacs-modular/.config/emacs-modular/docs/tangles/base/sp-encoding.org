This module makes UTF-8 the coding system for files, the terminal and keyboard input.

- It is the very first module loaded from =init.el=, in both the default and minimal lists, so later modules can assume UTF-8.
- It has no dependencies.

** UTF-8 defaults

Encoding settings:

- Sets UTF-8 as the default for new buffers, file names and processes.
- Puts it first in the list used to detect a file's encoding.
- Uses it for terminal output and keyboard input in terminal frames.
- Sets the language environment to English.
- Also sets =default-buffer-file-coding-system=, though that name is an obsolete alias of =buffer-file-coding-system=.
- Caveat: =set-language-environment= runs after the coding settings, so it can reset some of them depending on the system locale. Calling it first is the usual order.

#+begin_src emacs-lisp -i
(set-default-coding-systems 'utf-8)     ; Default to utf-8 encoding
(prefer-coding-system       'utf-8)     ; Add utf-8 at the front for automatic detection.
(set-terminal-coding-system 'utf-8)     ; Set coding system of terminal output
(set-keyboard-coding-system 'utf-8)     ; Set coding system for keyboard input on TERMINAL
(set-language-environment "English")    ; Set up multilingual environment
(setq default-buffer-file-coding-system 'utf-8)
#+end_src
