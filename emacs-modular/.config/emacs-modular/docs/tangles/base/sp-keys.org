Literate source for =libraries/modules/base/sp-keys.el=.

- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../tangling-instructions.org][Tangling instructions]].

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module is the central place for keybindings in the config.

- Almost every personal binding lives here, instead of being scattered across modules.
- Bindings are grouped into prefix maps under a single personal leader prefix, =sp-prefix= (=C-;= by default; =C-x C-SPC= is a shim that says so).
- They are made with =bind-keys= and =bind-key= from the =bind-key= library that ships with =use-package=, and with the built-in =keymap-global-set= for plain global keys.

Where the commands come from:

- Most bound commands are defined elsewhere. =sp-= helpers live in =sp-helper-funct= and other modules.
- Many targets come from third-party packages: =consult=, =crux=, =magit=, =git-gutter=, =mu4e=, =citar=, =tabspaces=, =ace-window=, =easysession=.
- A key whose command is not loaded yet simply errors when pressed.

What the module installs and defines:

- Installs =ironkey=, =hydra=, =use-package-hydra=, =which-key=, =helm-descbinds= and =keycast=.
- Defines two =transient= menus (ediff and rectangle editing).

The file has grown in layers: a curated, well-commented part under the leader prefix, followed after the "End keybindings" marker by an older collection of global bindings and package declarations, some of which duplicate earlier settings. It is loaded early in both the default and minimal module lists in =init.el=.

* Sensible-defaults style helpers

Small functions in the style of the sensible-defaults package. They only set bindings when called, and nothing in the repository appears to call the umbrella function, so these are likely inactive.

** Commenting with M-;

=sp-bind-commenting= rebinds =M-;= to =sp-comment-region-or-line=, which is defined in =sp-helper-funct=. It still uses the older =global-set-key= style.

#+begin_src emacs-lisp -i
(defun sp-bind-commenting ()
  "Comment or uncomment a region by hitting M-;."
  (global-set-key (kbd "M-;")
                  'sp-comment-region-or-line))
#+end_src

** Home and End keys

=sp-bind-home-and-end-keys= makes =<home>= and =<end>= move to the beginning and end of the line. The comment above it notes that this is redundant with =C-a= and =C-e= and should probably be removed.

#+begin_src emacs-lisp -i
;; this should be removed because I can already do C-a and C-e on Linux and MacOS to get
;; to the proper end of line.
(defun sp-bind-home-and-end-keys ()
  "Make <home> and <end> move point to the beginning and end of
the line, respectively."
  (keymap-global-set "<home>" 'move-beginning-of-line)
  (keymap-global-set "<end>" 'move-end-of-line))
#+end_src

** Enable all sensible-defaults bindings

=sensible-defaults/use-all-keybindings= calls the two helpers above. No caller was found in the config, so neither binding is applied unless this is invoked by hand.

#+begin_src emacs-lisp -i
(defun sensible-defaults/use-all-keybindings ()
  "Use all of the sensible-defaults keybindings."
  (sp-bind-commenting)
  (sp-bind-home-and-end-keys))
#+end_src

* Protected keys and bind-key

** ironkey

=ironkey= (installed from GitHub) protects selected global bindings from being shadowed by minor or major mode keymaps.

- =ironkey-iron-alist= lists =M-.= and the =C-x p= project prefix, both mapped to =nil=. Per the inline comments, that means "keep the global-map definition".
- =ironkey-update= runs on =after-init-hook=, so it picks up bindings made during startup.
- =ironkey-mode= is switched on.

#+begin_src emacs-lisp -i
;;;; ironkey setup
;; Protecting keybindings in certain keymaos
(use-package ironkey
  :ensure (:type git :host github :repo "JimDBh/ironkey")
  :demand t
  :hook 
  ((after-init . ironkey-update))
  
  :config
  (setq ironkey-iron-alist `((,(kbd "M-.") . nil) ;; command in global-map
                             (,(kbd "C-x p") . nil))) ;; prefix keymap in global-map
                             
  (ironkey-mode t))
#+end_src

** bind-key settings

* Replaced prefixes and chords

Most of the common Emacs keys are bound differently here. This table is the place to look them up.

- How to find what a key does on this machine:
   + =C-h k= then the key shows the command under it.
   + =C-h w= (=where-is=) then a command name shows its keys.
   + =M-x describe-key-briefly= is the one-line version.
- Where the changes are made: =sp-macos= (Command is Super, Option is Meta), =sp-text-manipulation= (clipboard, undo, prefix swap) and the leader below.
- "Mac" is macOS with Command as =s-=. "Linux/Windows" is Ctrl for the clipboard and Super for the prefixes.
- A second key of a chord can stay a Ctrl chord: =s-x C-f= is =C-x C-f=.

| Stock Emacs        | Job                  | Mac                | Linux/Windows           | Notes |
|--------------------+----------------------+--------------------+-------------------------+-------|
| =C-c= (region)     | copy (CUA)           | =s-c=              | =C-c= (typed first)     | =kill-ring-save= |
| =C-x= (region)     | cut (CUA)            | =s-x=              | =C-x= (typed first)     | =kill-region= |
| =M-w=              | copy                 | unbound            | unbound                 | use the copy key |
| =C-w=              | cut                  | unbound            | unbound                 | use the cut key |
| =C-y=              | paste                | =s-v=              | =C-v=                   | =yank= |
| =C-v=              | scroll               | =C-v= (scroll)     | paste                   | scroll with =<next>= (page down) there |
| =C-_=, =C-/=, =C-?=, =C-x u= | undo       | =s-z=              | =C-z=                   | =undo=, all four unbound |
| =C-M-_=            | redo                 | =s-Z= or =S-s-z=   | =C-S-z=                 | =undo-redo= |
| =C-z=              | suspend frame        | unbound            | undo                    | |
| =C-x C-c=          | quit Emacs           | unbound            | unbound                 | too easy to hit; see =sp-text-manipulation= |
| =M-q=              | fill paragraph       | quit Emacs         | quit Emacs              | Option+Q / Alt+Q; fill moved to =C-; p= |
| =s-q=              | (Mac default: quit)  | quit Emacs         | unbound                 | Command+Q |
| =C-; p=            | (none)               | fill paragraph     | fill paragraph          | was =M-q= |
| =C-c= prefix       | user and mode keys   | =C-c=              | =s-c=                   | =s-c C-c= is =C-c C-c= |
| =C-x= prefix       | core commands        | =C-x=              | =s-x=                   | =s-x C-f= is =C-x C-f= |
| =C-x C-SPC=        | old leader           | =C-x C-SPC=        | =s-x C-SPC=             | prints where the leader moved |
| =C-;= (flyspell)   | correct word         | leader             | leader                  | spelling is on =C-; z= |

- Lines marked "typed first" mean the typed key starts a sequence; inside a sequence it keeps its stock meaning.
- The leader (=C-;=) and the shims for old =C-c= keys are described in the sections below; =M-x sp-keys-audit= lists them.
- The top-level [[file:../../../../../../README.org][README.org]] points here.

* Leader prefix

Everything personal hangs off one prefix so that it can be remapped in one place.

** The personal prefix

- =sp-prefix= is a user option holding the prefix string for all personal keys.
- Its default is =C-;=.
- It was =C-x C-SPC=, which cannot be typed when the OS keeps Ctrl+Space for the input-source switch.
- It is not =C-z=, =C-x=, =C-c= or =C-v=: these are clipboard and undo keys (=C-v=, =C-z=, and copy and cut on =C-c= and =C-x= on Linux and Windows); see =sp-text-manipulation=.
- =flyspell-mode-map= used to bind =C-;=; =sp-spelling= now unbinds it, and its command lives on =C-; z p=.
- Every prefix map below is built by appending a letter to this string.
- Design: [[file:../../architecture/global-keymap-namespaces.org][global-keymap-namespaces]].

#+begin_src emacs-lisp -i
;;;;; Personal Keybindings Prefix
(defcustom sp-prefix "C-;"
  "Prefix for all personal keybinds."
  :type 'string
  :group 'spcustom)
#+end_src

** Leader keymap

=lem+leader-map= is meant as an overriding keymap for a modal-style leader key.

- Its declared =:type= is ='string= although the value is a keymap. That only matters if it is edited through Customize.
- The =bind-keys= call then installs this map as the prefix map on =sp-prefix=.

#+begin_src emacs-lisp -i
;;;;; Personal Leader Key

(defcustom lem+leader-map (make-sparse-keymap)
  "An overriding keymap for <leader> key, for use with modal keybindings."
  :type 'string
  :group 'spcustom)

;; Use sp-prefix as leader namespace
(bind-keys :prefix-map lem+leader-map
           :prefix sp-prefix)
;; Filling a paragraph moved here when M-q became quit (`sp-text-manipulation').
(keymap-set lem+leader-map "p" #'fill-paragraph)
#+end_src

- =C-; p= is =fill-paragraph=, moved from =M-q= (now quit); Org buffers get =org-fill-paragraph= through Org's remap.

** Legacy leader (C-x C-SPC)

- =sp-keys-legacy-leader= answers the old leader key.
- It prints where the leader is now (=sp-prefix=).
- It then waits for the next key in =lem+leader-map=, so =C-x C-SPC b b= still works where the OS lets that key through.
- Remove it when you decide the shims can go.

#+begin_src emacs-lisp -i
;;;;; Legacy Leader (C-x C-SPC)
(defun sp-keys-legacy-leader ()
  "Say that the leader moved to `sp-prefix', then read the next key as usual."
  (interactive)
  (message "The leader moved to %s" sp-prefix)
  (set-transient-map lem+leader-map))

(keymap-global-set "C-x C-SPC" #'sp-keys-legacy-leader)
#+end_src

** Moved keys (shims)

- =sp-keys-moved= lists each key that moved: old key, new key (below =sp-prefix=) and command.
- =sp-keys--shim= builds a command that prints where the key went, then runs the command.
- =sp-keys-define-shims= binds every old key to its shim.
- The shims stay until you remove them: delete a row of =sp-keys-moved=.
- Keys that moved without a shim, because they were not working or are used by another command now:
  + =C-c s l=, =C-c s r= (now =consult-line=, =consult-ripgrep=),
  + =C-c m= (now =supersonic=; the minibuffer jump is =w M=),
  + =<f6>= (now =projectile-run-project=; redraw is =w D=),
  + =C-c f= (now only the Org footnote prefix; dirvish is =f d=, the focus HUD =a f=).
- The old academic keys have no shims (removed on request): =C-c w b ...= is now =B ...= (BibTeX lint: =L b ...=, the key fix =L b f k=), =C-c k ...= is now =k ...=. They are unbound.

#+begin_src emacs-lisp -i
;;;;;; Moved keys (shims)
(defconst sp-keys-moved
  '(("C-c s s" "S s" easysession-save-as)
    ("C-c s L" "S L" easysession-switch-to-and-restore-geometry)
    ("C-c s d" "S d" easysession-delete)
    ("C-c s R" "S R" easysession-reset)
    ("C-c e b b" "e b" eval-buffer))
  "Old key, new key below `sp-prefix' and command of each key that moved.")

(defun sp-keys--shim (old new command)
  "Return a command that says OLD moved to NEW, then runs COMMAND."
  (lambda ()
    (interactive)
    (message "%s moved to %s %s" old sp-prefix new)
    (call-interactively command)))

(defun sp-keys-define-shims ()
  "Bind every old key of `sp-keys-moved' to a shim for its new key."
  (dolist (entry sp-keys-moved)
    (pcase-let ((`(,old ,new ,command) entry))
      (keymap-global-set old (sp-keys--shim old new command)))))

(sp-keys-define-shims)
#+end_src

** Audit of the leader tree

- =M-x sp-keys-audit= opens =*sp-keys-audit*=.
- It lists every leader key whose command is not defined.
  + A command of a package that is not loaded yet shows up too; load the package and run it again.
- It lists the shims still alive.
- =sp-keys--walk= walks a keymap and calls a function on each key and binding, following prefix maps.

#+begin_src emacs-lisp -i
;;;;;; Audit of the leader tree
(defun sp-keys--walk (map prefix function)
  "Call FUNCTION with each key and binding of MAP, below the key string PREFIX."
  (map-keymap
   (lambda (event binding)
     (let ((key (string-trim (concat prefix " " (key-description (vector event))))))
       (if (and (symbolp binding) binding (keymapp binding))
           (sp-keys--walk (indirect-function binding) key function)
         (funcall function key binding))))
   map))

(defun sp-keys-audit ()
  "List leader keys whose command is not defined, and the shims still alive."
  (interactive)
  (let (void)
    (sp-keys--walk lem+leader-map sp-prefix
                   (lambda (key binding)
                     (when (and (symbolp binding) binding (not (fboundp binding)))
                       (push (format "%s  %s" key binding) void))))
    (with-current-buffer (get-buffer-create "*sp-keys-audit*")
      (let ((inhibit-read-only t))
        (erase-buffer)
        (insert (format "Leader: %s\n\n" sp-prefix))
        (insert (format "Bound to a command that is not defined (%d):\n" (length void)))
        (dolist (line (nreverse void))
          (insert "  " line "\n"))
        (insert (format "\nShims still alive (%d):\n" (length sp-keys-moved)))
        (dolist (entry sp-keys-moved)
          (insert (format "  %s -> %s %s\n" (nth 0 entry) sp-prefix (nth 1 entry))))
        (goto-char (point-min)))
      (special-mode)
      (pop-to-buffer (current-buffer)))))
#+end_src

** Quote block

=<leader> "= (=C-; "=) runs =sp-org-insert-quote-from-kill= from [[file:../text/sp-org-base.org][sp-org-base]].

- It inserts an Org quote block holding the latest kill ring item, or the region when one is active.
- Hard line breaks in the text are joined; blank lines between paragraphs stay.
- A prefix argument (=C-u C-; "=) gives an empty block.
- It replaces =C-c C-,= then =q= followed by a paste: two keys instead of four chords.
- It sits on the leader root, not under a group, because it is meant to be fast.
- The key is free in the leader tree: the neighbours are the group letters, =.= (transpose) and nothing on punctuation.
- =C-; "= needs a GUI frame (a terminal cannot send =C-;=), like the rest of the leader.
- The command is autoloaded from =sp-org-base=, which is loaded with the Org modules; =org-block-wrap= (=C-; c o=) stays for the other block types.

#+begin_src emacs-lisp -i
;;;;;; Quote block from the kill ring

(bind-key (concat sp-prefix " \"") #'sp-org-insert-quote-from-kill)

** Rectangle menu

=sp-rectangle-transient= is a persistent menu for rectangle editing.

- Movement, kill, yank, copy, open, string insert, clear, exchange point and mark, line numbering and undo all stay in the menu (=:transient t=). =g= quits.
- Its body enables =rectangle-mark-mode= on entry.
- It adds a one-shot =transient-exit-hook= function that deactivates the mark and removes itself, so every exit path leaves a clean region.
- Like the ediff menu, it has no key binding here.

    ("d" "Kill"   kill-rectangle           :transient t)

#+begin_src emacs-lisp -i
;;; sp-keys-test.el --- Tests for the academic and lint groups of sp-keys -*- lexical-binding: t; -*-

(require 'ert)
(require 'bind-key)
(require 'cl-lib)
(require 'subr-x)

(defconst sp-keys-test--file
  (expand-file-name "../libraries/modules/base/sp-keys.el"
                    (file-name-directory (or load-file-name buffer-file-name)))
  "The module under test.")

(defvar sp-prefix)
(defvar lem+leader-map)

(defun sp-keys-test--forms ()
  "The top-level forms of `sp-keys-test--file'."
  (with-temp-buffer
    (insert-file-contents sp-keys-test--file)
    (goto-char (point-min))
    (let (forms)
      (condition-case nil
          (while t (push (read (current-buffer)) forms))
        (end-of-file nil))
      (nreverse forms))))

(defun sp-keys-test--prefix (form)
  "The key string of the :prefix of a `bind-keys' FORM, with `sp-prefix' bound."
  (eval (plist-get (cdr form) :prefix) t))

(defun sp-keys-test--setup ()
  "Evaluate the groups B, k and L, the shim table and the shim function."
  (setq sp-prefix "C-;"
        lem+leader-map (make-sparse-keymap))
  (bind-keys :prefix-map lem+leader-map :prefix sp-prefix)
  (let (maps)
    (dolist (form (sp-keys-test--forms))
      (pcase form
        (`(bind-keys . ,_)
         (when (string-match-p "\\`C-; [BkL]\\(?: \\|\\'\\)" (sp-keys-test--prefix form))
           (eval form t)
           (push (plist-get (cdr form) :prefix-map) maps)))
        (`(defconst sp-keys-moved . ,_) (eval form t))
        (`(defun sp-keys--shim . ,_) (eval form t))))
    (nreverse maps)))

(defun sp-keys-test--command (map key)
  "The command KEY runs in the keymap variable MAP."
  (let ((binding (keymap-lookup (symbol-value map) key)))
    (and (symbolp binding) binding)))

(ert-deftest sp-keys-lint-verbs-are-the-same-everywhere ()
  (let ((maps (sp-keys-test--setup)) (groups 0))
    (dolist (map maps)
      (when (string-prefix-p "lem+lint-" (symbol-name map))
        (let ((list-cmd (sp-keys-test--command map "l"))
              (apply-cmd (sp-keys-test--command map "a")))
          (when apply-cmd
            (cl-incf groups)
            (should list-cmd)
            (should (string-suffix-p "-dryrun" (symbol-name list-cmd)))
            (should (string-suffix-p "-convert" (symbol-name apply-cmd)))
            (should (equal (string-remove-suffix "-dryrun" (symbol-name list-cmd))
                           (string-remove-suffix "-convert" (symbol-name apply-cmd))))))))
    (should (>= groups 8))))
