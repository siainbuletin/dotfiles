* What it is for

- A PDF can carry /page labels/ (the =/PageLabels= entry): a rule that says "physical page 1 is called 360, page 2 is 361, ...".
- A PDF viewer then shows the printed number, and a program can turn a printed number back into the physical page.
- Why it is needed here:
  - a journal PDF numbered 1 to 5 holds the pages 360 to 364 of the journal;
  - a book PDF has a cover and front matter, so printed page 1 is the 9th physical page.
- =sp-devonthink= opens a chapter in its parent's PDF at the chapter's first page; it needs printed page -> physical page.
- The information lives *in the PDF file* (ADR 0032), not in Emacs variables, not in the BibTeX file, and not in DEVONthink.
- Nothing here touches DEVONthink. DEVONthink only sees a file whose bytes changed.

* Using it

- All tools need =pikepdf= (it bundles qpdf): =pip install pikepdf=. Each script also has a PEP 723 header, so =uv run tools/pdf-labels-articles.py= works without installing anything.
- Every tool that can write is a *dry run unless you pass =--apply=*.
  - The dry run opens the PDFs read-only and prints what it would change.
  - With =--apply=, the original is copied to =~/.local/state/pdf-page-labels/backups/TIMESTAMP/...= first (change it with =--backup-dir=).
  - The new file is written next to the PDF under a temporary name, checked (same page count, same labels), and only then moved over the original.

** Articles, in batch

#+begin_example
tools/pdf-labels-articles.py                        # dry run over every .bib in ~/Documents/bibliography
tools/pdf-labels-articles.py --only smith-2017-x    # one entry (repeatable)
tools/pdf-labels-articles.py --apply --only smith-2017-x
tools/pdf-labels-articles.py --apply                # all of them
#+end_example

- It handles an entry when all of this holds:
  - the BibTeX type is =article=, =inproceedings=, =conference= or =suppperiodical= (change it with =--types=);
  - it has no =crossref= or =xref= (an entry tied to a parent is a chapter or paper in someone else's PDF);
  - it has a =pages= field whose first page it can read;
  - exactly one PDF is found for it.
- It skips, and reports why, every other entry: =book=, =collection=, =incollection=, =inbook=, =proceedings=, theses and reports (their =pages= is often a page count), and so on.
- The first page of =pages= becomes the label of physical page 1:
  - =360--364=, =360-364= and =360, 365= give 360;
  - =e123= gives the label =e123= (prefix =e=, then 123, 124, ...);
  - =xii--xv= gives roman numerals starting at xii; =XII= gives upper case;
  - anything else (=2:45=, =A-5=, an empty field) is skipped and reported.
- A PDF that already has different labels is skipped unless you pass =--force=; the same labels are reported as unchanged, so running it twice is safe.
- A warning is printed (and the PDF is still labelled) when the page range is not as long as the PDF, for example a 5-page range in a 6-page PDF with a cover sheet.
- Files are found as =sp-citations= finds them: the =file= field (relative to =~/Documents/literature=), then the same file name anywhere below the library.

** One book, by hand

#+begin_example
tools/pdf-labels-book.py smith-2017-x --first-page 9                       # dry run
tools/pdf-labels-book.py smith-2017-x --first-page 9 --front-roman         # pages 1-8 are i-viii
tools/pdf-labels-book.py smith-2017-x --first-page 11 --front-roman --front-roman-from 3
tools/pdf-labels-book.py ~/Documents/literature/x.pdf --first-page 9 --apply
#+end_example

- The target is a citekey or the path of a PDF.
- =--first-page N= is the physical page of the PDF where *printed page 1* starts (1 is the first page of the file).
- It never reads the BibTeX =pages= field: for a book that field is not about this PDF.
  - The citekey is only used to find the file.
- =--front-roman= numbers the pages before =--first-page= as i, ii, iii, ...; =--front-roman-upper= gives I, II, III.
  - =--front-roman-from N= starts the roman numbers at physical page N (default 1); pages before it get no label.
- Without =--front-roman=, pages before =--first-page= get no label (an empty label).
- It replaces any existing labels (you asked for it), after the backup.

** Label rules

- A =LabelRange= is one entry of the =/PageLabels= number tree:
  - =index= is the 0-based physical page where the rule starts, and it holds until the next rule;
  - =style= is =D= (1, 2, 3), =r= (i, ii), =R= (I, II) or None (no number);
  - =start= is the number the first page of the rule gets;
  - =prefix= is text put before the number (=e= gives =e123=).

#+begin_src python
@dataclass(frozen=True)
class LabelRange:
    """One page-label rule: from physical page INDEX (0-based) on."""
    index: int
    style: str = None
    start: int = 1
    prefix: str = ""


class Unparseable(ValueError):
    """A pages field (or a roman numeral) that cannot give a first page."""
#+end_src

** Reading the =pages= field

- =first_page_token= cuts the first page out of the field:
  - it drops a leading =p.= or =pp.=;
  - it cuts at the first range or list separator (=--=, =-=, en dash, em dash, comma, semicolon);
  - it drops a trailing =+=.
- =parse_first_page= turns the token into a =LabelRange= for physical page 1:
  - letters followed by digits (=e123=, =S45=) give prefix and decimal style;
  - digits give the decimal style;
  - a valid roman numeral gives style =r=, or =R= if written in capitals;
  - a number below 1, or anything else, raises =Unparseable= with the reason.

#+begin_src python
_ROMAN_RE = re.compile(
    r"(?=[mdclxvi])m{0,3}(cm|cd|d?c{0,3})(xc|xl|l?x{0,3})(ix|iv|v?i{0,3})", re.I)
_ROMAN_VALUES = {"i": 1, "v": 5, "x": 10, "l": 50, "c": 100, "d": 500, "m": 1000}
_SEPARATOR_RE = re.compile(r"\s*[-\u2013\u2014,;]+\s*")


def roman_to_int(text):
    """The value of the roman numeral TEXT, or Unparseable."""
    if not _ROMAN_RE.fullmatch(text):
        raise Unparseable(f"{text!r} is not a roman numeral")
    total, previous = 0, 0
    for char in reversed(text.lower()):
        value = _ROMAN_VALUES[char]
        if value < previous:
            total -= value
        else:
            total += value
            previous = value
    return total


def _clean_pages(pages):
    text = (pages or "").strip().strip("{}").strip()
    return re.sub(r"^pp?\.?\s*", "", text, flags=re.I)


def first_page_token(pages):
    """The text of the first page in the BibTeX PAGES string."""
    text = _clean_pages(pages)
    if not text:
        raise Unparseable("empty pages field")
    return _SEPARATOR_RE.split(text, maxsplit=1)[0].strip().rstrip("+").strip()


def parse_first_page(pages):
    """The LabelRange that makes physical page 1 carry the first page of PAGES."""
    token = first_page_token(pages)
    match = re.fullmatch(r"([A-Za-z]{1,4})?(\d+)", token)
    if match:
        number = int(match.group(2))
        if number < 1:
            raise Unparseable(f"page {number} is not positive")
        return LabelRange(0, "D", number, match.group(1) or "")
    try:
        number = roman_to_int(token)
    except Unparseable:
        raise Unparseable(f"cannot read a first page from {pages!r}") from None
    return LabelRange(0, "R" if token.isupper() else "r", number)


def page_span(pages):
    """How many pages the decimal range in PAGES covers, or None.

    =360--364= gives 5.  An abbreviated end (=1234--45=) is completed from the start."""
    parts = _SEPARATOR_RE.split(_clean_pages(pages))
    if len(parts) != 2:
        return None
    first, last = parts[0].strip(), parts[1].strip()
    if not (first.isdigit() and last.isdigit()):
        return None
    if len(last) < len(first):
        last = first[:len(first) - len(last)] + last
    span = int(last) - int(first) + 1
    return span if span >= 1 else None
#+end_src

** Reading and writing labels in a PDF

- =labels_of= gives the label of every physical page (pikepdf's =Page.label=, which follows the PDF's rules, and is the page number when there are none).
- =existing_ranges= gives the rules a PDF has, as =LabelRange= values, so a dry run can say what would be replaced, and a second run can see "unchanged".
- =set_labels= replaces the =/PageLabels= tree with a flat list of rules.
- =find_pages= is the reverse lookup used by Emacs: label -> physical pages counted from 1; case is ignored only when there is no exact match.

#+begin_src python
def open_pdf(path):
    """Open PATH from memory, so that the file can be replaced while open."""
    require_pikepdf()
    return pikepdf.open(io.BytesIO(Path(path).read_bytes()))


def has_labels(pdf):
    return "/PageLabels" in pdf.Root


def labels_of(pdf):
    """The label of every page, in physical order."""
    return [page.label for page in pdf.pages]


def existing_ranges(pdf):
    """The label rules of PDF as a list of LabelRange, empty when it has none."""
    if not has_labels(pdf):
        return []
    ranges = []
    for index, rule in sorted(pikepdf.NumberTree(pdf.Root.PageLabels).items()):
        style = str(rule.S)[1:] if "/S" in rule else None
        prefix = str(rule.P) if "/P" in rule else ""
        start = int(rule.St) if "/St" in rule else 1
        ranges.append(LabelRange(int(index), style, start, prefix))
    return ranges


def set_labels(pdf, ranges):
    """Replace the page labels of PDF with RANGES."""
    nums = pikepdf.Array()
    for item in sorted(ranges, key=lambda r: r.index):
        rule = pikepdf.Dictionary()
        if item.style:
            rule["/S"] = pikepdf.Name("/" + item.style)
        if item.prefix:
            rule["/P"] = pikepdf.String(item.prefix)
        if item.start != 1:
            rule["/St"] = item.start
        nums.append(item.index)
        nums.append(rule)
    pdf.Root["/PageLabels"] = pdf.make_indirect(pikepdf.Dictionary(Nums=nums))


def find_pages(pdf, label):
    """The physical pages (counted from 1) whose label is LABEL."""
    labels = labels_of(pdf)
    exact = [i + 1 for i, found in enumerate(labels) if found == label]
    return exact or [i + 1 for i, found in enumerate(labels)
                     if found.casefold() == label.casefold()]


def describe(ranges):
    """A short text for RANGES, for reports."""
    if not ranges:
        return "no page labels"
    names = {"D": "1,2,3", "r": "i,ii,iii", "R": "I,II,III", None: "no number"}
    return "; ".join(
        f"from PDF page {r.index + 1}: {r.prefix}{r.start} ({names.get(r.style, r.style)})"
        if r.style else f"from PDF page {r.index + 1}: unnumbered"
        for r in ranges)

** Writing a PDF safely

- =write_labels= is the only function that changes a file:
  1. it reads the PDF and sets the labels in memory;
  2. it saves to a temporary file in the same folder;
  3. it reopens the temporary file and checks the page count and the label rules;
  4. it copies the *original* to the backup folder;
  5. it replaces the original with the temporary file.
- If any step fails, the temporary file is removed and the original is untouched.
- The backup path repeats the original's folders, so two PDFs with the same name do not clash.
- The modification time is not kept: it changes, so tools that watch files notice.

#+begin_src python
def backup_path(path, backup_root):
    """Where the backup of PATH goes below BACKUP_ROOT."""
    return Path(backup_root).joinpath(*Path(path).resolve().parts[1:])


def new_backup_root(base):
    """A fresh folder for one run's backups, named by the time."""
    return Path(base).expanduser() / datetime.now().strftime("%Y%m%d-%H%M%S")


def write_labels(path, ranges, backup_root):
    """Back PATH up below BACKUP_ROOT, then rewrite it with the labels RANGES.

    Returns the path of the backup."""
    path = Path(path)
    ranges = sorted(ranges, key=lambda r: r.index)
    pdf = open_pdf(path)
    pages = len(pdf.pages)
    set_labels(pdf, ranges)
    handle, temp = tempfile.mkstemp(suffix=".pdf", prefix=".labels-", dir=path.parent)
    os.close(handle)
    try:
        pdf.save(temp)
        with pikepdf.open(temp) as check:
            if len(check.pages) != pages or existing_ranges(check) != ranges:
                raise RuntimeError("the saved file does not match: left the original alone")
        backup = backup_path(path, backup_root)
        backup.parent.mkdir(parents=True, exist_ok=True)
        shutil.copy2(path, backup)
        shutil.copymode(path, temp)
        os.replace(temp, path)
    except BaseException:
        if os.path.exists(temp):
            os.remove(temp)
        raise
    return backup
#+end_src

** Reading BibTeX

- A small reader, enough for citekey, type and fields; it does not expand macros or concatenations.
- Field names are lower-cased, values have braces around the whole value removed and white space collapsed.
- =@string=, =@comment= and =@preamble= are ignored.
- A citekey that occurs twice keeps the first entry, and the duplicate is reported by =load_bibs=.

#+begin_src python
_ENTRY_START = re.compile(r"@\s*([A-Za-z]+)\s*([{(])\s*([^,\s{}()]*)\s*(,?)")
_FIELD_START = re.compile(r"[\s,]*([A-Za-z][\w:\-]*)\s*=\s*")
_NOT_ENTRIES = {"string", "comment", "preamble"}


@dataclass
class Entry:
    key: str
    type: str
    fields: dict
    source: Path = None


def _balanced(text, start, open_char, close_char):
    """The index just after the bracket that closes the one at TEXT[START]."""
    depth, i = 0, start
    while i < len(text):
        char = text[i]
        if char == "\\":
            i += 2
            continue
        if char == open_char:
            depth += 1
        elif char == close_char:
            depth -= 1
            if depth == 0:
                return i + 1
        i += 1
    return len(text)


def _parse_fields(body):
    fields, i = {}, 0
    while True:
        match = _FIELD_START.match(body, i)
        if not match or match.end() >= len(body):
            return fields
        name, i = match.group(1).lower(), match.end()
        if body[i] == "{":
            end = _balanced(body, i, "{", "}")
            value = body[i + 1:end - 1]
        elif body[i] == '"':
            end = i + 1
            depth = 0
            while end < len(body) and not (body[end] == '"' and depth == 0):
                if body[end] == "\\":
                    end += 1
                elif body[end] == "{":
                    depth += 1
                elif body[end] == "}":
                    depth -= 1
                end += 1
            value = body[i + 1:end]
            end += 1
        else:
            end = re.compile(r"[^,]*").match(body, i).end()
            value = body[i:end].strip()
        fields.setdefault(name, " ".join(value.split()))
        i = end


def parse_bib(text, source=None):
    """The entries of the BibTeX TEXT, as a list of Entry."""
    entries, position = [], 0
    while True:
        match = _ENTRY_START.search(text, position)
        if not match:
            return entries
        close = "}" if match.group(2) == "{" else ")"
        end = _balanced(text, match.start(2), match.group(2), close)
        position = end
        kind = match.group(1).lower()
        if kind in _NOT_ENTRIES or not match.group(4):
            continue
        entries.append(Entry(match.group(3), kind,
                             _parse_fields(text[match.end():end - 1]), source))


def bib_files(bib_dir):
    """Every .bib file directly in BIB_DIR."""
    return sorted(Path(bib_dir).expanduser().glob("*.bib"))


def load_bibs(paths):
    """Entries of the .bib files PATHS by citekey, and the keys found twice."""
    entries, duplicates = {}, []
    for path in paths:
        for entry in parse_bib(Path(path).read_text(encoding="utf-8", errors="replace"), path):
            if entry.key in entries:
                duplicates.append(entry.key)
            else:
                entries[entry.key] = entry
    return entries, duplicates
#+end_src

** Finding the PDF of an entry

- It follows =sp-citations= (=sp-citations-parser-library=):
  - the =file= field is split at =;= (a JabRef =description:path:type= triple gives its middle part);
  - a path is relative to the library unless it is absolute or starts with =~=;
  - a name that does not exist is looked up by file name, ignoring case and Unicode form, anywhere below the library;
  - an entry with no =file= field is looked up as =CITEKEY.pdf=.
- The index of the library is built once, the first time a lookup misses.

#+begin_src python
def _normal(name):
    return unicodedata.normalize("NFC", name).casefold()


class Library:
    """The literature folder, with a lazy index of its files by name."""

    def __init__(self, root):
        self.root = Path(root).expanduser()
        self._index = None

    def find(self, name):
        """The files below the library called like the path NAME."""
        if self._index is None:
            self._index = {}
            for folder, dirs, files in os.walk(self.root):
                dirs[:] = [d for d in dirs if not d.startswith(".")]
                for file in files:
                    self._index.setdefault(_normal(file), []).append(Path(folder) / file)
        return self._index.get(_normal(Path(name).name), [])

    def pdfs_of(self, entry):
        """The existing PDFs of ENTRY, without duplicates."""
        found = []
        pieces = [p.strip() for p in entry.fields.get("file", "").split(";") if p.strip()]
        for piece in pieces:
            parts = piece.split(":")
            if len(parts) >= 3:
                piece = parts[1]
            if not piece.lower().endswith(".pdf"):
                continue
            path = Path(piece).expanduser()
            if not path.is_absolute():
                path = self.root / path
            found.extend([path] if path.is_file() else self.find(piece))
        if not pieces:
            found.extend(self.find(entry.key + ".pdf"))
        return list(dict.fromkeys(p for p in found if p.suffix.lower() == ".pdf"))

A dry run unless --apply is given.  Only entries that are not tied to a book:
type article (or inproceedings, conference, suppperiodical) without crossref.

Tangled from docs/tangles/academic/pdf-page-labels.org; edit that file.
"""

import argparse
import sys
from dataclasses import dataclass, field
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
import pdf_page_labels as pl  # noqa: E402

DEFAULT_TYPES = ("article", "inproceedings", "conference", "suppperiodical")


@dataclass
class Plan:
    key: str
    status: str                  # label, unchanged or skip
    reason: str = ""
    path: Path = None
    ranges: list = field(default_factory=list)
    warning: str = ""
    quiet: bool = False          # a skip that is only counted


def plan_entry(entry, library, types, force):
    """What to do for ENTRY.  Opens its PDF read-only; never writes."""
    if entry.type not in types:
        return Plan(entry.key, "skip", f"type {entry.type} is not handled", quiet=True)
    for tie in ("crossref", "xref"):
        if entry.fields.get(tie):
            return Plan(entry.key, "skip", f"tied to {entry.fields[tie]} ({tie}); use pdf-labels-book.py",
                        quiet=True)
    pages = entry.fields.get("pages", "")
    if not pages.strip():
        return Plan(entry.key, "skip", "no pages field")
    try:
        wanted = pl.parse_first_page(pages)
    except pl.Unparseable as error:
        return Plan(entry.key, "skip", str(error))
    pdfs = library.pdfs_of(entry)
    if not pdfs:
        return Plan(entry.key, "skip", "no PDF found")
    if len(pdfs) > 1:
        return Plan(entry.key, "skip", "several PDFs: " + ", ".join(p.name for p in pdfs))
    path = pdfs[0]
    try:
        pdf = pl.open_pdf(path)
        count = len(pdf.pages)
        current = pl.existing_ranges(pdf)
    except Exception as error:   # encrypted, damaged, not a PDF
        return Plan(entry.key, "skip", f"cannot open {path.name}: {error}", path)
    plan = Plan(entry.key, "label", f"pages {pages!r} -> first page {wanted.prefix}{wanted.start}",
                path, [wanted])
    span = pl.page_span(pages)
    if span and span != count:
        plan.warning = f"range has {span} pages, the PDF has {count}: check for a cover sheet"
    if current == [wanted]:
        plan.status = "unchanged"
    elif current and not force:
        plan.status = "skip"
        plan.reason = f"already has labels ({pl.describe(current)}); --force replaces them"
    return plan


def parse_args(argv):
    parser = argparse.ArgumentParser(description=__doc__.split("\n\n")[0])
    pl.add_common_arguments(parser)
    parser.add_argument("--only", action="append", default=[], metavar="KEY",
                        help="only this citekey; repeat it")
    parser.add_argument("--types", default=",".join(DEFAULT_TYPES),
                        help="comma-separated BibTeX types to handle (default %(default)s)")
    parser.add_argument("--force", action="store_true",
                        help="replace page labels the PDF already has")
    parser.add_argument("--verbose", action="store_true",
                        help="also list the entries skipped for their type or crossref")
    return parser.parse_args(argv)


def main(argv=None):
    args = parse_args(argv)
    pl.require_pikepdf()
    entries, duplicates = pl.load_bibs(pl.bib_paths(args))
    for key in duplicates:
        print(f"warning: citekey {key} occurs twice; the first entry is used", file=sys.stderr)
    types = {t.strip().lower() for t in args.types.split(",") if t.strip()}
    library = pl.Library(args.library)
    report = pl.Report(args.apply)
    backup_root = pl.new_backup_root(args.backup_dir)
    wanted_keys = set(args.only)
    for missing in sorted(wanted_keys - set(entries)):
        report.line("skip", missing, "not in the .bib files")
    for entry in entries.values():
        if wanted_keys and entry.key not in wanted_keys:
            continue
        plan = plan_entry(entry, library, types, args.force)
        suffix = f" [warning: {plan.warning}]" if plan.warning else ""
        if plan.status == "skip":
            report.line("skip", entry.key, plan.reason, show=args.verbose or not plan.quiet)
        elif plan.status == "unchanged":
            report.line("unchanged", entry.key, plan.path.name, show=args.verbose)
        elif not args.apply:
            report.line("would-label", entry.key, f"{plan.path.name}: {plan.reason}{suffix}")
        else:
            try:
                pl.write_labels(plan.path, plan.ranges, backup_root)
                report.line("labelled", entry.key, f"{plan.path.name}: {plan.reason}{suffix}")
            except Exception as error:
                report.line("failed", entry.key, f"{plan.path.name}: {error}")
    report.summary()
    if args.apply and report.counts.get("labelled"):
        print(f"Originals are in {backup_root}")
    return 1 if report.counts.get("failed") else 0


if __name__ == "__main__":
    sys.exit(main())

"""Write PDF page labels for one book, from the page where printed page 1 starts.

    pdf-labels-book.py CITEKEY-OR-PDF --first-page N [--front-roman] [--apply]

A dry run unless --apply is given.  It does not read the BibTeX `pages` field.

Tangled from docs/tangles/academic/pdf-page-labels.org; edit that file.
"""

import argparse
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
import pdf_page_labels as pl  # noqa: E402


def book_ranges(first_page, front_roman=False, roman_upper=False, roman_from=1):
    """The label rules for a book whose printed page 1 is physical page FIRST_PAGE."""
    if first_page < 1:
        raise ValueError("--first-page counts from 1")
    ranges = []
    if front_roman:
        if not 1 <= roman_from < first_page:
            raise ValueError("--front-roman-from must be at least 1 and before --first-page")
        if roman_from > 1:
            ranges.append(pl.LabelRange(0))
        ranges.append(pl.LabelRange(roman_from - 1, "R" if roman_upper else "r", 1))
    elif first_page > 1:
        ranges.append(pl.LabelRange(0))
    ranges.append(pl.LabelRange(first_page - 1, "D", 1))
    return ranges


def find_pdf(target, library, bib_files):
    """The PDF for TARGET, a path or a citekey; exits with a message when not exactly one."""
    path = Path(target).expanduser()
    if path.suffix.lower() == ".pdf" and path.is_file():
        return path
    entries, _ = pl.load_bibs(bib_files)
    if target in entries:
        pdfs = library.pdfs_of(entries[target])
    else:
        pdfs = library.find(target + ".pdf")
    if not pdfs:
        sys.exit(f"no PDF found for {target}")
    if len(pdfs) > 1:
        sys.exit(f"several PDFs for {target}; pass the path of one:\n  "
                 + "\n  ".join(map(str, pdfs)))
    return pdfs[0]


def parse_args(argv):
    parser = argparse.ArgumentParser(description=__doc__.split("\n\n")[0])
    parser.add_argument("target", help="a citekey, or the path of a PDF")
    pl.add_common_arguments(parser)
    parser.add_argument("--first-page", type=int, required=True, metavar="N",
                        help="the PDF page (1 is the first page of the file) where printed page 1 is")
    parser.add_argument("--front-roman", action="store_true",
                        help="number the pages before --first-page i, ii, iii, ...")
    parser.add_argument("--front-roman-upper", action="store_true",
                        help="with --front-roman: I, II, III")
    parser.add_argument("--front-roman-from", type=int, default=1, metavar="N",
                        help="with --front-roman: the PDF page where i is (default 1)")
    return parser.parse_args(argv)


def main(argv=None):
    args = parse_args(argv)
    pl.require_pikepdf()
    try:
        ranges = book_ranges(args.first_page, args.front_roman,
                             args.front_roman_upper, args.front_roman_from)
    except ValueError as error:
        sys.exit(str(error))
    path = find_pdf(args.target, pl.Library(args.library), pl.bib_paths(args))
    pdf = pl.open_pdf(path)
    count = len(pdf.pages)
    if args.first_page > count:
        sys.exit(f"{path.name} has {count} pages, --first-page {args.first_page} is past the end")
    current = pl.existing_ranges(pdf)
    print(f"file:     {path}")
    print(f"pages:    {count}")
    print(f"current:  {pl.describe(current)}")
    print(f"new:      {pl.describe(ranges)}")
    if current == ranges:
        print("nothing to do: the labels are already these")
        return 0
    if not args.apply:
        print("This was a dry run: nothing was written.  Add --apply to write.")
        return 0
    backup = pl.write_labels(path, ranges, pl.new_backup_root(args.backup_dir))
    print(f"written; the original is {backup}")
    return 0


if __name__ == "__main__":
    sys.exit(main())

"""Read the page labels of a PDF.

    pdf-labels-read.py FILE --resolve LABEL   print the PDF page (from 1)
    pdf-labels-read.py FILE --list            print PDF page and label
    pdf-labels-read.py FILE --describe        print the label rules

Tangled from docs/tangles/academic/pdf-page-labels.org; edit that file.

import argparse
import sys

import pdf_page_labels as pl  # noqa: E402

EXIT_NO_LABELS, EXIT_NOT_FOUND, EXIT_ERROR = 3, 4, 2


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__.split("\n\n")[0])
    parser.add_argument("file")
    what = parser.add_mutually_exclusive_group(required=True)
    what.add_argument("--resolve", metavar="LABEL")
    what.add_argument("--list", action="store_true")
    what.add_argument("--describe", action="store_true")
    args = parser.parse_args(argv)
    pl.require_pikepdf()
    try:
        pdf = pl.open_pdf(args.file)
    except Exception as error:
        print(f"cannot open {args.file}: {error}", file=sys.stderr)
        return EXIT_ERROR
    if args.describe:
        print(pl.describe(pl.existing_ranges(pdf)))
        return 0
    if args.list:
        for number, label in enumerate(pl.labels_of(pdf), 1):
            print(f"{number}\t{label}")
        return 0
    if not pl.has_labels(pdf):
        print("the PDF has no page labels", file=sys.stderr)
        return EXIT_NO_LABELS
    pages = pl.find_pages(pdf, args.resolve)
    if not pages:
        print(f"no page is labelled {args.resolve}", file=sys.stderr)
        return EXIT_NOT_FOUND
    if len(pages) > 1:
        print(f"warning: {len(pages)} pages are labelled {args.resolve}; using the first",
              file=sys.stderr)
    print(pages[0])
    return 0


if __name__ == "__main__":
    sys.exit(main())
