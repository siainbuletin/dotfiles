- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../tangling-instructions.org][Tangling instructions]].
- Status: first implementation, macOS only. The AppleScript was written from the DEVONthink dictionary as remembered and has not been run: test each command by hand first (see the end of this file).

* What it is for

- One command, =sp-reading-open=, takes a citekey and opens that work for reading.
- Reading happens in DEVONthink when the work is already there.
- When it is not, the command decides what to do with the PDF.

| Situation | What happens |
|-----------+--------------|
| record found in DEVONthink | opens it at the page, with =x-devonthink-item://= |
| no record, PDF known to =citar= | you choose: index in DEVONthink, or open in Preview |
| no PDF | tells you; fetch it with =sp-fetch-academic= |

- /Index/ means DEVONthink points at the file where it is (=~/Documents/literature/=); the file is not copied into the database.
- Preview is the reader for files you decide not to index.

* Looking up a record

- The cache =sp-reading-index= maps citekey to the DEVONthink UUID.
  - It is filled by one AppleScript call (=sp-reading-refresh=) that lists the names and UUIDs of the PDFs in a database.
  - The name of a record is =KEY.pdf=, so the citekey is the name without its extension.
- When the cache has no hit, one more lookup asks DEVONthink directly, by file path and then by name.
- The UUID is used as the link: =x-devonthink-item://UUID?page=N=.
  - DEVONthink counts pages from 0 in this URL, so page 6 of the paper is =?page=5=.

;; the PDF or open it in Preview.  macOS only.

(require 'cl-lib)
(require 'subr-x)
(require 'seq)

(declare-function citar-get-files "citar")

(defgroup sp-reading nil
  "Read cited works in DEVONthink."
  :group 'convenience)

(defcustom sp-reading-database "literature"
  "Name of the DEVONthink database that holds the literature."
  :type 'string :group 'sp-reading)

(defcustom sp-reading-index-group nil
  "Name of the group in `sp-reading-database' that new indexed files go to.
Nil means the root of the database."
  :type '(choice (const nil) string) :group 'sp-reading)

(defcustom sp-reading-preview-command '("open" "-a" "Preview")
  "Command (a list) that opens a PDF in the fallback reader; the file is appended."
  :type '(repeat string) :group 'sp-reading)
#+end_src

* Talking to DEVONthink

- All access goes through =osascript=; the database package is never touched as files.
- Strings put into a script are escaped, so a quote or backslash in a key cannot break it.
- A failing script raises an error with DEVONthink's message.

#+begin_src emacs-lisp
(defun sp-reading--quote (string)
  "STRING as an AppleScript string literal."
  (concat "\""
          (replace-regexp-in-string "\"" "\\\\\"" (replace-regexp-in-string "\\\\" "\\\\\\\\" string))
          "\""))

(defun sp-reading--osascript (script)
  "Run the AppleScript SCRIPT and return its output without the final newline."
  (with-temp-buffer
    (let ((status (call-process "osascript" nil t nil "-e" script)))
      (unless (eql status 0)
        (error "osascript failed: %s" (string-trim (buffer-string))))
      (string-trim-right (buffer-string) "\n"))))
#+end_src

* The cache of citekeys

- =sp-reading--parse-listing= turns the script output (one =UUID<tab>name= per line) into the cache; it is a plain function so the tests can feed it text.
- Only names ending in =.pdf= count, and the citekey is the name without it.
- The refresh script asks for the names and the UUIDs of all PDFs in one go, which is far quicker than one call per record.

#+begin_src emacs-lisp
(defvar sp-reading-index nil
  "Hash table from citekey to DEVONthink UUID, or nil before the first refresh.")

(defun sp-reading--parse-listing (text)
  "A hash table from citekey to UUID, read from TEXT (lines of UUID, tab, name)."
  (let ((table (make-hash-table :test 'equal)))
    (dolist (line (split-string text "\n" t))
      (let ((parts (split-string line "\t")))
        (when (and (= (length parts) 2) (string-suffix-p ".pdf" (cadr parts) t))
          (puthash (substring (cadr parts) 0 -4) (car parts) table))))
    table))

(defun sp-reading--listing-script ()
  "The AppleScript that lists UUID and name of every PDF in the database."
  (format "tell application id \"DNtp\"
  set theRecords to search \"kind:pdf\" in root of database %s
  set theOut to {}
  repeat with r in theRecords
    set end of theOut to (uuid of r as text) & tab & (name of r as text)
  end repeat
  set AppleScript's text item delimiters to linefeed
  return theOut as text
end tell"
          (sp-reading--quote sp-reading-database)))

(defun sp-reading-refresh ()
  "Read the citekeys and UUIDs of the PDFs in DEVONthink into `sp-reading-index'."
  (interactive)
  (setq sp-reading-index
        (sp-reading--parse-listing (sp-reading--osascript (sp-reading--listing-script))))
  (message "sp-reading: %d PDFs in %s" (hash-table-count sp-reading-index) sp-reading-database)
  sp-reading-index)
#+end_src

* Finding one record

- First the cache, no call to DEVONthink.
- If the key is not there, ask DEVONthink once for a record whose name is =KEY.pdf=, and remember the answer.
- A key that is not in DEVONthink returns nil.
- The lookup by content hash that the design mentions is not built yet: it needs a command whose name must first be checked in the dictionary.

#+begin_src emacs-lisp
(defun sp-reading--lookup-script (key)
  "The AppleScript that finds the UUID of the record named KEY.pdf."
  (format "tell application id \"DNtp\"
  set theRecords to search %s in root of database %s
  repeat with r in theRecords
    if (name of r) is %s then return uuid of r
  end repeat
  return \"\"
end tell"
          (sp-reading--quote (concat "name:" key ".pdf"))
          (sp-reading--quote sp-reading-database)
          (sp-reading--quote (concat key ".pdf"))))

(defun sp-reading-uuid (key)
  "The DEVONthink UUID of the record for the citekey KEY, or nil."
  (or (and sp-reading-index (gethash key sp-reading-index))
      (let ((uuid (sp-reading--osascript (sp-reading--lookup-script key))))
        (unless (string-empty-p uuid)
          (unless sp-reading-index
            (setq sp-reading-index (make-hash-table :test 'equal)))
          (puthash key uuid sp-reading-index)
          uuid))))

(defun sp-reading--url (uuid &optional page)
  "The DEVONthink item URL for UUID, at PAGE (counted from 0) if given."
  (concat "x-devonthink-item://" uuid (if page (format "?page=%d" page) "")))
#+end_src

* Indexing a PDF

- The PDF stays where it is; DEVONthink only gets a pointer to it.
- The record is created in =sp-reading-index-group= (or the root), then renamed to =KEY.pdf= so the lookup finds it next time.
- The new UUID is put into the cache.

#+begin_src emacs-lisp
(defun sp-reading--index-script (file key)
  "The AppleScript that indexes FILE in DEVONthink under the name KEY.pdf."
  (format "tell application id \"DNtp\"
  set theDb to database %s
  set theGroup to %s
  set theRecord to index path %s to theGroup
  set name of theRecord to %s
  return uuid of theRecord
end tell"
          (sp-reading--quote sp-reading-database)
          (if sp-reading-index-group
              (format "get record at %s in theDb"
                      (sp-reading--quote (concat "/" sp-reading-index-group)))
            "root of theDb")
          (sp-reading--quote (expand-file-name file))
          (sp-reading--quote (concat key ".pdf"))))

(defun sp-reading-index-file (key file)
  "Index the PDF FILE in DEVONthink as KEY.pdf and return the new UUID."
  (let ((uuid (sp-reading--osascript (sp-reading--index-script file key))))
    (when (string-empty-p uuid) (error "DEVONthink did not index %s" file))
    (unless sp-reading-index (setq sp-reading-index (make-hash-table :test 'equal)))
    (puthash key uuid sp-reading-index)
    uuid))
#+end_src

* Opening

- =sp-reading-open= is the command; with a prefix argument it asks for the page.
- Called from Lisp, =page= counts from 0.
- The PDF files come from =citar=. Only files that exist and end in =.pdf= are offered.

#+begin_src emacs-lisp
(defun sp-reading--pdf (key)
  "The first existing PDF file for the citekey KEY, from citar, or nil."
  (when (fboundp 'citar-get-files)
    (let* ((files (ignore-errors (citar-get-files (list key))))
           (list (and (hash-table-p files) (gethash key files))))
      (seq-find (lambda (f) (and (string-suffix-p ".pdf" f t) (file-exists-p f))) list))))

(defun sp-reading--run (program &rest args)
  "Start PROGRAM with ARGS without waiting for it."
  (apply #'call-process program nil 0 nil args))

(defun sp-reading--open-url (url)
  "Open URL with the system."
  (sp-reading--run "open" url))

(defun sp-reading--ask (key)
  "Ask what to do with the PDF of KEY, which is not in DEVONthink."
  (completing-read (format "%s is not in DEVONthink: " key)
                   '("Index in DEVONthink" "Open in Preview" "Cancel") nil t))

;;;###autoload
(defun sp-reading-open (key &optional page)
  "Open the work KEY for reading: in DEVONthink, or after asking what to do.
PAGE (counted from 0) is the page to open; interactively a prefix argument asks."
  (interactive
   (list (if (fboundp 'citar-select-ref) (citar-select-ref) (read-string "Citekey: "))
         (when current-prefix-arg (1- (read-number "Page: ")))))
  (let ((uuid (sp-reading-uuid key)))
    (if uuid
        (sp-reading--open-url (sp-reading--url uuid page))
      (let ((file (sp-reading--pdf key)))
        (if (not file)
            (progn (message "sp-reading: no PDF for %s (try sp-fetch-academic)" key) nil)
          (pcase (sp-reading--ask key)
            ("Index in DEVONthink"
             (sp-reading--open-url (sp-reading--url (sp-reading-index-file key file) page)))
            ("Open in Preview"
             (apply #'sp-reading--run (append sp-reading-preview-command (list file))))))))))
#+end_src

* Testing it by hand on the Mac

- Check the cache script first: =M-x sp-reading-refresh=. It should report the number of PDFs in =literature= (about 15,000).
  - If it errors, run the script from =sp-reading--listing-script= in Script Editor to see which line fails.
- Open one: =M-x sp-reading-open= with a citekey that has a record. DEVONthink should come to the front on that record.
- Index one: pick a citekey with a PDF but no record, choose /Index in DEVONthink/. Check that the record is a pointer (its path is in =~/Documents/literature/=) and is named =KEY.pdf=.
- Unknown until tried:
  - whether =search "kind:pdf"= returns every PDF in nested groups;
  - the exact wording of the =index path ... to= command and of =get record at=;
  - (fixed 2026-11-12) =uuid of every item of= on a search result returned object references (=content id … of database id …=), so the script now loops over the records and reads =uuid of r= and =name of r=.
