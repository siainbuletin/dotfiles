* sp-academic.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/academic/sp-academic.el
:END:

This is the umbrella module for academic work.

- Loads five sub-modules (=sp-bibprocess=, =sp-pdfprocess=, =sp-citations=, =sp-litnotes= and =sp-fetch-academic=) so they can be enabled together.
- Defines the three citation user options before any sub-module needs them.
- Configures the reference managers directly:
  - =org-ref= set up to insert =org-cite= citations,
  - =helm-bibtex= library and notes paths,
  - the =binder= package for Scrivener-like manuscript work.
- The list of =.bib= files is no longer written here: =sp-bibtex-register= in =sp-bibprocess= finds every =.bib= file in =~/Documents/bibliography/= and hands the list to Org, =citar=, =org-ref= and =helm-bibtex= alike.

The long commentary is a roadmap more than a description.

- Planned pieces: DEVONthink integration, deep links into PDFs, semantic search over PDFs. Paper fetching now has its own sub-module, [[file:sp-fetch-academic.org][sp-fetch-academic]].
- Literature notes are made with =citar-vulpea= (see =sp-litnotes=); =citar-denote= is gone. =ROAM_REFS= handling goes through =vulpea-citar=.
- Bibliography files are expected under =~/Documents/bibliography/=, PDFs under =~/Documents/literature/=.
- The module appears in the default module list in =init.el= under Academic.

** Citation keys

Every entry in a plain BibTeX file gets its key from =bibtex-generate-autokey=, with one scheme everywhere. The options are set once, in =sp-bibprocess=.

- Shape: the family names of the first two authors, four-digit year and the first two significant title words, each cut to five letters and joined by hyphens, all in lower case, for example =smithjones-2017-atten-all= (Smith and Jones, Attention Is All You Need) or =hegel-1807-phanom-geist= (one author). "Is" is in the ignore list, so it is skipped. A third word is added when the second is short (=bibtex-autokey-titlewords-stretch= is 1).
- Several authors: the first two are joined without a separator and later ones are dropped, so Smith, Jones and Lee is still =smithjones-2017-...=.
- Accents are stripped to plain ASCII (=Müller= becomes =muller=) so keys survive any tool.
- The title words skip articles (English and German), "Is", "the", "a", "On" and "on" (the last five are your additions), and any word that is not capitalised or has odd characters.
- Three ways to apply it: =C-c C-c= in =bibtex-mode= cleans an entry (=C-u C-c C-c= also makes a new key), =biblio= entries get one on insertion (=biblio-bibtex-use-autokey=), and the key is checked against every registered =.bib= file so duplicates are noticed.
- Existing keys are left alone. Changing a key breaks the =cite:= links and =ROAM_REFS= that mention it, so regenerate only entries you have not cited yet.

** Settings worth knowing

The ones that change how the setup behaves most. All are set in the modules named in brackets.

- =bibtex-autokey-*= [=sp-bibprocess=]: the key scheme above. =bibtex-autokey-edit-before-use= is =t=, so =bibtex-clean-entry= shows the key in the minibuffer for approval.
- =bibtex-entry-format= [=sp-bibprocess=]: what cleaning does to an entry (page dashes, whitespace, alignment, trailing comma, braces). Required-field checks are left out so incomplete =biblio= entries are not rejected.
- =bibtex-search-entry-globally= with =bibtex-files= [=sp-bibprocess=]: key look-ups and duplicate checks span all registered files, not just the open buffer.
- =bibtex-dialect= [=sp-bibprocess=]: =biblatex=, so =date=, =journaltitle= and =file= are valid fields.
- =sp-bibliography-dir= [=sp-bibprocess=]: where the =.bib= files live. Add or remove a file, then run =C-c w b r=.
- =org-cite-global-bibliography= and =citar-bibliography= [=sp-citations=]: both read the registered list, so Org and =citar= always see the same files.
- =citar-library-paths=, =citar-library-file-extensions=, =citar-file-additional-files-separator= [=sp-citations=]: where =citar= looks for PDFs (=~/Documents/literature/=), which extensions count, and the separator for several files per key. The library path was commented out before, so =citar= found no PDFs.
- =citar-notes-paths= and =citar-templates= [=sp-citations=]: where notes live and how candidates are displayed.
- =org-cite-export-processors= [=sp-citations=]: CSL for every export format; needs the styles in =sp-data-home=.
- =biblio-bibtex-use-autokey= [=sp-fetch-academic=]: gives entries inserted from CrossRef, arXiv and DOI the same key scheme.

The old sections of this document that set BibTeX options twice, repeated three definitions or tried to set Citar options inside =:custom= are fixed below, and each fix says so.

*** Showing cite keys in descriptive links

=org-ref-make-org-link-cite-key-visible= runs after =org-activate-bracket-links= highlights a link.

- When the link target starts with one of =org-ref-cite-types=, it removes the invisibility from the whole link and colours it with =org-ref-cite-color=.
- So the cite key stays visible even when the link has a description.
- It uses =-sort= from =dash= to try longer cite types first.

#+begin_src emacs-lisp -i
(defun org-ref-make-org-link-cite-key-visible (&rest _)
  "Make the org-ref cite link visible in descriptive links."

  (save-match-data
    (let ((s (match-string 1))
      (beg (match-beginning 0))
      (end (match-end 0))
      (cite-re (format "^\\(%s:\\)"
               (regexp-opt (-sort
                    (lambda (a b)
                      (> (length a) (length b)))
                    org-ref-cite-types))))
      cite-type)

      (when (and s (string-match cite-re s))
    (setq cite-type (match-string 1 s))
    (remove-text-properties beg end
                '(invisible))
    (add-text-properties
     beg end
     `(face (:foreground ,org-ref-cite-color)))))))
#+end_src

* sp-bibprocess.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/academic/sp-bibprocess.el
:END:

This module manages the BibTeX bibliography that the academic modules build on. It:

- defines where the =.bib= files live (=sp-bibliography-dir=, =~/Documents/bibliography/= by default),
- keeps one list of them and shares it with Org's citation system (=org-cite-global-bibliography=), =citar= (=citar-bibliography=), =org-ref= (=org-ref-default-bibliography=), =helm-bibtex= (=bibtex-completion-bibliography=) and =bibtex-mode= itself (=bibtex-files=),
- configures the built-in =bibtex= mode for BibLaTeX, including the one scheme for citation keys described under [[*Citation keys]],
- adds commands to audit attachments. Looking up new entries online (=biblio=) moved to [[file:sp-fetch-academic.org][sp-fetch-academic]].

Loading:

- It is not listed directly in the module profiles; =sp-academic= loads it with =require=.
- It used to repeat the variable, the register command and the lookup helper verbatim under a "BIBLIOGRAPHY" heading, and to set the key options a second time in =sp-academic=. Both repeats are gone, so every option has one definition.

*** Bibliography directory

The folder holding the BibTeX files and their attachments is =sp-bibliography-dir=, defined in =sp-globals= (=~/Documents/bibliography/= by default, or the folder named by =SP_BIBLIOGRAPHY_DIR=). This module used to define a second option, =sp-bibtex-dir=, that only copied it; there is now one option, and the old name is gone with no alias.


*** List of BibTeX files

=sp-bibtex-file-regexp= matches the =.bib= files that count: a name that starts with a letter or digit (so editor backups and dotfiles are skipped) and ends in =.bib=. The old pattern =^[A-Z|a-z|0-9].+.bib$= also matched names like =x-bib= and, through the literal =|=, names starting with a pipe.

=sp-bibtex-files= is filled at load time with every matching file in the directory, or left =nil= if the directory does not exist.

#+begin_src emacs-lisp -i
(defconst sp-bibtex-file-regexp "\\`[[:alnum:]].*\\.bib\\'"
  "Regexp for the names of the BibTeX files in `sp-bibliography-dir'.")

(defvar sp-bibtex-files
  (when (file-exists-p sp-bibliography-dir)
    (directory-files sp-bibliography-dir t sp-bibtex-file-regexp))
  "List of BibTeX files. Use `sp-bibtex-register' to configure.")
#+end_src

*** Register BibTeX files

=sp-bibtex-register= rescans =sp-bibliography-dir= and gives the same list to every consumer, then echoes the registered files.

- =sp-bibtex-files=, the list itself.
- =org-cite-global-bibliography= and =citar-bibliography=, for citations in Org and for =citar=.
- =org-ref-default-bibliography= and =bibtex-completion-bibliography=, for =org-ref= and =helm-bibtex=.
- =bibtex-files=, so that with =bibtex-search-entry-globally= a key is looked up (and checked for duplicates) in all of them.

Run it after adding or removing a =.bib= file.

#+begin_src emacs-lisp -i
;;;###autoload
(defun sp-bibtex-register ()
  "Register the contents of the `sp-bibliography-dir' with `sp-bibtex-files`.
Use when adding or removing a BibTeX file from or to `sp-bibliography-dir'."
  (interactive)
  (when (file-exists-p sp-bibliography-dir)
    (let ((bib-files (directory-files sp-bibliography-dir t sp-bibtex-file-regexp)))
      (setq sp-bibtex-files bib-files
            org-cite-global-bibliography bib-files
            citar-bibliography bib-files
            org-ref-default-bibliography bib-files
            bibtex-completion-bibliography bib-files
            bibtex-files bib-files)))
  (message "Registered:\n%s" (mapconcat #'identity sp-bibtex-files "\n")))
#+end_src

** Citation keys

*** Key helper

=sp-bibtex-ascii-key= is the =bibtex-autokey-before-presentation-function=: it receives the generated key and returns it with accents removed. The key is decomposed (=ü= into =u= and a combining mark) and everything outside ASCII is dropped, so =müller2020= becomes =muller2020=. Authors in a non-Latin script would lose their name entirely, so an empty result keeps the original key.

#+begin_src emacs-lisp -i
;;;; Citation keys

(require 'ucs-normalize)

(defun sp-bibtex-ascii-key (key)
  "Return KEY as plain ASCII, or KEY itself when nothing is left."
  (let ((ascii (replace-regexp-in-string
                "[^[:ascii:]]" "" (ucs-normalize-NFKD-string key))))
    (if (string-empty-p ascii) key ascii)))
#+end_src

*** bibtex

Configures the built-in =bibtex= mode:

- the BibLaTeX dialect,
- the key scheme (see [[*Citation keys]] in the first part of this document): first two authors, four-digit year and two title words of at most five letters, in lower case, with hyphens between year and title words, such as =smithjones-2017-atten-all=,
- the articles to skip in the title (English and German, plus any word that is not capitalised or has odd characters), now also "Is", "the", "a", "On" and "on",
- what cleaning an entry does: =opts-or-alts= (drop empty optional fields), =page-dashes= (=10-20= to =10--20=), =whitespace=, =realign=, =last-comma=, =delimiters=, =unify-case= and =braces=. =required-fields= and =numerical-fields= are left out so that an incomplete entry from a look-up is not rejected,
- a duplicate check across all registered files,
- two extra optional fields offered when creating entries (=keywords= and =file= for attachments),
- alignment of field values at the equals sign.

Also:

- =bibtex-aux-opt-alist= carries the same two fields. It used to be saved by Customize in =init.el= and is now set here.
- =:demand t= loads it at once, which registers the bibliography files (=sp-bibtex-register= in =:config=) before anything reads them; =sp-academic= used to do that with =(require 'bibtex)=.
- =C-c w b r= runs =sp-bibtex-register= at any time.
- =H-b= in a BibTeX buffer opens the org-ref hydra (it needs a Hyper key). It was =define-key= in =sp-academic=.

#+begin_src emacs-lisp -i
(use-package bibtex
  :ensure nil
  :demand t
  :custom
  (bibtex-dialect 'biblatex)

  ;; Keys: smith-2017-atten-all
  (bibtex-autokey-names 2)
  (bibtex-autokey-names-stretch 0)
  (bibtex-autokey-name-separator "")
  (bibtex-autokey-name-year-separator "-")
  (bibtex-autokey-year-length 4)
  (bibtex-autokey-year-title-separator "-")
  (bibtex-autokey-titlewords 2)
  (bibtex-autokey-titlewords-stretch 1)
  (bibtex-autokey-titleword-length 5)
  (bibtex-autokey-titleword-separator "-")
  (bibtex-autokey-name-case-convert-function #'downcase)
  (bibtex-autokey-titleword-case-convert-function #'downcase)
  (bibtex-autokey-before-presentation-function #'sp-bibtex-ascii-key)
  (bibtex-autokey-edit-before-use t)
  (bibtex-autokey-titleword-ignore
   '("A" "An" "The" "Is" "the" "a" "On" "on" "Eine?" "Der" "Die" "Das"
     "[^[:upper:]].*" ".*[^[:upper:][:lower:]0-9].*"))

  ;; Cleaning and duplicates
  (bibtex-entry-format
   '(opts-or-alts page-dashes whitespace realign last-comma
                  delimiters unify-case braces))
  (bibtex-search-entry-globally t)

  (bibtex-user-optional-fields
   '(("keywords" "Keywords to describe the entry" "")

*** Names

Names are the base of the lint. A name in an =author= or =editor= field is canonical when it reads =Last, First= (=van Gogh, Vincent=, =Smith, John=). =sp-bibtex-canonical-name= turns =John Smith= into =Smith, John=, keeps lower case particles (=sp-bibtex-name-particles=) with the last name, and leaves corporate names in braces (={Big Corp}=), =others= and one-word names alone. Splitting at =and= and at spaces ignores what is inside braces.

#+begin_src emacs-lisp -i
(defun sp-bibtex--unwrap (value)
  "VALUE without its outer braces or quotes, and the delimiter pair; nil if it has none.
Return (TEXT . OPEN), or nil for a value that is a macro or a concatenation."
  (let ((value (string-trim value)))
    (when (> (length value) 1)
      (let ((open (aref value 0)) (close (aref value (1- (length value)))))
        (cond
         ((and (eq open ?{) (eq close ?}) (sp-bibtex--balanced-p (substring value 1 -1)))
          (cons (substring value 1 -1) ?{))
         ((and (eq open ?\") (eq close ?\") (not (string-search "\"" (substring value 1 -1))))
          (cons (substring value 1 -1) ?\")))))))

(defun sp-bibtex--balanced-p (text)
  "Non-nil when the braces of TEXT never close more than they open and end even."
  (let ((depth 0) (ok t))
    (dolist (c (string-to-list text))
      (cond ((eq c ?{) (cl-incf depth))
            ((eq c ?}) (cl-decf depth) (when (< depth 0) (setq ok nil)))))
    (and ok (= depth 0))))

(defun sp-bibtex--split-depth0 (text separator-re)
  "Split TEXT at the matches of SEPARATOR-RE that are outside braces."
  (let ((depth 0) (start 0) (i 0) (n (length text)) parts)
    (while (< i n)
      (let ((c (aref text i)))
        (cond ((eq c ?{) (cl-incf depth) (cl-incf i))
              ((eq c ?}) (cl-decf depth) (cl-incf i))
              ((and (= depth 0) (eq (string-match separator-re text i) i))
               (push (substring text start i) parts)
               (setq i (match-end 0) start i))
              (t (cl-incf i)))))
    (push (substring text start) parts)
    (nreverse parts)))

(defun sp-bibtex-split-names (text)
  "The names in the author or editor TEXT, split at \" and \" outside braces."
  (seq-remove #'string-empty-p
              (mapcar #'string-trim
                      (sp-bibtex--split-depth0 (replace-regexp-in-string "[ \t\n]+" " " text)
                                               "[ \t]+and[ \t]+"))))

(defun sp-bibtex-canonical-name (name)
  "NAME as \"Last, First\".  A corporate {Name}, \"others\" and one-word names stay."
  (let ((name (string-trim (replace-regexp-in-string "[ \t\n]+" " " name))))
    (cond
     ((or (string-empty-p name) (equal name "others")
          (and (eq (aref name 0) ?{) (sp-bibtex--balanced-p name)
               (= 1 (length (sp-bibtex--split-depth0 name "[ \t]+")))))
      name)
     ((string-search "," name)
      (string-join (mapcar #'string-trim (sp-bibtex--split-depth0 name ",")) ", "))
     (t
      (let ((words (sp-bibtex--split-depth0 name "[ \t]+")))
        (if (null (cdr words))
            name
          (let ((last (list (car (last words))))
                (rest (butlast words)))
            (while (and rest (member (car (last rest)) sp-bibtex-name-particles))
              (push (car (last rest)) last)
              (setq rest (butlast rest)))
            (if (null rest)
                name
              (format "%s, %s" (string-join last " ") (string-join rest " "))))))))))

(defun sp-bibtex-canonical-names (text)
  "The author or editor TEXT with every name in the canonical form."
  (string-join (mapcar #'sp-bibtex-canonical-name (sp-bibtex-split-names text)) " and "))

(defun sp-bibtex--name-key (canonical)
  "A lookup key for the CANONICAL name: lower case, no braces, dots or extra spaces."
  (string-trim (replace-regexp-in-string
                "[ \t]+" " "
                (replace-regexp-in-string "[{}.]" "" (downcase canonical)))))
#+end_src

*** The author notes

Author notes (=:person:= notes) are only /read/: =sp-bibtex-people= indexes their titles in the canonical form and keeps the index for =sp-bibtex-people-cache-seconds=. A name in a =.bib= file that is close to an author note (two edits, same first letters) is reported as a likely typo of it. A name with no note is /not/ reported and no note is ever created.

#+begin_src emacs-lisp -i
(defvar sp-bibtex--people-cache nil
  "(TIME . INDEX) of the author notes, see `sp-bibtex-people'.")

(defun sp-bibtex--note-aliases (file)
  "The aliases in the head of the note FILE (its ROAM_ALIASES), as a list of strings."
  (when (and file (file-readable-p file))
    (with-temp-buffer
      (insert-file-contents file nil 0 4096)
      (let ((case-fold-search t) aliases)
        (while (re-search-forward "^\\(?:#\\+\\|[ \t]*:\\)ROAM_ALIASES:?[ \t]*\\(.*\\)$" nil t)
          (setq aliases (append aliases (ignore-errors
                                         (split-string-and-unquote (match-string-no-properties 1))))))
        aliases))))

(defun sp-bibtex--make-people (people)
  "The index of PEOPLE: a plist of :names, :keys, :files and :buckets.
Each of PEOPLE is a title, or a plist with :title and :file from
`sp-author-notes--file-head'.  The aliases of the note files count as known
names, so a name that is an alias is not suggested to be a typo."
  (let ((keys (make-hash-table :test #'equal))
        (buckets (make-hash-table :test #'equal))
        (files (make-hash-table :test #'equal))
        names)
    (dolist (person people)
      (let* ((title (if (stringp person) person (plist-get person :title)))
             (canonical (sp-bibtex-canonical-name title))
             (key (sp-bibtex--name-key canonical)))
        (unless (gethash key keys)
          (puthash key canonical keys)
          (when-let* ((file (and (consp person) (plist-get person :file))))
            (puthash key file files))
          (push canonical names)
          (push canonical (gethash (sp-bibtex--bucket key) buckets)))))
    (dolist (person people)
      (when-let* ((file (and (consp person) (plist-get person :file))))
        (dolist (alias (sp-bibtex--note-aliases file))
          (let ((key (sp-bibtex--name-key (sp-bibtex-canonical-name alias))))
            (unless (gethash key keys)
              (puthash key (sp-bibtex-canonical-name (plist-get person :title)) keys))))))
    (list :names (sort names #'string<) :keys keys :files files :buckets buckets
          :memo (make-hash-table :test #'equal))))

(defun sp-bibtex--bucket (key)
  "The bucket of the name KEY: the first letter of the last name and the first of the first name."
  (let ((parts (split-string key ", " t)))
    (format "%s|%s"
            (if parts (substring (car parts) 0 (min 1 (length (car parts)))) "")
            (if (cdr parts) (substring (cadr parts) 0 (min 1 (length (cadr parts)))) ""))))

(defun sp-bibtex-people (&optional refresh)
  "The index of the author notes, read again when REFRESH or older than the cache time."
  (interactive "P")
  (when (or refresh (null sp-bibtex--people-cache)
            (> (- (float-time) (car sp-bibtex--people-cache))
               sp-bibtex-people-cache-seconds))
    (require 'sp-author-notes-bibtex)
    (setq sp-bibtex--people-cache
          (cons (float-time)
                (sp-bibtex--make-people (sp-author-notes-bibtex--people)))))
  (cdr sp-bibtex--people-cache))

(defun sp-bibtex--suggestion (canonical people)
  "The author note a name CANONICAL is probably a typo of, or nil.
It is the note in the same bucket with a name at most two edits away.  A name
that has a note, or none close to it, gets nil."
  (let ((key (sp-bibtex--name-key canonical)))
    (unless (gethash key (plist-get people :keys))
      (let* ((memo (plist-get people :memo))
             (known (gethash key memo 'none)))
        (if (not (eq known 'none))
            known
          (puthash key
                   (seq-find (lambda (candidate)
                               (<= (string-distance key (sp-bibtex--name-key candidate)) 2))
                             (gethash (sp-bibtex--bucket key) (plist-get people :buckets)))
                   memo))))))
#+end_src

*** Entries

An entry is read with =bibtex-parse-entry= (raw values, in file order). Linting it gives the fields with canonical names in the order of =sp-bibtex-field-order= and a list of what differs. An entry that is rewritten is written as =@type{key,= with the fields aligned at the equal sign; its values keep their delimiters and text. An entry with a =%= comment line inside would lose it, so it is reported and never rewritten. The reading runs in slices of 100 entries through =sp-async-work=, like =sp-author-notes-bibtex=.

#+begin_src emacs-lisp -i
(defun sp-bibtex--field-rank (name)
  "The rank of the field NAME in `sp-bibtex-field-order'; unlisted fields come last."
  (or (seq-position sp-bibtex-field-order (downcase name)) (length sp-bibtex-field-order)))

(defun sp-bibtex--case-problem (case)
  "The sentence for CASE, a list (FIELD NAME NOTE-NAME NOTE-FILE)."
  (format "%s: %s is not an author note; did you mean %s?"
          (nth 0 case) (nth 1 case) (nth 2 case)))

(defun sp-bibtex--lint-names (fields people)
  "Check the author and editor names in FIELDS, an alist of name and raw value.
Return (NEW-FIELDS PROBLEMS CASES): FIELDS with canonical names, the strings
that say what changed, and for each name one typo away from an author note a
list (FIELD NAME NOTE-NAME NOTE-FILE)."
  (let (problems cases new)
    (dolist (field fields)
      (let ((name (car field)) (value (cdr field)))
        (when (member (downcase name) '("author" "editor"))
          (when-let* ((unwrapped (sp-bibtex--unwrap value))
                      (text (car unwrapped)))
            (let ((fixed (sp-bibtex-canonical-names text)))
              (unless (equal fixed (string-trim (replace-regexp-in-string "[ \t\n]+" " " text)))
                (push (format "%s: %s → %s" name
                              (replace-regexp-in-string "[ \t\n]+" " " text) fixed)
                      problems)
                (setq value (if (eq (cdr unwrapped) ?\")
                                (format "\"%s\"" fixed)
                              (format "{%s}" fixed))))
              (when people
                (dolist (n (sp-bibtex-split-names fixed))
                  (when-let* ((near (sp-bibtex--suggestion n people)))
                    (push (list name n near
                                (gethash (sp-bibtex--name-key near) (plist-get people :files)))
                          cases)))))))
        (push (cons name value) new)))
    (list (nreverse new) (nreverse problems) (nreverse cases))))

(defun sp-bibtex--sort-fields (fields)
  "FIELDS in the order of `sp-bibtex-field-order'."
  (sort (copy-sequence fields)
        (lambda (a b) (< (sp-bibtex--field-rank (car a)) (sp-bibtex--field-rank (car b))))))

(defun sp-bibtex--order-problem (fields sorted)
  "The sentence that says FIELDS are not in the order of SORTED, or nil."
  (unless (equal (mapcar #'car sorted) (mapcar #'car fields))
    (format "fields: %s → %s" (string-join (mapcar #'car fields) " ")
            (string-join (mapcar #'car sorted) " "))))

(defun sp-bibtex--lint-fields (fields people)
  "Lint the FIELDS, an alist of name and raw value.
Return (NEW-FIELDS . PROBLEMS): the fields with canonical names, in the
configured order, and a list of strings that say what differs."
  (let* ((names (sp-bibtex--lint-names fields people))
         (sorted (sp-bibtex--sort-fields (car names))))
    (cons sorted
          (append (nth 1 names)
                  (mapcar #'sp-bibtex--case-problem (nth 2 names))
                  (when-let* ((problem (sp-bibtex--order-problem (car names) sorted)))
                    (list problem))))))

(defun sp-bibtex--entry-text (type key fields)
  "The text of the entry TYPE, KEY and FIELDS (an alist of name and raw value)."
  (let ((width (apply #'max 1 (mapcar (lambda (f) (length (car f))) fields))))
    (concat "@" type "{" key ",\n"
            (mapconcat (lambda (f)
                         (format "  %s%s = %s," (car f)
                                 (make-string (- width (length (car f))) ?\s) (cdr f)))
                       fields "\n")
            "\n}")))

(defvar sp-bibtex--fill-buffer nil
  "Scratch `bibtex-mode' buffer in which `sp-bibtex--fill-text' lays entries out.")

(defun sp-bibtex--fill-text (text)
  "The entry TEXT laid out the way `bibtex-fill-entry' does it.
That is the standard of `bibtex-mode': field names at `bibtex-field-indentation',
text at `bibtex-text-indentation'.  TEXT itself when it cannot be filled."
  (unless (buffer-live-p sp-bibtex--fill-buffer)
    (setq sp-bibtex--fill-buffer (generate-new-buffer " *sp-bibtex-fill*"))
    (with-current-buffer sp-bibtex--fill-buffer (delay-mode-hooks (bibtex-mode))))
  (with-current-buffer sp-bibtex--fill-buffer
    (erase-buffer)
    (insert text)
    (goto-char (point-min))
    (condition-case nil
        (progn (bibtex-fill-entry)
               (buffer-substring-no-properties (point-min) (point-max)))
      (error text))))

(defun sp-bibtex--entry-rewrites (kinds type key fields people old start end)
  "The rewrites of the entry TYPE, KEY and FIELDS that are of one of KINDS.
OLD is the text of the entry, between START and END.  KINDS are `order',
`indent', `authors' (names to `Last, First') and `notes' (names near an author
note).  Return (REWRITES . PROBLEMS).  REWRITES is an alist from a kind to a
plist of :start, :end, :old, :desc and :new (the new text) or :cases (for
`notes'); PROBLEMS are the lines for the report."
  (let* ((names (sp-bibtex--lint-names fields people))
         (sorted (sp-bibtex--sort-fields fields))
         (order (sp-bibtex--order-problem fields sorted))
         (near (mapcar #'sp-bibtex--case-problem (nth 2 names)))
         (form (nth 1 names))
         (filled (and (memq 'indent kinds) (sp-bibtex--fill-text old)))
         (base (list :start start :end end :old old))
         rewrites)
    (when (and filled (not (equal filled old)))
      (push (cons 'indent (append base (list :new filled :desc '("indentation differs from bibtex-mode"))))
            rewrites))
    (when (and order (memq 'order kinds))
      (push (cons 'order (append base (list :desc (list order)
                                            :new (sp-bibtex--fill-text
                                                  (sp-bibtex--entry-text type key sorted)))))
            rewrites))
    (when (and form (memq 'authors kinds))
      (push (cons 'authors (append base (list :desc form
                                              :new (sp-bibtex--fill-text
                                                    (sp-bibtex--entry-text type key (car names))))))
            rewrites))
    (when (and (nth 2 names) (memq 'notes kinds))
      (push (cons 'notes (append base (list :desc near :cases (nth 2 names)))) rewrites))
    (cons (nreverse rewrites)
          (append form near (and order (list order))
                  (and filled (not (equal filled old))
                       (list "indentation differs from bibtex-mode"))))))

(defun sp-bibtex--lint-chunk (file limit people seen kinds)
  "Lint the entries from point in the current buffer, at most LIMIT of them.
Return (RESULTS . MORE).  RESULTS lists (FILE KEY POSITION PROBLEMS REWRITES);
MORE is non-nil when LIMIT was reached.  SEEN is a hash table of the keys met
so far.  REWRITES is what `sp-bibtex--entry-rewrites' returns for KINDS: an
alist, empty for an entry that is only reported.  The buffer is not changed."
  (let ((count 0) results)
    (while (and (< count limit)
                (re-search-forward "^[ \t]*@[[:alpha:]]+[ \t]*[{(]" nil t))
      (cl-incf count)
      (let ((beg (match-beginning 0))
            (header (match-string 0)))
        (goto-char beg)
        (let* ((entry (ignore-errors (bibtex-parse-entry)))
               (type (cdr (assoc "=type=" entry)))
               (key (cdr (assoc "=key=" entry)))
               (end (and entry (ignore-errors (bibtex-end-of-entry)))))
          (if (not (and entry key end (not (member (downcase type) '("string" "preamble" "comment")))))
              (progn
                (unless (string-match-p "@[ \t]*\\(string\\|preamble\\|comment\\)" (downcase header))
                  (push (list file (or key "?") beg
                              '("could not be read (a comment inside?), left as it is"))
                        results))
                (goto-char (min (point-max) (1+ beg))))
            (let* ((fields (seq-remove (lambda (f) (string-prefix-p "=" (car f))) entry))
                   (start (save-excursion (goto-char beg) (skip-chars-forward " \t") (point)))
                   (commented (save-excursion
                                (goto-char beg)
                                (re-search-forward "^[ \t]*%" end t)))
                   (analysis (sp-bibtex--entry-rewrites
                              (unless commented kinds) type key fields people
                              (buffer-substring-no-properties start end) start end))
                   (problems (cdr analysis)))
              (when-let* ((first (gethash key seen)))
                (push (format "duplicate key (also in %s)" (file-name-nondirectory first)) problems))
              (puthash key (or (gethash key seen) file) seen)
              (when commented
                (setq problems (append problems '("has a comment inside, left as it is"))))
              (when problems
                (push (list file key beg problems (car analysis)) results))
              (goto-char end))))))
    (cons (nreverse results) (>= count limit))))
#+end_src

*** Report and apply

The lint works on one =.bib= file at a time, and it is read-only. The fixes are three separate commands, each with a button in the report.

- Which file:
  - the file of the current buffer, when it is a =.bib= file
  - otherwise, or with a prefix argument, one read with completion from =sp-bibtex-files=
- =M-x sp-bibtex-lint-dryrun= (=C-c w b l=):
  - lists the entries to fix in the shared report buffer (=sp-batch-report=)
  - each entry is a link to its line: =RET= visits it, =n= and =p= move, =g= refreshes
  - the top of the report has one button for each fix, with the number of entries it would change
  - never changes a file
- The buttons are links of a =sp-bibtex-lint:KIND:FILE= type, so =RET= on one runs the fix; no confirmation question comes before the batches.
- The three fixes:
  - =M-x sp-bibtex-lint-fix-order=:
    - puts the fields in the order of =sp-bibtex-field-order=
    - changes nothing else in the entry's values
  - =M-x sp-bibtex-lint-fix-indent=:
    - lays out every entry the way =bibtex-mode= does it (=bibtex-fill-entry=)
    - so field names sit at =bibtex-field-indentation= and text at =bibtex-text-indentation=, with the settings of the running Emacs
    - changes only whitespace
  - =M-x sp-bibtex-lint-fix-authors=, in two steps:
    - step 1: names that are not =Last, First= are rewritten
    - step 2: names one typo away from an author note; for each batch you choose =n=, =l=, =e=, =s= or =q=
      - =n= normalises the name in the BibTeX field to the name of the note
      - =l= adds the name, as =Last, First=, as an alias of the note (a vulpea alias, in =ROAM_ALIASES=), and the =.bib= file is not changed
      - =e= asks =n=, =l=, =s= or =q= for each name, and =q= there drops the batch
      - the aliases of the notes count as known names, so an alias is not suggested as a typo any more
- =M-x sp-bibtex-lint-convert= (=C-c w b L=) asks which of the three to run.
- Batches, for all three:
  - batch size is =sp-bibtex-lint-batch-size= (default 50)
  - for each batch =a= applies it, =s= skips it, =q= quits; the next batch is shown only after the answer
  - nothing is written without an answer
  - the file is copied to =sp-bibtex-lint-backup-directory= before the first write, then written again after each applied batch
  - if the file changed on disk since the lint, nothing more is written and you are asked to run the command again
  - an entry whose text is no longer the one that was linted is left alone and counted
  - the open buffer of the file must be saved first, and is reverted after a write
- Duplicate keys and entries with a comment inside are reported only; a rewritten entry is laid out like =bibtex-fill-entry= does it.

(defun sp-bibtex-lint--replace (beg end new)
  "Replace the text between the markers BEG and END with NEW; END ends after it."
  (goto-char beg)
  (delete-region beg end)
  (insert new)
  (set-marker end (point)))

(defun sp-bibtex-lint--apply-batch (work batch kind)
  "Rewrite the entries of BATCH in the buffer WORK, for the fix KIND.
BATCH is a list of (RESULT BEG END) with markers.  An entry whose text is no
longer the one that was linted is left alone.  Return (CHANGED STALE WROTE)."
  (let ((changed 0) (stale 0))
    (with-current-buffer work
      (dolist (item batch)
        (pcase-let* ((`(,r ,beg ,end) item)
                     (rewrite (alist-get kind (nth 4 r))))
          (if (not (equal (plist-get rewrite :old) (buffer-substring-no-properties beg end)))
              (cl-incf stale)
            (sp-bibtex-lint--replace beg end (plist-get rewrite :new))
            (cl-incf changed)))))
    (list changed stale t)))

(defun sp-bibtex-lint--signature (file)
  "The modification time and size of FILE, to notice that it changed."
  (let ((attributes (file-attributes file)))
    (list (file-attribute-modification-time attributes) (file-attribute-size attributes))))

(defun sp-bibtex-lint--save (work file)
  "Write the buffer WORK to FILE and bring the buffer that visits FILE up to date."
  (with-current-buffer work
    (write-region (point-min) (point-max) file nil 'silent))
  (when-let* ((visiting (find-buffer-visiting file)))
    (unless (buffer-modified-p visiting)
      (with-current-buffer visiting (revert-buffer t t t)))))

(defun sp-bibtex-lint--run (file kind results ask apply-fn &optional then)
  "Go through the entries of RESULTS with a fix of KIND for FILE, in batches.
Batches have `sp-bibtex-lint-batch-size' entries.  ASK is called with (BATCH
INDEX TOTAL ALL) and returns `skip', `quit' or an answer for APPLY-FN, which is
called with (WORK BATCH ANSWER) and returns (CHANGED STALE WROTE).  When WROTE,
FILE is copied to `sp-bibtex-lint-backup-directory' (once) and written; nothing
is written without an answer.  THEN is called when the run was not quit."
  (let* ((fixable (seq-filter (lambda (r) (alist-get kind (nth 4 r))) results))
         (what (alist-get kind sp-bibtex-lint--kinds))
         (work (generate-new-buffer " *sp-bibtex-lint-work*"))
         (stop nil))
    (if (null fixable)
        (message "BibTeX lint: no %s to fix in %s" what (file-name-nondirectory file))
      (unwind-protect
          (let* ((items (with-current-buffer work
                          (insert-file-contents file)
                          (delay-mode-hooks (bibtex-mode))
                          (mapcar (lambda (r)
                                    (let ((rewrite (alist-get kind (nth 4 r))))
                                      (list r (copy-marker (plist-get rewrite :start))
                                            (copy-marker (plist-get rewrite :end)))))
                                  fixable)))
                 (batches (seq-partition items (max 1 sp-bibtex-lint-batch-size)))
                 (total (length batches))
                 (stamp (format-time-string "%Y%m%dT%H%M%S"))
                 (signature (sp-bibtex-lint--signature file))
                 (index 0) (changed 0) (skipped 0) (stale 0) (backed-up nil))
            (while (and batches (not stop))
              (let* ((batch (pop batches))
                     (answer (funcall ask batch (cl-incf index) total (length items))))
                (pcase answer
                  ('quit (setq stop t) (cl-incf skipped (length batch)))
                  ('skip (cl-incf skipped (length batch)))
                  (_
                   (when-let* ((visiting (find-buffer-visiting file))
                               ((buffer-modified-p visiting)))
                     (user-error "Save %s first" (file-name-nondirectory file)))
                   (let ((done (funcall apply-fn work batch answer)))
                     (cl-incf changed (nth 0 done))
                     (cl-incf stale (nth 1 done))
                     (when (nth 2 done)
                       (unless (equal signature (sp-bibtex-lint--signature file))
                         (user-error "%s changed on disk since it was linted; run the command again"
                                     (file-name-nondirectory file)))
                       (unless backed-up
                         (sp-bibtex-lint--backup file stamp)
                         (setq backed-up t))
                       (sp-bibtex-lint--save work file)
                       (setq signature (sp-bibtex-lint--signature file))))))))
            (message "BibTeX %s of %s: %d done, %d skipped, %d not reached%s%s"
                     what (file-name-nondirectory file) changed skipped
                     (apply #'+ (mapcar #'length batches))
                     (if (> stale 0) (format ", %d changed since the lint" stale) "")
                     (if backed-up
                         (format "; backup in %s" (abbreviate-file-name sp-bibtex-lint-backup-directory))
                       "")))
        (kill-buffer work)))
    (when (and then (not stop)) (funcall then))))

(defun sp-bibtex-lint--review (file kind results &optional then)
  "Go through the rewrites of KIND in RESULTS for FILE, a batch at a time.
Each batch is applied, skipped or quit; see `sp-bibtex-lint--run'."
  (sp-bibtex-lint--run
   file kind results
   (lambda (batch index total all)
     (pcase (sp-bibtex-lint--ask-batch file batch index total all kind)
       (?a 'apply) (?s 'skip) (_ 'quit)))
   (lambda (work batch _answer) (sp-bibtex-lint--apply-batch work batch kind))
   then))

(defun sp-bibtex--rename-names (fields cases)
  "FIELDS with the names of CASES replaced by the names of the author notes.
CASES are lists (FIELD NAME NOTE-NAME ...); the other names stay as written."
  (mapcar
   (lambda (field)
     (let ((mine (seq-filter (lambda (c) (string-equal-ignore-case (car c) (car field))) cases)))
       (if-let* (((consp mine))
                 (unwrapped (sp-bibtex--unwrap (cdr field))))
           (let ((names (mapcar
                         (lambda (n)
                           (if-let* ((hit (seq-find (lambda (m) (equal (nth 1 m) (sp-bibtex-canonical-name n)))
                                                    mine)))
                               (nth 2 hit)
                             n))
                         (sp-bibtex-split-names (car unwrapped)))))
             (cons (car field)
                   (format (if (eq (cdr unwrapped) ?\") "\"%s\"" "{%s}")
                           (string-join names " and "))))
         field)))
   fields))

(defun sp-bibtex-lint--add-alias (file alias)
  "Add ALIAS to the aliases of the note FILE, with vulpea, and save the note."
  (require 'vulpea nil t)
  (unless (fboundp 'vulpea-buffer-alias-add)
    (user-error "vulpea is not loaded; cannot add the alias %s" alias))
  (unless (member alias (sp-bibtex--note-aliases file))
    (with-current-buffer (find-file-noselect file)
      (when (buffer-modified-p)
        (user-error "Save %s first" (file-name-nondirectory file)))
      (vulpea-buffer-alias-add alias)
      (save-buffer))))

(defun sp-bibtex-lint--ask-notes (file batch index total all)
  "Show BATCH of names near an author note and ask what to do with the names.
Return ?n to normalise the names in the BibTeX field, ?l to add each as an alias
of the note, ?e to be asked for each name, ?s to skip or ?q to stop."
  (sp-bibtex-lint--show-batch file 'notes batch index total all)
  (read-char-choice
   (format "Batch %d of %d (%d entries): [n]ormalise in the field, [l] alias on the note, [e]ach name, [s]kip, [q]uit "
           index total (length batch))

(defun sp-bibtex-lint--ask-case (case)
  "Ask what to do with CASE, a list (FIELD NAME NOTE-NAME NOTE-FILE).
Return ?n to normalise, ?l for an alias, ?s to skip or ?q to stop."
  (read-char-choice
   (format "%s is not an author note.  [n]ormalise to %s%s, [s]kip, [q]uit "
           (nth 1 case) (nth 2 case)
           (if (nth 3 case) ", [l] add as alias of the note" ""))
   (if (nth 3 case) '(?n ?l ?s ?q) '(?n ?s ?q))))

(defun sp-bibtex-lint--decide-notes (batch choice)
  "The decisions for BATCH from CHOICE, or `quit'.
A decision is a list (ITEM CASE DECISION), DECISION `normalise' or `alias'.
With ?e each case is asked."
  (catch 'quit
    (let (decisions)
      (dolist (item batch)
        (dolist (case (plist-get (alist-get 'notes (nth 4 (car item))) :cases))
          (let ((decision (pcase choice
                            (?n 'normalise)
                            (?l (and (nth 3 case) 'alias))
                            (_ (pcase (sp-bibtex-lint--ask-case case)
                                 (?n 'normalise)
                                 (?l 'alias)
                                 (?q (throw 'quit 'quit))
                                 (_ nil))))))
            (when decision (push (list item case decision) decisions)))))
      (nreverse decisions))))

(defun sp-bibtex-lint--apply-notes (work batch decisions)
  "Carry out DECISIONS for BATCH: rewrite entries in WORK, add aliases to notes.
Return (CHANGED STALE WROTE)."
  (let ((changed 0) (stale 0) (wrote nil) aliases)
    (dolist (d decisions)
      (when (eq (nth 2 d) 'alias)
        (push (cons (nth 3 (nth 1 d)) (nth 1 (nth 1 d))) aliases)))
    (dolist (item batch)
      (when-let* ((cases (mapcar #'cadr (seq-filter (lambda (d) (and (eq (car d) item)
                                                                      (eq (nth 2 d) 'normalise)))
                                                    decisions))))
        (pcase-let ((`(,r ,beg ,end) item))
          (with-current-buffer work
            (if (not (equal (plist-get (alist-get 'notes (nth 4 r)) :old)
                            (buffer-substring-no-properties beg end)))
                (cl-incf stale)
              (goto-char beg)
              (let* ((entry (bibtex-parse-entry))
                     (fields (seq-remove (lambda (f) (string-prefix-p "=" (car f))) entry)))
                (sp-bibtex-lint--replace
                 beg end
                 (sp-bibtex--fill-text
                  (sp-bibtex--entry-text (cdr (assoc "=type=" entry)) (cdr (assoc "=key=" entry))
                                         (sp-bibtex--rename-names fields cases)))))
              (cl-incf changed (length cases))
              (setq wrote t))))))
    (dolist (alias (delete-dups aliases))
      (sp-bibtex-lint--add-alias (car alias) (cdr alias))
      (cl-incf changed))
    (when aliases (setq sp-bibtex--people-cache nil))
    (list changed stale wrote)))

(defun sp-bibtex-lint--review-notes (file results)
  "Go through the names near an author note in RESULTS for FILE, a batch at a time.
Each name is normalised in the BibTeX field, or added as an alias of the note."
  (sp-bibtex-lint--run
   file 'notes results
   (lambda (batch index total all)
     (pcase (sp-bibtex-lint--ask-notes file batch index total all)
       (?s 'skip)
       (?q 'quit)
       (choice (sp-bibtex-lint--decide-notes batch choice))))
   #'sp-bibtex-lint--apply-notes))

=sp-bibtex-author-capf= completes the name under the cursor in an =author= or =editor= field (after =\{=, a quote or =and=) from the author notes, in the canonical form, so names are picked instead of typed. It is added to =completion-at-point-functions= in =bibtex-mode=.

#+begin_src emacs-lisp -i
(defun sp-bibtex-author-capf ()
  "Complete a name in an author or editor field from the author notes.
Add to `completion-at-point-functions' in `bibtex-mode'."
  (when-let* ((_ (save-excursion
                             (re-search-backward "^[ \t]*\\([[:alnum:]_-]+\\)[ \t]*=" nil t)))
              (name (match-string-no-properties 1))
              ((member (downcase name) '("author" "editor")))
              (value-start (match-end 0))
              ((string-match-p "[{\"]" (buffer-substring-no-properties value-start (point))))
              (people (sp-bibtex-people)))
    (let* ((end (point))
           (start (save-excursion
                    (if (re-search-backward "\\(?:[{\"]\\|\\band[ \t\n]+\\)" value-start t)
                        (match-end 0)
                      end))))
      (when (<= start end)
        (list start end
              (lambda (string pred action)
                (let ((completion-ignore-case t))
                  (complete-with-action action (plist-get people :names) string pred)))
              :exclusive 'no)))))

(defun sp-bibtex-setup-completion ()
  "Complete author names in this `bibtex-mode' buffer."
  (add-hook 'completion-at-point-functions #'sp-bibtex-author-capf nil t))

** PDF metadata from Citar

*** Writing title and author into a PDF

=sia-citar-update-pdf-metadata= updates a PDF's embedded metadata.

- Asks you to pick a reference with =citar-select-ref=.
- Checks that =citar-library-paths= is set, and finds the PDF files attached to that key. If there is more than one, you choose.
- Takes the title from the bibliography, and the author, falling back to the editor with " (ed.)" appended.
- Copies the PDF into the backup directory.
- Runs =exiftool= to overwrite the Title and Author fields in place.

The =let*= used to refer to =cite-key= (with a hyphen) although the argument is =citekey=, which signalled a void-variable error; it now uses =citekey=. One weakness remains: the shell command is built by string concatenation with single quotes, so a title containing an apostrophe or a path with spaces would break it.

#+begin_src emacs-lisp -i
;;;; Working with PDF metadata from citar
(defun sia-citar-update-pdf-metadata (citekey)
  (interactive (list (citar-select-ref)))
  (citar--check-configuration 'citar-library-paths)
  (unless citar-library-paths
    (user-error "Make sure `citar-library-paths' is non-nil"))
  (let* ((files (gethash citekey (citar-get-files citekey))))
    (unless files
      (user-error (format "There are no PDF files associated with %s" citekey)))
    (let ((file (or (unless (cdr files) (car files)) (completing-read "Please select a PDF file: " files)))
          (title (citar-get-value 'title citekey))
          (author (cond ((citar-get-value 'author citekey)
                         (citar-get-value 'author citekey))
                        ((citar-get-value 'editor citekey)
                         (concat (citar-get-value 'editor citekey) " (ed.)")))))
      (progn
        (copy-file file sia-citar-library-backup-path 1)
        (call-process-shell-command
         (concat "exiftool -overwrite_original_in_place -Title='" title "' -Author='" author "' " file))))))

*** Citar

Citar provides completing-read based selection of bibliography entries. Under =:custom= it:

- reads the bibliography from =sp-bibtex-files=, the list =sp-bibtex-register= keeps, for both Org-cite and Citar (it used the obsolete =sp-bibliography=, which is nil by default, so Citar loaded with an empty bibliography),
- leaves the processor settings to the =oc= block above, which already sets them,
- points the library at =sp-literature-dir=, counting PDF and JPG files as attachments with a hyphen between several files of one key (these were in =sp-academic=, with the library path commented out),

*** Citation hover

Hovering over a =[cite:@key]= link shows the full reference of the entry, modelled on the hover card of Obsidian's Pandoc Reference List. The text is the =preview= template of =citar-templates=, so change that template to change the hover text. =sp-cite-hover-display= chooses where it appears:

- =tooltip=: the =help-echo= of the link, shown when the mouse rests on it. A font-lock matcher adds the property to every =[cite...]= link in Org buffers, so it survives Org's own link fontification.
- =echo=: an Eldoc function (=sp-cite-hover--eldoc=) shows the reference in the echo area when point is on the link. Eldoc only follows point, not the mouse.

On a link with several keys, the reference is the one under the mouse or point, or the first key when it is on the prefix, suffix or style. A key missing from the bibliography shows =@key: not found in the bibliography=. Set =sp-cite-hover-display= to nil to turn both off; changing it needs no restart, but a new value for =tooltip= applies as buffers are refontified.

Tested in Emacs 29.3 in batch, with =citar= stubbed (key lookup, tooltip, Eldoc callback, outside a link); not run in the interactive config.

#+begin_src emacs-lisp -i
;;;; Citation hover
;; Show the formatted reference of the citation under the mouse or point.
(defcustom sp-cite-hover-display '(tooltip echo)
  "Where to show the reference of the `[cite:@key]' link under the mouse or point.
`tooltip' sets the `help-echo' of the link, shown when the mouse hovers over
it.  `echo' adds an Eldoc function, which shows the reference in the echo area
when point is on the link.  Set it to nil to turn both off."
  :type '(set (const :tag "Tooltip on mouse hover" tooltip)
              (const :tag "Echo area when point is on the link" echo))
  :group 'sp)

(defconst sp-cite-hover--link-regexp
  "\\[cite\\(?:/[-_/[:alnum:]]*\\)?:[^]]*\\]"
  "Regexp matching an Org citation such as `[cite/t:see @key1; @key2 p. 3]'.")

(defconst sp-cite-hover--key-regexp
  "@\\([-.:?!`'/*@+|(){}<>&_^$#%~[:alnum:]]+\\)"
  "Regexp matching a citation key, with the key itself in group 1.")

(defun sp-cite-hover--key-at (pos)
  "Return the citation key at POS, or the first key of the citation around it.
Return nil when POS is not inside a `[cite:]' link."
  (save-excursion
    (goto-char pos)
    (let ((line-start (line-beginning-position))
          (line-end (line-end-position))
          found)
      (while (and (not found)
                  (re-search-backward "\\[cite" line-start t))
        (when (and (looking-at sp-cite-hover--link-regexp)
                   (<= pos (match-end 0)))
          (setq found (cons (match-beginning 0) (match-end 0)))))
      (when found
        (goto-char (car found))
        (let (first at-pos)
          (while (and (not at-pos)
                      (re-search-forward sp-cite-hover--key-regexp
                                         (min (cdr found) line-end) t))
            (unless first (setq first (match-string-no-properties 1)))
            (when (and (<= (match-beginning 0) pos) (<= pos (match-end 0)))
              (setq at-pos (match-string-no-properties 1))))
          (or at-pos first))))))

(defun sp-cite-hover--reference (key)
  "Return the formatted reference of KEY from the bibliography, or nil.
It uses `citar-format-reference', which applies the `preview' template of
`citar-templates'.  Any error from citar gives nil, so a hover never breaks."
  (when (and key (require 'citar nil t) (fboundp 'citar-format-reference))
    (and-let* ((entry (ignore-errors (citar-get-entry key)))
               (text (ignore-errors (citar-format-reference (list key))))
               ((stringp text))
               (text (string-trim (substring-no-properties text)))
               ((not (string-empty-p text))))
      text)))

(defun sp-cite-hover--help-echo (_window object pos)
  "Return the reference of the citation at POS in OBJECT for `help-echo'."
  (when (and (memq 'tooltip sp-cite-hover-display) (bufferp object))
    (with-current-buffer object
      (when-let* ((key (sp-cite-hover--key-at pos)))
        (or (sp-cite-hover--reference key)
            (format "@%s: not found in the bibliography" key))))))

(defun sp-cite-hover--fontify (limit)
  "Put the `help-echo' tooltip on the citations up to LIMIT.
It is a font-lock matcher: it adds the property and never fontifies."
  (while (re-search-forward sp-cite-hover--link-regexp limit t)
    (add-text-properties (match-beginning 0) (match-end 0)
                         '(help-echo sp-cite-hover--help-echo)))
  nil)

(defun sp-cite-hover--eldoc (callback &rest _)
  "Eldoc function: show the reference of the citation at point with CALLBACK."
  (when (memq 'echo sp-cite-hover-display)
    (when-let* ((key (sp-cite-hover--key-at (point)))
                (text (sp-cite-hover--reference key)))
      (funcall callback text :thing (concat "@" key) :face 'font-lock-doc-face))))

(defun sp-cite-hover-setup ()
  "Turn on the citation tooltip and echo area reference in this Org buffer."
  (add-hook 'eldoc-documentation-functions #'sp-cite-hover--eldoc nil t)
  (font-lock-add-keywords nil '((sp-cite-hover--fontify)) 'append)
  (font-lock-flush))

(add-hook 'org-mode-hook #'sp-cite-hover-setup)
#+end_src

This academic module connects bibliography entries to notes. Literature notes are Vulpea notes; =citar-denote= is no longer used.

- =citar-vulpea= makes Citar use Vulpea notes, tagged =litnote=, in =~/notes/litnotes=.

** Literature notes as Vulpea nodes

*** citar-vulpea

Installs =citar-vulpea=, loaded after Citar and Vulpea, and turns on =citar-vulpea-mode=, which registers it as Citar's notes source.

- Notes use the =litnote= tag and the =ROAM_REFS= property, notes are titled "author (date) title" and live in =~/notes/litnotes=.
- Citar always creates a note when you open notes for a reference that has none (=citar-open-always-create-notes=, which was set by the =citar-denote= block).
- Global keys: =C-c w b c= creates a note, =C-c w b n= opens one.
- In Org buffers: =C-c w b k= and =C-c w b K= add or remove a citekey of the current note, =C-c w b d= runs the do-what-I-mean command (opens the reference of the note, or offers to add one), =C-c w b e= opens a bibliography entry (it asks which; =citar-denote-open-reference-entry= took it from the note).
- =C-c w b x= (=citar-denote-nocite=) is gone; =citar-vulpea= has no equivalent.
- The title template still has to be matched to the titles of the existing notes (many are just the citekey).
