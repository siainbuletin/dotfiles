* sp-academic.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/academic/sp-academic.el
:END:

This is the umbrella module for academic work.

- Loads five sub-modules (=sp-bibprocess=, =sp-pdfprocess=, =sp-citations=, =sp-litnotes= and =sp-fetch-academic=) so they can be enabled together.
- Defines the three citation user options before any sub-module needs them.
- Configures the reference managers directly:
  - =org-ref= set up to insert =org-cite= citations,
  - =helm-bibtex= library and notes paths,
  - the =binder= package for Scrivener-like manuscript work.
- The list of =.bib= files is no longer written here: =sp-bibtex-register= in =sp-bibprocess= finds every =.bib= file in =~/Documents/bibliography/= and hands the list to Org, =citar=, =org-ref= and =helm-bibtex= alike.

The long commentary is a roadmap more than a description.

- Planned pieces: DEVONthink integration, deep links into PDFs, semantic search over PDFs. Paper fetching now has its own sub-module, [[file:sp-fetch-academic.org][sp-fetch-academic]].
- Literature notes are made with =citar-vulpea= (see =sp-litnotes=); =citar-denote= is gone. =ROAM_REFS= handling goes through =vulpea-citar=.
- Bibliography files are expected under =~/Documents/bibliography/=, PDFs under =~/Documents/literature/=.
- The module appears in the default module list in =init.el= under Academic.

** Citation keys

Every entry in a plain BibTeX file gets its key from =bibtex-generate-autokey=, with one scheme everywhere. The options are set once, in =sp-bibprocess=.

- Shape: the family names of the first two authors, four-digit year and the first two significant title words, each cut to five letters and joined by hyphens, all in lower case, for example =smithjones-2017-atten-all= (Smith and Jones, Attention Is All You Need) or =hegel-1807-phanom-geist= (one author). "Is" is in the ignore list, so it is skipped. A third word is added when the second is short (=bibtex-autokey-titlewords-stretch= is 1).
- Several authors: the first two are joined without a separator and later ones are dropped, so Smith, Jones and Lee is still =smithjones-2017-...=.
- Accents are stripped to plain ASCII (=Müller= becomes =muller=) so keys survive any tool.
- The title words skip articles (English and German), "Is", "the", "a", "On" and "on" (the last five are your additions), and any word that is not capitalised or has odd characters.
- Three ways to apply it: =C-c C-c= in =bibtex-mode= cleans an entry (=C-u C-c C-c= also makes a new key), =biblio= entries get one on insertion (=biblio-bibtex-use-autokey=), and the key is checked against every registered =.bib= file so duplicates are noticed.
- Existing keys are left alone. Changing a key breaks the =cite:= links and =ROAM_REFS= that mention it, so regenerate only entries you have not cited yet.

** Settings worth knowing

The ones that change how the setup behaves most. All are set in the modules named in brackets.

- =bibtex-autokey-*= [=sp-bibprocess=]: the key scheme above. =bibtex-autokey-edit-before-use= is =t=, so =bibtex-clean-entry= shows the key in the minibuffer for approval.
- =bibtex-entry-format= [=sp-bibprocess=]: what cleaning does to an entry (page dashes, whitespace, alignment, trailing comma, braces). Required-field checks are left out so incomplete =biblio= entries are not rejected.
- =bibtex-search-entry-globally= with =bibtex-files= [=sp-bibprocess=]: key look-ups and duplicate checks span all registered files, not just the open buffer.
- =bibtex-dialect= [=sp-bibprocess=]: =biblatex=, so =date=, =journaltitle= and =file= are valid fields.
- =sp-bibliography-dir= [=sp-bibprocess=]: where the =.bib= files live. Add or remove a file, then run =C-c w b r=.
- =org-cite-global-bibliography= and =citar-bibliography= [=sp-citations=]: both read the registered list, so Org and =citar= always see the same files.
- =citar-library-paths=, =citar-library-file-extensions=, =citar-file-additional-files-separator= [=sp-citations=]: where =citar= looks for PDFs (=~/Documents/literature/=), which extensions count, and the separator for several files per key. The library path was commented out before, so =citar= found no PDFs.
- =citar-notes-paths= and =citar-templates= [=sp-citations=]: where notes live and how candidates are displayed.
- =org-cite-export-processors= [=sp-citations=]: CSL for every export format; needs the styles in =sp-data-home=.
- =biblio-bibtex-use-autokey= [=sp-fetch-academic=]: gives entries inserted from CrossRef, arXiv and DOI the same key scheme.

The old sections of this document that set BibTeX options twice, repeated three definitions or tried to set Citar options inside =:custom= are fixed below, and each fix says so.

*** Showing cite keys in descriptive links

=org-ref-make-org-link-cite-key-visible= runs after =org-activate-bracket-links= highlights a link.

- When the link target starts with one of =org-ref-cite-types=, it removes the invisibility from the whole link and colours it with =org-ref-cite-color=.
- So the cite key stays visible even when the link has a description.
- It uses =-sort= from =dash= to try longer cite types first.

#+begin_src emacs-lisp -i
(defun org-ref-make-org-link-cite-key-visible (&rest _)
  "Make the org-ref cite link visible in descriptive links."

  (save-match-data
    (let ((s (match-string 1))
      (beg (match-beginning 0))
      (end (match-end 0))
      (cite-re (format "^\\(%s:\\)"
               (regexp-opt (-sort
                    (lambda (a b)
                      (> (length a) (length b)))
                    org-ref-cite-types))))
      cite-type)

      (when (and s (string-match cite-re s))
    (setq cite-type (match-string 1 s))
    (remove-text-properties beg end
                '(invisible))
    (add-text-properties
     beg end
     `(face (:foreground ,org-ref-cite-color)))))))
#+end_src

* sp-bibprocess.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/academic/sp-bibprocess.el
:END:

This module manages the BibTeX bibliography that the academic modules build on. It:

- defines where the =.bib= files live (=sp-bibliography-dir=, =~/Documents/bibliography/= by default),
- keeps one list of them and shares it with Org's citation system (=org-cite-global-bibliography=), =citar= (=citar-bibliography=), =org-ref= (=org-ref-default-bibliography=), =helm-bibtex= (=bibtex-completion-bibliography=) and =bibtex-mode= itself (=bibtex-files=),
- configures the built-in =bibtex= mode for BibLaTeX, including the one scheme for citation keys described under [[*Citation keys]],
- adds commands to audit attachments. Looking up new entries online (=biblio=) moved to [[file:sp-fetch-academic.org][sp-fetch-academic]].

Loading:

- It is not listed directly in the module profiles; =sp-academic= loads it with =require=.
- It used to repeat the variable, the register command and the lookup helper verbatim under a "BIBLIOGRAPHY" heading, and to set the key options a second time in =sp-academic=. Both repeats are gone, so every option has one definition.

*** Bibliography directory

The folder holding the BibTeX files and their attachments is =sp-bibliography-dir=, defined in =sp-globals= (=~/Documents/bibliography/= by default, or the folder named by =SP_BIBLIOGRAPHY_DIR=). This module used to define a second option, =sp-bibtex-dir=, that only copied it; there is now one option, and the old name is gone with no alias.


*** List of BibTeX files

=sp-bibtex-file-regexp= matches the =.bib= files that count: a name that starts with a letter or digit (so editor backups and dotfiles are skipped) and ends in =.bib=. The old pattern =^[A-Z|a-z|0-9].+.bib$= also matched names like =x-bib= and, through the literal =|=, names starting with a pipe.

=sp-bibtex-files= is filled at load time with every matching file in the directory, or left =nil= if the directory does not exist.

#+begin_src emacs-lisp -i
(defconst sp-bibtex-file-regexp "\\`[[:alnum:]].*\\.bib\\'"
  "Regexp for the names of the BibTeX files in `sp-bibliography-dir'.")

(defvar sp-bibtex-files
  (when (file-exists-p sp-bibliography-dir)
    (directory-files sp-bibliography-dir t sp-bibtex-file-regexp))
  "List of BibTeX files. Use `sp-bibtex-register' to configure.")
#+end_src

*** Register BibTeX files

=sp-bibtex-register= rescans =sp-bibliography-dir= and gives the same list to every consumer, then echoes the registered files.

- =sp-bibtex-files=, the list itself.
- =org-cite-global-bibliography= and =citar-bibliography=, for citations in Org and for =citar=.
- =org-ref-default-bibliography= and =bibtex-completion-bibliography=, for =org-ref= and =helm-bibtex=.
- =bibtex-files=, so that with =bibtex-search-entry-globally= a key is looked up (and checked for duplicates) in all of them.

Run it after adding or removing a =.bib= file.

#+begin_src emacs-lisp -i
;;;###autoload
(defun sp-bibtex-register ()
  "Register the contents of the `sp-bibliography-dir' with `sp-bibtex-files`.
Use when adding or removing a BibTeX file from or to `sp-bibliography-dir'."
  (interactive)
  (when (file-exists-p sp-bibliography-dir)
    (let ((bib-files (directory-files sp-bibliography-dir t sp-bibtex-file-regexp)))
      (setq sp-bibtex-files bib-files
            org-cite-global-bibliography bib-files
            citar-bibliography bib-files
            org-ref-default-bibliography bib-files
            bibtex-completion-bibliography bib-files
            bibtex-files bib-files)))
  (message "Registered:\n%s" (mapconcat #'identity sp-bibtex-files "\n")))
#+end_src

** Citation keys

*** Key helper

=sp-bibtex-ascii-key= is the =bibtex-autokey-before-presentation-function=: it receives the generated key and returns it with accents removed. The key is decomposed (=ü= into =u= and a combining mark) and everything outside ASCII is dropped, so =müller2020= becomes =muller2020=. Authors in a non-Latin script would lose their name entirely, so an empty result keeps the original key.

#+begin_src emacs-lisp -i
;;;; Citation keys

(require 'ucs-normalize)

(defun sp-bibtex-ascii-key (key)
  "Return KEY as plain ASCII, or KEY itself when nothing is left."
  (let ((ascii (replace-regexp-in-string
                "[^[:ascii:]]" "" (ucs-normalize-NFKD-string key))))
    (if (string-empty-p ascii) key ascii)))
#+end_src

*** Long keys

Keys over 45 characters do not fit in the =citar= candidates, where the key column is limited to 45 (see [[*Citar]]). The helpers here find them, suggest a shorter key and say where a key is used; the fix itself is a kind of the lint, =sp-bibtex-lint-fix-keys= (see [[*Long citation keys]]).

- =sp-bibtex-key-max-length= (45): the longest key that is not flagged.
- =sp-bibtex-key-update-targets= (=notes files bibrefs=): what a rename may update besides the entry.
- =sp-bibtex-key-notes-directory= (nil is =sp-notes-dir=): the folder of the notes.
- =sp-bibtex-entry-keys= and =sp-bibtex-long-keys=: the keys of the current buffer, and the ones over the limit, each with the position of the key; =string=, =preamble= and =comment= are skipped.
- =sp-bibtex--suggest-key=: the key =bibtex-generate-autokey= makes with the key scheme above; when that fails or is too long, the old key cut to the limit; when it is taken, a letter is added.
- =sp-bibtex--read-short-key=: asks with the old key, its length and the title, and asks again until the answer has at most 45 characters, no character BibTeX does not allow (space, comma, braces, quotes, =#=, =%=, =~= and so on) and is not the key of another entry of any registered file; an empty answer keeps the key.

What a key is used by, and what a rename changes:

- notes (=sp-bibtex-keys--note-edits=), in the folder of the notes, every =.org= file:
  - the key on a =#+reference:= or =:ROAM_REFS:= line (a key by itself, after =@=, or in =cite:=);
  - citations: =@key= (in =[cite:@key]=, =[cite/t:@a; @b]= or in the text) and =cite:key=;
  - the key must end at a space, =;=, =,=, a bracket or the end of the line (a full stop after it is allowed), so =smith2020= does not change =smith2020attention=;
  - a note that is open with unsaved changes is left alone and listed;
  - each changed note is copied to =key-renames-STAMP/= in =sp-bibtex-lint-backup-directory= first, then vulpea is told (=vulpea-db-update-file=) so the database follows.
- cross references (=sp-bibtex-keys--replace-refs=): =crossref=, =xref=, =xdata= and =related= fields of the entries, in the file and in the other registered files (copied first).
- PDFs (=sp-bibtex-keys--pdf-moves=): the files of =sp-literature-dir= called =KEY.ext= or =KEY-anything.ext= (the second form is what =citar= reads as an additional file), with =KEY= changed in the name; a move whose new name exists is left out. The =file= field of the entry gets the new names (=sp-bibtex-keys--rewrite-entry=).
  - the files move through =sp-bibtex-files--move=: with =sp-bibtex-files-devonthink-tool= set, DEVONthink renames the record (see [[file:devonthink-move.org][devonthink-move.org]]), which keeps its UUID, tags and annotations, and the record is filed back in the group it was in; otherwise the file is renamed on disk.
  - PDFs named after an old BibDesk key (not the citekey) are not touched.

(defun sp-bibtex--suggest-key (text max table)
  "Suggest a key of at most MAX characters for the entry TEXT.
It is the key `bibtex-generate-autokey' makes, or the old key cut to MAX
when that fails, and a letter is added when TABLE, the keys taken, has it."
  (with-temp-buffer
    (insert text)
    (delay-mode-hooks (bibtex-mode))
    (goto-char (point-min))
    (let* ((old (and (re-search-forward sp-bibtex--entry-key-regexp nil t)
                     (match-string-no-properties 2)))
           (generated (ignore-errors
                        (goto-char (point-min))
                        (bibtex-generate-autokey)))
           (base (if (and (stringp generated) (not (string-empty-p generated))
                          (<= (length generated) max))
                     generated
                   (substring (or old "key") 0 (min max (length (or old "key"))))))
           (candidate base)
           (suffix ?a))
      (while (and (gethash candidate table) (<= suffix ?z))
        (setq candidate (concat (substring base 0 (min (length base) (1- max)))
                                (string suffix))
              suffix (1+ suffix)))
      candidate)))

(defun sp-bibtex--key-problem (key max table)

TABLE holds the keys already taken."
  (cond ((string-empty-p key) "the key is empty")
        ((> (length key) max) (format "%d characters, the limit is %d" (length key) max))
        ((string-match-p "[][ \t\n,{}()\"#%'\\\\~=]" key) "it has a character BibTeX does not allow")
        ((gethash key table) "another entry has this key")))

(defun sp-bibtex--read-short-key (old suggestion title max table)
  "Ask for a key of at most MAX characters to replace OLD, until it is valid.
SUGGESTION is the initial input and TITLE is shown to recognise the entry.
Return the new key, or nil when the answer is empty, which keeps OLD.  TABLE

  (let (answer done)
    (while (not done)
      (setq answer (string-trim
                    (read-string (format "%s (%d characters, over %d)\n%s\nShorter key (empty keeps it): "

                     (let ((problem (sp-bibtex--key-problem answer max table)))
                       (when problem
                         (message "%s: %s" answer problem)
                         (sit-for 1)
                         (setq suggestion answer)
                         nil)
                       (not problem)))))
    (unless (string-empty-p answer) answer)))

(defun sp-bibtex-keys--boundary-p (end)
  "Non-nil when the key that ends at END is not the start of a longer word."
  (save-excursion
    (goto-char end)
    (or (eobp)
        (looking-at "[]; ,\n\t)}]")
        (looking-at "\\.\\(?:[]; ,\n\t)}]\\|\\'\\)"))))

(defun sp-bibtex-keys--note-edits (renames)
  "Return the edits RENAMES, (OLD . NEW) pairs, need in the current note.
Each edit is (BEG END NEW KIND) and KIND is `ref' for a key on a `#+reference:'
or `ROAM_REFS' line, `cite' for `@key' and `cite:key'.  The edits are in
descending order of position, so they can be made one after the other."
  (when renames
    (let ((case-fold-search nil)
          (regexp (regexp-opt (mapcar #'car renames) t))
          edits)
      (save-excursion
        (goto-char (point-min))
        (while (re-search-forward regexp nil t)
          (let* ((beg (match-beginning 1))
                 (end (match-end 1))
                 (old (match-string-no-properties 1))
                 (ref (save-excursion
                        (goto-char beg)
                        (beginning-of-line)
                        (let ((case-fold-search t))
                          (looking-at "[ \t]*\\(?:#\\+reference:\\|:ROAM_REFS:\\)"))))
                 (before (and (> beg (point-min)) (char-before beg))))
            (when (and (or (eq before ?@)
                           (and (eq before ?:)
                                (save-excursion
                                  (goto-char (1- beg))
                                  (looking-back "cite[[:alpha:]*]*" (line-beginning-position))))
                           (and ref (memq before '(?\s ?\t ?\; ?,))))
                       (sp-bibtex-keys--boundary-p end))
              (push (list beg end (cdr (assoc old renames)) (if ref 'ref 'cite)) edits)))))
      edits)))

(defun sp-bibtex-keys--update-notes (renames files stamp)
  "Make the RENAMES in the notes FILES, after a copy of each in the backup folder of STAMP.
A note that is open with unsaved changes is left alone.  Return (CHANGED . SKIPPED),
SKIPPED the files that were left."
  (let ((changed 0) skipped
        (dir (sp-bibtex-keys--backup-directory stamp))
        (notes (sp-bibtex-keys--notes-directory)))
    (dolist (file files)
      (let ((visiting (find-buffer-visiting file)))
        (if (and visiting (buffer-modified-p visiting))
            (push file skipped)
          (let ((edits (with-temp-buffer
                         (insert-file-contents file)
                         (sp-bibtex-keys--note-edits renames))))
            (when edits
              (make-directory dir t)
              (copy-file file (expand-file-name
                               (replace-regexp-in-string "/" "!" (file-relative-name file notes))
                               dir)
                         t)
              (with-temp-buffer
                (insert-file-contents file)
                (dolist (edit edits)
                  (goto-char (nth 0 edit))
                  (delete-region (nth 0 edit) (nth 1 edit))
                  (insert (nth 2 edit)))
                (write-region nil nil file nil 'silent))
              (when visiting (with-current-buffer visiting (revert-buffer t t t)))
              (when (fboundp 'vulpea-db-update-file)
                (ignore-errors (vulpea-db-update-file file)))
              (cl-incf changed))))))
    (cons changed (nreverse skipped))))

(defun sp-bibtex-keys--replace-refs (renames)
  "Make the RENAMES in the `crossref', `xref', `xdata' and `related' fields of this buffer.
Return the number of keys changed."
  (let ((count 0) (case-fold-search t))
    (save-excursion
      (goto-char (point-min))
      (while (re-search-forward
              "^[ \t]*\\(?:crossref\\|xref\\|xdata\\|related\\)[ \t]*=[ \t]*[{\"]\\([^}\"]*\\)[}\"]"
              nil t)
        (let* ((beg (match-beginning 1))
               (end (match-end 1))
               (value (match-string-no-properties 1))
               (new (mapconcat
                     (lambda (part)
                       (if-let* ((hit (assoc (string-trim part) renames)))
                           (progn (cl-incf count)
                                  (replace-regexp-in-string (regexp-quote (car hit)) (cdr hit)
                                                            part t t))
                         part))
                     (split-string value "," nil) ",")))
          (unless (equal new value)
            (goto-char beg)
            (delete-region beg end)
            (insert new)))))
    count))

(defun sp-bibtex-keys--bib-refs (renames file)
  "Return (FILE . COUNT) for each registered .bib file, and FILE, that RENAMES change."
  (let (found)
    (dolist (path (delete-dups (cons file (and (boundp 'sp-bibtex-files) sp-bibtex-files))))
      (when (file-readable-p path)
        (let ((count (with-temp-buffer
                       (insert-file-contents path)
                       (sp-bibtex-keys--replace-refs renames))))
          (when (> count 0) (push (cons path count) found)))))
    (nreverse found)))

(defun sp-bibtex-keys--update-bibs (renames file stamp)
  "Make the RENAMES in the fields of the registered .bib files other than FILE.
Each file is copied to the backup folder of STAMP first.  Return the number
of files changed."
  (let ((changed 0))
    (dolist (path (seq-remove (lambda (p) (file-equal-p p file))
                              (and (boundp 'sp-bibtex-files) sp-bibtex-files)))
      (when (and (file-readable-p path)
                 (not (when-let* ((visiting (find-buffer-visiting path)))
                        (buffer-modified-p visiting))))
        (let ((new (with-temp-buffer
                     (insert-file-contents path)
                     (and (> (sp-bibtex-keys--replace-refs renames) 0) (buffer-string)))))
          (when new
            (make-directory (sp-bibtex-keys--backup-directory stamp) t)
            (copy-file path (expand-file-name (file-name-nondirectory path)
                                              (sp-bibtex-keys--backup-directory stamp))
                       t)
            (write-region new nil path nil 'silent)
            (when-let* ((visiting (find-buffer-visiting path)))
              (with-current-buffer visiting (revert-buffer t t t)))
            (cl-incf changed)))))
    changed))

;;;; PDFs named after a key

(defun sp-bibtex-keys--pdf-moves (renames)
  "Return ((OLD (FROM . TO) ...) ...): the files of the library named after an old key.
A file is named after OLD when its name is OLD, a dot and an extension, or OLD,
a hyphen and anything (`citar' takes the part after the hyphen as the name of an
additional file).  TO is FROM with OLD changed to the new key; a move whose TO
exists is left out."
  (when-let* (((boundp 'sp-literature-dir))
              (ctx (sp-bibtex-files--library)))
    (let ((dir (sp-bibtex-files--ctx-dir ctx))
          result)
      (maphash
       (lambda (_name rels)
         (dolist (rel rels)
           (let ((base (file-name-nondirectory rel)))
             (dolist (rename renames)
               (let ((old (car rename)))
                 (when (and (string-prefix-p old base)
                            (memq (aref (concat base " ") (length old)) '(?. ?-)))
                   (let* ((from (expand-file-name rel dir))
                          (to (expand-file-name
                               (concat (file-name-directory rel) (cdr rename)
                                       (substring base (length old)))
                               dir)))
                     (unless (file-exists-p to)
                       (push (cons from to) (alist-get old result nil nil #'equal))))))))))
       (sp-bibtex-files--ctx-names ctx))
      (mapcar (lambda (entry) (cons (car entry) (sort (cdr entry) (lambda (a b) (string< (car a) (car b))))))
              (nreverse result)))))

(defun sp-bibtex-keys--rename-in-value (value from to)
  "Return the `file' field VALUE with the file name FROM changed to TO."
  (replace-regexp-in-string
   (concat "\\(\\`\\|[;/ ]\\)" (regexp-quote from) "\\(\\'\\|;\\)")
   (lambda (match) (concat (match-string 1 match) to (match-string 2 match)))
   value t))

(defun sp-bibtex-keys--rewrite-entry (text old new moves)
  "Return the entry TEXT with its key OLD changed to NEW.
The file names of MOVES, (FROM . TO) pairs, are changed in its `file' field."
  (with-temp-buffer
    (insert text)
    (goto-char (point-min))
    (let ((case-fold-search nil))
      (when (and (re-search-forward sp-bibtex--entry-key-regexp nil t)
                 (equal (match-string 2) old))
        (replace-match new t t nil 2)))
    (goto-char (point-min))
    (let ((case-fold-search t))
      (when (and moves (re-search-forward "^[ \t]*file[ \t]*=[ \t]*{\\([^{}]*\\)}" nil t))
        (let ((beg (match-beginning 1))
              (end (match-end 1))
              (value (match-string-no-properties 1)))
          (dolist (move moves)
            (setq value (sp-bibtex-keys--rename-in-value
                         value (file-name-nondirectory (car move)) (file-name-nondirectory (cdr move)))))
          (goto-char beg)
          (delete-region beg end)
          (insert value))))
    (buffer-string)))

*** bibtex

Configures the built-in =bibtex= mode:

- the BibLaTeX dialect,
- the key scheme (see [[*Citation keys]] in the first part of this document): first two authors, four-digit year and two title words of at most five letters, in lower case, with hyphens between year and title words, such as =smithjones-2017-atten-all=,
- the articles to skip in the title (English and German, plus any word that is not capitalised or has odd characters), now also "Is", "the", "a", "On" and "on",
- what cleaning an entry does: =opts-or-alts= (drop empty optional fields), =page-dashes= (=10-20= to =10--20=), =whitespace=, =realign=, =last-comma=, =delimiters=, =unify-case= and =braces=. =required-fields= and =numerical-fields= are left out so that an incomplete entry from a look-up is not rejected,
- a duplicate check across all registered files,
- two extra optional fields offered when creating entries (=keywords= and =file= for attachments),
- alignment of field values at the equals sign.

Also:

- =bibtex-aux-opt-alist= carries the same two fields. It used to be saved by Customize in =init.el= and is now set here.
- =:demand t= loads it at once, which registers the bibliography files (=sp-bibtex-register= in =:config=) before anything reads them; =sp-academic= used to do that with =(require 'bibtex)=.
- =C-c w b r= runs =sp-bibtex-register= at any time; =C-c w b k= runs =sp-bibtex-lint-fix-keys=.
- =H-b= in a BibTeX buffer opens the org-ref hydra (it needs a Hyper key). It was =define-key= in =sp-academic=.

*** Names

Names are the base of the lint. A name in an =author= or =editor= field is canonical when it reads =Last, First= (=van Gogh, Vincent=, =Smith, John=). =sp-bibtex-canonical-name= turns =John Smith= into =Smith, John=, keeps lower case particles (=sp-bibtex-name-particles=) with the last name, and leaves corporate names in braces (={Big Corp}=), =others= and one-word names alone. Splitting at =and= and at spaces ignores what is inside braces.

#+begin_src emacs-lisp -i
(defun sp-bibtex--unwrap (value)
  "VALUE without its outer braces or quotes, and the delimiter pair; nil if it has none.
Return (TEXT . OPEN), or nil for a value that is a macro or a concatenation."
  (let ((value (string-trim value)))
    (when (> (length value) 1)
      (let ((open (aref value 0)) (close (aref value (1- (length value)))))
        (cond
         ((and (eq open ?{) (eq close ?}) (sp-bibtex--balanced-p (substring value 1 -1)))
          (cons (substring value 1 -1) ?{))
         ((and (eq open ?\") (eq close ?\") (not (string-search "\"" (substring value 1 -1))))
          (cons (substring value 1 -1) ?\")))))))

(defun sp-bibtex--balanced-p (text)
  "Non-nil when the braces of TEXT never close more than they open and end even."
  (let ((depth 0) (ok t))
    (dolist (c (string-to-list text))
      (cond ((eq c ?{) (cl-incf depth))
            ((eq c ?}) (cl-decf depth) (when (< depth 0) (setq ok nil)))))
    (and ok (= depth 0))))

(defun sp-bibtex--split-depth0 (text separator-re)
  "Split TEXT at the matches of SEPARATOR-RE that are outside braces."
  (let ((depth 0) (start 0) (i 0) (n (length text)) parts)
    (while (< i n)
      (let ((c (aref text i)))
        (cond ((eq c ?{) (cl-incf depth) (cl-incf i))
              ((eq c ?}) (cl-decf depth) (cl-incf i))
              ((and (= depth 0) (eq (string-match separator-re text i) i))
               (push (substring text start i) parts)
               (setq i (match-end 0) start i))
              (t (cl-incf i)))))
    (push (substring text start) parts)
    (nreverse parts)))

(defun sp-bibtex-split-names (text)
  "The names in the author or editor TEXT, split at \" and \" outside braces."
  (seq-remove #'string-empty-p
              (mapcar #'string-trim
                      (sp-bibtex--split-depth0 (replace-regexp-in-string "[ \t\n]+" " " text)
                                               "[ \t]+and[ \t]+"))))

(defun sp-bibtex-canonical-name (name)
  "NAME as \"Last, First\".  A corporate {Name}, \"others\" and one-word names stay."
  (let ((name (string-trim (replace-regexp-in-string "[ \t\n]+" " " name))))
    (cond
     ((or (string-empty-p name) (equal name "others")
          (and (eq (aref name 0) ?{) (sp-bibtex--balanced-p name)
               (= 1 (length (sp-bibtex--split-depth0 name "[ \t]+")))))
      name)
     ((string-search "," name)
      (string-join (mapcar #'string-trim (sp-bibtex--split-depth0 name ",")) ", "))
     (t
      (let ((words (sp-bibtex--split-depth0 name "[ \t]+")))
        (if (null (cdr words))
            name
          (let ((last (list (car (last words))))
                (rest (butlast words)))
            (while (and rest (member (car (last rest)) sp-bibtex-name-particles))
              (push (car (last rest)) last)
              (setq rest (butlast rest)))
            (if (null rest)
                name
              (format "%s, %s" (string-join last " ") (string-join rest " "))))))))))

(defun sp-bibtex-canonical-names (text)
  "The author or editor TEXT with every name in the canonical form."
  (string-join (mapcar #'sp-bibtex-canonical-name (sp-bibtex-split-names text)) " and "))

(defun sp-bibtex--name-key (canonical)
  "A lookup key for the CANONICAL name: lower case, no braces, dots or extra spaces."
  (string-trim (replace-regexp-in-string
                "[ \t]+" " "
                (replace-regexp-in-string "[{}.]" "" (downcase canonical)))))

*** The author notes

Author notes (=:person:= notes) are only /read/: =sp-bibtex-people= indexes their titles in the canonical form and keeps the index for =sp-bibtex-people-cache-seconds=. A name in a =.bib= file that is close to an author note (two edits, same first letters) is reported as a likely typo of it. A name with no note is /not/ reported and no note is ever created.

#+begin_src emacs-lisp -i
(defvar sp-bibtex--people-cache nil
  "(TIME . INDEX) of the author notes, see `sp-bibtex-people'.")

(defun sp-bibtex--note-aliases (file)
  "The aliases in the head of the note FILE (its ROAM_ALIASES), as a list of strings."
  (when (and file (file-readable-p file))
    (with-temp-buffer
      (insert-file-contents file nil 0 4096)
      (let ((case-fold-search t) aliases)
        (while (re-search-forward "^\\(?:#\\+\\|[ \t]*:\\)ROAM_ALIASES:?[ \t]*\\(.*\\)$" nil t)
          (setq aliases (append aliases (ignore-errors
                                         (split-string-and-unquote (match-string-no-properties 1))))))
        aliases))))

(defun sp-bibtex--make-people (people)
  "The index of PEOPLE: a plist of :names, :keys, :files, :surnames and :buckets.
Each of PEOPLE is a title, or a plist with :title and :file from
`sp-author-notes--file-head'.  The aliases of the note files count as known
names, so a name that is an alias is not suggested to be a typo."
  (let ((keys (make-hash-table :test #'equal))
        (buckets (make-hash-table :test #'equal))
        (files (make-hash-table :test #'equal))
        (surnames (make-hash-table :test #'equal))
        names)
    (dolist (person people)
      (let* ((title (if (stringp person) person (plist-get person :title)))
             (canonical (sp-bibtex-canonical-name title))
             (key (sp-bibtex--name-key canonical)))
        (unless (gethash key keys)
          (puthash key canonical keys)
          (push canonical (gethash (sp-bibtex--surname-key canonical) surnames))
          (when-let* ((file (and (consp person) (plist-get person :file))))
            (puthash key file files))
          (push canonical names)
          (push canonical (gethash (sp-bibtex--bucket key) buckets)))))
    (dolist (person people)
      (when-let* ((file (and (consp person) (plist-get person :file))))
        (dolist (alias (sp-bibtex--note-aliases file))
          (let ((key (sp-bibtex--name-key (sp-bibtex-canonical-name alias))))
            (unless (gethash key keys)
              (puthash key (sp-bibtex-canonical-name (plist-get person :title)) keys))))))
    (list :names (sort names #'string<) :keys keys :files files :surnames surnames
          :buckets buckets
          :memo (make-hash-table :test #'equal))))

(defun sp-bibtex--bucket (key)
  "The bucket of the name KEY: the first letter of the last name and the first of the first name."
  (let ((parts (split-string key ", " t)))
    (format "%s|%s"
            (if parts (substring (car parts) 0 (min 1 (length (car parts)))) "")
            (if (cdr parts) (substring (cadr parts) 0 (min 1 (length (cadr parts)))) ""))))

(defun sp-bibtex-people (&optional refresh)
  "The index of the author notes, read again when REFRESH or older than the cache time."
  (interactive "P")
  (when (or refresh (null sp-bibtex--people-cache)
            (> (- (float-time) (car sp-bibtex--people-cache))
               sp-bibtex-people-cache-seconds))
    (require 'sp-author-notes-bibtex)
    (setq sp-bibtex--people-cache
          (cons (float-time)
                (sp-bibtex--make-people (sp-author-notes-bibtex--people)))))
  (cdr sp-bibtex--people-cache))

(defun sp-bibtex--fold (string)
  "STRING without accents, when `sp-author-notes-fold-diacritics' is loaded."
  (if (fboundp 'sp-author-notes-fold-diacritics)
      (sp-author-notes-fold-diacritics string)

(defun sp-bibtex--name-parts (canonical)
  "The last name and the given names of the CANONICAL name, as (LAST . GIVEN).
GIVEN is nil for a name without a comma."
  (let ((parts (mapcar #'string-trim (sp-bibtex--split-depth0 canonical ","))))
    (cons (car parts) (cadr parts))))

(defun sp-bibtex--surname-key (canonical)
  "A lookup key for the last name of the CANONICAL name: no accents, braces or case."
  (sp-bibtex--name-key (sp-bibtex--fold (car (sp-bibtex--name-parts canonical)))))

(defun sp-bibtex--given-units (given)
  "The given names GIVEN as a list of units (INITIAL . WORD).
INITIAL is an upper case letter.  WORD is the lower case name for a name
written out and nil for an initial: `TW' and `T. W.' give (\"T\") (\"W\"), and
`Theodor W.' gives (\"T\" . \"theodor\") (\"W\").  A hyphen starts a new unit."
  (let (units)
    (dolist (token (split-string (replace-regexp-in-string "[{}.]" " " (sp-bibtex--fold (or given "")))
                                 "[ \t]+" t))
      (dolist (part (split-string token "-" t))
        (cond
         ((string-match-p "\\`[[:upper:]]\\{1,3\\}\\'" part)
          (dolist (c (string-to-list part)) (push (list (char-to-string c)) units)))
         ((= (length part) 1) (push (list (upcase part)) units))
         (t (push (cons (upcase (substring part 0 1)) (downcase part)) units)))))
    (nreverse units)))

(defun sp-bibtex--initials-compatible-p (given note-given)
  "Non-nil when the given names GIVEN fit the NOTE-GIVEN names of an author note.
Each name, in order, has the initial of the other's name in that place, and two
names written out are the same.  One side may stop early or go on: `T', `TW',
`Theodor' and `Theodor W. X.' fit `Theodor W.'; `W', `Michael', `Theodor L.'
and `Theodore' do not."
  (let ((mine (sp-bibtex--given-units given))
        (theirs (sp-bibtex--given-units note-given)))
    (and mine theirs
         (cl-every (lambda (m n)
                     (and (equal (car m) (car n))
                          (or (null (cdr m)) (null (cdr n)) (equal (cdr m) (cdr n)))))
                   mine theirs))))

(defun sp-bibtex--surname-match (canonical people)
  "The author notes with the last name of CANONICAL and compatible given names.
Return nil when CANONICAL is a name of a note already, has no given names, or
no note matches; else the list of the matching note names (canonical).  When
several notes match, those that have as many given names as CANONICAL are
preferred: `TW Adorno' is `Theodor W. Adorno', not `Tamara Adorno'."
  (let ((parts (sp-bibtex--name-parts canonical)))
    (when (and (cdr parts)
               (not (gethash (sp-bibtex--name-key canonical) (plist-get people :keys))))
      (let* ((hits (seq-filter
                    (lambda (note)
                      (when-let* ((given (cdr (sp-bibtex--name-parts note))))
                        (sp-bibtex--initials-compatible-p (cdr parts) given)))
                    (gethash (sp-bibtex--surname-key canonical) (plist-get people :surnames))))
             (wanted (length (sp-bibtex--given-units (cdr parts))))
             (full (seq-filter (lambda (note)
                                 (>= (length (sp-bibtex--given-units (cdr (sp-bibtex--name-parts note))))
                                     wanted))
                               hits)))
        (if (and (cdr hits) full) full hits)))))

(defun sp-bibtex--suggestion (canonical people)
  "The author note a name CANONICAL is probably a typo of, or nil.
It is the note in the same bucket with a name at most two edits away.  A name
that has a note, or none close to it, gets nil."
  (let ((key (sp-bibtex--name-key canonical)))
    (unless (gethash key (plist-get people :keys))
      (let* ((memo (plist-get people :memo))
             (known (gethash key memo 'none)))
        (if (not (eq known 'none))
            known
          (puthash key
                   (seq-find (lambda (candidate)
                               (<= (string-distance key (sp-bibtex--name-key candidate)) 2))
                             (gethash (sp-bibtex--bucket key) (plist-get people :buckets)))
                   memo))))))
#+end_src

*** Name prefixes

An old Zotero export wrote names with a prefix as =biblatex= key=value text, for example =family=Hayek given=Friedrich given=Friedrich, given=Friedrich A., prefix=von useprefix=false=. This part reads such names and moves misplaced prefixes (particles such as =von=, =van=, =de=). It is its own fix, =prefixes=; nothing else calls it.

- What counts as a key=value name:
  - it has one or more of the keys =family=, =given=, =prefix=, =suffix= and =useprefix=
  - nothing but spaces comes before the first key
  - the whole name may be wrapped in braces
  - names are still split at =and=, so one field can hold several of them
- How the parts are read, by =sp-bibtex--keyvalue-parts=:
  - a value runs from its key to the next key
  - commas, spaces and braces around a value are dropped
  - empty values are dropped
- How the parts become one name, by =sp-bibtex--keyvalue-name=:
  - =family= is the last name, with =prefix= in front of it: =von Hayek=
  - =suffix= goes in the middle, as BibTeX wants: =Last, Jr., First=
  - =useprefix= is ignored; the prefix is always kept in the last name
  - the result is =Last, First=, the form of the rest of the lint: =von Hayek, Friedrich A.=
- Repeated =given= parts:
  - equal ones are merged: five times =Friedrich= is one
  - a shorter one that fits a longer one is dropped: =Friedrich= and =F.= fit =Friedrich A.=
  - fitting is the one of the author notes (=sp-bibtex--initials-compatible-p=)
  - the fullest one stays: most names, then most letters
  - given names that do not fit (=Friedrich= and =Hans=) are never guessed: the name is reported and left as it is
  - a name with no =family= or with two different ones is reported and left as it is
- Misplaced prefixes, by =sp-bibtex--move-particles=, in names that already have a comma:
  - =Hayek, Friedrich A. von= becomes =von Hayek, Friedrich A.=
  - =Hayek von, Friedrich= becomes =von Hayek, Friedrich=
  - =Hayek, Friedrich A., von= (the prefix as a part of its own) becomes =von Hayek, Friedrich A.=
  - several particles move together and keep their order: =de la=
  - a prefix that is already in front is not doubled
  - only lower case words of =sp-bibtex-name-particles= move, and one given name always stays, so =Li, Bin= is not touched
- Names with no comma and no key are left to the =authors= fix, which already moves the particles in front of the last name.

#+begin_src emacs-lisp -i
(defconst sp-bibtex--keyvalue-re
  "\\(?:\\`\\|[ \t,]\\)\\(family\\|given\\|prefix\\|suffix\\|useprefix\\)="
  "A key of the key=value name form (family=, given=, prefix=, suffix=, useprefix=).
Group 1 is the key; the match starts at the space or comma before it.")

(defun sp-bibtex--keyvalue-clean (value)
  "The text of a key=value VALUE: no spaces, commas or outer braces around it."
  (let ((clean (string-trim (replace-regexp-in-string "[ \t\n]+" " " value) "[ ,]+" "[ ,]+")))
    (when-let* ((unwrapped (sp-bibtex--unwrap clean))
                ((eq (cdr unwrapped) ?{)))
      (setq clean (string-trim (car unwrapped))))
    clean))

(defun sp-bibtex--keyvalue-parts (name)
  "The parts of NAME, when it is written as key=value text, as an alist (KEY . VALUE).
The alist is in the order of the text.  Return nil when NAME is not written so."
  (let* ((text (string-trim name))
         (text (if (string-match-p "\\`{[ \t]*\\(?:family\\|given\\|prefix\\|suffix\\|useprefix\\)=" text)
                   (or (car (sp-bibtex--unwrap text)) text)
                 text))
         (pos 0) hits parts)
    (while (string-match sp-bibtex--keyvalue-re text pos)
      (push (list (match-string 1 text) (match-beginning 0) (match-end 0)) hits)
      (setq pos (match-end 0)))
    (setq hits (nreverse hits))
    (when (and hits (string-empty-p (string-trim (substring text 0 (nth 1 (car hits))))))
      (while hits
        (let* ((hit (pop hits))
               (end (if hits (nth 1 (car hits)) (length text)))
               (value (sp-bibtex--keyvalue-clean (substring text (nth 2 hit) end))))
          (unless (string-empty-p value) (push (cons (car hit) value) parts))))
      (nreverse parts))))

(defun sp-bibtex--fullest-given (givens)
  "The fullest of the GIVENS, a list of given names; nil when two do not fit each other.
Equal ones count once.  `Friedrich' and `F.' fit `Friedrich A.', which is the
fullest: the most names, then the most letters."
  (let* ((all (delete-dups (copy-sequence givens)))
         (best (car all)))
    (dolist (given (cdr all))
      (let ((n (length (sp-bibtex--given-units given)))
            (m (length (sp-bibtex--given-units best))))
        (when (or (> n m) (and (= n m) (> (length given) (length best))))
          (setq best given))))
    (and best
         (seq-every-p (lambda (given) (sp-bibtex--initials-compatible-p given best)) all)
         best)))

(defun sp-bibtex--keyvalue-name (name)
  "NAME, written as key=value text, as a plist: (:name \"Last, First\") or (:error TEXT).
Return nil when NAME is not written as key=value text.  The prefix goes in front
of the family name and `useprefix' is ignored."
  (when-let* ((parts (sp-bibtex--keyvalue-parts name)))
    (let* ((values (lambda (key)
                     (delete-dups (mapcar #'cdr (seq-filter (lambda (p) (equal (car p) key)) parts)))))
           (families (funcall values "family"))
           (prefixes (funcall values "prefix"))
           (suffixes (funcall values "suffix"))
           (givens (funcall values "given"))
           (given (sp-bibtex--fullest-given givens)))
      (cond
       ((null families) (list :error "no family= part, left as it is"))
       ((cdr families) (list :error "several different family= parts, left as it is"))
       ((and givens (null given)) (list :error "given= parts that do not fit each other, left as it is"))
       (t
        (let* ((family (car families))
               (prefix (string-join prefixes " "))
               (last (if (or (string-empty-p prefix)
                             (string-prefix-p (concat prefix " ") family))
                         family
                       (concat prefix " " family))))
          (list :name (string-join (delq nil (list last (and suffixes (string-join suffixes " "))
                                                    given))
                                   ", "))))))))

(defun sp-bibtex--trailing-particles (words)
  "Split WORDS into (REST . PARTICLES): the particles at its end, one word always left in REST."
  (let ((rest (copy-sequence words)) particles)
    (while (and (cdr rest) (member (car (last rest)) sp-bibtex-name-particles))
      (push (car (last rest)) particles)
      (setq rest (butlast rest)))
    (cons rest particles)))

(defun sp-bibtex--move-particles (name)
  "NAME with the particles that stand after the last name moved in front of it.
Only a NAME with a comma is changed: `Hayek, Friedrich A. von', `Hayek von,
Friedrich' and `Hayek, Friedrich A., von' give `von Hayek, Friedrich A.'."
  (let* ((parts (mapcar #'string-trim (sp-bibtex--split-depth0 name ",")))
         (n (length parts)))
    (if (not (memq n '(2 3)))
        name
      (let* ((last-split (sp-bibtex--trailing-particles
                          (sp-bibtex--split-depth0 (car parts) "[ \t]+")))
             (tail (car (last parts)))
             (tail-words (sp-bibtex--split-depth0 tail "[ \t]+"))
             (alone (and (= n 3) (seq-every-p (lambda (w) (member w sp-bibtex-name-particles))
                                              tail-words)))
             (given-split (if alone
                              (cons nil tail-words)
                            (sp-bibtex--trailing-particles tail-words)))
             (moved (append (cdr given-split) (cdr last-split)))
             (rest-last (car last-split)))
        (if (null moved)
            name
          (let* ((front (if (equal (seq-take rest-last (length moved)) moved) nil moved))
                 (new-last (string-join (append front rest-last) " "))
                 (middle (and (= n 3) (list (nth 1 parts))))
                 (given (and (not alone) (list (string-join (car given-split) " ")))))
            (string-join (append (list new-last) middle given) ", ")))))))

(defun sp-bibtex--lint-prefixes (fields)
  "Check the prefixes of the author and editor names in FIELDS, an alist of name and raw value.
Return (NEW-FIELDS PROBLEMS UNRESOLVED): FIELDS with key=value names rewritten
and particles in front of the last name, the strings that say what changed, and
the strings for the names that could not be read and are left as they are."
  (let (new problems unresolved)
    (dolist (field fields)
      (let ((name (car field)) (value (cdr field)))
        (when (member (downcase name) '("author" "editor"))
          (when-let* ((unwrapped (sp-bibtex--unwrap value)))
            (let* ((text (string-trim (replace-regexp-in-string "[ \t\n]+" " " (car unwrapped))))
                   (fixed (mapconcat
                           (lambda (n)
                             (let ((kv (sp-bibtex--keyvalue-name n)))
                               (cond ((plist-get kv :name))
                                     ((plist-get kv :error)
                                      (push (format "%s: %s: %s" name n (plist-get kv :error))
                                            unresolved)
                                      n)
                                     (t (sp-bibtex--move-particles n)))))
                           (sp-bibtex-split-names text) " and ")))
              (unless (equal fixed text)
                (push (format "%s: %s → %s" name text fixed) problems)
                (setq value (format (if (eq (cdr unwrapped) ?\") "\"%s\"" "{%s}") fixed))))))
        (push (cons name value) new)))
    (list (nreverse new) (nreverse problems) (nreverse unresolved))))

*** Entries

An entry is read with =bibtex-parse-entry= (raw values, in file order). Linting it gives the fields with canonical names in the order of =sp-bibtex-field-order= and a list of what differs. An entry that is rewritten is written as =@type{key,= with the fields aligned at the equal sign; its values keep their delimiters and text. An entry with a =%= comment line inside would lose it, so it is reported and never rewritten. The reading runs in slices of 100 entries through =sp-async-work=, like =sp-author-notes-bibtex=.

#+begin_src emacs-lisp -i
(defun sp-bibtex--field-rank (name)
  "The rank of the field NAME in `sp-bibtex-field-order'; unlisted fields come last."
  (or (seq-position sp-bibtex-field-order (downcase name)) (length sp-bibtex-field-order)))

(defun sp-bibtex--case-problem (case)
  "The sentence for CASE, a list (FIELD NAME NOTE-NAME NOTE-FILE [KIND]).
KIND is `surname' for a name with the surname of a note, else a typo of one."
  (if (eq (nth 4 case) 'surname)
      (format "%s: %s → %s (same surname)" (nth 0 case) (nth 1 case) (nth 2 case))
    (format "%s: %s is not an author note; did you mean %s?"
            (nth 0 case) (nth 1 case) (nth 2 case))))

(defun sp-bibtex--lint-names (fields people)
  "Check the author and editor names in FIELDS, an alist of name and raw value.
Return (NEW-FIELDS PROBLEMS CASES AMBIGUOUS): FIELDS with canonical names, the
strings that say what changed, for each name one typo away from an author note
a list (FIELD NAME NOTE-NAME NOTE-FILE), and for each name with the surname of
one note and compatible initials the same list with `surname' added.  AMBIGUOUS
lists (FIELD NAME NOTE-NAMES) for names whose surname and initials fit several
notes."
  (let (problems cases ambiguous new)
    (dolist (field fields)
      (let ((name (car field)) (value (cdr field)))
        (when (member (downcase name) '("author" "editor"))
          (when-let* ((unwrapped (sp-bibtex--unwrap value))
                      (text (car unwrapped)))
            (let ((fixed (sp-bibtex-canonical-names text)))
              (unless (equal fixed (string-trim (replace-regexp-in-string "[ \t\n]+" " " text)))
                (push (format "%s: %s → %s" name
                              (replace-regexp-in-string "[ \t\n]+" " " text) fixed)
                      problems)
                (setq value (if (eq (cdr unwrapped) ?\")
                                (format "\"%s\"" fixed)
                              (format "{%s}" fixed))))
              (when people
                (dolist (n (sp-bibtex-split-names fixed))
                  (if-let* ((near (sp-bibtex--suggestion n people)))
                      (push (list name n near
                                  (gethash (sp-bibtex--name-key near) (plist-get people :files)))
                            cases)
                    (let ((same (sp-bibtex--surname-match n people)))
                      (cond
                       ((null same))
                       ((null (cdr same))
                        (push (list name n (car same)
                                    (gethash (sp-bibtex--name-key (car same)) (plist-get people :files))
                                    'surname)
                              cases))
                       (t (push (list name n same) ambiguous))))))))))
        (push (cons name value) new)))
    (list (nreverse new) (nreverse problems) (nreverse cases) (nreverse ambiguous))))

(defun sp-bibtex--sort-fields (fields)
  "FIELDS in the order of `sp-bibtex-field-order'."
  (sort (copy-sequence fields)
        (lambda (a b) (< (sp-bibtex--field-rank (car a)) (sp-bibtex--field-rank (car b))))))

(defun sp-bibtex--order-problem (fields sorted)
  "The sentence that says FIELDS are not in the order of SORTED, or nil."
  (unless (equal (mapcar #'car sorted) (mapcar #'car fields))
    (format "fields: %s → %s" (string-join (mapcar #'car fields) " ")
            (string-join (mapcar #'car sorted) " "))))

(defun sp-bibtex--lint-fields (fields people)
  "Lint the FIELDS, an alist of name and raw value.
Return (NEW-FIELDS . PROBLEMS): the fields with canonical names, in the
configured order, and a list of strings that say what differs."
  (let* ((names (sp-bibtex--lint-names fields people))
         (sorted (sp-bibtex--sort-fields (car names))))
    (cons sorted
          (append (nth 1 names)
                  (mapcar #'sp-bibtex--case-problem (seq-remove (lambda (c) (eq (nth 4 c) 'surname))
                                                                (nth 2 names)))
                  (when-let* ((problem (sp-bibtex--order-problem (car names) sorted)))
                    (list problem))))))

(defun sp-bibtex--entry-text (type key fields)
  "The text of the entry TYPE, KEY and FIELDS (an alist of name and raw value)."
  (let ((width (apply #'max 1 (mapcar (lambda (f) (length (car f))) fields))))
    (concat "@" type "{" key ",\n"
            (mapconcat (lambda (f)
                         (format "  %s%s = %s," (car f)
                                 (make-string (- width (length (car f))) ?\s) (cdr f)))
                       fields "\n")
            "\n}")))

(defvar sp-bibtex--fill-buffer nil
  "Scratch `bibtex-mode' buffer in which `sp-bibtex--fill-text' lays entries out.")

(defun sp-bibtex--fill-text (text)
  "The entry TEXT laid out the way `bibtex-fill-entry' does it.
That is the standard of `bibtex-mode': field names at `bibtex-field-indentation',
text at `bibtex-text-indentation'.  TEXT itself when it cannot be filled."
  (unless (buffer-live-p sp-bibtex--fill-buffer)
    (setq sp-bibtex--fill-buffer (generate-new-buffer " *sp-bibtex-fill*"))
    (with-current-buffer sp-bibtex--fill-buffer (delay-mode-hooks (bibtex-mode))))
  (with-current-buffer sp-bibtex--fill-buffer
    (erase-buffer)
    (insert text)
    (goto-char (point-min))
    (condition-case nil
        (progn (bibtex-fill-entry)
               (buffer-substring-no-properties (point-min) (point-max)))
      (error text))))

(defun sp-bibtex--entry-rewrites (kinds type key fields people old start end)
  "The rewrites of the entry TYPE, KEY and FIELDS that are of one of KINDS.
OLD is the text of the entry, between START and END.  KINDS are `order',
`indent', `authors' (names to `Last, First'), `prefixes' (key=value names and
misplaced particles), `notes' (names one typo away from
an author note), `surnames' (names with the surname of one author note and
compatible initials), `ambiguous' (the same for several notes; reported only)
and `files' (attachment paths, see `sp-bibtex-files--rewrite').  Return (REWRITES . PROBLEMS).  REWRITES is an alist from a kind to a
plist of :start, :end, :old, :desc and :new (the new text) or :cases (for
`notes'); PROBLEMS are the lines for the report."
  (let* ((names (sp-bibtex--lint-names fields people))
         (sorted (sp-bibtex--sort-fields fields))
         (order (sp-bibtex--order-problem fields sorted))
         (cases (seq-remove (lambda (c) (eq (nth 4 c) 'surname)) (nth 2 names)))
         (same (seq-filter (lambda (c) (eq (nth 4 c) 'surname)) (nth 2 names)))
         (near (mapcar #'sp-bibtex--case-problem cases))
         (form (nth 1 names))
         (prefix (and (memq 'prefixes kinds) (sp-bibtex--lint-prefixes fields)))
         (filled (and (memq 'indent kinds) (sp-bibtex--fill-text old)))
         (filed (and (memq 'files kinds) sp-bibtex-lint--library
                     (sp-bibtex-files--rewrite old key sp-bibtex-lint--library)))
         (base (list :start start :end end :old old))
         rewrites)
    (when (and filled (not (equal filled old)))
      (push (cons 'indent (append base (list :new filled :desc '("indentation differs from bibtex-mode"))))
            rewrites))
    (when (and order (memq 'order kinds))
      (push (cons 'order (append base (list :desc (list order)
                                            :new (sp-bibtex--fill-text
                                                  (sp-bibtex--entry-text type key sorted)))))
            rewrites))
    (when (and form (memq 'authors kinds))
      (push (cons 'authors (append base (list :desc form
                                              :new (sp-bibtex--fill-text
                                                    (sp-bibtex--entry-text type key (car names))))))
            rewrites))
    (when (nth 1 prefix)
      (push (cons 'prefixes (append base (list :desc (nth 1 prefix)
                                               :new (sp-bibtex--fill-text
                                                     (sp-bibtex--entry-text type key (car prefix))))))
            rewrites))
    (when (and cases (memq 'notes kinds))
      (push (cons 'notes (append base (list :desc near :cases cases))) rewrites))
    (when (and same (memq 'surnames kinds))
      (push (cons 'surnames (append base (list :desc (mapcar #'sp-bibtex--case-problem same)
                                               :cases same)))
            rewrites))
    (when-let* ((changes (mapcar #'cdr (seq-filter (lambda (n) (eq (car n) 'change)) (nth 1 filed))))
                ((not (equal (car filed) old))))
      (push (cons 'files (append base (list :new (car filed) :desc changes :moves (nth 2 filed))))
            rewrites))
    (when-let* (((memq 'keys kinds))
                (max (bound-and-true-p sp-bibtex-key-max-length))
                ((> (length key) max)))
      (push (cons 'keys (append base (list :key key
                                           :desc (list (format "key has %d characters, over the limit of %d"
                                                               (length key) max)))))
            rewrites))
    (when (and (nth 3 names) (memq 'ambiguous kinds))
      (push (cons 'ambiguous
                  (append base (list :desc (mapcar (lambda (a)
                                                     (format "%s: %s could be %s" (nth 0 a) (nth 1 a)
                                                             (string-join (nth 2 a) " or ")))
                                                   (nth 3 names)))))
            rewrites))
    (cons (nreverse rewrites)
          (append form (nth 1 prefix) (nth 2 prefix) near (and order (list order))
                  (mapcar #'cdr (seq-filter (lambda (n) (eq (car n) 'problem)) (nth 1 filed)))
                  (and filled (not (equal filled old))
                       (list "indentation differs from bibtex-mode"))))))

(defun sp-bibtex--lint-chunk (file limit people seen kinds)
  "Lint the entries from point in the current buffer, at most LIMIT of them.
Return (RESULTS . MORE).  RESULTS lists (FILE KEY POSITION PROBLEMS REWRITES);
MORE is non-nil when LIMIT was reached.  SEEN is a hash table of the keys met
so far.  REWRITES is what `sp-bibtex--entry-rewrites' returns for KINDS: an
alist, empty for an entry that is only reported.  The buffer is not changed."
  (let ((count 0) results)
    (while (and (< count limit)
                (re-search-forward "^[ \t]*@[[:alpha:]]+[ \t]*[{(]" nil t))
      (cl-incf count)
      (let ((beg (match-beginning 0))
            (header (match-string 0)))
        (goto-char beg)
        (let* ((entry (ignore-errors (bibtex-parse-entry)))
               (type (cdr (assoc "=type=" entry)))
               (key (cdr (assoc "=key=" entry)))
               (end (and entry (ignore-errors (bibtex-end-of-entry)))))
          (if (not (and entry key end (not (member (downcase type) '("string" "preamble" "comment")))))
              (progn
                (unless (string-match-p "@[ \t]*\\(string\\|preamble\\|comment\\)" (downcase header))
                  (push (list file (or key "?") beg
                              '("could not be read (a comment inside?), left as it is"))
                        results))
                (goto-char (min (point-max) (1+ beg))))
            (let* ((fields (seq-remove (lambda (f) (string-prefix-p "=" (car f))) entry))
                   (start (save-excursion (goto-char beg) (skip-chars-forward " \t") (point)))
                   (commented (save-excursion
                                (goto-char beg)
                                (re-search-forward "^[ \t]*%" end t)))
                   (analysis (sp-bibtex--entry-rewrites
                              (unless commented kinds) type key fields people
                              (buffer-substring-no-properties start end) start end))
                   (problems (cdr analysis)))
              (when-let* ((first (gethash key seen)))
                (push (format "duplicate key (also in %s)" (file-name-nondirectory first)) problems))
              (puthash key (or (gethash key seen) file) seen)
              (when commented
                (setq problems (append problems '("has a comment inside, left as it is"))))
              (when (or problems (car analysis))
                (push (list file key beg problems (car analysis)) results))
              (goto-char end))))))
    (cons (nreverse results) (>= count limit))))

*** Attachment paths

A further fix of the lint, separate from the others: =M-x sp-bibtex-lint-fix-files=. It has a button in the report and an entry in =M-x sp-bibtex-lint-convert=. It never touches names or field order.

- What it does to each entry:
  - turns the BibDesk =bdsk-file-N= fields (a base64 bookmark) into one =file = {...}= field; several files are joined with =;=
  - merges into an existing plain =file= field when there is one
  - makes paths like =~/Documents/literature/x.pdf= relative to =sp-literature-dir= (typos such as =Docuemnts= are accepted)
  - finds the file of a relative path elsewhere in the library, by name, when it is not at the path written
  - leaves Zotero-style =label:path:type= parts alone
- How a =bdsk-file-N= is resolved:
  - the bookmark holds the old relative path; only its file name is used
  - the name is looked up anywhere below =sp-literature-dir= (case and accents ignored) and must match exactly one file
  - otherwise the PDF whose name, without BibDesk's trailing digit, equals the citekey (letters and digits only) is used, if it is the only one
  - an entry that cannot be resolved keeps its =bdsk-file-N= fields and is listed as a problem in the report
- Where it shows:
  - the report has a section "Attachment paths" with each change, and the button runs the fix
  - the fix works like =sp-bibtex-lint-fix-order=: whole file, one question, a backup, nothing else changed in the entry
- =sp-bibtex-files-flatten= (default nil):
  - nil: the files stay where they are, and the path is written relative to the library (=inbox/mac-bibdesk/x.pdf=)
  - non-nil: the files are moved to the top of the library and the bare name is written; a file never overwrites another, and the moves are added to a =.tsv= next to the backups
  - off by default, because DEVONthink sees a file moved outside it as a new record
- =sp-bibtex-files-devonthink-tool= (default nil): with =sp-bibtex-files-flatten= on, the path of =tools/devonthink-move.py= ([[file:devonthink-move.org][doc]]); the files are then moved through DEVONthink, so the records keep their UUID, and a stop of the tool (the file did not move as asked) cancels the write of the =.bib= file

;;;; Attachment paths

(require 'ucs-normalize)
(defvar sp-literature-dir)

(defconst sp-bibtex-files--absolute-re
  "\\`\\(?:~\\|/Users/[^/]+\\)/Doc[[:alpha:]]*/\\.?literature/\\(.+\\)\\'"
  "An absolute path into the literature folder; accepts typos of `Documents'.")

(defconst sp-bibtex-files--bdsk-field-re
  "^\\([ \t]*\\)bdsk-file-\\([0-9]+\\)\\([ \t]*\\)=[ \t\n\r]*{\\([^}]*\\)}\\([ \t]*,?\\)"
  "A bdsk-file-N field: indent, N, space before =, base64 value, trailing comma.")

(defconst sp-bibtex-files--file-field-re
  "^\\([ \t]*\\)file\\([ \t]*\\)=\\([ \t]*\\){\\([^{}]*\\)}\\([ \t]*,?\\)"
  "A plain file field: indent, space, space, value, trailing comma.")

(defvar sp-bibtex-files--pending nil
  "The moves (FROM . TO) the entry being rewritten needs.")

(cl-defstruct (sp-bibtex-files--ctx (:constructor sp-bibtex-files--ctx-create))
  "The library to resolve in: its DIR, file NAMES, STEMS and the planned MOVES."
  dir names stems flatten
  (moves (make-hash-table :test #'equal))
  (dests (make-hash-table :test #'equal)))

(defun sp-bibtex-files--norm (string)
  "STRING in lower case with only letters and digits of a to z left."
  (replace-regexp-in-string "[^a-z0-9]" "" (downcase (ucs-normalize-NFC-string string))))

(defun sp-bibtex-files--stem-key (name)
  "Key of the file NAME: without extension and BibDesk's trailing digits."
  (sp-bibtex-files--norm
   (replace-regexp-in-string "[0-9]+\\'" "" (file-name-sans-extension name))))

(defun sp-bibtex-files-index (dir flatten)
  "Index the files below DIR (not the hidden ones) for `sp-bibtex-files-report'."
  (let ((ctx (sp-bibtex-files--ctx-create
              :dir dir :flatten flatten
              :names (make-hash-table :test #'equal)
              :stems (make-hash-table :test #'equal))))
    (dolist (file (directory-files-recursively
                   dir "" nil
                   (lambda (d) (not (string-prefix-p "." (file-name-nondirectory d))))))
      (let ((base (file-name-nondirectory file)))
        (unless (string-prefix-p "." base)
          (let ((rel (file-relative-name file dir)))
            (push rel (gethash (downcase (ucs-normalize-NFC-string base))
                               (sp-bibtex-files--ctx-names ctx)))
            (when (string-suffix-p ".pdf" (downcase base))
              (push rel (gethash (sp-bibtex-files--stem-key base)
                                 (sp-bibtex-files--ctx-stems ctx))))))))
    ctx))

(defun sp-bibtex-files--bdsk-path (value)
  "The relative path stored in VALUE, the base64 text of a bdsk-file field.
Nil when VALUE is not a BibDesk bookmark."
  (ignore-errors
    (let* ((text (replace-regexp-in-string "[^A-Za-z0-9+/=]" "" value))
           (raw (base64-decode-string
                 (concat text (make-string (mod (- (length text)) 4) ?=)) nil t))
           (pos (string-match "Xbookmark" raw)))
      (when (and pos (string-prefix-p "bplist00" raw))
        (let* ((p (+ pos 9))
               (marker (aref raw p))
               (kind (ash marker -4))
               (low (logand marker 15))
               (len low) (start (1+ p)))
          (when (= low 15)
            (pcase (aref raw (1+ p))
              (#x10 (setq len (aref raw (+ p 2)) start (+ p 3)))
              (#x11 (setq len (+ (ash (aref raw (+ p 2)) 8) (aref raw (+ p 3)))
                          start (+ p 4)))))
          (pcase kind
            (5 (decode-coding-string (substring raw start (+ start len)) 'utf-8))
            (6 (decode-coding-string (substring raw start (+ start (* 2 len))) 'utf-16be))))))))

(defun sp-bibtex-files--lookup (name ctx)
  "The library paths of the files called like the last part of NAME."
  (gethash (downcase (ucs-normalize-NFC-string (file-name-nondirectory name)))
           (sp-bibtex-files--ctx-names ctx)))

(defun sp-bibtex-files--target-1 (rel ctx)
  "The path for REL as `sp-bibtex-files--target' says, without recording the move."
  (let ((base (file-name-nondirectory rel))
        (dir (sp-bibtex-files--ctx-dir ctx))
        (moves (sp-bibtex-files--ctx-moves ctx))
        (dests (sp-bibtex-files--ctx-dests ctx)))
    (cond ((or (not (sp-bibtex-files--ctx-flatten ctx)) (not (string-match-p "/" rel))) rel)
          ((gethash rel moves))
          ((or (file-exists-p (expand-file-name base dir)) (gethash base dests)) rel)
          (t (puthash base t dests) (puthash rel base moves)))))

(defun sp-bibtex-files--target (rel ctx)
  "The path to write for the library path REL; with `flatten' it plans the move."
  (let ((target (sp-bibtex-files--target-1 rel ctx))
        (dir (sp-bibtex-files--ctx-dir ctx)))
    (unless (equal target rel)
      (push (cons (expand-file-name rel dir) (expand-file-name target dir))
            sp-bibtex-files--pending))
    target))

(defun sp-bibtex-files--resolve (value key ctx)
  "Resolve the bdsk-file VALUE of entry KEY; return (PATH . nil) or (nil . PROBLEM)."
  (if-let* ((old (sp-bibtex-files--bdsk-path value)))
      (let ((found (or (sp-bibtex-files--lookup old ctx)
                       (gethash (sp-bibtex-files--norm key) (sp-bibtex-files--ctx-stems ctx)))))
        (cond ((null found) (cons nil (format "not found: %s" old)))
              ((cdr found) (cons nil (format "ambiguous: %s" (string-join found ", "))))
              (t (cons (car found) nil))))
    (cons nil "not a BibDesk bookmark")))

(defun sp-bibtex-files--relativise (value ctx)
  "Make the absolute literature paths in the file field VALUE relative.
Return (NEW-VALUE NOTES)."
  (let (notes)
    (cons (mapconcat
           (lambda (part)
             (let ((trimmed (string-trim part)))
               (if (and (string-match sp-bibtex-files--absolute-re trimmed)
                        (not (string-search ":" (match-string 1 trimmed))))
                   (let* ((rel (match-string 1 trimmed))
                          (new (if (file-exists-p (expand-file-name rel (sp-bibtex-files--ctx-dir ctx)))
                                   rel
                                 (let ((found (sp-bibtex-files--lookup rel ctx)))
                                   (if (and found (null (cdr found)))
                                       (sp-bibtex-files--target (car found) ctx)
                                     (push (cons 'problem (format "file not found: %s" rel)) notes)
                                     rel)))))
                     (push (cons 'change (format "file: %s → %s" trimmed new)) notes)
                     new)
                 part)))
           (split-string value ";") ";")
          (list (nreverse notes)))))

(defun sp-bibtex-files--rewrite (text key ctx)
  "Rewrite the attachment fields of the entry TEXT (entry KEY).
Return (NEW-TEXT NOTES MOVES), NOTES a list of (KIND . MESSAGE) with KIND
`change' or `problem' and MOVES the files to move, (FROM . TO).  Entries with
unresolved bdsk-file fields keep them."
  (let ((new text) (notes nil) (fields nil) (start 0) (sp-bibtex-files--pending nil))
    (save-match-data
      (while (string-match sp-bibtex-files--bdsk-field-re text start)
        (push (list (match-beginning 0) (match-end 0) (match-string 1 text)
                    (match-string 2 text) (match-string 3 text) (match-string 4 text)
                    (match-string 5 text))
              fields)
        (setq start (match-end 0)))
      (setq fields (nreverse fields))
      (when fields
        (let* ((sorted (sort (copy-sequence fields)
                             (lambda (a b) (< (string-to-number (nth 3 a))
                                              (string-to-number (nth 3 b))))))
               (existing (string-match sp-bibtex-files--file-field-re text))
               paths problems)
          (dolist (f sorted)
            (let ((r (sp-bibtex-files--resolve (nth 5 f) key ctx)))
              (if (car r)
                  (push (car r) paths)
                (push (format "bdsk-file-%s: %s" (nth 3 f) (cdr r)) problems))))
          (setq paths (nreverse paths))
          (when (and (null problems) (cl-some (lambda (p) (string-match-p "[;{}]\\|\\`[ \t]\\|[ \t]\\'" (file-name-nondirectory p))) paths))
            (push "a file name has ; { } or edge spaces" problems))
          (when (and (null problems) (not existing)
                     (string-match-p "^[ \t]*file[ \t]*=" text))
            (push "existing file field is not a plain {...}" problems))
          (if problems
              (dolist (p (nreverse problems)) (push (cons 'problem p) notes))
            (let* ((targets (mapcar (lambda (p) (sp-bibtex-files--target p ctx)) paths))
                   (value (string-join targets ";"))
                   (last-field (car (last fields))))
              (dolist (f (reverse fields))
                (let ((st (nth 0 f)) (en (nth 1 f)))
                  (if (and (eq f last-field) (not existing))
                      (setq new (concat (substring new 0 st)
                                        (nth 2 f) "file"
                                        (make-string (max 1 (+ 6 (length (nth 3 f)) (length (nth 4 f)))) ?\s)
                                        "= {" value "}" (nth 6 f)
                                        (substring new en)))
                    (cond ((string-prefix-p "\r\n" (substring new en)) (setq en (+ en 2)))
                          ((string-prefix-p "\n" (substring new en)) (setq en (1+ en))))
                    (setq new (concat (substring new 0 st) (substring new en))))))
              (when existing
                (when (string-match sp-bibtex-files--file-field-re new)
                  (setq new (concat (substring new 0 (match-end 4)) ";" value
                                    (substring new (match-end 4))))))
              (push (cons 'change (format "%s → file = {%s}"
                                          (mapconcat (lambda (f) (concat "bdsk-file-" (nth 3 f))) sorted ", ")
                                          value))
                    notes)))))
      (when (string-match sp-bibtex-files--file-field-re new)
        (let* ((b (match-beginning 4)) (e (match-end 4))
               (r (sp-bibtex-files--relativise (match-string 4 new) ctx)))
          (setq new (concat (substring new 0 b) (car r) (substring new e)))
          (setq notes (append (reverse (cadr r)) notes)))))
    (list new (nreverse notes) (reverse sp-bibtex-files--pending))))

*** Report and apply

The lint works on one =.bib= file at a time, and it is read-only. The fixes are five separate commands, each with a button in the report.

- Which file:
  - the file of the current buffer, when it is a =.bib= file
  - otherwise, or with a prefix argument, one read with completion from =sp-bibtex-files=
- =M-x sp-bibtex-lint-dryrun= (=C-c w b l=):
  - lists the entries to fix in the shared report buffer (=sp-batch-report=)
  - each entry is a link to its line: =RET= visits it, =n= and =p= move, =g= refreshes
  - the top of the report has one button for each fix, with the number of entries it would change
  - never changes a file
- The buttons are links of a =sp-bibtex-lint:KIND:FILE= type, so =RET= on one runs the fix; no confirmation question comes before the batches.
- The fixes (attachment paths has its own section):
  - =M-x sp-bibtex-lint-fix-order=:
    - whole file at once
    - puts the fields in the order of =sp-bibtex-field-order=
    - changes nothing else in the entry's values
  - =M-x sp-bibtex-lint-fix-indent=:
    - whole file at once
    - lays out every entry the way =bibtex-mode= does it (=bibtex-fill-entry=)
    - so field names sit at =bibtex-field-indentation= and text at =bibtex-text-indentation=, with the settings of the running Emacs
    - changes only whitespace
  - =M-x sp-bibtex-lint-fix-prefixes=, see [[*Name prefixes]]:
    - key=value names from an old Zotero export (=family=Hayek given=Friedrich ..., prefix=von useprefix=false=) become =von Hayek, Friedrich A.=
    - prefixes after the last name (=Hayek, Friedrich A. von=) move in front of it
    - names it cannot read are listed in the report with the reason and left as they are
    - goes in batches, with =a=, =g=, =s=, =d=, =u= and =q=, like the author names
    - the report has a button for it, and =M-x sp-bibtex-lint-dryrun= lists the entries
  - =M-x sp-bibtex-lint-fix-authors=, in four steps, one after the other:
    - step 0: the name prefixes fix above runs first, with its own batches, so key=value names and misplaced prefixes are fixed before the names are checked
    - step 1: names that are not =Last, First= are rewritten
    - step 2: names one typo away from an author note
    - step 3: names with the surname of an author note, see below
    - for each batch of step 2 and 3 you choose =n=, =l=, =e=, =s= or =q=
      - =n= normalises the name in the BibTeX field to the name of the note
      - =l= adds the name, as =Last, First=, as an alias of the note (a vulpea alias, in =ROAM_ALIASES=), and the =.bib= file is not changed
      - =e= asks =n=, =l=, =s= or =q= for each name, and =q= there drops the batch
      - the aliases of the notes count as known names, so an alias is not suggested again
- Names with the surname of an author note (step 3):
  - a kind of match of its own, so it does not bury the typos: the report lists them in a section of their own, with their own count, and the main list holds only the other problems
  - the name must not be a name of a note already, nor a typo of one (the typo wins)
  - the surname must be the same (accents, case and dots ignored)
  - the given names must fit those of the note, name by name:
    - an initial fits a name that starts with it, so =TW=, =T. W.= and =Theodor= fit =Theodor W.=
    - two names written out must be the same
    - extra names on either side are ignored: =Theodor W. X.= fits =Theodor W.=
    - a different name or initial does not fit: =Michael Smith= is not =John Smith=, and =W Adorno= or =Theodor L. Adorno= are not =Theodor W. Adorno=
  - several notes with that surname and compatible names:
    - those with as many given names as the BibTeX name are preferred, so =TW Adorno= is =Theodor W. Adorno=, not =Tamara Adorno=
    - if more than one is left (=T Adorno=), the name is ambiguous
    - an ambiguous name is listed in its own section of the report (with the candidates) and is never changed or aliased
- =M-x sp-bibtex-lint-fix-files= is a further fix, described under "Attachment paths" above; =M-x sp-bibtex-lint-convert= (=C-c w b L=) asks which of the five to run.
- Dropping entries for later (author fixes only), the mechanism of the other lint reports (=sp-batch-report=):
  - in the report: =d= drops the entry at point, =u= on a dropped one brings it back, =A= runs the author fixes with what is left
  - the dropped entries move to a section "Dropped from the list" at the end of the report, with their count
  - in an author batch question: =d= asks (comma separated, with completion) which entries of the batch to drop, =u= which dropped ones to bring back; the batch is shown again each time
  - a dropped entry is left out of all three author steps and of the name prefixes fix, in this run and in later ones
  - a brought-back entry is part of the next run, not of the batch on screen
  - =M-x sp-bibtex-lint-restore-dropped= brings entries back without the report
  - where it lives: the list =sp-bibtex-lint--excluded= holds the keys =FILE::ENTRY-KEY=
    - it lasts for the Emacs session, like the dropped entries of the other lint reports, and is not saved to disk
    - the =.bib= file and the notes are never changed by a drop
  - field order and indentation ignore drops: they are fixed for every entry
  - the report's counts for those two buttons include the dropped entries; the author count and the lists do not
- Field order and indentation are applied to the whole file at once:
  - one yes-or-no question gives the number of entries, then everything is fixed
  - no batches and no apply/skip per batch
  - the file is copied to =sp-bibtex-lint-backup-directory= before it is written
- Name prefixes and author names go in batches:
  - batch size is =sp-bibtex-lint-batch-size= (default 50)
  - in the name prefixes and in step 1 of the author names: =a= applies a batch, =g= applies it and every later batch without asking again, =s= skips it, =d= and =u= drop and bring back entries, =q= quits; the next batch is shown only after the answer
  - a dropped entry stays out of a global run
  - in steps 2 and 3 the choices are the ones above
  - the file is copied before the first write, then written again after each applied batch
- For all of them:
  - nothing is written without an answer
  - if the file changed on disk since the lint, nothing more is written and you are asked to run the command again
  - an entry whose text is no longer the one that was linted is left alone and counted
  - the open buffer of the file must be saved first, and is reverted after a write
- Duplicate keys and entries with a comment inside are reported only; a rewritten entry is laid out like =bibtex-fill-entry= does it.

(defun sp-bibtex-lint--files ()
  "The .bib files to lint; a `user-error' says what is wrong when there are none."
  (let ((files (seq-filter #'file-readable-p
                           (if (boundp 'sp-bibtex-files) sp-bibtex-files nil))))
    (or files
        (user-error "No readable BibTeX files in `sp-bibtex-files'; run `sp-bibtex-register'"))))

(defun sp-bibtex-lint--read-file (&optional ask)
  "The one .bib file to lint.
It is the file of the current buffer when that is a .bib file, unless ASK is
non-nil; otherwise it is read with completion over `sp-bibtex-files', with the
current .bib file as the default."
  (let* ((current (and buffer-file-name
                       (string-match-p "\\.bib\\'" buffer-file-name)
                       buffer-file-name))
         (file (if (and current (not ask))
                   current
                 (completing-read "BibTeX file: " (sp-bibtex-lint--files)
                                  nil nil nil nil current))))
    (setq file (expand-file-name file))
    (unless (file-readable-p file)
      (user-error "Cannot read %s" file))
    file))

(defun sp-bibtex-lint--job (name files kinds done)
  "Run the lint job NAME over FILES for the fixes KINDS, without changing them.
DONE gets the list of (FILE KEY POSITION PROBLEMS REWRITES)."
  (let ((people (condition-case nil (sp-bibtex-people) (error nil)))
        (seen (make-hash-table :test #'equal))
        all)
    (setq sp-bibtex-lint--library
          (and (memq 'files kinds) (sp-bibtex-files--library)))
    (sp-async-work-run
     name
     (list (list "reading BibTeX" (lambda () files)
                 (lambda (item job)
                   (let* ((file (if (consp item) (car item) item))
                          (buffer (if (consp item)
                                      (cdr item)
                                    (let ((b (generate-new-buffer " *sp-bibtex-lint*")))
                                      (sp-async-work-on-cleanup job (lambda () (when (buffer-live-p b) (kill-buffer b))))
                                      (with-current-buffer b
                                        (insert-file-contents file)
                                        (delay-mode-hooks (bibtex-mode))
                                        (goto-char (point-min)))
                                      b))))
                     (with-current-buffer buffer
                       (let ((result (sp-bibtex--lint-chunk file 100 people seen kinds)))
                         (setq all (append all (car result)))
                         (if (cdr result)
                             (sp-async-work-push job (cons file buffer))
                           (kill-buffer buffer))))))))
     :done (lambda (_job)
             (setq sp-bibtex-lint--library nil)
             (funcall done all)))))

(defun sp-bibtex-lint--backup (file stamp)
  "Copy FILE to the STAMP sub-folder of `sp-bibtex-lint-backup-directory'."
  (let ((dir (expand-file-name (concat stamp "/") sp-bibtex-lint-backup-directory)))
    (make-directory dir t)
    (copy-file file (expand-file-name (file-name-nondirectory file) dir) t)))

(defun sp-bibtex-lint--entry-text (result link &optional lines)
  "The Org text for the lint RESULT: a heading and its problems, or LINES.
LINK is the Org link to the entry, or nil."
  (concat "* " (or link (nth 1 result)) "\n"
          (mapconcat (lambda (p) (concat "- " p "\n")) (or lines (nth 3 result)) "")))

(defun sp-bibtex-lint--lines (file positions)
  "The line numbers of the buffer POSITIONS of FILE, in the order of POSITIONS.
Each position is the start of a line."
  (with-temp-buffer
    (insert-file-contents file)
    (let ((last 1) (line 1) (table (make-hash-table :test #'eql)))
      (dolist (pos (sort (delete-dups (copy-sequence positions)) #'<))
        (setq pos (min pos (point-max)))
        (setq line (+ line (count-lines last pos)) last pos)
        (puthash pos line table))
      (mapcar (lambda (pos) (or (gethash (min pos (point-max)) table) 1)) positions))))

(defun sp-bibtex-lint--section (title kind results pairs file)
  "The Org section TITLE with the RESULTS that have a rewrite of KIND.
PAIRS says the line of each result in FILE.  Nothing when there are none."
  (when-let* ((mine (seq-filter (lambda (r) (alist-get kind (nth 4 r))) results)))
    (concat
     (format "\n* %s (%d)\n" title
             (apply #'+ (mapcar (lambda (r) (length (plist-get (alist-get kind (nth 4 r)) :desc)))
                                mine)))
     (mapconcat
      (lambda (r)
        (propertize
         (concat "** " (sp-batch-report-file-link file (nth 1 r) (alist-get r pairs nil nil #'eq)) "\n"
                 (mapconcat (lambda (d) (concat "- " d "\n"))
                            (plist-get (alist-get kind (nth 4 r)) :desc) ""))
         'sp-batch-report-key (sp-bibtex-lint--entry-key file (nth 1 r))
         'sp-batch-report-file file))
      mine ""))))

(defun sp-bibtex-lint--render (file results)
  "Show RESULTS, a list of (FILE KEY POSITION PROBLEMS REWRITES) of FILE, as a report.
Names with the surname of an author note have sections of their own, so they do
not bury the typos.  `d' drops an entry from the author fixes and `u' brings it
back; the dropped ones are listed at the end."
  (let* ((pairs (cl-mapcar #'cons results
                           (sp-bibtex-lint--lines file (mapcar (lambda (r) (nth 2 r)) results))))
         (shown (seq-remove (lambda (r) (sp-bibtex-lint--dropped-p file r)) results))
         (dropped (sp-bibtex-lint--dropped-keys file))
         (main (seq-filter (lambda (r) (nth 3 r)) shown)))
    (sp-batch-report-open
     sp-bibtex-lint--buffer
     (concat
      (format "#+title: BibTeX lint of %s\n\n" (file-name-nondirectory file))
      (format "- %d entr%s with problems in %s.\n"
              (length main) (if (= 1 (length main)) "y" "ies")
              (sp-batch-report-file-link file))
      (format "- %d entr%s with a name that has the surname of an author note (own section below); %d with a name that fits several.\n"
              (sp-bibtex-lint--count shown 'surnames)
              (if (= 1 (sp-bibtex-lint--count shown 'surnames)) "y" "ies")
              (sp-bibtex-lint--count shown 'ambiguous))
      "- =d= drops an entry from the author fixes for later, =u= brings it back, =A= runs the author fixes.\n"
      (format "- Fix, in batches of %d (a button runs the fix; the file is copied first):\n"
              sp-bibtex-lint-batch-size)
      (format "  - %s\n" (sp-bibtex-lint--button "order" file "field order"
                                                 (sp-bibtex-lint--count results 'order)))
      (format "  - %s\n" (sp-bibtex-lint--button "indent" file "indentation, as in bibtex-mode"
                                                 (sp-bibtex-lint--count results 'indent)))
      (format "  - %s\n" (sp-bibtex-lint--button "prefixes" file "name prefixes (key=value, misplaced)"
                                                 (sp-bibtex-lint--count shown 'prefixes)))
      (format "  - %s\n" (sp-bibtex-lint--button "files" file "attachment paths"
                                                 (sp-bibtex-lint--count results 'files)))
      (format "  - %s\n" (sp-bibtex-lint--button "keys" file "long citation keys"
                                                 (sp-bibtex-lint--count results 'keys)))
      (format "  - %s\n" (sp-bibtex-lint--button
                          "authors" file "author names"
                          (length (seq-filter (lambda (r) (seq-some (lambda (k) (alist-get k (nth 4 r)))
                                                                    '(authors notes surnames)))
                                              shown))))
      (mapconcat (lambda (r)
                   (propertize
                    (concat "\n" (sp-bibtex-lint--entry-text
                                  r (sp-batch-report-file-link file (nth 1 r) (alist-get r pairs nil nil #'eq))))
                    'sp-batch-report-key (sp-bibtex-lint--entry-key file (nth 1 r))
                    'sp-batch-report-file file))
                 main "")
      (sp-bibtex-lint--section "Attachment paths" 'files shown pairs file)
      (sp-bibtex-lint--section "Long citation keys" 'keys shown pairs file)
      (sp-bibtex-lint--section "Same surname as an author note" 'surnames shown pairs file)
      (sp-bibtex-lint--section "Same surname, several author notes" 'ambiguous shown pairs file)
      (and dropped
           (concat "\n" (sp-batch-report-dropped-section dropped nil #'sp-bibtex-lint--key-label))))
     :refresh (lambda (excluded)
                (setq sp-bibtex-lint--excluded excluded)
                (sp-bibtex-lint-dryrun file))
     :excluded sp-bibtex-lint--excluded
     :apply (lambda (excluded)
              (setq sp-bibtex-lint--excluded excluded)

(defun sp-bibtex-lint--replace (beg end new)
  "Replace the text between the markers BEG and END with NEW; END ends after it."
  (goto-char beg)
  (delete-region beg end)
  (insert new)
  (set-marker end (point)))

(defun sp-bibtex-lint--apply-batch (work batch kind)
  "Rewrite the entries of BATCH in the buffer WORK, for the fix KIND.
BATCH is a list of (RESULT BEG END) with markers.  An entry whose text is no
longer the one that was linted is left alone.  Return (CHANGED STALE WROTE)."
  (let ((changed 0) (stale 0) moves)
    (with-current-buffer work
      (dolist (item batch)
        (pcase-let* ((`(,r ,beg ,end) item)
                     (rewrite (alist-get kind (nth 4 r))))
          (if (not (equal (plist-get rewrite :old) (buffer-substring-no-properties beg end)))
              (cl-incf stale)
            (sp-bibtex-lint--replace beg end (plist-get rewrite :new))
            (setq moves (append moves (plist-get rewrite :moves)))
            (cl-incf changed)))))
    ;; The files move once for the batch, before the .bib file is written.
    (when moves (sp-bibtex-files--move moves))
    (list changed stale t)))

(defun sp-bibtex-lint--signature (file)
  "The modification time and size of FILE, to notice that it changed."
  (let ((attributes (file-attributes file)))
    (list (file-attribute-modification-time attributes) (file-attribute-size attributes))))

(defun sp-bibtex-lint--save (work file)
  "Write the buffer WORK to FILE and bring the buffer that visits FILE up to date."
  (with-current-buffer work
    (write-region (point-min) (point-max) file nil 'silent))
  (when-let* ((visiting (find-buffer-visiting file)))
    (unless (buffer-modified-p visiting)
      (with-current-buffer visiting (revert-buffer t t t)))))

(defun sp-bibtex-lint--run (file kind results ask apply-fn &optional then whole)
  "Go through the entries of RESULTS with a fix of KIND for FILE, in batches.
Batches have `sp-bibtex-lint-batch-size' entries, or with WHOLE all the entries
are one batch.  ASK is called with (BATCH
INDEX TOTAL ALL) and returns `skip', `quit', `apply-all' (an answer for this and
every later batch, which are then not asked) or an answer for APPLY-FN, which is
called with (WORK BATCH ANSWER) and returns (CHANGED STALE WROTE).  When WROTE,
FILE is copied to `sp-bibtex-lint-backup-directory' (once) and written; nothing
is written without an answer.  THEN is called when the run was not quit."
  (let* ((authorial (memq kind '(authors prefixes notes surnames)))
         (fixable (seq-filter (lambda (r) (and (alist-get kind (nth 4 r))
                                               (not (and authorial (sp-bibtex-lint--dropped-p file r)))))
                              results))
         (what (alist-get kind sp-bibtex-lint--kinds))
         (work (generate-new-buffer " *sp-bibtex-lint-work*"))
         (stop nil) (global nil))
    (if (null fixable)
        (message "BibTeX lint: no %s to fix in %s" what (file-name-nondirectory file))
      (unwind-protect
          (let* ((items (with-current-buffer work
                          (insert-file-contents file)
                          (delay-mode-hooks (bibtex-mode))
                          (mapcar (lambda (r)
                                    (let ((rewrite (alist-get kind (nth 4 r))))
                                      (list r (copy-marker (plist-get rewrite :start))
                                            (copy-marker (plist-get rewrite :end)))))
                                  fixable)))
                 (batches (seq-partition items (max 1 (if whole (length items) sp-bibtex-lint-batch-size))))
                 (total (length batches))
                 (stamp (format-time-string "%Y%m%dT%H%M%S"))
                 (signature (sp-bibtex-lint--signature file))
                 (index 0) (changed 0) (skipped 0) (stale 0) (backed-up nil))
            (while (and batches (not stop))
              (let* ((batch (pop batches))
                     (answer (progn
                               (cl-incf index)
                               (if global
                                   'apply
                                 (funcall ask batch index total (length items))))))
                (when (eq answer 'apply-all) (setq global t answer 'apply))
                ;; Entries dropped while the batch was asked are not touched.
                (when authorial (setq batch (sp-bibtex-lint--undropped file batch)))
                (pcase (if (and authorial (null batch)) 'skip answer)
                  ('quit (setq stop t) (cl-incf skipped (length batch)))
                  ('skip (cl-incf skipped (length batch)))
                  (_
                   (when-let* ((visiting (find-buffer-visiting file))
                               ((buffer-modified-p visiting)))
                     (user-error "Save %s first" (file-name-nondirectory file)))
                   (let ((done (funcall apply-fn work batch answer)))
                     (cl-incf changed (nth 0 done))
                     (cl-incf stale (nth 1 done))
                     (when (nth 2 done)
                       (unless (equal signature (sp-bibtex-lint--signature file))
                         (user-error "%s changed on disk since it was linted; run the command again"
                                     (file-name-nondirectory file)))
                       (unless backed-up
                         (sp-bibtex-lint--backup file stamp)
                         (setq backed-up t))
                       (sp-bibtex-lint--save work file)
                       (setq signature (sp-bibtex-lint--signature file))))))))
            (message "BibTeX %s of %s: %d done, %d skipped, %d not reached%s%s"
                     what (file-name-nondirectory file) changed skipped
                     (apply #'+ (mapcar #'length batches))
                     (if (> stale 0) (format ", %d changed since the lint" stale) "")
                     (if backed-up
                         (format "; backup in %s" (abbreviate-file-name sp-bibtex-lint-backup-directory))
                       "")))
        (kill-buffer work)))
    (when (and then (not stop)) (funcall then))))

(defun sp-bibtex-lint--review (file kind results &optional then)
  "Go through the rewrites of KIND in RESULTS for FILE, a batch at a time.
Each batch is applied, skipped or quit; see `sp-bibtex-lint--run'."
  (sp-bibtex-lint--run
   file kind results
   (lambda (batch index total all)
     (pcase (sp-bibtex-lint--ask-batch file batch index total all kind)
       (?a 'apply) (?g 'apply-all) (?s 'skip) (_ 'quit)))
   (lambda (work batch _answer) (sp-bibtex-lint--apply-batch work batch kind))
   then))

(defun sp-bibtex--rename-names (fields cases)
  "FIELDS with the names of CASES replaced by the names of the author notes.
CASES are lists (FIELD NAME NOTE-NAME ...); the other names stay as written."
  (mapcar
   (lambda (field)
     (let ((mine (seq-filter (lambda (c) (string-equal-ignore-case (car c) (car field))) cases)))
       (if-let* (((consp mine))
                 (unwrapped (sp-bibtex--unwrap (cdr field))))
           (let ((names (mapcar
                         (lambda (n)
                           (if-let* ((hit (seq-find (lambda (m) (equal (nth 1 m) (sp-bibtex-canonical-name n)))
                                                    mine)))
                               (nth 2 hit)
                             n))
                         (sp-bibtex-split-names (car unwrapped)))))
             (cons (car field)
                   (format (if (eq (cdr unwrapped) ?\") "\"%s\"" "{%s}")
                           (string-join names " and "))))
         field)))
   fields))

(defun sp-bibtex-lint--add-alias (file alias)
  "Add ALIAS to the aliases of the note FILE, with vulpea, and save the note."

  (unless (fboundp 'vulpea-buffer-alias-add)
    (user-error "vulpea is not loaded; cannot add the alias %s" alias))

    (with-current-buffer (find-file-noselect file)
      (when (buffer-modified-p)
        (user-error "Save %s first" (file-name-nondirectory file)))
      (vulpea-buffer-alias-add alias)
      (save-buffer))))

Return ?n to normalise the names in the BibTeX field, ?l to add each as an alias

(defun sp-bibtex-lint--ask-case (case)
  "Ask what to do with CASE, a list (FIELD NAME NOTE-NAME NOTE-FILE).
Return ?n to normalise, ?l for an alias, ?s to skip or ?q to stop."
  (read-char-choice
   (format "%s is not an author note.  [n]ormalise to %s%s, [s]kip, [q]uit "
           (nth 1 case) (nth 2 case)
           (if (nth 3 case) ", [l] add as alias of the note" ""))
   (if (nth 3 case) '(?n ?l ?s ?q) '(?n ?s ?q))))

(defun sp-bibtex-lint--decide-notes (batch choice &optional kind)
  "The decisions for BATCH of the fix KIND (default `notes') from CHOICE, or `quit'.
A decision is a list (ITEM CASE DECISION), DECISION `normalise' or `alias'.
With ?e each case is asked."
  (catch 'quit
    (let (decisions)
      (dolist (item batch)
        (dolist (case (plist-get (alist-get (or kind 'notes) (nth 4 (car item))) :cases))
          (let ((decision (pcase choice
                            (?n 'normalise)
                            (?l (and (nth 3 case) 'alias))
                            (_ (pcase (sp-bibtex-lint--ask-case case)
                                 (?n 'normalise)
                                 (?l 'alias)
                                 (?q (throw 'quit 'quit))
                                 (_ nil))))))
            (when decision (push (list item case decision) decisions)))))
      (nreverse decisions))))

(defun sp-bibtex-lint--apply-notes (work batch decisions &optional kind)
  "Carry out DECISIONS for BATCH of the fix KIND: rewrite entries in WORK, add aliases.
Return (CHANGED STALE WROTE)."
  (let ((changed 0) (stale 0) (wrote nil) aliases)
    (dolist (d decisions)
      (when (eq (nth 2 d) 'alias)
        (push (cons (nth 3 (nth 1 d)) (nth 1 (nth 1 d))) aliases)))
    (dolist (item batch)
      (when-let* ((cases (mapcar #'cadr (seq-filter (lambda (d) (and (eq (car d) item)
                                                                      (eq (nth 2 d) 'normalise)))
                                                    decisions))))
        (pcase-let ((`(,r ,beg ,end) item))
          (with-current-buffer work
            (if (not (equal (plist-get (alist-get (or kind 'notes) (nth 4 r)) :old)
                            (buffer-substring-no-properties beg end)))
                (cl-incf stale)
              (goto-char beg)
              (let* ((entry (bibtex-parse-entry))
                     (fields (seq-remove (lambda (f) (string-prefix-p "=" (car f))) entry)))
                (sp-bibtex-lint--replace
                 beg end
                 (sp-bibtex--fill-text
                  (sp-bibtex--entry-text (cdr (assoc "=type=" entry)) (cdr (assoc "=key=" entry))
                                         (sp-bibtex--rename-names fields cases)))))
              (cl-incf changed (length cases))
              (setq wrote t))))))
    (dolist (alias (delete-dups aliases))
      (sp-bibtex-lint--add-alias (car alias) (cdr alias))
      (cl-incf changed))
    (when aliases (setq sp-bibtex--people-cache nil))
    (list changed stale wrote)))

*** Long citation keys

The lint kind =keys= and its fix =sp-bibtex-lint-fix-keys= (~C-c w b k~, or the =keys= button of the report, or =sp-bibtex-lint-convert=).

- the entries whose key is over =sp-bibtex-key-max-length= get a rewrite of the kind =keys=; the dry run lists them in a section of their own.
- the fix goes in batches of =sp-bibtex-lint-batch-size=, as the other fixes do, with a backup of the =.bib= file before the first write:
  - the batch is shown, and you answer =p= (prompt for each key), =s= (skip) or =q= (quit);
  - each key is asked for with =sp-bibtex--read-short-key=;
  - the plan is shown in =*BibTeX key renames*=: the old and new keys, how many notes, =#+reference:= values and citations, PDFs and cross references would change;
  - you answer =y= (rename and update everything listed), =b= (only the =.bib= file), =s= or =q=.
- what is updated follows =sp-bibtex-key-update-targets=: =notes=, =files= (the PDFs and the =file= field) and =bibrefs=.
- the order of the changes, so that a failure leaves things as they were:
  - the PDFs move first (an error stops everything);
  - then the notes and the other =.bib= files;
  - then the entries in the buffer, written by the lint as for the other fixes;
  - then =citar-refresh=.
- an entry that is not the text that was linted (changed meanwhile) is left alone and counted.
- the new keys are checked against the keys of all the registered files and the ones chosen in the same run.

;;;; Long citation keys, the fix
(defvar sp-bibtex-lint--key-table nil
  "The keys taken, while `sp-bibtex-lint-fix-keys' asks for new ones.")

(defun sp-bibtex-lint--ask-keys (file batch index total all)
  "Show BATCH of long keys of FILE, ask for a shorter key for each, and confirm.
Return `skip', `quit' or a plist for `sp-bibtex-lint--apply-keys': :file,
:decisions, a list of (ITEM NEW), and :plan, what `sp-bibtex-keys-plan' says.
After the keys, the notes, citations, cross references and PDFs that use them
are counted and you choose to update them too, only the .bib file, or to skip
the batch."
  (sp-bibtex-lint--show-batch file 'keys batch index total all)
  (pcase (read-char-choice
          (format "Batch %d of %d (%d long keys): [p]rompt for a shorter key for each, [s]kip, [q]uit "
                  index total (length batch))
          '(?p ?s ?q))
    (?s 'skip)
    (?q 'quit)
    (_
     (let (decisions renames)
       (dolist (item batch)
         (let* ((rewrite (alist-get 'keys (nth 4 (car item))))
                (old (plist-get rewrite :key))
                (text (plist-get rewrite :old))
                (new (sp-bibtex--read-short-key
                      old
                      (sp-bibtex--suggest-key text sp-bibtex-key-max-length sp-bibtex-lint--key-table)
                      (sp-bibtex--text-title text)
                      sp-bibtex-key-max-length sp-bibtex-lint--key-table)))
           (when new
             (puthash new t sp-bibtex-lint--key-table)
             (push (list item new) decisions)
             (push (cons old new) renames))))
       (setq decisions (nreverse decisions)
             renames (nreverse renames))
       (if (null decisions)
           'skip
         (let ((plan (sp-bibtex-keys-plan renames file sp-bibtex-key-update-targets)))
           (sp-bibtex-keys--show-plan file plan)
           (pcase (read-char-choice
                   (format "%d new keys: [y] rename them and update the notes, citations, cross references and PDFs listed, [b] only in the .bib file, [s]kip, [q]uit "
                           (length decisions))
                   '(?y ?b ?s ?q))
             (?s 'skip)
             (?q 'quit)
             (?y (list :file file :decisions decisions :plan plan))
             (?b (list :file file :decisions decisions
                       :plan (sp-bibtex-keys-plan renames file nil))))))))))

(defun sp-bibtex-lint--apply-keys (work batch answer)
  "Rename the keys of ANSWER, the plist `sp-bibtex-lint--ask-keys' made, in BATCH.
WORK is the buffer with the .bib file.  The PDFs move first, so a failed move
changes nothing; then the notes and the other .bib files are updated, then
the entries in WORK.  An entry that is not the one that was linted is left alone.
Return (CHANGED STALE WROTE)."
  (ignore batch)
  (let ((plan (plist-get answer :plan))
        (stamp (format-time-string "%Y%m%dT%H%M%S"))
        (stale 0)
        valid)
    (with-current-buffer work
      (dolist (decision (plist-get answer :decisions))
        (pcase-let* ((`(,item ,new) decision)
                     (`(,r ,beg ,end) item)
                     (rewrite (alist-get 'keys (nth 4 r))))
          (if (equal (plist-get rewrite :old) (buffer-substring-no-properties beg end))
              (push (list item (plist-get rewrite :key) new) valid)
            (cl-incf stale)))))
    (setq valid (nreverse valid))
    (let* ((renames (mapcar (lambda (v) (cons (nth 1 v) (nth 2 v))) valid))
           (moves (seq-filter (lambda (entry) (assoc (car entry) renames))
                              (plist-get plan :moves)))
           (notes (plist-get plan :notes))
           skipped)
      (when moves
        (sp-bibtex-files--move (apply #'append (mapcar #'cdr moves))))
      (when notes
        (setq skipped (cdr (sp-bibtex-keys--update-notes renames (mapcar #'car notes) stamp))))
      (when (plist-get plan :bibrefs)
        (sp-bibtex-keys--update-bibs renames (plist-get answer :file) stamp))
      (with-current-buffer work
        (dolist (v valid)
          (pcase-let* ((`(,item ,old ,new) v)
                       (beg (nth 1 item))
                       (end (nth 2 item)))
            (sp-bibtex-lint--replace
             beg end
             (sp-bibtex-keys--rewrite-entry (buffer-substring-no-properties beg end)
                                            old new (cdr (assoc old moves))))))
        (when (plist-get plan :bibrefs)
          (sp-bibtex-keys--replace-refs renames)))
      (when (fboundp 'citar-refresh) (ignore-errors (citar-refresh)))
      (when skipped
        (message "Not updated, open with unsaved changes: %s"
                 (mapconcat #'file-name-nondirectory skipped ", ")))
      (list (length valid) stale t))))

(defun sp-bibtex-lint--review-keys (file results &optional then)
  "Go through the long keys in RESULTS for FILE, a batch at a time.
Each key is asked for, then what uses the new keys is counted and updated;
see `sp-bibtex-lint--ask-keys' and `sp-bibtex-lint--apply-keys'."

     file 'keys results
     (lambda (batch index total all) (sp-bibtex-lint--ask-keys file batch index total all))

*** Completion

=sp-bibtex-author-capf= completes the name under the cursor in an =author= or =editor= field (after =\{=, a quote or =and=) from the author notes, in the canonical form, so names are picked instead of typed. It is added to =completion-at-point-functions= in =bibtex-mode=.

#+begin_src emacs-lisp -i
(defun sp-bibtex-author-capf ()
  "Complete a name in an author or editor field from the author notes.
Add to `completion-at-point-functions' in `bibtex-mode'."
  (when-let* ((_ (save-excursion
                             (re-search-backward "^[ \t]*\\([[:alnum:]_-]+\\)[ \t]*=" nil t)))
              (name (match-string-no-properties 1))
              ((member (downcase name) '("author" "editor")))
              (value-start (match-end 0))
              ((string-match-p "[{\"]" (buffer-substring-no-properties value-start (point))))
              (people (sp-bibtex-people)))
    (let* ((end (point))
           (start (save-excursion
                    (if (re-search-backward "\\(?:[{\"]\\|\\band[ \t\n]+\\)" value-start t)
                        (match-end 0)
                      end))))
      (when (<= start end)
        (list start end
              (lambda (string pred action)
                (let ((completion-ignore-case t))
                  (complete-with-action action (plist-get people :names) string pred)))
              :exclusive 'no)))))

** PDF metadata from Citar

*** Writing title and author into a PDF

=sia-citar-update-pdf-metadata= updates a PDF's embedded metadata.

- Asks you to pick a reference with =citar-select-ref=.
- Checks that =citar-library-paths= is set, and finds the PDF files attached to that key. If there is more than one, you choose.

(defun sia-citar-update-pdf-metadata (citekey)

    (user-error "Make sure `citar-library-paths' is non-nil"))

        (copy-file file sia-citar-library-backup-path 1)
        (call-process-shell-command

*** Citar

Citar provides completing-read based selection of bibliography entries. Under =:custom= it:

- reads the bibliography from =sp-bibtex-files=, the list =sp-bibtex-register= keeps, for both Org-cite and Citar (it used the obsolete =sp-bibliography=, which is nil by default, so Citar loaded with an empty bibliography),
- leaves the processor settings to the =oc= block above, which already sets them,
- points the library at =sp-literature-dir=, counting PDF and JPG files as attachments with a hyphen between several files of one key (these were in =sp-academic=, with the library path commented out),
- sets the notes directory to =sp-bib-notes=, or =sp-notes-dir= when that is nil,
- makes Embark the at-point action,
- adds DOI and URL as extra fields, so they can be shown in templates and opened,
- defines the display templates, with the note template taken from =sp-citar-note=.

Candidate layout (=citar-templates=):

- the order is fixed: emoji, authors or editors, year, title, citekey, then the tags or keywords.
- =main=: the entry type as an emoji (3 columns), the authors or editors, the year (4) and the title; the other widths come from the layout below.
- =suffix=: the citekey (up to 45 columns), then the tags or keywords when there is room.
- the entry type is an emoji from =sp-org-tag-groups-bibtex-types= (see [[file:../custom/sp-org-tag-groups.org][sp-org-tag-groups]]), made by the =etype= transform of =citar-display-transform-functions= (=sp-citations--type-emoji=); a type that is not in the table gets the fallback emoji, and so does every type when =sp-org-tag-groups= is not loaded.
- the type emoji sits in a cell of 3 columns measured in pixels (see "Exact emoji cells" below), so the next column starts in the same place whatever the emoji.
- the =beref= field is no longer shown, to leave the room to the titles and citekeys.
- the candidates are cached by =citar= as pre-formatted strings (there is no =citar-refresh= any more): after a change to the table of types, run =M-x sp-citations-fit-layout=, which formats them again.
- the citekey comes after the title, in the =sp-citar-key= face (=shadow= and italic, a faded grey in every theme).
- columns are two spaces apart.
- every column has a fixed width, so the columns are padded with spaces and line up in a monospaced font.

Indicators (=citar-indicators=, set by =sp-citations-setup-indicators= in =:config=):

- four emoji, in this order: link 🌿️, file 📁️, note 📝️, cited 🎓️.
- the cited indicator is new here; it uses =citar-is-cited=.
- each indicator is a cell of =sp-citations-indicator-cell= (2) columns measured in pixels; one that is absent is a blank of the same width.
- there is no padding between the indicators; one space ends the block.
- =citar= makes the padding from the last character of each indicator, so an empty padding would replace the emoji by a space; =sp-citations--indicator-symbols= (override of =citar--make-indicator-symbols=) builds the block instead.
- the old =citar-symbols= setting is gone: it is obsolete since citar 1.4 and nothing read it.
- the indicator faces and the Modus colours of the first version are gone: an emoji has its own colours.

Exact emoji cells (=sp-citations--emoji-cell=):

- why the columns drifted: an emoji is drawn by the emoji font, not by the mono font, and its width is not the =string-width= that =citar= pads with.
  - a glyph can be wider than two cells, or narrower;
  - a variation selector (U+FE0F, in 🌿️ 📁️ 📝️ 🎓️) or a ZWJ sequence (the master's thesis emoji) changes what is drawn but not the character count;
  - =citar= pads and cuts by =string-width=, so every row with a different emoji ended at a different pixel.
- the fix measures instead of counting:
  - =string-pixel-width= gives the width of the emoji in the font in use;
  - the cell is a string of the right number of spaces (so =string-width= is exact and =citar= never pads or cuts it), with a =display= property: the emoji, then a space of the pixels left up to the cell (cells times =frame-char-width=);
  - an emoji wider than its cell is made smaller (the =:height= of its face) until it fits;
  - the pad is relative to the cell, not an =:align-to= from the left of the window, so it does not matter where the line starts (the Vertico mark, the posframe border).
- the cells are cached by emoji, columns, character width and font; =sp-citations-fit-layout= clears the cache.
- on a terminal the emoji is followed by spaces, as before.
- not verified without a graphical Emacs: the real widths come from the emoji font of the machine (Apple Color Emoji on macOS), so check the rows by eye (see the PR).

Candidate layout widths (=sp-citations--layout=, from the display):

- the columns come from the frame Emacs has on the screen (=sp-citations--frame-columns=), not from an assumed size of the display:
  - =frame-width= of the selected frame (its parent when a child frame is selected), which Emacs works out in characters of the =default= face (base height 150, Aporetic Sans Mono) from the pixel width of the frame less its borders;
  - times =sp-posframe-width-fraction= (0.75) while the posframe is on in a graphical frame, as =sp-posframe-get-size= does, so the layout has the same width as the posframe;
  - so an AeroSpace tile, a maximized frame, or any other size, gives its own columns.
- the widths follow the frame (=sp-citations--apply-layout=):
  - it runs before =citar-select-ref= and =citar-select-refs=, which every command that asks for a reference goes through (=citar-open=, =citar-insert-citation=, =citar-create-note=);
  - the state is compared with the one of the last time: the columns, the width of a character and the family and height of the =default= face;
  - when it differs the emoji cells are made again, and the templates are set; =citar= formats the candidates again by itself when the templates changed (it compares the format string), and when only the font changed they are formatted again here (=sp-citations--repreformat=, which calls =citar-cache--preformat-bibliography= on the cached bibliographies, without reading the files);
  - a command in a frame and font that did not change costs nothing.
- =sp-citations-layout-columns= sets the columns by hand; nil takes them from the frame.
- 27 columns are fixed (=sp-citations-layout-overhead=): the margin, the Vertico mark and the four indicators, the type emoji, the year and the separators.
- the rest is shared like this:
  - the authors take a fifth, between 10 and 30 columns;
  - the citekey takes up to 45 columns, but the title keeps 20 at least and the key keeps 16 at least;
  - the title takes what is left;
  - the tags are shown only with 110 columns of room or more (22 columns).
- a citekey is only whole (45) from about 110 columns in all; below that the key is cut first, to 16 at the least: 80 columns give a key of 22, 90 give 30, 104 give 42.
- =M-x sp-citations-fit-layout= works the widths out again whatever the state and formats the cached candidates again; a change of font size is noticed on its own at the next command, but =sp-posframe-width-fraction= is not (it is part of the columns, so it is seen once the frame or font changes, or with this command).

The notes path was written inside =:custom= once, which expects pairs of variable and value, so use-package tried to customise variables literally named when and setq and neither was ever applied.

Keybindings: ~C-c w b o~ runs =citar-open= globally, and ~C-c b~ in Org buffers runs =org-cite-insert=. Citar completion at point is added to LaTeX, Org and Markdown buffers.

Also in =:custom=: =citar-library-file-extensions= is nil, meaning Citar does not filter library files by extension and will offer any attached file. It used to be a =setq= after the =use-package=.

- =citar= finds the file of an entry from its =file= field, and gave up when the PDF was not at the path the field names (for example BibDesk's =inbox/mac-bibdesk/= folder). It only printed "None of the files for ... exist".
- =sp-citations-parser-library= is added to =citar-file-parser-functions=:
  - for each name in the field that does not exist (absolute, or relative to =sp-literature-dir=), it looks for a file of the same name below =sp-literature-dir=;
  - hidden folders and the backup folder are not searched;
  - names that exist are left to =citar='s own parsers.
- =sp-citations--library-index= keeps a table of the file names below =sp-literature-dir=:
  - built on the first lookup;
  - rebuilt, at most every =sp-citations-library-index-ttl= seconds (60), when a name is not found.
- This makes =citar-open=, =citar-get-files= and the PDF column of the query tables find the same files.


#+begin_src emacs-lisp -i
;;;; Citar library lookup
;; A `file' field names the PDF where BibDesk, or an earlier layout, put it.
;; When it is not there, look it up by name below the library.
(require 'ucs-normalize)

(defcustom sp-citations-library-index-ttl 60
  "Seconds the index of `sp-literature-dir' is kept before a missing file rebuilds it."
  :type 'integer
  :group 'sp)

(defvar sp-citations--library-index nil
  "Cons of the time and a table of file name to the paths below `sp-literature-dir'.")

(defun sp-citations--library-index (&optional rebuild)
  "Return the table of file names below `sp-literature-dir', built when REBUILD or nil.
Keys are the lower-case file names; values are lists of absolute paths.
Hidden folders and the backup folder are skipped."
  (when (or rebuild (null sp-citations--library-index))
    (let ((table (make-hash-table :test #'equal))
          (backup (and (boundp 'sia-citar-library-backup-path)
                       (file-name-as-directory
                        (expand-file-name sia-citar-library-backup-path)))))
      (when (and (stringp sp-literature-dir) (file-directory-p sp-literature-dir))
        (dolist (file (directory-files-recursively
                       sp-literature-dir "" nil
                       (lambda (dir)
                         (not (or (string-prefix-p "." (file-name-nondirectory dir))
                                  (equal (file-name-as-directory dir) backup))))))
          (let ((base (file-name-nondirectory file)))
            (unless (string-prefix-p "." base)
              (push file (gethash (downcase (ucs-normalize-NFC-string base)) table))))))
      (setq sp-citations--library-index (cons (float-time) table))))
  (cdr sp-citations--library-index))

(defun sp-citations--find-in-library (name)
  "Return the files below `sp-literature-dir' named like the path NAME.
The folders of NAME are ignored; the index is rebuilt once when it is older
than `sp-citations-library-index-ttl' and has no match."
  (let ((key (downcase (ucs-normalize-NFC-string (file-name-nondirectory name)))))
    (or (gethash key (sp-citations--library-index))
        (when (> (- (float-time) (car sp-citations--library-index))
                 sp-citations-library-index-ttl)
          (gethash key (sp-citations--library-index t))))))

(defun sp-citations-parser-library (fieldvalue)
  "Parse the `file' field FIELDVALUE; find the files that are not where it says.
For `citar-file-parser-functions'.  Each name the default parsers give that
does not exist, as an absolute path or relative to `sp-literature-dir', is
searched by its file name below `sp-literature-dir'.  Names that exist are
left to the other parsers, so this returns only the files it found."
  (let (found)
    (dolist (parser '(citar-file--parser-default citar-file--parser-triplet))
      (when (fboundp parser)
        (dolist (name (funcall parser fieldvalue))
          (unless (file-exists-p (expand-file-name name sp-literature-dir))
            (setq found (append found (sp-citations--find-in-library name)))))))
    (delete-dups found)))

;; An emoji is not drawn as wide as its `string-width' says: the width of the glyph
;; comes from the emoji font, and a variation selector (U+FE0F) or a ZWJ sequence changes
;; it again.  So each emoji is put in a cell whose width is measured in pixels, in the
;; font in use, and padded to a whole number of character cells with a `display' space.
;; The pad is relative, so it does not depend on where the line starts on the screen.
(defvar sp-citations--cell-cache (make-hash-table :test 'equal)
  "Cells made by `sp-citations--emoji-cell', by emoji, columns, character width and font.")

(defun sp-citations--pixel-cells-p ()
  "Non-nil when widths can be measured in pixels: a graphical frame."
  (and (display-graphic-p) (fboundp 'string-pixel-width)))

(defun sp-citations--build-cell (emoji cells)
  "Return EMOJI shown in CELLS character cells, measured in pixels.
The string is CELLS spaces, so its `string-width' is CELLS whatever the emoji is; its
`display' property is the emoji, made smaller if it is wider than the cells, then a
space that takes the pixels left.  `citar' therefore never pads or cuts it."
  (let* ((target (* cells (frame-char-width)))
         (glyph emoji)
         (factor 1.0)
         (width (string-pixel-width glyph)))
    (dotimes (_ 2)
      (when (> width target)
        (setq factor (* factor 0.98 (/ (float target) width))
              glyph (propertize emoji 'face `(:height ,factor))
              width (string-pixel-width glyph))))
    (propertize (make-string cells ?\s)
                'display (concat glyph (propertize " " 'display
                                                   `(space :width (,(max 0 (- target width)))))))))

(defun sp-citations--emoji-cell (emoji cells)
  "Return EMOJI in a cell of CELLS columns, exact in pixels on a graphical display.
On a terminal it is the emoji and spaces up to CELLS columns."
  (if (not (sp-citations--pixel-cells-p))
      (concat emoji (make-string (max 1 (- cells (string-width emoji))) ?\s))
    (let ((key (list emoji cells (frame-char-width)
                     (face-attribute 'default :family nil t)
                     (face-attribute 'default :height nil t))))
      (or (gethash key sp-citations--cell-cache)
          (puthash key (sp-citations--build-cell emoji cells) sp-citations--cell-cache)))))

(defun sp-citations--blank-cell (cells)
  "Return a blank of CELLS character cells, exact in pixels on a graphical display."
  (if (sp-citations--pixel-cells-p)
      (propertize (make-string cells ?\s)
                  'display `(space :width (,(* cells (frame-char-width)))))
    (make-string cells ?\s)))

(defun sp-citations-setup-indicators ()
  "Set `citar-indicators' to the link, file, note and cited emoji."
  (cl-flet ((indicator (symbol function tag)
              (citar-indicator-create
               :symbol symbol :padding ""
               :emptysymbol (make-string sp-citations-indicator-cell ?\s)
               :function function :tag tag)))
    (setq citar-indicators
          (list (indicator "\U0001F33F️" #'citar-has-links "has:links")   ; link
                (indicator "\U0001F4C1️" #'citar-has-files "has:files")   ; file
                (indicator "\U0001F4DD️" #'citar-has-notes "has:notes")   ; note
                (indicator "\U0001F393️" #'citar-is-cited "is:cited")))))  ; cited

(defun sp-citations--indicator-symbols (candidate)
  "Return the indicators of CANDIDATE, ended by one space.
Replaces `citar--make-indicator-symbols'.  Its padding is the last character of each
indicator, so it cannot be empty.  Each indicator is a cell of
`sp-citations-indicator-cell' columns, measured in pixels."
  (concat (mapconcat
           (lambda (indicator)
             (if (string-match-p (citar-indicator-tag indicator) candidate)
                 (sp-citations--emoji-cell (citar-indicator-symbol indicator)
                                           sp-citations-indicator-cell)
               (sp-citations--blank-cell sp-citations-indicator-cell)))
           citar-indicators "")
          " "))

(defvar sp-org-tag-groups-bibtex-type-fallback)

(defun sp-citations--type-emoji (type)
  "Return the emoji of the BibTeX entry TYPE in a cell of 3 columns, for the type column.
The emoji come from `sp-org-tag-groups-bibtex-types'; a type that is not in it,
or the module not being loaded, gives the fallback emoji.  The cell is measured in
pixels (`sp-citations--emoji-cell').  Used as the `etype' transform of
`citar-display-transform-functions'."
  (sp-citations--emoji-cell
   (or (and (boundp 'sp-org-tag-groups-bibtex-types)
            (nth 1 (assoc (downcase (or type "")) sp-org-tag-groups-bibtex-types)))

;;;; Citar layout
;; The widths in `citar-templates' are numbers, so they are worked out here from the
;; columns of the frame Emacs has on the screen, as the posframe takes them, at the size
;; of the `default' face.  They are worked out again when the frame has changed size
;; since the last time (a tile of AeroSpace, then a maximized frame), each time a
;; command asks for a reference.  The citekey is shown in full (45) when it fits; the
;; authors and the title share what is left, and the tags only come back on a wide frame.
(defvar sp-posframe-width-fraction)

(defcustom sp-citations-layout-columns nil
  "Columns the `citar' candidates may take, or nil to work them out from the frame.
Nil means the columns of the posframe: see `sp-citations--frame-columns'."
  :type '(choice (const :tag "From the frame" nil) integer)
  :group 'sp)

(defconst sp-citations-layout-overhead 27
  "Columns the template spends besides authors, title, citekey and tags.
That is 2 for the margin, 11 for the Vertico mark and the four indicators, 3 for the
type emoji, 1 after it, 4 for the year and 6 for the separators (two columns each).")

(defun sp-citations--frame-columns ()
  "Return the columns the `citar' candidates have, from the frame on the screen.
It is the text width of the selected frame (the parent when a child frame is selected)
in pixels, divided by the pixel width of a character of the `default' face, so a change
of font size shows at once, before the frame has been resized.  While the posframe is on in a graphical frame it takes
`sp-posframe-width-fraction' of that, as `sp-posframe-get-size' does; otherwise the
whole width."
  (let* ((frame (or (frame-parameter nil 'parent-frame) (selected-frame)))
         (width (floor (frame-text-width frame) (frame-char-width frame))))
    (if (and (bound-and-true-p vertico-posframe-mode) (display-graphic-p frame)
             (boundp 'sp-posframe-width-fraction))
        (round (* sp-posframe-width-fraction width))
      width)))

(defun sp-citations--layout (&optional columns)
  "Return the widths of the `citar' columns for COLUMNS as a plist.
The keys are :author, :title, :key and :tags.  The citekey takes up to 45 columns, but
never leaves the title under 20 and the authors under 10, and not under 16 itself;
the title takes what is left after the authors, a fifth of the room (10 to 30).  Tags
get 20 columns once the room is 110 columns or more."
  (let* ((columns (or columns sp-citations-layout-columns (sp-citations--frame-columns)))
         (room (max 0 (- columns sp-citations-layout-overhead)))
         (tags (if (>= room 110) 22 0))
         (room (- room tags))
         (author (max 10 (min 30 (round (* 0.2 room)))))
         (key (max 16 (min 45 (- room author 20))))
         (title (max 20 (- room author key))))
    (list :author author :title title :key key :tags (max 0 (- tags 2)))))

(defun sp-citations--layout-templates (&optional columns)
  "Return the `main' and `suffix' entries of `citar-templates' for COLUMNS."
  (let* ((layout (sp-citations--layout columns))
         (tags (plist-get layout :tags)))
    `((main . ,(format "${=type=:3%%etype} ${author editor:%d}  ${year issued date:4}  ${title:%d}"
                       (plist-get layout :author) (plist-get layout :title)))
      (suffix . ,(concat "  "
                         (propertize (format "${=key= id:%d}" (plist-get layout :key))
                                     'face 'sp-citar-key)
                         (if (> tags 0) (format "  ${tags keywords:%d}" tags) ""))))))

(defvar sp-citations--applied-state nil
  "What the widths of `citar-templates' were last worked out for.
A list of the columns, the width of a character, and the family and height of the
`default' face: the emoji cells depend on the font as well as on the columns.")

(defun sp-citations--repreformat ()
  "Format the cached `citar' candidates again.
`citar' keeps each candidate as a pre-formatted string, made when the bibliography is
read or when the format string changes, and the emoji cells of the type column are in
it.  When only the font changed, nothing makes `citar' do it again, so it is done here."
  (when (and (boundp 'citar-cache--bibliographies)
             (fboundp 'citar-cache--preformat-bibliography))
    (maphash (lambda (_file bib) (citar-cache--preformat-bibliography bib))
             citar-cache--bibliographies)))

(defun sp-citations--apply-layout (&optional force)
  "Work the `citar' widths out for the frame and font as they are now, if they changed.
With FORCE the widths are always worked out again.  `citar' formats the candidates
again by itself when the templates change; when only the font changed (the emoji cells)
the cached candidates are formatted again here."
  (let* ((columns (or sp-citations-layout-columns (sp-citations--frame-columns)))
         (state (list columns (frame-char-width)
                      (face-attribute 'default :family nil t)
                      (face-attribute 'default :height nil t))))
    (when (or force (not (equal state sp-citations--applied-state)))
      (setq sp-citations--applied-state state)
      (clrhash sp-citations--cell-cache)
      (let* ((templates (sp-citations--layout-templates columns))
             (same (and (equal-including-properties (cdr (assq 'main templates))
                                                    (cdr (assq 'main citar-templates)))
                        (equal-including-properties (cdr (assq 'suffix templates))
                                                    (cdr (assq 'suffix citar-templates))))))
        (setq citar-templates (append templates
                                      (assq-delete-all 'suffix (assq-delete-all 'main citar-templates))))
        (when same (sp-citations--repreformat))))))

(defun sp-citations--before-select (&rest _)
  "Advice before the commands that ask for a reference: fit the widths to the frame."
  (sp-citations--apply-layout))

(defun sp-citations-fit-layout ()
  "Work the `citar' column widths out again from the frame and the font.
This is done on its own, before a command that asks for a reference, when the frame
or the font changed; this command forces it, and the cached candidates are formatted
again."
  (interactive)
  (sp-citations--apply-layout t)
  (message "citar layout: %S columns" (car sp-citations--applied-state)))

*** Citation hover

Hovering over a =[cite:@key]= link shows the full reference of the entry, modelled on the hover card of Obsidian's Pandoc Reference List. The text is the =preview= template of =citar-templates=, so change that template to change the hover text. =sp-cite-hover-display= chooses where it appears:

- =tooltip=: the =help-echo= of the link, shown when the mouse rests on it. A font-lock matcher adds the property to every =[cite...]= link in Org buffers, so it survives Org's own link fontification.
- =echo=: an Eldoc function (=sp-cite-hover--eldoc=) shows the reference in the echo area when point is on the link. Eldoc only follows point, not the mouse.

On a link with several keys, the reference is the one under the mouse or point, or the first key when it is on the prefix, suffix or style. A key missing from the bibliography shows =@key: not found in the bibliography=. Set =sp-cite-hover-display= to nil to turn both off; changing it needs no restart, but a new value for =tooltip= applies as buffers are refontified.

Tested in Emacs 29.3 in batch, with =citar= stubbed (key lookup, tooltip, Eldoc callback, outside a link); not run in the interactive config.

#+begin_src emacs-lisp -i
;;;; Citation hover
;; Show the formatted reference of the citation under the mouse or point.
(defcustom sp-cite-hover-display '(tooltip echo)
  "Where to show the reference of the `[cite:@key]' link under the mouse or point.
`tooltip' sets the `help-echo' of the link, shown when the mouse hovers over
it.  `echo' adds an Eldoc function, which shows the reference in the echo area
when point is on the link.  Set it to nil to turn both off."
  :type '(set (const :tag "Tooltip on mouse hover" tooltip)
              (const :tag "Echo area when point is on the link" echo))
  :group 'sp)

(defconst sp-cite-hover--link-regexp
  "\\[cite\\(?:/[-_/[:alnum:]]*\\)?:[^]]*\\]"
  "Regexp matching an Org citation such as `[cite/t:see @key1; @key2 p. 3]'.")

(defconst sp-cite-hover--key-regexp
  "@\\([-.:?!`'/*@+|(){}<>&_^$#%~[:alnum:]]+\\)"
  "Regexp matching a citation key, with the key itself in group 1.")

(defun sp-cite-hover--key-at (pos)
  "Return the citation key at POS, or the first key of the citation around it.
Return nil when POS is not inside a `[cite:]' link."
  (save-excursion
    (goto-char pos)
    (let ((line-start (line-beginning-position))
          (line-end (line-end-position))
          found)
      (while (and (not found)
                  (re-search-backward "\\[cite" line-start t))
        (when (and (looking-at sp-cite-hover--link-regexp)
                   (<= pos (match-end 0)))
          (setq found (cons (match-beginning 0) (match-end 0)))))
      (when found
        (goto-char (car found))
        (let (first at-pos)
          (while (and (not at-pos)
                      (re-search-forward sp-cite-hover--key-regexp
                                         (min (cdr found) line-end) t))
            (unless first (setq first (match-string-no-properties 1)))
            (when (and (<= (match-beginning 0) pos) (<= pos (match-end 0)))
              (setq at-pos (match-string-no-properties 1))))
          (or at-pos first))))))

(defun sp-cite-hover--reference (key)
  "Return the formatted reference of KEY from the bibliography, or nil.
It uses `citar-format-reference', which applies the `preview' template of
`citar-templates'.  Any error from citar gives nil, so a hover never breaks."
  (when (and key (require 'citar nil t) (fboundp 'citar-format-reference))
    (and-let* ((entry (ignore-errors (citar-get-entry key)))
               (text (ignore-errors (citar-format-reference (list key))))
               ((stringp text))
               (text (string-trim (substring-no-properties text)))
               ((not (string-empty-p text))))
      text)))

(defun sp-cite-hover--help-echo (_window object pos)
  "Return the reference of the citation at POS in OBJECT for `help-echo'."
  (when (and (memq 'tooltip sp-cite-hover-display) (bufferp object))
    (with-current-buffer object
      (when-let* ((key (sp-cite-hover--key-at pos)))
        (or (sp-cite-hover--reference key)
            (format "@%s: not found in the bibliography" key))))))

(defun sp-cite-hover--fontify (limit)
  "Put the `help-echo' tooltip on the citations up to LIMIT.
It is a font-lock matcher: it adds the property and never fontifies."
  (while (re-search-forward sp-cite-hover--link-regexp limit t)
    (add-text-properties (match-beginning 0) (match-end 0)
                         '(help-echo sp-cite-hover--help-echo)))
  nil)

(defun sp-cite-hover--eldoc (callback &rest _)
  "Eldoc function: show the reference of the citation at point with CALLBACK."
  (when (memq 'echo sp-cite-hover-display)
    (when-let* ((key (sp-cite-hover--key-at (point)))
                (text (sp-cite-hover--reference key)))
      (funcall callback text :thing (concat "@" key) :face 'font-lock-doc-face))))

(defun sp-cite-hover-setup ()
  "Turn on the citation tooltip and echo area reference in this Org buffer."
  (add-hook 'eldoc-documentation-functions #'sp-cite-hover--eldoc nil t)
  (font-lock-add-keywords nil '((sp-cite-hover--fontify)) 'append)
  (font-lock-flush))

(add-hook 'org-mode-hook #'sp-cite-hover-setup)
#+end_src

* sp-litnotes.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/academic/sp-litnotes.el
:END:

This academic module connects bibliography entries to notes. Literature notes are Vulpea notes; =citar-denote= is no longer used.

- =citar-vulpea= makes Citar use Vulpea notes, tagged =litnote=, in =~/notes/litnotes=.
- A note's citation key is the =@key= value of its =ROAM_REFS= property (the property Org-roam and Vulpea use for references), not a =#+reference:= keyword. =sp-litnotes-refs= converts the existing notes.

It builds on Citar (configured in the citation module) and on Vulpea. It is required by =sp-academic=. The =C-c w b= prefix holds the literature-note keys.

** Literature notes as Vulpea nodes

*** citar-vulpea

Installs =citar-vulpea=, loaded after Citar and Vulpea, and turns on =citar-vulpea-mode=, which registers it as Citar's notes source.

- Notes use the =litnote= tag and the =ROAM_REFS= property, notes are titled "author (date) title" and live in =~/notes/litnotes=.
- Citar always creates a note when you open notes for a reference that has none (=citar-open-always-create-notes=, which was set by the =citar-denote= block).
- Global keys: =C-c w b c= creates a note, =C-c w b n= opens one.
- In Org buffers: =C-c w b k= and =C-c w b K= add or remove a citekey of the current note, =C-c w b d= runs the do-what-I-mean command (opens the reference of the note, or offers to add one), =C-c w b e= opens a bibliography entry (it asks which; =citar-denote-open-reference-entry= took it from the note).
- =C-c w b x= (=citar-denote-nocite=) is gone; =citar-vulpea= has no equivalent.
- The title template still has to be matched to the titles of the existing notes (many are just the citekey).

#+begin_src emacs-lisp -i
;;; sp-litnotes.el --- Literature notes with citar-vulpea -*- lexical-binding: t; -*-

;;; Commentary:

;; This academic module connects bibliography entries to notes.  `citar-vulpea'
;; makes Citar use Vulpea notes as literature notes, with the citation key in
;; the `ROAM_REFS' property.  `sp-litnotes-refs' converts notes made by
;; `citar-denote' (which used a `#+reference:' keyword).

;;; Code:

;;;; Literature notes as Vulpea nodes
(use-package citar-vulpea
  :ensure t
  :after (citar vulpea)

  :custom
  ;; Tag used to identify bibliographic notes
  (citar-vulpea-keyword "litnote")

  ;; Name of the property used for citation keys
  (citar-vulpea-references-property "ROAM_REFS")

  ;; Template for new note titles
  (citar-vulpea-note-title-template "${author} (${date}) ${title}") ;; this has to be adapted to the titles of the existing notes

  (citar-vulpea-notes-directory (sp-path sp-notes-dir "litnotes/")) ;; Directory to store notes (nil uses vulpea-default-notes-directory)

  ;; Create a note when opening notes for a reference that has none
  (citar-open-always-create-notes t)

  :config
  (citar-vulpea-mode 1)

  :bind
  (("C-c w b c" . citar-create-note)
   ("C-c w b n" . citar-open-notes)

   :map org-mode-map
   ("C-c w b k" . citar-vulpea-add-reference)
   ("C-c w b K" . citar-vulpea-remove-reference)
   ("C-c w b d" . citar-vulpea-dwim)
   ("C-c w b e" . citar-open-entry)))
