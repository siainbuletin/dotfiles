The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module configures the built-in =tab-bar= and the =tabspaces= package so that tabs act as workspaces.

- Each tab holds a window layout and its own isolated set of buffers, usually tied to a project.
- It adds numbered tab names using circled digits, a do-what-I-mean tab switcher, a keymap of tabspaces commands, and a consult buffer source limited to the current workspace.

Origin and loading:

- The setup is inherited from Lambda Emacs (hence the =lem-= prefix).
- Loaded in the window-management part of =init.el=, after =sp-buffers= and =sp-windows=.
- =tabspaces-mode= starts after init, so workspaces and their sessions are live.
- =tab-bar-show= is nil, so the tab bar itself stays hidden.
- The consult integration needs =consult= and the tabspaces predicate =tabspaces--local-buffer-p=.

* Tab bar

The tab bar replaces the older =eyebrowse= package for grouping window layouts.

** Numbered tab names

Numbered tab names:

- =lem-tab-bar--circle-numbers-alist= maps 0 to 15 to circled Unicode digits.
- =lem--tab-bar-tab-name-format= uses it to draw each tab as its number, a small gap, the tab name and optionally a close button, with the face given by =tab-bar-tab-face-function=.
- The number only appears when =tab-bar-tab-hints= is on and the index is below 16.
- The idea comes from a post by Christian Tietze.

#+begin_src emacs-lisp -i
;;;; Tab Bar
;; Use tab-bar for window grouping and configuration within a project (replaces eyebrowse)

;; https://christiantietze.de/posts/2022/02/emacs-tab-bar-numbered-tabs/
(defvar lem-tab-bar--circle-numbers-alist
  '((0 . "⓪")
    (1 . "①")
    (2 . "②")
    (3 . "③")
    (4 . "④")
    (5 . "⑤")
    (6 . "⑥")
    (7 . "⑦")
    (8 . "⑧")
    (9 . "⑨")
    (10 . "⑩")
    (11 . "⑪")
    (12 . "⑫")
    (13 . "⑬")
    (14 . "⑭")
    (15 . "⑮"))

  "Alist of integers to strings of circled unicode numbers.")
(defun lem--tab-bar-tab-name-format (tab i)
  (let ((current-p (eq (car tab) 'current-tab))
        (tab-num (if (and tab-bar-tab-hints (< i 16))
                     (alist-get i lem-tab-bar--circle-numbers-alist) "")))
    (propertize
     (concat
      " "
      tab-num
      (propertize " " 'display '(space :width (4)))
      (alist-get 'name tab)
      (or (and tab-bar-close-button-show
               (not (eq tab-bar-close-button-show
                        (if current-p 'non-selected 'selected)))
               tab-bar-close-button)
          "")
      (propertize " " 'display '(space :width (4))))
     'face (funcall tab-bar-tab-face-function tab))))
#+end_src

** tab-bar settings and DWIM switcher

Configures the built-in =tab-bar= once =project= is loaded.

- The tab bar is hidden (=tab-bar-show= nil), but tabs show numbers.
- New tabs open the =*scratch*= buffer and are placed at the far right.
- =s-1= to =s-9= select tabs by number.
- Closing a tab returns to the most recently used one. Closing the last tab turns =tab-bar-mode= off.
- The new and close buttons are hidden, and tabs keep their natural width.
- The bar layout is history buttons, tabs, the suffix space and an add-tab element.
- =tab-bar-new-button= is set twice, which is harmless.

=lem-tab-bar-select-tab-dwim= creates a tab when there is only one, switches to the other when there are two, and otherwise asks with completion. It comes from Protesilaos Stavrou and is not bound to a key here.

#+begin_src emacs-lisp -i
(use-package tab-bar
  :ensure nil
  :after (project)
  :commands (tab-bar-new-tab
             tab-bar-switch-to-tab
             tab-bar-switch-to-next-tab
             tab-bar-switch-to-prev-tab)
  :custom
  ;; Set this to nil unless tab bar is in use
  (tab-bar-show nil)
  (tab-bar-tab-hints t) ;; show numbers in tabs
  ;; Unless another file/buffer is designated, start from workspace scratch buffer
  (tab-bar-new-tab-choice "*scratch*")
  (tab-bar-select-tab-modifiers '(super))
  (tab-bar-close-tab-select 'recent)
  (tab-bar-new-tab-to 'rightmost)
  (tab-bar-close-last-tab-choice 'tab-bar-mode-disable)
  (tab-bar-tab-name-format-function #'lem--tab-bar-tab-name-format)
  (tab-bar-new-button nil)
  (tab-bar-close-button nil)
  (tab-bar-close-button-show nil)
  (tab-bar-new-button nil)
  (tab-bar-auto-width nil)
  (tab-bar-format '(tab-bar-format-history
                    tab-bar-format-tabs
                    lem--tab-bar-suffix
                    tab-bar-format-add-tab))
  :config

  ;; https://protesilaos.com/codelog/2020-08-03-emacs-custom-functions-galore/
  (defun lem-tab-bar-select-tab-dwim ()
    "Do-What-I-Mean function for getting to a `tab-bar-mode' tab.
If no other tab exists, create one and switch to it.  If there is
one other tab (so two in total) switch to it without further
questions.  Otherwise use completion to select the tab."
    (interactive)
    (let ((tabs (mapcar (lambda (tab)
                          (alist-get 'name tab))
                        (tab-bar--tabs-recent))))
      (cond ((eq tabs nil)
             (tab-new))
            ((eq (length tabs) 1)
             (tab-next))
            (t
             (tab-bar-switch-to-tab
              (completing-read "Select tab: " tabs nil t)))))))
#+end_src

* Tabspaces workspaces

** tabspaces package

Installs =tabspaces= and makes its main commands autoload.

- Buffer lists are filtered to the current workspace by default.
- The default tab is called =Home=. Removed buffers go back to it.
- =*scratch*= is included in every workspace. =*Messages*= and =*Compile-Log*= are left out.
- Opening a project creates a =project-todo.org= file.
- Workspaces are saved as a session and restored automatically. Project paths are resolved to absolute ones.
- =tabspaces-mode= starts from =after-init=. Without it the session options do nothing.
- The session (the file-visiting buffers of each workspace) is stored in =tabspaces-session.eld= in =sp-var-dir=. =tabspaces-save-session= and =tabspaces-restore-session= do it by hand.

#+begin_src emacs-lisp -i
;;;; Tab Workspaces
(use-package tabspaces
  :ensure t
  ;; The session is only saved and restored while `tabspaces-mode' is on.
  :hook (after-init . tabspaces-mode)
  :commands (tabspaces-switch-or-create-workspace
             tabspaces-open-or-create-project-and-workspace)
  
  :custom
  (tabspaces-use-filtered-buffers-as-default nil) ; C-x b is `sp-tabs-switch-to-buffer', see below
  (tabspaces-default-tab "Home")
  (tabspaces-remove-to-default t)
  (tabspaces-include-buffers '("*scratch*"))
  (tabspaces-initialize-project-with-todo t)
  (tabspaces-todo-file-name "project-todo.org")
  
  ;; sessions
  (tabspaces-session t)
  (tabspaces-session-auto-restore t)
  (tabspaces-session-file (expand-file-name "tabspaces-session.eld" sp-var-dir))
  
  ;; additional options
  (tabspaces-fully-resolve-paths t)  ; Resolve relative project paths to absolute
  (tabspaces-exclude-buffers '("*Messages*" "*Compile-Log*"))  ; Additional buffers to exclude
  (tab-bar-new-tab-choice "*scratch*"))
#+end_src

** Dired buffers are not restored

Stops the session from reopening dired buffers, which printed an error at startup.

- Restoring a dired buffer starts Dirvish while Emacs is still starting.
- Dirvish's background directory scan then fails: =Fetch dir data failed with error: (end-of-file)=.
- The =dired= buffer kind is replaced by one that neither saves nor restores.
- Old session files may still hold a dired record. It is skipped.
- File-visiting buffers are saved and restored as before.

#+begin_src emacs-lisp -i
;; Dired buffers are not kept in the session: restoring one runs Dirvish at
;; startup, and its async directory scan fails with "Fetch dir data failed
;; with error: (end-of-file)".  A saved dired record is skipped on restore.
(with-eval-after-load 'tabspaces
  (tabspaces-register-buffer-kind 'dired #'ignore #'ignore))
#+end_src

** Tabspaces command map

Defines =tabspaces-command-map= with single-key commands:

- =s=: switch or create a workspace.
- =o=: open a project in a workspace.
- =b=: switch buffer within the workspace.
- =t=: switch to a buffer and its tab.
- =d=: close a workspace.
- =k=: kill its buffers and close it.
- =n=: rename.
- =r= and =R=: remove buffers.
- =C=: clear buffers.
- =w=: show workspaces.
- =T=: toggle echo area display.

It is defined before tabspaces loads, so this map is the one tabspaces uses. It becomes reachable under =tabspaces-keymap-prefix= once =tabspaces-mode= is on.

#+begin_src emacs-lisp -i
;; Keybindings for tabspaces
(defvar tabspaces-command-map
  (let ((map (make-sparse-keymap)))
    (define-key map (kbd "C") 'tabspaces-clear-buffers)
    (define-key map (kbd "b") 'tabspaces-switch-to-buffer)
    (define-key map (kbd "d") 'tabspaces-close-workspace)
    (define-key map (kbd "k") 'tabspaces-kill-buffers-close-workspace)
    (define-key map (kbd "n") 'tabspaces-rename-workspace)
    (define-key map (kbd "o") 'tabspaces-open-or-create-project-and-workspace)
    (define-key map (kbd "r") 'tabspaces-remove-current-buffer)
    (define-key map (kbd "R") 'tabspaces-remove-selected-buffer)
    (define-key map (kbd "s") 'tabspaces-switch-or-create-workspace)
    (define-key map (kbd "t") 'tabspaces-switch-buffer-and-tab)
    (define-key map (kbd "w") 'tabspaces-show-workspaces)
    (define-key map (kbd "T") 'tabspaces-toggle-echo-area-display)
    map)
  "Keymap for tabspace/workspace commands after `tabspaces-keymap-prefix'.")
#+end_src

* Buffer filtering per tab: =C-x b=

Why =*Messages*= was missing from =C-x b=:

- =tabspaces-use-filtered-buffers-as-default= remapped =switch-to-buffer= to =tabspaces-switch-to-buffer=, which offers only the current tab's buffers.
- =tabspaces-exclude-buffers= removes =*Messages*= from that list at startup, so it was missing until something re-added it.

New behavior:

- =tabspaces-use-filtered-buffers-as-default= is now nil, so tabspaces no longer filters everywhere.
- =C-x b= runs =sp-tabs-switch-to-buffer=, remapped in =tabspaces-mode-map=.
- By default it is the regular =switch-to-buffer=: every buffer, =*Messages*= included.
- When filtering applies, it runs =sp-tabs-filtered-switch-to-buffer= instead.
- =sp-tabs--filtering-p= decides, and filtering applies when any of these holds:
  - =sp-tabs-filter-buffers= is non-nil: filter in every tab.
  - The current tab's name is in =sp-tabs-filtered-tab-names=, default ="Email"=.
  - The current buffer's major mode is derived from one of =sp-tabs-filtered-modes=: mu4e main, headers, view and =message-mode=.
- =sp-tabs-toggle-tab-filter= adds or removes the current tab's name in =sp-tabs-filtered-tab-names=; it is =f= in =tabspaces-command-map=.
- Use the toggle in a project (Projectile) tab to see only that project's buffers; the setting lasts for the Emacs session.
- Make it permanent with =(setopt sp-tabs-filtered-tab-names '("Email" "my-project"))=.
- The filtered switcher lists the tab's buffers by recency, then =sp-tabs-always-listed-buffers= (=*Messages*=) at the end.
- Its completion table sets =display-sort-function= to =identity= and keeps category =buffer=, so Marginalia still annotates.
- =tabspaces-exclude-buffers= is unchanged, so closing a workspace never touches =*Messages*=.

#+begin_src emacs-lisp -i
;;;;; Buffer filtering per tab: C-x b
;; `C-x b' is the regular `switch-to-buffer' (all buffers, *Messages* included)
;; unless filtering is on for the current tab.
(defcustom sp-tabs-filter-buffers nil
  "Non-nil filters `C-x b' to the current tab's buffers in every tab."
  :type 'boolean
  :group 'tabspaces)

(defcustom sp-tabs-filtered-tab-names '("Email")
  "Names of tabs where `C-x b' offers only that tab's buffers."
  :type '(repeat string)
  :group 'tabspaces)

(defcustom sp-tabs-filtered-modes '(mu4e-main-mode mu4e-headers-mode
                                    mu4e-view-mode message-mode)
  "Major modes in which `C-x b' offers only the current tab's buffers."
  :type '(repeat symbol)
  :group 'tabspaces)

(defcustom sp-tabs-always-listed-buffers '("*Messages*")
  "Buffer names that the filtered `C-x b' still offers, at the end."
  :type '(repeat string)
  :group 'tabspaces)

(defun sp-tabs--filtering-p ()
  "Return non-nil when `C-x b' should be filtered to this tab's buffers."
  (or sp-tabs-filter-buffers
      (member (alist-get 'name (tab-bar--current-tab)) sp-tabs-filtered-tab-names)
      (apply #'derived-mode-p sp-tabs-filtered-modes)))

(defun sp-tabs-toggle-tab-filter ()
  "Toggle filtering of `C-x b' for the current tab by its name.
Use it in a project tab, for example, to see only that project's buffers."
  (interactive)
  (let ((name (alist-get 'name (tab-bar--current-tab))))
    (if (member name sp-tabs-filtered-tab-names)
        (setq sp-tabs-filtered-tab-names (delete name sp-tabs-filtered-tab-names))
      (push name sp-tabs-filtered-tab-names))
    (message "Buffer filter for tab %s: %s" name
             (if (member name sp-tabs-filtered-tab-names) "on" "off"))))

(defun sp-tabs-filtered-switch-to-buffer ()
  "Switch to a buffer of this tab, plus `sp-tabs-always-listed-buffers'.
Like `tabspaces-switch-to-buffer', but the always-listed buffers that
exist are added after the tab's own buffers."
  (interactive)
  (let* ((current (buffer-name))
         (local (cl-remove current (mapcar #'buffer-name (tabspaces--buffer-list))
                           :test #'equal))
         (extra (cl-remove-if (lambda (name)
                                (or (member name local) (equal name current)
                                    (not (get-buffer name))))
                              sp-tabs-always-listed-buffers))
         (names (append local extra))
         (table (lambda (string pred action)
                  (if (eq action 'metadata)
                      '(metadata (category . buffer)
                                 (display-sort-function . identity))
                    (complete-with-action action names string pred)))))
    (switch-to-buffer
     (completing-read "Switch to local buffer: " table nil nil nil
                      'buffer-name-history (car names)))))

(defun sp-tabs-switch-to-buffer ()
  "Run the tab-filtered or the regular buffer switcher, see `sp-tabs--filtering-p'."
  (interactive)
  (call-interactively (if (sp-tabs--filtering-p)
                          #'sp-tabs-filtered-switch-to-buffer
                        #'switch-to-buffer)))

;; A minor-mode remap works even though `tabspaces-use-filtered-buffers-as-default' is nil.
(with-eval-after-load 'tabspaces
  (define-key tabspaces-mode-map [remap switch-to-buffer] #'sp-tabs-switch-to-buffer)
  (define-key tabspaces-command-map (kbd "f") #'sp-tabs-toggle-tab-filter))
#+end_src

* Workspace buffers in consult

** Buffer filter

=lem-buff-filter= returns non-nil when a buffer is in the current frame's buffer list, other than the current buffer. It is not used anywhere else in the config.

#+begin_src emacs-lisp -i
;;;;; Consult Isolated Workspace Buffers
;; Filter Buffers for Consult-Buffer
(defun lem-buff-filter (buffer)
  (let ((blst (cl-remove (buffer-name) (frame-parameter nil 'buffer-list))))
    (memq buffer blst)))
#+end_src

** Consult source for workspace buffers

After consult loads:

- The normal buffer source is hidden from =consult-buffer= (still reachable with the =b= narrowing key) and is no longer the default.
- A new source, =consult-source-workspace=, lists only buffers that belong to the current tabspace, sorted by visibility, under the narrowing key =w=.
- The new source is not added to =consult-buffer-sources= in this module, so it only shows up if that is done elsewhere.
- As things stand, hiding the default source means =consult-buffer= lists fewer buffers by default.

#+begin_src emacs-lisp -i
(with-eval-after-load 'consult
  ;; hide full buffer list (still available with "b" prefix)
  ;; Use plist-put instead of consult-customize for internal sources
  ;; Use boundp check to handle package-quickstart timing issues
  (when (boundp 'consult-source-buffer)
    (plist-put consult-source-buffer :hidden t)
    (plist-put consult-source-buffer :default nil))
  ;; set consult-workspace buffer list
  (defvar consult-source-workspace
    (list :name     "Workspace Buffers"
          :narrow   ?w
          :history  'buffer-name-history
          :category 'buffer
          :state    #'consult--buffer-state
          :default  t
          :items    (lambda () (consult--buffer-query
                           :predicate #'tabspaces--local-buffer-p
                           :sort 'visibility
                           :as #'buffer-name)))

    "Set workspace buffer list for consult-buffer."))
#+end_src
