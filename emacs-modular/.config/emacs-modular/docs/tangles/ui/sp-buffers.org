This module covers two things: how the buffer list looks and behaves (the built-in =ibuffer=, with icons from =nerd-icons-ibuffer=), and how transient pop-up buffers such as help, messages and compilation output are displayed (Karthik Chikmagalur's =popper= package, using settings adapted from Lambda Emacs).

It is loaded among the window management UI modules in =init.el=. The ibuffer icons are actually switched on by a hook in =sp-icons=; here the library is only required.

* Ibuffer

** Ibuffer appearance

Configures the built-in =ibuffer=:
- no summary line at the bottom and a header line on top instead,
- ibuffer opens in the current window rather than another one,
- empty filter groups are hidden,
- buffers are sorted by file name or process,
- the title uses =font-lock-doc-face=, and the window is not shrunk to fit.

=ibuffer-formats= defines two column layouts, toggled with ~`~ in ibuffer:
- detailed: mark, flags, a 36 character name (the =sp-name= column, see "Org title in the buffer list"), size, an 18 character mode and the file or process,
- compact: mark, a 24 character name (=sp-name=) and the file name.
- Long names and modes are cut with =:elide=, which keeps the start and end and puts =...= in the middle, so you can still tell similar buffers apart.
- The last column has no width limit, so file paths use whatever room is left.

=nerd-icons-ibuffer-mode= (switched on in =sp-icons=) overwrites =ibuffer-formats= with =nerd-icons-ibuffer-formats= when it starts.
- Setting only =ibuffer-formats= therefore had no visible effect.
- The same widths are set for =nerd-icons-ibuffer-formats= after that package loads, with an icon column added.

The Main groups are activated by =sp-buffers-activate-filter-groups= on =ibuffer-mode-hook=.

#+begin_src emacs-lisp -i
(use-package ibuffer
  :ensure nil
  
  :custom ;; this is for customizing variables. :config is for functions
  (ibuffer-display-summary nil)
  (ibuffer-use-other-window nil)
  (ibuffer-show-empty-filter-groups nil)
  (ibuffer-default-sorting-mode 'filename/process)
  (ibuffer-title-face 'font-lock-doc-face)
  (ibuffer-use-header-line t)
  (ibuffer-default-shrink-to-minimum-size nil)
  (ibuffer-formats
        '((mark modified read-only locked " "
                (sp-name 36 36 :left :elide)
                " "
                (size 9 -1 :right)
                " "
                (mode 18 18 :left :elide)
                " " filename-and-process)
          (mark " "
                (sp-name 24 24 :left :elide)
                " " filename)))
  ;; Group the list as soon as ibuffer opens, otherwise the saved groups
  ;; below are defined but never applied.
  :hook (ibuffer-mode . sp-buffers-activate-filter-groups))

(defun sp-buffers-activate-filter-groups ()
  "Switch the current ibuffer to the \"Main\" saved filter groups."
  (when (assoc "Main" ibuffer-saved-filter-groups)
    (ibuffer-switch-to-saved-filter-groups "Main")))
#+end_src

** Org title in the buffer list

Org files are listed by their =#+title= instead of the file name.
- It is a display-only column, =sp-name=; buffers are not renamed.
- So =switch-to-buffer=, Uniquify, Popper and the =name= filters still see the real buffer name.
- Why not rename: the title changes while you type, the file name carries meaning, and two notes can share a title.
- Both format lists use =sp-name= where they used =name=.
- The column copies the built-in =name= column (mouse map, help text, summary, face); only the text differs.
- Sorting is unchanged: the sorters still compare the real buffer names, and the Org filter group still matches by mode.

Variables and functions:
- =sp-buffers-org-title-in-ibuffer=: option, non-nil by default; set it to nil to list buffer names again.
- =sp-buffers-org-title-regexp=: matches a =#+title:= line, case-insensitive; group 1 is the title.
- =sp-buffers-org-title-search-limit=: only the first 4000 characters are searched, so large buffers stay cheap.
- =sp-buffers--title-cache=: buffer-local cons of =buffer-chars-modified-tick= and the title (or =none=); the text is only scanned again after an edit.
- =sp-buffers-org-title=: the title of an Org buffer, ignoring narrowing; nil when the mode is not Org or the title is missing or empty.
- =sp-buffers-display-name=: the title when the option is on and there is one, else =buffer-name=.
- Tests: =tests/sp-buffers-test.el=.

#+begin_src emacs-lisp -i
;; Show the `#+title' of an Org file in the buffer list instead of its file
;; name.  This is a display column only: the buffers are not renamed, so
;; `switch-to-buffer', Uniquify and the "name" filters keep working.
(defcustom sp-buffers-org-title-in-ibuffer t
  "Non-nil shows the `#+title' of Org buffers in the `sp-name' ibuffer column.
Buffers without a title, and buffers that are not in Org mode, show their
buffer name as usual."
  :type 'boolean
  :group 'ibuffer)

(defconst sp-buffers-org-title-regexp "^[ \t]*#\\+title:[ \t]*\\(.*?\\)[ \t]*$"
  "Match a `#+title' keyword line; group 1 is the title.")

(defconst sp-buffers-org-title-search-limit 4000
  "Look for `#+title' only in the first this many characters of a buffer.")

(defvar-local sp-buffers--title-cache nil
  "Cons of `buffer-chars-modified-tick' and the title found then (or `none').")

(defun sp-buffers-org-title (&optional buffer)
  "Return the `#+title' of the Org BUFFER, or nil when it has none.
BUFFER defaults to the current buffer.  The result is cached in the buffer
and only looked up again after the text changed."
  (with-current-buffer (or buffer (current-buffer))
    (when (derived-mode-p 'org-mode)
      (let ((tick (buffer-chars-modified-tick)))
        (unless (eq (car sp-buffers--title-cache) tick)
          (setq sp-buffers--title-cache
                (cons tick
                      (save-restriction
                        (widen)
                        (save-excursion
                          (goto-char (point-min))
                          (let ((case-fold-search t))
                            (if (re-search-forward
                                 sp-buffers-org-title-regexp
                                 sp-buffers-org-title-search-limit t)
                                (let ((title (match-string-no-properties 1)))
                                  (if (string-empty-p title) 'none title))
                              'none)))))))
        (and-let* ((title (cdr sp-buffers--title-cache))
                   ((stringp title)))
          title)))))

(defun sp-buffers-display-name (&optional buffer)
  "Return the name to list for BUFFER: its Org title, else its buffer name."
  (or (and sp-buffers-org-title-in-ibuffer
           (sp-buffers-org-title buffer))
      (buffer-name buffer)))

(eval-when-compile (require 'ibuf-macs))
(define-ibuffer-column sp-name
  (:name "Name"
   :inline t
   :header-mouse-map ibuffer-name-header-map
   :props
   ('mouse-face 'highlight 'keymap ibuffer-name-map
                'ibuffer-name-column t
                'help-echo "mouse-1: mark buffer   mouse-2: select buffer   mouse-3: operate")
   :summarizer
   (lambda (strings)
     (let ((bufs (length strings)))
       (cond ((zerop bufs) "No buffers")
             ((= 1 bufs) "1 buffer")
             (t (format "%s buffers" bufs))))))
  (let ((string (propertize (sp-buffers-display-name buffer)
                            'font-lock-face
                            (ibuffer-buffer-name-face buffer mark))))
    (string-replace
     "\n" (propertize "^J" 'font-lock-face 'escape-glyph) string)))
#+end_src

** Saved filter groups

Defines a filter group set named Main that sorts buffers into:

- Directories (Dired),
- Scripts (shell, Lua and batch modes),
- Markup (Markdown and AsciiDoc),
- Org,
- Emacs Internals (Emacs Lisp plus buffers like =*Help*=, =*Messages*= and =*scratch*=).

Defining =ibuffer-saved-filter-groups= only stores the groups; ibuffer does not use them by itself.
- This was the bug: nothing called =ibuffer-switch-to-saved-filter-groups=, so the list stayed ungrouped unless you ran ~/ r~ by hand.
- =sp-buffers-activate-filter-groups=, run from =ibuffer-mode-hook= (the =:hook= in the block above), now switches to "Main" every time ibuffer opens.
- Buffers that match no group stay at the bottom, ungrouped.

#+begin_src emacs-lisp -i
(setq ibuffer-saved-filter-groups
      '(("Main"
         ("Directories" (mode . dired-mode))
         ("Scripts" (or
                     (mode . shell-script-mode)
                     (mode . shell-mode)
                     (mode . sh-mode)
                     (mode . lua-mode)
                     (mode . bat-mode)))
         ("Markup" (or
                    (mode . markdown-mode)
                    (mode . adoc-mode)))
         ("Org" (mode . org-mode))
         ("Emacs Internals" (or
                   (mode . emacs-lisp-mode)
                   (name . "^\\*Help\\*$")
                   (name . "^\\*Custom.*")
                   (name . "^\\*Org Agenda\\*$")
                   (name . "^\\*info\\*$")
                   (name . "^\\*scratch\\*$")
                   (name . "^\\*Backtrace\\*$")
                   (name . "^\\*Messages\\*$"))))))
#+end_src

** Popper

=popper= marks certain buffers as pop-ups so they can be summoned, dismissed and cycled independently of regular windows. It is enabled after init, with echo-area hints from =popper-echo-mode=.

Keybindings:
- ~M-`~ toggles the most recent pop-up (=popper-toggle-latest=).
- ~C-`~ cycles through pop-ups (=popper-cycle=).
- ~C-M-`~ turns the current buffer into a pop-up or back into a regular buffer (=popper-toggle-type=).

Buffers treated as pop-ups are =*Messages*=, anything ending in Output, =*Async Shell Command*=, and buffers in help, compilation and =vulpea-sidebar-ui-mode=. Pop-ups are grouped by directory (the comment mentions project roots, but the function used is =popper-group-by-directory=).

The =:config= block defines four display functions:

- two that show the pop-up in a top side window,
- two that show it in a right side window,
- each in a select variant (which also moves focus) and a display-only variant.

Then:

- =popper-display-function= is set to the right-hand, focus-moving one, so pop-ups open as a 20-line high side window on the right.
- The docstrings of the right-hand functions still say top, a copy-paste leftover.

#+begin_src emacs-lisp -i
;;;; Popper (Pop-up Buffers)
;; this is a package created by Karthik and it makes it possible to bring up windows without
;; messing up the layout
(use-package popper
  :ensure t
  :hook (after-init . popper-mode)
  :bind (("M-`"   . popper-toggle-latest)
         ("C-`"   . popper-cycle)
         ("C-M-`" . popper-toggle-type))

  :custom
  (popper-window-height 20)
  (popper-display-control t)
  (popper-display-function #'popper-select-popup-right)   ;; set display to top -- if user prefers they can set this to `bottom' (i set it to the custom function for sending it right-ward)
  ;; group by project.el project root, with fall back to default-directory
  (popper-group-function #'popper-group-by-directory)
  ;; Set popper buffers
  (popper-reference-buffers
   '("\\*Messages\\*"
     "Output\\*$"
     "\\*Async Shell Command\\*"
     help-mode
     compilation-mode
     vulpea-sidebar-ui-mode))
  
  :init
  ;; For echo area hints
  (popper-echo-mode +1)
  
  :config
  ;; Display functions for popup buffers at top, where they are easy to read.
  ;; This is just a slight modification of the existing functions.
  (defun popper-select-popup-at-top (buffer &optional _alist)
    "Display and switch to popup-buffer BUFFER at the top of the screen."
    (let ((window (popper-display-popup-at-top buffer)))
      (select-window window)))

  (defun popper-display-popup-at-top (buffer &optional _alist)
    "Display popup-buffer BUFFER at the top of the screen."
    (display-buffer-in-side-window
     buffer
     `((window-height . ,popper-window-height)
       (side . top)
       (slot . 1))))
       
  ;; Displaying functions on the side if wanted
  (defun popper-select-popup-right (buffer &optional _alist)
    "Display and switch to popup-buffer BUFFER at the top of the screen."
    (let ((window (popper-display-popup-right buffer)))
      (select-window window)))

  (defun popper-display-popup-right (buffer &optional _alist)
    "Display popup-buffer BUFFER at the top of the screen."
    (display-buffer-in-side-window
     buffer
     `((window-height . ,popper-window-height)
       (side . right)
       (slot . 1))))
       )
#+end_src
