- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../tangling-instructions.org][Tangling instructions]].

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module configures Emacs frames, meaning the top-level windows managed by the operating system. It:

- produces a minimal, undecorated frame with wide internal borders and no tool bar or scroll bars,
- recentres new frames,
- adds small window margins everywhere,
- turns on =keycast= in the header line,
- shares the buffer list with new frames (=sp-frame-share-buffers-mode=).

Some basic frame settings live in =early-init.el= instead, for faster startup.

It depends on the built-in =frame= library, on =keycast= (installed in =sp-keys=), and optionally on =ns-auto-titlebar= for macOS. It is loaded with the window management modules, before =sp-buffers= and =sp-windows=.

* Frame defaults

** Minimal frame parameters

Inside the built-in =frame= package, =default-frame-alist= is set so new frames have:

- a 30 pixel internal border,
- no tool bar,
- no vertical or horizontal scroll bars,
- no window manager decorations (=undecorated=). Per the comment, this makes macOS frames square-cornered and closer to the Linux look.

Other settings:

- The =frame-title-format= entry is not a real frame parameter and has no effect.
- Pixel-wise resizing of windows and frames avoids gaps around the edges.
- =ns-use-proxy-icon= hides the document icon in the macOS title bar.
- This replaces any earlier contents of =default-frame-alist= rather than adding to it.

#+begin_src emacs-lisp -i
;;;; Frame defaults
;; This setting will ensure that the frame is actually square, which 
;; radically changes the appearance on MacOS and brings it closer to a
;; Linux experience.

;; Make a clean & minimalist frame
;; To modify initial frame set `initial-frame-alist`

(use-package frame
  :ensure nil
  :config

  (setq-default default-frame-alist
                (append (list
                         '(frame-title-format . nil)
                         '(internal-border-width . 30)
                         '(tool-bar-lines . 0)
                         '(vertical-scroll-bars . nil)
                         '(horizontal-scroll-bars . nil)
                         '(undecorated . t))))
  ;; Resize pixel-wise to avoid gaps
  (setq-default window-resize-pixelwise t)
  (setq-default frame-resize-pixelwise t)

  ;; Don't show icon in frame
  (setq-default ns-use-proxy-icon nil))
#+end_src

** Recentre a frame

=sp-frame-recenter= moves a frame to the centre of the screen by setting its =top= and =left= parameters to 0.5.

- It skips frames that are already maximized, using the value Emacs reports, =maximized=. The code used to compare against =maximised=, which never matches.
- It checks the selected frame rather than FRAME.

#+begin_src emacs-lisp -i
(defun sp-frame-recenter (&optional frame)
  "Center FRAME on the screen.
FRAME can be a frame name, a terminal name, or a frame.
If FRAME is omitted or nil, use currently selected frame."
  (interactive)
  (unless (eq 'maximized (frame-parameter nil 'fullscreen))
    (modify-frame-parameters
     frame '((user-position . t) (top . 0.5) (left . 0.5)))))
#+end_src

** Recentre new frames

Runs =sp-frame-recenter= for every newly created frame. The comment invites disabling the hook if recentring is not wanted.

#+begin_src emacs-lisp -i
;; un/comment this hook if you want frames recentered
(add-hook 'after-make-frame-functions #'sp-frame-recenter)
#+end_src

* Window margins

Small left and right margins keep text from touching the window edge now that frame borders are narrow.

** Set margins on all windows

=sp-set-window-margins= walks every window in the selected frame and gives each non-minibuffer window a two-column margin on both sides. It skips windows whose buffer is in =olivetti-mode=, because Olivetti centres the text with those same window margins; setting two columns there on every window change undid the centring and the 80-column body.

#+begin_src emacs-lisp -i
;;;;; Window Margins for Text Indentation
;; Add margins to windows to maintain text indentation with smaller frame borders
(defun sp-set-window-margins ()
  "Set left and right margins for all windows to maintain text indentation.
Windows showing a buffer in `olivetti-mode' are skipped: Olivetti
centres the text with these same margins."
  (walk-windows
   (lambda (window)
     (unless (or (window-minibuffer-p window)
                 (with-current-buffer (window-buffer window)
                   (bound-and-true-p olivetti-mode)))
       (set-window-margins window 2 2)))))
#+end_src

** Reapply on layout changes

Adds the function to =window-configuration-change-hook=, so margins are restored whenever windows are split, deleted or change buffers.

#+begin_src emacs-lisp -i
;; Apply margins when windows change
(add-hook 'window-configuration-change-hook #'sp-set-window-margins)
#+end_src

** Apply at startup

Applies the margins once after init, for the initial frame.

#+begin_src emacs-lisp -i
;; Apply margins to initial frame
(add-hook 'after-init-hook #'sp-set-window-margins)
#+end_src

** Apply to new frames

For each new frame, selects it and applies the margins. Selecting the frame from this hook can change which frame is focused, a side effect to keep in mind with =emacsclient=.

#+begin_src emacs-lisp -i
;; Apply margins to new frames
(add-hook 'after-make-frame-functions
          (lambda (frame)
            (select-frame frame)
            (sp-set-window-margins)))
#+end_src

* Frame functions

** Delete frame or quit

=sp-delete-frame-or-quit=:

- Deletes the current frame.
- If that fails because it is the last frame, falls back to =save-buffers-kill-emacs=.
- Finally gives input focus to whatever frame is now selected.

#+begin_src emacs-lisp -i
;;;;; Frame Functions
;;;;;; Delete Frame or Quit
(defun sp-delete-frame-or-quit ()
  "Delete the selected frame. If the last frame, kill Emacs."
  (interactive)
  (when (condition-case nil (delete-frame)
          (error (save-buffers-kill-emacs))))
  (select-frame-set-input-focus (selected-frame)))
#+end_src

* Share the buffer list between frames

Why this exists:

- A new frame starts with an empty =buffer-list= frame parameter.
- =tabspaces= (see =sp-tabs=) builds the workspace buffer list from that parameter, so =consult-buffer= in a new frame offered almost nothing.
- The built-in =switch-to-prev-buffer= machinery reads the same parameters (=buffer-list= and =buried-buffer-list=).
- Fix: when a frame is made, copy the lists into it.

** Option and group

#+begin_src emacs-lisp -i
;;;;; Share the buffer list between frames
;; A new frame starts with an empty `buffer-list' frame parameter.  `tabspaces'
;; (sp-tabs) lists a workspace's buffers from that parameter, so `consult-buffer'
;; in a new frame showed almost nothing.

(defgroup sp-frame-share-buffers nil
  "Give new frames the buffer list of an existing frame."
  :group 'frames)
#+end_src

- =sp-frame-share-buffers-scope= chooses what a new frame gets:
  - =selected= (default): the lists of the frame that was selected before =make-frame=, so the new frame is in the same workspace.
  - =all=: every live buffer whose name does not start with a space, with an empty buried list.

#+begin_src emacs-lisp -i
(defcustom sp-frame-share-buffers-scope 'selected
  "Which buffers a new frame gets in its buffer list.
`selected' copies the buffer list of the frame that was selected before
the new frame was made.  `all' uses every live buffer whose name does
not start with a space."
  :type '(choice (const :tag "Buffers of the previously selected frame" selected)
                 (const :tag "All live buffers" all)))
#+end_src

** Helpers

- =sp-frame-share-buffers--source= is set by =before-make-frame-hook= to the frame selected before =make-frame=.
  - In =after-make-frame-functions= the new frame is already the selected one, so the previous frame cannot be read from there.
- =sp-frame-share-buffers--live= drops killed buffers and duplicates.
- =sp-frame-share-buffers--eligible-p= skips:
  - child frames (frames with a =parent-frame= parameter, for example posframes),
  - frames with the =sp-no-share-buffers= parameter set, an escape hatch for any frame that must stay isolated.

#+begin_src emacs-lisp -i
(defvar sp-frame-share-buffers--source nil
  "Frame that was selected just before the latest `make-frame'.")

(defun sp-frame-share-buffers--live (buffers)
  "Return the live buffers of BUFFERS, without duplicates."
  (delete-dups (seq-filter #'buffer-live-p buffers)))

(defun sp-frame-share-buffers--eligible-p (frame)
  "Return non-nil if FRAME should receive a shared buffer list.
Child frames (posframe and similar) and frames with the
`sp-no-share-buffers' parameter are left alone."
  (and (frame-live-p frame)
       (not (frame-parameter frame 'parent-frame))
       (not (frame-parameter frame 'sp-no-share-buffers))))

(defun sp-frame-share-buffers--remember-source ()
  "Remember the selected frame before a new frame is made."
  (setq sp-frame-share-buffers--source (selected-frame)))
#+end_src

** Copying the lists

- =sp-frame-share-buffers-into= sets =buffer-list= and =buried-buffer-list= on FRAME.
  - SOURCE defaults to the remembered frame, then to the first other eligible frame (for example when a daemon makes a frame with nothing selected).
  - It does nothing when no source frame exists, such as the very first frame.
- =sp-frame-share-buffers--after-make= wraps it in =condition-case=, so a failure only prints a message and never breaks =make-frame=.
- =sp-frame-share-buffers-now= is an interactive command: it copies another frame's lists into the selected frame, for a frame that was made before the mode was on.

#+begin_src emacs-lisp -i
(defun sp-frame-share-buffers-into (frame &optional source)
  "Set the buffer lists of FRAME from SOURCE, per `sp-frame-share-buffers-scope'.
SOURCE defaults to the frame remembered before the latest `make-frame',
or else the first other frame."
  (when-let* (((sp-frame-share-buffers--eligible-p frame))
              (source (or (and (frame-live-p source) source)
                          (and (frame-live-p sp-frame-share-buffers--source)
                               (not (eq sp-frame-share-buffers--source frame))
                               sp-frame-share-buffers--source)
                          (seq-find (lambda (f) (and (not (eq f frame))
                                                     (sp-frame-share-buffers--eligible-p f)))
                                    (frame-list)))))
    (pcase sp-frame-share-buffers-scope
      ('all
       (set-frame-parameter
        frame 'buffer-list
        (seq-remove (lambda (b) (string-prefix-p " " (buffer-name b)))
                    (sp-frame-share-buffers--live (buffer-list))))
       (set-frame-parameter frame 'buried-buffer-list nil))
      (_
       (set-frame-parameter
        frame 'buffer-list
        (sp-frame-share-buffers--live (frame-parameter source 'buffer-list)))
       (set-frame-parameter
        frame 'buried-buffer-list
        (sp-frame-share-buffers--live (frame-parameter source 'buried-buffer-list)))))))

(defun sp-frame-share-buffers--after-make (frame)
  "Share the buffer list into the new FRAME; never signal an error."
  (condition-case err
      (sp-frame-share-buffers-into frame)
    (error (message "sp-frame-share-buffers: %s" (error-message-string err)))))

(defun sp-frame-share-buffers-now ()
  "Share the buffer list of another frame into the selected frame."
  (interactive)
  (sp-frame-share-buffers-into (selected-frame)))
#+end_src

** Minor mode

- =sp-frame-share-buffers-mode= is global and on by default.
- It adds the two hooks when enabled and removes them when disabled.
- It applies to every new frame, whoever made it:
  - frames made by code, such as the =vulpea-ui-view= frame (=sp-vulpea-ui-view=), call =make-frame= and so run the same hooks,
  - frames made by =emacsclient= or by an AeroSpace-tiled window run them too.
- The frame still keeps its own lists afterwards: buffers selected later in one frame are not copied to the others.

#+begin_src emacs-lisp -i
(define-minor-mode sp-frame-share-buffers-mode
  "Give every new frame the buffer list of an existing frame.
Frames made by code, such as the vulpea-ui view frame, count too."
  :global t
  :group 'sp-frame-share-buffers
  (if sp-frame-share-buffers-mode
      (progn
        (add-hook 'before-make-frame-hook #'sp-frame-share-buffers--remember-source)
        (add-hook 'after-make-frame-functions #'sp-frame-share-buffers--after-make))
    (remove-hook 'before-make-frame-hook #'sp-frame-share-buffers--remember-source)
    (remove-hook 'after-make-frame-functions #'sp-frame-share-buffers--after-make)))

(sp-frame-share-buffers-mode 1)
#+end_src
