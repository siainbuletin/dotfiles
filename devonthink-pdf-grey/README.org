#+title: devonthink-pdf-grey: set the grey of DEVONthink's PDF background

=dt-pdf-grey= changes the hidden =PDFBackground= preference of DEVONthink 4, reversibly. macOS only.

* Why a script

- DEVONthink has no setting in its preferences window for the colour behind a PDF page.
- The value lives in the preferences domain =com.devon-technologies.think=.
- On Sia's Mac it reads as a mid grey: red = green = blue = 0.4246723651885986, alpha 1, colour space =NSCalibratedRGBColorSpace=.

* Setting up

- =cd ~/dotfiles && stow devonthink-pdf-grey= links =~/.local/bin/dt-pdf-grey=.
- =~/.local/bin= must be on =PATH=.
- =stow-migration/packages.tsv= lists the package as =darwin=, so =migrate.sh= does not stow it on Linux.
- This README stays out of =$HOME= (=.stow-local-ignore=).

* Usage

- =dt-pdf-grey 0.3=: grey level from 0 (black) to 1 (white).
- =dt-pdf-grey dark=: a preset. =charcoal= 0.20, =dark= 0.30, =mid= 0.425 (about the current value), =light= 0.60.
- =dt-pdf-grey --reset=: puts back the values saved before the first change.
- =dt-pdf-grey --show=: prints the current values and the saved original. Safe while DEVONthink runs.
- =--quit=: quits DEVONthink first (asks it to quit; stops if it stays open).
- =--relaunch=: opens DEVONthink afterwards.
- =--disable-pdf-dark-mode=: also writes =DisablePDFDarkMode=true= (see below).
- =--dry-run=: prints the =defaults= commands and changes nothing.

* Safety

- Without =--quit= the script refuses while DEVONthink is open. DEVONthink rewrites its preferences when it quits, so a change made while it runs is lost.
- The original =PDFBackground= and =DisablePDFDarkMode= values are saved once in =~/.local/state/dt-pdf-grey/original=, before the first change. Later changes do not overwrite them.
- =--reset= restores them (or deletes the key if it did not exist) and removes the saved file.
- Nothing else in the preferences is touched.

* What is not verified

- Claude could not run DEVONthink: the script was only tested on Linux with stubbed =defaults=, =plutil= and =pgrep=.
- It is not known whether =PDFBackground= is the colour used in dark mode, in light mode, or in both. The related keys =FormViewBackground= and =FormViewBackgroundDark= suggest DEVONthink may keep separate light and dark values, but no =PDFBackgroundDark= key was seen.
- It is not known whether DEVONthink reads this dict with string components (as stored now) without a restart beyond the quit.
- =DisablePDFDarkMode= (from a public note, [[https://github.com/gavischneider/til/blob/main/devonthink/turn-pdf-color-inversion-off.md][gavischneider/til]]) turns off forced PDF inversion. It may be needed so the grey is not inverted; try the grey alone first.

* Confirm which key the GUI uses

- Quit DEVONthink, then =defaults read com.devon-technologies.think > /tmp/before.txt=.
- Open DEVONthink, switch the appearance (light/dark) or change the PDF-related setting in the GUI, quit it.
- =defaults read com.devon-technologies.think > /tmp/after.txt=, then =diff /tmp/before.txt /tmp/after.txt=.
- If a different key (for example one ending in =Dark=) changes, tell Claude: the script should write that key.
- If nothing changes, check the effect directly: =dt-pdf-grey --quit --relaunch 0.2= and open a PDF.
