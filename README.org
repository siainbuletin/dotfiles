* Sia's Arch Linux dotfiles

These are meant to possibly be replicated across different flavours of Arch Linux. As of December 2nd, 2025, I am using basic Arch Linux on my Legion laptop (which is mostly used at home) and EndeavourOS in a duaboot on a Thinkpad E14.

** Future possinle improvements

We'll see in the future if they can be subject to a move towards NixOS or even GNU Guix in the future.

** General notes

Most of my operating system needs revolve around Emacs. Although there's a regular =.emacs.d/= directory at the top level, my actual individual configurations live in =.config=. This is because I'm using different configuration profiles for Emacs, through the use of Chemacs2. See my literate configuration for Emacs for more details.

All of the existing configurations and their names (so you can start with Emacs with the proper flair in the terminal, as ~emacs --with-profile=<name>~ can be found declared in ~.emacs.profiles.el~ in the top directory.

** Required software to install

All names for the software are listed as they can be found either in the official Arch Linux repository or in the AUR. All may be downloadable through =pacman= or =paru= (prefered AUR helper in this case).

More necessary software to install will probably be self explanatory from the directories that exist in these dotfiles

*** Necessary for functioning
- git
- github-cli
- paru (my prefered AUR helper)

Copy paste this command if you want to make the installation faster for all of these dependencies.

#+BEGIN_SRC
sudo pacman -S git github-cli paru
#+END_SRC

*** General applications
- alacritty
- emacs (could be running in both the native Wayland version or Xwayland, depending on the case)
- recoll
- qutebrowser

*** Window manager configurations
- i3-wm
- stumpwm
- swaywm

Most of the configurations done for KDE Plasma actually live in .gitignore, as I don't yet know how to properly manage all of this without creating some really big conflicts.

** Installation instructions

*** ARCHVED: Installing via GNU Stow

Clone the directory of dotfiles into the $HOME directory with git. (I usually prefer to use GitHub through the CLI for authentication when setting the remote origin). Then, authenticate using HTTPS:

#+BEGIN_SRC
git clone https://github.com/siainbuletin/dotfiles.git
cd dotfiles
#+END_SRC

Then, in order to create symlinks, you need to use GNU Stow.

#BEGIN_SRC
stow .
#END_SRC

If you happen to be creating a symlink for a directory that already exists, you can choose to overwrite the existing repository by using the =--adopt= flag. This will tell Stow to move any of the conflicting files into the dotfiles directory.

#BEGIN_SRC shell
stow --adopt .
#END_SRC
