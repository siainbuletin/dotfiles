** General notes

Most of my operating system needs revolve around Emacs. Although there's a regular =.emacs.d/= directory at the top level, my actual individual configurations live in =.config=. This is because I'm using different configuration profiles for Emacs, through the use of Chemacs2. See my literate configuration for Emacs for more details: [[file:.config/emacs-modular/README.org][.config/emacs-modular/README.org]] describes the modular configuration and how to tangle its literate sources, and [[file:.config/emacs-modular/docs/main.org][.config/emacs-modular/docs/main.org]] is its root document, with a tree of all the modules.

All of the existing configurations and their names (so you can start with Emacs with the proper flair in the terminal, as ~emacs --with-profile=<name>~ can be found declared in ~.emacs.profiles.el~ in the top directory.

** Installation instructions

*** ARCHVED: Installing via GNU Stow

Clone the directory of dotfiles into the $HOME directory with git. (I usually prefer to use GitHub through the CLI for authentication when setting the remote origin). Then, authenticate using HTTPS:

#+BEGIN_SRC
git clone https://github.com/siainbuletin/dotfiles.git
cd dotfiles
#+END_SRC

Then, in order to create symlinks, you need to use GNU Stow.

#BEGIN_SRC
stow .
#END_SRC

If you happen to be creating a symlink for a directory that already exists, you can choose to overwrite the existing repository by using the =--adopt= flag. This will tell Stow to move any of the conflicting files into the dotfiles directory.

#BEGIN_SRC shell
stow --adopt .
#END_SRC
