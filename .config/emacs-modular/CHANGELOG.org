#+title: Changelog
#+startup: overview
            
Changes to the Emacs configuration, one entry per pull request. Entries are
grouped by merge date, newest first, using the Keep a Changelog categories
(Added, Changed, Fixed, Removed). Paths are relative to this folder. Long
lists of files sit in a sub-list under their entry: press =TAB= on the entry
to fold or unfold it.
