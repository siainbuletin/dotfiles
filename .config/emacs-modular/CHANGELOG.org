#+title: Changelog
#+startup: overview

Changes to the Emacs configuration, one entry per pull request. Entries are
grouped by merge date, newest first, using the Keep a Changelog categories
(Added, Changed, Fixed, Removed). Paths are relative to this folder. Long
lists of files sit in a sub-list under their entry: press =TAB= on the entry
to fold or unfold it.

* Open pull requests
** Added
- =sp-dg-positions=: an outline, a Graphviz graph, a view per status (=M-x dg-positions-status=), a gaps view and a check view for the positions in discourse-graphs, driven by one readable rule list, =dg-positions-rules=, where a new relation such as =contests= is one line. New doc =docs/tangles/research-question-states.org= says which state every research question, claim and reading task should be in; the old single =CONTESTED= state is replaced by a computed status on each answer. ([[https://github.com/siainbuletin/dotfiles/pull/12][#12]], Claude)

* 2026-10-20
** Added

** Changed
- Every module doc in =docs/tangles/= now sits in the subdirectory that matches its module's place in =libraries/modules/=, next to its =-old.org= predecessor. * 2026-10-19
** Added
- A literate =sp-*.org= doc in =docs/tangles/= for every module in =libraries/modules/= (127 modules, =cloned/= excluded). Each holds the module's full source with prose for every block, and tangling it (=C-c C-v t=) regenerates the module. The five empty modules (=sp-syslinux=, =sp-instant-messenger=, =sp-mail=, =sp-music-comp=, =sp-vulpea-ext-back=) get skeleton docs. ([[https://github.com/siainbuletin/dotfiles/pull/2][#2]], Claude)
- =sp-org-issues=: an issue tracker kept as a vulpea-para "Issues" area with one heading per repository. =C-c c I= files an issue, =C-c o a i i= shows the issue board, and =M-x sp-org-issues-start= gives an issue its own git worktree under =~/src/dotfiles-wt/=. ([[https://github.com/siainbuletin/dotfiles/pull/3][#3]], Claude)
- =sp-treemacs=: =<f9>= toggles a treemacs side window rooted at the emacs-modular folder. ([[https://github.com/siainbuletin/dotfiles/pull/4][#4]], Claude)
- A =libraries/modules/custom/= directory for bespoke modules, now holding =sp-trails=, =sp-vc-ai-workbench= and =sp-vulpea-hierarchy=, with its own section in the module tree of =docs/main.org=. ([[https://github.com/siainbuletin/dotfiles/pull/8][#8]], Claude)
