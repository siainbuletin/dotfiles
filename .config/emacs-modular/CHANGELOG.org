#+title: Changelog
#+startup: overview

Changes to the Emacs configuration, grouped by the feature they build or fix. Within a set the pull requests follow the order they depend on each other, the base first. For the reason behind a change, open the pull request or the decision record linked from the set. Paths are relative to this folder. Each line starts with what happened (Added, Changed, Fixed, Removed); the category headings are not repeated.

* Open pull requests
- Added the =sp= themes, =sp-dark= (a simplified =ef-dream= palette) and =sp-light=, from the new =sp-theme-engine=: base colours in a =catppuccin-set-color=-style flavors alist, the Doric palette and faces from Doric's bundles instead of hex codes, Modus-style semantic mappings, Lambda-style semantic face names (=sp-urgent= and the others), and the Modus headings, mixed fonts and variable-pitch UI ported. Changed =sp-themes= to read every theme file into one registry (name, background, description, package) and to follow the light or dark appearance through one switch, =sp-theme-auto-mode= (macOS setting or time of day), which =sp-macos= turns on and which replaces its own code. Removed the colour-blind themes. 19 ERT tests. ([[https://github.com/siainbuletin/dotfiles/pull/97][#97]], Claude)
- Changed the themes to be vendored in =libraries/themes/= (engines in =lib/=, the seven themes in use in =active/=, all others in =library/=, no Elpaca), grouped in four families (hard light, faded light, faded dark, hard dark) and loaded only by =sp-load-theme=: no confirmation, the old theme is disabled only after the new one loads, =T= loads a family. Removed =lem-dashboard=, =sp-archived-configs.el=, the dead Modus options and the theme-resetting =sp-disable-all-themes=; =sp-macos=, the toggle and the dashboard logo go through =sp-themes=. Added a list of the Modus faces a palette-only system would leave out. ([[https://github.com/siainbuletin/dotfiles/pull/89][#89]], Claude)
- Changed the BibTeX setup in =sp-academic=, =sp-bibprocess= and =sp-citations=: one citation-key scheme (=smith-2017-atten-is=) set once, one registered list of =.bib= files for Org, Citar, org-ref and helm-bibtex, Citar's library, notes and icons options now applied, and the repeated definitions removed. ([[https://github.com/siainbuletin/dotfiles/pull/90][#90]], Claude)
- Added =sp-typst=: a PDF of the literate docs through =ox-typst= and Typst. ([[https://github.com/siainbuletin/dotfiles/pull/79][#79]], Claude)
- Changed the package options that sat in =setq= forms next to a =use-package= into its =:custom= block, in 14 modules and their docs; the options of built-in features and of packages declared elsewhere stay as they were. ([[https://github.com/siainbuletin/dotfiles/pull/86][#86]], Claude)

* Testing pull requests in a sandbox: =emacs-pr=
/2026-10-21 to 2026-10-23./ The fish function =emacs-pr N= builds a sandboxed Emacs from the PR's ref alone: a detached worktree, its own packages and a copy of the notes. A proposed =sp-reload= would bring a running Emacs up to date with the modules that changed in git. The decisions are in [[file:../../adr/0018-emacs-pr-sandbox-and-reload.org][ADR 0018]], [[file:../../adr/0007-emacs-tooling-for-pr-review.org][ADR 0007]].

- Added =emacs-pr=, which fetches =pull/N/head= into a worktree and starts a second Emacs on it with a throwaway =HOME=. ([[https://github.com/siainbuletin/dotfiles/pull/24][#24]], Claude)
- Changed each sandbox to have its own packages and notes so several can run at once, and added =sp-sandbox= to start them from Emacs. ([[https://github.com/siainbuletin/dotfiles/pull/26][#26]], Claude)
- Added =emacs-pr --help=. ([[https://github.com/siainbuletin/dotfiles/pull/27][#27]], Claude)
- Added the =run-emacs-modular= skill for headless module checks. ([[https://github.com/siainbuletin/dotfiles/pull/42][#42]], Claude)
- Proposed =sp-reload=, not in the repository yet: =M-x sp-reload-changed= reloads the modules that differ from the last synchronised revision (see [[file:../../adr/0018-emacs-pr-sandbox-and-reload.org][ADR 0018]]).
