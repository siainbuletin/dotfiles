#+title: Changelog
#+startup: overview

Changes to the Emacs configuration, grouped by the feature they build or fix. Within a set the pull requests follow the order they depend on each other, the base first. For the reason behind a change, open the pull request or the decision record linked from the set. Paths are relative to this folder. Each line starts with its pull request number, then the author, then what happened: ✨ Added, 🔧 Changed, 🐛 Fixed, 🔥 Removed, 💡 Proposed; the category headings are not repeated.

A proposed =sp-reload= would bring a running Emacs up to date with the modules that changed in git. The decisions are in [[file:../../adr/0018-emacs-pr-sandbox-and-reload.org][ADR 0018]], [[file:../../adr/0007-emacs-tooling-for-pr-review.org][ADR 0007]].

- [[https://github.com/siainbuletin/dotfiles/pull/24][#24]] (Claude) ✨ Added =emacs-pr=, which fetches =pull/N/head= into a worktree and starts a second Emacs on it with a throwaway =HOME=.
- [[https://github.com/siainbuletin/dotfiles/pull/26][#26]] (Claude) 🔧 Changed each sandbox to have its own packages and notes so several can run at once, and added =sp-sandbox= to start them from Emacs.
- [[https://github.com/siainbuletin/dotfiles/pull/27][#27]] (Claude) ✨ Added =emacs-pr --help=.
- [[https://github.com/siainbuletin/dotfiles/pull/42][#42]] (Claude) ✨ Added the =run-emacs-modular= skill for headless module checks.
