#+title: Changelog
#+startup: overview
            
Changes to the Emacs configuration, one entry per pull request. Entries are
grouped by merge date, newest first, using the Keep a Changelog categories
(Added, Changed, Fixed, Removed). Paths are relative to this folder. Long
lists of files sit in a sub-list under their entry: press =TAB= on the entry
to fold or unfold it.

* Open pull requests
** Agenda and capture

** Reviewing merges in Magit
- =sp-merge-pick=, a new module in =libraries/modules/prog/=: =C-x C-SPC g m= opens a graph log of every branch (git's lanes drawn with unicode glyphs, coloured by Magit), where =C-c v i= marks the commit at point as INTO and =C-c v f= another as FROM. From the two marks =C-c v p= previews the merge in memory (=git merge-tree=) and lists the files that would conflict, =C-c v d= shows what FROM adds, =C-c v e= (or =RET= on a conflicting file in the preview) opens a three-way Ediff of INTO, FROM and their merge base, and =C-c v n= starts a =--no-commit= merge for the usual Magit, Ediff and Smerge resolution. Only the last command changes the worktree, and it asks first. Run in a headless Emacs 29 with Magit; the Ediff session and the drawing in a real frame were not tried. ([[https://github.com/siainbuletin/dotfiles/pull/68][#68]], Claude)
