#+TITLE: Vendored themes

Every theme of this configuration lives here, copied from the upstream packages; nothing is installed by Elpaca. Themes are loaded with =sp-load-theme= (=sp-themes.el=, [[file:../../docs/tangles/ui/sp-themes.org][docs]]). The reasons for the layout are in [[file:../../docs/architecture/theme-system-design.org][theme-system-design.org]].

| Folder | Holds |
|-+-|
| =lib/= | The theme engines, on =load-path=: =modus-themes.el=, =ef-themes.el=, =doric-themes.el=, =lambda-themes.el=. Ef needs Modus, and every theme file of a package requires its engine. |
| =active/= | The theme files in use (7). The families in =sp-theme-families= name these. |
| =library/= | Every other theme of the packages, one folder per package, to try palettes out with =M-x sp-load-theme=. To use one, copy its file to =active/= and add it to a family. |
| =sp/= | Themes written for this configuration (none yet). |
