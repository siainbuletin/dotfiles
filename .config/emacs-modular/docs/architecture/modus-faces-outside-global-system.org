#+TITLE: Modus faces that a global face system would leave out
#+STARTUP: content

Sia's plan is a theme system where a theme is only a palette and the faces are defined once, globally, in the style of =doric-themes= (see [[file:theme-system-design.org][theme-system-design.org]]). This note lists what such a system would not cover, so each item can be re-added by hand (as a bundle, a palette entry or an override) or dropped on purpose. It is a list only: nothing here is implemented.

Method: the face names in =modus-themes-faces= (Modus 5.3.0, 2,382 names) were compared with every face that =doric-themes= 1.3.0 sets, either in =doric-themes-define-theme= or in one of its bundles (1,306 names). 1,145 faces are in both, and *1237 faces are only in Modus*. (The earlier note's "about 225 faces" for Doric counted only the macro; most of Doric's faces sit in the bundles.) Face names are matched exactly, so a package that both themes cover under different names shows up here too.

* Modus mechanisms that are not faces

These are the adjustments a palette-only system loses even if every face is covered.

| Mechanism | What it does | Palette-only replacement |
|-+-+-|
| =modus-themes-italic-constructs=, =-bold-constructs= | Italic or bold for comments, keywords, prompts and completion matches | One global option read by the face bundles (Doric has italic and bold bundles) |
| =modus-themes-mixed-fonts= | Keeps code, tables and Org markup fixed-pitch inside variable-pitch buffers | A bundle of fixed-pitch faces; the only one Sia sets that is not a colour |
| =modus-themes-variable-pitch-ui= | Variable-pitch mode line, tab bar, header line | A bundle of the UI faces |
| =modus-themes-headings= | Per-level height, weight and variable pitch for Org, Markdown, Outline, Info and agenda headings, plus commit summary | An alist of heading level to face attributes, applied to the heading faces of all those modes |
| =modus-themes-common-palette-overrides=, =modus-NAME-palette-overrides=, =modus-themes-common-palette-user= | Override named colours or semantic mappings, per theme or for all | Part of the new palette layer |
| =modus-themes-preset-overrides-faint=, =-intense=, =-cooler=, =-warmer= | Four ready-made override lists | Personal presets, only if wanted |
| Semantic mappings (about 94 shared, such as =bg-region=, =fg-heading-1=, =bg-search-current=) | A face asks for a role, not a colour | The roles Doric already has (shadow, neutral, accent primary and secondary, six hues, each with a foreground and a background) |
| Colour-blind variants (=deuteranopia=, =tritanopia=) | Different palette and a few faces (=modus-themes-faces-deuteranopia=, =-tritanopia=) | None needed unless wanted; Ef has its own deuteranopia themes |
| =modus-themes-with-colors= | Binds the palette names while writing faces | =doric-themes-with-colors= |
| =modus-themes-completions=, =-prompts=, =-org-blocks= | Obsolete or removed in 5.3.0 | Dropped |
