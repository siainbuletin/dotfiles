Literate source for =libraries/modules/prog/sp-latex.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module sets up LaTeX editing with AUCTeX, RefTeX, preview and latexmk, configures Org's LaTeX exporter to compile with XeLaTeX through latexmk, and adds a few spelling, indentation and BibTeX tweaks. It is listed in the =plus-programming= profile in =sp-config-profiles.el=.

Packages involved are =auctex=, =auctex-latexmk=, =company-auctex=, =org-pandoc-import= (fetched from GitHub), and the built-in =preview=, =reftex=, =bibtex=, =ox-latex= and =align=. External programs: a TeX distribution with =latexmk=, =xelatex=, =luatex= and =dvipdfmx=. The setup hook also uses =company= and =rainbow-delimiters=.

The file has grown by accretion and has a few rough edges worth knowing: the =auctex=, =preview= and =reftex= =use-package= forms appear twice, the TeX engine is set to XeTeX by default but to LuaTeX by the setup hook, =org-latex-listings= is set twice, and the file ends without =(provide 'sp-latex)=. Since the loader uses =require=, loading this module will run all its code but then report the feature as not provided, so it shows as =[FAILED]= in the module log.

** Per-buffer LaTeX setup

=sia/latex-setup= runs in every =TeX-mode= buffer (see the =latex= block below). It turns on RefTeX, hooks in =auctex-latexmk=, switches the engine to LuaTeX, enables multi-level script fontification, PDF output, source correlation (SyncTeX), =TeX-fold-mode= and rainbow delimiters, and gives the buffer a local =company-backends= of =company-auctex= and =company-files= before starting =company-mode=.

#+begin_src emacs-lisp -i
(defun sia/latex-setup ()
  "Setup the latex environment"
  (reftex-mode t)
  (auctex-latexmk-setup)
  (TeX-engine-set "luatex")
  (setq font-latex-fontify-script 'multi-level)
  (setq TeX-PDF-mode t)
  (setq TeX-source-correlate-mode t)
  (TeX-fold-mode 1)
  (rainbow-delimiters-mode t)
  (make-local-variable 'company-backends)
  (setq company-backends '(company-auctex
                           company-files))
  (company-auctex-init)
  (company-mode t))
#+end_src

** Run latexmk

=sia/latexmk-run= saves the document without asking and runs latexmk synchronously on the master file. If the run reports errors it jumps to the first one with =TeX-next-error=, otherwise it shows "latexmk-done". It is bound to =F5= in =TeX-mode-map=.

#+begin_src emacs-lisp -i
(defun sia/latexmk-run ()
  "Run latexmk on the master file"
  (interactive)
  (let ((TeX-save-query nil)
        (TeX-process-asynchronous nil)
        (master-file (TeX-master-file)))
    (TeX-save-document "")
    (TeX-run-TeX "latexmk" "latexmk" master-file)
    (if (plist-get TeX-error-report-switches (intern master-file))
        (TeX-next-error)
      (minibuffer-message "latexmk-done"))))
#+end_src

** AUCTeX

Installs AUCTeX and opens =.tex= and =.latex= files in =latex-mode=. On LaTeX buffers it enables preview, Flyspell and RefTeX. It defaults the engine to XeTeX, turns off auto-save and self-parsing of style information, skips the save prompt before compiling, enables PDF mode, and leaves =TeX-master= nil so AUCTeX asks for the master file. This block is unconditional; a guarded duplicate appears later.

#+begin_src emacs-lisp -i
(use-package auctex
  :ensure t
  :mode (("\\.tex\\'" . latex-mode)
         ("\\.latex\\'" . latex-mode))
  :commands (latex-mode LaTeX-mode plain-tex-mode)
  :init
  (progn
    (add-hook 'LaTeX-mode-hook #'LaTeX-preview-setup)
    (add-hook 'LaTeX-mode-hook #'flyspell-mode)
    (add-hook 'LaTeX-mode-hook #'turn-on-reftex)
    (setq-default TeX-engine 'xetex)
    (setq TeX-auto-save nil
          TeX-parse-self nil
          TeX-save-query nil
          TeX-PDF-mode t)
    (setq-default TeX-master nil)))
#+end_src

** TeX mode bindings and Org LaTeX export

The =latex= block runs =sia/latex-setup= from =TeX-mode-hook= and binds =F5= to =sia/latexmk-run=, =TAB= to =company-indent-or-complete-common= and =F1= to =company-show-doc-buffer= in =TeX-mode-map=. After AUCTeX loads it loads =latex-compile-on-save.el=, which defines a minor mode that compiles on every save; that file lives in the config root, so the load only works if that directory is on the load path.

The same unit then sets Org export to use =xelatex= and builds =org-latex-pdf-process= as a single latexmk call with the recorder, SyncTeX and conditional BibTeX.

#+begin_src emacs-lisp -i
(use-package latex
  :ensure nil
  :defer t
  :hook (TeX-mode . sia/latex-setup)
  :bind (:map TeX-mode-map
              ([f5] . sia/latexmk-run)
              ([tab] . company-indent-or-complete-common)
              ([f1] . company-show-doc-buffer))
  :config
  (load "latex-compile-on-save.el"))



(setq org-latex-compiler "xelatex")
(setq org-latex-pdf-process
      (list (concat "latexmk -"
                    org-latex-compiler
                    " -recorder -synctex=1 -bibtex-cond %b")))
#+end_src

** Plain article class

* Supporting LaTeX packages

** Preview

Configures AUCTeX's =preview= after AUCTeX loads, with a scale of 1.4 relative to the document font size. =LaTeX-preview-setup= is the command the AUCTeX hook calls.

#+begin_src emacs-lisp -i
;;;; Latex Packages
;; Basic settings


(use-package preview
  :ensure nil
  :after auctex
  :commands LaTeX-preview-setup
  :init
  (progn
    (setq-default preview-scale 1.4
                  preview-scale-function '(lambda () (* (/ 10.0 (preview-document-pt)) preview-scale)))))
#+end_src

** BibTeX and auto-fill

Opens =.bib= files in =bibtex-mode= with fields aligned at the equals sign and a fill column of 120. =lem-latex-auto-fill= turns on auto-fill at 80 columns with left justification in LaTeX buffers.

#+begin_src emacs-lisp -i
(use-package bibtex
  :ensure nil
  :defer t
  :mode ("\\.bib" . bibtex-mode)
  :init
  (progn
    (setq bibtex-align-at-equal-sign t)
    (add-hook 'bibtex-mode-hook (lambda () (set-fill-column 120)))))


;; Auto-fill for LaTeX
(defun lem-latex-auto-fill ()
  "Turn on auto-fill for LaTeX mode."
  (turn-on-auto-fill)
  (set-fill-column 80)
  (setq default-justification 'left))
(add-hook 'LaTeX-mode-hook #'lem-latex-auto-fill)
#+end_src

** Spell-check exclusions

Tells ispell to skip the arguments of common reference and metadata commands such as =\cite=, =\ref=, =\label= and =\includegraphics=, by appending them to the first list in =ispell-tex-skip-alists=.

#+begin_src emacs-lisp -i
;; Prevent ispell from verifying some LaTeX commands
;; http://stat.genopole.cnrs.fr/dw/~jchiquet/fr/latex/emacslatex
(defvar lem-ispell-tex-skip-alists
  '("cite" "nocite"
    "includegraphics"
    "author" "affil"
    "ref" "eqref" "pageref"
    "label"))
(setq ispell-tex-skip-alists
      (list
       (append (car ispell-tex-skip-alists)
               (mapcar #'(lambda (cmd) (list (concat "\\\\" cmd) 'ispell-tex-arg-end)) lem-ispell-tex-skip-alists))
       (cadr ispell-tex-skip-alists)))
#+end_src

** Aligned indentation in tabular

In LaTeX buffers, makes =tabular= and =tabular*= environments indent with =align-current=, so cells line up on =&= when the environment is re-indented.

#+begin_src emacs-lisp -i
;; Indentation with align-current in LaTeX environments
(defvar lem-LaTeX-align-environments '("tabular" "tabular*"))
(add-hook 'LaTeX-mode-hook
          (lambda ()
            (require 'align)
            (setq LaTeX-indent-environment-list
                  ;; For each item in the list...
                  (mapcar (lambda (item)
                            ;; The car is an environment
                            (let ((env (car item)))
                              ;; If this environment is in our list...
                              (if (member env lem-LaTeX-align-environments)
                                  ;; ...then replace this item with a correct one
                                  (list env 'align-current)
                                ;; else leave it alone
                                item)))
                          LaTeX-indent-environment-list))))
#+end_src

** SyncTeX helper

=synctex/un-urlify= strips a =file://= prefix from a path. It is a leftover from an EmacsWiki SyncTeX recipe and is not used elsewhere in the module. The file ends here with no =provide= form.

#+begin_src emacs-lisp -i
;; SyncTeX (http://www.emacswiki.org/emacs/AUCTeX#toc19)
(defun synctex/un-urlify (fname-or-url)
  "A trivial function that replaces a prefix of file:/// with just /."
  (if (string= (substring fname-or-url 0 8) "file:///")
      (substring fname-or-url 7)
    fname-or-url))
#+end_src
