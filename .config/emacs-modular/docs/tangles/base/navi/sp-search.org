This navigation sub-module, loaded by =sp-navi=, installs the search packages: Consult and Counsel for in-buffer and project search, front-ends for =ag= and =rg=, Deadgrep, and =p-search=. It also adds a directory-prompting ripgrep command, a Counsel-based search over a Recoll full-text index, and =sp-search-menu=, a results buffer with a transient menu on top (=C-c s m=) that gathers all of these and the semantic and note searches of other modules.

External programs used are =rg= (ripgrep), =ag= (the silver searcher) and =recollq= from Recoll. The commentary sketches future plans to tie search into =sp-browsing= and Embark; those plans are not implemented here.

** Recoll query function

=counsel-recoll-function= runs =recollq -b= on the input asynchronously, once at least three characters have been typed, returning matching file URLs.

- The search string is placed inside single quotes on the shell command line, so a query containing a quote breaks it.
- It calls =counsel-more-chars=, which newer Counsel releases have replaced with =ivy-more-chars=. It may need updating.

#+begin_src emacs-lisp -i
;; More advanced searching

(defun counsel-recoll-function (string &rest _unused)
  "Issue recallq for STRING."
  (if (< (length string) 3)
      (counsel-more-chars 3)
    (counsel--async-command
     (format "recollq -b '%s'" string))
    nil))
#+end_src

** Recoll search command

=counsel-recoll= searches the Recoll index with Ivy and opens the selected file.

- For non-PDF files it then starts =swiper= with the same query, so you land on the matches inside the file.
- It reuses =counsel-git-grep-history= as its history.

#+begin_src emacs-lisp -i
(defun counsel-recoll (&optional initial-input)
  "Search for a string in the recoll database.
You'll be given a list of files that match.
Selecting a file will launch `swiper' for that file.
INITIAL-INPUT can be given as the initial minibuffer input."
  (interactive)
  (ivy-read "recoll: " 'counsel-recoll-function
            :initial-input initial-input
            :dynamic-collection t
            :history 'counsel-git-grep-history
            :action (lambda (x)
                      (when (string-match "file://\\(.*\\)\\'" x)
                        (let ((file-name (match-string 1 x)))
                          (find-file file-name)
                          (unless (string-match "pdf$" x)
                            (swiper ivy-text)))))))
#+end_src

* The search menu

=M-x sp-search= (=C-c s m=) is the entry point. It shows a Magit-style buffer, =*sp-search*=, as the first screen, and opens the transient menu =sp-search-menu= at the top of the frame over it. The buffer has a header (the search directory and project, which completion frameworks are active in green, a warning if =rg= is missing), the current search with its results grouped by file, and the list of saved views. The menu gathers every search command of the configuration; closing it leaves the buffer, and =?= opens it again.

Commands from packages that may be missing are listed with an =:if= test on =fboundp=, so the menu never offers a key that would fail. Nothing in the menu needs a package that the configuration does not already install.

** Keys in the buffer

| Key   | Command                    | What it does                                                         |
|-------+----------------------------+----------------------------------------------------------------------|
| =?=   | =sp-search-menu=           | Open the menu at the top.                                            |
| =s=   | =sp-search-grep=           | New ripgrep search; =C-u= also asks for directory, glob, case, regexp. |
| =g=   | =sp-search-rerun=          | Run the search again.                                                |
| =m= / =u= | =sp-search-mark= / =sp-search-unmark= | Mark or unmark the match at point.                          |
| =M= / =U= | =sp-search-mark-all= / =sp-search-unmark-all= | Mark or unmark every match.                         |
| =x=   | =sp-search-export=         | Export the marked matches (all if none) to a saved view.             |
| =RET= | =sp-search-visit=          | Visit the match at point, or run the saved view at point.            |
| =V= / =O= | =sp-search-run-view= / =sp-search-open-view= | Run or open a saved view.                          |

** Saved views

A saved view is an Org file in =sp-search-views-dir= (default: =search-views/= in =sp-notes-dir=), named =YYYYMMDD-query.org=. Nothing is stored in Lisp. It looks like this:

#+begin_example
,#+title: Search: org-node
,#+filetags: :search_view:
,#+date: [2026-10-28 Wed 22:30]

,* Parameters
:PROPERTIES:
:SEARCH_TOOL: rg
:SEARCH_QUERY: org-node
:SEARCH_DIR: /Users/me/notes/
:SEARCH_GLOB: *.org
:SEARCH_CASE: smart
:SEARCH_REGEXP: nil
:END:

Re-run this search with =M-x sp-search-run-view=.

,* Results (2)
- [[file:/Users/me/notes/a.org::12][a.org:12]] :: text of the match
#+end_example

=sp-search-run-view= (from the buffer with =V=, or inside the view file) reads the =SEARCH_*= properties and runs the search again, so a view works as a saved query whose chosen results are also kept as links. Searches made with Consult can be exported too: =embark-export= (=C-. E=) turns the candidates of =consult-ripgrep= into a =grep-mode= buffer; there =E= (=sp-search-export-grep-buffer=) exports the region, or the whole buffer, and asks for the query so it can be stored. The view files are plain Org files without an =ID=; add one if they should be vulpea notes.

** The ripgrep runner

=sp-search--rg= runs =rg= from a parameter list (=:query :dir :glob :case :regexp=) and returns one plist per match. The parameter list is also what a saved view stores.

#+begin_src emacs-lisp -i
(defvar-local sp-search--params nil
  "Parameters of the search shown in this buffer.")
(defvar-local sp-search--results nil
  "Matches of the search shown in this buffer, one plist each.")

(defun sp-search--rg (params)
  "Run ripgrep as described by PARAMS and return its matches."
  (let ((rg (or (executable-find "rg") (user-error "Ripgrep (rg) is not installed")))
        (dir (expand-file-name (plist-get params :dir)))
        (glob (plist-get params :glob))
        results)
    (with-temp-buffer
      (apply #'call-process rg nil '(t nil) nil
             "--line-number" "--no-heading" "--with-filename"
             "--color" "never" "--max-columns" "500"
             (append (pcase (plist-get params :case)
                       ("sensitive" '("--case-sensitive"))
                       ("ignore" '("--ignore-case"))
                       (_ '("--smart-case")))
                     (unless (plist-get params :regexp) '("--fixed-strings"))
                     (when (and glob (not (string-empty-p glob)))
                       (list "--glob" glob))
                     (list "-e" (plist-get params :query) "--" dir)))
      (goto-char (point-min))
      (while (and (< (length results) sp-search-max-results)
                  (re-search-forward "^\\(.+?\\):\\([0-9]+\\):\\(.*\\)$" nil t))
        (push (list :file (match-string 1)
                    :line (string-to-number (match-string 2))
                    :text (string-trim (match-string 3))
                    :marked nil)
              results)))
    (nreverse results)))
#+end_src

** Saved views: files

A saved view is an Org file. Its =Parameters= heading holds the search as =SEARCH_*= properties and its =Results= list holds one link per selected match, so the file can be read, linked and edited like any note. =sp-search--read-view= reads the properties back with a regexp, without loading Org.

#+begin_src emacs-lisp -i
(defun sp-search--slug (text)
  "Return TEXT as a short file name part."
  (let ((s (string-trim (replace-regexp-in-string "[^[:alnum:]]+" "-" (downcase text)) "-" "-")))
    (if (string-empty-p s) "search" (substring s 0 (min 40 (length s))))))

(defun sp-search--write-view (name params items)
  "Write the saved view NAME for the search PARAMS with the matches ITEMS.
Return the file written, which is also opened."
  (require 'org)
  (let* ((dir (sp-search--views-dir))
         (base (format "%s-%s" (format-time-string "%Y%m%d") (sp-search--slug name)))
         (file (expand-file-name (concat base ".org") dir))
         (n 1)
         (one-line (lambda (s) (replace-regexp-in-string "[\n\r]+" " " (or s "")))))
    (make-directory dir t)
    (while (file-exists-p file)
      (setq n (1+ n)
            file (expand-file-name (format "%s-%d.org" base n) dir)))
    (with-temp-file file
      (insert (format "#+title: Search: %s\n#+filetags: :search_view:\n#+date: %s\n\n"
                      (funcall one-line (plist-get params :query))
                      (format-time-string "[%Y-%m-%d %a %H:%M]"))
              "* Parameters\n:PROPERTIES:\n"
              (format ":SEARCH_TOOL: %s\n" (or (plist-get params :tool) "rg"))
              (format ":SEARCH_QUERY: %s\n" (funcall one-line (plist-get params :query)))
              (format ":SEARCH_DIR: %s\n" (plist-get params :dir))
              (format ":SEARCH_GLOB: %s\n" (or (plist-get params :glob) ""))
              (format ":SEARCH_CASE: %s\n" (or (plist-get params :case) "smart"))
              (format ":SEARCH_REGEXP: %s\n" (if (plist-get params :regexp) "t" "nil"))
              ":END:\n\nRe-run this search with =M-x sp-search-run-view=.\n\n"
              (format "* Results (%d)\n" (length items)))
      (dolist (r items)
        (insert (format "- [[file:%s::%d][%s:%d]] :: %s\n"
                        (org-link-escape (plist-get r :file)) (plist-get r :line)
                        (file-name-nondirectory (plist-get r :file)) (plist-get r :line)
                        (plist-get r :text)))))
    (message "Saved view: %s" file)
    (find-file-other-window file)
    file))

(defun sp-search--read-view (file)
  "Return the SEARCH_* properties of the saved view FILE as a plist."
  (with-temp-buffer
    (insert-file-contents file)
    (let (plist)
      (while (re-search-forward "^:SEARCH_\\([A-Z]+\\): ?\\(.*\\)$" nil t)
        (setq plist (plist-put plist (intern (concat ":" (downcase (match-string 1))))
                               (match-string 2))))
      plist)))

(defun sp-search--view-params (file)
  "Return the search parameters stored in the saved view FILE."
  (let ((p (sp-search--read-view file)))
    (list :tool (plist-get p :tool)
          :query (plist-get p :query)
          :dir (plist-get p :dir)
          :glob (plist-get p :glob)
          :case (or (plist-get p :case) "smart")
          :regexp (equal (plist-get p :regexp) "t"))))

(defun sp-search--view-files ()
  "Return the saved view files, newest first."
  (let ((dir (sp-search--views-dir)))
    (and (file-directory-p dir)
         (sort (directory-files dir t "\\.org\\'") #'file-newer-than-file-p))))
#+end_src

** Drawing the buffer

=sp-search--render= redraws the buffer: the header, the current search with its results grouped by file (each line carries its index as a text property), and the list of saved views.

#+begin_src emacs-lisp -i
(defun sp-search--insert-views ()
  "Insert the list of saved views."
  (insert "\n" (propertize "Saved views" 'face 'bold)
          (format " (%s)\n" (abbreviate-file-name (sp-search--views-dir))))
  (if-let* ((files (sp-search--view-files)))
      (dolist (f files)
        (insert (propertize (format "  %s  %s\n" (file-name-base f)
                                    (or (plist-get (sp-search--read-view f) :query) ""))
                            'sp-search-view f)))
    (insert "  none yet: select results and press x\n")))

(defun sp-search--render ()
  "Redraw the results buffer."
  (let ((inhibit-read-only t)
        (line (line-number-at-pos))
        (params sp-search--params)
        (results sp-search--results))
    (erase-buffer)
    (insert (sp-search--header) "\n\n")
    (if (not params)
        (insert (propertize "No search yet." 'face 'bold)
                " Press s to search, ? for the menu.\n")
      (let ((glob (plist-get params :glob)))
        (insert (propertize "Search" 'face 'bold) "\n"
                "  " (propertize (plist-get params :query) 'face 'font-lock-string-face)
                " in " (abbreviate-file-name (plist-get params :dir)) "\n"
                (format "  glob: %s, case: %s, %s\n"
                        (if (member glob '(nil "")) "all files" glob)
                        (plist-get params :case)
                        (if (plist-get params :regexp) "regexp" "fixed string"))
                (format "\nResults: %d, marked %d\n" (length results)
                        (length (seq-filter (lambda (r) (plist-get r :marked)) results)))))
      (let ((i 0) last)
        (dolist (r results)
          (unless (equal last (plist-get r :file))
            (setq last (plist-get r :file))
            (insert (propertize (file-relative-name last (plist-get params :dir))
                                'face 'font-lock-function-name-face)
                    "\n"))
          (insert (propertize (format "%s %5d  %s\n"
                                      (if (plist-get r :marked) "*" " ")
                                      (plist-get r :line) (plist-get r :text))
                              'sp-search-index i))
          (setq i (1+ i)))))
    (sp-search--insert-views)
    (goto-char (point-min))
    (forward-line (1- line))))
#+end_src

** Commands in the buffer

=sp-search-grep= asks for a query and searches the project or current directory; with a prefix argument it also asks for the directory, a glob, the case mode and whether the query is a regexp. =RET= visits the match at point, or re-runs the saved view at point. =m= and =u= mark and unmark, =M= and =U= do all.

#+begin_src emacs-lisp -i
(defun sp-search--show (params)
  "Run the search PARAMS and show its results in the search buffer."
  (let ((results (sp-search--rg params))
        (buf (get-buffer-create "*sp-search*")))
    (with-current-buffer buf
      (unless (derived-mode-p 'sp-search-mode) (sp-search-mode))
      (setq sp-search--params params
            sp-search--results results)
      (goto-char (point-min))
      (sp-search--render))
    (pop-to-buffer-same-window buf)
    (message "%d results" (length results))))

(defun sp-search-grep (query &optional dir glob case-mode regexp)
  "Search for QUERY with ripgrep and show the results in the search buffer.
DIR, GLOB, CASE-MODE and REGEXP are asked for with a prefix argument."
  (interactive
   (let ((prefix current-prefix-arg))
     (list (read-string "Search for: "
                        (when (use-region-p)
                          (buffer-substring-no-properties (region-beginning) (region-end))))
           (if prefix (read-directory-name "In directory: ")
             (if-let* ((p (and (fboundp 'project-current) (project-current))))
                 (project-root p)
               default-directory))
           (when prefix (read-string "Glob (empty for all files): "))
           (if prefix (completing-read "Case: " '("smart" "sensitive" "ignore") nil t nil nil "smart")
             "smart")
           (if prefix (y-or-n-p "Regexp (no: fixed string)? ") t))))
  (sp-search--show (list :tool "rg" :query query
                         :dir (expand-file-name (or dir default-directory))
                         :glob glob :case (or case-mode "smart") :regexp regexp)))

(defun sp-search-rerun ()
  "Run the search of this buffer again."
  (interactive)
  (unless sp-search--params (user-error "No search to repeat"))
  (sp-search--show sp-search--params))

(defun sp-search-visit ()
  "Visit the match at point, or run the saved view at point."
  (interactive)
  (if-let* ((view (get-text-property (point) 'sp-search-view)))
      (sp-search-run-view view)
    (if-let* ((i (get-text-property (point) 'sp-search-index))
              (r (nth i sp-search--results)))
        (progn (find-file-other-window (plist-get r :file))
               (goto-char (point-min))
               (forward-line (1- (plist-get r :line))))
      (user-error "Nothing to open here"))))

(defun sp-search--set-mark (flag)
  "Set the mark of the match at point to FLAG, then go to the next line."
  (if-let* ((i (get-text-property (line-beginning-position) 'sp-search-index)))
      (progn (plist-put (nth i sp-search--results) :marked flag)
             (sp-search--render)
             (forward-line 1))
    (user-error "No match on this line")))

(defun sp-search-mark () "Mark the match at point for export." (interactive) (sp-search--set-mark t))
(defun sp-search-unmark () "Unmark the match at point." (interactive) (sp-search--set-mark nil))

(defun sp-search-mark-all (&optional unmark)
  "Mark every match for export; with UNMARK non-nil unmark them all."
  (interactive)
  (dolist (r sp-search--results) (plist-put r :marked (not unmark)))
  (sp-search--render))

(defun sp-search-unmark-all () "Unmark every match." (interactive) (sp-search-mark-all t))
#+end_src

** Export and saved views

=sp-search-export= (=x=) writes the marked matches, or all of them when none is marked, to a new Org file with the search parameters. =sp-search-run-view= reads those parameters and runs the search again in the buffer; called from inside a view file it uses that file. Searches made with Consult can be exported too: =embark-export= turns the candidates into a =grep-mode= buffer, where =E= (=sp-search-export-grep-buffer=) exports the region, or the whole buffer, after asking for the query so it can be stored.

#+begin_src emacs-lisp -i
(defun sp-search-export (name)
  "Export the marked matches (all if none) to the saved view NAME."
  (interactive
   (list (read-string "View name: " (sp-search--slug (or (plist-get sp-search--params :query) "")))))
  (unless sp-search--params (user-error "No search to export"))
  (let ((items (or (seq-filter (lambda (r) (plist-get r :marked)) sp-search--results)
                   sp-search--results)))
    (unless items (user-error "Nothing to export"))
    (sp-search--write-view name sp-search--params items)
    (sp-search--render)))

(defun sp-search--pick-view-file ()
  "Ask for a saved view file."
  (let* ((files (or (sp-search--view-files)
                    (user-error "No saved views in %s" (sp-search--views-dir))))
         (alist (mapcar (lambda (f) (cons (file-name-base f) f)) files)))
    (cdr (assoc (completing-read "Saved view: " alist nil t) alist))))

(defun sp-search-run-view (file)
  "Run the search stored in the saved view FILE and show it in the search buffer."
  (interactive
   (list (or (and buffer-file-name
                  (plist-get (sp-search--read-view buffer-file-name) :query)
                  buffer-file-name)
             (sp-search--pick-view-file))))
  (let ((params (sp-search--view-params file)))
    (unless (plist-get params :query) (user-error "%s has no search parameters" file))
    (sp-search--show params)))

(defun sp-search-open-view (file)
  "Open the saved view FILE."
  (interactive (list (sp-search--pick-view-file)))
  (find-file file))

(defun sp-search-export-grep-buffer (query name)
  "Export the grep lines of this buffer (or the region) to the saved view NAME.
QUERY is the search that produced them; it is stored in the view."
  (interactive
   (let* ((q (read-string "Query that produced these results: "
                          (car (bound-and-true-p grep-history))))
          (n (read-string "View name: " (sp-search--slug q))))
     (list q n)))
  (let ((beg (if (use-region-p) (region-beginning) (point-min)))
        (end (if (use-region-p) (region-end) (point-max)))
        items)
    (save-excursion
      (goto-char beg)
      (while (re-search-forward "^\\([^ \n:][^\n]*?\\):\\([0-9]+\\):\\(.*\\)$" end t)
        (push (list :file (expand-file-name (match-string 1))
                    :line (string-to-number (match-string 2))
                    :text (string-trim (match-string 3)))
              items)))
    (unless items (user-error "No grep lines found"))
    (sp-search--write-view name
                           (list :tool "rg" :query query
                                 :dir (expand-file-name default-directory)
                                 :glob "" :case "smart" :regexp t)
                           (nreverse items))))

(with-eval-after-load 'grep
  (keymap-set grep-mode-map "E" #'sp-search-export-grep-buffer))
#+end_src

** Menu at the top

The menu is always shown in a window at the top of the frame (=sp-search-menu-display-action=). Transient has one global display action, so an advice on =transient--show= swaps it only while =sp-search-menu= is the active prefix; Magit and the other menus keep theirs.

#+begin_src emacs-lisp -i
(define-advice transient--show (:around (fn &rest args) sp-search-top)
  "Show `sp-search-menu' at the top of the frame."
  (let ((transient-display-buffer-action
         (if (eq transient-current-command 'sp-search-menu)
             sp-search-menu-display-action
           transient-display-buffer-action)))
    (apply fn args)))
#+end_src

** Links with Vertico and the other completion frameworks

The menu itself is only a launcher. The commands in it read their candidates through =completing-read=, so whatever completion framework is active shapes what they look like:

- *Vertico* (=sp-completion=) shows the candidates of every Consult command (=l=, =i=, =r=, =d=, =T=, =c=, =C=, =s=). Consult's async commands, such as =consult-ripgrep=, hand the typed text to =rg= and Vertico lists the output as it arrives. =vertico-buffer-mode= can show the same list in a side window.
- *Vertico-posframe* (=sp-posframe=) draws the same minibuffer in a centred child frame.
- *Orderless* (=sp-completion=) filters the candidates by space-separated components in any order. It applies to the candidates that Consult has already collected, for example the lines of =consult-line=; for the async grep commands the first part of the input (before the =#=) is the regexp passed to =rg=, and Orderless only filters afterwards.
- *Marginalia* (=sp-completion=) adds annotations (file, size, mode) beside the candidates in the minibuffer.
- *Embark* (=sp-embark=, =C-.=) acts on a candidate: open it elsewhere, copy it, or export the whole list. =embark-export= on =consult-ripgrep= or =consult-line= candidates opens a =grep-mode= or =occur= buffer (editing it in place would need =wgrep=, which is not installed); =embark-consult= adds previews and the collect/export hooks. This is the nearest thing to a Magit-like results buffer for these searches.
- *Corfu* and *Cape* complete text in a buffer, not search; they have no link to this menu.
- *Ivy* and *Counsel* are used only by =counsel-recoll=, which reads its candidates through =ivy-read=; =ivy-prescient= sorts them. It is the one command here that does not go through Vertico.
- *Prescient* (=sp-minibuffer=, =vertico-prescient=) sorts recent choices first; with Orderless it only changes the order.

The semantic commands (=org-semantic=) show their results in an =org-semantic-results-mode= buffer, not in the minibuffer, and =next-error-follow-minor-mode= is on there.
