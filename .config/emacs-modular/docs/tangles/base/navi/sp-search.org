This navigation sub-module, loaded by =sp-navi=, installs the search packages: Consult and Counsel for in-buffer and project search, front-ends for =ag= and =rg=, Deadgrep, and =p-search=. It also adds a directory-prompting ripgrep command and a Counsel-based search over a Recoll full-text index.

External programs used are =rg= (ripgrep), =ag= (the silver searcher) and =recollq= from Recoll. The commentary sketches future plans to tie search into =sp-browsing= and Embark; those plans are not implemented here.

** Search a chosen directory

=sp-search-in-input-dir= calls =consult-ripgrep= as if with =C-u=, which makes it ask for the directory to search before prompting for the pattern. It is bound to =D= under the leader map in =sp-keys=.

#+begin_src emacs-lisp -i
;; Functions written for searches
;;;;; Search given directory
(defun sp-search-in-input-dir ()
  "Grep for a string in the input directory using completing read function"
  (interactive)
  (let ((current-prefix-arg '(4))) (call-interactively #'consult-ripgrep)))
#+end_src

** Recoll query function

=counsel-recoll-function= runs =recollq -b= on the input asynchronously once at least three characters have been typed, returning matching file URLs. The search string is placed inside single quotes on the shell command line, so a query containing a quote breaks it. It calls =counsel-more-chars=, which newer Counsel releases have replaced with =ivy-more-chars=, so this may need updating.

#+begin_src emacs-lisp -i
;; More advanced searching

(defun counsel-recoll-function (string &rest _unused)
  "Issue recallq for STRING."
  (if (< (length string) 3)
      (counsel-more-chars 3)
    (counsel--async-command
     (format "recollq -b '%s'" string))
    nil))
#+end_src

** Recoll search command

=counsel-recoll= searches the Recoll index with Ivy and opens the selected file. For non-PDF files it then starts =swiper= with the same query, so you land on the matches inside the file. It reuses =counsel-git-grep-history= as its history.

#+begin_src emacs-lisp -i
(defun counsel-recoll (&optional initial-input)
  "Search for a string in the recoll database.
You'll be given a list of files that match.
Selecting a file will launch `swiper' for that file.
INITIAL-INPUT can be given as the initial minibuffer input."
  (interactive)
  (ivy-read "recoll: " 'counsel-recoll-function
            :initial-input initial-input
            :dynamic-collection t
            :history 'counsel-git-grep-history
            :action (lambda (x)
                      (when (string-match "file://\\(.*\\)\\'" x)
                        (let ((file-name (match-string 1 x)))
                          (find-file file-name)
                          (unless (string-match "pdf$" x)
                            (swiper ivy-text)))))))
#+end_src
