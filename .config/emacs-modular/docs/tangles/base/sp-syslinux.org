Literate source for =libraries/modules/base/sp-syslinux.el=. Every =emacs-lisp= block below goes into that file, except the blocks marked =:tangle no=. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

This module is the Linux counterpart of =sp-syswin=, which handles running Emacs on Windows. It is meant to hold settings that only apply when Emacs runs on Linux, such as paths, clipboard and desktop integration, or anything that should load only when =system-type= is =gnu/linux=. The purpose is inferred from the name and from =sp-syswin=.

The =.el= file is empty for now, and nothing in =init.el= or =sp-config-profiles.el= loads it. The blocks below are a skeleton for when you fill it in. Tangling it now replaces the empty file with a valid module that loads and does nothing, so =(sp-require-module 'sp-syslinux)= would succeed.

#+end_src
