Literate source for =libraries/modules/base/sp-globals.el=.

- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README.

This module is the one file to open when one of my own settings has to change: where my files live, which credentials file is read, who I am, what the dashboard keeps private, and the habits (prompts, bells, backups) that used to be spread over the modules that happen to use them.

- *The former =sp-paths= is part of this module.* The locations should have been a module of their own, but are combined with the other settings for the sake of simplicity and brevity. =sp-paths= is no longer a module; =(provide 'sp-paths)= at the end keeps an old =(require 'sp-paths)= working.
- Each setting is a =defcustom= in the =spcustom= group.
- When it controls a variable of Emacs or of a package, its =:set= function also applies the value there, so editing the default here and changing it with Customize have the same effect.
- Where a setting used to live, the module (and its doc) now has a comment that points here.

It is loaded first among the core modules, in both module lists in =init.el= and in the profiles of =sp-config-profiles.el=, because the modules that use these variables read them while they load. It depends on no module, only on =sp-var-dir= and =sp-cache-dir= from =early-init.el=.

Left where they are on purpose:

- =sp-headless-host= (=early-init.el=) and =sp-defer-late-modules= (=init.el=): they are read before the module lists run, so they cannot come from a module.
- Settings of one package (the =:custom= of a =use-package=), which are documented with the package.
- Platform settings such as =mac-command-modifier= (=sp-macos=), which belong to their platform module.
- Values derived from a path, such as =org-directory= and =vulpea-db-sync-directories=: they follow =sp-notes-dir=, so changing the path here is enough.
- The default font and the theme (=sp-fonts=, =sp-themes=): they are set separately on purpose.
- Paths inside the configuration's own tree (=~/.config/...=), the legacy =~/.emacs.d= entries, =~/bin/mark.sh=, =~/opt/plantuml= and the plain =~/= used as a starting directory. They are tool locations rather than data.

* Helpers

The group, a function that reads an environment variable, =sp-path=, which joins path components below one of the directories, and =sp-globals--set=, which builds the =:set= function of the settings that also control a variable of Emacs.

- =sp-globals--set= is what makes editing a default here and using Customize the same thing: the value is stored in the =sp-= variable and in the variable it controls.
- With =skip-nil= a =nil= value leaves the controlled variable alone; the identity settings use that, because =nil= means "not set".

#+begin_src emacs-lisp -i
(defgroup sp-paths nil
  "Locations of my notes, documents and checkouts."
  :group 'files)

(defun sp-paths--dir (env default)
  "Directory named by environment variable ENV, or DEFAULT (relative to ~)."
  (file-name-as-directory
   (expand-file-name (or (getenv env) default))))

(defun sp-path (dir &rest parts)
  "Join PARTS below the directory DIR (a variable's value) into one path."
  (let ((path (expand-file-name dir)))
    (dolist (part parts path)
      (setq path (expand-file-name part path)))))

(defun sp-globals--set (target &optional skip-nil)
  "Return a :set function that stores the value in its symbol and in TARGET.
With SKIP-NIL, a nil value leaves TARGET alone."
  (lambda (symbol value)
    (set-default symbol value)
    (unless (and skip-nil (null value))
      (set-default target value))))
#+end_src

* Locations

The notes, documents, literature, bibliography, org, source and clone folders. They came from the former =sp-paths= module. Each is a directory with a trailing slash.

- Before =sp-paths= existed, about thirty modules spelled out =~/notes= and similar paths themselves, which made the configuration depend on one machine's layout.
- A module now says =sp-notes-dir= or =(sp-path sp-notes-dir "inbox/")= instead.
- Each location can be overridden from the environment before Emacs starts, for example =SP_NOTES_DIR=/tmp/notes emacs=. That is how a test run (a sandbox for a pull request, say) is kept away from the real notes.

  (expand-file-name

* Credentials: =sp-auth-sources=

Sets =auth-sources=, the list of places where Emacs looks for credentials.

- The default is just =~/.authinfo=. That replaces Emacs's own list, so credentials are read only from that plain-text file, and =~/.authinfo.gpg= and the keychain are not looked at.
- Forge takes its GitHub token from here (a line such as =machine api.github.com login USERNAME^forge password TOKEN=, added by hand). Nothing secret is in this config.
- It used to be a =setq= in =sp-vcontrol=, which is a late module, so it was only set once that module had loaded.
- To read an encrypted file as well, change the default to =("~/.authinfo.gpg" "~/.authinfo")=.

#+begin_src emacs-lisp -i
(defcustom sp-auth-sources '("~/.authinfo")
  "Where Emacs looks for credentials, as in `auth-sources'.
The default is the plain-text file ~/.authinfo only, so ~/.authinfo.gpg and
the keychain are not read.  Forge, for example, takes its GitHub token from
here."
  :type '(repeat sexp)
  :set (sp-globals--set 'auth-sources)
  :group 'spcustom)
#+end_src

* Prompts, dialogs and sounds

* Backups and lock files

Where backups go and whether lock files are made, from =sp-backups=. The rest of the backup settings (how many versions to keep, copying by default, and so on) stay in =sp-backups=.

- =sp-backup-directory= becomes the only entry of =backup-directory-alist=, for all files. It is below =sp-var-dir=, as before.
- =sp-create-lockfiles= is =nil=: lock files cause more pain than benefit.

#+begin_src emacs-lisp -i
(defcustom sp-backup-directory (expand-file-name "backups/" sp-var-dir)
  "Folder for the backup files of every file, as in `backup-directory-alist'."
  :type 'directory
  :set (lambda (symbol value)
         (set-default symbol value)
         (set-default 'backup-directory-alist
                      `(("." . ,(expand-file-name value)))))
  :group 'spcustom)

(defcustom sp-create-lockfiles nil
  "Non-nil makes lock files (.#file) next to edited files, as `create-lockfiles'."
  :type 'boolean
  :set (sp-globals--set 'create-lockfiles)
  :group 'spcustom)
#+end_src
