Literate source for =libraries/modules/base/sp-navi.el=.

- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README.

This is the umbrella module for moving around in Emacs.

- Pulls in the navigation sub-modules =sp-consult-snapfile=, =sp-dired=, =sp-goto= and =sp-search=.
- Configures a few navigation essentials of its own:
  - an imenu outline sidebar,
  - remembering point in files,
  - the recent-files list,
  - a heading jumper,
  - a replacement for =C-x C-f= that lets you pick between several file-listing tools.

Dependencies:

- Uses =sp-cache-dir= for state files.
- =sp-find-file= shells out to =find=, =fd= or =rg=, so those programs need to be installed for the corresponding choices to work.
- Consult (installed by =sp-search=) is needed for =lem-jump-in-buffer=.

* Utility functions

** Start file searches at home

=sp-open-from-home-dir= sets =default-directory= to the home directory. It is not called here; =sensible-defaults/use-all-settings= in =sp-helper-funct= calls it.

#+begin_src emacs-lisp -i
;;;; Defining utility functions
(defun sp-open-from-home-dir ()
  "When opening a file, start searching at the user's home
directory."
  (setq default-directory "~/"))
#+end_src

** Follow symlinks

=sp-auto-follow-symlinks= sets =vc-follow-symlinks= so visiting a symlink to a version-controlled file opens the real file without asking. Like the previous helper, it is called from =sensible-defaults/use-all-settings=.

  (setq vc-follow-symlinks t))

* Places and outlines

** Imenu list outline

Configures =imenu-list=, a sidebar that shows the current buffer's imenu entries as an outline.

- It opens on the right, resizes itself and takes focus when shown.
- =imenu-list-smart-toggle= is bound to =o= under the leader map in =sp-keys=.
- A copy of the package also lives in the =cloned= modules directory.

#+begin_src emacs-lisp -i
;;;; Imenu list outline
;; Make a useful outline buffer
;; Binding set to toggle "o"
(use-package imenu-list
  :ensure t
  :commands (imenu-list-smart-toggle imenu-list-minor-mode)

  :config
  (setq imenu-list-focus-after-activation t
        imenu-list-auto-resize t
        imenu-list-position 'right))
#+end_src

** Save place

Enables =save-place-mode= after startup so each file reopens at the position where you left it. The data is stored in =saved-places= under =sp-cache-dir=, and entries for files that are currently unreadable are kept rather than dropped.

#+begin_src emacs-lisp -i
;;;; Save place
;; Everyone remember where we parked.
(use-package saveplace
  :ensure nil
  :hook (emacs-startup . save-place-mode)
  :config
  (setq save-place-file (concat sp-cache-dir "saved-places"))
  (setq save-place-forget-unreadable-files nil))
#+end_src

** Recent files

Enables =recentf-mode= after two seconds idle, keeping up to 500 recent files in =recentf= under =sp-cache-dir= and showing 10 in the menu.

#+begin_src emacs-lisp -i
;;;; Recent files
;; List recent files
(use-package recentf
  :ensure nil
  :defer 2
  :custom
  (recentf-save-file (concat sp-cache-dir "recentf"))
  (recentf-max-saved-items 500)
  (recentf-max-menu-items 10)
  :config
  (recentf-mode 1))
#+end_src

** Jump to a heading

=lem-jump-in-buffer= jumps to a heading using Consult: =consult-org-heading= in Org buffers, otherwise =consult-outline=. No key is bound to it in this module.

#+begin_src emacs-lisp -i
;;;; Jump in Buffer
(defun lem-jump-in-buffer ()
  "Jump between headlines in buffer using consult"
  (interactive)
  (cond
   ((eq major-mode 'org-mode)
    (call-interactively 'consult-org-heading))
   (t
    (call-interactively 'consult-outline))))
#+end_src

* Finding files

** Choose how to find a file

The shell methods and the command are listed in =sp-find-file-options=. =sp-find-file= first asks which one to use:

- =find=, =fd= or =rg= to list every file under the current directory,
- =find-name-dired= to search by name into a Dired buffer.

For the three shell tools:

- =sp-find-file--read= collects the NUL-separated output and offers it with =completing-read=, optionally keeping only the files whose name matches a regexp.
- Candidates are tagged with the =file= category so Marginalia and Embark treat them as files.
- Listing every file under a large directory can be slow.

=sp-find-file-pick= is the same search for other commands: it takes a directory and an optional regexp, lists the files there with one of the shell tools (it does not offer =find-name-dired=, which cannot return a file), and returns the chosen file instead of visiting it. =sp-org-insert-config-doc-link= uses it.

#+begin_src emacs-lisp -i
;;;; Better find-file
(defvar sp-find-file-options '(("find -type f -printf \"$PWD/%p\\0\"" . :string)
                               ("fd --absolute-path --type f -0" . :string)
                               ("rg --follow --files --null" . :string)
                               ("find-name-dired" . :command))
  "Ways `sp-find-file' can list files, each with how to run it.
A `:string' method is a shell command printing NUL-separated files;
a `:command' method is an interactive command.")

(defun sp-find-file--read (method &optional regexp)
  "Complete on the files that the shell command METHOD lists in `default-directory'.
When REGEXP is non-nil, only offer files whose name matches it.
Return the chosen file as an absolute name, or nil if none is chosen."
  (let* ((metadata '((category . file)))
         (file-list (split-string (shell-command-to-string method) "\0" t))
         (file-list (if regexp
                        (seq-filter (lambda (f) (string-match-p regexp f)) file-list)
                      file-list))
         (file (completing-read (format "Find file in %s: " (abbreviate-file-name default-directory))
                                (lambda (str pred action)
                                  (if (eq action 'metadata)
                                      `(metadata . ,metadata)
                                    (complete-with-action action file-list str pred)))
                                nil t nil 'file-name-history)))
    (when (and file (not (string-empty-p file)))
      (expand-file-name file))))

(defun sp-find-file ()
  "Find file from current directory in many different ways."
  (interactive)
  (let* ((selection (completing-read "Select : " sp-find-file-options)))
    (pcase (alist-get selection sp-find-file-options nil nil #'string=)
      (:command
       (call-interactively (intern selection)))
      (:string
       (when-let* ((file (sp-find-file--read selection)))
         (find-file file))))))

(defun sp-find-file-pick (dir &optional regexp)
  "Return a file under DIR chosen with the same fuzzy search as `sp-find-file'.
Ask for the method among the shell ones, run it in DIR, and offer only
the files whose name matches REGEXP, if given.  Visit nothing; return
the absolute file name, or nil if none is chosen."
  (let* ((default-directory (file-name-as-directory (expand-file-name dir)))
         (methods (seq-filter (lambda (option) (eq (cdr option) :string))
                              sp-find-file-options))
         (selection (completing-read "Select : " methods)))
    (sp-find-file--read selection regexp)))
#+end_src

** Rebind C-x C-f

Replaces the standard =find-file= binding on =C-x C-f= with =sp-find-file=. The plain =find-file= command remains available through =M-x=.

#+begin_src emacs-lisp -i
(global-unset-key (kbd "C-x C-f")) ; Rebinding the find-file command.
(keymap-global-set "C-x C-f" #'sp-find-file)
#+end_src
