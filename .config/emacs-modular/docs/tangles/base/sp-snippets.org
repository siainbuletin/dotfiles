The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module sets up =yasnippet= for text snippets, together with the community =yasnippet-snippets= collection. Personal snippets are looked for in a =snippets= directory under the Emacs directory.

The module is commented out in the default and minimal module lists in =init.el= (the note there says snippets are not used much yet), but it is listed in several profiles in =sp-config-profiles.el=, so whether it loads depends on which loader is active.

** yasnippet

Installs =yasnippet= synchronously and loads it immediately. In =:config= it first runs =yas-reload-all=, then adds the =snippets= directories under =user-emacs-directory= and =sp-load-path= to =yas-snippet-dirs= and enables =yas-global-mode=. In this config both paths are likely the same directory. Because the reload runs before the directories are added, snippets in those directories may not be picked up until the next =yas-reload-all=. =C-M-S-y= shows the snippet tables for the current mode, and the extra =sh-mode= hook for =yas-minor-mode= is redundant with the global mode.

#+begin_src emacs-lisp -i
(use-package yasnippet
  :ensure (:wait t)
  :demand t

  :config
  (yas-reload-all)
  (progn
    (add-to-list 'yas-snippet-dirs (expand-file-name "snippets" user-emacs-directory))
    (add-to-list 'yas-snippet-dirs (expand-file-name "snippets" sp-load-path))
    (yas-global-mode 1))
  :bind (("C-M-S-y" . 'yas-describe-tables))

  :hook
  (sh-mode . yas-minor-mode))
#+end_src

** yasnippet-snippets

Installs the =yasnippet-snippets= collection after =yasnippet=, giving ready-made snippets for many languages.

#+begin_src emacs-lisp -i
;; install useful snippets
(use-package yasnippet-snippets
  :after yasnippet
  :ensure (:wait t))
#+end_src
