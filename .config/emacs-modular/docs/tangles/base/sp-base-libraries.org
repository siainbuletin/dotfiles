Literate source for =libraries/modules/base/sp-base-libraries.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This is one of the first modules loaded in every profile. It installs or declares the small libraries many other packages and =sp-= modules rely on (=subr-x=, =cl-lib=, =async=, =dash=, =s=, =f=, =transient= and others), and then collects a number of general defaults that did not have a better home: Org Babel languages, cursor shape, undo history, electric pairs, auto-revert, Avy and a few global keys.

Packages are installed through elpaca via =use-package=; =:ensure (:wait t)= makes elpaca finish installing a package before the rest of the config continues, which matters for =transient= because =sp-keys= uses =transient-define-prefix= at load time. The module uses =sp-cache-dir= from the core config. The library section is adapted from Lambda Emacs's =lem-setup-libraries.el=.

** async

Installs =async=, which runs Lisp in a child Emacs process. After Dired loads it enables =dired-async-mode=, so copies, renames and symlinks in Dired run asynchronously, and hides its mode-line indicator.

#+begin_src emacs-lisp -i
;; Asynchronous commands. Adds the ability to call asynchronous functions and
;; process with ease. See the documentation for `async-start' and
;; `async-start-process'.

(use-package async
  :ensure t
  :after dired
  :config
  (dired-async-mode 1)
  (setq dired-async--modeline-mode nil))
#+end_src

** Transient

Installs and loads =transient= immediately so =transient-define-prefix= is available when =sp-keys= is loaded. Its level, value and history files are stored under =sp-cache-dir=. Key conflict detection and fixed-pitch popups are on, and popups appear in a dedicated side window at the top of the frame that =other-window= skips.

#+begin_src emacs-lisp -i
(use-package transient
  :ensure (:wait t)
  :demand t ;; this makes sure that the macro `transient-define-prefix` can actually be called by the time we get to `sp-keys.el`
  :commands (transient-setup transient-show transient-help)
  
  :custom
  (transient-levels-file (concat sp-cache-dir "transient/levels.el"))
  (transient-values-file (concat sp-cache-dir "transient/values.el"))
  (transient-history-file (concat sp-cache-dir "transient/history.el"))
  (transient-detect-key-conflicts t)
  (transient-force-fixed-pitch t)
  (transient-show-popup t)

  ;; set transient popop to top of window
  (transient-display-buffer-action '(display-buffer-in-side-window
                                     (side . top)
                                     (dedicated . t)
                                     (inhibit-same-window . t)
                                     (window-parameters (no-other-window . t)))))
#+end_src

** Crux

Installs =crux=, a set of handy commands from Emacs Prelude. It rebinds =C-k= to =crux-smart-kill-line= and =C-a= to =crux-move-beginning-of-line=, which toggles between the first non-blank character and column 0.

#+begin_src emacs-lisp -i
;;;; CRUX
;; This is loading the library of default functions coming from Emacs Prelude. Lots
;; of useful defaults that you can start working in Emacs with.
;;
;; Crux bundles many useful interactive commands to enhance your overall Emacs 
;; experience. 

(use-package crux
  :ensure t
  :defer 1
  :bind
  ("C-k"   . crux-smart-kill-line)
  ("C-a"   . crux-move-beginning-of-line))
#+end_src

* Miscellaneous settings

Settings collected here because they had no other home, mainly around Org tangling and general editing.

** Execute all Babel blocks

=sia-execute-all-buffers= runs every source block in the current Org buffer with confirmation turned off. Despite its name it only acts on the current buffer.

#+begin_src emacs-lisp -i
;; Other settings I don't know what to do with
;; This is the configuration that I need in order to make my tangling work.
;; Also, the code should appear to be referenced elsewhere on the system.

(defun sia-execute-all-buffers ()
  (interactive)
  (let ((org-confirm-babel-evaluate nil))
    (org-babel-execute-buffer))
)
#+end_src

** undo-tree

Installs =undo-tree= and enables it globally, excluding =nxml-mode=. Undo history is persisted to =~/.emacs.d/undo=, a hard-coded path that does not follow =sp-cache-dir=.

#+begin_src emacs-lisp -i
(use-package undo-tree
  :ensure (:wait t)
  :config
  (add-to-list 'undo-tree-incompatible-major-modes #'nxml-mode)
  (global-undo-tree-mode)

  :custom
  (undo-tree-history-directory-alist '(("." . "~/.emacs.d/undo"))))
#+end_src

** dwim-shell-command

Installs =dwim-shell-command= and uses it in place of =shell-command= globally and =dired-smart-shell-command= in Dired. It runs shell commands with placeholders for the file at point or the marked files. Remapping the other Dired shell commands is left commented out.

#+begin_src emacs-lisp -i
(use-package dwim-shell-command
  :ensure t
  :bind (([remap shell-command] . dwim-shell-command)
         :map dired-mode-map
         ;; ([remap dired-do-async-shell-command] . dwim-shell-command)
         ;; ([remap dired-do-shell-command] . dwim-shell-command)
         ([remap dired-smart-shell-command] . dwim-shell-command)))
#+end_src

Installs and loads Avy for jumping to visible text. =C-:= jumps to a character and =C-M-:= jumps using a timed multi-character input.

  :ensure t
  :demand t
