It depends on the =magit= and =transient= packages, and the YADM helper also needs a TRAMP method for =yadm= to be defined somewhere, which this file does not do. ** Magit

Installs =magit=, loaded only after =transient=, and binds =C-M-g= to =magit=. When a Magit buffer is quit, the window configuration from before it was opened is restored. Because the form waits for =transient=, the key binding is only set up once =transient= has loaded.

#+begin_src emacs-lisp -i
(use-package magit
  :ensure t
  :defer t
  :after transient
  :bind
  (("C-M-g" . magit))
  :custom
  (magit-bury-buffer-function 'magit-restore-window-configuration))
#+end_src

* YADM

** Magit on the YADM repository

The =yadm= command opens =magit-status= on the TRAMP path =/yadm::=, which is the usual way to let Magit work on YADM's bare repository. That path only works with a matching entry in =tramp-methods=, which is not set up here; the comment admits the author has not yet got YADM working inside Emacs.

#+begin_src emacs-lisp -i
;; YADM is theoretically used for dotfile management.
;; I haven't yet been able to do anything with that within Emacs.
(defun yadm ()
  (interactive)
  (magit-status "/yadm::"))
#+end_src
