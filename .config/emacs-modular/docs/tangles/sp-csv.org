A small utility module with one command that reads a CSV file and plans one Org file per row, named after the row's =date= column and holding its =body= column. The commentary credits jwiegley's =parse-reddit.el= as the source of the idea.

It relies on =parse-csv-string-rows= from the =parse-csv= package and on =cl-lib=, neither of which is required here, so both must already be loaded. As written the command is a dry run: the actual file writing is commented out.

* CSV to Org files

** create-org-files-from-csv

Prompts for a CSV file, parses it with comma separators and double-quote quoting, and finds the =date= and =body= columns from the header row. For each row it builds a filename of the form =DATE.org= and messages it. The =with-temp-file= call that would write the body into that file is commented out, so nothing is created yet. Files would be written relative to the current =default-directory=, and a missing =date= or =body= column would cause an error.

#+begin_src emacs-lisp -i
(defun create-org-files-from-csv (csv-file)
  "Process CSV-FILE to generate .org files named after the \"date\" field with \"body\" content."
  (interactive "fCSV file: ")
  (let* ((data (with-temp-buffer
                 (insert-file-contents csv-file)
                 (buffer-string)))
         (rows (parse-csv-string-rows data ?\, ?\" ?\n))
         (headers (pop rows)))
    (let ((date-index (cl-position "date" headers :test 'string=))
          (body-index (cl-position "body" headers :test 'string=)))
      (dolist (row rows)
        (let* ((date (nth date-index row))
               (filename (format "%s.org" date))
               (content (nth body-index row)))
          (message (format "filename %s" filename))
          ;; (with-temp-file filename
          ;;   (insert content))
          )))))
#+end_src
