Utilities for working with PDF files in the academic setup. It has a command that writes a reference's title and author from the Citar bibliography into the PDF's metadata using the external =exiftool= program, and it installs the =emacs-reader= document viewer from Codeberg.

It is required by =sp-academic=. The metadata command depends on Citar (configured in =sp-citations=) and on =sia-citar-library-backup-path=, which =sp-citations= defines as =~/Documents/literature/backup=.

* PDF metadata from Citar

** Writing title and author into a PDF

=sia-citar-update-pdf-metadata= asks you to pick a reference with =citar-select-ref=, checks that =citar-library-paths= is set, and finds the PDF files attached to that key. If there is more than one it lets you choose. It takes the title from the bibliography and the author, falling back to the editor with " (ed.)" appended. It then copies the PDF into the backup directory and runs =exiftool= to overwrite the Title and Author fields in place.

As written the function has bugs and will likely fail when run:
- It refers to =cite-key= (with a hyphen) in the =let*=, but the argument is =citekey=, so it signals a void-variable error.
- The shell command is built by string concatenation with single quotes, so a title containing an apostrophe or a path with spaces would break it.

#+begin_src emacs-lisp -i
;;;; Working with PDF metadata from citar
(defun sia-citar-update-pdf-metadata (citekey)
  (interactive (list (citar-select-ref)))
  (citar--check-configuration 'citar-library-paths)
  (unless citar-library-paths
    (user-error "Make sure `citar-library-paths' is non-nil"))
  (let* ((files (gethash cite-key (citar-get-files cite-key))))
    (unless files
      (user-error (format "There are no PDF files associated with %s" citekey)))
    (let ((file (or (unless (cdr files) (car files)) (completing-read "Please select a PDF file: " files)))
          (title (citar-get-value 'title citekey))
          (author (cond ((citar-get-value 'author citekey)
                         (citar-get-value 'author citekey))
                        ((citar-get-value 'editor citekey)
                         (concat (citar-get-value 'editor citekey) " (ed.)")))))
      (progn
        (copy-file file sia-citar-library-backup-path 1)
        (call-process-shell-command
         (concat "exiftool -overwrite_original_in_place -Title='" title "' -Author='" author "' " file))))))
#+end_src

* PDF viewer

** emacs-reader

Installs =emacs-reader= directly from its Codeberg git repository using Elpaca's =:ensure= recipe. It is a document reader for Emacs backed by a native rendering library. No configuration is applied here.

#+begin_src emacs-lisp -i
;;;; Calling emacs-reader
(use-package emacs-reader
  :ensure (:type git :url "https://codeberg.org/MonadicSheep/emacs-reader.git"))
#+end_src
