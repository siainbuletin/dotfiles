- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../tangling-instructions.org][Tangling instructions]].

* Basic functionality

The module decorates Org tags, in the way the Obsidian plugin [[https://github.com/mdelobelle/obsidian_supercharged_links][Supercharged Links]] decorates links by tag, property or path: a rule says which tags a note has, and the result is a coloured name, or a symbol put before or after it. Here the same rules are used in three places.

1. *The modeline.* =sp-org-tag-groups-mode= shows the tags of the heading at point, or of the file (its =#+filetags:=), as emoji instead of text.
2. *Note selection.* In =vulpea-select= (and so =vulpea-find=, =vulpea-insert= and everything built on them) the emoji of a note's tags stand in front of its title. =sp-select-note= is a selector of my own on top of it that also prints the tags in a column on the right.
3. *Links.* =id:= links in Org buffers get the emoji of the tags of the note they point to as a prefix or suffix, and the link takes the rule's face (Supercharged Links' "coloured text"). The tags come from the vulpea database.

** The rules

=sp-org-tag-groups-rules= is an alist. Each rule is =(KEY . PLIST)=:

#+begin_src emacs-lisp :tangle no
(("project"             :emoji "🚀")
 (("@writing" "deep")   :emoji "✍️" :face (:foreground "orchid"))
 ("done"                :face (:foreground "gray" :strike-through t) :position suffix))
#+end_src

- =KEY= is one tag, or a list of tags that must *all* be present, so a combination is just a longer key.
- =:emoji= is the symbol (an emoji, or any string), =:face= a face or a face plist.
- =:position= is =prefix= or =suffix= (links only; the default is =sp-org-tag-groups-link-position=).
- =:modeline nil=, =:links nil= or =:select nil= keeps a rule out of the modeline, the links or the note selection.

When several rules match, the more specific one wins its tags.

- With =sp-org-tag-groups-combo-consumes= (the default), a rule for =("@writing" "deep")= takes both tags. The single rules for =@writing= and =deep= then do not add their own emoji on top.
- Set it to nil to show every matching rule.
- The first face found, most specific rule first, is used.

** Where the tags come from

=sp-org-tag-groups-source= says what the modeline reads:

- =heading-or-file= (the default): the tags of the heading at point, or the file tags when the heading has none or point is above the first heading.
- =heading=.
- =file=.
- =both=.

Other points:

- =M-x sp-org-tag-groups-cycle-source= switches between them.
- Tags of parent headings count only if =sp-org-tag-groups-inherit= is set.

** Placing the segment

=sp-org-tag-groups-placement= is:

- =mode-line=: the segment is added to =global-mode-string=.
- =header-line=: it is the first thing in the header line of Org buffers, which works whatever modeline package draws the bottom line.

The modeline in use is lambda-line. Whether it prints =global-mode-string= has not been checked, so the header line is the fallback.

** Selecting notes

With =sp-org-tag-groups-mode= on, =vulpea-select-describe-fn= is =sp-org-tag-groups-describe-note=, which returns the emoji of the note's tags, a space and the title. It depends on the note alone, so vulpea's candidate cache stays valid (it is dropped once when the mode is turned on or off, so the new strings are built). The tags come from =vulpea-note-tags=, and the rules apply with the =select= context.

=sp-select-note= is the selector of my own. It calls =vulpea-select-from= with the same describe function and an annotation function that puts the tags in a column at the right edge of the minibuffer:

- The tag text starts at the same screen column in every row, because it is preceded by a =(space :align-to (- right N))= display property. =N= is =sp-org-tag-groups-select-column-fraction= of the frame width (a third by default), at least =sp-org-tag-groups-select-column-min= columns, worked out when the selector starts, so a wide display gets a wide column and a narrow one a narrow column.
- Each tag is a chip: its name with a space on either side, on a coloured background, in =sp-org-tag-groups-select-tags-face= (smaller than the title, height 0.85). The colour is the colour of the tag's group, see "Tag groups and their colours". The characters that fit in the column are counted from that height; chips that do not fit are replaced by an ellipsis.
- The tags stay part of the candidate text, so they can be matched: typing =deep= narrows the list to notes with that tag.
- A title that is longer than the room before the column pushes the tags to the right; it never overlaps them.

=M-x sp-insert-note= is the same for inserting a link: it runs =vulpea-insert= with the emoji in front of the titles and the tag column, and the link text is the plain title. It takes the keywords of =vulpea-insert=. No key is bound to either. The commands that link to or pick a note (=sp-org-create-note-and-link=, the wikilink conversion, =sp-tab-inbox=, =sp-move-region-to-heading=, the graph start note and the query-table pickers) call them, so every picker looks the same. Vulpea's candidate cache is skipped while either command runs, since the column width belongs to the display and not to the note. Because =sp-select-note= takes the same keywords as =vulpea-select= (=:require-match=, =:filter-fn=, =:initial-prompt=, =:expand-aliases=), it can replace a call to =vulpea-select= anywhere.

** Tag groups and their colours

=sp-org-tag-groups-alist= sorts the note tags into groups by function, in the shape proposed in [[file:../../../../../adr/0020-tag-groups.org][ADR 0020]]: a list of =(GROUP TAG…)=. Each group has a colour in =sp-org-tag-groups-colors=, chosen from the ten of Notion's tag palette (=default=, =gray=, =brown=, =orange=, =yellow=, =green=, =blue=, =purple=, =pink=, =red=). A tag that is in no group, or in a group without a colour, gets =default=.

As in Notion, a colour is a pair: a light tinted background and a dark text colour on a light theme, a dark muted background and a light text colour on a dark theme. =sp-org-tag-groups-palette= holds the pairs (=(NAME LIGHT-BG LIGHT-FG DARK-BG DARK-FG)=). The pairs are Notion's, written from memory, not read from a Notion source; change them there if a colour looks off. The theme is read from the =background-mode= of the frame each time the selector draws, so changing the theme needs no restart.

The registry file =sp-org-tag-registry.el= does not use =sp-org-tag-groups-alist= yet: it is still the flat =org-tag-persistent-alist=, and the two lists are kept in step by hand until the ADR is decided. Nested groups are not followed.

** Tag registry

The rule tags should be tags that exist. =M-x sp-org-tag-groups-check-rules= lists the tags in the rules that are not in =org-tag-alist= or =org-tag-persistent-alist=, so the alist can stay the single registry of tags and this module only decorates what is registered there.

** Fonts

The emoji need a colour emoji font. =sp-emoji-font= (a separate module in =ui/=) picks Apple Color Emoji, or Noto Color Emoji on a Linux machine without it.

*Not tested in a graphical frame* by the session that wrote this module: the matching, the modeline string, the note selector's candidates and the link overlays were run in a headless Emacs 29 and with a fake tag lookup instead of vulpea, so how they look, and whether lambda-line shows =global-mode-string=, has to be checked on the Mac.

* Matching rules

** Rule helpers

A rule's tags, whether the rule belongs to a context (=modeline= or =link=), and the matching itself. The matching rules come back in the order of their tags in the note, so the emoji follow the tag order.

#+begin_src emacs-lisp -i
;;;; Matching rules
(defun sp-org-tag-groups--rule-tags (rule)
  "The list of tags RULE requires."
  (let ((key (car rule)))
    (if (listp key) key (list key))))

(defun sp-org-tag-groups--rule-applies-p (rule context)
  "Non-nil when RULE is meant for CONTEXT: `modeline', `link' or `select'."
  (let ((plist (cdr rule)))
    (pcase context
      ('modeline (not (and (plist-member plist :modeline)
                           (null (plist-get plist :modeline)))))
      ('link (not (and (plist-member plist :links)
                       (null (plist-get plist :links)))))
      ('select (not (and (plist-member plist :select)
                         (null (plist-get plist :select)))))
      (_ t))))

(defun sp-org-tag-groups--matching-rules (tags &optional context)
  "The rules of `sp-org-tag-groups-rules' that match TAGS in CONTEXT.
The most specific rules (most tags) are tried first and, with
`sp-org-tag-groups-combo-consumes', use up their tags.  The result is
ordered by the position of each rule's first tag in TAGS."
  (let ((rules (sort (copy-sequence sp-org-tag-groups-rules)
                     (lambda (a b) (> (length (sp-org-tag-groups--rule-tags a))
                                      (length (sp-org-tag-groups--rule-tags b))))))
        consumed matched)
    (dolist (rule rules)
      (let ((need (sp-org-tag-groups--rule-tags rule)))
        (when (and need
                   (cl-every (lambda (tag) (member tag tags)) need)
                   (not (and sp-org-tag-groups-combo-consumes
                             (cl-every (lambda (tag) (member tag consumed)) need)))
                   (sp-org-tag-groups--rule-applies-p rule context))
          (push rule matched)
          (when sp-org-tag-groups-combo-consumes
            (setq consumed (append need consumed))))))
    (let ((specific-first (nreverse matched)))
      (cons (cl-stable-sort
             (copy-sequence specific-first)
             #'<
             :key (lambda (rule)
                    (apply #'min (mapcar (lambda (tag) (or (cl-position tag tags :test #'equal) 0))
                                         (sp-org-tag-groups--rule-tags rule)))))
            specific-first))))
#+end_src

The function returns a pair: the rules in tag order, and the same rules most specific first. =sp-org-tag-groups--decorate= uses the first for the emoji and the second for the face.

** Decoration of a set of tags

#+begin_src emacs-lisp -i
(defun sp-org-tag-groups--decorate (tags context)
  "Decoration of TAGS in CONTEXT, as a plist.
Keys: :emoji, a list of (EMOJI POSITION FACE TAGS) in tag order; and
:face, the face of the most specific rule that has one."
  (let* ((pair (sp-org-tag-groups--matching-rules tags context))
         (ordered (car pair))
         (specific (cdr pair)))
    (list :emoji (cl-loop for rule in ordered
                          for plist = (cdr rule)
                          when (plist-get plist :emoji)
                          collect (list (plist-get plist :emoji)
                                        (or (plist-get plist :position)
                                            sp-org-tag-groups-link-position)
                                        (plist-get plist :face)
                                        (sp-org-tag-groups--rule-tags rule)))
          :face (cl-loop for rule in specific
                         when (plist-get (cdr rule) :face)
                         return (plist-get (cdr rule) :face)))))
#+end_src

* Tags at point

** Reading heading and file tags

File tags come from =org-file-tags=, which Org fills from =#+filetags:=. Heading tags are the local ones unless =sp-org-tag-groups-inherit= is set.

#+begin_src emacs-lisp -i
;;;; Tags at point
(defun sp-org-tag-groups--file-tags ()
  "The tags of the current buffer's #+filetags:, without text properties."
  (when (derived-mode-p 'org-mode)
    (mapcar #'substring-no-properties (bound-and-true-p org-file-tags))))

(defun sp-org-tag-groups--heading-tags ()
  "The tags of the heading at point, or nil above the first heading."
  (when (derived-mode-p 'org-mode)
    (save-excursion
      (when (ignore-errors (org-back-to-heading t) t)
        (mapcar #'substring-no-properties
                (org-get-tags nil (not sp-org-tag-groups-inherit)))))))

(defun sp-org-tag-groups-tags-at-point ()
  "The tags `sp-org-tag-groups-source' selects at point."
  (pcase sp-org-tag-groups-source
    ('heading (sp-org-tag-groups--heading-tags))
    ('file (sp-org-tag-groups--file-tags))
    ('both (delete-dups (append (sp-org-tag-groups--heading-tags)
                                (sp-org-tag-groups--file-tags))))
    (_ (or (sp-org-tag-groups--heading-tags) (sp-org-tag-groups--file-tags)))))
#+end_src

* The modeline segment

** Building the string

Each emoji is propertized with its rule's face and a =help-echo= naming the tags, so hovering over the symbol tells which tags it stands for. The tag text itself is never shown.

#+begin_src emacs-lisp -i
;;;; The modeline segment
(defun sp-org-tag-groups-modeline-string ()
  "The modeline segment for the tags at point, or an empty string."
  (let* ((decoration (sp-org-tag-groups--decorate (sp-org-tag-groups-tags-at-point) 'modeline))
         (items (plist-get decoration :emoji)))
    (if (null items)
        ""
      (concat
       " "
       (mapconcat
        (pcase-lambda (`(,emoji ,_pos ,face ,tags))
          (apply #'propertize emoji
                 'help-echo (concat ":" (mapconcat #'identity tags ":") ":")
                 (when face (list 'face face))))
        items sp-org-tag-groups-separator)
       " "))))

** Adding it to the modeline or the header line

#+begin_src emacs-lisp -i
(defun sp-org-tag-groups--install-segment ()
  "Add the segment where `sp-org-tag-groups-placement' says."
  (pcase sp-org-tag-groups-placement
    ('mode-line
     (unless (listp global-mode-string)
       (setq global-mode-string (list global-mode-string)))
     (add-to-list 'global-mode-string sp-org-tag-groups-mode-line-construct t))
    ('header-line
     (add-hook 'org-mode-hook #'sp-org-tag-groups--header-line)

(defun sp-org-tag-groups--remove-segment ()
  "Remove the segment from both places."
  (setq global-mode-string
        (delete sp-org-tag-groups-mode-line-construct
                (if (listp global-mode-string) global-mode-string
                  (list global-mode-string))))
  (remove-hook 'org-mode-hook #'sp-org-tag-groups--header-line)
  (dolist (buffer (buffer-list))
    (with-current-buffer buffer
      (when (local-variable-p 'header-line-format)
        (setq header-line-format
              (delete sp-org-tag-groups-mode-line-construct
                      (if (listp header-line-format) header-line-format
                        (list header-line-format))))))))

(defun sp-org-tag-groups--header-line ()
  "Put the segment at the start of this buffer's header line."
  (let ((current (if (listp header-line-format) header-line-format
                   (list header-line-format))))
    (unless (memq sp-org-tag-groups-mode-line-construct current)
      (setq-local header-line-format
                  (cons sp-org-tag-groups-mode-line-construct current)))))

* Decorating links

** Looking up the tags of a link target

The default lookup reads the note from the vulpea database by its ID, so it only works for =id:= links; a target that is not in the database has no tags. Lookups are remembered for =sp-org-tag-groups-link-cache-seconds=, because fontification asks for every link on screen each time it runs.

#+begin_src emacs-lisp -i
;;;; Decorating links
(defvar sp-org-tag-groups--link-cache (make-hash-table :test #'equal)
  "Cache of (TYPE . PATH) to (TIME . TAGS).")

(defun sp-org-tag-groups--vulpea-link-tags (type path)
  "Tags of the vulpea note an `id' link of TYPE and PATH points to."
  (when (and (equal type "id")
             (fboundp 'vulpea-db-get-by-id)
             (fboundp 'vulpea-note-tags))
    (let* ((id (car (split-string path "::")))
           (note (ignore-errors (vulpea-db-get-by-id id))))
      (when note (vulpea-note-tags note)))))

(defun sp-org-tag-groups--link-tags (type path)
  "Cached tags of the target of a link of TYPE and PATH."
  (let* ((key (cons type path))
         (hit (gethash key sp-org-tag-groups--link-cache))
         (now (float-time)))
    (if (and hit (< (- now (car hit)) sp-org-tag-groups-link-cache-seconds))
        (cdr hit)
      (let ((tags (mapcar #'substring-no-properties
                          (funcall sp-org-tag-groups-link-tags-function type path))))
        (puthash key (cons now tags) sp-org-tag-groups--link-cache)
        tags))))

(defun sp-org-tag-groups--link-decoration (type path)
  "Decoration for a link of TYPE and PATH, or nil when no rule matches."
  (when (member type sp-org-tag-groups-link-types)
    (let ((decoration (sp-org-tag-groups--decorate (sp-org-tag-groups--link-tags type path) 'link)))
      (when (or (plist-get decoration :emoji) (plist-get decoration :face))
        decoration))))
#+end_src

** The face and the emoji

How the emoji is added to a link:

- Org asks a link type for its face with =:face= and lets =:activate-func= decorate it.
- The face function gives the rule's face.
- The activation function adds the emoji as the =before-string= and =after-string= of an overlay on the link's label, so the buffer text is not changed.
- The overlays are removed and recreated whenever Org fontifies the link again.

#+begin_src emacs-lisp -i
(defun sp-org-tag-groups--link-face (type)
  "A function giving the face of a link of TYPE, for `org-link-set-parameters'."
  (lambda (path)
    (let ((face (plist-get (sp-org-tag-groups--link-decoration type path) :face)))
      (if face (list face 'org-link) 'org-link))))

(defun sp-org-tag-groups--link-label-bounds (start end)
  "Bounds of the visible label of the link between START and END."
  (save-excursion
    (goto-char start)
    (if (looking-at org-link-bracket-re)
        (if (match-beginning 2)
            (cons (match-beginning 2) (match-end 2))
          (cons (match-beginning 1) (match-end 1)))
      (cons start end))))

(defun sp-org-tag-groups--activate-link (type)
  "An activation function for links of TYPE."
  (lambda (start end path _bracketed)
    (remove-overlays start end 'sp-org-tag-groups t)
    (when-let* ((decoration (sp-org-tag-groups--link-decoration type path))
                (items (plist-get decoration :emoji)))
      (let* ((bounds (sp-org-tag-groups--link-label-bounds start end))
             (overlay (make-overlay (car bounds) (cdr bounds) nil t nil))
             (collect (lambda (position)
                        (mapconcat #'car
                                   (seq-filter (lambda (item) (eq (nth 1 item) position))
                                               items)
                                   " "))))
        (overlay-put overlay 'sp-org-tag-groups t)
        (overlay-put overlay 'evaporate t)
        (let ((before (funcall collect 'prefix))
              (after (funcall collect 'suffix)))
          (unless (string-empty-p before)
            (overlay-put overlay 'before-string (concat before " ")))
          (unless (string-empty-p after)
            (overlay-put overlay 'after-string (concat " " after))))))))

(defun sp-org-tag-groups--set-link-parameters ()
  "Attach the face and activation functions to `sp-org-tag-groups-link-types'."
  (dolist (type sp-org-tag-groups-link-types)
    (org-link-set-parameters type
                             :face (sp-org-tag-groups--link-face type)
                             :activate-func (sp-org-tag-groups--activate-link type))))

(defun sp-org-tag-groups--clear-link-parameters ()
  "Remove the face and activation functions again."
  (dolist (type sp-org-tag-groups-link-types)
    (org-link-set-parameters type :face nil :activate-func nil))
  (dolist (buffer (buffer-list))
    (with-current-buffer buffer
      (when (derived-mode-p 'org-mode)
        (remove-overlays (point-min) (point-max) 'sp-org-tag-groups t)))))

(defun sp-org-tag-groups-refresh ()
  "Forget remembered tags and fontify Org buffers again."
  (interactive)
  (clrhash sp-org-tag-groups--link-cache)

(defun sp-org-tag-group-of (tag)
  "The groups of TAG, as a list of names, in the order of `sp-org-tag-groups-alist'."
  (cl-loop for (group . members) in sp-org-tag-groups-alist
           when (member tag (mapcar (lambda (member) (if (consp member) (car member) member))
                                    members))
           collect group))

(defvar sp-org-tag-groups--memo (make-hash-table :test #'equal)
  "Results of the selector's per-note work, by (KIND . ARGS).")

(defvar sp-org-tag-groups--memo-state nil
  "Settings `sp-org-tag-groups--memo' was filled under, compared with `eq'.")

(defun sp-org-tag-groups--memo-state ()
  "The settings and frame state the remembered selector results depend on."
  (list sp-org-tag-groups-rules sp-org-tag-groups-combo-consumes
        sp-org-tag-groups-link-position sp-org-tag-groups-alist
        sp-org-tag-groups-colors sp-org-tag-groups-palette
        (face-attribute 'sp-org-tag-groups-select-tags-face :height nil t)
        (frame-parameter nil 'background-mode)))

(defun sp-org-tag-groups--memoize (key fn)
  "The value for KEY, calling FN once per KEY until a setting changes.
`vulpea-select' asks for every note's title and tag column on each call,
so the colours, the rules and the chips are worked out once per distinct
tag list instead of once per note."
  (let ((state (sp-org-tag-groups--memo-state)))
    (unless (and sp-org-tag-groups--memo-state
                 (cl-every #'eq state sp-org-tag-groups--memo-state))
      (clrhash sp-org-tag-groups--memo)
      (setq sp-org-tag-groups--memo-state state)))
  (let ((hit (gethash key sp-org-tag-groups--memo 'sp-org-tag-groups--miss)))
    (if (eq hit 'sp-org-tag-groups--miss)
        (puthash key (funcall fn) sp-org-tag-groups--memo)
      hit)))

(defun sp-org-tag-groups--chip-face (tag)
  "Face for the chip of TAG: the colour of its first group, from the palette."
  (sp-org-tag-groups--memoize
   (cons 'face tag) (lambda () (sp-org-tag-groups--chip-face-1 tag))))

(defun sp-org-tag-groups--chip-face-1 (tag)
  "Work out the face of `sp-org-tag-groups--chip-face' for TAG."
  (let* ((group (car (sp-org-tag-group-of tag)))
         (name (or (cdr (assoc group sp-org-tag-groups-colors)) 'default))
         (entry (or (assq name sp-org-tag-groups-palette) (assq 'default sp-org-tag-groups-palette)))
         (dark (eq (frame-parameter nil 'background-mode) 'dark)))
    (list :inherit 'sp-org-tag-groups-select-tags-face
          :background (nth (if dark 3 1) entry)
          :foreground (nth (if dark 4 2) entry))))

(defun sp-org-tag-groups--chips (tags columns)
  "TAGS as coloured chips, an ellipsis replacing those that exceed COLUMNS."
  (sp-org-tag-groups--memoize
   (list 'chips columns tags) (lambda () (sp-org-tag-groups--chips-1 tags columns))))

(defun sp-org-tag-groups--chips-1 (tags columns)
  "Build the chips of `sp-org-tag-groups--chips' for TAGS within COLUMNS."
  (let* ((height (face-attribute 'sp-org-tag-groups-select-tags-face :height nil t))
         (height (if (numberp height) height 1.0))
         (room (max 4 (floor (/ columns height))))
         (used 0) chips)
    (catch 'full
      (dolist (tag tags)
        (let ((width (+ (string-width tag) 2 (if chips 1 0))))
          (when (> (+ used width) (1- room))
            (push (propertize "…" 'face 'sp-org-tag-groups-select-tags-face) chips)
            (throw 'full nil))
          (setq used (+ used width))
          (when chips (push " " chips))
          (push (propertize (concat " " tag " ") 'face (sp-org-tag-groups--chip-face tag)) chips))))
    (apply #'concat (nreverse chips))))
#+end_src

** The tag column

The width is worked out once per selection and bound while the selector runs. The annotation is a space with an =:align-to= display property followed by the tag chips; text with a smaller face needs more characters per column, so the number of characters that fit is the column width divided by the face height.

#+begin_src emacs-lisp -i

(defun sp-org-tag-groups--select-columns ()
  "Columns for the tag column, from the width of the selected frame."
  (max sp-org-tag-groups-select-column-min
       (round (* sp-org-tag-groups-select-column-fraction (frame-width)))))

(defun sp-org-tag-groups--annotate-note (note)
  "The tags of NOTE at the right edge, for `vulpea-select-annotate-fn'."
  (let ((columns (or sp-org-tag-groups--select-columns (sp-org-tag-groups--select-columns)))
        (tags (mapcar #'substring-no-properties (vulpea-note-tags note))))
    (if (null tags)
        ""
      (concat (propertize " " 'display `(space :align-to (- right ,columns)))
              (sp-org-tag-groups--chips tags columns)))))

** Tag menu

=sp-org-tag-groups-read-tags= reads several tags with =completing-read-multiple= over =sp-org-tag-groups-completion-table=: the tags are sorted and headed by their first group in =sp-org-tag-groups-alist= (tags in no group under "other"), each annotated with its group in the group's colour. =sp-org-tag-read-note-tags= (in =sp-org-tag-lint=) calls it when this module is loaded.

#+begin_src emacs-lisp -i
;;;; Tag menu
(defun sp-org-tag-groups-completion-table (tags)
  "A completion table over TAGS, sorted and headed by tag group.
Tags in no group fall under \"other\"."
  (let ((sorted (sort (copy-sequence tags)
                      (lambda (a b)
                        (let ((ga (or (car (sp-org-tag-group-of a)) "~other"))
                              (gb (or (car (sp-org-tag-group-of b)) "~other")))
                          (if (string= ga gb) (string< a b) (string< ga gb)))))))
    (lambda (string pred action)
      (if (eq action 'metadata)
          `(metadata
            (display-sort-function . identity)
            (group-function
             . ,(lambda (tag transform)
                  (if transform tag (or (car (sp-org-tag-group-of tag)) "other"))))
            (annotation-function
             . ,(lambda (tag)
                  (concat " " (propertize (or (car (sp-org-tag-group-of tag)) "other")
                                          'face (sp-org-tag-groups--chip-face tag))))))
        (complete-with-action action sorted string pred)))))

(defun sp-org-tag-groups-read-tags (prompt tags)
  "Read several of TAGS with PROMPT, grouped by tag group.
Return the chosen tags as a list of strings; typing a tag not in TAGS
is allowed."
  (completing-read-multiple prompt (sp-org-tag-groups-completion-table tags)))
