This module installs =beets-edit-mode=, a major mode for the temporary YAML-like buffers that the =beets= music library manager opens when you run =beet edit= with Emacs as the editor.

- The external =beets= program and its =edit= plugin must be installed separately.
- =EDITOR= must point at Emacs (for example =emacsclient=) for the mode to come into play.
- The author's opening comment asks exactly how this should be wired up.

The module is not listed in any module list or profile. It also has no =(provide 'sp-beets)= form, so loading it with =require= would signal an error after the code runs; it can only be used with =load= as it stands.

** beets-edit-mode

Installs the package from GitHub.

- Beets writes its edit buffers to randomly named temporary files, so the mode cannot be chosen by file name.
- Instead, an entry in =magic-mode-alist= calls =beets-edit-buffer-p= to recognise such buffers by their contents.
- Two optional hooks start the mode in its compact view with =beets-edit-compact-mode=, and turn on =electric-quote-local-mode=, which inserts curly quotes while typing.
- Curly quotes will be written into tag values as typed.

#+begin_src emacs-lisp -i
(use-package beets-edit-mode
  :ensure (:host github :repo "emreyolcu/beets-edit-mode")
  :init
  ;; The plugin's buffers have random temporary file names,
  ;; so nothing associates them with the mode; detect them by content.
  (add-to-list 'magic-mode-alist '(beets-edit-buffer-p . beets-edit-mode))
  :hook
  ;; Both are optional.
  ((beets-edit-mode . beets-edit-compact-mode)      ; start in the compact view
   (beets-edit-mode . electric-quote-local-mode)))  ; curly quotes as you type
#+end_src
