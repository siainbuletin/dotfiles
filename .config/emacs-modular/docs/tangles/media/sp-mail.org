Literate source for =libraries/modules/media/sp-mail.el=. Every =emacs-lisp= block below goes into that file, except the blocks marked =:tangle no=. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

This module is meant to hold the mail setup. The planning notes in =sp-mail-old.org= say the first client to try is =notmuch=, because it works well with =consult-recoll=. They also list the open questions: local mail storage, an address book (=org-contacts= or BBDB), encryption through GnuPG, and making Disroot work. =conditional-loading.org= lists the module as "EMPTY".

The =.el= file is empty for now, and nothing in =init.el= or =sp-config-profiles.el= loads it. The blocks below are a skeleton for when you fill it in. Tangling it now replaces the empty file with a valid module that loads and does nothing, so =(sp-require-module 'sp-mail)= would succeed.

The commentary at the top of the module says:

#+begin_quote
Mail reading, searching and sending from Emacs.
#+end_quote
