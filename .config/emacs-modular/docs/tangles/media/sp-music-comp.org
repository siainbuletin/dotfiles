This module is meant to hold the configuration for writing and working with music from Emacs. The planning notes in =sp-music-composition.org= describe the goals: control an audio server, write scores declaratively in the spirit of OpusModus rather than engraving by hand, and live-code music through REPLs.

Status:

- The =.el= file is empty for now, and nothing in =init.el= or =sp-config-profiles.el= loads it.
- The blocks below are a skeleton for when you fill it in.
- Tangling it now replaces the empty file with a valid module that loads and does nothing, so =(sp-require-module 'sp-music-comp)= would succeed.

I'm not actually looking for a way to write directly like Dorico, but rather to write my scores somehow declaratively and be able to interact with my music more easily. Something like _replicating_ how OpusModus works would genuinely be great.
