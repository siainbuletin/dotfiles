Literate source for =libraries/modules/media/sp-music-comp.el=. Every =emacs-lisp= block below goes into that file, except the blocks marked =:tangle no=. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

This module is meant to hold the configuration for writing and working with music from Emacs. The planning notes in =sp-music-composition.org= describe the goals: control an audio server, write scores declaratively in the spirit of OpusModus rather than engraving by hand, and live-code music through REPLs.

The =.el= file is empty for now, and nothing in =init.el= or =sp-config-profiles.el= loads it. The blocks below are a skeleton for when you fill it in. Tangling it now replaces the empty file with a valid module that loads and does nothing, so =(sp-require-module 'sp-music-comp)= would succeed.
