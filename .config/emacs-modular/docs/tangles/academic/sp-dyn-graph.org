This module installs =vulpea-graph= from the Arenile/vulpea-graph-ui GitHub repository, an interactive graph view of Vulpea notes served to a browser. It needs the =websocket= and =simple-httpd= packages, and builds on the Vulpea setup loaded through =sp-org-ext=. The module is loaded in the Academic block of the default module list in =init.el=.

** Vulpea graph package

Installs =vulpea-graph= along with its =assets= folder, which holds the browser side files. The commands =vulpea-graph= and =vulpea-graph-mode= are autoloaded. The =:after= clause holds the configuration back until both =websocket= and =simple-httpd= are loaded; since use-package wraps the whole form, including the autoloads, in that condition, the commands may only become available once those two libraries have been loaded by something else.

#+begin_src emacs-lisp -i
(use-package vulpea-graph
  :ensure (:host github :repo "Arenile/vulpea-graph-ui" :files ("*.el" "assets"))
  :after (websocket simple-httpd)
  :commands
  (vulpea-graph vulpea-graph-mode))
#+end_src
