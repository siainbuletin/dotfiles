This module installs ESS (Emacs Speaks Statistics), which provides editing modes and interactive sessions for R and other statistics languages.

- It is a single package declaration with no further configuration.
- It is listed in the Academic block of =init.el= but commented out, so it is not loaded by default.

** Install ESS

Installs the =ess= package with its default settings. Its modes are set up by the package's own autoloads, so opening an R file uses ESS once it is installed.

#+begin_src emacs-lisp -i
(use-package ess
  :ensure t)
#+end_src
