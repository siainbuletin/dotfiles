* sp-academic.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/academic/sp-academic.el
:END:

This is the umbrella module for academic work.

- Loads five sub-modules (=sp-bibprocess=, =sp-pdfprocess=, =sp-citations=, =sp-litnotes= and =sp-fetch-academic=) so they can be enabled together.
- Defines the three citation user options before any sub-module needs them.
- Configures the reference managers directly:
  - =org-ref= set up to insert =org-cite= citations,
  - =helm-bibtex= library and notes paths,
  - the =citar-org-node= bridge,
  - the =binder= package for Scrivener-like manuscript work.
- The list of =.bib= files is no longer written here: =sp-bibtex-register= in =sp-bibprocess= finds every =.bib= file in =~/Documents/bibliography/= and hands the list to Org, =citar=, =org-ref= and =helm-bibtex= alike.

The long commentary is a roadmap more than a description.

- Planned pieces: DEVONthink integration, deep links into PDFs, semantic search over PDFs. Paper fetching now has its own sub-module, [[file:sp-fetch-academic.org][sp-fetch-academic]].
- Literature notes are still made with =citar-denote=. =ROAM_REFS= handling goes through =vulpea-citar=.
- Bibliography files are expected under =~/Documents/bibliography/=, PDFs under =~/Documents/literature/=.
- The module appears in the default module list in =init.el= under Academic.

** Citation keys

Every entry in a plain BibTeX file gets its key from =bibtex-generate-autokey=, with one scheme everywhere. The options are set once, in =sp-bibprocess=.

- Shape: the family names of the first two authors, four-digit year and the first two significant title words, each cut to five letters and joined by hyphens, all in lower case, for example =smithjones-2017-atten-all= (Smith and Jones, Attention Is All You Need) or =hegel-1807-phanom-geist= (one author). "Is" is in the ignore list, so it is skipped. A third word is added when the second is short (=bibtex-autokey-titlewords-stretch= is 1).
- Several authors: the first two are joined without a separator and later ones are dropped, so Smith, Jones and Lee is still =smithjones-2017-...=.
- Accents are stripped to plain ASCII (=Müller= becomes =muller=) so keys survive any tool.
- The title words skip articles (English and German), "Is", "the", "a", "On" and "on" (the last five are your additions), and any word that is not capitalised or has odd characters.
- Three ways to apply it: =C-c C-c= in =bibtex-mode= cleans an entry (=C-u C-c C-c= also makes a new key), =biblio= entries get one on insertion (=biblio-bibtex-use-autokey=), and the key is checked against every registered =.bib= file so duplicates are noticed.
- Existing keys are left alone. Changing a key breaks the =cite:= links and =ROAM_REFS= that mention it, so regenerate only entries you have not cited yet.

** Settings worth knowing

The ones that change how the setup behaves most. All are set in the modules named in brackets.

- =bibtex-autokey-*= [=sp-bibprocess=]: the key scheme above. =bibtex-autokey-edit-before-use= is =t=, so =bibtex-clean-entry= shows the key in the minibuffer for approval.
- =bibtex-entry-format= [=sp-bibprocess=]: what cleaning does to an entry (page dashes, whitespace, alignment, trailing comma, braces). Required-field checks are left out so incomplete =biblio= entries are not rejected.
- =bibtex-search-entry-globally= with =bibtex-files= [=sp-bibprocess=]: key look-ups and duplicate checks span all registered files, not just the open buffer.
- =bibtex-dialect= [=sp-bibprocess=]: =biblatex=, so =date=, =journaltitle= and =file= are valid fields.
- =sp-bibliography-dir= [=sp-bibprocess=]: where the =.bib= files live. Add or remove a file, then run =C-c w b r=.
- =org-cite-global-bibliography= and =citar-bibliography= [=sp-citations=]: both read the registered list, so Org and =citar= always see the same files.
- =citar-library-paths=, =citar-library-file-extensions=, =citar-file-additional-files-separator= [=sp-citations=]: where =citar= looks for PDFs (=~/Documents/literature/=), which extensions count, and the separator for several files per key. The library path was commented out before, so =citar= found no PDFs.
- =citar-notes-paths= and =citar-templates= [=sp-citations=]: where notes live and how candidates are displayed.
- =org-cite-export-processors= [=sp-citations=]: CSL for every export format; needs the styles in =sp-data-home=.
- =biblio-bibtex-use-autokey= [=sp-fetch-academic=]: gives entries inserted from CrossRef, arXiv and DOI the same key scheme.

The old sections of this document that set BibTeX options twice, repeated three definitions or tried to set Citar options inside =:custom= are fixed below, and each fix says so.

*** Showing cite keys in descriptive links

=org-ref-make-org-link-cite-key-visible= runs after =org-activate-bracket-links= highlights a link.

- When the link target starts with one of =org-ref-cite-types=, it removes the invisibility from the whole link and colours it with =org-ref-cite-color=.
- So the cite key stays visible even when the link has a description.
- It uses =-sort= from =dash= to try longer cite types first.

#+begin_src emacs-lisp -i
(defun org-ref-make-org-link-cite-key-visible (&rest _)
  "Make the org-ref cite link visible in descriptive links."

  (save-match-data
    (let ((s (match-string 1))
      (beg (match-beginning 0))
      (end (match-end 0))
      (cite-re (format "^\\(%s:\\)"
               (regexp-opt (-sort
                    (lambda (a b)
                      (> (length a) (length b)))
                    org-ref-cite-types))))
      cite-type)

      (when (and s (string-match cite-re s))
    (setq cite-type (match-string 1 s))
    (remove-text-properties beg end
                '(invisible))
    (add-text-properties
     beg end
     `(face (:foreground ,org-ref-cite-color)))))))
#+end_src

* sp-bibprocess.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/academic/sp-bibprocess.el
:END:

This module manages the BibTeX bibliography that the academic modules build on. It:

- defines where the =.bib= files live (=sp-bibliography-dir=, =~/Documents/bibliography/= by default),
- keeps one list of them and shares it with Org's citation system (=org-cite-global-bibliography=), =citar= (=citar-bibliography=), =org-ref= (=org-ref-default-bibliography=), =helm-bibtex= (=bibtex-completion-bibliography=) and =bibtex-mode= itself (=bibtex-files=),
- configures the built-in =bibtex= mode for BibLaTeX, including the one scheme for citation keys described under [[*Citation keys]],
- adds commands to audit attachments. Looking up new entries online (=biblio=) moved to [[file:sp-fetch-academic.org][sp-fetch-academic]].

Loading:

- It is not listed directly in the module profiles; =sp-academic= loads it with =require=.
- It used to repeat the variable, the register command and the lookup helper verbatim under a "BIBLIOGRAPHY" heading, and to set the key options a second time in =sp-academic=. Both repeats are gone, so every option has one definition.

*** Bibliography directory

The folder holding the BibTeX files and their attachments is =sp-bibliography-dir=, defined in =sp-globals= (=~/Documents/bibliography/= by default, or the folder named by =SP_BIBLIOGRAPHY_DIR=). This module used to define a second option, =sp-bibtex-dir=, that only copied it; there is now one option, and the old name is gone with no alias.


*** List of BibTeX files

=sp-bibtex-file-regexp= matches the =.bib= files that count: a name that starts with a letter or digit (so editor backups and dotfiles are skipped) and ends in =.bib=. The old pattern =^[A-Z|a-z|0-9].+.bib$= also matched names like =x-bib= and, through the literal =|=, names starting with a pipe.

=sp-bibtex-files= is filled at load time with every matching file in the directory, or left =nil= if the directory does not exist.

#+begin_src emacs-lisp -i
(defconst sp-bibtex-file-regexp "\\`[[:alnum:]].*\\.bib\\'"
  "Regexp for the names of the BibTeX files in `sp-bibliography-dir'.")

(defvar sp-bibtex-files
  (when (file-exists-p sp-bibliography-dir)
    (directory-files sp-bibliography-dir t sp-bibtex-file-regexp))
  "List of BibTeX files. Use `sp-bibtex-register' to configure.")
#+end_src

*** Register BibTeX files

=sp-bibtex-register= rescans =sp-bibliography-dir= and gives the same list to every consumer, then echoes the registered files.

- =sp-bibtex-files=, the list itself.
- =org-cite-global-bibliography= and =citar-bibliography=, for citations in Org and for =citar=.
- =org-ref-default-bibliography= and =bibtex-completion-bibliography=, for =org-ref= and =helm-bibtex=.
- =bibtex-files=, so that with =bibtex-search-entry-globally= a key is looked up (and checked for duplicates) in all of them.

Run it after adding or removing a =.bib= file.

#+begin_src emacs-lisp -i
;;;###autoload
(defun sp-bibtex-register ()
  "Register the contents of the `sp-bibliography-dir' with `sp-bibtex-files`.
Use when adding or removing a BibTeX file from or to `sp-bibliography-dir'."
  (interactive)
  (when (file-exists-p sp-bibliography-dir)
    (let ((bib-files (directory-files sp-bibliography-dir t sp-bibtex-file-regexp)))
      (setq sp-bibtex-files bib-files
            org-cite-global-bibliography bib-files
            citar-bibliography bib-files
            org-ref-default-bibliography bib-files
            bibtex-completion-bibliography bib-files
            bibtex-files bib-files)))
  (message "Registered:\n%s" (mapconcat #'identity sp-bibtex-files "\n")))
#+end_src

** Citation keys

*** Key helper

=sp-bibtex-ascii-key= is the =bibtex-autokey-before-presentation-function=: it receives the generated key and returns it with accents removed. The key is decomposed (=ü= into =u= and a combining mark) and everything outside ASCII is dropped, so =müller2020= becomes =muller2020=. Authors in a non-Latin script would lose their name entirely, so an empty result keeps the original key.

#+begin_src emacs-lisp -i
;;;; Citation keys

(require 'ucs-normalize)

(defun sp-bibtex-ascii-key (key)
  "Return KEY as plain ASCII, or KEY itself when nothing is left."
  (let ((ascii (replace-regexp-in-string
                "[^[:ascii:]]" "" (ucs-normalize-NFKD-string key))))
    (if (string-empty-p ascii) key ascii)))
#+end_src

*** bibtex

Configures the built-in =bibtex= mode:

- the BibLaTeX dialect,
- the key scheme (see [[*Citation keys]] in the first part of this document): first two authors, four-digit year and two title words of at most five letters, in lower case, with hyphens between year and title words, such as =smithjones-2017-atten-all=,
- the articles to skip in the title (English and German, plus any word that is not capitalised or has odd characters), now also "Is", "the", "a", "On" and "on",
- what cleaning an entry does: =opts-or-alts= (drop empty optional fields), =page-dashes= (=10-20= to =10--20=), =whitespace=, =realign=, =last-comma=, =delimiters=, =unify-case= and =braces=. =required-fields= and =numerical-fields= are left out so that an incomplete entry from a look-up is not rejected,
- a duplicate check across all registered files,
- two extra optional fields offered when creating entries (=keywords= and =file= for attachments),
- alignment of field values at the equals sign.

Also:

- =bibtex-aux-opt-alist= carries the same two fields. It used to be saved by Customize in =init.el= and is now set here.
- =:demand t= loads it at once, which registers the bibliography files (=sp-bibtex-register= in =:config=) before anything reads them; =sp-academic= used to do that with =(require 'bibtex)=.
- =C-c w b r= runs =sp-bibtex-register= at any time.
- =H-b= in a BibTeX buffer opens the org-ref hydra (it needs a Hyper key). It was =define-key= in =sp-academic=.

#+begin_src emacs-lisp -i
(use-package bibtex
  :ensure nil
  :demand t
  :custom
  (bibtex-dialect 'biblatex)

  ;; Keys: smith-2017-atten-all
  (bibtex-autokey-names 2)
  (bibtex-autokey-names-stretch 0)
  (bibtex-autokey-name-separator "")
  (bibtex-autokey-name-year-separator "-")
  (bibtex-autokey-year-length 4)
  (bibtex-autokey-year-title-separator "-")
  (bibtex-autokey-titlewords 2)
  (bibtex-autokey-titlewords-stretch 1)
  (bibtex-autokey-titleword-length 5)
  (bibtex-autokey-titleword-separator "-")
  (bibtex-autokey-name-case-convert-function #'downcase)
  (bibtex-autokey-titleword-case-convert-function #'downcase)
  (bibtex-autokey-before-presentation-function #'sp-bibtex-ascii-key)
  (bibtex-autokey-edit-before-use t)
  (bibtex-autokey-titleword-ignore
   '("A" "An" "The" "Is" "the" "a" "On" "on" "Eine?" "Der" "Die" "Das"
     "[^[:upper:]].*" ".*[^[:upper:][:lower:]0-9].*"))

  ;; Cleaning and duplicates
  (bibtex-entry-format
   '(opts-or-alts page-dashes whitespace realign last-comma
                  delimiters unify-case braces))
  (bibtex-search-entry-globally t)

  (bibtex-user-optional-fields
   '(("keywords" "Keywords to describe the entry" "")
     ("file"     "Relative or absolute path to attachments" "" )))
  (bibtex-align-at-equal-sign t)
  (bibtex-aux-opt-alist
   '(("keywords" "Keywords to describe the entry" "")
     ("file" "Relative or absolute path to attachments" "")))
  :config
  (sp-bibtex-register)
  :bind
  (("C-c w b r" . sp-bibtex-register)
   :map bibtex-mode-map
   ("H-b" . org-ref-bibtex-hydra/body))
)
#+end_src

** Auditing attachments

Two reports that compare the files stored in =sp-bibliography-dir= against the =file= fields in the BibTeX entries.

*** Collect attachment paths from entries

=sp--bibtex-extract-attachments= re-registers the bibliography and scans each =.bib= file for =file = {...}= fields, splitting multiple attachments on semicolons and expanding each path relative to =sp-bibliography-dir=.

#+begin_src emacs-lisp -i
;; Search for missing BibTeX attachments and filenames
(defun sp--bibtex-extract-attachments ()
  "Extract attachment file names from BibTeX files in `sp-bibliography-dir'."
  (sp-bibtex-register)
  (let ((attachments '()))
    (dolist (bibtex-file sp-bibtex-files)
      (with-temp-buffer
        (insert-file-contents bibtex-file)
        (goto-char (point-min))
        (while (re-search-forward "file.*=.*{\\([^}]+\\)}" nil t)
          (let ((file-paths (split-string (match-string 1)
                                          "[[:space:]]*;[[:space:]]*")))
            (dolist (file-path file-paths)
              (push (expand-file-name (string-trim file-path)
                                      sp-bibliography-dir)
                    attachments))))))
    attachments))
#+end_src

*** Collect files on disk

=sp--bibtex-extract-files= lists every file under =sp-bibliography-dir= recursively, leaving out =.bib= and =.csl= files.

#+begin_src emacs-lisp -i
(defun sp--bibtex-extract-files ()
  "List files recursively in `sp-bibliography-dir', excluding `.bib' and `.csl'."
  (seq-remove (lambda (file)
                (or (string-suffix-p ".bib" file)
                    (string-suffix-p ".csl" file)))
              (mapcar 'expand-file-name
                      (directory-files-recursively sp-bibliography-dir ""))))
#+end_src

*** Files with no entry

=sp-bibtex-missing-files= reports files on disk that no BibTeX entry refers to, printing the count and each path to the =*Messages*= buffer.

#+begin_src emacs-lisp -i
;;;###autoload

** PDF metadata from Citar

*** Writing title and author into a PDF

=sia-citar-update-pdf-metadata= updates a PDF's embedded metadata.

- Asks you to pick a reference with =citar-select-ref=.
- Checks that =citar-library-paths= is set, and finds the PDF files attached to that key. If there is more than one, you choose.
- Takes the title from the bibliography, and the author, falling back to the editor with " (ed.)" appended.
- Copies the PDF into the backup directory.
- Runs =exiftool= to overwrite the Title and Author fields in place.

The =let*= used to refer to =cite-key= (with a hyphen) although the argument is =citekey=, which signalled a void-variable error; it now uses =citekey=. #+begin_src emacs-lisp -i
;;;; Working with PDF metadata from citar
(defun sia-citar-update-pdf-metadata (citekey)
  (interactive (list (citar-select-ref)))
  (citar--check-configuration 'citar-library-paths)
  (unless citar-library-paths
    (user-error "Make sure `citar-library-paths' is non-nil"))
  (let* ((files (gethash citekey (citar-get-files citekey))))
    (unless files
      (user-error (format "There are no PDF files associated with %s" citekey)))
    (let ((file (or (unless (cdr files) (car files)) (completing-read "Please select a PDF file: " files)))
          (title (citar-get-value 'title citekey))
          (author (cond ((citar-get-value 'author citekey)
                         (citar-get-value 'author citekey))
                        ((citar-get-value 'editor citekey)
                         (concat (citar-get-value 'editor citekey) " (ed.)")))))
      (progn
        (copy-file file sia-citar-library-backup-path 1)
        (call-process-shell-command
         (concat "exiftool -overwrite_original_in_place -Title='" title "' -Author='" author "' " file))))))

*** Citation hover

Hovering over a =[cite:@key]= link shows the full reference of the entry, modelled on the hover card of Obsidian's Pandoc Reference List. The text is the =preview= template of =citar-templates=, so change that template to change the hover text. =sp-cite-hover-display= chooses where it appears:

- =tooltip=: the =help-echo= of the link, shown when the mouse rests on it. A font-lock matcher adds the property to every =[cite...]= link in Org buffers, so it survives Org's own link fontification.
- =echo=: an Eldoc function (=sp-cite-hover--eldoc=) shows the reference in the echo area when point is on the link. Eldoc only follows point, not the mouse.

On a link with several keys, the reference is the one under the mouse or point, or the first key when it is on the prefix, suffix or style. A key missing from the bibliography shows =@key: not found in the bibliography=. Set =sp-cite-hover-display= to nil to turn both off; changing it needs no restart, but a new value for =tooltip= applies as buffers are refontified.

Tested in Emacs 29.3 in batch, with =citar= stubbed (key lookup, tooltip, Eldoc callback, outside a link); not run in the interactive config.

#+begin_src emacs-lisp -i
;;;; Citation hover
;; Show the formatted reference of the citation under the mouse or point.
(defcustom sp-cite-hover-display '(tooltip echo)
  "Where to show the reference of the `[cite:@key]' link under the mouse or point.
`tooltip' sets the `help-echo' of the link, shown when the mouse hovers over
it.  `echo' adds an Eldoc function, which shows the reference in the echo area
when point is on the link.  Set it to nil to turn both off."
  :type '(set (const :tag "Tooltip on mouse hover" tooltip)
              (const :tag "Echo area when point is on the link" echo))
  :group 'sp)

(defconst sp-cite-hover--link-regexp
  "\\[cite\\(?:/[-_/[:alnum:]]*\\)?:[^]]*\\]"
  "Regexp matching an Org citation such as `[cite/t:see @key1; @key2 p. 3]'.")

(defconst sp-cite-hover--key-regexp
  "@\\([-.:?!`'/*@+|(){}<>&_^$#%~[:alnum:]]+\\)"
  "Regexp matching a citation key, with the key itself in group 1.")

(defun sp-cite-hover--key-at (pos)
  "Return the citation key at POS, or the first key of the citation around it.
Return nil when POS is not inside a `[cite:]' link."
  (save-excursion
    (goto-char pos)
    (let ((line-start (line-beginning-position))
          (line-end (line-end-position))
          found)
      (while (and (not found)
                  (re-search-backward "\\[cite" line-start t))
        (when (and (looking-at sp-cite-hover--link-regexp)
                   (<= pos (match-end 0)))
          (setq found (cons (match-beginning 0) (match-end 0)))))
      (when found
        (goto-char (car found))
        (let (first at-pos)
          (while (and (not at-pos)
                      (re-search-forward sp-cite-hover--key-regexp
                                         (min (cdr found) line-end) t))
            (unless first (setq first (match-string-no-properties 1)))
            (when (and (<= (match-beginning 0) pos) (<= pos (match-end 0)))
              (setq at-pos (match-string-no-properties 1))))
          (or at-pos first))))))

(defun sp-cite-hover--reference (key)
  "Return the formatted reference of KEY from the bibliography, or nil.
It uses the `preview' template of `citar-templates'."
  (when (and key (require 'citar nil t))
    (when-let* ((entry (citar-get-entry key))
                (text (citar-format--entry (citar-get-template 'preview) entry)))
      (string-trim (substring-no-properties text)))))

(defun sp-cite-hover--help-echo (_window object pos)
  "Return the reference of the citation at POS in OBJECT for `help-echo'."
  (when (and (memq 'tooltip sp-cite-hover-display) (bufferp object))
    (with-current-buffer object
      (when-let* ((key (sp-cite-hover--key-at pos)))
        (or (sp-cite-hover--reference key)
            (format "@%s: not found in the bibliography" key))))))

(defun sp-cite-hover--fontify (limit)
  "Put the `help-echo' tooltip on the citations up to LIMIT.
It is a font-lock matcher: it adds the property and never fontifies."
  (while (re-search-forward sp-cite-hover--link-regexp limit t)
    (add-text-properties (match-beginning 0) (match-end 0)
                         '(help-echo sp-cite-hover--help-echo)))
  nil)

(defun sp-cite-hover--eldoc (callback &rest _)
  "Eldoc function: show the reference of the citation at point with CALLBACK."
  (when (memq 'echo sp-cite-hover-display)
    (when-let* ((key (sp-cite-hover--key-at (point)))
                (text (sp-cite-hover--reference key)))
      (funcall callback text :thing (concat "@" key) :face 'font-lock-doc-face))))

(defun sp-cite-hover-setup ()
  "Turn on the citation tooltip and echo area reference in this Org buffer."
  (add-hook 'eldoc-documentation-functions #'sp-cite-hover--eldoc nil t)
  (font-lock-add-keywords nil '((sp-cite-hover--fontify)) 'append)
  (font-lock-flush))

(add-hook 'org-mode-hook #'sp-cite-hover-setup)
#+end_src

* sp-litnotes-refs.el
:PROPERTIES:
:header-args:emacs-lisp+: :tangle ../../../libraries/modules/academic/sp-litnotes-refs.el
:END:

Moves the reference of each literature note from the =#+reference:= keyword of =citar-denote= to the =ROAM_REFS= property that =citar-vulpea= reads. Required by =sp-litnotes=.

- =M-x sp-litnotes-refs-report= is a dry run: it writes nothing and shows a report in =*litnote refs*=.
- =M-x sp-litnotes-refs-convert= shows the same report and then asks up to three questions, each only when there is something to do: move the references of the notes that have an ID; create an ID for the notes that have none; add stub entries to the inbox BibTeX file. Every note it changes, and the inbox file, is copied to =litnote-refs-backups/= under =sp-var-dir= first. It is safe to run again.
- What it does to a note in =sp-litnotes-refs-directory= (default =~/notes/litnotes/=):
  - =convert=: no =ROAM_REFS=, has =#+reference: key=. It adds =:ROAM_REFS: @key= to the top property drawer and removes the keyword.
  - =merge=: has both. The keys are joined (no key twice) and the keyword is removed.
  - =normalise=: =ROAM_REFS= holds the key as =key=, =cite:key= or =[cite:@key]=. It is rewritten as =@key=; URLs and DOIs in the value are kept as they are. =citar-vulpea= only reads =@key=, so a bare key is invisible to it.
  - =ok= and =no-reference= notes are not touched.
  - =no-id=: the note has no top-level property drawer with an =:ID:=, so it is not a file-level Vulpea node. If you agree to the second question, the note gets a property drawer with a new =:ID:= (an =org-id= UUID) and its =ROAM_REFS=, and loses its =#+reference:= keyword. Otherwise it is listed and skipped.
- The report also shows:
  - keys that no registered =.bib= file has (=sp-bibtex-files=),
  - keys used by more than one note,
  - for every key whether a PDF named after it is in =sp-literature-dir=, or only one named after its =crossref= parent (a book section whose PDF is the book). The later DEVONthink link needs this: see [[file:../../architecture/devonthink-emacs-integration.org][DEVONthink and Emacs]].
- Stub entries: a key (from any note, with or without an ID) that no registered =.bib= file has gets a stub in =sp-litnotes-refs-inbox-bib= (default =master.bib= in =sp-bibliography-dir=), which is the inbox of the bibliography. The entry type comes from the file tag of the note (=journalarticle= is =article=, =booksection= is =incollection=, =book=, =collection=, =inreference=, =phdthesis=; anything else =misc=); the title is =pub-title= or, if that is missing or equals the key, the note title; =author=, =year= and =pages= come from =pub-author=, =pub-year= and =pub-pages=, with links reduced to their text; =file= is added only when =KEY.pdf= exists in =sp-literature-dir=; a =note= field says which litnote the stub came from, and =DATE_ADDED= is the time. A key used by several notes gets one stub. The old keys of Denote-era notes (such as =kant2009ideea=) have no entry, so each gets a stub under that old key; renaming them to the new scheme is a separate job.
- BibTeX files are read with a small scanner (entry key and =crossref= field only), not a full parser.
- The =#+reference:= keyword is deleted from converted notes, so the Denote-based commands no longer find the key. The backup folder has the old files.

#+begin_src emacs-lisp -i
;;; sp-litnotes-refs.el --- Move litnote references to ROAM_REFS -*- lexical-binding: t; -*-

;;; Commentary:

;; `citar-denote' stored a note's citation key in a `#+reference:' keyword.
;; `citar-vulpea' reads `@key' values from a property, `ROAM_REFS'.  This module
;; reports what would change (`sp-litnotes-refs-report') and then converts the
;; notes (`sp-litnotes-refs-convert').  Nothing is written by the report.

;;; Code:

(require 'cl-lib)
(require 'subr-x)

;;;; Reading references

(defun sp-litnotes-refs--tokens (string)
  "Split the reference STRING into (KEYS . OTHERS).
KEYS are citation keys without a prefix; OTHERS are values that are not keys
(URLs, DOIs) and are kept as they are.  `@key', `key', `cite:key' and
`[cite:@a;@b]' are all read."
  (let ((clean (replace-regexp-in-string "\\[cite[^:]*:\\|\\]" "" (or string "")))
        keys others)
    (dolist (token (split-string clean "[ \t;,]+" t))
      (let ((bare (replace-regexp-in-string "\\`\\(cite:\\)?@?" "" token)))
        (cond ((string-match-p "\\`https?:\\|\\`doi:\\|/" token) (push token others))
              ((string-match-p sp-litnotes-refs--key-regexp bare) (push bare keys))
              (t (push token others)))))
    (cons (nreverse keys) (nreverse others))))

(defconst sp-litnotes-refs--meta-keys '("pub-title" "pub-author" "pub-year" "pub-pages")
  "Metadata of a litnote that a stub BibTeX entry takes over.")

(defun sp-litnotes-refs--clean-value (value)
  "VALUE without quotes, and with Org links reduced to their text."
  (let* ((v (string-trim value))
         (v (replace-regexp-in-string "\\[\\[[^]]*\\]\\[\\([^]]*\\)\\]\\]" "\\1" v))
         (v (replace-regexp-in-string "\\[\\[[^]]*\\]\\]" "" v))
         (v (replace-regexp-in-string "\\`\"\\(.*\\)\"\\'" "\\1" v)))
    (string-trim v)))

(defun sp-litnotes-refs--parse (file)
  "Read the reference data of the note FILE as a plist.
The keys are :file, :id, :roam (the =ROAM_REFS= value), :keyword (the
=#+reference:= value) and :drawer (non-nil when the note starts with a
property drawer, which a file-level Vulpea node needs)."
  (with-temp-buffer
    (insert-file-contents file)
    (let (id roam keyword title tags meta drawer-end (case-fold-search t))
      (goto-char (point-min))
      (when (looking-at ":PROPERTIES:[ \t]*$")
        (when (re-search-forward "^:END:[ \t]*$" nil t)
          (setq drawer-end (line-beginning-position))
          (goto-char (point-min))
          (when (re-search-forward "^:ID:[ \t]+\\(.+\\)$" drawer-end t)
            (setq id (match-string 1)))
          (goto-char (point-min))
          (when (re-search-forward "^:ROAM_REFS:[ \t]*\\(.*\\)$" drawer-end t)
            (setq roam (string-trim (match-string 1))))))
      (goto-char (point-min))
      (when (re-search-forward "^#\\+reference:[ \t]*\\(.*\\)$" nil t)
        (setq keyword (string-trim (match-string 1))))
      (goto-char (point-min))
      (when (re-search-forward "^#\\+title:[ \t]*\\(.*\\)$" nil t)
        (setq title (string-trim (match-string 1))))
      (goto-char (point-min))
      (when (re-search-forward "^#\\+filetags:[ \t]*\\(.*\\)$" nil t)
        (setq tags (split-string (match-string 1) "[: \t]+" t)))
      (dolist (key sp-litnotes-refs--meta-keys)
        (goto-char (point-min))
        (when (re-search-forward
               (format "^\\(?:- +\\|:\\)%s\\(?: ?::\\|:\\)[ \t]*\\(.+\\)$" (regexp-quote key)) nil t)
          (push (cons key (sp-litnotes-refs--clean-value (match-string 1))) meta)))
      (list :file file :id id :roam roam :keyword keyword :title title :tags tags
            :meta meta :drawer (and drawer-end t)))))

;;;; Planning

(defun sp-litnotes-refs--plan (parsed)
  "Say what to do with the note PARSED (see `sp-litnotes-refs--parse').
Returns PARSED plus :status and :refs, the new =ROAM_REFS= value.  The status is
one of `no-id', `no-reference', `ok', `normalise', `convert' and `merge'."
  (let* ((roam (and parsed (plist-get parsed :roam)))
         (roam (and roam (not (string-empty-p roam)) roam))
         (keyword (let ((k (plist-get parsed :keyword)))
                    (and k (not (string-empty-p k)) k)))
         (from-roam (sp-litnotes-refs--tokens roam))
         (from-key (sp-litnotes-refs--tokens keyword))
         (keys (delete-dups (append (car from-roam) (car from-key))))
         (others (delete-dups (append (cdr from-roam) (cdr from-key))))
         (refs (string-join (append (mapcar (lambda (k) (concat "@" k)) keys) others) " "))
         (status (cond ((not (and (plist-get parsed :drawer) (plist-get parsed :id))) 'no-id)
                       ((and (not roam) (not keyword)) 'no-reference)
                       ((not keyword) (if (equal roam refs) 'ok 'normalise))
                       (roam 'merge)
                       (t 'convert))))
    (append parsed (list :status status :keys keys :refs refs))))

;;;; Bibliography and PDFs

(defun sp-litnotes-refs--bib-index (files)
  "Read the BibTeX FILES into a hash table of key to crossref (or :none)."
  (let ((table (make-hash-table :test 'equal)))
    (dolist (file files)
      (when (file-readable-p file)
        (with-temp-buffer
          (insert-file-contents file)
          (goto-char (point-min))
          (while (re-search-forward
                  "^@\\([[:alpha:]]+\\)[ \t]*[{(][ \t]*\\([^, \t\n]+\\)[ \t]*," nil t)
            (unless (member (downcase (match-string 1)) '("comment" "string" "preamble"))
              (let ((key (match-string 2))
                    (end (save-excursion (or (and (re-search-forward "^@" nil t)
                                                  (line-beginning-position))
                                             (point-max))))
                    crossref)
                (save-excursion
                  (when (re-search-forward
                         "^[ \t]*crossref[ \t]*=[ \t]*[{\"]\\([^}\"]+\\)" end t)
                    (setq crossref (match-string 1))))
                (puthash key (or crossref :none) table)))))))
    table))

(defun sp-litnotes-refs--pdf (key index)
  "Return how the PDF for KEY is found: `own', `crossref' or nil.
A book section often has no PDF of its own; its crossref entry (the book) does."
  (let ((dir (if (boundp 'sp-literature-dir) sp-literature-dir "~/Documents/literature/"))
        (parent (gethash key index)))
    (cond ((file-exists-p (expand-file-name (concat key ".pdf") dir)) 'own)
          ((and (stringp parent)
                (file-exists-p (expand-file-name (concat parent ".pdf") dir)))
           'crossref))))

;;;; Stub BibTeX entries

(defconst sp-litnotes-refs--entry-types
  '(("journalarticle" . "article") ("booksection" . "incollection")
    ("incollection" . "incollection") ("book" . "book") ("collection" . "collection")
    ("inreference" . "inreference") ("encyclopedia" . "inreference")
    ("phdthesis" . "phdthesis") ("thesis" . "thesis"))
  "BibTeX entry type for the file tag of a litnote; any other tag gives `misc'.")

(defun sp-litnotes-refs--entry-type (tags)
  "The BibTeX entry type for the file TAGS of a litnote."
  (or (cl-some (lambda (tag) (cdr (assoc (downcase tag) sp-litnotes-refs--entry-types))) tags)
      "misc"))

(defun sp-litnotes-refs--braced (value)
  "VALUE as a BibTeX field value, with no braces of its own."
  (concat "{" (replace-regexp-in-string "[{}]" "" value) "}"))

(defun sp-litnotes-refs--stub (plan key)
  "A stub BibTeX entry for KEY, from the litnote of PLAN."
  (let* ((meta (plist-get plan :meta))
         (title (or (cdr (assoc "pub-title" meta))
                    (let ((note-title (plist-get plan :title)))
                      (and note-title (not (equal note-title key)) note-title))))
         (dir (if (boundp 'sp-literature-dir) sp-literature-dir "~/Documents/literature/"))
         (fields
          (delq nil
                (list (and title (cons "title" title))
                      (and (assoc "pub-author" meta) (cons "author" (cdr (assoc "pub-author" meta))))
                      (and (assoc "pub-year" meta) (cons "year" (cdr (assoc "pub-year" meta))))
                      (and (assoc "pub-pages" meta) (cons "pages" (cdr (assoc "pub-pages" meta))))
                      (and (file-exists-p (expand-file-name (concat key ".pdf") dir))
                           (cons "file" (format "~/Documents/literature/%s.pdf" key)))
                      (cons "note" (format "Stub made from the litnote %s; complete it"
                                           (file-name-nondirectory (plist-get plan :file))))
                      (cons "DATE_ADDED" (current-time-string))))))
    (concat (format "@%s{%s,\n" (sp-litnotes-refs--entry-type (plist-get plan :tags)) key)
            (mapconcat (lambda (f) (format "  %-12s = %s,\n" (car f) (sp-litnotes-refs--braced (cdr f))))
                       fields "")
            "}\n")))

(defun sp-litnotes-refs--stubs (plans index)
  "Stub entries, as (KEY . TEXT), for the keys of PLANS that INDEX does not have.
A key used by several notes gets one entry, from the first note."
  (let (stubs seen)
    (dolist (plan plans)
      (dolist (key (plist-get plan :keys))
        (unless (or (gethash key index) (member key seen))
          (push key seen)
          (push (cons key (sp-litnotes-refs--stub plan key)) stubs))))
    (nreverse stubs)))

;;;; Report

(defun sp-litnotes-refs--plans (&optional directory)
  "Plans for every note in DIRECTORY (default `sp-litnotes-refs-directory')."
  (mapcar (lambda (file) (sp-litnotes-refs--plan (sp-litnotes-refs--parse file)))
          (directory-files (or directory sp-litnotes-refs-directory) t "\\.org\\'")))

(defun sp-litnotes-refs--report-text (plans index)
  "Return the dry-run report for PLANS, looking keys up in INDEX."
  (let ((by-status (make-hash-table :test 'eq))
        (by-key (make-hash-table :test 'equal))
        (pdf-counts (list (cons 'own 0) (cons 'crossref 0) (cons nil 0)))
        unknown)
    (dolist (plan plans)
      (push plan (gethash (plist-get plan :status) by-status))
      (dolist (key (plist-get plan :keys))
        (push plan (gethash key by-key))
        (unless (gethash key index) (push (cons key plan) unknown))
        (cl-incf (alist-get (sp-litnotes-refs--pdf key index) pdf-counts nil nil #'eq))))
    (with-temp-buffer
      (insert (format "#+title: Litnote references: dry run\n\nFolder: =%s=\nNotes: %d\n\n"
                      sp-litnotes-refs-directory (length plans)))
      (insert "* Counts\n")
      (dolist (status '(convert merge normalise ok no-reference no-id))
        (insert (format "- %s: %d\n" status (length (gethash status by-status)))))
      (insert (format "- keys not in any registered .bib: %d\n" (length unknown)))
      (insert (format "- keys with a PDF of their own: %d; through crossref: %d; none: %d\n\n"
                      (alist-get 'own pdf-counts) (alist-get 'crossref pdf-counts)
                      (alist-get nil pdf-counts nil nil #'eq)))
      (let ((stubs (sp-litnotes-refs--stubs plans index)))
        (when stubs
          (insert (format "* Would add to %s (%d stub entries)\n"
                          (file-name-nondirectory sp-litnotes-refs-inbox-bib) (length stubs)))
          (dolist (stub stubs)
            (insert (format "- %s: %s\n" (car stub)
                            (if (string-match "^@\\([[:alpha:]]+\\)" (cdr stub))
                                (match-string 1 (cdr stub)) ""))))
          (insert "\n")))
      (dolist (spec '((convert "Would add ROAM_REFS and drop #+reference:")
                      (merge "Has both: would merge into ROAM_REFS and drop #+reference:")
                      (normalise "ROAM_REFS in another format: would rewrite as @key")
                      (no-id "No top-level :ID: drawer: would get a new ID (and ROAM_REFS) if you agree; otherwise skipped")))
        (when-let* ((items (reverse (gethash (car spec) by-status))))
          (insert (format "* %s (%d)\n" (cadr spec) (length items)))
          (dolist (plan items)
            (insert (format "- =%s=: %s -> %s\n"
                            (file-name-nondirectory (plist-get plan :file))
                            (or (plist-get plan :keyword) (plist-get plan :roam) "")
                            (plist-get plan :refs))))
          (insert "\n")))
      (when unknown
        (insert (format "* Keys that no registered .bib has (%d)\n" (length unknown)))
        (dolist (item (reverse unknown))
          (insert (format "- %s in =%s=\n" (car item)
                          (file-name-nondirectory (plist-get (cdr item) :file)))))
        (insert "\n"))
      (let (dups)
        (maphash (lambda (key notes) (when (cdr notes) (push (cons key notes) dups))) by-key)
        (when dups
          (insert (format "* Keys used by more than one note (%d)\n" (length dups)))
          (dolist (dup (sort dups (lambda (a b) (string< (car a) (car b)))))
            (insert (format "- %s: %s\n" (car dup)
                            (mapconcat (lambda (p) (file-name-nondirectory (plist-get p :file)))
                                       (cdr dup) ", "))))))
      (buffer-string))))

(defun sp-litnotes-refs-report ()
  "Show what `sp-litnotes-refs-convert' would do.  Writes nothing."
  (interactive)
  (let* ((plans (sp-litnotes-refs--plans))
         (index (sp-litnotes-refs--bib-index (if (boundp 'sp-bibtex-files) sp-bibtex-files nil)))
         (text (sp-litnotes-refs--report-text plans index)))

        (insert text)
        (org-mode)
        (goto-char (point-min))
        (read-only-mode 1)))
    (pop-to-buffer "*litnote refs*")
    plans))

;;;; Conversion

(defun sp-litnotes-refs--apply (file refs &optional create-id)
  "Set =ROAM_REFS= to REFS in the property drawer of FILE and drop =#+reference:=.
With CREATE-ID the note gets an =:ID:= (and a property drawer, when it has none).
An empty REFS leaves =ROAM_REFS= alone."
  (with-temp-buffer
    (insert-file-contents file)
    (goto-char (point-min))
    (when (and create-id (not (looking-at ":PROPERTIES:[ \t]*$")))
      (insert ":PROPERTIES:\n:END:\n"))
    (goto-char (point-min))
    (re-search-forward "^:END:[ \t]*$")
    (let ((end (copy-marker (line-beginning-position) t)))
      (when create-id
        (goto-char (point-min))
        (unless (re-search-forward "^:ID:" end t)
          (goto-char end)
          (insert ":ID:       " (org-id-uuid) "\n")))
      (unless (string-empty-p refs)
        (goto-char (point-min))
        (if (re-search-forward "^:ROAM_REFS:.*$" end t)
            (replace-match (concat ":ROAM_REFS: " refs) t t)
          (goto-char end)
          (insert ":ROAM_REFS: " refs "\n"))))
    (goto-char (point-min))
    (let ((case-fold-search t))
      (while (re-search-forward "^#\\+reference:.*\n" nil t)
        (replace-match "" t t)))
    (write-region nil nil file nil 'silent)))

(defun sp-litnotes-refs--backup (file)
  "Copy FILE to `sp-litnotes-refs-backup-directory', with a time stamp when needed."
  (make-directory sp-litnotes-refs-backup-directory t)
  (let ((target (expand-file-name (file-name-nondirectory file)
                                  sp-litnotes-refs-backup-directory)))
    (when (file-exists-p target)
      (setq target (concat target (format-time-string ".%Y%m%dT%H%M%S"))))
    (copy-file file target t)))

(defun sp-litnotes-refs--append-stubs (stubs)
  "Append the STUBS, from `sp-litnotes-refs--stubs', to `sp-litnotes-refs-inbox-bib'."
  (when (file-exists-p sp-litnotes-refs-inbox-bib)
    (sp-litnotes-refs--backup sp-litnotes-refs-inbox-bib))
  (with-temp-buffer
    (when (file-exists-p sp-litnotes-refs-inbox-bib)
      (insert-file-contents sp-litnotes-refs-inbox-bib))
    (goto-char (point-max))
    (unless (or (bobp) (bolp)) (insert "\n"))
    (dolist (stub stubs) (insert "\n" (cdr stub)))
    (write-region nil nil sp-litnotes-refs-inbox-bib nil 'silent)))

(defun sp-litnotes-refs-convert ()
  "Convert the notes of the report, after showing it and asking three times.
1. Move =#+reference:= to =ROAM_REFS= in the notes that have an ID.
2. Create an ID (and move the reference) in the notes that have none.
3. Add stub entries to `sp-litnotes-refs-inbox-bib' for the keys that no
   registered .bib file has.
Each question is asked only when there is something to do, and each changed note
and the inbox file is copied to `sp-litnotes-refs-backup-directory' first.
Running it again changes nothing."
  (interactive)
  (let* ((plans (sp-litnotes-refs-report))
         (index (sp-litnotes-refs--bib-index
                 (if (boundp 'sp-bibtex-files) sp-bibtex-files nil)))
         (todo (cl-remove-if-not
                (lambda (p) (memq (plist-get p :status) '(convert merge normalise)))
                plans))
         (no-id (cl-remove-if-not (lambda (p) (eq (plist-get p :status) 'no-id)) plans))
         (stubs (sp-litnotes-refs--stubs plans index))
         (written 0) (ids 0) (added 0))
    (when (and todo (yes-or-no-p (format "Move the reference of %d notes to ROAM_REFS (backups in %s)? "
                                         (length todo) sp-litnotes-refs-backup-directory)))
      (dolist (plan todo)
        (sp-litnotes-refs--backup (plist-get plan :file))
        (sp-litnotes-refs--apply (plist-get plan :file) (plist-get plan :refs))
        (cl-incf written)))
    (when (and no-id (yes-or-no-p (format "Create an ID for %d notes that have none? " (length no-id))))
      (dolist (plan no-id)
        (sp-litnotes-refs--backup (plist-get plan :file))
        (sp-litnotes-refs--apply (plist-get plan :file) (plist-get plan :refs) t)
        (cl-incf ids)))
    (when (and stubs (yes-or-no-p (format "Add %d stub entries to %s? " (length stubs)
                                          (file-name-nondirectory sp-litnotes-refs-inbox-bib))))
      (sp-litnotes-refs--append-stubs stubs)
      (setq added (length stubs)))
    (message "Converted %d notes, created %d IDs, added %d stub entries." written ids added)))
