Literate source for =libraries/modules/academic/sp-academic.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This is the umbrella module for academic work. It loads four sub-modules (=sp-bibprocess=, =sp-pdfprocess=, =sp-citations= and =sp-litnotes=) so they can be enabled together, and then configures bibliography lookup and BibTeX handling directly: =biblio= for looking up references online, BibTeX citation-key generation, =org-ref= set up to insert =org-cite= citations, =helm-bibtex= paths, a few =citar= file options, the =citar-org-node= bridge, and the =binder= package for Scrivener-like manuscript work.

The long commentary is a roadmap more than a description. It lists planned pieces (DEVONthink integration, deep links into PDFs, semantic search over PDFs, paper fetching) and notes that literature notes are still made with =citar-denote= while =ROAM_REFS= handling goes through =vulpea-citar=. Bibliography files are expected under =~/bibliography/= and PDFs under =~/Documents/literature/=. The module appears in the default module list in =init.el= under Academic.

The file shows signs of accumulated config: BibTeX key settings are made twice with different values (the later ones win), and the =C-c w b b= binding points at a command that is not defined anywhere in the repository.

* Looking up sources

** biblio

Installs =biblio=, which queries services such as CrossRef and arXiv for BibTeX entries, and binds =C-c w b b= to =sp-bibtex-biblio-lookup=, defined in =sp-bibprocess= (which this module requires). The binding used to point at =sia-bibtex-biblio-lookup=, a name that is not defined anywhere, so the key signalled an error.

#+begin_src emacs-lisp -i

;;; Looking up academic sources 

(use-package biblio
  :ensure t

  :bind
  (("C-c w b b" . sp-bibtex-biblio-lookup))
)
#+end_src

** Use org-cite for insertion

Sets =org-ref-insert-cite-function= so that inserting a citation through org-ref calls =org-cite-insert= and produces native =[cite:...]= syntax rather than org-ref links.

#+begin_src emacs-lisp -i
;;; Forcing org-ref to recognize org-cite citation syntax instead of org-ref blocks
(setq org-ref-insert-cite-function
      (lambda ()
	(org-cite-insert nil)))
#+end_src

** Showing cite keys in descriptive links

=org-ref-make-org-link-cite-key-visible= runs after =org-activate-bracket-links= highlights a link. When the link target starts with one of =org-ref-cite-types=, it removes the invisibility from the whole link and colours it with =org-ref-cite-color=, so the cite key stays visible even when the link has a description. It uses =-sort= from =dash= to try longer cite types first.

#+begin_src emacs-lisp -i
(defun org-ref-make-org-link-cite-key-visible (&rest _)
  "Make the org-ref cite link visible in descriptive links."

  (save-match-data
    (let ((s (match-string 1))
      (beg (match-beginning 0))
      (end (match-end 0))
      (cite-re (format "^\\(%s:\\)"
               (regexp-opt (-sort
                    (lambda (a b)
                      (> (length a) (length b)))
                    org-ref-cite-types))))
      cite-type)

      (when (and s (string-match cite-re s))
    (setq cite-type (match-string 1 s))
    (remove-text-properties beg end
                '(invisible))
    (add-text-properties
     beg end
     `(face (:foreground ,org-ref-cite-color)))))))
#+end_src

** bibtex-completion paths

Sets the =.bib= files used by =helm-bibtex= and friends (a master file plus several topic and thesis bibliographies), the PDF directory, the notes directory =~/notes/=, and a template for notes that creates a heading with author, title, journal, year and type, followed by a =cite:= link.

#+begin_src emacs-lisp -i
(setq bibtex-completion-bibliography
      (mapcar (lambda (bib) (sp-path sp-bibliography-dir bib))
              '("master.bib" "thesis.bib" "marx.bib" "hci.bib" "aesthetics.bib"
                "hegel-prezentare.bib" "modernitate.bib"))
        bibtex-completion-library-path (list sp-literature-dir)
        bibtex-completion-notes-path sp-notes-dir
        bibtex-completion-notes-template-multiple-files "* ${author-or-editor}, ${title}, ${journal}, (${year}) :${=type=}: \n\nSee [[cite:&${=key=}]]\n")
#+end_src

* BibTeX mode

** Second set of autokey options

Loads =bibtex= and sets the autokey options: four-digit years, hyphen separators, and two title words (stretchable by one) of at most five characters. These are the only values for these options; an earlier block used to set them too (with three title words of up to eight characters), but this block ran later and overwrote them.

#+begin_src emacs-lisp -i
;; Automatically generating BibTeX keys
(require 'bibtex)

(setq bibtex-autokey-year-length 4
      bibtex-autokey-name-year-separator "-"
      bibtex-autokey-year-title-separator "-"
      bibtex-autokey-titleword-separator "-"
      bibtex-autokey-titlewords 2
      bibtex-autokey-titlewords-stretch 1
      bibtex-autokey-titleword-length 5)
#+end_src

* Citation variables

** User options

Defines =sp-bibliography=, =sp-bib-notes= and =sp-citar-note= in the =sia-lambda= group, all nil by default. =sp-citations= uses the last two for the =citar= notes path and note template. They are defined here, after that module is required, so they only take effect if the =citar= configuration runs later.

#+begin_src emacs-lisp -i
;;;; Citation Variables
(defcustom sp-bibliography nil "User bibliography for citation."
  :group 'spconfig
  :tag "Lambda-Emacs User Bibliography")
(defcustom sp-bib-notes nil "User citation notes directory."
  :group 'spconfig
  :tag "Lambda-Emacs Citation Notes Directory")
(defcustom sp-citar-note nil "Template for use with citar notes."
  :group 'spconfig
  :tag "Lambda-Emacs Citar Notes Template")
#+end_src
