Literate source for =libraries/modules/academic/sp-litnotes.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This academic module connects bibliography entries to notes. =citar-denote= creates one Denote file per reference (file-level literature notes) in a =litnotes= subdirectory, and =citar-vulpea= supports literature notes as Vulpea nodes inside larger files. Both mark notes with the =litnote= keyword.

It builds on Citar (configured in the citation module) and on Denote and Vulpea. It is required by =sp-academic=. The =C-c w b= prefix holds the literature-note keys.

* File-level literature notes

** citar-denote

Installs and enables =citar-denote-mode=, which makes Citar use Denote files as notes, and has Citar always create a note when you open notes for a reference that has none. Global keys: =C-c w b c= creates a note, =C-c w b n= opens one, and =C-c w b x= adds a nocite reference. In Org buffers, =C-c w b k= and =C-c w b K= add or remove a citekey from the current note, =C-c w b d= runs the do-what-I-mean command, and =C-c w b e= opens the bibliography entry.

#+begin_src emacs-lisp -i
;;; sp-litnotes.el --- Literature notes with citar-denote and citar-vulpea -*- lexical-binding: t; -*-

;;; Commentary:

;; This academic module connects bibliography entries to notes. `citar-denote'
;; creates one Denote file per reference (file-level literature notes) in a
;; `litnotes' subdirectory, and `citar-vulpea' supports literature notes as
;; Vulpea nodes inside larger files.

;;; Code:

;;; File-level literature notes
(use-package citar-denote
  :ensure (:wait t)

  :custom
  (citar-open-always-create-notes t)
  
  :init
  (citar-denote-mode)
  
  :bind
  (("C-c w b c" . citar-create-note)
   ("C-c w b n" . citar-denote-open-note)
   ("C-c w b x" . citar-denote-nocite)
   
   :map org-mode-map
   ("C-c w b k" . citar-denote-add-citekey)
   ("C-c w b K" . citar-denote-remove-citekey)
   ("C-c w b d" . citar-denote-dwim)
   ("C-c w b e" . citar-denote-open-reference-entry)))
#+end_src

** Note title format

New literature notes are titled with author, year and title.

#+begin_src emacs-lisp -i
(setq citar-denote-title-format 'author-year-title)
#+end_src

** Authors in titles

At most two author names are used in the generated title.

#+begin_src emacs-lisp -i
(setq citar-denote-title-format-authors '2)
#+end_src

** Literature note keyword

Tags literature notes with the Denote keyword =litnote=.

#+begin_src emacs-lisp -i
(setq citar-denote-keyword "litnote")
#+end_src

** Subdirectory

Stores new literature notes in the =litnotes= subdirectory of the Denote directory.

#+begin_src emacs-lisp -i
(setq citar-denote-subdir "litnotes")
#+end_src

* Node-level literature notes

** citar-vulpea

Installs =citar-vulpea=, loaded after Citar and Vulpea, so references can be linked to Vulpea nodes. Notes use the =litnote= tag, store citation keys in a =REFERENCES= property, are titled "author (date) title", and live in =~/notes/litnotes=. A comment says the title template still needs to match the citar-denote convention.

#+begin_src emacs-lisp -i
;;; Node-level literature note configuration
(use-package citar-vulpea
  :ensure t
  :after (citar vulpea)
  
  :custom
  ;; Tag used to identify bibliographic notes
  (citar-vulpea-keyword "litnote")
  
  ;; Name of the property used for citation keys
  (citar-vulpea-references-property "REFERENCES")
  
  ;; Template for new note titles
  (citar-vulpea-note-title-template "${author} (${date}) ${title}") ;; this has to be adapted to the citar-denote workflow

  (citar-vulpea-notes-directory (sp-path sp-notes-dir "litnotes/")) ;; Directory to store notes (nil uses vulpea-default-notes-directory)
)
#+end_src
