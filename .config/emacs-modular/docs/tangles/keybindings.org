* TODO Looking for better keybinding solutions (as well as their management)

The =general.el= package is, unfortunately, about to be deprecated. It seems that the best and easiest option to go about keybindings nowadays is to try and work with a declarative setup, by using =(use-package :bind (...))= for all of the packages that support it.[fn:7]

=use-package= allows the creation of global keybindings

Using :bind with a list of conses
Here is an example of using :bind with a list of conses:

#+begin_example emacs-lisp :tangle no :eval never
(use-package hi-lock
  :bind (("M-o l" . highlight-lines-matching-regexp)
         ("M-o r" . highlight-regexp)
         ("M-o w" . highlight-phrase)))
#+end_example
