Literate source for =libraries/modules/funct/sp-helper-funct.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

This module is a grab bag of small interactive commands and a few global settings that do not belong to any one feature area. It covers buffer management (new, temporary, reverted and copied buffers, user-buffer cycling), file and directory helpers, text insertion helpers (timestamps, comment separators, weather, YAML fences), some Org writing helpers adapted from Emacs Writing Studio, and a copy of the sensible-defaults library.

It relies on directory constants defined in =early-init.el= (=sp-emacs-dir=, =sp-setup-dir=, =sp-user-dir=) and loads several packages lazily inside commands: =consult= for the config file finders, =titlecase= and =denote= for the heading and link helpers, and =evil= for the escape key bindings. Some commands shell out to external programs: =rg= (ripgrep), =curl= and =maim=. Many of the commands defined here are bound under the =sp-prefix= leader in =sp-keys.el=. The module is loaded in the Functions block of the default module list in =init.el= and ends by installing the =wizard= package.

=sp-call-emacs= starts a fresh Emacs process with no buffer attached, which is handy for testing configuration changes without closing the current session.   (start-process "Emacs" nil
                 ;; (executable-find "/usr/local/bin/emacs")))
                 (executable-find "/Applications/Emacs.app/Contents/MacOS/Emacs")

))

** Quit and bell behaviour

Setting =confirm-kill-processes= to nil lets Emacs exit without asking about running subprocesses. =ring-bell-function= is set to =ignore= to silence the bell, and then =visible-bell= is enabled. Because a custom =ring-bell-function= takes precedence, the visible flash probably never happens; that is an inference from how the two options interact.

#+begin_src emacs-lisp -i
;;; Exiting without confirmation
(setq confirm-kill-processes nil)

;; Sounds
(setq ring-bell-function 'ignore) ;; Disable the bell sound

;; flash-screen-instead-of-ringing-bell
;; When you perform a problematic operation, flash the screen
;; instead of ringing the terminal bell
(setq visible-bell t)
#+end_src

Commands for finding, searching and reloading the configuration files themselves.

=sp-files-sources-data= lists the directories to offer when finding configuration files. Each entry has a display title, a narrowing key (=i=, =s=, =u=) and a directory taken from the =early-init.el= constants.

    ("User Files"      ?u ,sp-user-dir))
  "Define titles, quick-keys, and directories to be searched for files.")
#+end_src

** Building a consult source

=sp--files-make-source= turns one entry of that table into a source plist for =consult--multi=. Items are the files in the directory whose names contain an extension, prefixed with an invisible copy of the directory so that only the bare name shows while the full path is still available. Choosing an item opens it with =find-file=.

#+begin_src emacs-lisp -i
(defun sp--files-make-source (name char dir)
  "Return a source list suitable for `consult--multi'.
  NAME is the source name, CHAR is the narrowing character,
  and DIR is the directory to find files. "
  (let ((idir (propertize (file-name-as-directory dir) 'invisible t)))
    `(:name     ,name
      :narrow   ,char
      :category file
      :face     consult-file
      :items    ,(lambda () (mapcar (lambda (f) (concat idir f))
				               ;; filter files that glob *.*
				               (directory-files dir nil "[^.].*[.].+")))
      :action   ,(lambda (f) (find-file f)))))
#+end_src

** Find a configuration file

=sp-find-lambda-file= presents all the sources together in one =consult--multi= prompt, so you can narrow by typing the source key. It is bound under the config prefix in =sp-keys.el=.

#+begin_src emacs-lisp -i
(defun sp-find-lambda-file ()
  "Find a file from list of λ-Emacs configuration files."
  (interactive)
  (require 'consult)
  (consult--multi (mapcar #'(lambda (s) (apply 'sp--files-make-source s))
			              sp-files-sources-data)
		          :prompt "λ-files: "
		          :history 'file-name-history))
#+end_src

** Search configuration files

=sp-search-lambda-files= runs =consult-ripgrep= over =sp-emacs-dir= with custom ripgrep arguments that include hidden files and exclude =straight=, =var= and =.git=. The include glob still points at a =lambda-library= directory, while the modules now live under =libraries/=, so that glob may no longer match anything useful. If =rg= is missing it just prints a message.

#+begin_src emacs-lisp -i
(defun sp-search-lambda-files ()
  "Search all configuration files in λ-Emacs with consult-ripgrep."
  (interactive)
  (require 'consult)
  (let ((consult-ripgrep-args
         "rg --null --line-buffered --max-columns=1000 --path-separator /\
   --smart-case --no-heading --line-number --hidden --glob=lambda-library/** --glob=!straight --glob=!var --glob=!.git/ ."))
    (if (executable-find "rg")
        (consult-ripgrep sp-emacs-dir)
      (message "Please install `rg' first."))))
#+end_src

* Buffer functions

** New buffers

=sp-new-buffer-new-frame= opens an =untitled= buffer in its own new frame, adapted from a Stack Overflow answer. =sp-create-new-buffer= creates a =*new*= buffer in the current window and puts it in the default major mode. Both are bound under the buffer prefix in =sp-keys.el=.

#+begin_src emacs-lisp -i
(defun sp-new-buffer-new-frame ()
  "Create a new frame with a new empty buffer."
  (interactive)
  (let ((buffer (generate-new-buffer "untitled")))
    (set-buffer-major-mode buffer)
    (display-buffer buffer '(display-buffer-pop-up-frame . nil))))


;;;;; Create new buffer
(defun sp-create-new-buffer ()
  "Create a new buffer in the default major mode."
  (interactive)
  (let ((buffer (generate-new-buffer "*new*")))
    (set-window-buffer nil buffer)
    (with-current-buffer buffer
      (funcall (default-value 'major-mode)))))
#+end_src

** Revert all file buffers

=sp-revert-all-file-buffers= walks every buffer that visits a file and is not modified in Emacs. Readable files are reverted without confirmation, keeping their modes; buffers whose files no longer exist or cannot be read are killed with a message. Unsaved edits are never touched.

#+begin_src emacs-lisp -i
;;;;; Revert all buffers
;;
(defun sp-revert-all-file-buffers ()
  "Refresh all open file buffers without confirmation.
Buffers in modified (not yet saved) state in emacs will not be reverted. They
will be reverted though if they were modified outside emacs.
Buffers visiting files which do not exist any more or are no longer readable
will be killed."
  (interactive)
  (dolist (buf (buffer-list))
    (let ((filename (buffer-file-name buf)))
      ;; Revert only buffers containing files, which are not modified;
      ;; do not try to revert non-file buffers like *Messages*.
      (when (and filename
                 (not (buffer-modified-p buf)))
        (if (file-readable-p filename)
            ;; If the file exists and is readable, revert the buffer.
            (with-current-buffer buf
              (revert-buffer :ignore-auto :noconfirm :preserve-modes))
          ;; Otherwise, kill the buffer.
          (let (kill-buffer-query-functions) ; No query done when killing buffer
            (kill-buffer buf)
            (message "Killed non-existing/unreadable file buffer: %s" filename))))))
  (message "Finished reverting buffers containing unmodified files."))
#+end_src

** Cycling through user buffers

=sp-user-buffer-q= decides whether the current buffer is a user buffer: anything whose name starts with an asterisk, and any Dired buffer, is not. =sp-next-user-buffer= and =sp-previous-user-buffer= call =next-buffer= or =previous-buffer= and keep going, up to 20 times, until they land on a user buffer. These come from Xah Lee's ergoemacs site and are bound to =[= and =]= under the buffer prefix. A TODO notes they do not yet respect workspaces.

#+begin_src emacs-lisp -i
;;;;; Useful Buffers
;; TODO: make this respect workspace buffers
(defun sp-user-buffer-q ()
  "Return t if current buffer is a user buffer, else nil.
  Typically, if buffer name starts with *, it's not considered a user buffer.
  This function is used by buffer switching command and close buffer command, so that next buffer shown is a user buffer.
  You can override this function to get your idea of “user buffer”.
  version 2016-06-18"
  (interactive)
  (if (string-equal "*" (substring (buffer-name) 0 1))
      nil
    (if (string-equal major-mode "dired-mode")
        nil
      t
      )))

(defun sp-next-user-buffer ()
  "Switch to the next user buffer.
  “user buffer” is determined by `sp-user-buffer-q'.
  URL `http://ergoemacs.org/emacs/elisp_next_prev_user_buffer.html'
  Version 2016-06-19"
  (interactive)
  (next-buffer)
  (let ((i 0))
    (while (< i 20)
      (if (not (sp-user-buffer-q))
          (progn (next-buffer)
                 (setq i (1+ i)))
        (progn (setq i 100))))))

(defun sp-previous-user-buffer ()
  "Switch to the previous user buffer.
  “user buffer” is determined by `sp-user-buffer-q'.
  URL `http://ergoemacs.org/emacs/elisp_next_prev_user_buffer.html'
  Version 2016-06-19"
  (interactive)
  (previous-buffer)
  (let ((i 0))
    (while (< i 20)
      (if (not (sp-user-buffer-q))
          (progn (previous-buffer)
                 (setq i (1+ i)))
        (progn (setq i 100))))))
#+end_src

** Evaluate a buffer until an error

=sp-eval-buffer-until-error= jumps to the start of the buffer and reads and evaluates forms one at a time in an endless loop. It stops at the first error, leaving point just after the last good form, which helps locate a broken form in a configuration file. Reaching the end of the buffer also stops it, with an end of file error.

#+begin_src emacs-lisp -i
;;;;; Eval emacs buffer until error

(defun sp-eval-buffer-until-error ()
  "Evaluate emacs buffer until error occured."
  (interactive)
  (goto-char (point-min))
  (while t (eval (read (current-buffer)))))
#+end_src

** Kill the current buffer

=sp-kill-this-buffer= is a thin wrapper around =kill-buffer=, because =kill-this-buffer= is unreliable outside the menu bar. Unlike deleting the buffer through Evil, it keeps the window open. It is bound to =k= under the buffer prefix.

#+begin_src emacs-lisp -i
;;;;; Kill Current Buffer
;; (kill-this-buffer) is unreliable when not invoked from the menubar. So here's a
;; wrapper on (kill-buffer) to kill the current buffer. This is sometimes better
;; than (evil-delete-buffer) since it keeps the window.

(defun sp-kill-this-buffer ()
  (interactive)
  (kill-buffer))
#+end_src

** Show and copy the file name

Two commands echo the current buffer's file name in the minibuffer and also put it on the kill ring: =sp-show-and-copy-buffer-full-filename= uses the full path and =sp-show-and-copy-buffer-filename= uses the abbreviated form with =~=. Both signal an error in a buffer that is not visiting a file.

#+begin_src emacs-lisp -i
;;;;; Show Filename of Buffer

;; http://camdez.com/blog/2013/11/14/emacs-show-buffer-file-name/
(defun sp-show-and-copy-buffer-full-filename ()
  "Show the full path to the current file in the minibuffer and copy to clipboard."
  (interactive)
  (let ((file-name (buffer-file-name)))
    (if file-name
        (progn
          (message file-name)
          (kill-new file-name))
      (error "Buffer not visiting a file"))))

(defun sp-show-and-copy-buffer-filename ()
  "Show the abbreviated path to the current file in the minibuffer and copy to clipboard."
  (interactive)
  (let ((file-name (buffer-file-name)))
    (if file-name
        (let ((abbrev-name (abbreviate-file-name file-name)))
          (message abbrev-name)
          (kill-new abbrev-name))
      (error "Buffer not visiting a file"))))
#+end_src

* File functions

** Delete the current file

=sp-delete-current-buffer-file=, from Magnar Sveen, asks for confirmation and then deletes the file behind the current buffer (to the trash where supported) and kills the buffer. If the buffer has no file it falls back to =ido-kill-buffer=, which assumes =ido= is available.

#+begin_src emacs-lisp -i
;;;; File Functions

;;;;; Delete Current File
;; from magnars

(defun sp-delete-current-buffer-file ()
  "Removes file connected to current buffer and kills buffer."
  (interactive)
  (let ((filename (buffer-file-name))
        (buffer (current-buffer))
        (name (buffer-name)))
    (if (not (and filename (file-exists-p filename)))
        (ido-kill-buffer)
      (when (yes-or-no-p "Are you sure you want to delete this file? ")
        (delete-file filename t)
        (kill-buffer buffer)
        (message "File '%s' successfully removed" filename)))))
#+end_src

* Directory and insertion helpers

** Create missing parent directories

Adapted from Marcin Borkowski, =make-parent-directory= creates the directory of the file being visited, including any missing parents. Adding it to =find-file-not-found-functions= means that opening a file in a nonexistent directory silently creates that directory, so a later save just works.

#+begin_src emacs-lisp -i
;;;; Directory Functions
;;;;; Make Parent Directory
;;  Create a directory – or a hierarchy of them – while finding a file in a

;;  http://mbork.pl/2016-07-25_Making_directories_on_the_fly

(defun make-parent-directory ()
  "Make sure the directory of `buffer-file-name' exists."
  (make-directory (file-name-directory buffer-file-name) t))

(add-hook 'find-file-not-found-functions #'make-parent-directory)

** Insert a comment separator

=sp-insert-commented-separator=, adapted from kuanyui's writing-utils, inserts a three line block: a line of 54 equals signs, an empty comment line for a title, and another line of equals signs, using the current mode's comment syntax (two semicolons in Lisp modes). It moves to a fresh line first if point is not at column zero, and leaves point on the middle line.

#+begin_src emacs-lisp -i
;;;;; Insert Comment Seperator
;; ======================================================
;; Insert commented seperator like this line
;; ======================================================
;; https://github.com/kuanyui/writing-utils.el/blob/db29d30e11b6d6d96c0d351b642af97631f3365f/writing-utils.el#L85

(defun sp-insert-commented-separator()
  "Insert a commented separator in your code. Like this in
      ELisp:
      ;; ======================================================
      ;; Title
      ;; ======================================================
      Which makes code easier to read.
      "
  (interactive)
  (let* ((line (make-string 54 (string-to-char "=")))
	     (comment-start (if (member major-mode '(emacs-lisp-mode lisp-mode))
			                ";; " comment-start))
         (seperator (concat comment-start line)))
    (when (> (current-column) 0) (end-of-line) (newline))
    (insert (format "%s\n%s\n%s"
		            seperator comment-start seperator))
    (previous-line)
    ))
#+end_src

** Insert the weather

=sp-insert-weather=, from Jack Baty, fetches a short forecast from wttr.in with =curl= and inserts it with each line prefixed by a colon and space, which Org renders as fixed width text. It needs network access and =curl=.

#+begin_src emacs-lisp -i
;;;;; Insert Weather
;; From [[https://www.baty.blog/2019/insert-weather-into-emacs-buffer][Jack Baty]] with some slight modifications for formatting. See also [[https://github.com/chubin/wttr.in][wttr.in]].
(defun sp-insert-weather ()
  "Insert `'wttr.in' weather forecast in buffer."
  (interactive)
  (let ((w (shell-command-to-string "curl -s 'wttr.in/?0qT' | head -n10")))
    (insert (mapconcat (function (lambda (x) (format ": %s" x)))
                       (split-string w "\n")
                       "\n")))
  (newline))
#+end_src

** Jump to the matching bracket

=sp-forward-or-backward-sexp= moves to the matching parenthesis when point is next to one, similar to the percent motion in Vim. It handles being just before an opening bracket, just after a closing one, and the two cases from inside a bracket.

#+begin_src emacs-lisp -i
;;;;; Jump to sexp

(defun sp-forward-or-backward-sexp (&optional arg)
  "Go to the matching parenthesis character if one is adjacent to point."
  (interactive "^p")
  (cond ((looking-at "\\s(") (forward-sexp arg))
        ((looking-back "\\s)" 1) (backward-sexp arg))
        ;; Now, try to succeed from inside of a bracket
        ((looking-at "\\s)") (forward-char) (backward-sexp arg))
        ((looking-back "\\s(" 1) (backward-char) (forward-sexp arg))))
#+end_src

** Escape quits everything

From Juanjo Alvarez's Vim migration guide, =minibuffer-keyboard-quit= aborts the minibuffer, first just deactivating an active mark when Delete Selection mode is on. Once Evil is loaded, escape is bound to =keyboard-quit= in normal and visual state, to this function in all the minibuffer keymaps, and globally to =evil-exit-emacs-state=. Since =sp-evil= is commented out of the module list, these bindings only take effect if Evil gets loaded some other way.

#+begin_src emacs-lisp -i
;;;;; Quit All the Things!
;; From a great vim migration guide by Juanjo Álvarez
;; https://juanjoalvarez.net/en/detail/2014/sep/19/vim-emacsevil-chaotic-migration-guide/
;; (original code from davvil) https://github.com/davvil/.emacs.d/blob/master/init.el
;;
;; This should make operating with the minibuffer a little easier.
(defun minibuffer-keyboard-quit ()
  "Abort recursive edit.
      In Delete Selection mode, if the mark is active, just deactivate it;
      then it takes a second \\[keyboard-quit] to abort the minibuffer."
  (interactive)
  (if (and delete-selection-mode transient-mark-mode mark-active)
      (setq deactivate-mark  t)
    (when (get-buffer "*Completions*") (delete-windows-on "*Completions*"))
    (abort-recursive-edit)))
(with-eval-after-load 'evil
  (define-key evil-normal-state-map [escape] 'keyboard-quit)
  (define-key evil-visual-state-map [escape] 'keyboard-quit)
  (define-key minibuffer-local-map [escape] 'minibuffer-keyboard-quit)
  (define-key minibuffer-local-ns-map [escape] 'minibuffer-keyboard-quit)
  (define-key minibuffer-local-completion-map [escape] 'minibuffer-keyboard-quit)
  (define-key minibuffer-local-must-match-map [escape] 'minibuffer-keyboard-quit)
  (define-key minibuffer-local-isearch-map [escape] 'minibuffer-keyboard-quit)
  (global-set-key [escape] 'evil-exit-emacs-state))
#+end_src

** Check for missing executables

=sia-missing-executables= takes a list of program names and reports any that are not on the path. A sublist means any one of its entries is enough. It prints the result as a message.

#+begin_src emacs-lisp -i
;; Check for missing external software
;;;###autoload
(defun sia-missing-executables (prog-list)
  "Identify missing executables in PROG-LIST.
Sublists indicate that one of the entries is required."
  (let ((missing '()))
    (dolist (exec prog-list)
      (if (listp exec)
          (unless (cl-some #'executable-find exec)
            (push (format "(%s)" (mapconcat 'identity exec " or ")) missing))
        (unless (executable-find exec)
          (push exec missing))))
    (if missing
        (message "Missing executable files(s): %s"
                 (mapconcat 'identity missing ", "))
      (message "No missing executable files."))))
#+end_src

** Insert a screenshot

=sia-org-insert-screenshot= prompts for a file name, forces a =.png= extension, runs =maim --select= to capture a region of the screen, and inserts a caption keyword and a file link before refreshing inline images. =maim= is an X11 tool, so this only works on Linux with X.

** Title case headings

=sia-org-headings-titlecase= rewrites every Org heading using the =titlecase= package, honouring =titlecase-style=, or sentence case with a prefix argument. Only headings at or above the level set in =sia-org-heading-level-capitalise= are changed.

#+begin_src emacs-lisp -i
;;;###autoload
(defun sia-org-headings-titlecase (&optional arg)
  "Cycle through all headings in an Org buffer and convert them to title case.
When used with universal argument (ARG) converts to sentence case.
Customise `titlecase-style' for styling."
  (interactive "P")
  (require 'titlecase)
  (let ((style (if arg 'sentence titlecase-style)))
    (message "Converting headings to '%s' style" style)
    (org-map-entries
     (lambda ()
       (let* ((heading (substring-no-properties (org-get-heading t t t t)))
	      (level (org-current-level))
	      (heading-lower (downcase heading))
              (new-heading (titlecase--string heading-lower style)))
	 (when (<= level (or sia-org-heading-level-capitalise 999))
	   (org-edit-headline new-heading)))))))
#+end_src

** Denote link descriptions in title case

=sia-denote-link-description-title-case=, fixed by Prot, is intended as the value of =denote-link-description-function=. It uses the active region if there is one, returns an empty string when there is no title, leaves titles containing spaces alone, and otherwise turns hyphens between words into spaces and title cases the result. It is defined here but nothing in this module sets it as the description function.

#+begin_src emacs-lisp -i
;; Fixed by Prot
(defun sia-denote-link-description-title-case (file)
  "Return link description for FILE.

If the region is active, use it as the description.
The title is formatted with the `titlecase' package.

This function is useful as the value of `denote-link-description-function' to
generate links in titlecase for attachments."
  (require 'titlecase)
  (let* ((file-type (denote-filetype-heuristics file))
         (title (denote-retrieve-title-or-filename file file-type)))
    (cond
     ((denote--get-active-region-content))
     ((or (null title) (string-blank-p title))
      "")
     ((string-match-p " " title)
      title)
     (t
      (let ((clean-title (replace-regexp-in-string "\\([a-zA-Z0-9]\\)-\\([a-zA-Z0-9]\\)" "\\1 \\2" title)))
        (format "%s" (titlecase--string clean-title titlecase-style)))))))
#+end_src

** Offer to create directories on save

=sp-offer-to-create-parent-directories-on-save= adds a =before-save-hook= that asks whether to create a missing parent directory before saving. With =make-parent-directory= already on the find file hook above, this prompt would rarely appear.

(defun sp-offer-to-create-parent-directories-on-save ()
  "When saving a file in a directory that doesn't exist, offer
to (recursively) create the file's parent directories."
  (add-hook 'before-save-hook
            (lambda ()
              (when buffer-file-name
