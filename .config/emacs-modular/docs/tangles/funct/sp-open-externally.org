* openwith

** Enabling openwith-mode

Installs =openwith= and turns on the global =openwith-mode=. Because =openwith-associations= is set to =nil=, the mode is active but has no rules, so every file still opens inside Emacs. To make it do something, add entries of the form (regexp program args) to that list, for example to send videos or office documents to the system viewer.

#+begin_src emacs-lisp -i
;; Taken from Emacs Writing Studio.
(use-package openwith
  :ensure t
  :config
  (openwith-mode t)
  :custom
  (openwith-associations nil))
#+end_src
