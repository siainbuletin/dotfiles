#+TITLE: sp-collection-query-tables: tables of Vulpea notes
#+STARTUP: content

Literate source for the =sp-collection-query-tables= family in =libraries/modules/funct/=: seven modules written from this one file, each under its own heading below. The =:tangle= path is set per heading, in a property drawer, as in =sp-org-agenda.org=; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README. This document replaces =sp-vulpea-dblock.org=, =sp-vulpea-vui-table.org= and =sp-collection-query-tables-views.org=.

* What it is for

A table of Vulpea notes, like a Dataview query: choose the notes (by tag, directory, TODO state, links, meta keys or parent), choose the columns and the sort, and see the result as a live table, an Org table inside a note, or a saved view you reopen later. Everything is one query description, a /spec/, so the same query can be built in a menu, saved, inserted in a note and shown by any renderer.

* Layout

All of it is loaded from =sp-collection-query-tables.el=, which =sp-org-ext= requires right after the Vulpea modules (it is not part of that group).

| File                       | Role                                                        |
|----------------------------+-------------------------------------------------------------|
| =sp-collection-query-tables=          | Entry point, renderer choice, keys, Elpaca recipes          |
| =sp-collection-query-tables-core=     | Spec, query, cells, sorting, writing meta back, refreshing  |
| =sp-collection-query-tables-views=    | Saved views on disk                                         |
| =sp-collection-query-tables-org=      | =collection-query-table= dynamic block, Org buffer renderer           |
| =sp-collection-query-tables-menu=     | Transient menu that builds a spec                           |
| =sp-collection-query-tables-exc=      | exc grid renderer (loaded on first use)                     |
| =sp-collection-query-tables-vui=      | vui renderer and inline tables (loaded on first use)        |

* The spec

A plist. Every filter is optional and the filters are combined with /and/.

| Key                              | Meaning                                                                 |
|----------------------------------+-------------------------------------------------------------------------|
| =:tags=, =:tags-any=, =:tags-none= | all of, at least one of, none of these tags                             |
| =:directories=                   | the note's file lies under one of these directories                     |
| =:todo=                          | the note's TODO state is one of these                                   |
| =:links=                         | the note links to at least one of these note IDs                        |
| =:meta=                          | list of =(KEY . VALUE)=; a nil =VALUE= only requires the key            |
| =:parent-of=, =:parent-prop=     | an ID or ="self"=; the meta key (default =parents=) that links to it    |
| =:level=                         | nil, =0= (file-level notes) or =headings=                               |
| =:title-match=                   | regexp for the title, case-insensitive                                  |
| =:columns=                       | =:title :tags :todo :level :priority :id :file :path= or a meta key     |
| =:sort-by=, =:sort-desc=         | a column, and non-nil for descending                                    |

In a note, the same spec is the parameter list of a dynamic block:

#+begin_example
,#+BEGIN: collection-query-table :tags ("book") :columns (:title "author" "rating") :sort-by "rating"
,#+END:
#+end_example

* Using it

=C-c w T= opens the menu. Each key sets one thing and shows its value; =RET= opens the table, =P= counts the notes, =i= inserts the spec as a dynamic block at point, =S= saves it as a view, =V= loads one and =D= deletes one.

| Key       | Command                          | What it does                                         |
|-----------+----------------------------------+------------------------------------------------------|
| =C-c w T= | =sp-collection-query-tables-menu=           | Build a query                                        |
| =C-c w v= | =sp-collection-query-tables-open-view=      | Open a saved view                                    |
| =C-c w V= | =sp-collection-query-tables-view-save=      | Open the menu to save a view (was: prompts)          |
| =C-c w t= | =sp-collection-query-tables-inline-toggle=  | Live inline tables in this note (vui)                |

In an exc table: =C-c o= opens the note in the row, =C-c q= edits the query in the menu and redraws the table, =C-c C-u= runs the query again. Meta columns are edited in place and written to the note; titles, tags and the other built-in columns are read-only.

* Renderers

=sp-collection-query-tables-renderer= picks one: =auto= (the first that loads of exc, vui, org), =exc=, =vui= or =org=.

- *exc* is https://github.com/yibie/grid-table (package name =exc= since 0.5.1), a spreadsheet drawn with ETAF. It is not part of emacs-taf; the organization at https://github.com/emacs-taf provides ETAF (=ecss=, =ebox=, =etaf=, =etaf-ui=). Checked on 2026-10-21 against exc 0.5.1, ecss 0.1.0, ebox 3.1.1 and etaf 0.3.1: it needs Emacs 29.1 or later and the three ETAF libraries, none of which is on a package archive. Only the rows and columns that fit the window are drawn.
- *vui* is the component library the first version used.
- *org* is a read-only Org buffer; no extra packages.

* Installing

Packages come from =use-package= with the Elpaca recipe in =:ensure=, never from clones put on =load-path=. The entry file declares =ecss=, =ebox=, =etaf= and =exc= that way when =sp-collection-query-tables-install-exc= is non-nil (the default). The ETAF repositories keep their code in =lisp/=, so their recipes say =:files ("*.el" "lisp/*.el")=. exc's README gives =yibie/exc= as its address, but only =yibie/grid-table= resolved when this was written, so the recipe uses that.

* Old names

The first version's commands still work as obsolete aliases: =sia-vulpea-open-table= (now the menu), =sia-vulpea-open-saved-table=, =sia-vulpea-insert-table-from-view=, =sia-insert-vulpea-table=, =sia-vulpea-inline-tables-toggle= (and =-mount=, =-unmount=), =sia-vulpea-refresh-all-tables=, =sia-vulpea-select-note= and =sia-vulpea-read-parent=. A views file written by the first version is read and converted. The rename to =sp-collection-query-tables= (2026-10-23) keeps the old =sp-vulpea-table-*= settings and main commands as obsolete aliases (the settings =-renderer=, =-install-exc=, =-refresh-delay=, =-link-titles=, =-views-file= and =-exc-column-widths=; the commands =-menu=, =-open=, =-open-view=, =-view-save=, =-view-delete=, =-insert-dblock=, =-inline-toggle=, =-inline-mount=, =-inline-unmount= and =-refresh-all=). The views file is now =sp-collection-query-tables-views.el= in =user-emacs-directory=; while it does not exist, the old =sp-vulpea-table-views.el= is read instead. The dynamic block is =collection-query-table=; =#+BEGIN: vulpea-table= in existing notes still works. The features =sp-vulpea-dblock=, =sp-vulpea-vui-table= and =sp-collection-query-tables-views= (with its old contents) are gone: require =sp-collection-query-tables=. The functions =sia-vulpea--note-matches-p= and the other double-dash helpers were internal and are not aliased.

* What was wrong, and what changed

Found while reading the first version, and fixed here:

- Sorting a live table by =:title= did nothing, because the cell text of =:title= was empty.
- A =|= or a line break in a cell broke the Org table; both are escaped now.
- Editing a meta cell of a heading's row rewrote the file's top-level meta; it is refused now. Matching of the key was case-insensitive, unlike Vulpea's.
- Mounting inline tables left the buffer marked modified after every save.
- The saved-view file was a fixed list of positional fields; adding a filter would have broken old files. It is a spec plist now.
- A =vui= table was the only interactive option and =vui= a hard requirement of the views module; now it is one renderer of three.
- Three prefixes (=sia-=, =sp-= and unprefixed) became =sp-collection-query-tables-=.

Left as they were: =org-id-get-create= still adds an ID to the file when a "self" parent is resolved in a note without one; =vulpea-db-query= still loads every note and filters in Lisp.

* Not tested

Run in a container on Emacs 29.3 with a real Vulpea database (a handful of notes, then 1000): queries for every filter, the dynamic block, saved views and the old-format conversion, writing meta back, the Org and vui renderers, the exc grid and its in-place editing, and the menu's commands called directly with the prompts stubbed. Not run: the menu on screen, the exc and vui tables in a graphical frame, mouse use, inline tables, Elpaca building ETAF and exc, anything on your real notes, and macOS. =renderer-test-plan.md= in the project files (not in this repository) lists what to try on the Mac.

* Sandbox

Try a spec without saving anything: evaluate with =C-c C-c=.

(defun sp-collection-query-tables-open (spec &optional name target)
  "Show the table SPEC describes, in the renderer `sp-collection-query-tables-renderer' picks.
A \"self\" :parent-of is resolved against the current buffer first.  NAME
(a view name) names the buffer; with TARGET, an exc table buffer, that

  (let* ((spec (sp-collection-query-tables-resolve-spec spec))
         (renderer (sp-collection-query-tables--renderer)))
    (if (and (eq renderer 'exc) target (buffer-live-p target)
             (buffer-local-value 'sp-collection-query-tables-exc--spec target))

               (with-current-buffer target (sp-collection-query-tables-exc--draw spec))

** Specs

The keys a spec may carry. The filters are all optional and are combined with /and/: tags (all, any, none), directories, TODO states, links to notes, meta keys with an optional value, children of a parent note, level, and a title regexp. =:columns=, =:sort-by= and =:sort-desc= shape the table. A "self" parent is resolved against the buffer the table is asked from, because a renderer may switch buffers before it queries.

#+end_src

#+begin_src emacs-lisp -i
(defconst sp-collection-query-tables-spec-keys
  '(:tags :tags-any :tags-none :directories :todo :links :meta
    :parent-of :parent-prop :level :title-match
    :columns :sort-by :sort-desc)
  "Keys a table spec may carry.
:TAGS, :TAGS-ANY and :TAGS-NONE are lists of tags (all, at least one,
none of them); :DIRECTORIES a list of directories a note's file lies
under; :TODO a list of TODO states; :LINKS a list of note IDs, at least
one of which the note links to; :META a list of (KEY . VALUE) where a nil
VALUE only asks for KEY to be present; :PARENT-OF an ID or the string
\"self\", checked against the meta key :PARENT-PROP (default \"parents\");
:LEVEL nil, 0 (file-level notes) or `headings'; :TITLE-MATCH a regexp;
:COLUMNS the columns to show and :SORT-BY the column to sort on, each a
keyword (see `sp-collection-query-tables-builtin-columns') or the name of a meta key;
:SORT-DESC non-nil to sort descending.")
#+end_src

#+begin_src emacs-lisp -i
(defun sp-collection-query-tables-spec-normalize (spec)
  "Return SPEC with only known keys, and :columns defaulting to (:title).
Tags, directories and the like are copied so callers may keep editing SPEC."
  (let (out)
    (dolist (key sp-collection-query-tables-spec-keys)
      (when-let* ((cell (plist-member spec key)))
        (setq out (plist-put out key (copy-tree (cadr cell))))))
    (unless (plist-get out :columns)
      (setq out (plist-put out :columns (list :title))))
    out))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-collection-query-tables-resolve-parent-of (parent-of)
  "Resolve PARENT-OF to a literal note ID.
The string \"self\" (or the symbol `self') becomes the ID of the note the
current buffer visits, which `org-id-get-create' adds to the file when it
has none; anything else is returned unchanged."
  (if (member parent-of '("self" self))
      (progn
        (unless buffer-file-name
          (user-error "\"self\" needs a buffer that visits a note"))
        (save-excursion (goto-char (point-min)) (org-id-get-create)))
    parent-of))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-collection-query-tables-resolve-spec (spec)
  "Return SPEC with a \"self\" :parent-of resolved against the current buffer.
Call this in the buffer the table was asked from, before a renderer
switches buffers."
  (let ((spec (sp-collection-query-tables-spec-normalize spec)))
    (if (plist-get spec :parent-of)
        (plist-put spec :parent-of
                   (sp-collection-query-tables-resolve-parent-of (plist-get spec :parent-of)))
      spec)))

** Querying

(defun sp-collection-query-tables-note-matches-p (note spec)
  "Non-nil if NOTE satisfies every filter in SPEC.
:PARENT-OF in SPEC must already be a literal ID."
  (let ((tags (vulpea-note-tags note))
        (parent-of (plist-get spec :parent-of)))
    (and (seq-every-p (lambda (tag) (member tag tags)) (plist-get spec :tags))
         (or (null (plist-get spec :tags-any))
             (seq-some (lambda (tag) (member tag tags)) (plist-get spec :tags-any)))
         (not (seq-some (lambda (tag) (member tag tags)) (plist-get spec :tags-none)))
         (or (null (plist-get spec :directories))
             (sp-collection-query-tables--under-directory-p (vulpea-note-path note)
                                                 (plist-get spec :directories)))
         (or (null (plist-get spec :todo))
             (member (vulpea-note-todo note) (plist-get spec :todo)))
         (or (null (plist-get spec :links))
             (let ((dests (mapcar (lambda (l) (plist-get l :dest))
                                  (vulpea-note-links note))))
               (seq-some (lambda (id) (member id dests)) (plist-get spec :links))))
         (seq-every-p (lambda (clause) (sp-collection-query-tables--meta-match-p note clause))
                      (plist-get spec :meta))
         (or (null parent-of)
             (member parent-of
                     (vulpea-note-meta-get-list
                      note (or (plist-get spec :parent-prop) "parents") 'link)))
         (pcase (plist-get spec :level)
           ('nil t)
           (0 (eql (vulpea-note-level note) 0))
           ('headings (> (or (vulpea-note-level note) 0) 0)))
         (or (null (plist-get spec :title-match))
             (let ((case-fold-search t))
               (string-match-p (plist-get spec :title-match)
                               (or (vulpea-note-title note) "")))))))

(defun sp-collection-query-tables--sort-lessp (a b)
  "Non-nil if the cell text A sorts before B.

  (let ((num-a (and (string-match-p "\\`-?[0-9]+\\(?:\\.[0-9]+\\)?\\'" a)

                    (string-to-number b))))

          ((string-empty-p b) t)
          ((and num-a num-b) (< num-a num-b))
          (num-a t)
          (num-b nil)
          (t (string-collate-lessp a b nil t)))))

** Writing a meta value back

Used by the exc and vui renderers when a meta cell is edited. It replaces the first =- key :: value= line before the first heading, or adds the key after the last meta line of that block, and saves the file. (defun sp-collection-query-tables-write-meta (note key value)
  "Set the meta KEY of the file-level NOTE to VALUE, in NOTE's own file.
Replaces the first \"- KEY :: ...\" line before the first heading, or adds
one there (at the end of the file when it has no heading), then saves the
file.  A note for a heading has no meta of its own in this layout, so it
is refused rather than written to the wrong place."
  (unless (eql (vulpea-note-level note) 0)
    (user-error "Only file-level notes can be edited here (%s is a heading)"
                (vulpea-note-title note)))
  (with-current-buffer (find-file-noselect (vulpea-note-path note))
    (save-excursion
      (save-restriction
        (widen)
        (goto-char (point-min))
        (let* ((case-fold-search nil)
               (limit (save-excursion
                        (if (re-search-forward "^\\*" nil t)
                            (line-beginning-position)
                          (point-max))))
               (re (format "^\\(-[ \t]+%s[ \t]+::[ \t]*\\).*$" (regexp-quote key))))
          (if (re-search-forward re limit t)
              (replace-match (concat "\\1" (replace-regexp-in-string
                                            "\\\\" "\\\\\\\\" value))
                             t)
            ;; After the last meta line of the file's own block, else at the limit.
            (goto-char (point-min))
            (let (last)
              (while (re-search-forward "^-[ \t]+[^ \t:]+[ \t]+::" limit t)
                (setq last (line-end-position)))
              (if last
                  (progn (goto-char last) (insert (format "\n- %s :: %s" key value)))
                (goto-char limit)
                (unless (bolp) (insert "\n"))
                (insert (format "- %s :: %s\n" key value))))))))
    (save-buffer)
    (setq sp-collection-query-tables--last-write (current-time))))
#+end_src

  "Return the text shown for the setting KEY."
  (let ((value (sp-collection-query-tables-menu--get key)))
    (pcase key
      (:links (mapconcat (lambda (id)

                         value ", "))

#+begin_src emacs-lisp -i
(defun sp-collection-query-tables-exc--guard (source columns notes)
  "Make SOURCE write meta cells to their notes and refuse other edits.
COLUMNS are the table's columns and NOTES a vector of its notes."
  (let ((original (gethash :set-raw-value-at source))
        (ncols (length columns)))
    (puthash :set-raw-value-at
             (lambda (s row col value)
               (cond
                ((= row 0) (user-error "The header row is not editable"))
                ((or (>= col ncols) (> row (length notes)))
                 (user-error "Outside the table"))
                ((not (stringp (nth col columns)))
                 (user-error "The %s column is read-only"
                             (sp-collection-query-tables-header-label (nth col columns))))
                (t (sp-collection-query-tables-write-meta (aref notes (1- row)) (nth col columns) value)
                   (funcall original s row col value))))
             source)))
#+end_src

(defun sp-collection-query-tables-exc--source (spec notes)
  "Return an exc data source for SPEC and the list NOTES."
  (let* ((columns (plist-get spec :columns))
         (labels (mapcar #'sp-collection-query-tables-header-label columns))
         (source (make-exc-default-data-source
                  labels
                  (cons labels (sp-collection-query-tables-rows notes columns))
                  (sp-collection-query-tables-spec-summary spec))))
    (cl-loop for column in columns
             for i from 0
             do (exc-set-style-at source 0 i '(:bold t))
             do (exc-set-column-width source i (sp-collection-query-tables-exc--width column)))
    (exc-set-frozen source 1 0)
    (sp-collection-query-tables-exc--guard source columns (vconcat notes))
    source))

(defun sp-collection-query-tables-vui--dblock-regions ()
  "Return (SPEC CONTENT-BEGIN CONTENT-END) for each query table dblock."
  (let (blocks)
    (save-excursion
      (goto-char (point-min))
      (while (re-search-forward "^[ \t]*#\\+BEGIN:[ \t]+\\(?:collection-query-table\\|vulpea-table\\)\\(.*\\)$" nil t)
        (let* ((params (ignore-errors (car (read-from-string (format "(%s)" (match-string 1))))))
               (begin (progn (forward-line 1) (point)))
               (end (if (re-search-forward "^[ \t]*#\\+END:" nil t)
                        (line-beginning-position)
                      (point))))
          (when params (push (list params begin end) blocks)))))
    (nreverse blocks)))
