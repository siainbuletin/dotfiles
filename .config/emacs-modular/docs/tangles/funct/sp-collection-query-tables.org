#+TITLE: sp-collec-query: tables of Vulpea notes
#+STARTUP: content

Literate source for the =sp-collection-query-tables= family in =libraries/modules/funct/=.

- Seven modules are written from this one file, each under its own heading below.
- The =:tangle= path is set per heading, in a property drawer, as in =sp-org-agenda.org=.
- To tangle, see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README.
- This document replaces =sp-vulpea-dblock.org=, =sp-vulpea-vui-table.org= and =sp-collection-query-tables-views.org=.

* What it is for

A table of Vulpea notes, like a Dataview query.

- Choose the notes: by tag, directory, TODO state, links, meta keys or parent.
- Choose the columns and the sort.
- See the result as a live table, an Org table inside a note, or a saved view you reopen later.
- Everything is one query description, a /spec/. The same query can be built in a menu, saved, inserted in a note and shown by any renderer.

* Layout

All of it is loaded from =sp-collection-query-tables.el=, which =sp-org-ext= requires right after the Vulpea modules (it is not part of that group).

| File                       | Role                                                        |
|----------------------------+-------------------------------------------------------------|
| =sp-collection-query-tables= | Entry point, renderer choice, keys, Elpaca recipes          |
| =sp-collection-query-tables-core= | Spec, query, cells, sorting, writing meta back, refreshing  |
| =sp-collection-query-tables-views= | Saved views on disk                                         |
| =sp-collection-query-tables-org= | =collection-query-table= dynamic block, Org buffer renderer           |
| =sp-collection-query-tables-menu= | Transient menu that builds a spec                           |
| =sp-collection-query-tables-exc= | exc grid renderer (loaded on first use)                     |
| =sp-collection-query-tables-vui= | vui renderer and inline tables (loaded on first use)        |

* Names: why the prefix is =sp-collec-query-=

Naming:

- Files and features keep the full name, =sp-collection-query-tables=, so =require= and the file list say what the module is.
- Symbols (commands, settings, functions, the customize group) use the abbreviation =sp-collec-query-=.
- Why: with the full name the longest symbol reached 45 characters (=sp-collection-query-tables-menu--d-tags-none=), and the commands were tiresome to type or read in =M-x=.

What the abbreviation stands for:

- /collec/ is /collection/: the set of notes a query is run against. These are the notes in the Vulpea database. The name does not tie the module to Vulpea; any source of notes could be put behind =sp-collec-query-query=.
- /query/ is the spec that selects notes and columns.
- The tables are how the result is shown.
- The trailing /tables/ is dropped from the prefix because every renderer here shows a table.

This breaks the Emacs Lisp habit that a prefix equals the feature name, on purpose. Two things follow:

- Completing =sp-collec-query-= in =M-x= lists every command of the family.
- A module and a command can look alike: =sp-collec-query-menu= is the transient command, =sp-collection-query-tables-menu= the file that defines it.

The customize group is =sp-collec-query= and its =:prefix= says so.

* The spec

A plist. Every filter is optional and the filters are combined with /and/.

| Key                              | Meaning                                                                 |
|----------------------------------+-------------------------------------------------------------------------|
| =:tags=, =:tags-any=, =:tags-none= | all of, at least one of, none of these tags                             |
| =:directories=                   | the note's file lies under one of these directories                     |
| =:todo=                          | the note's TODO state is one of these                                   |
| =:links=                         | the note links to at least one of these note IDs                        |
| =:meta=                          | list of =(KEY . VALUE)=; a nil =VALUE= only requires the key            |
| =:parent-of=, =:parent-prop=     | an ID or ="self"=; the meta key (default =parents=) that links to it    |
| =:level=                         | nil, =0= (file-level notes) or =headings=                               |
| =:title-match=                   | regexp for the title, case-insensitive                                  |
| =:columns=                       | =:title :tags :todo :level :priority :id :file :path= or a meta key     |
| =:sort-by=, =:sort-desc=         | a column, and non-nil for descending                                    |
| =:column-widths=                 | exc only: alist =(COLUMN . WIDTH)=; =t= stands for the columns not listed |
| =:wrap=                          | exc only: =wrap= (wrap inside the width) or =fit= (size to the text)    |

In a note, the same spec is the parameter list of a dynamic block:

#+begin_example
,#+BEGIN: collection-query-table :tags ("book") :columns (:title "author" "rating") :sort-by "rating"
,#+END:
#+end_example

* Using it

=C-c w T= opens the menu. Each key sets one thing and shows its value; =RET= opens the table, =P= counts the notes, =i= inserts the spec as a dynamic block at point, =S= saves it as a view, =V= loads one and =D= deletes one.

| Key       | Command                          | What it does                                         |
|-----------+----------------------------------+------------------------------------------------------|
| =C-c w T= | =sp-collec-query-menu=           | Build a query                                        |
| =C-c w v= | =sp-collec-query-open-view=      | Open a saved view                                    |
| =C-c w V= | =sp-collec-query-view-save=      | Open the menu to save a view (was: prompts)          |
| =C-c w t= | =sp-collec-query-inline-toggle=  | Live inline tables in this note (vui)                |

In an exc table: =C-c o= opens the note in the row, =C-c q= edits the query in the menu and redraws the table, =C-c C-u= runs the query again. Meta columns are edited in place and written to the note; titles, tags and the other built-in columns are read-only.

* Renderers

=sp-collec-query-renderer= picks one: =auto= (the first that loads of exc, vui, org), =exc=, =vui= or =org=.

- *exc* is https://github.com/yibie/grid-table (package name =exc= since 0.5.1), a spreadsheet drawn with ETAF. It is not part of emacs-taf; the organization at https://github.com/emacs-taf provides ETAF (=ecss=, =ebox=, =etaf=, =etaf-ui=). Checked on 2026-10-21 against exc 0.5.1, ecss 0.1.0, ebox 3.1.1 and etaf 0.3.1: it needs Emacs 29.1 or later and the three ETAF libraries, none of which is on a package archive. Only the rows and columns that fit the window are drawn.

  Column width and word wrap are part of the spec, so a saved view keeps them with its columns: in the menu =w= sets the width of one column (or of =other=, the columns not listed) and =W= cycles the wrap between the option (default), =wrap= and =fit=. =wrap= keeps the widths and wraps long text onto more lines; =fit= sizes each column to its longest text, up to =sp-collec-query-exc-max-width= (80), and an explicit width still wins. The defaults are =sp-collec-query-exc-column-widths= and =sp-collec-query-exc-wrap=; a width in the spec overrides them. vui and Org ignore both keys.
- *vui* is the component library the first version used.
- *org* is a read-only Org buffer; no extra packages.

* Installing

Packages come from =use-package= with the Elpaca recipe in =:ensure=, never from clones put on =load-path=.

- The entry file declares =ecss=, =ebox=, =etaf= and =exc= that way when =sp-collec-query-install-exc= is non-nil (the default).
- The ETAF repositories keep their code in =lisp/=, so their recipes say =:files ("*.el" "lisp/*.el")=.
- exc's README gives =yibie/exc= as its address, but only =yibie/grid-table= resolved when this was written, so the recipe uses that.

* What was wrong, and what changed

Found while reading the first version, and fixed here:

- Sorting a live table by =:title= did nothing, because the cell text of =:title= was empty.
- A =|= or a line break in a cell broke the Org table; both are escaped now.
- Editing a meta cell of a heading's row rewrote the file's top-level meta; it is refused now. Matching of the key was case-insensitive, unlike Vulpea's.
- Mounting inline tables left the buffer marked modified after every save.
- The saved-view file was a fixed list of positional fields; adding a filter would have broken old files. It is a spec plist now.
- A =vui= table was the only interactive option and =vui= a hard requirement of the views module; now it is one renderer of three.
- Three prefixes (=sia-=, =sp-= and unprefixed) became =sp-collec-query-=.

Left as they were: =org-id-get-create= still adds an ID to the file when a "self" parent is resolved in a note without one; =vulpea-db-query= still loads every note and filters in Lisp.

  "Return the buffer name for the table called NAME with SPEC."

(defun sp-collec-query-open (spec &optional name target)
  "Show the table SPEC describes, in the renderer `sp-collec-query-renderer' picks.
A \"self\" :parent-of is resolved against the current buffer first.  NAME
(a view name) names the buffer; with TARGET, an exc table buffer, that
buffer is redrawn with SPEC instead of opening another."
  (let* ((spec (sp-collec-query-resolve-spec spec))
         (renderer (sp-collec-query--renderer)))
    (if (and (eq renderer 'exc) target (buffer-live-p target)
             (buffer-local-value 'sp-collec-query-exc--spec target))
        (progn (require 'sp-collection-query-tables-exc)
               (with-current-buffer target (sp-collec-query-exc--draw spec))
               (pop-to-buffer target))
      (let ((buffer-name (sp-collec-query--buffer-name name spec)))
        (pcase renderer
          ('exc (require 'sp-collection-query-tables-exc)
                (sp-collec-query-exc-open spec buffer-name))
          ('vui (require 'sp-collection-query-tables-vui)
                (sp-collec-query-vui-open spec buffer-name))
          (_ (sp-collec-query-org-open spec buffer-name)))))))

** Specs

The keys a spec may carry:

- The filters are all optional and are combined with /and/:
  - tags (all, any, none),
  - directories,
  - TODO states,
  - links to notes,
  - meta keys with an optional value,
  - children of a parent note,
  - level,
  - a title regexp.
- =:columns=, =:sort-by= and =:sort-desc= shape the table; =:column-widths= and =:wrap= only change how the exc renderer draws it.
- A "self" parent is resolved against the buffer the table is asked from, because a renderer may switch buffers before it queries.

#+begin_src emacs-lisp -i
(defconst sp-collec-query-spec-keys
  '(:tags :tags-any :tags-none :directories :todo :links :meta
    :parent-of :parent-prop :level :title-match
    :columns :sort-by :sort-desc :column-widths :wrap)
  "Keys a table spec may carry.
:TAGS, :TAGS-ANY and :TAGS-NONE are lists of tags (all, at least one,
none of them); :DIRECTORIES a list of directories a note's file lies
under; :TODO a list of TODO states; :LINKS a list of note IDs, at least
one of which the note links to; :META a list of (KEY . VALUE) where a nil
VALUE only asks for KEY to be present; :PARENT-OF an ID or the string
\"self\", checked against the meta key :PARENT-PROP (default \"parents\");
:LEVEL nil, 0 (file-level notes) or `headings'; :TITLE-MATCH a regexp;
:COLUMNS the columns to show and :SORT-BY the column to sort on, each a
keyword (see `sp-collec-query-builtin-columns') or the name of a meta key;
:SORT-DESC non-nil to sort descending; :COLUMN-WIDTHS an alist of
\(COLUMN . WIDTH) giving the width in characters of a column in the exc
table, T standing for the columns not listed; :WRAP `wrap' to wrap long
text inside the width, or `fit' to size a column to its text, up to
`sp-collec-query-exc-max-width'.  The last two only apply to the exc
renderer and fall back to the options of the same name.")
#+end_src

#+begin_src emacs-lisp -i
(defun sp-collec-query-spec-normalize (spec)
  "Return SPEC with only known keys, and :columns defaulting to (:title).
Tags, directories and the like are copied so callers may keep editing SPEC."
  (let (out)
    (dolist (key sp-collec-query-spec-keys)
      (when-let* ((cell (plist-member spec key)))
        (setq out (plist-put out key (copy-tree (cadr cell))))))
    (unless (plist-get out :columns)
      (setq out (plist-put out :columns (list :title))))
    out))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-collec-query-resolve-parent-of (parent-of)
  "Resolve PARENT-OF to a literal note ID.
The string \"self\" (or the symbol `self') becomes the ID of the note the
current buffer visits, which `org-id-get-create' adds to the file when it
has none; anything else is returned unchanged."
  (if (member parent-of '("self" self))
      (progn
        (unless buffer-file-name
          (user-error "\"self\" needs a buffer that visits a note"))
        (save-excursion (goto-char (point-min)) (org-id-get-create)))
    parent-of))
#+end_src

(defun sp-collec-query-note-matches-p (note spec)
  "Non-nil if NOTE satisfies every filter in SPEC.
:PARENT-OF in SPEC must already be a literal ID."
  (let ((tags (vulpea-note-tags note))
        (parent-of (plist-get spec :parent-of)))
    (and (seq-every-p (lambda (tag) (member tag tags)) (plist-get spec :tags))
         (or (null (plist-get spec :tags-any))
             (seq-some (lambda (tag) (member tag tags)) (plist-get spec :tags-any)))
         (not (seq-some (lambda (tag) (member tag tags)) (plist-get spec :tags-none)))
         (or (null (plist-get spec :directories))
             (sp-collec-query--under-directory-p (vulpea-note-path note)
                                                 (plist-get spec :directories)))
         (or (null (plist-get spec :todo))
             (member (vulpea-note-todo note) (plist-get spec :todo)))
         (or (null (plist-get spec :links))
             (let ((dests (mapcar (lambda (l) (plist-get l :dest))
                                  (vulpea-note-links note))))
               (seq-some (lambda (id) (member id dests)) (plist-get spec :links))))
         (seq-every-p (lambda (clause) (sp-collec-query--meta-match-p note clause))
                      (plist-get spec :meta))
         (or (null parent-of)
             (member parent-of
                     (vulpea-note-meta-get-list
                      note (or (plist-get spec :parent-prop) "parents") 'link)))
         (pcase (plist-get spec :level)
           ('nil t)
           (0 (eql (vulpea-note-level note) 0))
           ('headings (> (or (vulpea-note-level note) 0) 0)))
         (or (null (plist-get spec :title-match))
             (let ((case-fold-search t))
               (string-match-p (plist-get spec :title-match)
                               (or (vulpea-note-title note) "")))))))

(defun sp-collec-query--sort-lessp (a b)
  "Non-nil if the cell text A sorts before B.
Numbers sort numerically and before text; empty cells go last."
  (let ((num-a (and (string-match-p "\\`-?[0-9]+\\(?:\\.[0-9]+\\)?\\'" a)

                    (string-to-number b))))

          ((string-empty-p b) t)
          ((and num-a num-b) (< num-a num-b))
          (num-a t)
          (num-b nil)
          (t (string-collate-lessp a b nil t)))))

Used by the exc and vui renderers when a meta cell is edited.

(defun sp-collec-query-write-meta (note key value)
  "Set the meta KEY of the file-level NOTE to VALUE, in NOTE's own file.
Replaces the first \"- KEY :: ...\" line before the first heading, or adds
one there (at the end of the file when it has no heading), then saves the
file.  A note for a heading has no meta of its own in this layout, so it
is refused rather than written to the wrong place."
  (unless (eql (vulpea-note-level note) 0)
    (user-error "Only file-level notes can be edited here (%s is a heading)"
                (vulpea-note-title note)))
  (with-current-buffer (find-file-noselect (vulpea-note-path note))
    (save-excursion
      (save-restriction
        (widen)
        (goto-char (point-min))
        (let* ((case-fold-search nil)
               (limit (save-excursion
                        (if (re-search-forward "^\\*" nil t)
                            (line-beginning-position)
                          (point-max))))
               (re (format "^\\(-[ \t]+%s[ \t]+::[ \t]*\\).*$" (regexp-quote key))))
          (if (re-search-forward re limit t)
              (replace-match (concat "\\1" (replace-regexp-in-string
                                            "\\\\" "\\\\\\\\" value))
                             t)
            ;; After the last meta line of the file's own block, else at the limit.
            (goto-char (point-min))
            (let (last)
              (while (re-search-forward "^-[ \t]+[^ \t:]+[ \t]+::" limit t)
                (setq last (line-end-position)))
              (if last
                  (progn (goto-char last) (insert (format "\n- %s :: %s" key value)))
                (goto-char limit)
                (unless (bolp) (insert "\n"))
                (insert (format "- %s :: %s\n" key value))))))))
    (save-buffer)
    (setq sp-collec-query--last-write (current-time))))
#+end_src

** Refreshing open tables

(defun sp-collec-query-exc--width (column spec &optional texts)
  "Return the width for COLUMN of SPEC, whose cell and header text is TEXTS.
A width in the spec's :column-widths wins; then, if the table fits its
columns, the longest line in TEXTS up to `sp-collec-query-exc-max-width';
then `sp-collec-query-exc-column-widths'."
  (let ((own (plist-get spec :column-widths)))
    (or (alist-get column own nil nil #'equal)
        (and (eq (or (plist-get spec :wrap) sp-collec-query-exc-wrap) 'fit)
             (min sp-collec-query-exc-max-width
                  (apply #'max 1
                         (mapcar (lambda (text)
                                   (apply #'max 0
                                          (mapcar #'string-width
                                                  (split-string text "\n"))))
                                 texts))))
        (alist-get t own)
        (alist-get column sp-collec-query-exc-column-widths nil nil #'equal)
        (alist-get t sp-collec-query-exc-column-widths)
        20)))

(defun sp-collec-query-exc--guard (source columns notes)
  "Make SOURCE write meta cells to their notes and refuse other edits.
COLUMNS are the table's columns and NOTES a vector of its notes."
  (let ((original (gethash :set-raw-value-at source))
        (ncols (length columns)))
    (puthash :set-raw-value-at
             (lambda (s row col value)
               (cond
                ((= row 0) (user-error "The header row is not editable"))
                ((or (>= col ncols) (> row (length notes)))
                 (user-error "Outside the table"))
                ((not (stringp (nth col columns)))
                 (user-error "The %s column is read-only"
                             (sp-collec-query-header-label (nth col columns))))
                ((sp-collec-query-has-link-p
                  (sp-collec-query-cell (aref notes (1- row)) (nth col columns)))
                 (user-error "This cell holds a link; edit it in the note"))
                (t (sp-collec-query-write-meta (aref notes (1- row)) (nth col columns) value)
                   (funcall original s row col value))))
             source)))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-collec-query-exc--source (spec notes)
  "Return an exc data source for SPEC and the list NOTES."
  (let* ((columns (plist-get spec :columns))
         (labels (mapcar #'sp-collec-query-header-label columns))
         (rows (sp-collec-query-rows notes columns))
         (source (make-exc-default-data-source
                  labels
                  (cons labels rows)
                  (sp-collec-query-spec-summary spec))))
    (cl-loop for column in columns
             for i from 0
             do (exc-set-style-at source 0 i '(:bold t))
             do (exc-set-column-width
                 source i
                 (sp-collec-query-exc--width
                  column spec
                  (cons (nth i labels)
                        (mapcar (lambda (row) (format "%s" (or (nth i row) "")))
                                rows)))))
    (exc-set-frozen source 1 0)
    (sp-collec-query-exc--guard source columns (vconcat notes))
    source))

Meta columns are editable fields that write back to their note.  Click a
column in the \"Sort by\" row to sort by it, and again to reverse."
  :state ((refresh-tick 0)
          (sort-override nil)
          (sort-desc nil))
  :render
  (progn
    (vui-use-effect ()
      (let ((fn (lambda () (vui-set-state :refresh-tick #'1+))))
        (add-hook 'sp-collec-query-refresh-functions fn)
        (lambda () (remove-hook 'sp-collec-query-refresh-functions fn))))
    (let* ((columns (plist-get spec :columns))
           (effective-sort (or sort-override (plist-get spec :sort-by)))
           (descending (if sort-override sort-desc (plist-get spec :sort-desc)))
           (notes (sp-collec-query-sort
                   (sp-collec-query-query (plist-put (copy-sequence spec) :sort-by nil))
                   effective-sort descending))
           (rows (mapcar
                  (lambda (note)
                    (mapcar
                     (lambda (c)
                       (cond
                        ((eq c :title)
                         (vui-button (or (vulpea-note-title note) "")
                                     :on-click (lambda () (find-file (vulpea-note-path note)))))
                        ((keywordp c) (sp-collec-query-linkify (sp-collec-query-cell note c)))
                        ;; A field would show the raw [[id:..][..]] text and
                        ;; save the description over the link when edited.
                        ((sp-collec-query-has-link-p
                          (or (car (vulpea-note-meta-get-list note c)) ""))
                         (vui-text (sp-collec-query-linkify
                                    (sp-collec-query-cell note c))))
                        (t (vui-field
                            :value (or (car (vulpea-note-meta-get-list note c)) "")
                            :on-change (lambda (val)
                                         (sp-collec-query-write-meta note c val)
                                         (vui-set-state :refresh-tick #'1+))))))
                     columns))
                  notes)))
      (vui-vstack
       (vui-text (sp-collec-query-spec-summary spec) :face 'bold)
       (vui-text (format "%d note%s" (length notes) (if (= (length notes) 1) "" "s"))
                 :face 'shadow)
       (vui-newline)
       (apply #'vui-hstack
              (vui-text "Sort by: " :face 'shadow)
              (mapcar
               (lambda (c)
                 (vui-button
                  (concat (sp-collec-query-header-label c)
                          (cond ((not (equal effective-sort c)) "")
                                (descending " ↓") (t " ↑")))
                  :on-click (lambda ()
                              (if (equal effective-sort c)
                                  (progn (vui-set-state :sort-override c)
                                         (vui-set-state :sort-desc (not descending)))
                                (vui-set-state :sort-override c)
                                (vui-set-state :sort-desc nil)))))
               columns))
       (vui-newline)
       (vui-table :columns (mapcar (lambda (c)
                                     (list :header (sp-collec-query-header-label c)
                                           :width 24))
                                   columns)
                  :rows rows :border :ascii)))))

** Inline mounting

Replaces the content of every =vulpea-table= block with a live table, and puts the plain text back before a save so the file never holds widget state. The buffer's modified flag is restored after mounting and unmounting, so a save no longer leaves it marked modified.

#+begin_src emacs-lisp -i
(defun sp-collec-query-vui--dblock-regions ()
  "Return (SPEC CONTENT-BEGIN CONTENT-END) for each query table dblock."
  (let (blocks)
    (save-excursion
      (goto-char (point-min))
      (while (re-search-forward "^[ \t]*#\\+BEGIN:[ \t]+\\(?:collection-query-table\\|vulpea-table\\)\\(.*\\)$" nil t)
        (let* ((params (ignore-errors (car (read-from-string (format "(%s)" (match-string 1))))))
               (begin (progn (forward-line 1) (point)))
               (end (if (re-search-forward "^[ \t]*#\\+END:" nil t)
                        (line-beginning-position)
                      (point))))
          (when params (push (list params begin end) blocks)))))
    (nreverse blocks)))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-collec-query-vui--clear ()
  "Unmount the inline tables and write the plain dblock text back."
  (dolist (instance sp-collec-query-vui--instances)
    (vui-unmount instance))
  (setq sp-collec-query-vui--instances nil)
  (let ((modified (buffer-modified-p)))
    (save-excursion
      (goto-char (point-min))
      (while (re-search-forward "^[ \t]*#\\+BEGIN:[ \t]+\\(?:collection-query-table\\|vulpea-table\\)" nil t)
        (beginning-of-line)
        (ignore-errors (org-dblock-update))
        (forward-line 1)))
    (restore-buffer-modified-p modified)))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-collec-query-inline-mount ()
  "Replace the content of every query table dblock with a live table."
  (interactive)
  (sp-collec-query-vui--clear)
  (let ((modified (buffer-modified-p)))
    (dolist (block (reverse (sp-collec-query-vui--dblock-regions)))
      (pcase-let ((`(,params ,begin ,end) block))
        ;; Resolved here, in the note's own buffer, so "self" is this note.
        (let ((spec (sp-collec-query-resolve-spec params)))
          (goto-char begin)
          (delete-region begin end)
          (push (vui-mount-inline (vui-component 'sp-collec-query :spec spec))
                sp-collec-query-vui--instances))))
    (restore-buffer-modified-p modified))
  (setq sp-collec-query-vui--active t))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-collec-query-inline-unmount ()
  "Unmount the inline tables, restoring plain dblock text."
  (interactive)
  (sp-collec-query-vui--clear)
  (setq sp-collec-query-vui--active nil))
#+end_src
