Literate source for =libraries/modules/ui/sp-textui.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module installs two packages by yibie from GitHub: =textui=, which the comment describes as a new package for better rendering of widgets in a buffer, and =org-table-widget=, which displays Org tables as interactive widgets. It then turns on =org-table-widget-mode= in every Org buffer. The module is in the UI group of the default module list in =init.el=, loaded just before the themes.

** Packages

Installs =textui= and =org-table-widget= from their GitHub repositories with Elpaca.

#+begin_src emacs-lisp -i
(use-package textui
    :ensure (:host github :repo "yibie/textui"))

(use-package org-table-widget
    :ensure (:host github :repo "yibie/org-table-widget"))
#+end_src

** Enable in Org

Adds =org-table-widget-mode= to =org-mode-hook=, so every Org buffer shows its tables through the widget layer.

#+begin_src emacs-lisp -i
(add-hook 'org-mode-hook #'org-table-widget-mode)
#+end_src
