Literate source for =libraries/modules/academic/sp-statistics.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. Tangling this file (=C-c C-v t=) rewrites that =.el= file from these blocks; nothing is tangled unless you run it.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module installs ESS (Emacs Speaks Statistics), which provides editing modes and interactive sessions for R and other statistics languages. It is a single package declaration with no further configuration. It is listed in the Academic block of =init.el= but commented out, so it is not loaded by default.

** Install ESS

Installs the =ess= package with its default settings. Its modes are set up by the package's own autoloads, so opening an R file uses ESS once it is installed.

  :ensure t)
