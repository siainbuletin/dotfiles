Literate source for =libraries/modules/tooling/sp-templating.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. Tangling this file (=C-c C-v t=) rewrites that =.el= file from these blocks; nothing is tangled unless you run it.

A very small placeholder module for templating. Currently it only loads =org-tempo=, the part of Org that expands short keys like =<s= followed by TAB into a source block skeleton (and similarly for quote, example and other blocks). The TODO notes that more template expansion, in Org and possibly in programming modes, would be useful later.

It is loaded in both the default and minimal module lists. Since =org-tempo= ships with Org, requiring it also loads Org itself at startup if it is not loaded yet.

** org-tempo

Requires =org-tempo=, which enables the =<= plus key shortcuts for inserting Org blocks and keywords. The comment that follows asks whether it is built in: it is, as part of Org since version 9.2, where this shortcut stopped being enabled by default.

#+begin_src emacs-lisp -i
(require 'org-tempo) ; for template expansion

;; Is this package built in?
#+end_src
