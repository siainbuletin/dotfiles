A tiny module that configures Emacs' built-in =bookmark= library. It has no external dependencies and is loaded from =init.el= as part of the general tooling modules.

The only behaviour it changes is how often bookmarks are saved to disk and which key deletes a bookmark.

* Bookmark configuration

** The bookmark package

=bookmark= is built in, so =:ensure nil= stops the package manager from trying to install it. Setting =bookmark-save-flag= to 1 makes Emacs write the bookmark file after every single change, instead of only when Emacs exits, so bookmarks survive a crash. ~C-x r D~ is bound to =bookmark-delete=, which complements the default ~C-x r m~ (set) and ~C-x r b~ (jump) bindings.

#+begin_src emacs-lisp -i
(use-package bookmark
  :ensure nil
  :custom
  (bookmark-save-flag 1)
  :bind
  ("C-x r D" . bookmark-delete))
#+end_src
