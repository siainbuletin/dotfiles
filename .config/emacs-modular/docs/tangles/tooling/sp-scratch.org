The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module, inherited from Lambda Emacs (hence the =lem--= function prefix), makes the =*scratch*= buffer more useful. It starts scratch in =org-mode=, refuses to kill scratch and buries it instead, and when =sp-persistent-scratch= is on it saves scratch to a file in the cache directory on exit and every five minutes of idle time, and restores it at startup.

It uses =sp-cache-dir=, defined in =early-init.el= as the =cache/= directory under the config's var directory, so the saved file is =scratch= in that directory. There are no package dependencies. The module is in both the default and minimal module lists in =init.el=. The commentary leaves a TODO to bring in settings from an older configuration.

* Variables

** Persistence switch

=sp-persistent-scratch= controls whether scratch is saved and restored across sessions. It defaults to on.

#+begin_src emacs-lisp -i
;;;; Variables

(defcustom sp-persistent-scratch t
  "If t, make scratch buffer persist across sessions.
Default is to persist."
  :group 'spcustom
  :type 'boolean)
#+end_src

** Save and working directories

=sp-scratch-save-dir= is where the scratch file is written, defaulting to =sp-cache-dir=. =sp-scratch-default-dir= is the =default-directory= given to the scratch buffer, defaulting to the home directory, though it is overridden a few blocks below.

#+begin_src emacs-lisp -i
(defcustom sp-scratch-save-dir sp-cache-dir
  "Default directory for saving scratch file."
  :group 'spcustom
  :type 'string)

(defcustom sp-scratch-default-dir (expand-file-name "~/")
  "Default directory for scratch buffer.
User may prefer to set this to `sp-scratch-save-dir'."
  :group 'spcustom
  :type 'string)
#+end_src

** Bury scratch

=lem--bury-scratch= is added to =kill-buffer-query-functions=. When the buffer being killed is =*scratch*= it buries it and returns nil, which cancels the kill; for any other buffer it returns t and the kill proceeds.

#+begin_src emacs-lisp -i
(defun lem--bury-scratch ()
  "Don't kill scratch buffer, bury it."
  (if (eq (current-buffer) (get-buffer "*scratch*"))
      (progn (bury-buffer)
             nil)
    t))

(add-hook 'kill-buffer-query-functions 'lem--bury-scratch)
#+end_src

* Saving persistent scratch

** Save function

=lem--save-persistent-scratch= writes the whole scratch buffer to the =scratch= file in the save directory, creating the buffer first if it has been lost.

#+begin_src emacs-lisp -i
;;;; Saving persistent scratch

(defun lem--save-persistent-scratch ()
  "Save the contents of *scratch*."
  (with-current-buffer (get-buffer-create "*scratch*")
    (write-region (point-min) (point-max)
                  (concat sp-scratch-save-dir "scratch"))))
#+end_src

** Load function

=lem--load-persistent-scratch= replaces the scratch buffer's contents with the saved file when it exists, and in any case sets the buffer's local =default-directory= to =sp-scratch-default-dir=. It assumes =*scratch*= exists at that point.

#+begin_src emacs-lisp -i
(defun lem--load-persistent-scratch ()
  "Reload the scratch buffer."
  (let ((scratch-file (concat sp-scratch-save-dir "scratch")))
    (if (file-exists-p scratch-file)
        (with-current-buffer (get-buffer "*scratch*")
          (delete-region (point-min) (point-max))
          (insert-file-contents scratch-file))))
  ;; set default dir for scratch buffer
  (with-current-buffer (get-buffer "*scratch*")
    (setq-local default-directory sp-scratch-default-dir)))
#+end_src

** Hooks and timer

When persistence is on, scratch is restored from =after-init-hook=, saved from =kill-emacs-hook=, and saved again by a repeating idle timer after every 300 seconds of idleness. The setting is read once when the module loads, so changing it later does not add or remove these hooks.

#+begin_src emacs-lisp -i
;; Hooks for loading and saving the scratch buffer
(cond (sp-persistent-scratch
       (add-hook 'after-init-hook 'lem--load-persistent-scratch)
       (add-hook 'kill-emacs-hook 'lem--save-persistent-scratch)
       ;; Save scratch buffer every 5 minutes (300 seconds)
       (run-with-idle-timer 300 t 'lem--save-persistent-scratch)))
#+end_src
