#+TITLE: sp-prot-modeline.el: A native mode line adapted from Prot's
#+PROPERTY: header-args:emacs-lisp :tangle ../../../libraries/modules/tooling/sp-prot-modeline.el :comments no :padline yes :noweb no :mkdirp yes
#+STARTUP: content

Literate source for =libraries/modules/tooling/sp-prot-modeline.el=.

- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README.

This module is an alternative to =sp-lambda-modeline=. It is adapted from =prot-modeline.el= and the mode line section of =prot-emacs-modeline.el= in [[https://github.com/protesilaos/dotfiles][Protesilaos Stavrou's dotfiles]]. It needs no package: it fills =mode-line-format= with a few constructs, the way the default mode line does.

- It is /not/ loaded by =init.el=. To try it, comment out ='sp-lambda-modeline= in both module lists and add ='sp-prot-modeline= (both are in the file as commented lines). Only one of the two should be active, because both set =mode-line-format=.
- Untested in a running Emacs: the container that wrote it has no Emacs 31.

* What differs from Prot's file

- *No =prot-common= or =prot-icons=.* The only function used from =prot-common= (=prot-common-window-narrow-p=) is written out here. Icons are replaced by text, so no font is needed.
- *Colours come from the theme.* Prot's faces have fixed hex colours and a block in =prot-emacs-modeline.el= that reads the Modus palette. Here the faces inherit from =error=, =success=, =warning=, =font-lock-keyword-face= and so on, so every theme in =libraries/themes= works with no extra code.
- *Minor modes are shown.* Prot's mode line has no minor modes. =sp-prot-modeline-minor-modes= shows their lighters, a count, or nothing (=sp-prot-modeline-minor-modes-style=).
- *Header line and divider.* Prot's own mode line has no header. Here the header line and the divider above the mode line come from =sp-nano-style= (nano-modeline's blocks: =RW=, =RO= or =**=, the path in bold, the project at the right), as in =sp-lambda-modeline=. The buffer name stays in the mode line.
- *Major mode icon.* The major mode is shown as its =nerd-icons= icon, with the name as its tooltip (=sp-prot-modeline-mode-icon=); Prot's text is the fallback when there is no icon. Prot's own file has the =prot-icons= library for this.
- *Keycast.* The keys and commands are shown at the bottom, in the mode line, with =keycast-mode-line-mode=, after the branch, as in Prot's =prot-emacs-modeline.el= (same format, window predicate and substitutions for typing and mouse events). Turn it off with =sp-prot-modeline-keycast=. =keycast-header-line-mode= is turned off, so the keys are not shown twice.
- *Left out:* the Eglot and =notmuch-indicator= parts, which Sia's configuration does not use.
- *Org-aware.* =sp-prot-modeline-misc-info= keeps =global-mode-string= (the clock, and the tag emoji of =sp-tag-emoji=, which lambda-line never displays).
- *Emacs 30.* =mode-line-format-right-align= and =mode-line-right-align-edge= are Emacs 30 features, as in Prot's file. They are safe on Emacs 29 because an unbound symbol in a mode line format is ignored.

* Changing the settings

Everything below is set with =M-x customize-group RET sp-prot-modeline RET=, or with a =setq= in your own configuration /before/ the module loads (for example in =init.el=, above the module list). Names with =sp-nano-style= belong to the header line and the divider. After changing a setting, turn the mode off and on again with =M-x sp-prot-modeline-mode= twice, or restart Emacs, unless the table says otherwise. None of this needs any change to the Emacs Lisp code of the module.

** Options (variables)

| Variable                                | Default                      | What it does                                                                                                   |
|-----------------------------------------+------------------------------+----------------------------------------------------------------------------------------------------------------|
| =sp-prot-modeline-minor-modes-style=    | =lighters=                   | How enabled minor modes are shown: =lighters= (the text each mode puts in the line, as in the default Emacs mode line), =count= (a number such as =(7)=, the names in the tooltip) or =nil= (nothing). Takes effect at once. |
| =sp-prot-modeline-mode-icon=            | =t=                          | Show the major mode as a nerd-icons icon (=t=) or as its name in bold (=nil=). Takes effect at once.            |
| =sp-prot-modeline-string-truncate-length= | =9=                        | In a narrow window (narrower than =split-width-threshold=, with more than one window) names are cut to this many characters: the buffer name in the middle, the branch and the minor modes at the end. Raise it for longer names, set it very high (=999=) to never cut. Takes effect at once. |
| =sp-prot-modeline-keycast=              | =t=                          | Show the keys and commands (keycast) at the bottom. =nil= turns it off at the next enabling of the mode.        |
| =sp-prot-modeline-keycast-format=       | ="%2s%k%c%R"=                | What keycast prints: =%k= the key, =%c= the command, =%R= how many times it was repeated, =%s= padding (=%2s= is two spaces). Example: ="%k %c"= for the key and the command only. |
| =sp-prot-modeline-keycast-insert-after= | =sp-prot-modeline-vc-branch= | The segment of the line (a name from the list below) that keycast comes after.                                |
| =sp-nano-style-divider=                 | =t=                          | The thin line between the text of the buffer and the mode line; =nil= removes it.                              |
| =sp-nano-style-divider-face=            | =shadow=                     | The face whose foreground colours the divider. Any face works, for example =font-lock-comment-face=.            |
| =sp-prot-modeline-format=               | see the next section         | The order of the segments.                                                                                    |

Example, in your configuration:

#+begin_src emacs-lisp :tangle no
(setq sp-prot-modeline-minor-modes-style 'count   ; (7) instead of the lighters
      sp-prot-modeline-string-truncate-length 20  ; cut long names later
      sp-prot-modeline-keycast-format "%k %c"     ; no padding, no repeat count
      sp-nano-style-divider-face 'font-lock-comment-face)
#+end_src

** The segments and their order

=sp-prot-modeline-format= is a list. Each name in it is a segment; strings such as ="  "= are spaces between them. To remove a segment delete its name from the list, to move it cut and paste the name, to add space put a string in. =mode-line-format-right-align= is not a segment: everything after it is pushed to the right edge of the window.

| Segment                                    | Shows                                                                                          |
|--------------------------------------------+------------------------------------------------------------------------------------------------|
| =sp-prot-modeline-kbd-macro=               | A blue =KMacro= block while a keyboard macro is being recorded (selected window only).         |
| =sp-prot-modeline-narrow=                  | A =Narrow= block when the buffer is narrowed (not in Info, help, message and special buffers). |
| =sp-prot-modeline-buffer-status=           | A red =@= block for a remote (TRAMP) buffer.                                                   |
| =sp-prot-modeline-window-dedicated-status= | A grey block with an equals sign when the window is dedicated to its buffer.                                  |
| =sp-prot-modeline-input-method=            | The title of the input method, in a green block, when one is on.                               |
| =sp-prot-modeline-buffer-identification=   | The buffer name (italic when the file has unsaved changes, bold in the selected window) and =RO= when read-only. Hover for the file name. |
| =sp-prot-modeline-major-mode=              | The major mode icon (or name); click for =describe-mode=. =%[= and =%]= show recursive edits.   |
| =sp-prot-modeline-minor-modes=             | The minor modes, see =sp-prot-modeline-minor-modes-style=.                                      |
| =sp-prot-modeline-process=                 | The process status of the buffer (=mode-line-process=), for example in shells.                  |
| =sp-prot-modeline-vc-branch=               | The branch (or a short revision), coloured by the state of the file; click for the diff.        |
| =sp-prot-modeline-flymake=                 | Counts of errors (=E=), warnings (=!=) and notes (=.=) while Flymake is on.                     |
| =sp-prot-modeline-which-function-indicator= | The current function or Org heading, in a small face (text and programming buffers).           |
| =sp-prot-modeline-misc-info=               | =mode-line-misc-info=: the clock, and the tag emoji of =sp-tag-emoji= in Org buffers.           |

Example, a shorter line without the process, Flymake and function segments (the keycast segment is added by keycast itself after =sp-prot-modeline-vc-branch=):

#+begin_src emacs-lisp :tangle no
(setq sp-prot-modeline-format
      '("%e"
        sp-prot-modeline-kbd-macro
        sp-prot-modeline-narrow
        " "
        sp-prot-modeline-buffer-identification
        "  "
        sp-prot-modeline-major-mode
        "  "
        sp-prot-modeline-vc-branch
        mode-line-format-right-align
        sp-prot-modeline-misc-info))
;; then: M-x sp-prot-modeline-mode twice
#+end_src

If you remove =sp-prot-modeline-vc-branch= set =sp-prot-modeline-keycast-insert-after= to another segment that stays in the list, or keycast cannot start.

** Colours

The coloured blocks use these faces. They inherit from faces every theme defines, so they change with =sp-load-theme=; to change one yourself use =M-x customize-face= (or =set-face-attribute=) on it.

| Face                                  | Inherits from              | Used by                                      |
|---------------------------------------+----------------------------+----------------------------------------------|
| =sp-prot-modeline-indicator-red-bg=   | =error= (inverted)         | remote buffer block                          |
| =sp-prot-modeline-indicator-green-bg= | =success= (inverted)       | input method block                           |
| =sp-prot-modeline-indicator-blue-bg=  | =font-lock-keyword-face= (inverted) | keyboard macro block                |
| =sp-prot-modeline-indicator-cyan-bg=  | =font-lock-type-face= (inverted) | narrow block                           |
| =sp-prot-modeline-indicator-gray-bg=  | =shadow= (inverted)        | dedicated window block                       |
| =sp-prot-modeline-indicator-red=      | =error=                    | =RO= marker and the =%[ %]= recursive-edit marks |
| =sp-prot-modeline-indicator-gray=     | =shadow=                   | minor modes, counts, unselected windows      |
| =sp-prot-modeline-indicator-button=   | nothing                    | inherited by all the =-bg= faces: give it a =:box= to put a border round every block |

The colour of the selected and the other windows is the theme's own =mode-line= and =mode-line-inactive=. The branch takes the colour of the =vc-*-state= faces of the theme, the Flymake counts that of =error=, =warning= and =success=. The header line blocks have their own faces, =sp-nano-style-header-ro=, =-md=, =-rw=, =-name= and =-faded=.

Example, a border around the blocks and a bolder divider colour:

#+begin_src emacs-lisp :tangle no
(set-face-attribute 'sp-prot-modeline-indicator-button nil :box '(:style flat-button))
(setq sp-nano-style-divider-face 'default)
#+end_src

** Adding a segment of your own

A segment is a variable whose value is a mode line construct, marked as safe to evaluate. This one shows the number of the current line when the buffer is longer than 1000 lines:

#+begin_src emacs-lisp :tangle no
(defvar sp-prot-modeline-big-buffer
  '(:eval (when (> (line-number-at-pos (point-max)) 1000) " big ")))
(put 'sp-prot-modeline-big-buffer 'risky-local-variable t)
(setq sp-prot-modeline-format
      (append sp-prot-modeline-format '(sp-prot-modeline-big-buffer)))
#+end_src

** Where the original differs

Prot sets some things in =prot-emacs-modeline.el= that are not options here: =mode-line-compact= (off) and =mode-line-right-align-edge= (=right-margin=) are set when the mode is turned on. Prot's =prot-modeline-show-frame-name= and the Eglot, =notmuch-indicator= and Modus palette parts are not included (see above).

** Options and faces

The truncation length applies in narrow windows. The style of the minor modes is one of =lighters= (the text each mode puts in the mode line), =count= (the number of enabled minor modes, with the full list in the tooltip) or nil.

The indicator faces with a =-bg= suffix use =:inverse-video=, so the colour of the theme's own =error=, =success=, =warning= and =font-lock-keyword-face= becomes the background and the text takes the mode line background.

#+begin_src emacs-lisp -i
(defgroup sp-prot-modeline nil
  "A mode line adapted from Prot's."
  :group 'mode-line)

(defcustom sp-prot-modeline-string-truncate-length 9
  "String length after which truncation is done in small windows."
  :type 'natnum
  :group 'sp-prot-modeline)

(defcustom sp-prot-modeline-minor-modes-style 'lighters
  "How to show the enabled minor modes.
`lighters' shows the text each mode puts in the mode line, `count'
shows how many are enabled, nil shows nothing."
  :type '(choice (const :tag "Lighters" lighters)
                 (const :tag "Count" count)
                 (const :tag "None" nil))
  :group 'sp-prot-modeline)

(defface sp-prot-modeline-indicator-button nil
  "Face inherited by the indicators that have a background.
Add a :box attribute to it to give all of them a border.")

(defface sp-prot-modeline-indicator-gray
  '((t :inherit (bold shadow)))
  "Face for muted indicators.")

(defface sp-prot-modeline-indicator-red
  '((t :inherit (bold error)))
  "Face for indicators that need attention.")

(defface sp-prot-modeline-indicator-red-bg
  '((t :inherit (bold error sp-prot-modeline-indicator-button) :inverse-video t))
  "Face for indicators that need attention, with a background.")

(defface sp-prot-modeline-indicator-green-bg
  '((t :inherit (bold success sp-prot-modeline-indicator-button) :inverse-video t))
  "Face for informative indicators, with a background.")

(defface sp-prot-modeline-indicator-blue-bg
  '((t :inherit (bold font-lock-keyword-face sp-prot-modeline-indicator-button)
       :inverse-video t))
  "Face for the keyboard macro indicator, with a background.")

(defface sp-prot-modeline-indicator-cyan-bg
  '((t :inherit (bold font-lock-type-face sp-prot-modeline-indicator-button)
       :inverse-video t))
  "Face for the narrowing indicator, with a background.")

(defface sp-prot-modeline-indicator-gray-bg

** Truncation helpers

#+begin_src emacs-lisp -i
(defun sp-prot-modeline--window-narrow-p ()
  "Return non-nil if the window is narrower than `split-width-threshold'."
  (and (numberp split-width-threshold)
       (< (window-total-width) split-width-threshold)))

(defun sp-prot-modeline--truncate-p (str)
  "Return non-nil if the non-blank string STR should be truncated."
  (and (stringp str)
       (not (string-blank-p str))
       (sp-prot-modeline--window-narrow-p)
       (> (length str) sp-prot-modeline-string-truncate-length)
       (not (one-window-p :no-minibuffer))))

(defun sp-prot-modeline-string-cut-end (str)
  "Return STR cut at `sp-prot-modeline-string-truncate-length' when appropriate."
  (if (sp-prot-modeline--truncate-p str)
      (concat (substring str 0 sp-prot-modeline-string-truncate-length) "...")
    str))

(defun sp-prot-modeline-string-cut-middle (str)
  "Return STR with its middle cut out when appropriate."
  (let ((half (floor sp-prot-modeline-string-truncate-length 2)))
    (if (sp-prot-modeline--truncate-p str)
        (concat (substring str 0 half) "..." (substring str (- half)))
      str)))
#+end_src

** Indicators

Each construct is a buffer-local variable holding an =:eval= form. They show only in the selected window (=mode-line-window-selected-p=), so the other windows stay quiet.

#+begin_src emacs-lisp -i
(defvar-local sp-prot-modeline-kbd-macro
    '(:eval
      (when (and (mode-line-window-selected-p) defining-kbd-macro)
        (propertize " KMacro " 'face 'sp-prot-modeline-indicator-blue-bg)))
  "Mode line construct for a keyboard macro being defined.")

(defvar-local sp-prot-modeline-narrow
    '(:eval
      (when (and (mode-line-window-selected-p)
                 (buffer-narrowed-p)
                 (not (derived-mode-p 'Info-mode 'help-mode 'message-mode 'special-mode)))
        (propertize " Narrow " 'face 'sp-prot-modeline-indicator-cyan-bg)))
  "Mode line construct for a narrowed buffer.")

(defvar-local sp-prot-modeline-input-method
    '(:eval
      (when (and (mode-line-window-selected-p) current-input-method-title)
        (propertize (format " %s " current-input-method-title)
                    'face 'sp-prot-modeline-indicator-green-bg
                    'mouse-face 'mode-line-highlight)))
  "Mode line construct for the input method.")

(defvar-local sp-prot-modeline-buffer-status
    '(:eval
      (when (file-remote-p default-directory)
        (propertize " @ "
                    'face 'sp-prot-modeline-indicator-red-bg
                    'mouse-face 'mode-line-highlight)))
  "Mode line construct for a remote buffer.")

(defvar-local sp-prot-modeline-window-dedicated-status
    '(:eval
      (when (window-dedicated-p)
        (propertize " = "
                    'face 'sp-prot-modeline-indicator-gray-bg
                    'mouse-face 'mode-line-highlight)))
  "Mode line construct for a dedicated window.")
#+end_src

** Buffer name

The name is bold in the selected window, italic when the buffer visits a modified file, and shows a =RO= marker when read-only. The tooltip gives the file name, or the directory when there is no file.

#+begin_src emacs-lisp -i
(defun sp-prot-modeline-buffer-identification-face ()
  "Return the face for `sp-prot-modeline-buffer-identification'."
  (let ((file (buffer-file-name)))
    (cond
     ((and (mode-line-window-selected-p) file (buffer-modified-p))
      '(italic mode-line-buffer-id))
     ((and file (buffer-modified-p)) 'italic)
     ((mode-line-window-selected-p) 'mode-line-buffer-id))))

(defun sp-prot-modeline-buffer-name-help-echo ()
  "Return the `help-echo' text for the buffer name."
  (concat
   (propertize (buffer-name) 'face 'mode-line-buffer-id)
   "\n"
   (propertize
    (or (buffer-file-name)
        (format "No underlying file.\nDirectory is: %s" default-directory))
    'face 'font-lock-doc-face)))

(defvar-local sp-prot-modeline-buffer-identification
    '(:eval
      (let ((name (propertize (sp-prot-modeline-string-cut-middle (buffer-name))
                              'face (sp-prot-modeline-buffer-identification-face)
                              'mouse-face 'mode-line-highlight
                              'help-echo (sp-prot-modeline-buffer-name-help-echo))))
        (if buffer-read-only
            (concat (propertize "RO"
                                'face (if (mode-line-window-selected-p)
                                          'sp-prot-modeline-indicator-red
                                        'sp-prot-modeline-indicator-gray))
                    " " name)
          name)))
  "Mode line construct for the buffer name and its read-only state.")
#+end_src

** Major and minor modes

The major mode name is the one Emacs shows (=mode-name=), with =%[= and =%]= marking recursive edits. The minor modes come from =minor-mode-alist=, so a mode hidden with =diminish= or =delight= stays hidden. A click on either opens =describe-mode=.

#+begin_src emacs-lisp -i
(defvar sp-prot-modeline-describe-map
  (let ((map (make-sparse-keymap)))
    (define-key map [mode-line down-mouse-1] 'describe-mode)
    map)
  "Keymap for the mode name and minor modes.")

(defun sp-prot-modeline-major-mode-help-echo ()
  "Return the `help-echo' text for the major mode."
  (if-let* ((parent (get major-mode 'derived-mode-parent)))
      (format "Symbol: `%s'.  Derived from: `%s'\nmouse-1: `describe-mode'"
              major-mode parent)
    (format "Symbol: `%s'.\nmouse-1: `describe-mode'" major-mode)))

(declare-function nerd-icons-icon-for-mode "nerd-icons")

(defcustom sp-prot-modeline-mode-icon t
  "When non-nil, show the major mode as a `nerd-icons' icon, not as text."
  :type 'boolean
  :group 'sp-prot-modeline)

(defun sp-prot-modeline--mode-icon ()
  "Return the `nerd-icons' icon of the major mode, or nil."
  (when (and sp-prot-modeline-mode-icon (require 'nerd-icons nil t))
    (let ((icon (nerd-icons-icon-for-mode major-mode)))
      (and (stringp icon) (not (string-empty-p icon)) icon))))

(defvar-local sp-prot-modeline-major-mode
    (list
     (propertize "%[" 'face 'sp-prot-modeline-indicator-red)
     '(:eval
       (let ((icon (sp-prot-modeline--mode-icon)))
         (apply #'propertize
                (or icon (sp-prot-modeline-string-cut-end (format-mode-line mode-name)))
                'mouse-face 'mode-line-highlight
                'help-echo (concat (format-mode-line mode-name) "\n"
                                   (sp-prot-modeline-major-mode-help-echo))
                'local-map sp-prot-modeline-describe-map
                (unless icon (list 'face 'bold)))))
     (propertize "%]" 'face 'sp-prot-modeline-indicator-red))
  "Mode line construct for the major mode.")

(defun sp-prot-modeline--enabled-minor-modes ()
  "Return the symbols of the minor modes enabled in this buffer."
  (let (modes)
    (dolist (entry minor-mode-alist)
      (let ((mode (car entry)))
        (when (and (boundp mode) (symbol-value mode))
          (push mode modes))))
    (nreverse modes)))

(defun sp-prot-modeline--minor-modes-text ()
  "Return the text for the enabled minor modes, or nil."
  (when-let* ((style sp-prot-modeline-minor-modes-style)
              (modes (sp-prot-modeline--enabled-minor-modes)))
    (pcase style
      ('lighters
       (let ((text (string-trim (format-mode-line minor-mode-alist))))
         (unless (string-empty-p text)
           (propertize (sp-prot-modeline-string-cut-end text)
                       'face 'sp-prot-modeline-indicator-gray
                       'mouse-face 'mode-line-highlight
                       'help-echo (format "Minor modes: %s\nmouse-1: `describe-mode'"
                                          (mapconcat #'symbol-name modes ", "))
                       'local-map sp-prot-modeline-describe-map))))
      ('count
       (propertize (format "(%d)" (length modes))
                   'face 'sp-prot-modeline-indicator-gray
                   'mouse-face 'mode-line-highlight
                   'help-echo (format "Minor modes: %s\nmouse-1: `describe-mode'"
                                      (mapconcat #'symbol-name modes ", "))
                   'local-map sp-prot-modeline-describe-map)))))

(defvar-local sp-prot-modeline-minor-modes
    '(:eval (when (mode-line-window-selected-p)
              (sp-prot-modeline--minor-modes-text)))
  "Mode line construct for the minor modes of the selected window.")

(defvar-local sp-prot-modeline-process
    (list '("" mode-line-process))
  "Mode line construct for the process indicator.")
#+end_src

** Version control branch

As in Prot's file, but with the VC backend taken from =vc-backend= and nothing shown for files outside version control. (Prot falls back to Git for any directory; that costs a =vc-state= call in every buffer.)

#+begin_src emacs-lisp -i
(declare-function vc-git--symbolic-ref "vc-git" (file))

(defvar sp-prot-modeline-vc-map
  (let ((map (make-sparse-keymap)))
    (define-key map [mode-line down-mouse-1] 'vc-diff)
    (define-key map [mode-line down-mouse-3] 'vc-root-diff)
    map)
  "Keymap for `sp-prot-modeline-vc-branch'.")

(defvar sp-prot-modeline--vc-faces
  '((added . vc-locally-added-state)
    (edited . vc-edited-state)
    (removed . vc-removed-state)
    (missing . vc-missing-state)
    (conflict . vc-conflict-state)
    (locked . vc-locked-state)
    (up-to-date . vc-up-to-date-state))
  "Faces for the states `vc-state' returns.")

(defun sp-prot-modeline--vc-branch-name (file backend)
  "Return the branch name of FILE under BACKEND, or a short revision."
  (when-let* ((rev (vc-working-revision file backend)))
    (or (and (eq backend 'Git) (vc-git--symbolic-ref file))
        (substring rev 0 (min 7 (length rev))))))

(defun sp-prot-modeline--vc-text ()
  "Return the propertized branch text for the current buffer, or nil."
  (when-let* ((file (or buffer-file-name default-directory))
              (backend (vc-backend file))
              (branch (sp-prot-modeline--vc-branch-name file backend))
              (state (vc-state file backend)))
    (propertize (sp-prot-modeline-string-cut-end branch)
                'face (alist-get state sp-prot-modeline--vc-faces 'vc-up-to-date-state)
                'mouse-face 'mode-line-highlight
                'help-echo (format "Revision: %s\nmouse-1: `vc-diff'\nmouse-3: `vc-root-diff'"
                                   (vc-working-revision file backend))
                'local-map sp-prot-modeline-vc-map)))

(defvar-local sp-prot-modeline-vc-branch
    '(:eval (when (mode-line-window-selected-p)
              (sp-prot-modeline--vc-text)))
  "Mode line construct for the version control branch.")

** Flymake

Counts of errors, warnings and notes, with the same mouse commands as Prot's. Shown only while =flymake-mode= is on.

#+begin_src emacs-lisp -i
(declare-function flymake--severity "flymake" (type))
(declare-function flymake-diagnostic-type "flymake" (diag))
(declare-function flymake-diagnostics "flymake" (&optional beg end))

(defvar sp-prot-modeline-flymake-map
  (let ((map (make-sparse-keymap)))
    (define-key map [mode-line down-mouse-1] 'flymake-show-buffer-diagnostics)
    (define-key map [mode-line down-mouse-3] 'flymake-show-project-diagnostics)
    map)
  "Keymap for the Flymake counters.")

(defun sp-prot-modeline--flymake-counter (type indicator face)
  "Return INDICATOR and the count of TYPE diagnostics in FACE, or nil."
  (let ((count 0))
    (dolist (d (flymake-diagnostics))
      (when (= (flymake--severity type)
               (flymake--severity (flymake-diagnostic-type d)))
        (setq count (1+ count))))
    (when (> count 0)
      (concat
       (propertize indicator 'face 'sp-prot-modeline-indicator-gray)
       (propertize (number-to-string count)
                   'face face
                   'mouse-face 'mode-line-highlight
                   'local-map sp-prot-modeline-flymake-map
                   'help-echo "mouse-1: buffer diagnostics\nmouse-3: project diagnostics")))))

(defvar-local sp-prot-modeline-flymake
    '(:eval
      (when (and (bound-and-true-p flymake-mode) (mode-line-window-selected-p))
        (concat (sp-prot-modeline--flymake-counter :error "E" 'error)
                (sp-prot-modeline--flymake-counter :warning "!" 'warning)
                (sp-prot-modeline--flymake-counter :note "." 'success))))
  "Mode line construct for the Flymake counters.")
#+end_src

** Which function and the rest

=which-function-mode= puts its indicator in =mode-line-misc-info=. It is taken out of there and shown on its own, in a small face, for text and programming modes, as Prot does. The misc info is for the selected window only, and it carries =global-mode-string=.

#+begin_src emacs-lisp -i
(defvar-local sp-prot-modeline-which-function-indicator
    '(which-function-mode
      (:eval
       (when (and (mode-line-window-selected-p)
                  (derived-mode-p 'text-mode 'prog-mode))
         (let ((string (or (gethash (selected-window) which-func-table)
                           which-func-unknown)))
           (propertize string
                       'face '(:height 0.8 :inherit which-func)
                       'mouse-face 'mode-line-highlight
                       'help-echo (format "Current definition: `%s'" string))))))
  "The equivalent of `which-func-format'.")

(with-eval-after-load 'which-func

              mode-line-misc-info))

** The mode

=sp-prot-modeline-mode= saves the default =mode-line-format= and replaces it with the constructs. Turning the mode off puts the saved format back. Its layout is that of Prot's: indicators, buffer name, modes, version control and Flymake on the left; which-function and the misc info on the right.

#+begin_src emacs-lisp -i
(defvar keycast-mode-line-mode)

(defvar sp-prot-modeline--saved-format nil
  "The default `mode-line-format' before `sp-prot-modeline-mode' was enabled.")

(defvar sp-prot-modeline-format
  '("%e"
    sp-prot-modeline-kbd-macro
    sp-prot-modeline-narrow
    sp-prot-modeline-buffer-status
    sp-prot-modeline-window-dedicated-status
    sp-prot-modeline-input-method
    "  "
    sp-prot-modeline-buffer-identification
    "  "
    sp-prot-modeline-major-mode
    " "
    sp-prot-modeline-minor-modes
    sp-prot-modeline-process
    "  "
    sp-prot-modeline-vc-branch
    "  "
    sp-prot-modeline-flymake
    "  "
    mode-line-format-right-align
    sp-prot-modeline-which-function-indicator
    "  "
    sp-prot-modeline-misc-info)
  "The mode line format of `sp-prot-modeline-mode'.
Change it, then run `sp-prot-modeline-mode' twice (off, on).")

;;;###autoload
(define-minor-mode sp-prot-modeline-mode
  "Show the mode line adapted from Prot's: buffer name, modes, branch."
  :global t
  :group 'sp-prot-modeline
  (if sp-prot-modeline-mode
      (progn
        (setq sp-prot-modeline--saved-format (default-value 'mode-line-format))
        (setq mode-line-compact nil)
        (setq mode-line-right-align-edge 'right-margin)
        (setq-default mode-line-format sp-prot-modeline-format)
        (sp-nano-style-install)
        (when (and sp-prot-modeline-keycast (require 'keycast nil t))
          (when (bound-and-true-p keycast-header-line-mode)
            (keycast-header-line-mode -1))
          (keycast-mode-line-mode 1)))
    (when (bound-and-true-p keycast-mode-line-mode)
      (keycast-mode-line-mode -1))
    (setq-default mode-line-format sp-prot-modeline--saved-format)
    (sp-nano-style-uninstall))
  (force-mode-line-update t))
