This module installs and configures =lambda-line=, the minimal status line from the Lambda Emacs project, fetched from Codeberg.

- Loaded in both the default and minimal module lists.
- An alternative module, =sp-choose-modeline=, can pick between =lambda-line= and =doom-modeline=. It is commented out in those lists, so this file is the one that decides the mode line.

The clock icon option relies on the ClockFace font being installed, and the status symbols use non-ASCII glyphs that need a font able to display them.

** lambda-line

The =:custom= block sets the look of the status line:

- a clock icon drawn with the ClockFaceRect font face,
- the line placed at the bottom of each window,
- abbreviated major mode names,
- extra horizontal spacing, a prefix symbol with padding, and no inverted colours for the status indicator,
- custom symbols for read-only, modified and unmodified buffers in graphical frames,
- vertical padding above and below the line and a small vertical offset for the symbols.

In =:config=, =lambda-line-mode= is activated.

- Only when the position is =top= (the status line lives in the header line) are the default and current =mode-line-format= set to a bare =%_= construct, so that the mode line shrinks to a thin divider.
- With the position =bottom=, lambda-line puts its status line /in/ the mode line, so nothing may touch =mode-line-format= after =lambda-line-mode=.
- This condition used to be =bottom=, which overwrote the format lambda-line had just installed: the mode line was empty, with no buffer name, no major or minor mode and no position. See the CHANGELOG and =sp-modeline= for the diagnosis and for a mode line that also shows minor modes.
- lambda-line never shows minor modes: its default format composes the status symbol, the buffer name, the major mode name with the VC branch, and the position and time. Use =sp-modeline= if you want them.

#+begin_src emacs-lisp -i
(use-package lambda-line
    :ensure (:type git :repo "https://codeberg.org/Lambda-Emacs/lambda-line")

    :custom
    (lambda-line-icon-time t) ;; requires ClockFace font (see below)
    (lambda-line-clockface-update-fontset "ClockFaceRect") ;; set clock icon
    (lambda-line-position 'bottom) ;; Set position of status-line 
    (lambda-line-abbrev t) ;; abbreviate major modes
    (lambda-line-hspace "  ")  ;; add some cushion
    (lambda-line-prefix t) ;; use a prefix symbol
    (lambda-line-prefix-padding t) ;; extra space for prefix 
    (lambda-line-status-invert nil)  ;; no invert colors
    (lambda-line-gui-ro-symbol  " ⨂") ;; symbols
    (lambda-line-gui-mod-symbol " ⬤") 
    (lambda-line-gui-rw-symbol  " ◯") 
    (lambda-line-space-top +.70)  ;; padding on top and bottom of line
    (lambda-line-space-bottom -.70)
    (lambda-line-symbol-position 0.1) ;; adjust the vertical placement of symbol

    :config
    (lambda-line-mode)  ;; activate lambda-line 
    ;; With the status line at the top (in the header line), shrink the mode
    ;; line to a thin divider.  At the bottom the status line IS the mode line,
    ;; so it must be left alone.
    (when (eq lambda-line-position 'top)
      (setq-default mode-line-format (list "%_"))
      (setq mode-line-format (list "%_"))))
#+end_src
