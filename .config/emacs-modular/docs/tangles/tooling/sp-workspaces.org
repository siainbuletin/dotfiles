Literate source for =libraries/modules/tooling/sp-workspaces.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

This module builds named workspaces on top of =tab-bar= and =tabspaces=. A workspace is a tab with its own isolated set of buffers. The functions here open a fixed set of dedicated workspaces (Home, the config directory, the Org agenda, notes, a terminal, email) or switch to them if they already exist, and bind them to number keys under the leader map from =sp-keys=.

=tabspaces= itself is declared in =sp-tabs=; this file only calls its internals such as =tabspaces--list-tabspaces= and =tabspaces--name-tab-by-project-or-default=. Other dependencies are =project.el=, =magit=, =org=, =mu4e=, =multi-vterm=, and helpers from other modules such as =sp-denote-notebook= (in =sp-notes=). One helper it calls, =project-magit-dir=, is not defined anywhere in the repository, so the command that relies on it stops with an error at that step.

The module ends with a =projectile= declaration that was moved here from a deprecated =sp-projects= module. It is loaded in both the default and minimal module lists.

* Workspace functions

Each command follows the same pattern: if a tab with the expected name exists, switch to it; otherwise create a new tab, name it, and open the relevant buffers.

** Startup workspace

=sp--workspace-setup= renames the first tab to "Home" and pushes the =*Messages*= and =*splash*= buffers onto the frame's buffer list, so =tabspaces= treats them as belonging to the Home workspace.

#+begin_src emacs-lisp -i
;;;;; Startup Workspaces
(defun sp--workspace-setup ()
  "Set up workspace at startup."
  ;; Add *Messages* and *splash* to Tab \`Home\'
  (progn
    (tab-bar-rename-tab "Home")
    (when (get-buffer "*Messages*")
      (set-frame-parameter nil
                           'buffer-list
                           (cons (get-buffer "*Messages*")
                                 (frame-parameter nil 'buffer-list))))
    (when (get-buffer "*splash*")
      (set-frame-parameter nil
                           'buffer-list
                           (cons (get-buffer "*splash*")
                                 (frame-parameter nil 'buffer-list))))))
#+end_src

** Run setup at startup and go home

The setup runs on =after-init-hook=. =sp-go-home= switches back to the Home tab.

#+begin_src emacs-lisp -i
(add-hook 'after-init-hook #'sp--workspace-setup)
(defun sp-go-home ()
  (interactive)
  (tab-bar-switch-to-tab "Home"))
#+end_src

** Open a project as a workspace

=sp-open-existing-project-and-workspace= opens a new tab, prompts for a project and a file in it, names the tab after the project, and then calls =project-magit-dir= to show Magit for it. Because =project-magit-dir= is not defined in this config, the last step errors after the file has opened.

#+begin_src emacs-lisp -i
;;;;; Open Project in New Workspace
(defun sp-open-existing-project-and-workspace ()
  "Open a project as its own workspace"
  (interactive)
  (progn
    (tab-bar-new-tab)
    (call-interactively 'project-switch-project-open-file)
    (tab-bar-rename-tab (tabspaces--name-tab-by-project-or-default))
    (project-magit-dir)))
#+end_src

** Agenda workspace

=sp-open-agenda-in-workspace= switches to an existing "Agenda" tab, shows =*Org Agenda*=, refreshes it with =org-agenda-redo= and makes it the only window. Otherwise it creates the tab and runs =org-agenda-list=.

#+begin_src emacs-lisp -i
;;;;; Open Agenda as Workspace
(defun sp-open-agenda-in-workspace ()
  "Open agenda in its own workspace"
  (interactive)
  (if (member "Agenda" (tabspaces--list-tabspaces))
      (progn
        (tab-bar-switch-to-tab "Agenda")
        (switch-to-buffer "*Org Agenda*")
        (org-agenda-redo)
        (delete-other-windows))
    (progn
      (tab-bar-new-tab)
      (tab-bar-rename-tab "Agenda")
      (require 'org)
      (org-agenda-list))))
#+end_src

** Config directory workspace

=sp-open-emacsd-in-workspace= opens =sp-library-dir= in Dired in a new tab, with a second window intended for Magit through the undefined =project-magit-dir=. It checks for a tab called "emacs-modular-configuration" and switches to it if it exists. The check used to look for "emacs.d", a name the new tab never had, so it never matched and each call created another tab.

#+begin_src emacs-lisp -i
;;;;; Open emacs.d in Workspace
(defun sp-open-emacsd-in-workspace ()
  "Open emacs.d in its own workspace"
  (interactive)
  (require 'tabspaces)
  (if (member "emacs-modular-configuration" (tabspaces--list-tabspaces))
      (tab-bar-switch-to-tab "emacs-modular-configuration")
    (progn
      (tab-bar-new-tab)
      (tab-bar-rename-tab "emacs-modular-configuration")
      (find-file sp-library-dir)
      (split-window-right)
      (other-window 1)
      (project-magit-dir))))
#+end_src

** Eshell workspace

=sp-open-new-eshell-and-workspace= switches to or creates an "Eshell" tab, starts Eshell in the home directory through =lem-eshell-home= (from =sp-eshell=), and renames the buffer to =eshell-workspace=. It used to call =sp-eshell-home=, which is not defined anywhere, so creating the tab failed at that point. It is not bound to a key here.

#+begin_src emacs-lisp -i

(defun sp-open-new-eshell-and-workspace ()

  (interactive)
  (if (member "Eshell" (tabspaces--list-tabspaces))
      (tab-bar-switch-to-tab "Eshell")
    (progn
      (tab-bar-new-tab)
      (tab-bar-rename-tab "Eshell")
      (lem-eshell-home)
      (rename-buffer "eshell-workspace")
      (delete-other-windows))))

** vterm in the home directory

** Email workspace

=sp-open-email-in-workspace= handles the "Email" tab. If it exists, it shows the mu4e headers buffer, or the main mu4e buffer, or starts =mu4e=. A new Email tab opens =mail.org= from =org-directory= alongside mu4e and then shows the mu4e main view.

#+begin_src emacs-lisp -i
;;;;; Open Mu4e Email in Workspace
(defun sp-open-email-in-workspace ()
  "Open mu4e email in its own workspace"
  (interactive)
  (require 'tabspaces)
  (if (member "Email" (tabspaces--list-tabspaces))
      (progn
        (tab-bar-switch-to-tab "Email")
        (cond ((get-buffer "*mu4e-headers*")
               (switch-to-buffer "*mu4e-headers*"))
              ((get-buffer " *mu4e-main*")
               (progn
                 (switch-to-buffer " *mu4e-main*")
                 (delete-other-windows)))
              (t (mu4e))))
    (progn
      (tab-bar-new-tab)
      (tab-bar-rename-tab "Email")
      (require 'org) ; need this for loading?
      (find-file (concat org-directory "mail.org"))
      (mu4e)
      (switch-to-buffer " *mu4e-main*"))))
#+end_src

** New scratch project workspace

=sp-open-new-buffer-and-workspace= creates a tab called "New project" backed by a throwaway git repository in =/tmp/temp-projects/=. It creates the directory, runs =magit-init= and writes an empty =temp= file if needed, then visits that file. The point, as the comment says, is to get the buffer isolation of a real project for an ad hoc buffer. All such tabs share the same directory.

#+begin_src emacs-lisp -i
;;;;; Open New Buffer & Workspace
;; This function is a bit weird; It creates a new buffer in a new workspace with a
;; dummy git project to give the isolation of buffers typical with a git project
;; I'm sure there is a more elegant way to do this but I don't know how :)
(defun sp-open-new-buffer-and-workspace ()
  "Open an empty buffer in its own workspace"
  (interactive)
  (tab-bar-new-tab)
  (tab-bar-rename-tab "New project")
  (let ((sp-project-temp-dir "/tmp/temp-projects/"))
    (progn
      (when (not (file-exists-p sp-project-temp-dir))
        (make-directory sp-project-temp-dir t))
      (when (not (file-exists-p (concat sp-project-temp-dir ".git/")))
        (magit-init sp-project-temp-dir))
      (when (not (file-exists-p (concat sp-project-temp-dir "temp")))
        (with-temp-buffer (write-file (concat sp-project-temp-dir "temp")))))
    (setq default-directory sp-project-temp-dir)
    (find-file (concat sp-project-temp-dir "temp"))))
#+end_src

* Keybindings

** Workspace keys

Number keys on the leader map (=sp-prefix= followed by a digit) jump to the workspaces: 1 Home, 2 config, 3 agenda, 4 notes, 5 email, 6 terminal. =N= in =project-prefix-map= (so =C-x p N=) opens a new scratch project workspace.

#+begin_src emacs-lisp -i
;;;; Workspace Keybindings

(bind-keys :map lem+leader-map
  ("1" . sp-go-home)
  ("2" . sp-open-emacsd-in-workspace)
  ("3" . sp-open-agenda-in-workspace)
  ("4" . sp-open-notes-in-workspace)
  ("6" . sp-open-new-terminal-and-workspace)
  ("5" . sp-open-email-in-workspace))
(bind-key "N" #'sp-open-new-buffer-and-workspace 'project-prefix-map)
#+end_src

* Projectile

Projectile is kept alongside =project.el= for experimentation, per the comment moved over from the deprecated =sp-projects= module on 2026-10-06.

** projectile

Enables =projectile-mode= globally with caching. Its command map is on =C-c p= and also on =C-c C-p= inside =projectile-mode-map=, and =<f5>=, =S-<f5>= and =<f6>= compile, test and run the project. Two things conflict here. =projectile-project-search-path= is set twice, to the writing and config directories in =:init= and to =~/git= and =~/src= in =:custom=, so which list takes effect depends on use-package's evaluation order rather than on clear intent. And the =<f6>= binding shadows the global =redraw-display= key from =sp-windows= whenever projectile mode is on.

#+begin_src emacs-lisp -i
;; Including projectile as well for the sake of posterity (and trying things out - and moving from sp-projects - deprecated 2026.10.06)
;; OPTIONAL: ag is nice alternative to using grep with Projectile

(use-package projectile
  :ensure t
  :init
  (setq projectile-project-search-path
        '("~/Documents/writing/"
          "~/.config/"))
  
  :config
  (projectile-mode +1)
  
  :bind (("C-c p" . projectile-command-map)
         :map projectile-mode-map
         ("C-c C-p" . projectile-command-map)
         ("<f5>" . projectile-compile-project)
         ("S-<f5>" . projectile-test-project)
         ("<f6>" . projectile-run-project))

  :custom
  (projectile-project-search-path '("~/git" "~/src"))
  (projectile-enable-caching t)
  )
#+end_src
