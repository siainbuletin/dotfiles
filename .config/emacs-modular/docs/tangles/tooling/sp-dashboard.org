Literate source for =libraries/modules/tooling/sp-dashboard.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module replaces the stock Emacs startup screen with a =Dashboard= buffer showing a lambda logo, a welcome line, the Emacs version, package count and init time, a menu of boxed buttons with nested agendas, and a footer. There are two renderers: =sp-dashboard-screen= for graphical frames (PNG logo plus nerd-icons menu buttons) and =sp-dashboard-terminal= for terminal frames (ASCII banner read from =images/lambda-splash.txt=).

It depends on =cl-lib=, optionally on =nerd-icons=, on =sp-get-string-from-file= from =sp-helper-funct=, on =sp-library-dir= for the logo and banner files, and on =sys-mac=. The menu actions call workspace functions from the =sp-workspaces= module when it is loaded. The splash is installed on =window-setup-hook= unless the command line asks for a file or =--no-splash=. In =early-init.el= the module is listed in =sp-gui-only-set=, so it is normally only loaded in GUI sessions.

* Faces

All the faces of the dashboard are defined here, in one block. The first five (title, header, footer, menu and image) have no colours of their own, so a theme can style them and, without theme support, they look like the default face; the others are described by what they colour. The art, banner and accent faces are recoloured from the current theme by the colour palette (see below), and the colours given here are only the fallback until it runs.

- =sp-dashboard-title-face= is the "Welcome to λ-Emacs" line.
- =sp-dashboard-header-face= is the version and init-info lines.
- =sp-dashboard-footer-face= is the footer text, in italics.
- =sp-dashboard-menu-face= is the menu text and the clickable menu buttons.
- =sp-dashboard-box-face= is the lines around a menu block when no accent face is available; it inherits =shadow=, so it follows the theme.
- =sp-dashboard-image-face= is defined but not referenced anywhere in the module.
- =sp-dashboard-art-face= is the lambda art, dim grey on a dark background and pale grey on a light one.
- =sp-dashboard-banner-face= is the EMACS block-letter banner, a little stronger than the art.
- =sp-dashboard-accent-1-face=, =-2-face= and =-3-face= are the box lines of the first, second and third menu blocks. They inherit three font-lock faces.
- =sp-dashboard-focus-face= is the button that =TAB= has selected, since the cursor is hidden. It inherits =highlight=.

** Init info

=sp-dashboard-init-info= holds a function that returns a summary string such as "42 packages loaded in 1.2s". It counts =package-activated-list= for package.el, or the straight.el profile cache, and falls back to just the init time when no packages are counted. The approach is borrowed from emacs-dashboard and Doom. Its =:group= is =sp-dashboard=, the customization group defined above (it used to be =lambda-splash=, which this config never defines).

#+begin_src emacs-lisp -i
;; Init info
;; See https://github.com/emacs-dashboard/emacs-dashboard/blob/master/dashboard-widgets.el
;; https://github.com/hlissner/doom-emacs/blob/eddaae40e84b5eb1f0136aaba23d918f71b6a986/core/core.el#L479
(defcustom sp-dashboard-init-info
  (lambda ()
    (let ((package-count 0) (time (emacs-init-time)))
      (cond ((bound-and-true-p package-alist)
             (setq package-count (length package-activated-list)))
            ((boundp 'straight--profile-cache)
             (setq package-count (+ (hash-table-count straight--profile-cache) package-count))))
      (if (zerop package-count)
          (format "Emacs started in %s" time)
        (format "%d packages loaded in %s" package-count time))))
  "Init info with packages loaded and init time."
  :type '(function string)
  :group 'sp-dashboard)
#+end_src

* Art layers

The graphical splash draws text art behind the menu instead of the PNG logo: the lambda in =libraries/images/lambda-splash.txt= and the EMACS block-letter banner in =libraries/images/dashboard-banner-3.txt= (a local copy of banner 3 of the =dashboard= package, so it can be edited freely). A layer only fills blanks, so the welcome text and the buttons stay on top of it, and a layer that comes first in =sp-dashboard-art-layers= covers the ones after it. Art is in =sp-dashboard-art-face= or =sp-dashboard-banner-face=, whose colour is chosen by the background of the theme, so the same layers serve dark and light themes.

** Layers and steps

=sp-dashboard-art-layers= lists the layers, topmost first. Each is =(NAME :file FILE :x X :y Y :face FACE)=. =FILE= is a text file; a relative name is looked up in =sp-dashboard-art-directory= (=images/= under =sp-library-dir=). The art is centred on the window and then moved by =X= columns and =Y= lines (negative is left and up). The default puts the lambda centred vertically and 50 columns left, and the banner 30 columns right and 8 lines above the centre. Remove a layer from the list to hide it; set the list to nil to get the PNG logo back. The two step options set how far each nudge command moves a layer, and =sp-dashboard-art-layer= remembers which layer the nudge commands move.

#+begin_src emacs-lisp -i
(defcustom sp-dashboard-art-directory "images/"
  "Folder of the splash art files; relative to `sp-library-dir'."
  :type 'directory
  :group 'sp-dashboard)

(defcustom sp-dashboard-art-layers
  (copy-tree
   '((banner :file "dashboard-banner-3.txt" :x 30 :y -8 :face sp-dashboard-banner-face)
     (lambda :file "lambda-splash.txt" :x -50 :y 0 :face sp-dashboard-art-face)))
  "Art drawn behind the splash menu, topmost layer first.
Each element is (NAME :file FILE :x X :y Y :face FACE).  FILE is a text
file (a relative name is looked up in `sp-dashboard-art-directory').  X and
Y move the art right and down from the centre of the window, in columns
and lines (negative: left and up).  Remove an element to hide its layer."
  :type '(alist :key-type symbol :value-type plist)
  :group 'sp-dashboard)
#+end_src

** Finding the art

=sp-dashboard--layer-file= resolves a layer's file in =sp-dashboard-art-directory=; both the lambda and the banner are plain files there, so they can be changed or replaced. The terminal splash reads =lambda-splash.txt= from the same folder. =sp-dashboard--art-lines= reads the file and drops trailing blank lines. =sp-dashboard--layer-box= gives the place a layer takes in the window, which =sp-dashboard-content-layer= (the banner) uses: the title, the version line and the menu are centred on that layer's middle column and start two lines below it, so they stay under the banner when it is moved. =sp-dashboard--content-column= returns that column, or the window's middle when there is no such layer.

#+begin_src emacs-lisp -i
(defun sp-dashboard--layer-file (file)
  "Return the path of the art FILE of a layer, or nil when it is missing.
A relative FILE is looked up in `sp-dashboard-art-directory'."
  (let ((path (expand-file-name file (expand-file-name sp-dashboard-art-directory
                                                       sp-library-dir))))
    (and (file-regular-p path) path)))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-dashboard--art-lines (file)
  "Return the lines of the art FILE of a layer, or nil when unavailable."
  (when-let* ((path (sp-dashboard--layer-file file)))
    (let ((lines (with-temp-buffer
                   (insert-file-contents path)
                   (split-string (buffer-string) "\n"))))
      ;; Drop blank lines at the end so they don't count as height.
      (while (and lines (string-blank-p (car (last lines))))
        (setq lines (butlast lines)))
      lines)))
#+end_src

** Drawing

=sp-dashboard--draw-art= runs at the end of =sp-dashboard-screen= and draws each layer with =sp-dashboard--draw-layer=. For each non-blank art character it puts the character in the layer's face, but only on a plain blank: text, buttons and images are never overwritten, and a line shorter than the art is padded. Rows above the first or below the last window line, and columns left of the window, are cut.

#+begin_src emacs-lisp -i
(defcustom sp-dashboard-content-layer 'banner
  "Name of the art layer the title and the menu sit under.
The text is centred on this layer, below it.  Nil, or a layer that is not
in `sp-dashboard-art-layers', centres the text on the window."
  :type '(choice (const :tag "Centre on the window" nil) symbol)
  :group 'sp-dashboard)

(defcustom sp-dashboard-footer-layer 'lambda
  "Name of the art layer the footer text is centred on, as for the menu."
  :type '(choice (const :tag "Centre on the window" nil) symbol)
  :group 'sp-dashboard)

(defun sp-dashboard--layer-box (name)
  "Return (LEFT TOP WIDTH HEIGHT) of the art layer NAME in the window, or nil."
  (when-let* ((layer (assq name sp-dashboard-art-layers))
              (lines (sp-dashboard--art-lines (plist-get (cdr layer) :file))))
    (let ((width (apply #'max (mapcar #'length lines)))
          (height (length lines)))
      (list (+ (- (/ (window-width) 2) (/ width 2))
               (or (plist-get (cdr layer) :x) 0))
            (+ (- (/ (window-body-height) 2) (/ height 2))
               (or (plist-get (cdr layer) :y) 0))
            width height))))

(defun sp-dashboard--layer-column (name)
  "Return the middle column of the art layer NAME, or of the window."
  (if-let* ((box (sp-dashboard--layer-box name)))
      (+ (nth 0 box) (/ (nth 2 box) 2))
    (/ (window-width) 2)))

(defun sp-dashboard--content-column ()
  "Return the column the title and the menu are centred on."
  (sp-dashboard--layer-column sp-dashboard-content-layer))

(defun sp-dashboard--put-art-char (col ch face)
  "Put CH in FACE at column COL of the current line if it is blank."
  (move-to-column col)
  (cond ((and (eolp) (<= (current-column) col))
         (insert-char ?\s (- col (current-column)))
         (insert (propertize (string ch) 'face face)))
        ((and (= (current-column) col)
              (eq (char-after) ?\s)
              (not (get-text-property (point) 'face))
              (not (get-text-property (point) 'button))
              (not (get-text-property (point) 'display)))
         (delete-char 1)
         (insert (propertize (string ch) 'face face)))))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-dashboard--draw-layer (layer)
  "Draw the art LAYER, centred on the window and moved by its offsets.
Only plain blanks are replaced, so text, buttons and images are kept."
  (when-let* ((lines (sp-dashboard--art-lines (plist-get (cdr layer) :file))))
    (let* ((inhibit-read-only t)
           (indent-tabs-mode nil)
           (face (or (plist-get (cdr layer) :face) 'sp-dashboard-art-face))
           (box (sp-dashboard--layer-box (car layer)))
           (left (nth 0 box))
           (top (nth 1 box))
           (max-line (window-body-height))
           (row 0))
      (dolist (text lines)
        (let ((line (+ top row)))
          (when (and (>= line 1) (<= line max-line))
            ;; Grow the buffer when the art runs past its last line.
            (goto-char (point-max))
            (while (< (line-number-at-pos) line)
              (insert-char ?\n 1))
            (goto-char (point-min))
            (forward-line (1- line))
            (dotimes (i (length text))
              (let ((ch (aref text i))
                    (col (+ left i)))
                (when (and (/= ch ?\s) (>= col 0))
                  (sp-dashboard--put-art-char col ch face)
                  (forward-line 0)))))
          (setq row (1+ row)))))))
#+end_src

** Moving the art

In the splash buffer, =S-<left>=, =S-<right>=, =S-<up>= and =S-<down>= move the current layer and redraw; =l= picks the next layer (=TAB= is for the buttons). The splash rebuilds itself, so the change lasts until Emacs exits. =0= goes back to the defaults and =s= shows (and copies) the =setq= form for the current layers, to paste into the config.

;;;; Move the art
(defun sp-dashboard--current-layer ()
  "Return the layer the nudge commands move."
  (or (assq sp-dashboard-art-layer sp-dashboard-art-layers)
      (car sp-dashboard-art-layers)))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-dashboard-art-next-layer ()
  "Select the next art layer for the nudge commands."
  (interactive)
  (let* ((names (mapcar #'car sp-dashboard-art-layers))
         (rest (cdr (memq (car (sp-dashboard--current-layer)) names))))
    (setq sp-dashboard-art-layer (car (or rest names)))
    (message "Splash art layer: %s" sp-dashboard-art-layer)))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-dashboard-art-nudge (dx dy)
  "Move the current art layer DX columns right and DY lines down, and redraw."
  (let ((layer (sp-dashboard--current-layer)))
    (unless layer (user-error "No splash art layers"))
    (plist-put (cdr layer) :x (+ (or (plist-get (cdr layer) :x) 0) dx))
    (plist-put (cdr layer) :y (+ (or (plist-get (cdr layer) :y) 0) dy))
    (message "Splash art %s: x %d, y %d" (car layer)
             (plist-get (cdr layer) :x) (plist-get (cdr layer) :y)))
  (sp-dashboard-refresh))
#+end_src

* Colour palette

The splash colours follow the theme. Each colour role (the lambda =art=, the =banner=, the =footer= and three =accent=s) takes its colour from a face of the current theme, mixed towards the default background so the art stays quiet, and is applied to the splash face of that role. =sp-dashboard-palette-roles= says which theme face and how much of it each role uses, so the colours change with whatever theme is loaded, light or dark, with no per-theme code. To choose colours for one theme by hand, list them in =sp-dashboard-palettes=; roles not listed there are still derived.

The accents colour the boxes of the menu: block 1 takes =sp-dashboard-accent-1-face=, block 2 the second, and so on (=sp-dashboard-accent-faces=, repeating when there are more blocks). Add roles and faces to the lists to colour more parts of the splash.

When a theme is enabled or disabled, =sp-dashboard--theme-changed= (on =enable-theme-functions= and =disable-theme-functions=) applies the palette and redraws the splash; =sp-dashboard-palette-follow-theme= switches this off. =sp-dashboard-apply-palette= does it by hand and =sp-dashboard-show-palette= shows the colour of each role. The colours in the faces under Faces remain the fallback until the palette is applied.

(defun sp-dashboard--rgb (color)
  "Return COLOR as a list of red, green and blue between 0 and 1, or nil."
  (if (and (stringp color) (string-match "\\`#\\([[:xdigit:]]\\{2\\}\\)\\([[:xdigit:]]\\{2\\}\\)\\([[:xdigit:]]\\{2\\}\\)\\'" color))
      (mapcar (lambda (i) (/ (string-to-number (match-string i color) 16) 255.0))
              '(1 2 3))
    (and (stringp color) (color-name-to-rgb color))))
#+end_src

(defun sp-dashboard--mix (color background amount)
  "Return COLOR moved AMOUNT (0 to 1) of the way from BACKGROUND, as #rrggbb."
  (when-let* ((fg (sp-dashboard--rgb color))
              (bg (sp-dashboard--rgb background)))
    (apply #'format "#%02x%02x%02x"
           (cl-mapcar (lambda (f b) (round (* 255 (+ b (* amount (- f b))))))
                      fg bg))))

* Splash menu

The menu under the banner is a list of blocks, =sp-dashboard-menu=. Each block is drawn in a box of lines (=sp-dashboard-box-face=); a block with children, such as Agenda, shows them nested under its heading. All blocks are as wide as the widest row and are centred on the banner. Remove or reorder blocks in the list to change the menu, and bind the keys in =sp-dashboard-mode-map=. A heading without a command (as for Agenda) is plain text; every other row is a button that calls its command.

#+begin_src emacs-lisp -i

(defcustom sp-dashboard-menu

      ("Thesis" "t" sp-dashboard-open-thesis-agenda "Open the thesis agenda")

      ("Deadlines" "d" sp-dashboard-open-deadlines-agenda "Open the coming deadlines")))

`nerd-icons-faicon' name.  CHILDREN, when non-nil, is a list of

#+begin_src emacs-lisp -i
(defun sp-dashboard--menu-rows (entry)
  "Return the rows of the menu block ENTRY, heading first.
Each row is (TEXT KEY COMMAND HELP)."
  (pcase-let ((`(,icon ,label ,key ,command ,help ,children) entry))
    (let ((count (length children))
          (index 0))
      (cons (list (concat (nerd-icons-faicon icon) isep label) key command help)
            (mapcar (lambda (child)
                      (setq index (1+ index))
                      (cons (concat "  " (if (= index count) "└─ " "├─ ") (car child))
                            (cdr child)))
                    children)))))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-dashboard--insert-menu (content-col)
  "Insert the menu blocks in boxes, centred on column CONTENT-COL."
  (let* ((blocks (mapcar #'sp-dashboard--menu-rows sp-dashboard-menu))
         (text-width (apply #'max (mapcar (lambda (row) (string-width (car row)))
                                          (apply #'append blocks))))
         (body-width (+ text-width (length ksep) 3))
         (inner-width (+ body-width 2))
         (indent (max 0 (- content-col (/ (+ inner-width 2) 2))))
         (faces (copy-sequence sp-dashboard-accent-faces)))
    (when faces
      (setcdr (last faces) faces))
    (dolist (block blocks)
      (insert-char ?\s indent)
      (insert (propertize (concat "┌" (make-string inner-width ?─) "┐\n")
                          'face (or (car faces) 'sp-dashboard-box-face)))
      (dolist (row block)
        (pcase-let* ((`(,text ,key ,command ,help) row)
                     (body (concat text
                                   (make-string (- text-width (string-width text)) ?\s)
                                   ksep
                                   (if key (format "(%s)" key) "   "))))
          (insert-char ?\s indent)
          (insert (propertize "│ " 'face (or (car faces) 'sp-dashboard-box-face)))
          (if command
              (insert-text-button body
                                  'action (lambda (_) (funcall command))
                                  'help-echo help
                                  'face 'sp-dashboard-menu-face
                                  'follow-link t)
            (insert (propertize body 'face 'sp-dashboard-menu-face)))
          (insert (propertize " │\n" 'face (or (car faces) 'sp-dashboard-box-face)))))
      (insert-char ?\s indent)
      (insert (propertize (concat "└" (make-string inner-width ?─) "┘\n")
                          'face (or (car faces) 'sp-dashboard-box-face)))
      (insert "\n")
      (setq faces (cdr faces)))))

** Erase helper

=sp-dashboard--erase= switches to the splash buffer and clears it, but only if the buffer exists. It used to wrap its body in =when-let*=, which only bound =inhibit-read-only= and discarded the =get-buffer= result, so the body always ran and =switch-to-buffer= created the buffer when it was missing. Now =inhibit-read-only= is bound around =erase-buffer= alone. The function is not called anywhere in the module.

#+begin_src emacs-lisp -i
(defun sp-dashboard--erase ()
  ;; check if splash exists and switch if so
  (when (get-buffer "Dashboard")
    (switch-to-buffer "Dashboard")
    (let ((inhibit-read-only t))
      (erase-buffer))))
#+end_src

** Terminal splash

=sp-dashboard-terminal= builds the splash for terminal frames. If =Dashboard= already exists it just switches to it. Otherwise it creates the buffer, hides the mode line and header line, sets margins and fill column from the window size, disables the menu bar (except on graphical macOS), inserts the ASCII banner from =lambda-splash.txt= in =sp-library-dir=, and inserts the welcome, version and init-info lines as a rectangle roughly in the middle of the window. A footer is added at the bottom and =sp-dashboard-mode= is enabled. The local variables =midp=, =padding-top= and =height= are computed but unused, and the =defvar= of =sp-dashboard-footer= inside the body only provides a fallback value.

#+begin_src emacs-lisp -i
(defun sp-dashboard-terminal ()
  "A custom splash screen for terminal Emacs"
  (interactive)
  ;; Switch to or create splash buffer
  (or (when (get-buffer "Dashboard")

        (with-current-buffer splash-buffer
          (setq header-line-format nil)
          (setq mode-line-format nil)
          (erase-buffer))

        (let* ((buffer-read-only t)
               (midp  (/ (point-max) 2))
               (padding-top 3)
               (height (/ (window-height) 2))
	           (width (/ (window-width) 2))

            (if (one-window-p)
                (setq mode-line-format nil))
            (setq-local cursor-type nil)
            (setq vertical-scroll-bar nil)
            (setq horizontal-scroll-bar nil)

            (face-remap-add-relative 'link :underline nil)
            (unless (and (display-graphic-p) sys-mac) (menu-bar-mode 0))

** Graphical splash

=sp-dashboard-screen= is the GUI renderer. Called interactively it first kills an existing =Dashboard= buffer, because otherwise the command only switches to the old buffer and a changed setting would not show. After the same buffer setup as the terminal version it inserts, centered horizontally:
- the lambda logo PNG (white for the =lambda-dark= theme, black otherwise), only when the window is wider than 80 columns and taller than 20 lines and there are no art layers (see the previous section);
- the welcome text, the Emacs version and the init info;
- the menu blocks (see the previous section) in boxes, centred under the banner, each row showing its single-key shortcut;
- a footer pushed toward the bottom of the window, centred on the lambda (=sp-dashboard-footer-layer=) so it sits close to the art;
- the art layers, drawn last and behind the menu.
Each button calls its command, and the Config and Notes commands go through =sp-dashboard--workspace-dispatch=, so a missing workspaces module gives a message rather than an error. The Mail and Projects entries are gone; Projects is to be redone.

#+begin_src emacs-lisp -i
(defun sp-dashboard-screen ()
  "A custom splash screen for Emacs.
Called interactively, it drops an existing Dashboard buffer first so the
splash is drawn again with the current settings."
  (interactive)
  (when (and (called-interactively-p 'any) (get-buffer "Dashboard"))
    (kill-buffer "Dashboard"))
  (when sp-dashboard-palette-follow-theme
    (sp-dashboard-apply-palette))
  ;; Switch to or create splash buffer
  (or (when (get-buffer "Dashboard")
        (switch-to-buffer "Dashboard"))
      ;; Hide modeline before window-body-height is computed
      (let* ((splash-buffer (get-buffer-create "Dashboard")))
        (with-current-buffer splash-buffer
          (setq header-line-format nil)
          (setq mode-line-format nil)
          (erase-buffer))

        (let* ((buffer-read-only t)
               (midp  (/ (point-max) 2))
               (padding-top 3)
               (height (/ (window-height) 2))
	           (width (/ (window-width) 2))
               (image-scaling-factor 2.2)
               ;; scale icons
               (nerd-icons-scale-factor 1.10)
               (nerd-icons-default-adjust -0.02)
               (content-col (sp-dashboard--content-column)))

          (with-current-buffer splash-buffer
            ;; Buffer local settings
            (if (one-window-p)
                (setq mode-line-format nil))
            (setq-local cursor-type nil)
            (setq vertical-scroll-bar nil)
            (setq horizontal-scroll-bar nil)
            (setq fill-column width)
            (face-remap-add-relative 'link :underline nil)
            (unless (and (display-graphic-p) sys-mac) (menu-bar-mode 0))

            ;; Set margin padding locally
            (setq-local left-margin-width 0
                        right-margin-width (/ width 6))
            (set-window-buffer nil (current-buffer))

            ;; Add padding at top
            (insert-char ?\n padding-top)

            ;; Start the title and the menu below the content layer
            (when-let* ((box (sp-dashboard--layer-box sp-dashboard-content-layer)))
              (insert-char ?\n (max 0 (- (+ (nth 1 box) (nth 3 box) 2)
                                         (line-number-at-pos)))))
            
            ;; Simple centered layout
            (let* ((center-col (max 0 (/ (- (window-width) 60) 2))))
              
              ;; Add the lambda image, centered and reasonably sized
              (when (and (> (window-width) 80) (> (window-height) 20)
                         (null sp-dashboard-art-layers))
                (let* ((image-file (if (eq (car custom-enabled-themes) 'lambda-dark)
                                       (concat sp-library-dir "lambda-logo-white.png")
                                     (concat sp-library-dir "lambda-logo-black.png")))
                       (image (create-image image-file 'png nil :width 175 :height 175)))
                  (insert-char ?\s (+ center-col 19))
                  (insert-image image)
                  (insert-char ?\n 2)))
              
              (let ((welcome-text "Welcome to λ-Emacs")
                    (version-text (format "GNU Emacs version %d.%d" emacs-major-version emacs-minor-version))
                    (init-info (funcall sp-dashboard-init-info)))
                
                ;; Welcome text
                (let ((welcome-center (max 0 (- content-col (/ (length welcome-text) 2)))))
                  (insert-char ?\s welcome-center)
                  (insert (propertize welcome-text 'face 'sp-dashboard-title-face))
                  (insert-char ?\n 2))
                
                ;; Version text
                (let ((version-center (max 0 (- content-col (/ (length version-text) 2)))))
                  (insert-char ?\s version-center)
                  (insert (propertize version-text 'face 'sp-dashboard-header-face))
                  (insert-char ?\n 1))
                
                ;; Init info
                (let ((init-center (max 0 (- content-col (/ (length init-info) 2)))))
                  (insert-char ?\s init-center)
                  (insert (propertize init-info 'face 'sp-dashboard-header-face))
                  (insert-char ?\n 2))))

            ;; Insert the menu blocks, in boxes under the banner
            (goto-char (point-max))
            (sp-dashboard--insert-menu content-col)

            ;; Add footer with some space above bottom
            (goto-char (point-max))
            (let* ((current-line (line-number-at-pos))
                   (window-height (window-height))
                   (footer-padding (max 1 (- window-height current-line 15))))
              (insert-char ?\n footer-padding))
            
            ;; Footer text centered
            (defvar sp-dashboard-footer "   " "Footer text.")
            (let ((footer-center (max 0 (- (sp-dashboard--layer-column sp-dashboard-footer-layer)
                                           (/ (length sp-dashboard-footer) 2)))))
              (insert-char ?\s footer-center)
              (insert (propertize sp-dashboard-footer 'face 'sp-dashboard-footer-face)))

            ;; Lambda art behind the menu (a no-op when the art is off)
            (sp-dashboard--draw-art)

            (goto-char (point-min))
            (display-buffer-same-window splash-buffer nil))
          (switch-to-buffer "Dashboard"))
        (sp-dashboard-mode))))

* Splash minor mode

** Keymap

=sp-dashboard-mode-map= gives the splash single-key bindings: =a=, =t=, =i= and =d= for the four agendas, =c= and =n= for config and notes, =q= and =k= to kill the splash, and =<escape>= to bury it. =S-<arrow>= moves the current art layer, =l= picks the next layer, =0= resets the layers and =s= shows them. =TAB= and =S-TAB= are the only movement: they step through the buttons (the agendas, config and notes), wrapping around, and the selected button is highlighted with =sp-dashboard-focus-face= since the cursor is hidden. The keys and mouse events that scroll, move the cursor, search or mark a region are bound to =ignore=, so the splash can't be scrolled or marked; it simply fills the window and is redrawn when the window changes.

#+begin_src emacs-lisp -i
;;;; Define Minor Mode
;; Custom splash screen
(defvar sp-dashboard-mode-map
  (let ((map (make-sparse-keymap)))
    (define-key map (kbd "a") 'sp-dashboard-open-agenda)
    (define-key map (kbd "c") 'sp-dashboard-open-config)
    (define-key map (kbd "n") 'sp-dashboard-open-notes)
    (define-key map (kbd "t") 'sp-dashboard-open-thesis-agenda)
    (define-key map (kbd "i") 'sp-dashboard-open-issues-agenda)
    (define-key map (kbd "d") 'sp-dashboard-open-deadlines-agenda)
    (define-key map (kbd "S-<left>") 'sp-dashboard-art-left)
    (define-key map (kbd "S-<right>") 'sp-dashboard-art-right)
    (define-key map (kbd "S-<up>") 'sp-dashboard-art-up)
    (define-key map (kbd "S-<down>") 'sp-dashboard-art-down)
    (define-key map (kbd "TAB") 'sp-dashboard-next-button)
    (define-key map (kbd "<backtab>") 'sp-dashboard-previous-button)
    (define-key map (kbd "l") 'sp-dashboard-art-next-layer)
    (define-key map (kbd "0") 'sp-dashboard-art-reset)
    (define-key map (kbd "s") 'sp-dashboard-art-show-position)
    (define-key map (kbd "q") 'sp-dashboard-screen-kill)
    (define-key map (kbd "<escape>") 'sp-dashboard-screen-bury)
    (define-key map (kbd "k") 'sp-dashboard-screen-kill)
    ;; The splash is not for scrolling, moving the cursor or marking text:
    ;; only TAB and S-TAB move, between the buttons.
    (dolist (command '(next-line previous-line forward-char backward-char
                       forward-word backward-word left-word right-word
                       beginning-of-line end-of-line move-beginning-of-line
                       move-end-of-line beginning-of-buffer end-of-buffer
                       scroll-up-command scroll-down-command scroll-left
                       scroll-right scroll-other-window recenter
                       recenter-top-bottom reposition-window
                       set-mark-command mark-whole-buffer mark-word
                       mark-paragraph mark-sexp exchange-point-and-mark
                       mouse-set-region mouse-drag-region mouse-save-then-kill
                       mouse-set-point mouse-secondary-save-then-kill
                       mwheel-scroll pixel-scroll-precision
                       isearch-forward isearch-backward))
      (define-key map `[remap ,command] #'ignore))
    (dolist (event '(wheel-up wheel-down wheel-left wheel-right mouse-4 mouse-5
                     mouse-6 mouse-7 double-wheel-up double-wheel-down
                     triple-wheel-up triple-wheel-down down-mouse-1
                     drag-mouse-1 double-mouse-1 triple-mouse-1))
      (define-key map (vector event) #'ignore))
    map)
  "Keymap for sp-dashboard-mode.")

(defvar-local sp-dashboard--focus-overlay nil
  "Overlay marking the selected button of the splash.")

(defun sp-dashboard-next-button ()
  "Select the next button of the splash, wrapping around."
  (interactive)
  (forward-button 1 t nil t))

(defun sp-dashboard-previous-button ()
  "Select the previous button of the splash, wrapping around."
  (interactive)
  (backward-button 1 t nil t))

(defun sp-dashboard--mark-focus ()
  "Highlight the button at point, since the cursor is hidden."
  (when sp-dashboard--focus-overlay
    (delete-overlay sp-dashboard--focus-overlay))
  (when-let* ((button (button-at (point))))
    (setq sp-dashboard--focus-overlay
          (make-overlay (button-start button) (button-end button)))
    (overlay-put sp-dashboard--focus-overlay 'face 'sp-dashboard-focus-face)))

(defun sp-dashboard--no-region ()
  "Drop the region at once: the splash never marks text."
  (deactivate-mark))
#+end_src

** Minor mode

=sp-dashboard-mode= is a buffer-local minor mode that makes the splash look clean: it disables undo, auto-revert, whitespace mode and line numbers, makes the buffer read-only, hides the cursor, mode line and header line, and removes margins and fringes. It also sets the global =inhibit-startup-screen= family of variables and =truncate-lines=. When Evil is active it switches to Emacs state so the single-key bindings are not shadowed. Its =:group= is =sp-dashboard=; it used to be =sia-lambda=, which this config never defines.

#+begin_src emacs-lisp -i
(define-minor-mode sp-dashboard-mode
  "Emacs minor mode for splash screen."
  :global nil
  :keymap sp-dashboard-mode-map
  :group 'sp-dashboard
  
  :require 'sp-dashboard
  (buffer-disable-undo)
  (auto-revert-mode -1)
  (whitespace-mode -1)
  (when (fboundp 'linum-mode)
    (linum-mode -1))
  (when (>= emacs-major-version 26)
    (display-line-numbers-mode -1))
  
  (setq-local buffer-read-only t)
  (setq-local cursor-type nil)
  (setq-local hl-line-mode -1)
  (setq-local mode-line-format nil)
  (setq-local header-line-format nil)
  
  ;; No margin or fringe in splash buffer
  (setq-local left-margin-width nil
              right-margin-width nil)
  (set-window-fringes (selected-window) 0 0 nil)
  (setq inhibit-startup-screen t
        truncate-lines nil
        inhibit-startup-message t
        inhibit-startup-echo-area-message t)

  ;; The splash fills the window and never scrolls or wraps
  (setq-local truncate-lines t
              scroll-margin 0
              scroll-conservatively 0
              auto-window-vscroll nil
              shift-select-mode nil
              mouse-wheel-mode nil)
  (add-hook 'activate-mark-hook #'sp-dashboard--no-region nil t)
  (add-hook 'post-command-hook #'sp-dashboard--mark-focus nil t)
  
  ;; Use Emacs state if Evil is active so single-key bindings work
  (when (bound-and-true-p evil-mode)
    (evil-emacs-state))
  (goto-char (point-min))
  (set-window-start (selected-window) (point-min))
  (forward-button 1 t nil t)
  (sp-dashboard--mark-focus))
#+end_src

* Setup and refresh

** Refresh

=sp-dashboard-refresh= rebuilds the splash when the current buffer is =Dashboard=, by killing it and calling =sp-dashboard-screen= again so it is re-centred for the new window size. It always uses the graphical renderer and swallows errors.

#+begin_src emacs-lisp -i
;;;; Splash Setup & Refresh Functions
(defun sp-dashboard-refresh ()
  "Refresh & recenter splash after window switch."
  (interactive)
  (when (string= (buffer-name) "Dashboard")
    (progn
      (ignore-errors
        (sp-dashboard-screen-kill)
        (sp-dashboard-screen)))))
#+end_src

** Initial display and hooks

=sp-dashboard--setup-splash-hooks= shows the graphical or terminal splash depending on =display-graphic-p=, then adds =sp-dashboard-refresh= to =window-state-change-hook=, =window-configuration-change-hook= and =sp-switch-buffer-hook= so the splash redraws when windows change.

#+begin_src emacs-lisp -i
(defun sp-dashboard--setup-splash-hooks ()
  "Initialize splash and setup hooks."
  (progn
    (if (display-graphic-p)
        (sp-dashboard-screen)
      (sp-dashboard-terminal))
    (add-hook 'window-state-change-hook #'sp-dashboard-refresh)
    (add-hook 'window-configuration-change-hook  #'sp-dashboard-refresh)
    (add-hook 'sp-switch-buffer-hook #'sp-dashboard-refresh)))
#+end_src

** Install on startup

Adds the setup function to =window-setup-hook=, which runs after the frame parameters are applied, unless Emacs was started with =--no-splash=, =--file=, =--insert= or =--find-file=. A plain filename argument is not checked here.

#+begin_src emacs-lisp -i
;; Install hook after frame parameters have been applied and only if
;; no option on the command line
(when (and (not (member "--no-splash" command-line-args))
           (not (member "--file"      command-line-args))
           (not (member "--insert"    command-line-args))
           (not (member "--find-file" command-line-args)))
  (add-hook 'window-setup-hook #'sp-dashboard--setup-splash-hooks))
#+end_src
