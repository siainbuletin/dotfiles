- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module replaces the stock Emacs startup screen with a =Dashboard= buffer.

- The buffer shows:
  - a lambda logo,
  - a welcome line,
  - the Emacs version, package count and init time,
  - a menu of boxed buttons with nested agendas,
  - a footer.
- Two renderers:
  - =sp-dashboard-screen= for graphical frames (PNG logo plus nerd-icons menu buttons),
  - =sp-dashboard-terminal= for terminal frames (ASCII banner read from =images/lambda-splash.txt=).

Dependencies and loading:

- Needs =cl-lib=; optionally =nerd-icons=.
- Needs =sp-get-string-from-file= from =sp-helper-funct=, =sp-library-dir= for the logo and banner files, and =sys-mac=.
- Menu actions call workspace functions from =sp-workspaces= when it is loaded.
- The splash is installed on =window-setup-hook= unless the command line asks for a file or =--no-splash=.
- =early-init.el= lists the module in =sp-gui-only-set=, so it is normally only loaded in GUI sessions.

* Faces

All the faces of the dashboard are defined here, in one block.

- The first five (title, header, footer, menu and image) have no colours of their own. A theme can style them; without theme support they look like the default face.
- The others are described by what they colour.
- The art, banner and accent faces are recoloured from the current theme by the colour palette (see below).
- The colours given here are only the fallback until the palette runs.

- =sp-dashboard-title-face= is the "Welcome to λ-Emacs" line.
- =sp-dashboard-header-face= is the version and init-info lines.
- =sp-dashboard-footer-face= is the footer text, in italics.
- =sp-dashboard-menu-face= is the menu text and the clickable menu buttons.
- =sp-dashboard-box-face= is the lines around a menu block when no accent face is available; it inherits =shadow=, so it follows the theme.
- =sp-dashboard-image-face= is defined but not referenced anywhere in the module.
- =sp-dashboard-art-face= is the lambda art, dim grey on a dark background and pale grey on a light one.
- =sp-dashboard-banner-face= is the EMACS block-letter banner, a little stronger than the art.
- =sp-dashboard-accent-1-face=, =-2-face= and =-3-face= are the box lines of the first, second and third menu blocks. They inherit three font-lock faces.
- =sp-dashboard-focus-face= is the button that =TAB= has selected, since the cursor is hidden. It inherits =highlight= without =:extend=, so it stops at the end of the button.

** Init info

=sp-dashboard-init-info= holds a function that returns a summary string such as "42 packages loaded in 1.2s".

- Counts =package-activated-list= for package.el, or the straight.el profile cache.
- Falls back to just the init time when no packages are counted.
- The approach is borrowed from emacs-dashboard and Doom.
- Its =:group= is =sp-dashboard=, the customization group defined above. It used to be =lambda-splash=, which this config never defines.

#+begin_src emacs-lisp -i
;; Init info
;; See https://github.com/emacs-dashboard/emacs-dashboard/blob/master/dashboard-widgets.el
;; https://github.com/hlissner/doom-emacs/blob/eddaae40e84b5eb1f0136aaba23d918f71b6a986/core/core.el#L479
(defcustom sp-dashboard-init-info
  (lambda ()
    (let ((package-count 0) (time (emacs-init-time)))
      (cond ((bound-and-true-p package-alist)
             (setq package-count (length package-activated-list)))
            ((boundp 'straight--profile-cache)
             (setq package-count (+ (hash-table-count straight--profile-cache) package-count))))
      (if (zerop package-count)
          (format "Emacs started in %s" time)
        (format "%d packages loaded in %s" package-count time))))
  "Init info with packages loaded and init time."
  :type '(function string)
  :group 'spcustom)
#+end_src

* Art layers

The graphical splash draws text art behind the menu instead of the PNG logo.

- The lambda is =libraries/images/lambda-splash.txt=.
- The EMACS block-letter banner is =libraries/images/dashboard-banner-3.txt=, a local copy of banner 3 of the =dashboard= package, so it can be edited freely.
- A layer only fills blanks, so the welcome text and the buttons stay on top of it.
- A layer that comes first in =sp-dashboard-art-layers= covers the ones after it.
- The art uses =sp-dashboard-art-face= or =sp-dashboard-banner-face=. Their colour is chosen by the theme's background, so the same layers serve dark and light themes.

** Layers and steps

=sp-dashboard-art-layers= lists the layers, topmost first.

- Each layer is =(NAME :file FILE :x X :y Y :face FACE)=.
- =FILE= is a text file. A relative name is looked up in =sp-dashboard-art-directory= (=images/= under =sp-library-dir=).
- The layout has two columns. The side layer (=sp-dashboard-side-layer=, the lambda) is centred in the left column and in the height of the window; every other layer is centred in the right column, starting at line =sp-dashboard-content-top=. The title and the boxes share the right column. The two columns are centred in the window together, =sp-dashboard-column-gap= apart.
- The art is then moved by =X= columns and =Y= lines (negative is left and up). Both default to 0.
- The footer is centred in the window, at the bottom.
- When the window is too narrow for both columns the side layer is left out.
- Remove a layer from the list to hide it. Set the list to nil to get the PNG logo back.
- The two step options set how far each nudge command moves a layer.
- =sp-dashboard-art-layer= remembers which layer the nudge commands move.

#+begin_src emacs-lisp -i
(defcustom sp-dashboard-art-directory "images/"
  "Folder of the splash art files; relative to `sp-library-dir'."
  :type 'directory
  :group 'spcustom)

(defcustom sp-dashboard-art-layers

     (lambda :file "lambda-splash.txt" :x 0 :y 0 :face sp-dashboard-art-face)))
  "Art drawn behind the splash menu, topmost layer first.
Each element is (NAME :file FILE :x X :y Y :face FACE).  FILE is a text
file (a relative name is looked up in `sp-dashboard-art-directory').  X and
Y move the art right and down from its place, in columns and lines (negative:
left and up): the side layer, `sp-dashboard-side-layer', is centred in the
left column and in the window's height, any other layer in the right column.
Remove an element to hide its layer."
  :type '(alist :key-type symbol :value-type plist)
  :group 'spcustom)
#+end_src

** Finding the art

Layer helpers:

- =sp-dashboard--layer-file= resolves a layer's file in =sp-dashboard-art-directory=. The lambda and the banner are plain files there, so they can be changed or replaced. The terminal splash reads =lambda-splash.txt= from the same folder.
- =sp-dashboard--art-lines= reads the file and drops trailing blank lines.
- =sp-dashboard--column-geometry= works out the two columns, and =sp-dashboard--layer-box= gives the place a layer takes in the window. =sp-dashboard-content-layer= (the banner) uses it: the title, the version line and the menu are centred on that layer's middle column and start two lines below it, so they stay under the banner when it is moved.
- =sp-dashboard--content-column= returns that column, or the window's middle when there is no such layer.
- The lambda is drawn as an SVG image (=sp-dashboard-side-as-svg=) so it can be scaled without touching the font of the rest of the dashboard. Each art line becomes a =<text>= element per run of characters, stretched with =textLength= to the character grid, and the image is cut into one slice per buffer line so every line keeps its normal height (=:ascent= comes from the font, =:scale 1= overrides =image-scaling-factor=). =sp-dashboard-side-scale= (=auto=, a number, or nil) sets the size: =auto= picks the largest factor, within =sp-dashboard-side-scale-limits=, at which the lambda fills =sp-dashboard-side-fill= of the window height and of the room left of the other column. Without a graphical frame or SVG support the plain text lambda is used.

#+begin_src emacs-lisp -i
(defun sp-dashboard--layer-file (file)
  "Return the path of the art FILE of a layer, or nil when it is missing.
A relative FILE is looked up in `sp-dashboard-art-directory'."
  (let ((path (expand-file-name file (expand-file-name sp-dashboard-art-directory
                                                       sp-library-dir))))
    (and (file-regular-p path) path)))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-dashboard--art-lines (file)
  "Return the lines of the art FILE of a layer, or nil when unavailable."
  (when-let* ((path (sp-dashboard--layer-file file)))
    (let ((lines (with-temp-buffer
                   (insert-file-contents path)
                   (split-string (buffer-string) "\n"))))
      ;; Drop blank lines at the end so they don't count as height, trailing
      ;; blanks and the indent every line shares so they don't count as width.
      (setq lines (mapcar #'string-trim-right lines))
      (while (and lines (string-blank-p (car (last lines))))
        (setq lines (butlast lines)))
      (let ((indent (apply #'min most-positive-fixnum
                           (mapcar (lambda (line) (or (string-match "[^ ]" line)
                                                      most-positive-fixnum))
                                   lines))))
        (if (< 0 indent most-positive-fixnum)
            (mapcar (lambda (line) (if (> (length line) indent) (substring line indent) ""))
                    lines)
          lines)))))
#+end_src

** Drawing

=sp-dashboard--draw-art= runs at the end of =sp-dashboard-screen= and draws each layer with =sp-dashboard--draw-layer=.

- For each non-blank art character, it puts the character in the layer's face.
- It does so only on a plain blank: text, buttons and images are never overwritten.
- A line shorter than the art is padded.
- Rows above the first or below the last window line, and columns left of the window, are cut.

  :type '(choice (const :tag "Centre on the window" nil) symbol)
  :group 'spcustom)

  "Name of the art layer that gets a column of its own, to the left.
The other layers, the title and the boxes share the column to its right."
  :type 'symbol
  :group 'spcustom)

(defcustom sp-dashboard-column-gap 8
  "Columns between the side column and the content column."
  :type 'integer
  :group 'spcustom)

(defcustom sp-dashboard-content-top 3
  "Line the top of the content column's art is on, before the layer's Y."
  :type 'integer
  :group 'spcustom)

(defvar sp-dashboard-lane-width)

;;;; Window size
(defun sp-dashboard--columns ()
  "Return the columns of the window."
  (max 1 (window-width)))

(defun sp-dashboard--lines ()
  "Return the lines of the window."
  (max 1 (window-body-height)))

;;;; The side layer as an image
;; Text is drawn at the font's own size.  The lambda is drawn as an SVG image
;; instead, which scales to the window without touching the text: the image
;; fills a block of columns by lines and is cut into one slice per line, each
;; slice taking the place of the blanks of its line, so the lines keep their
;; height and the other column stays on the character grid.
(defcustom sp-dashboard-side-as-svg t
  "Non-nil draws the side layer as a scalable SVG image where Emacs can show one.
Otherwise, and in a terminal, it is drawn as text at the font's size."
  :type 'boolean
  :group 'spcustom)

(defcustom sp-dashboard-side-scale 'auto
  "How much larger than its text the SVG side layer is drawn.
`auto' makes it as large as `sp-dashboard-side-fill' of the window allows,
within `sp-dashboard-side-scale-limits'; a number sets it.  1 is the size the
text art would have."
  :type '(choice (const :tag "Fill the window" auto) number)
  :group 'spcustom)

(defcustom sp-dashboard-side-scale-limits '(0.4 . 4.0)
  "Smallest and largest factor `sp-dashboard-side-scale' may pick on its own."
  :type '(cons number number)
  :group 'spcustom)

(defcustom sp-dashboard-side-fill 0.9
  "Fraction of the window's height, and of the width the right column leaves,
that the SVG side layer may fill."
  :type 'number
  :group 'spcustom)

(defun sp-dashboard--side-svg-p ()
  "Return non-nil when the side layer is drawn as an SVG image."
  (and sp-dashboard-side-as-svg
       (display-graphic-p)
       (image-type-available-p 'svg)))

(defun sp-dashboard--side-scale (size)
  "Return the factor to scale the side layer of text SIZE, (WIDTH . HEIGHT), by."
  (if (numberp sp-dashboard-side-scale)
      (float sp-dashboard-side-scale)
    (let* ((room (max 1 (- (sp-dashboard--columns) sp-dashboard-column-gap
                           (sp-dashboard--right-width))))
           (fit (min (/ (* sp-dashboard-side-fill (sp-dashboard--lines))
                        (float (cdr size)))
                     (/ (* sp-dashboard-side-fill room) (float (car size))))))
      (max (car sp-dashboard-side-scale-limits)
           (min (cdr sp-dashboard-side-scale-limits) fit)))))

;;;; Columns
(defun sp-dashboard--art-size (name)
  "Return (WIDTH . HEIGHT), in characters, of the text art of the layer NAME, or nil."
  (when-let* ((layer (assq name sp-dashboard-art-layers))
              (lines (sp-dashboard--art-lines (plist-get (cdr layer) :file))))
    (cons (apply #'max (mapcar #'length lines)) (length lines))))

(defun sp-dashboard--layer-size (name)
  "Return (WIDTH . HEIGHT), in columns and lines, of the art layer NAME, or nil.
The side layer drawn as an SVG image takes its scaled size."
  (when-let* ((size (sp-dashboard--art-size name)))
    (if (and (eq name sp-dashboard-side-layer) (sp-dashboard--side-svg-p))
        (let ((scale (sp-dashboard--side-scale size)))
          (cons (max 1 (round (* scale (car size))))
                (max 1 (round (* scale (cdr size))))))
      size)))

(defun sp-dashboard--right-width ()
  "Return the width of the right column.
That is the widest layer other than the side layer, or `sp-dashboard-lane-width'."
  (let ((width (max (or (and (boundp 'sp-dashboard-lane-width)
                             sp-dashboard-lane-width)
                        0)
                    (apply #'max 0
                           (mapcar (lambda (layer)
                                     (if (eq (car layer) sp-dashboard-side-layer)
                                         0
                                       (or (car (sp-dashboard--art-size (car layer))) 0)))
                                   sp-dashboard-art-layers)))))
    (if (zerop width) 60 width)))

(defun sp-dashboard--column-geometry ()
  "Return (LEFT-START LEFT-WIDTH RIGHT-START RIGHT-WIDTH) of the two columns.
The side layer is the left column; the right column holds the other layers,
the title and the boxes, and is as wide as the widest of them or of
`sp-dashboard-lane-width'.  The two are centred in the window together."
  (let* ((right-width (sp-dashboard--right-width))
         (columns (sp-dashboard--columns))
         (side-width (or (car (sp-dashboard--layer-size sp-dashboard-side-layer)) 0))
         ;; The side column is dropped when the window is too narrow for both.
         (left-width (if (<= (+ side-width 2 right-width) columns) side-width 0))
         (gap (if (> left-width 0)
                  (min sp-dashboard-column-gap (- columns left-width right-width))
                0))
         (left-start (max 0 (/ (- columns (+ left-width gap right-width)) 2))))
    (list left-start left-width (+ left-start left-width gap) right-width)))

(defun sp-dashboard--layer-box (name)
  "Return (LEFT TOP WIDTH HEIGHT) of the art layer NAME in the window, or nil.
The side layer is centred in the left column and vertically in the window, and
has no box when the window is too narrow for the left column; any other layer
is centred in the right column, from `sp-dashboard-content-top'."
  (when-let* ((layer (assq name sp-dashboard-art-layers))
              (size (sp-dashboard--layer-size name)))
    (pcase-let* ((`(,left-start ,left-width ,right-start ,right-width)
                  (sp-dashboard--column-geometry))
                 (width (car size))
                 (height (cdr size))
                 (side (eq name sp-dashboard-side-layer))
                 (x (or (plist-get (cdr layer) :x) 0))
                 (y (or (plist-get (cdr layer) :y) 0)))
      (unless (and side (zerop left-width))
        (list (+ x (if side
                       (+ left-start (/ (- left-width width) 2))
                     (+ right-start (/ (- right-width width) 2))))
              (+ y (if side
                       (- (/ (sp-dashboard--lines) 2) (/ height 2))
                     sp-dashboard-content-top))
              width height)))))

(defun sp-dashboard--layer-column (name)
  "Return the middle column of the art layer NAME, or of the window."
  (if-let* ((box (sp-dashboard--layer-box name)))
      (+ (nth 0 box) (/ (nth 2 box) 2))
    (/ (sp-dashboard--columns) 2)))

(defun sp-dashboard--content-column ()
  "Return the column the title and the menu are centred on."
  (sp-dashboard--layer-column sp-dashboard-content-layer))

(defun sp-dashboard--put-art-char (col ch face)
  "Put CH in FACE at column COL of the current line if it is blank."
  (move-to-column col)
  (cond ((and (eolp) (<= (current-column) col))
         (insert-char ?\s (- col (current-column)))
         (insert (propertize (string ch) 'face face)))
        ((and (= (current-column) col)
              (eq (char-after) ?\s)
              (not (get-text-property (point) 'face))
              (not (get-text-property (point) 'button))
              (not (get-text-property (point) 'display)))
         (delete-char 1)
         (insert (propertize (string ch) 'face face)))))

#+begin_src emacs-lisp -i
(defun sp-dashboard--face-color (face)
  "Return the foreground of FACE as a hex colour string."
  (let ((color (or (face-foreground face nil t)
                   (face-foreground 'default nil t)
                   "#808080")))
    (if (string-prefix-p "#" color)
        color
      (if-let* ((values (color-values color)))
          (apply #'format "#%02x%02x%02x" (mapcar (lambda (value) (/ value 256)) values))
        "#808080"))))

(defun sp-dashboard--art-svg (lines face)
  "Return SVG data that draws the text art LINES in FACE.
One character cell is one unit of width and `frame-char-height' over
`frame-char-width' units of height, and every run of characters is stretched to
the cells it takes, so the picture has the shape of the text art in any font."
  (let* ((width (apply #'max (mapcar #'length lines)))
         (ratio (/ (float (frame-char-height)) (frame-char-width)))
         (font-size 1.6)
         (family (xml-escape-string
                  (format "%s, monospace" (face-attribute 'default :family nil t))))
         (row 0)
         rows)
    (dolist (text lines)
      (let ((start 0))
        ;; One text element for each run of characters between blanks.
        (while (string-match "[^ ]+" text start)
          (let ((run (match-string 0 text))
                (index (match-beginning 0))
                (end (match-end 0)))
            (push (format (concat "<text x=\"%d\" y=\"%.3f\" textLength=\"%d\" "
                                  "lengthAdjust=\"spacing\">%s</text>")
                          index
                          (+ (* (+ row 0.5) ratio) (* 0.3 font-size))
                          (length run)
                          (xml-escape-string run))
                  rows)
            (setq start end))))
      (setq row (1+ row)))
    (format (concat "<svg xmlns=\"http://www.w3.org/2000/svg\" "
                    "width=\"%.1f\" height=\"%.3f\" "
                    "viewBox=\"-0.3 0 %.1f %.3f\" preserveAspectRatio=\"none\">"
                    "<g font-family=\"%s\" font-size=\"%.3f\" "
                    "fill=\"%s\">%s</g></svg>")
            (+ width 0.6) (* (length lines) ratio) (+ width 0.6) (* (length lines) ratio)
            family font-size
            (sp-dashboard--face-color face)
            (apply #'concat (nreverse rows)))))

(defun sp-dashboard--put-svg-slice (left columns display)
  "Put DISPLAY on a blank in place of the COLUMNS blanks from column LEFT.
Works on the current line, and does nothing if those columns hold anything
but plain blanks."
  (end-of-line)
  (when (< (current-column) (+ left columns))
    (insert-char ?\s (- (+ left columns) (current-column))))
  (beginning-of-line)
  (move-to-column left)
  (let ((start (point)))
    (move-to-column (+ left columns))
    (when (and (= (current-column) (+ left columns))
               (string-match-p "\\` *\\'" (buffer-substring-no-properties start (point)))
               (not (text-property-not-all start (point) 'face nil))
               (not (text-property-not-all start (point) 'display nil))
               (not (text-property-not-all start (point) 'button nil)))
      (delete-region start (point))
      (insert (propertize " " 'display display)))))

(defun sp-dashboard--ascent-percent ()
  "Return how much of a text line, in percent, lies above the baseline."
  (or (ignore-errors
        (let* ((info (font-info (face-font 'default nil ?a)))
               (ascent (aref info 8))
               (descent (aref info 9)))
          (round (* 100.0 (/ (float ascent) (+ ascent descent))))))
      80))

(defun sp-dashboard--draw-side-svg (layer box)
  "Draw the art LAYER as an SVG image in BOX, one slice on each line it covers."
  (when-let* ((lines (sp-dashboard--art-lines (plist-get (cdr layer) :file))))
    (pcase-let* ((`(,left ,top ,columns ,rows) box)
                 (char-height (frame-char-height))
                 (pixel-width (* columns (frame-char-width)))
                 (face (or (plist-get (cdr layer) :face) 'sp-dashboard-art-face))
                 (image (create-image (sp-dashboard--art-svg lines face) 'svg t
                                      :width pixel-width
                                      :height (* rows char-height)
                                      :scale 1
                                      :ascent (sp-dashboard--ascent-percent)))
                 (inhibit-read-only t)
                 (max-line (sp-dashboard--lines)))
      (dotimes (row rows)
        (let ((line (+ top row)))
          (when (and (>= line 1) (<= line max-line) (>= left 0))
            (goto-char (point-max))
            (while (< (line-number-at-pos) line)
              (insert-char ?\n 1))
            (goto-char (point-min))
            (forward-line (1- line))
            (sp-dashboard--put-svg-slice
             left columns
             (list (list 'slice 0 (* row char-height) pixel-width char-height)
                   image))))))))

(defun sp-dashboard--draw-text-layer (layer)
  "Draw the text art LAYER in its box, a character for each column.
Only plain blanks are replaced, so text, buttons and images are kept."
  (when-let* ((lines (sp-dashboard--art-lines (plist-get (cdr layer) :file)))
              (box (sp-dashboard--layer-box (car layer))))
    (let* ((inhibit-read-only t)
           (indent-tabs-mode nil)
           (face (or (plist-get (cdr layer) :face) 'sp-dashboard-art-face))
           (left (nth 0 box))
           (top (nth 1 box))
           (max-line (sp-dashboard--lines))
           (row 0))
      (dolist (text lines)
        (let ((line (+ top row)))
          (when (and (>= line 1) (<= line max-line))
            ;; Grow the buffer when the art runs past its last line.
            (goto-char (point-max))
            (while (< (line-number-at-pos) line)
              (insert-char ?\n 1))
            (goto-char (point-min))
            (forward-line (1- line))
            (dotimes (i (length text))
              (let ((ch (aref text i))
                    (col (+ left i)))
                (when (and (/= ch ?\s) (>= col 0))
                  (sp-dashboard--put-art-char col ch face)
                  (forward-line 0)))))
          (setq row (1+ row)))))))
#+end_src

* Colour palette

The splash colours follow the theme.

- Each colour role takes its colour from a face of the current theme, mixed towards the default background so the art stays quiet. The roles are the lambda =art=, the =banner=, the =footer= and three =accent=s.
- The colour is applied to the splash face of that role.
- =sp-dashboard-palette-roles= says which theme face, and how much of it, each role uses.
- So the colours change with whatever theme is loaded, light or dark, with no per-theme code.
- To choose colours for one theme by hand, list them in =sp-dashboard-palettes=. Roles not listed there are still derived.

The accents colour the boxes of the menu: block 1 takes =sp-dashboard-accent-1-face=, block 2 the second, and so on (=sp-dashboard-accent-faces=, repeating when there are more blocks). Add roles and faces to the lists to colour more parts of the splash.

Palette updates:

- When a theme is enabled or disabled, =sp-dashboard--theme-changed= applies the palette and redraws the splash. It runs on =enable-theme-functions= and =disable-theme-functions=.
- =sp-dashboard-palette-follow-theme= switches this off.
- =sp-dashboard-apply-palette= applies the palette by hand.
- =sp-dashboard-show-palette= shows the colour of each role.
- The colours in the faces under Faces remain the fallback until the palette is applied.

* Agenda boxes

Each agenda is its own box (=sp-dashboard-agendas=).

Layout:

- The agenda boxes and the menu blocks are laid out together in one lane.
- The lane is as wide as the banner (=sp-dashboard-lane-width= overrides that) and centred on it, so the outer edges of the boxes line up with the banner and the title above them.
- The lane is split into =sp-dashboard-agenda-columns= equal columns (fewer when the lane is narrow), so the boxes grow sideways as well as down.

Contents of a box:

- Its title button, with the key.
- The =sp-dashboard-agenda-todo-count= most urgent open TODOs of its files, each wrapped onto at most =sp-dashboard-agenda-todo-lines= lines and cut with an ellipsis.
- Urgency is the priority, plus a bonus for a near or overdue deadline, for scheduled today or earlier, and for the keywords in =sp-dashboard-urgent-states=.
- The Deadlines box lists the nearest deadlines within =sp-dashboard-deadlines-days= instead.

Files and clicking:

- The files are the =sp-dashboard-agenda-*-files= variables, or =org-agenda-files= when nil.
- =sp-dashboard-agenda-todos-clickable= (on by default) makes the first line of each TODO a button that visits the entry with =RET= or a click. Each is then a =TAB= stop.
- Setting it to nil leaves only the titles.

** Privacy

Privacy: while the dashboard is public, private entries are not drawn at all.

- They are never put in the buffer, so there is nothing to scroll or copy.
- An entry is private when it has a tag in =sp-dashboard-private-tags= (=private=, inherited) or is in a file matching =sp-dashboard-private-files=.
- =sp-dashboard-public-mode= is =auto=, =public= or =private=. =P= cycles it and redraws.

In =auto= mode:

- The dashboard is public as soon as one function in =sp-dashboard-public-conditions= returns non-nil.
- A function that signals an error counts as public, so a check that breaks fails closed.
- The list holds =sp-dashboard-condition-focus= by default.

=sp-dashboard-condition-focus= is true when:

- the file =sp-dashboard-focus-flag-file= exists, or
- macOS reports a Focus as on in =~/Library/DoNotDisturb/DB/Assertions.json=. Reading it can need Full Disk Access for Emacs; without it only the flag file works.

Focus options:

- =sp-dashboard-focus-modes= limits it to Focus modes whose identifier contains one of its strings (for example =work=). nil means any.
- To follow a Focus reliably, make a Shortcuts automation that runs =touch= on the flag file when the Focus turns on and =rm= when it turns off.

Two more conditions are provided and do nothing until configured:

- =sp-dashboard-condition-untrusted-network= (Wi-Fi name not in =sp-dashboard-trusted-networks=).
- =sp-dashboard-condition-screen-share= (a process in =sp-dashboard-screen-share-processes= is running).

=M-x sp-dashboard-public-facing-mode= is a global minor mode that says you are in public: it forces the public mode whatever =sp-dashboard-public-mode= or the conditions say.

The dashboard remembers whether it was drawn as public.

- While the Dashboard buffer exists, a timer and file watches on the two Focus files compare that with the current status.
- The timer is =sp-dashboard-public-check-interval= (30 seconds, nil for none).
- The mode also checks when toggled.
- If the status changed, a visible Dashboard is redrawn in its window.
- A hidden one is killed, so it never reappears showing entries it should no longer show.

  (or (file-exists-p (expand-file-name sp-dashboard-focus-flag-file))

             (or (null sp-dashboard-focus-modes)

                             (seq-some (lambda (mode)

;;;;; Redrawing when the status changes
;; The dashboard remembers whether it was drawn as public.  A timer and file
;; watches on the Focus files compare that with the current status while the
;; Dashboard buffer exists.  A hidden Dashboard is killed instead of redrawn, so
;; it never comes back showing entries it should no longer show.
(defcustom sp-dashboard-public-check-interval 30
  "Seconds between checks of the public status while the Dashboard exists.
nil turns the timer off; the Focus files are still watched."
  :type '(choice (const :tag "No timer" nil) integer)
  :group 'spcustom)

(defvar sp-dashboard--drawn-public nil
  "Whether the Dashboard was last drawn as public.")

  "Timer that checks the public status.")

(defun sp-dashboard--stop-public-watch ()
  "Stop the timer and the file watches of the public status."
  (when sp-dashboard--public-timer
    (cancel-timer sp-dashboard--public-timer)
    (setq sp-dashboard--public-timer nil))
  (dolist (watch sp-dashboard--public-watches)
    (ignore-errors (file-notify-rm-watch watch)))
  (setq sp-dashboard--public-watches nil))

(defun sp-dashboard--check-public ()
  "Redraw the Dashboard when its public status changed since it was drawn."
  (if (not (get-buffer "Dashboard"))
      (sp-dashboard--stop-public-watch)
    (unless (eq (and (sp-dashboard-public-p) t) sp-dashboard--drawn-public)
      (if-let* ((window (get-buffer-window "Dashboard" t)))
          (with-selected-window window
            (sp-dashboard-refresh))
        (kill-buffer "Dashboard")))))

(defun sp-dashboard--watch-file (file)
  "Run `sp-dashboard--check-public' when FILE changes, if its folder exists."
  (let* ((file (expand-file-name file))
         (name (file-name-nondirectory file)))
    (when (file-directory-p (file-name-directory file))
      (ignore-errors
        (push (file-notify-add-watch
               (file-name-directory file) '(change)
               (lambda (event)
                 (when (string= (file-name-nondirectory (nth 2 event)) name)
                   (sp-dashboard--check-public))))
              sp-dashboard--public-watches)))))

(defun sp-dashboard--start-public-watch ()
  "Start checking the public status, if that is not already going on."
  (when (and sp-dashboard-public-check-interval (not sp-dashboard--public-timer))
    (setq sp-dashboard--public-timer
          (run-with-timer sp-dashboard-public-check-interval
                          sp-dashboard-public-check-interval
                          #'sp-dashboard--check-public)))
  (unless sp-dashboard--public-watches
    (require 'filenotify)
    (sp-dashboard--watch-file sp-dashboard-focus-flag-file)
    (sp-dashboard--watch-file sp-dashboard--focus-assertions-file)))

        ('private nil)
        (_ (condition-case nil

             (error t))))))

(defun sp-dashboard--days-until (timestamp)
  "Return the days from today to the Org TIMESTAMP string, or nil."
  (when timestamp
    (- (org-time-string-to-absolute timestamp) (org-today))))

(defun sp-dashboard--entry ()
  "Return a plist describing the open TODO at point, or nil."
  (when (org-entry-is-todo-p)
    (let ((heading (org-get-heading t t t t)))
      (list :heading heading
            :state (org-get-todo-state)
            :priority (org-get-priority
                       (buffer-substring (line-beginning-position)
                                         (line-end-position)))
            :deadline (sp-dashboard--days-until (org-entry-get nil "DEADLINE"))
            :scheduled (sp-dashboard--days-until (org-entry-get nil "SCHEDULED"))
            :tags (org-get-tags)
            :file buffer-file-name
            :pos (point)))))

(defun sp-dashboard--score (entry)
  "Return how urgent ENTRY is; higher is more urgent."
  (let ((deadline (plist-get entry :deadline))
        (scheduled (plist-get entry :scheduled)))
    (+ (plist-get entry :priority)
       (if deadline (max 0 (- 3000 (* 100 deadline))) 0)
       (if (and scheduled (<= scheduled 0)) 1000 0)
       (if (member (plist-get entry :state) sp-dashboard-urgent-states) 500 0))))

(defun sp-dashboard--todos (files mode)
  "Return the entries of FILES to list for MODE, most urgent first.
Private entries are left out while `sp-dashboard-public-p'."
  (require 'org)
  (let ((public (sp-dashboard-public-p))
        entries)
    (dolist (file files)
      (when (file-readable-p file)
        (condition-case nil
            (dolist (entry (org-map-entries #'sp-dashboard--entry nil (list file) 'archive))
              (unless (or (null entry)
                          (and public (sp-dashboard--private-p file (plist-get entry :tags))))
                (push entry entries)))
          (error nil))))
    (when (eq mode 'deadline)
      (setq entries (seq-filter (lambda (entry)
                                  (let ((days (plist-get entry :deadline)))
                                    (and days (<= days sp-dashboard-deadlines-days))))
                                entries)))
    (seq-take (if (eq mode 'deadline)
                  (sort entries (lambda (a b) (< (plist-get a :deadline)
                                                 (plist-get b :deadline))))
                (sort entries (lambda (a b) (> (sp-dashboard--score a)
                                               (sp-dashboard--score b)))))
              sp-dashboard-agenda-todo-count)))

(defun sp-dashboard--wrap (text width max-lines)
  "Wrap TEXT to WIDTH columns, at most MAX-LINES lines, the last one cut with an ellipsis."
  (let ((line "")
        lines)
    (dolist (word (split-string text))
      (while (> (string-width word) width)
        (let ((cut (truncate-string-to-width word width)))
          (unless (string= line "")
            (push line lines)
            (setq line ""))
          (push cut lines)
          (setq word (substring word (length cut)))))
      (cond ((string= line "") (setq line word))
            ((<= (+ (string-width line) 1 (string-width word)) width)
             (setq line (concat line " " word)))
            (t (push line lines)
               (setq line word))))
    (unless (string= line "")
      (push line lines))
    (setq lines (nreverse lines))
    (if (<= (length lines) max-lines)
        lines
      (let ((kept (seq-take lines max-lines)))
        (setcar (last kept)
                (concat (truncate-string-to-width (car (last kept)) (1- width)) "…"))
        kept))))

(defun sp-dashboard--box-line (width box-face &rest segments)

(defun sp-dashboard--title-segment (text key command help width)
  "Return the segment of a title or menu row, TEXT with KEY at the right of WIDTH.
It is a button calling COMMAND, with HELP, when COMMAND is non-nil."
  (let* ((keytext (if key (format "(%s)" key) ""))
         (body (concat text
                       (make-string (max 1 (- width (string-width text)
                                              (string-width keytext)))
                                    ?\s)
                       keytext)))
    (if command
        (list body 'sp-dashboard-menu-face (lambda (_) (funcall command)) help)
      (list body 'sp-dashboard-menu-face))))

(defun sp-dashboard--menu-box (entry width box-face)
  "Return the menu block ENTRY as a box of text WIDTH, drawn with BOX-FACE."
  (pcase-let* ((`(,icon ,label ,key ,command ,help ,children) entry)
               (rule (make-string (+ width 2) ?─))
               (count (length children))
               (index 0)
               (lines (list (list (list (concat "┌" rule "┐") box-face))
                            (sp-dashboard--box-line
                             width box-face
                             (sp-dashboard--title-segment
                              (concat (nerd-icons-faicon icon) isep label)
                              key command help width)))))
    (dolist (child children)
      (setq index (1+ index))
      (pcase-let ((`(,child-label ,child-key ,child-command ,child-help) child))

                             (sp-dashboard--title-segment
                              (concat "  " (if (= index count) "└─ " "├─ ") child-label)
                              child-key child-command child-help width)))))))
    (append lines (list (list (list (concat "└" rule "┘") box-face))))))

(defun sp-dashboard--agenda-box (agenda width box-face)

** Erase helper

=sp-dashboard--erase= switches to the splash buffer and clears it, but only if the buffer exists.

- It used to wrap its body in =when-let*=, which only bound =inhibit-read-only= and discarded the =get-buffer= result. The body always ran, and =switch-to-buffer= created the buffer when it was missing.
- Now =inhibit-read-only= is bound around =erase-buffer= alone.
- The function is not called anywhere in the module.

#+begin_src emacs-lisp -i
(defun sp-dashboard--erase ()
  ;; check if splash exists and switch if so
  (when (get-buffer "Dashboard")
    (switch-to-buffer "Dashboard")
    (let ((inhibit-read-only t))
      (erase-buffer))))

** Terminal splash

=sp-dashboard-terminal= builds the splash for terminal frames.

- If =Dashboard= already exists, it just switches to it.
- Otherwise it:
  - creates the buffer and hides the mode line and header line,
  - sets margins and fill column from the window size,
  - disables the menu bar (except on graphical macOS),
  - inserts the ASCII banner from =lambda-splash.txt= in =sp-library-dir=,
  - inserts the welcome, version and init-info lines as a rectangle roughly in the middle of the window,
  - adds a footer at the bottom and enables =sp-dashboard-mode=.
- Loose ends: the local variables =midp=, =padding-top= and =height= are computed but unused. The =defvar= of =sp-dashboard-footer= inside the body only provides a fallback value.

  "A custom splash screen for terminal Emacs"

  ;; Switch to or create splash buffer

** Graphical splash

=sp-dashboard-screen= is the GUI renderer.

- Called interactively, it first kills an existing =Dashboard= buffer. Otherwise the command only switches to the old buffer and a changed setting would not show.
- After the same buffer setup as the terminal version, it inserts, centered horizontally:
  - the lambda logo PNG (white when =sp-theme-dark-p= is true, black otherwise), only when the window is wider than 80 columns and taller than 20 lines and there are no art layers (see the previous section),
  - the welcome text, the Emacs version and the init info,
  - the menu blocks (see the previous section) in boxes, centred under the banner, each row showing its single-key shortcut,
  - a footer pushed to the bottom of the window and centred on it (=sp-dashboard-footer-layer= centres it on a layer instead),
  - the art layers, drawn last and behind the menu.
- Each button calls its command.
- The Config and Notes commands go through =sp-dashboard--workspace-dispatch=, so a missing workspaces module gives a message rather than an error.
- The Mail and Projects entries are gone. Projects is to be redone.

                                       (concat sp-library-dir "lambda-logo-white.png")
                                     (concat sp-library-dir "lambda-logo-black.png")))
                       (image (create-image image-file 'png nil :width 175 :height 175)))
                  (insert-char ?\s (+ center-col 19))
                  (insert-image image)
                  (insert-char ?\n 2)))
              
              (let ((welcome-text "Welcome to λ-Emacs")
                    (version-text (format "GNU Emacs version %d.%d" emacs-major-version emacs-minor-version))
                    (init-info (funcall sp-dashboard-init-info)))
                
                ;; Welcome text
                (let ((welcome-center (max 0 (- content-col (/ (length welcome-text) 2)))))
                  (insert-char ?\s welcome-center)
                  (insert (propertize welcome-text 'face 'sp-dashboard-title-face))
                  (insert-char ?\n 2))
                
                ;; Version text
                (let ((version-center (max 0 (- content-col (/ (length version-text) 2)))))
                  (insert-char ?\s version-center)
                  (insert (propertize version-text 'face 'sp-dashboard-header-face))
                  (insert-char ?\n 1))
                
                ;; Init info
                (let ((init-center (max 0 (- content-col (/ (length init-info) 2)))))
                  (insert-char ?\s init-center)
                  (insert (propertize init-info 'face 'sp-dashboard-header-face))
                  (insert-char ?\n 2))))

            ;; Insert the menu blocks, in boxes under the banner
            (goto-char (point-max))
            (sp-dashboard--insert-boxes content-col)
            (sp-dashboard--start-public-watch)

            ;; Add footer with some space above bottom
            (goto-char (point-max))
            (let* ((current-line (line-number-at-pos))
                   (footer-padding (max 1 (- (sp-dashboard--lines) current-line 2))))
              (insert-char ?\n footer-padding))
            
            ;; Footer text centered
            (defvar sp-dashboard-footer "   " "Footer text.")
            (let ((footer-center (max 0 (- (sp-dashboard--layer-column sp-dashboard-footer-layer)
                                           (/ (length sp-dashboard-footer) 2)))))
              (insert-char ?\s footer-center)
              (insert (propertize sp-dashboard-footer 'face 'sp-dashboard-footer-face)))

            ;; Lambda art behind the menu (a no-op when the art is off)
            (sp-dashboard--draw-art)

            (goto-char (point-min))
            (display-buffer-same-window splash-buffer nil))
          (switch-to-buffer "Dashboard"))
        (sp-dashboard-mode))))
#+end_src

** Agendas

The Agenda block of the menu has four agendas: General (=a=), thesis (=t=), issues (=i=) and deadlines (=d=).

- Each has a variable naming its files: =sp-dashboard-agenda-general-files=, =sp-dashboard-agenda-thesis-files=, =sp-dashboard-agenda-issues-files= and =sp-dashboard-agenda-deadlines-files=.
- Point them at the right files. While one is nil it uses =org-agenda-files=.
- =sp-dashboard--open-agenda= shows the agenda of a list of files. For deadlines it shows only deadlines in the next =sp-dashboard-deadlines-days= days.
- The General agenda keeps opening the agenda workspace (=sp-open-agenda-in-workspace=) while its variable is nil.

* Splash minor mode

** Keymap

=sp-dashboard-mode-map= gives the splash single-key bindings.

Keys:

- =a=, =t=, =i=, =d=: the four agendas.
- =c=, =n=: config and notes.
- =g=: redraw.
- =P=: cycle the privacy mode.
- =q=, =k=: kill the splash. =<escape>= buries it.
- =S-<arrow>= moves the current art layer, =l= picks the next layer, =0= resets the layers and =s= shows them.
- =TAB= and =S-TAB= are the only movement. They step through the buttons (the agendas, config and notes), wrapping around.
- =RET= and a click activate the button.

Look and feel:

- The selected button is highlighted with =sp-dashboard-focus-face=, since the cursor is hidden.
- The keys and mouse events that scroll, move the cursor, search or mark a region are bound to =ignore=. The splash can't be scrolled or marked; it fills the window and is redrawn when the window changes.

Only buttons are interactive:

- =sp-dashboard--isolate-menu= puts =sp-dashboard-mode-map= on an overlay over the whole buffer. That ranks above the button's own keymap, so =TAB= is =sp-dashboard-next-button= wherever point is. The commands that move point are bound to =ignore=, so the only way to move is =TAB= / =S-TAB=, and point rests on a button.
- It does not use =cursor-intangible-mode=. Its redisplay hook (=cursor-sensor--move-to-tangible= on =pre-redisplay-functions=) calls =cursor-sensor-tangible-pos=, which returns nil when it finds no tangible position, and then does arithmetic on nil: =(wrong-type-argument number-or-marker-p nil)=. Redisplay runs the hook inside =with-demoted-errors=, so the error is caught and printed there, before any handler of yours runs, on every redisplay while the condition holds. =condition-case=, =debug-on-error= and =warning-suppress-types= cannot reach it, and advising the function or the hook would mean patching Emacs. Starting the mode from an idle timer only narrowed the window: the dashboard is erased and redrawn by =sp-dashboard-refresh= whenever the window state changes, so a redisplay can still see a buffer with nothing tangible.
- It also puts =sp-dashboard-mode-map= on an overlay over the whole buffer. That ranks above the button's own keymap, so =TAB= is =sp-dashboard-next-button= wherever point is.

#+begin_src emacs-lisp -i
;;;; Define Minor Mode
;; Custom splash screen
(defvar sp-dashboard-mode-map
  (let ((map (make-sparse-keymap)))
    (define-key map (kbd "a") 'sp-dashboard-open-agenda)
    (define-key map (kbd "g") 'sp-dashboard-refresh)
    (define-key map (kbd "P") 'sp-dashboard-toggle-public-mode)
    (define-key map (kbd "c") 'sp-dashboard-open-config)
    (define-key map (kbd "n") 'sp-dashboard-open-notes)
    (define-key map (kbd "t") 'sp-dashboard-open-thesis-agenda)
    (define-key map (kbd "i") 'sp-dashboard-open-issues-agenda)
    (define-key map (kbd "d") 'sp-dashboard-open-deadlines-agenda)
    (define-key map (kbd "S-<left>") 'sp-dashboard-art-left)
    (define-key map (kbd "S-<right>") 'sp-dashboard-art-right)
    (define-key map (kbd "S-<up>") 'sp-dashboard-art-up)
    (define-key map (kbd "S-<down>") 'sp-dashboard-art-down)
    (define-key map (kbd "TAB") 'sp-dashboard-next-button)
    (define-key map (kbd "RET") 'push-button)
    (define-key map [mouse-2] 'push-button)
    (define-key map [follow-link] 'mouse-face)
    (define-key map (kbd "<backtab>") 'sp-dashboard-previous-button)
    (define-key map (kbd "l") 'sp-dashboard-art-next-layer)
    (define-key map (kbd "0") 'sp-dashboard-art-reset)
    (define-key map (kbd "s") 'sp-dashboard-art-show-position)
    (define-key map (kbd "q") 'sp-dashboard-screen-kill)
    (define-key map (kbd "<escape>") 'sp-dashboard-screen-bury)
    (define-key map (kbd "k") 'sp-dashboard-screen-kill)
    ;; The splash is not for scrolling, moving the cursor or marking text:
    ;; only TAB and S-TAB move, between the buttons.
    (dolist (command '(next-line previous-line forward-char backward-char
                       forward-word backward-word left-word right-word
                       beginning-of-line end-of-line move-beginning-of-line
                       move-end-of-line beginning-of-buffer end-of-buffer
                       scroll-up-command scroll-down-command scroll-left
                       scroll-right scroll-other-window recenter
                       recenter-top-bottom reposition-window
                       set-mark-command mark-whole-buffer mark-word
                       mark-paragraph mark-sexp exchange-point-and-mark
                       mouse-set-region mouse-drag-region mouse-save-then-kill
                       mouse-set-point mouse-secondary-save-then-kill
                       mwheel-scroll pixel-scroll-precision
                       isearch-forward isearch-backward))
      (define-key map `[remap ,command] #'ignore))
    (dolist (event '(wheel-up wheel-down wheel-left wheel-right mouse-4 mouse-5
                     mouse-6 mouse-7 double-wheel-up double-wheel-down
                     triple-wheel-up triple-wheel-down down-mouse-1
                     drag-mouse-1 double-mouse-1 triple-mouse-1))
      (define-key map (vector event) #'ignore))
    map)
  "Keymap for sp-dashboard-mode.")

(defvar-local sp-dashboard--focus-overlay nil
  "Overlay marking the selected button of the splash.")

(defun sp-dashboard-next-button ()
  "Select the next button of the splash, wrapping around."
  (interactive)
  (forward-button 1 t nil t))

(defun sp-dashboard-previous-button ()
  "Select the previous button of the splash, wrapping around."
  (interactive)
  (backward-button 1 t nil t))

(defun sp-dashboard--mark-focus ()
  "Highlight the button at point, since the cursor is hidden."
  (when sp-dashboard--focus-overlay
    (delete-overlay sp-dashboard--focus-overlay))
  (when-let* ((button (button-at (point))))
    (setq sp-dashboard--focus-overlay
          (make-overlay (button-start button) (button-end button)))
    (overlay-put sp-dashboard--focus-overlay 'face 'sp-dashboard-focus-face)))

(defun sp-dashboard--no-region ()
  "Drop the region at once: the splash never marks text."
  (deactivate-mark))

(defun sp-dashboard--isolate-menu ()
  "Make the keys of the dashboard the same wherever point is.
An overlay over the whole buffer carries `sp-dashboard-mode-map' as its
keymap, which ranks above the other keymaps.  The map binds TAB and S-TAB to
`sp-dashboard-next-button' and `sp-dashboard-previous-button' and ignores
the commands that move point, so point only ever rests on a button.  There
is no `cursor-intangible-mode': its redisplay hook signals
`wrong-type-argument' whenever it finds no button to move to, which cannot be
caught from outside (see the doc)."
  (let ((overlay (make-overlay (point-min) (point-max))))
    (overlay-put overlay 'keymap sp-dashboard-mode-map)
    (overlay-put overlay 'priority 100)))
#+end_src

** Minor mode

=sp-dashboard-mode= is a buffer-local minor mode that makes the splash look clean.

- Disables undo, auto-revert, whitespace mode and line numbers.
- Makes the buffer read-only.
- Hides the cursor, mode line and header line, and removes margins and fringes.
- Sets the global =inhibit-startup-screen= family of variables and =truncate-lines=.
- When Evil is active, switches to Emacs state so the single-key bindings are not shadowed.
- Its =:group= is =sp-dashboard=. It used to be =spcustom=, which this config never defines.

#+begin_src emacs-lisp -i
(define-minor-mode sp-dashboard-mode
  "Emacs minor mode for splash screen."
  :global nil
  :keymap sp-dashboard-mode-map
  :group 'sp-dashboard
  
  :require 'sp-dashboard
  (buffer-disable-undo)
  (auto-revert-mode -1)
  (whitespace-mode -1)
  (when (fboundp 'linum-mode)
    (linum-mode -1))
  (when (>= emacs-major-version 26)
    (display-line-numbers-mode -1))
  
  (setq-local buffer-read-only t)
  (setq-local cursor-type nil)
  (setq-local hl-line-mode -1)
  ;; `global-hl-line-mode' ignores the line above and would paint the whole row
  (setq-local global-hl-line-mode nil)
  (setq-local mode-line-format nil)
  (setq-local header-line-format nil)
  
  ;; No margin or fringe in splash buffer
  (setq-local left-margin-width nil
              right-margin-width nil)
  (set-window-fringes (selected-window) 0 0 nil)
  (setq inhibit-startup-screen t
        truncate-lines nil
        inhibit-startup-message t
        inhibit-startup-echo-area-message t)

  ;; The splash fills the window and never scrolls or wraps
  (setq-local truncate-lines t
              scroll-margin 0
              scroll-conservatively 0
              auto-window-vscroll nil
              shift-select-mode nil
              mouse-wheel-mode nil)
  (add-hook 'activate-mark-hook #'sp-dashboard--no-region nil t)
  (add-hook 'post-command-hook #'sp-dashboard--mark-focus nil t)
  
  ;; Use Emacs state if Evil is active so single-key bindings work
  (when (bound-and-true-p evil-mode)
    (evil-emacs-state))
  (sp-dashboard--isolate-menu)
  (goto-char (point-min))
  (set-window-start (selected-window) (point-min))
  (forward-button 1 t nil t)
  (sp-dashboard--mark-focus))
#+end_src

* Setup and refresh

** Refresh

=sp-dashboard-refresh= rebuilds the splash when the current buffer is =Dashboard=, by killing it and calling =sp-dashboard-screen= again so it is re-centred for the new window size. It always uses the graphical renderer and swallows errors.

#+begin_src emacs-lisp -i
;;;; Splash Setup & Refresh Functions
(defun sp-dashboard-refresh ()
  "Refresh & recenter splash after window switch."
  (interactive)
  (when (string= (buffer-name) "Dashboard")
    (progn
      (ignore-errors
        (sp-dashboard-screen-kill)
        (sp-dashboard-screen)))))
#+end_src

** Initial display and hooks

=sp-dashboard--setup-splash-hooks= shows the graphical or terminal splash depending on =display-graphic-p=, then adds =sp-dashboard-refresh= to =window-state-change-hook=, =window-configuration-change-hook= and =sp-switch-buffer-hook= so the splash redraws when windows change.

#+begin_src emacs-lisp -i
(defun sp-dashboard--setup-splash-hooks ()
  "Initialize splash and setup hooks."
  (progn
    (if (display-graphic-p)
        (sp-dashboard-screen)
      (sp-dashboard-terminal))
    (add-hook 'window-state-change-hook #'sp-dashboard-refresh)
    (add-hook 'window-configuration-change-hook  #'sp-dashboard-refresh)
    (add-hook 'sp-switch-buffer-hook #'sp-dashboard-refresh)))
#+end_src

** Install on startup

Adds the setup function to =window-setup-hook=, which runs after the frame parameters are applied, unless Emacs was started with =--no-splash=, =--file=, =--insert= or =--find-file=. A plain filename argument is not checked here.

#+begin_src emacs-lisp -i
;; Install hook after frame parameters have been applied and only if

           (not (member "--file"      command-line-args))
           (not (member "--insert"    command-line-args))
           (not (member "--find-file" command-line-args)))
  (add-hook 'window-setup-hook #'sp-dashboard--setup-splash-hooks))
