** use-package statistics

Setting =use-package-compute-statistics= makes use-package record how long each package took to load and configure. Run =M-x use-package-report= to see the table. It only measures packages declared after this setting takes effect, so its usefulness depends on how early the module is loaded.

#+begin_src emacs-lisp -i
;; Getting information on the launch time for packages.
(setq use-package-compute-statistics t)
#+end_src
