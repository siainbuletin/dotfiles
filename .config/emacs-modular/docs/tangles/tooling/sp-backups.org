Literate source for =libraries/modules/tooling/sp-backups.el=.

- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README.

This module decides where Emacs keeps backup files and auto-save files, turns on aggressive automatic saving of every modified file, disables lock files and enables =savehist= so minibuffer history survives restarts. It relies on the directory constants =sp-var-dir= and =sp-cache-dir= from =early-init.el= and installs the =vc-backup= package.

The backup settings are made once, in the final block:

- Backups go to =backups/= under =sp-var-dir=, numbered, keeping the 6 newest and 3 oldest versions.
- Auto-save files go to =auto-save-files/= under =sp-cache-dir=.

History and loading:

- The file used to set the backup directory, version counts and lock files several times with different values, where the later assignments won. Those earlier, overridden copies are gone, so the effective settings are unchanged.
- The module is loaded with the utility modules in =init.el=, in both the default and minimal lists.

The commentary at the top of the module says:

* Backups and auto-save

** use-package files

Configures the built-in =files= library. In =:init=:
- the auto-save list and auto-save files are kept under =sp-cache-dir=;
- auto-saving is turned on for every buffer, every 30 idle seconds or 300 keystrokes, and auto-save files are deleted after a real save;
- =auto-save-visited-mode= is enabled, which saves file-visiting buffers directly to their files.

The =:config= defines =lem-full-auto-save=, which saves every modified file buffer and ignores errors, and runs it from =auto-save-hook= and from a repeating 5 second idle timer. The net effect is that modified files are written to disk whenever Emacs is idle for a few seconds.

The backup settings that used to be repeated here, in =:config= and at the top of the file now live only in the final block below.

#+begin_src emacs-lisp -i
;;;; Backups / Auto-Save
(use-package files
  :ensure nil
  :defer 1
  :init
  
  ;; auto save
  (setq auto-save-list-file-prefix
        (concat sp-cache-dir "auto-save-list/.saves-"))
  (let ((auto-save-files-dir (concat sp-cache-dir "auto-save-files/")))
    (setq auto-save-file-name-transforms
          `((".*" ,auto-save-files-dir t)))
    (when (not (file-exists-p auto-save-files-dir))
      (make-directory auto-save-files-dir t)))
  
  ;; auto-save every file visiting buffer
  ;; see https://emacs.stackexchange.com/q/7729/11934
  (setq-default auto-save-default t)
  (setq-default
   auto-save-timeout 30              ; number of seconds idle time before auto-save (default: 30)
   auto-save-interval 300            ; number of keystrokes between auto-saves (default: 300)
   delete-auto-save-files t)
  (auto-save-visited-mode 1)
  :config
  (defun lem-full-auto-save ()
    (interactive)
    (save-excursion
      (dolist (buf (buffer-list))
        (when (buffer-live-p buf)  ; Check if buffer is still valid
          (with-current-buffer buf  ; Use with-current-buffer instead of set-buffer
            (when (and (buffer-file-name) (buffer-modified-p))
              (condition-case nil  ; Catch any errors during save
                  (basic-save-buffer)
                (error nil))))))))

  (add-hook 'auto-save-hook 'lem-full-auto-save)

  ;; Save all buffers after idle time
  (run-with-idle-timer 5 t (lambda () (lem-full-auto-save))))
#+end_src

** vc-backup

Installs =vc-backup=, a VC backend that treats Emacs backup files as a version history, so older backups can be browsed and diffed with the normal VC commands.

#+begin_src emacs-lisp -i
(use-package vc-backup
  :ensure (:wait t))
#+end_src

** Final backup settings

The one place where backups are configured:

- The folder (=backup-directory-alist=, =backups/= under =sp-var-dir=) is no longer set here. It moved to [[file:../base/sp-globals.org][sp-globals]] as =sp-backup-directory=, and a comment in the code says so.
- Backups are made by copying, and also for version-controlled files.
- Deleted files are moved to the system trash.
- 6 new and 3 old numbered versions are kept.
- The inline comment on =vc-make-backup-files= says the opposite of what the setting does. t means files under version control are backed up too.

#+begin_src emacs-lisp -i
;; The backup folder (`backup-directory-alist') moved to `sp-globals', as
;; `sp-backup-directory'.
(setq-default make-backup-files t
              vc-make-backup-files t ; Won't create backup of files that are already under version control
              backup-by-copying t ; Avoid symlinks
              delete-old-versions t
              delete-by-moving-to-trash t ; This makes sure that the files aren't permanently deleted
              kept-new-versions 6
              kept-old-versions 3
              version-control t)
#+end_src

** No lock files

Disables the =.#file= lock files Emacs creates while a buffer has unsaved changes, which the comment says cause more trouble than they prevent. The setting moved to [[file:../base/sp-globals.org][sp-globals]] as =sp-create-lockfiles=, and a comment in the code says so.

#+begin_src emacs-lisp -i
;;;; Lockfiles unfortunately cause more pain than benefit
;; Moved to `sp-globals': `sp-create-lockfiles' (nil: no lock files).
#+end_src

* History

** savehist

Enables =savehist-mode=, which saves minibuffer history between sessions, with the history file stored in =sp-var-dir=. The file is set in =:init=, before the mode is turned on, so the mode reads and writes =var/savehist= from the first start. (It used to be set in =:config=, after the mode had read its default file in the config folder, which is why a =savehist= file stayed there.)

#+begin_src emacs-lisp -i
;; What do you do with the saved history?
(use-package savehist
  :ensure nil
  :init
  (setq savehist-file (expand-file-name "savehist" sp-var-dir))
  (savehist-mode t))
#+end_src
