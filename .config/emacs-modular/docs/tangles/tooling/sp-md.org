Literate source for =libraries/modules/tooling/sp-md.el=.

- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README.

This module configures Markdown editing.

- Registers the built-in, still experimental =markdown-ts-mode= from Emacs 31 without enabling it.
- Sets up the established =markdown-mode= package as the actual mode for Markdown files, with:
  - super key shortcuts,
  - wiki links,
  - a custom open command,
  - an xwidget based live preview,
  - spell checking and TODO highlighting.
- =markdown-toc= adds table of contents support.

External pieces it expects: =flyspell= and =hl-todo= for the mode hook, an Emacs built with xwidget support for the live preview, and a script at =~/bin/mark.sh= for =markdown-open=. The module is loaded with the utility modules in both module lists in =init.el=.

* Tree-sitter Markdown mode

** Markdown-ts-mode

Declares the built-in =markdown-ts-mode= without installing anything, and defers it.

- The header comment says Emacs 21 but means Emacs 31, where this mode arrived.
- It is not added to =auto-mode-alist=, so this form has no visible effect beyond making the package known to use-package.

#+begin_src emacs-lisp -i
;;;; Markdown-ts-mode (native emacs 21)
;; Emacs 31 brought Markdown-ts-mode, which is closer to the keybindings
;; that you may find in org-mode, it feels more native to Emacs itself
;; in a lot of ways.

(use-package markdown-ts-mode
  :ensure nil
  :defer t)
#+end_src

** Opting in by hand

A note explaining that =markdown-ts-mode= is experimental and not wired to =.md= files, so you load it with =M-x load-library= and enable it per buffer, or add it to =auto-mode-alist= yourself.

#+begin_src emacs-lisp -i
;; One caveat I want to be upfront about: markdown-ts-mode is still experimental,
;; and you have to opt into it. As the header of markdown-ts-mode.el notes, it 
;; isn't wired up to auto-mode-alist yet, so it won't take over .md files on its 
;; own. For now you pull in the library with M-x load-library RET markdown-ts-mode,
;; then turn it on in a bufferf, or add it to auto-mode-alist yourself if you're feeling brave.
#+end_src

* Markdown mode

** Legacy markdown-mode

Installs =markdown-mode= and uses it for =.markdown= and =.md= files, with =README.md= files intended for =gfm-mode= (GitHub flavoured).

- In Markdown buffers, =s-*=, =s-b= and =s-i= insert a list item, bold and italic.
- The settings turn off math and turn on wiki links.
- They nest headings in imenu and put footnotes right after the reference.
- They use a dash and three spaces for bullets and scale headers.
- They read Pandoc style YAML metadata.
- =markdown-open-command= points to a personal =~/bin/mark.sh= script.

Live preview and per-buffer settings:

- Live preview is redirected to =sp--markdown-live-preview-window-xwidget=. It opens the exported file in an xwidget WebKit browser and pops to it, so it needs an Emacs built with xwidgets.
- =sp--markdown-settings= runs in every Markdown buffer to turn on =flyspell-mode= and =hl-todo-mode= (auto fill is commented out).
- Finally, =@= is made a symbol constituent, so word and symbol motions treat it as part of a word. The comment says this is for Meow point movement.

#+begin_src emacs-lisp -i
;;;; Legacy markdown mode
(use-package markdown-mode
  :ensure t
  :commands (markdown-mode gfm-mode)
  
  :mode (("\\.markdown\\'" . markdown-mode)
         ("\\.md\\'"       . markdown-mode)
         ("README\\.md\\'" . gfm-mode))
  
  :bind (:map markdown-mode-map
         ("s-*" . markdown-insert-list-item)
         ("s-b" . markdown-insert-bold)
         ("s-i" . markdown-insert-italic))
  
  :config
  (setq markdown-enable-math nil
        markdown-enable-wiki-links t
        markdown-nested-imenu-heading-index t
        markdown-open-command "~/bin/mark.sh"
        markdown-footnote-location 'immediately

        markdown-unordered-list-item-prefix "-   "
        markdown-header-scaling t
        markdown-use-pandoc-style-yaml-metadata t)
  
  (setq markdown-live-preview-window-function 'sp--markdown-live-preview-window-xwidget)

  (defun sp--markdown-live-preview-window-xwidget (file)
    "Preview file with xwidget browser"
    (xwidget-webkit-browse-url (concat "file://" file))
    (let ((buf (xwidget-buffer (xwidget-webkit-current-session))))
      (when (buffer-live-p buf)
        (and (eq buf (current-buffer)) (quit-window))
        (pop-to-buffer buf))))

  (defun sp--markdown-settings ()
    "settings for markdown mode"
    (progn
      (flyspell-mode 1)
      ;; (auto-fill-mode)
      (hl-todo-mode))
   )

  ;; markdown hooks
  (add-hook 'markdown-mode-hook 'sp--markdown-settings)

  ;; for use with meow point movement
  (modify-syntax-entry ?@ "_" markdown-mode-syntax-table))
#+end_src

** Table of contents

Installs =markdown-toc= and enables =markdown-toc-mode= in Markdown buffers, which provides commands to generate and refresh a table of contents.

#+begin_src emacs-lisp -i
;;;; Markdown TOC
(use-package markdown-toc
  :ensure t
  :after markdown-mode
  :hook 
  (markdown-mode . markdown-toc-mode))
#+end_src

** Delete backslashes macro

=lem-md-delete-backslash= is a saved keyboard macro meant to clean up stray backslashes left by a conversion to Markdown.

- It presses =M-q= twice and then the keys =f=, backslash and =x=. These are modal find and delete keys.
- So it only does what its name says in a Vim style state. In plain Emacs state those keys would insert text.
- Its exact intent is inferred from the comment.

#+begin_src emacs-lisp -i
;; macro: delete backslashes in paragraph to cleanup markdown conversion
(fset 'lem-md-delete-backslash
      (lambda (&optional arg) "Keyboard macro." (interactive "p") (funcall (kmacro "\361\361f\\x" 0 "%d") arg)))
#+end_src
