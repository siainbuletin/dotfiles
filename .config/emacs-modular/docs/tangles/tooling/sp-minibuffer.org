Literate source for =libraries/modules/tooling/sp-minibuffer.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

This module gathers the packages behind minibuffer and in-buffer completion. It pulls in =sp-completion= and then installs the =prescient= sorting and filtering library together with its adapters for Company, Ivy, Selectrum, Vertico and Corfu, plus Corfu itself and =counsel-fd=.

Most of the packages are only installed here (with elpaca's =:wait t= so they are available immediately); no adapter modes are switched on in this file, so any activation must happen elsewhere. A comment records an open question about whether this whole stack could be replaced by the improved built-in completion in Emacs 31. The module is loaded from =init.el= as part of the utility modules.

* Text buffer font size

** Larger text in text-mode buffers

Adds =sp-text-buffer= to =text-mode-hook=. That function is defined in =sp-fonts= and increases the text scale by four steps, so every text buffer opens with a larger font. It has little to do with the minibuffer and seems to live here for historical reasons; it relies on =sp-fonts= being loaded first.

#+begin_src emacs-lisp -i
(add-hook 'text-mode-hook 'sp-text-buffer)
#+end_src

* Counsel

** counsel-fd

Installs =counsel-fd=, which provides Counsel commands for finding files and directories with the external =fd= program. It loads after =counsel=.

#+begin_src emacs-lisp -i
(use-package counsel-fd
  :ensure t
  :after counsel)
#+end_src

** sp-completion and prescient

Requires the =sp-completion= module and installs =prescient=, the library that sorts and filters candidates by frequency and recency.

#+begin_src emacs-lisp -i
(require 'sp-completion)


;; prescient ecosystem
(use-package prescient
    :ensure (:wait t)
)
#+end_src

** Prescient adapters for each frontend

Installs the prescient integrations for Company, Ivy, Selectrum and Vertico. Several completion frontends are covered at once, which suggests the config has moved between them over time; Selectrum in particular is no longer maintained.

#+begin_src emacs-lisp -i
(use-package company-prescient
  :ensure (:wait t)
)

(use-package ivy-prescient
  :ensure (:wait t)
)

(use-package selectrum-prescient
  :ensure (:wait t)
)

(use-package vertico-prescient
  :ensure (:wait t)
)
#+end_src

** Corfu

Installs Corfu, the in-buffer completion popup, and its prescient adapter. Neither =global-corfu-mode= nor =corfu-prescient-mode= is enabled here.

#+begin_src emacs-lisp -i
(use-package corfu
  :ensure (:wait t))

(use-package corfu-prescient
  :ensure (:wait t))
#+end_src
