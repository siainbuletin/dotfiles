Literate source for =libraries/modules/tooling/sp-splash.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module replaces the stock Emacs startup screen with a =Dashboard= buffer showing a lambda logo, a welcome line, the Emacs version, package count and init time, a short menu of buttons, and a footer. There are two renderers: =sp-splash-screen= for graphical frames (PNG logo plus nerd-icons menu buttons) and =sp-splash-terminal= for terminal frames (ASCII banner read from =images/lambda-splash.txt=).

It depends on =cl-lib=, optionally on =nerd-icons=, on =sp-get-string-from-file= from =sp-helper-funct=, on =sp-library-dir= for the logo and banner files, and on =sys-mac=. The menu actions call workspace functions from the =sp-workspaces= module when it is loaded. The splash is installed on =window-setup-hook= unless the command line asks for a file or =--no-splash=. In =early-init.el= the module is listed in =sp-gui-only-set=, so it is normally only loaded in GUI sessions.

** Init info

=sp-splash-init-info= holds a function that returns a summary string such as "42 packages loaded in 1.2s". It counts =package-activated-list= for package.el, or the straight.el profile cache, and falls back to just the init time when no packages are counted. The approach is borrowed from emacs-dashboard and Doom. Its =:group= is =sp-splash=, the customization group defined above (it used to be =lambda-splash=, which this config never defines).

#+begin_src emacs-lisp -i
;; Init info
;; See https://github.com/emacs-dashboard/emacs-dashboard/blob/master/dashboard-widgets.el
;; https://github.com/hlissner/doom-emacs/blob/eddaae40e84b5eb1f0136aaba23d918f71b6a986/core/core.el#L479
(defcustom sp-splash-init-info
  (lambda ()
    (let ((package-count 0) (time (emacs-init-time)))
      (cond ((bound-and-true-p package-alist)
             (setq package-count (length package-activated-list)))
            ((boundp 'straight--profile-cache)
             (setq package-count (+ (hash-table-count straight--profile-cache) package-count))))
      (if (zerop package-count)
          (format "Emacs started in %s" time)
        (format "%d packages loaded in %s" package-count time))))
  "Init info with packages loaded and init time."
  :type '(function string)
  :group 'sp-splash)
#+end_src

* Art layers

The graphical splash draws text art behind the menu instead of the PNG logo: the lambda in =libraries/images/lambda-splash.txt= and the EMACS block-letter banner in =libraries/images/dashboard-banner-3.txt= (a local copy of banner 3 of the =dashboard= package, so it can be edited freely). ** Layers and steps

=sp-splash-art-layers= lists the layers, topmost first. Each is =(NAME :file FILE :x X :y Y :face FACE)=. =FILE= is a text file; a relative name is looked up in =sp-splash-art-directory= (=images/= under =sp-library-dir=). The art is centred on the window and then moved by =X= columns and =Y= lines (negative is left and up). The default puts the lambda centred vertically and 50 columns left, and the banner 30 columns right and 8 lines above the centre. Remove a layer from the list to hide it; set the list to nil to get the PNG logo back. The two step options set how far each nudge command moves a layer, and =sp-splash-art-layer= remembers which layer the nudge commands move.

#+begin_src emacs-lisp -i
(defcustom sp-splash-art-directory "images/"
  "Folder of the splash art files; relative to `sp-library-dir'."
  :type 'directory
  :group 'sp-splash)

(defcustom sp-splash-art-layers
  (copy-tree
   '((banner :file "dashboard-banner-3.txt" :x 30 :y -8 :face sp-splash-banner-face)
     (lambda :file "lambda-splash.txt" :x -50 :y 0 :face sp-splash-art-face)))
  "Art drawn behind the splash menu, topmost layer first.
Each element is (NAME :file FILE :x X :y Y :face FACE).  FILE is a text
file (a relative name is looked up in `sp-splash-art-directory').  X and
Y move the art right and down from the centre of the window, in columns
and lines (negative: left and up).  Remove an element to hide its layer."
  :type '(alist :key-type symbol :value-type plist)
  :group 'sp-splash)
#+end_src

** Finding the art

=sp-splash--layer-file= resolves a layer's file in =sp-splash-art-directory=; both the lambda and the banner are plain files there, so they can be changed or replaced. The terminal splash reads =lambda-splash.txt= from the same folder. =sp-splash--art-lines= reads the file and drops trailing blank lines. =sp-splash--layer-box= gives the place a layer takes in the window, which =sp-splash-content-layer= (the banner) uses: the title, the version line and the menu are centred on that layer's middle column and start two lines below it, so they stay under the banner when it is moved. =sp-splash--content-column= returns that column, or the window's middle when there is no such layer.

#+begin_src emacs-lisp -i
(defun sp-splash--layer-file (file)
  "Return the path of the art FILE of a layer, or nil when it is missing.
A relative FILE is looked up in `sp-splash-art-directory'."
  (let ((path (expand-file-name file (expand-file-name sp-splash-art-directory
                                                       sp-library-dir))))
    (and (file-regular-p path) path)))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-splash--art-lines (file)
  "Return the lines of the art FILE of a layer, or nil when unavailable."
  (when-let* ((path (sp-splash--layer-file file)))
    (let ((lines (with-temp-buffer
                   (insert-file-contents path)
                   (split-string (buffer-string) "\n"))))
      ;; Drop blank lines at the end so they don't count as height.
      (while (and lines (string-blank-p (car (last lines))))
        (setq lines (butlast lines)))
      lines)))
#+end_src

** Drawing

=sp-splash--draw-art= runs at the end of =sp-splash-screen= and draws each layer with =sp-splash--draw-layer=. For each non-blank art character it puts the character in the layer's face, but only on a plain blank: text, buttons and images are never overwritten, and a line shorter than the art is padded. Rows above the first or below the last window line, and columns left of the window, are cut.

#+begin_src emacs-lisp -i
(defcustom sp-splash-content-layer 'banner
  "Name of the art layer the title and the menu sit under.
The text is centred on this layer, below it.  Nil, or a layer that is not
in `sp-splash-art-layers', centres the text on the window."
  :type '(choice (const :tag "Centre on the window" nil) symbol)
  :group 'sp-splash)

(defun sp-splash--layer-box (name)
  "Return (LEFT TOP WIDTH HEIGHT) of the art layer NAME in the window, or nil."
  (when-let* ((layer (assq name sp-splash-art-layers))
              (lines (sp-splash--art-lines (plist-get (cdr layer) :file))))
    (let ((width (apply #'max (mapcar #'length lines)))
          (height (length lines)))
      (list (+ (- (/ (window-width) 2) (/ width 2))
               (or (plist-get (cdr layer) :x) 0))
            (+ (- (/ (window-body-height) 2) (/ height 2))
               (or (plist-get (cdr layer) :y) 0))
            width height))))

(defun sp-splash--content-column ()
  "Return the column the title and the menu are centred on."
  (if-let* ((box (sp-splash--layer-box sp-splash-content-layer)))
      (+ (nth 0 box) (/ (nth 2 box) 2))
    (/ (window-width) 2)))

(defun sp-splash--put-art-char (col ch face)
  "Put CH in FACE at column COL of the current line if it is blank."
  (move-to-column col)
  (cond ((and (eolp) (<= (current-column) col))
         (insert-char ?\s (- col (current-column)))
         (insert (propertize (string ch) 'face face)))
        ((and (= (current-column) col)
              (eq (char-after) ?\s)
              (not (get-text-property (point) 'face))
              (not (get-text-property (point) 'button))
              (not (get-text-property (point) 'display)))
         (delete-char 1)
         (insert (propertize (string ch) 'face face)))))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-splash--draw-layer (layer)
  "Draw the art LAYER, centred on the window and moved by its offsets.
Only plain blanks are replaced, so text, buttons and images are kept."
  (when-let* ((lines (sp-splash--art-lines (plist-get (cdr layer) :file))))
    (let* ((inhibit-read-only t)
           (indent-tabs-mode nil)
           (face (or (plist-get (cdr layer) :face) 'sp-splash-art-face))
           (box (sp-splash--layer-box (car layer)))
           (left (nth 0 box))
           (top (nth 1 box))
           (max-line (window-body-height))
           (row 0))
      (dolist (text lines)
        (let ((line (+ top row)))
          (when (and (>= line 1) (<= line max-line))
            ;; Grow the buffer when the art runs past its last line.
            (goto-char (point-max))
            (while (< (line-number-at-pos) line)
              (insert-char ?\n 1))
            (goto-char (point-min))
            (forward-line (1- line))
            (dotimes (i (length text))
              (let ((ch (aref text i))
                    (col (+ left i)))
                (when (and (/= ch ?\s) (>= col 0))
                  (sp-splash--put-art-char col ch face)
                  (forward-line 0)))))
          (setq row (1+ row)))))))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-splash--draw-art ()
  "Draw every art layer behind the menu, the topmost layer first."
  (dolist (layer sp-splash-art-layers)
    (sp-splash--draw-layer layer)))
#+end_src

** Moving the art

In the splash buffer, =S-<left>=, =S-<right>=, =S-<up>= and =S-<down>= move the current layer and redraw; =TAB= picks the next layer. The splash rebuilds itself, so the change lasts until Emacs exits. =0= goes back to the defaults and =s= shows (and copies) the =setq= form for the current layers, to paste into the config.

#+begin_src emacs-lisp -i
;;;; Move the art
(defun sp-splash--current-layer ()
  "Return the layer the nudge commands move."
  (or (assq sp-splash-art-layer sp-splash-art-layers)
      (car sp-splash-art-layers)))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-splash-art-next-layer ()
  "Select the next art layer for the nudge commands."
  (interactive)
  (let* ((names (mapcar #'car sp-splash-art-layers))
         (rest (cdr (memq (car (sp-splash--current-layer)) names))))
    (setq sp-splash-art-layer (car (or rest names)))
    (message "Splash art layer: %s" sp-splash-art-layer)))
#+end_src

#+begin_src emacs-lisp -i
(defun sp-splash-art-nudge (dx dy)
  "Move the current art layer DX columns right and DY lines down, and redraw."
  (let ((layer (sp-splash--current-layer)))
    (unless layer (user-error "No splash art layers"))
    (plist-put (cdr layer) :x (+ (or (plist-get (cdr layer) :x) 0) dx))
    (plist-put (cdr layer) :y (+ (or (plist-get (cdr layer) :y) 0) dy))
    (message "Splash art %s: x %d, y %d" (car layer)
             (plist-get (cdr layer) :x) (plist-get (cdr layer) :y)))
  (sp-splash-refresh))
#+end_src

** Erase helper

=sp-splash--erase= switches to the splash buffer and clears it, but only if the buffer exists. It used to wrap its body in =when-let*=, which only bound =inhibit-read-only= and discarded the =get-buffer= result, so the body always ran and =switch-to-buffer= created the buffer when it was missing. Now =inhibit-read-only= is bound around =erase-buffer= alone. The function is not called anywhere in the module.

#+begin_src emacs-lisp -i
(defun sp-splash--erase ()
  ;; check if splash exists and switch if so
  (when (get-buffer "Dashboard")
    (switch-to-buffer "Dashboard")
    (let ((inhibit-read-only t))
      (erase-buffer))))
#+end_src

** Terminal splash

=sp-splash-terminal= builds the splash for terminal frames. If =Dashboard= already exists it just switches to it. Otherwise it creates the buffer, hides the mode line and header line, sets margins and fill column from the window size, disables the menu bar (except on graphical macOS), inserts the ASCII banner from =lambda-splash.txt= in =sp-library-dir=, and inserts the welcome, version and init-info lines as a rectangle roughly in the middle of the window. A footer is added at the bottom and =sp-splash-mode= is enabled. The local variables =midp=, =padding-top= and =height= are computed but unused, and the =defvar= of =sp-splash-footer= inside the body only provides a fallback value.

#+begin_src emacs-lisp -i
(defun sp-splash-terminal ()
  "A custom splash screen for terminal Emacs"
  (interactive)
  ;; Switch to or create splash buffer
  (or (when (get-buffer "Dashboard")
        (switch-to-buffer "Dashboard"))
      ;; Hide modeline before window-body-height is computed
      (let* ((splash-buffer (get-buffer-create "Dashboard")))
        (with-current-buffer splash-buffer
          (setq header-line-format nil)
          (setq mode-line-format nil)
          (erase-buffer))

        (let* ((buffer-read-only t)
               (midp  (/ (point-max) 2))
               (padding-top 3)
               (height (/ (window-height) 2))
	           (width (/ (window-width) 2))
               ;; Original ascii image from here:
               ;; https://github.com/Triagle/emax/blob/master/boot.txt
               (banner (sp-get-string-from-file (expand-file-name "lambda-splash.txt"
                                                          (expand-file-name sp-splash-art-directory
                                                                            sp-library-dir)))))

          (with-current-buffer splash-buffer
            ;; Buffer local settings
            (if (one-window-p)
                (setq mode-line-format nil))
            (setq-local cursor-type nil)
            (setq vertical-scroll-bar nil)
            (setq horizontal-scroll-bar nil)
            (setq fill-column width)
            (face-remap-add-relative 'link :underline nil)
            (unless (and (display-graphic-p) sys-mac) (menu-bar-mode 0))
            ;; Set margin padding locally
            (setq-local left-margin-width (/ width 6)
                        right-margin-width (/ width 6))
            (set-window-buffer nil (current-buffer))
            ;; Add padding at top
            (insert-char ?\n 1)
            (unless sp-splash-banner
              ;; Insert text banner
              (insert banner))
            ;; Position point
            (goto-char (point-min))
            (forward-line (- (/ (window-height) 2) 10))
            (end-of-line)
            ;; Insert header text
            (insert-rectangle `(,(propertize "           Welcome to 𝛌-Emacs"  'face 'sp-splash-title-face)
                                ,(concat (propertize "         GNU Emacs version" 'face 'sp-splash-header-face)
                                         " "
                                         (propertize (format "%d.%d" emacs-major-version emacs-minor-version) 'face 'sp-splash-header-face))
                                ,(let ((init-info (funcall sp-splash-init-info)))
                                   (concat " " (propertize init-info 'face 'sp-splash-header-face)))))
            ;; ;; Vertical padding to bottom
            (goto-char (point-max))
            ;; Footer text
            (defvar sp-splash-footer "   " "Footer text.")
            (save-excursion (insert-char ?\s (- (/ (window-width) 4) 10))
                            (insert
                             (propertize sp-splash-footer 'face 'sp-splash-footer-face)))
            (goto-char (point-min))
            (display-buffer-same-window splash-buffer nil))
          (switch-to-buffer "Dashboard"))
        (sp-splash-mode))))
#+end_src

** Graphical splash

=sp-splash-screen= is the GUI renderer. Called interactively it first kills an existing =Dashboard= buffer, because otherwise the command only switches to the old buffer and a changed setting would not show. After the same buffer setup as the terminal version it inserts, centered horizontally:
- the lambda logo PNG (white for the =lambda-dark= theme, black otherwise), only when the window is wider than 80 columns and taller than 20 lines and there are no art layers (see the previous section);
- the welcome text, the Emacs version and the init info;
- a menu of text buttons with nerd-icons for Agenda, Config, Mail, Notes and Projects, each showing its single-key shortcut;
- a footer pushed toward the bottom of the window;
- the art layers, drawn last and behind the menu.
Each button calls its action through =sp-splash--workspace-dispatch=, so a missing workspaces module gives a message rather than an error. The Projects button calls =tabspaces-open-or-create-project-and-workspace=, while the =p= key (below) calls =sp-open-existing-project-and-workspace=, so mouse and keyboard differ there.

#+begin_src emacs-lisp -i
(defun sp-splash-screen ()
  "A custom splash screen for Emacs.
Called interactively, it drops an existing Dashboard buffer first so the
splash is drawn again with the current settings."
  (interactive)
  (when (and (called-interactively-p 'any) (get-buffer "Dashboard"))
    (kill-buffer "Dashboard"))
  ;; Switch to or create splash buffer
  (or (when (get-buffer "Dashboard")
        (switch-to-buffer "Dashboard"))
      ;; Hide modeline before window-body-height is computed
      (let* ((splash-buffer (get-buffer-create "Dashboard")))
        (with-current-buffer splash-buffer
          (setq header-line-format nil)
          (setq mode-line-format nil)
          (erase-buffer))

        (let* ((buffer-read-only t)
               (midp  (/ (point-max) 2))
               (padding-top 3)
               (height (/ (window-height) 2))
	           (width (/ (window-width) 2))
               (image-scaling-factor 2.2)
               ;; scale icons
               (nerd-icons-scale-factor 1.10)
               (nerd-icons-default-adjust -0.02)
               (content-col (sp-splash--content-column)))

          (with-current-buffer splash-buffer
            ;; Buffer local settings
            (if (one-window-p)
                (setq mode-line-format nil))
            (setq-local cursor-type nil)
            (setq vertical-scroll-bar nil)
            (setq horizontal-scroll-bar nil)
            (setq fill-column width)
            (face-remap-add-relative 'link :underline nil)
            (unless (and (display-graphic-p) sys-mac) (menu-bar-mode 0))

            ;; Set margin padding locally
            (setq-local left-margin-width 0
                        right-margin-width (/ width 6))
            (set-window-buffer nil (current-buffer))

            ;; Add padding at top
            (insert-char ?\n padding-top)

            ;; Start the title and the menu below the content layer
            (when-let* ((box (sp-splash--layer-box sp-splash-content-layer)))
              (insert-char ?\n (max 0 (- (+ (nth 1 box) (nth 3 box) 2)
                                         (line-number-at-pos)))))
            
            ;; Simple centered layout
            (let* ((center-col (max 0 (/ (- (window-width) 60) 2))))
              
              ;; Add the lambda image, centered and reasonably sized
              (when (and (> (window-width) 80) (> (window-height) 20)
                         (null sp-splash-art-layers))
                (let* ((image-file (if (eq (car custom-enabled-themes) 'lambda-dark)
                                       (concat sp-library-dir "lambda-logo-white.png")
                                     (concat sp-library-dir "lambda-logo-black.png")))
                       (image (create-image image-file 'png nil :width 175 :height 175)))
                  (insert-char ?\s (+ center-col 19))
                  (insert-image image)
                  (insert-char ?\n 2)))
              
              (let ((welcome-text "Welcome to λ-Emacs")
                    (version-text (format "GNU Emacs version %d.%d" emacs-major-version emacs-minor-version))
                    (init-info (funcall sp-splash-init-info)))
                
                ;; Welcome text
                (let ((welcome-center (max 0 (- content-col (/ (length welcome-text) 2)))))
                  (insert-char ?\s welcome-center)
                  (insert (propertize welcome-text 'face 'sp-splash-title-face))
                  (insert-char ?\n 2))
                
                ;; Version text
                (let ((version-center (max 0 (- content-col (/ (length version-text) 2)))))
                  (insert-char ?\s version-center)
                  (insert (propertize version-text 'face 'sp-splash-header-face))
                  (insert-char ?\n 1))
                
                ;; Init info
                (let ((init-center (max 0 (- content-col (/ (length init-info) 2)))))
                  (insert-char ?\s init-center)
                  (insert (propertize init-info 'face 'sp-splash-header-face))
                  (insert-char ?\n 2))))

            ;; Insert menu buttons - left-aligned as a group, group is centered
            (goto-char (point-max))
            (let* ((button-indent (max 0 (- content-col (/ (length "Welcome to λ-Emacs") 2))))
                   (button-labels '(("nf-fa-calendar" "Agenda" "a" sp-open-agenda-in-workspace "Open Agenda")
                                    ("nf-fa-code" "Config" "c" sp-open-emacsd-in-workspace "Visit config directory")
                                    ("nf-fa-envelope_o" "Mail" "m" sp-open-email-in-workspace "Open Email in Mu4e")
                                    ("nf-fa-book" "Notes" "n" sp-open-notes-in-workspace "Open notes directory")
                                    ("nf-fa-folder" "Projects" "p" tabspaces-open-or-create-project-and-workspace "Open project & workspace")))
                   (max-label-width (apply 'max (mapcar (lambda (item) (length (nth 1 item))) button-labels))))
            
              (dolist (button button-labels)
                (let* ((icon (nth 0 button))
                       (label (nth 1 button))
                       (key (nth 2 button))
                       (action (nth 3 button))
                       (help (nth 4 button))
                       (padded-label (format (format "%%-%ds" max-label-width) label)))
                  (insert-char ?\s button-indent)
                  (insert-text-button (concat (nerd-icons-faicon icon)
                                              isep 
                                              padded-label 
                                              ksep 
                                              "(" key ")")
                                      'action (lambda (_) (sp-splash--workspace-dispatch action))
                                      'help-echo help
                                      'face 'sp-splash-menu-face
                                      'follow-link t)
                  (insert-char ?\n 1))))


            ;; Add footer with some space above bottom
            (goto-char (point-max))
            (let* ((current-line (line-number-at-pos))
                   (window-height (window-height))
                   (footer-padding (max 1 (- window-height current-line 15))))
              (insert-char ?\n footer-padding))
            
            ;; Footer text centered
            (defvar sp-splash-footer "   " "Footer text.")
            (let ((footer-center (max 0 (/ (- (window-width) (length sp-splash-footer)) 2))))
              (insert-char ?\s footer-center)
              (insert (propertize sp-splash-footer 'face 'sp-splash-footer-face)))

            ;; Lambda art behind the menu (a no-op when the art is off)
            (sp-splash--draw-art)

            (goto-char (point-min))
            (display-buffer-same-window splash-buffer nil))
          (switch-to-buffer "Dashboard"))
        (sp-splash-mode))))
#+end_src

* Workspace dispatch

Menu actions come from the optional =sp-workspaces= module. These wrappers make each one safe to call when that module is absent.

** Dispatcher

=sp-splash--workspace-dispatch= calls a function if it is defined and otherwise prints a message asking the user to enable =sp-workspaces=.

#+begin_src emacs-lisp -i
;;;; Workspace Dispatch
(defun sp-splash--workspace-dispatch (fn)
  "Call FN when it is defined, otherwise prompt to enable the workspaces module."
  (if (fboundp fn)

    (message "Enable the workspaces module (sp-workspaces) for this action")))

* Splash minor mode

** Keymap

=sp-splash-mode-map= gives the splash single-key bindings: =a=, =c=, =m=, =n= and =p= for the menu actions, =q= and =k= to kill the splash, and =<escape>= to bury it. =S-<arrow>= moves the current art layer, =TAB= picks the next layer, =0= resets the layers and =s= shows them.

#+begin_src emacs-lisp -i
;;;; Define Minor Mode
;; Custom splash screen
(defvar sp-splash-mode-map
  (let ((map (make-sparse-keymap)))
    (define-key map (kbd "a") 'sp-splash-open-agenda)
    (define-key map (kbd "c") 'sp-splash-open-config)
    (define-key map (kbd "m") 'sp-splash-open-email)
    (define-key map (kbd "n") 'sp-splash-open-notes)
    (define-key map (kbd "p") 'sp-splash-open-project)
    (define-key map (kbd "S-<left>") 'sp-splash-art-left)
    (define-key map (kbd "S-<right>") 'sp-splash-art-right)
    (define-key map (kbd "S-<up>") 'sp-splash-art-up)
    (define-key map (kbd "S-<down>") 'sp-splash-art-down)
    (define-key map (kbd "TAB") 'sp-splash-art-next-layer)
    (define-key map (kbd "0") 'sp-splash-art-reset)
    (define-key map (kbd "s") 'sp-splash-art-show-position)
    (define-key map (kbd "q") 'sp-splash-screen-kill)
    (define-key map (kbd "<escape>") 'sp-splash-screen-bury)
    (define-key map (kbd "k") 'sp-splash-screen-kill)
    map)
  "Keymap for sp-splash-mode.")
#+end_src

** Minor mode

=sp-splash-mode= is a buffer-local minor mode that makes the splash look clean: it disables undo, auto-revert, whitespace mode and line numbers, makes the buffer read-only, hides the cursor, mode line and header line, and removes margins and fringes. It also sets the global =inhibit-startup-screen= family of variables and =truncate-lines=. When Evil is active it switches to Emacs state so the single-key bindings are not shadowed. Its =:group= is =sp-splash=; it used to be =sia-lambda=, which this config never defines.

#+begin_src emacs-lisp -i
(define-minor-mode sp-splash-mode
  "Emacs minor mode for splash screen."
  :global nil
  :keymap sp-splash-mode-map
  :group 'sp-splash
  
  :require 'sp-splash
  (buffer-disable-undo)
  (auto-revert-mode -1)
  (whitespace-mode -1)
  (when (fboundp 'linum-mode)
    (linum-mode -1))
  (when (>= emacs-major-version 26)
    (display-line-numbers-mode -1))
  
  (setq-local buffer-read-only t)
  (setq-local cursor-type nil)
  (setq-local hl-line-mode -1)
  (setq-local mode-line-format nil)
  (setq-local header-line-format nil)
  
  ;; No margin or fringe in splash buffer
  (setq-local left-margin-width nil
              right-margin-width nil)
  (set-window-fringes (selected-window) 0 0 nil)
  (setq inhibit-startup-screen t
        truncate-lines nil
        inhibit-startup-message t
        inhibit-startup-echo-area-message t)
  
  ;; Use Emacs state if Evil is active so single-key bindings work
  (when (bound-and-true-p evil-mode)
    (evil-emacs-state))
  (goto-char (point-min)))
#+end_src

* Setup and refresh

** Refresh

=sp-splash-refresh= rebuilds the splash when the current buffer is =Dashboard=, by killing it and calling =sp-splash-screen= again so it is re-centred for the new window size. It always uses the graphical renderer and swallows errors.

#+begin_src emacs-lisp -i
;;;; Splash Setup & Refresh Functions
(defun sp-splash-refresh ()
  "Refresh & recenter splash after window switch."
  (interactive)
  (when (string= (buffer-name) "Dashboard")
    (progn
      (ignore-errors
        (sp-splash-screen-kill)
        (sp-splash-screen)))))
#+end_src

** Initial display and hooks

=sp-splash--setup-splash-hooks= shows the graphical or terminal splash depending on =display-graphic-p=, then adds =sp-splash-refresh= to =window-state-change-hook=, =window-configuration-change-hook= and =sp-switch-buffer-hook= so the splash redraws when windows change.

#+begin_src emacs-lisp -i
(defun sp-splash--setup-splash-hooks ()
  "Initialize splash and setup hooks."
  (progn
    (if (display-graphic-p)
        (sp-splash-screen)
      (sp-splash-terminal))
    (add-hook 'window-state-change-hook #'sp-splash-refresh)
    (add-hook 'window-configuration-change-hook  #'sp-splash-refresh)
    (add-hook 'sp-switch-buffer-hook #'sp-splash-refresh)))
#+end_src

** Install on startup

Adds the setup function to =window-setup-hook=, which runs after the frame parameters are applied, unless Emacs was started with =--no-splash=, =--file=, =--insert= or =--find-file=. A plain filename argument is not checked here.

#+begin_src emacs-lisp -i
;; Install hook after frame parameters have been applied and only if
;; no option on the command line
(when (and (not (member "--no-splash" command-line-args))
           (not (member "--file"      command-line-args))
           (not (member "--insert"    command-line-args))
           (not (member "--find-file" command-line-args)))
  (add-hook 'window-setup-hook #'sp-splash--setup-splash-hooks))
#+end_src
