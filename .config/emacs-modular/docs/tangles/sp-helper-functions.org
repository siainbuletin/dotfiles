* Getting rid of customization via =M-x= menu

This will eliminate the =custom-file= which is created if you try to configure Emacs through the interactive menu.

In the event that I mistakenly call =M-x customize= to change something in my Emacs, this function makes sure that the file never actually appends to the =init.el=. (Afterall, it will get overwritten anyway once I run =org-babel-tangle= again.)

By using the =make-temp-file= function, the file will be placed in the =/tmp= directory[fn:1]

The function is taken from Protesilaos' configuration

#+begin_src emacs-lisp :tangle no :eval never
  (setq custom-file (make-temp-file "emacs-custom-"))
#+end_src

I basically need to handle three commands with just one:

1. =org-export-to-org=.
2. Switch over to =temp.org= as the buffer that's being evaluated. Maybe the temp file could be loaded into memory, or into =/tmp=, just to get this configuration working.
3. =org-babel-execute-block= for executing all of the blocks in the =temp.org=. (I have already fixed the part about going through all of the checking for each execution of each code block within the buffer.)
4. =org-babel-tangle= for the actual tangling process.

Since it's not a good idea to use a lambda (anonymous function) to call the multiple different functions within a single keybinding, it is a better idea to define my own function.

The lambda would look like this:

#+begin_example emacs-lisp
(global-set-key (kbd "C-c a b c") (lambda () (interactive) (some-command) (some-other-command)))
#+end_example

I recommend never binding lambda expressions to keys, for the simple reason that when you ask Emacs what that key does, it will end up telling you something like this (to use the accepted code, when byte-compiled, as an example):

function.

It is bound to C-c a b c.

* Configuring integration with shell tools

See notes on [[denote:20251119T222358][dwim-shell-command]] and the more general [[denote:20251119T222058][Interfacing with Emacs from outside of it]].

#+begin_quote
Alternatively, can also install via use-package, define your own commands and remap to shell-command’s existing binding.
#+end_quote

#+begin_src emacs-lisp :tangle "init.el" :eval never
(use-package dwim-shell-command
  :ensure t
  :bind (([remap shell-command] . dwim-shell-command)
         :map dired-mode-map
         ([remap dired-do-async-shell-command] . dwim-shell-command)
         ([remap dired-do-shell-command] . dwim-shell-command)
         ([remap dired-smart-shell-command] . dwim-shell-command)))
#+end_src

* Templating

Yasnippet makes boiler plate and other code snippets much faster to write with snippets that activates with small keywords. Just type the keyword and TAB, and yasnippet will fill in the snippet :) (you may have to fill in some names like class name or parameter names after TAB off course…).[fn:2]

  :after yasnippet)

#+begin_src emacs-lisp :tangle "init.el" :eval never
  (defun sia-clean-whitespace (&optional Begin End)
    "Delete trailing whitespace, and replace repeated blank lines to just 1.
  Only space and tab is considered whitespace here.
  Works on whole buffer or selection, respects `narrow-to-region'.

  URL `http://xahlee.info/emacs/emacs/elisp_compact_empty_lines.html'
  Created: 2017-09-22
  Version: 2025-05-04"
    (interactive)
    (let (xbeg xend)
      (seq-setq (xbeg xend)
                (if (and Begin End)
                    (list Begin End)
                  (if (region-active-p)
                      (list (region-beginning) (region-end))
                    (list (point-min) (point-max)))))
      (save-excursion
        (save-restriction
          (narrow-to-region xbeg xend)
          (progn
            (goto-char (point-min))
            (while (re-search-forward "[ \t]+\n" nil t) (replace-match "\n")))
          (progn
            (goto-char (point-min))
            (while (re-search-forward "\n\n\n+" nil t) (replace-match "\n\n")))
          (progn
            (goto-char (point-max))
            (while (eq (char-before) 32) (delete-char -1))))))
    (message "done xah-clean-whitespace"))
#+end_src

This will add a hook to always clean the whitespace after a save

#+begin_src emacs-lisp :tangle "init.el" :eval never
  (add-hook 'before-save-hook 'sia-clean-whitespace)
#+end_src
