The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module sets up =vulpea=, a library and database layer for Org-based notes (an alternative to org-roam), together with =vui=, the UI component library used by other Vulpea modules such as =sp-vulpea-vui-table=. It is required from =sp-org-ext=, and the further Vulpea extensions live in =sp-vulpea-ext=.

It configures which directories are indexed, how notes are displayed in the minibuffer, which property stores aliases, and how new note files are named. Several settings are given twice (once in =use-package= and once with a plain =setq=), and the plain =setq= forms run at load time, so they win.

** vulpea

Installs =vulpea= and waits for it to finish so later code can call its functions immediately. The empty =:init= only carries a comment copied from Doom-oriented documentation about =org-directory=. =vulpea-db-sync-directories= is set to =~/notes/= plus the Emacs configuration directory.

Keybindings: ~M-o f~ runs =vulpea-find= globally, and ~M-o n a~ in Org buffers runs =vulpea-buffer-alias-add= to add an alias to the current note.

#+begin_src emacs-lisp -i
(use-package vulpea
  :ensure (:wait t)

  :init
  ;; Vulpea derives its defaults from `org-directory'. Doom's :lang org
  ;; module sets it to ~/org/ - override here if your notes live elsewhere,
  ;; or set `vulpea-db-sync-directories' explicitly.
  
  :custom
  (vulpea-db-sync-directories (list "~/notes/" user-emacs-directory))

  :bind
  (("M-o f" . vulpea-find)
   :map org-mode-map
   ("M-o n a" . vulpea-buffer-alias-add))
)
#+end_src

* Database settings

** Synced directories (override)

Sets =vulpea-db-sync-directories= again, this time to =~/notes/= only. Because this =setq= runs after the =:custom= value above, the Emacs config directory is in practice no longer indexed. It is unclear which of the two is intended.

#+begin_src emacs-lisp -i
(setq vulpea-db-sync-directories '("~/notes/"))
#+end_src

** Parse method

=single-temp-buffer= makes Vulpea parse files by reusing one temporary buffer, which is faster than visiting each file normally.

#+begin_src emacs-lisp -i
(setq vulpea-db-parse-method 'single-temp-buffer)
#+end_src

** Automatic database sync

Turns on =vulpea-db-autosync-mode=, which keeps the database updated as note files change.

#+begin_src emacs-lisp -i
(vulpea-db-autosync-mode +1)
#+end_src

** Alias property

Stores aliases in the =ROAM_ALIASES= property instead of Vulpea's default =ALIASES=, which keeps notes compatible with org-roam.

#+begin_src emacs-lisp -i
(setq vulpea-buffer-alias-property "ROAM_ALIASES") ;; By default, aliases are stored in ALIASES. To use ROAM_ALIASES for org-roam compatibility:
#+end_src

** Sample query

Runs =vulpea-db-query-by-tags-every= for notes tagged both project and active. The result is discarded, so this line has no effect beyond executing the query at load time. It looks like an example left in from the documentation.

#+begin_src emacs-lisp -i
(vulpea-db-query-by-tags-every '("project" "active")) ;; Query all active projects
#+end_src

* Minibuffer display

** Describing notes

=vulpea-select-describe-outline-full= shows each candidate with its full outline path, such as My Notes, then Projects, then Task.

#+begin_src emacs-lisp -i
;; Configuring the display of notes in the minibuffer
;; "My Notes → Projects → Task"
(setq vulpea-select-describe-fn #'vulpea-select-describe-outline-full)
#+end_src

** Annotating notes

Uses the default =vulpea-select-annotate=, which shows the primary title and tags next to each candidate.

#+begin_src emacs-lisp -i
;; Default annotation: "(primary title) #tag1 #tag2"
(setq vulpea-select-annotate-fn #'vulpea-select-annotate)
#+end_src

* Templating for new notes

** Default note creation

=vulpea-create-default-function= decides the file name and tags for a new note. Files are named with a timestamp followed by a slug of the title. If the title contains the string TODO the note gets the tag task, otherwise note.

#+begin_src emacs-lisp -i
;; Templating for Vulpea

(setq vulpea-create-default-function
      (lambda (title)
        (list :file-name (format "%s_%s.org"
                                 (format-time-string "%Y%m%d%H%M%S")
                                 (vulpea-title-to-slug title))
              :tags (if (string-match-p "TODO" title)
                        '("task")
                      '("note")))))
#+end_src
