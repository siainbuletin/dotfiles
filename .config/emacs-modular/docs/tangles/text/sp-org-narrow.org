Commands that make it easier to work in long Org (and Markdown) buffers by narrowing:

- a do-what-I-mean narrow/widen toggle,
- commands to step to the next or previous sibling subtree while staying narrowed,
- a command that opens an indirect clone of the buffer narrowed to the current element.

Loaded in both the default and minimal module lists in =init.el=.

The commentary notes a future goal of making the =vulpea-ui= sidebar follow the narrowing so it shows only the narrowed context.

* Narrow or widen

** The do-what-I-mean toggle

=sp-narrow-or-widen-dwim= widens if the buffer is already narrowed. Otherwise it narrows to the most specific thing that applies:

- the active region;
- in Org: the source block at point (by opening =org-edit-src-code= in a full-frame window), else the block at point, else the current subtree;
- in Markdown: the subtree;
- in LaTeX: the current environment;
- anywhere else: the current defun.

With a prefix argument it always narrows, even inside an already narrowed buffer, which allows nested narrowing. This is the well-known command from Artur Malabarba's blog.

#+begin_src emacs-lisp -i
(defun sp-narrow-or-widen-dwim (p)
  "Widen if buffer is narrowed, narrow-dwim otherwise.
  Dwim means: region, org-src-block, org-subtree, markdown
  subtree, or defun, whichever applies first. Narrowing to
  org-src-block actually calls `org-edit-src-code'.

  With prefix P, don't widen, just narrow even if buffer
  is already narrowed."
  (declare (interactive-only t))
  (interactive "P")
  (cond ((and (buffer-narrowed-p) (not p)) (widen))
        ((region-active-p)
         (narrow-to-region (region-beginning)
                           (region-end)))
        ((derived-mode-p 'org-mode)
         ;; `org-edit-src-code' is not a real narrowing
         ;; command. Remove this first conditional if
         ;; you don't want it.
         (cond ((ignore-errors (org-edit-src-code) t)
                (delete-other-windows))
               ((ignore-errors (org-narrow-to-block) t))
               (t (org-narrow-to-subtree))))
        ((derived-mode-p 'markdown-mode)
         (markdown-narrow-to-subtree))
        ((derived-mode-p 'latex-mode)
         (LaTeX-narrow-to-environment))
        (t (narrow-to-defun))))
#+end_src

** Keybinding

Binds the toggle to =C-x n n= with =bind-key*=, replacing the stock =narrow-to-region= binding and winning in every mode, since =bind-key*= uses the override map. The trailing =narrow-map= is not a target keymap here: =bind-key*= takes its third argument as a predicate, and because the keymap is always non-nil the binding is simply always active.

#+begin_src emacs-lisp -i
;;bind this in the narrow keymap
(bind-key* "C-x n n" #'sp-narrow-or-widen-dwim narrow-map)
#+end_src

* Stepping between subtrees

** Advance to the next sibling

=sp-org-advance= widens (if narrowed), jumps to the next heading at the same level, and narrows to that subtree.

- Repeated calls walk through siblings one at a time.
- It has no keybinding in this module.

#+begin_src emacs-lisp -i
;;;;; Narrow & Advance/Retreat
;; Functions to advance forwards or backwards through narrowed tree
(defun sp-org-advance ()
  (interactive)
  (when (buffer-narrowed-p)
    (goto-char (point-min))
    (widen)
    (org-forward-heading-same-level 1))
  (org-narrow-to-subtree))
#+end_src

** Retreat to the previous sibling

=sp-org-retreat= is the mirror image, moving to the previous sibling and narrowing to it.

#+begin_src emacs-lisp -i
(defun sp-org-retreat ()
  (interactive)
  (when (buffer-narrowed-p)
    (goto-char (point-min))
    (widen)
    (org-backward-heading-same-level 1))
  (org-narrow-to-subtree))
#+end_src

* Clone and narrow

** Indirect clone narrowed to the element

=sp-clone-buffer-and-narrow= creates an indirect buffer in another window, so edits are shared with the original, and narrows it.

- In Org it narrows to the element at point via =org-narrow-to-element=. In Markdown, to the subtree.
- This lets you focus on one part of a file while keeping the full view open.
- The final =switch-to-buffer-other-window= may open a further window, since the clone is already shown in one.

#+begin_src emacs-lisp -i
;;;;; Clone and Narrow
(defun sp-clone-buffer-and-narrow ()
  "Clone buffer and narrow outline tree"
  (interactive)
  (let ((buf (clone-indirect-buffer-other-window nil nil)))
    (with-current-buffer buf
      (cond ((derived-mode-p 'org-mode)
             (org-narrow-to-element))
            ((derived-mode-p 'markdown-mode)
             (markdown-narrow-to-subtree))))
    (switch-to-buffer-other-window buf)))
#+end_src
