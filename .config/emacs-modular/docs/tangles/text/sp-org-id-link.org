The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module gathers everything about Org IDs and links. It configures the built-in =org-id= library so that links to headings use stable timestamp IDs stored in the cache directory, and adds four link helpers: one that repairs old percent-escaped link syntax, one that copies the Org link at point, one that replaces a link with its description, and one that inserts a link to a configuration doc.

It depends only on Org and on =sp-cache-dir= from =early-init.el=. The module is loaded in the Org block of the default module list in =init.el= (it is not in the minimal list).

* Org IDs

** Org-id settings

After Org loads, =org-id= stores its locations file as =.org-id-locations= in =sp-cache-dir=, keeping the config directory tidy. New IDs are generated from timestamps rather than random UUIDs, and =org-store-link= creates an ID for a heading when called interactively, so stored links point at the ID rather than at the heading text.

#+begin_src emacs-lisp -i
;;;; Org ID
;; Use org ids for reference
(use-package org-id
  :ensure nil
  :after org
  :custom
  (org-id-locations-file (concat sp-cache-dir ".org-id-locations")) ;; this keeps in line with the no-littering principle
  (org-id-method 'ts) ;; use timestamp for id
  (org-id-link-to-org-use-id 'create-if-interactive)) ;; create ids
#+end_src

* Link helpers

** Update link syntax and copy a link

=org-update-link-syntax= has the same name as a function that ships with Org, so this copy replaces Org's own version once the module loads.

- It scans the buffer for bracket links containing old percent escapes (spaces and square brackets).
- It asks for each one, unless given a prefix argument.
- It rewrites the URI using the current escaping rules.

=lem-org-link-copy-at-point=, from an Emacs Stack Exchange answer, searches backward for =[[= and forward for a complete bracket link, then puts the whole link text on the kill ring. Because the backward search starts from point, running it when point is not on a link copies the nearest earlier one.

#+begin_src emacs-lisp -i
;;;;; Org link Syntax
(defun org-update-link-syntax (&optional no-query)
  "Update syntax for links in current buffer.
Query before replacing a link, unless optional argument NO-QUERY
is non-nil."
  (interactive "P")
  (org-with-point-at 1
    (let ((case-fold-search t))
      (while (re-search-forward "\\[\\[[^]]*?%\\(?:2[05]\\|5[BD]\\)" nil t)
        (let ((object (save-match-data (org-element-context))))
          (when (and (eq 'link (org-element-type object))
                     (= (match-beginning 0)
                        (org-element-property :begin object)))
            (goto-char (org-element-property :end object))
            (let* ((uri-start (+ 2 (match-beginning 0)))
                   (uri-end (save-excursion
                              (goto-char uri-start)
                              (re-search-forward "\\][][]" nil t)
                              (match-beginning 0)))
                   (uri (buffer-substring-no-properties uri-start uri-end)))
              (when (or no-query
                        (y-or-n-p
                         (format "Possibly obsolete URI syntax: %S.  Fix? "
                                 uri)))
                (setf (buffer-substring uri-start uri-end)
                      (org-link-escape (org-link-decode uri)))))))))))

;;;;; Org Copy Link
;; see https://emacs.stackexchange.com/a/63038/11934
(defun lem-org-link-copy-at-point ()
  (interactive)
  (save-excursion
    (let* ((ol-regex "\\[\\[.*?:.*?\\]\\(\\[.*?\\]\\)?\\]")
           (beg (re-search-backward "\\[\\["))
           (end (re-search-forward ol-regex))
           (link-string (buffer-substring-no-properties (match-beginning 0) (match-end 0))))
      (kill-new link-string)
      (message "Org link %s is copied." link-string))))
#+end_src

** Replace a link with its description

=lem-org-replace-link-by-link-description= removes the bracket link at point and leaves its description, or its address when there is no description. It uses =org-match-string-no-properties=, an obsolete Org alias that recent Org versions may no longer provide.

#+begin_src emacs-lisp -i
;;;;; Remove Org Links
;; https://emacs.stackexchange.com/a/10714/11934
(defun lem-org-replace-link-by-link-description ()
  "Replace an org link by its description or, if empty, its address"
  (interactive)
  (if (org-in-regexp org-link-bracket-re 1)
      (save-excursion
        (let ((remove (list (match-beginning 0) (match-end 0)))
              (description
               (if (match-end 2)
                   (org-match-string-no-properties 2)
                 (org-match-string-no-properties 1))))
          (apply 'delete-region remove)
          (insert description)))))
#+end_src

** Link to the configuration docs

=sp-org-insert-config-doc-link= inserts at point an Org link to one of the docs of this configuration (the literate files under =docs/tangles/= and the architecture notes), from a regular note outside the configuration.

- The file is chosen with =sp-find-file-pick=, the fuzzy search of =sp-find-file= (=find=, =fd= or =rg=) run in =sp-config-docs-directory= (=docs/= next to =init.el= by default) and limited to =.org= files.
- The link is a =file:= link with the path abbreviated to =~/=, so it works wherever the home directory is. The docs have no =:ID:=, and an =id:= link would need them in the vulpea database, which this command avoids on purpose.
- The description is the =#+title= of the file (read from its first 4096 bytes by =sp-org-doc-title=), or its name without extension when there is none. With a prefix argument it asks for the description, offering the title.
- It is bound to =C-c l c= in Org mode, next to =C-c l d=, in =sp-org-base=, which autoloads it from this module.

#+begin_src emacs-lisp -i
;;;;; Link to the configuration docs
;; Plain `file:' links, so the docs stay out of the vulpea database.
(declare-function sp-find-file-pick "sp-navi")

(defcustom sp-config-docs-directory (expand-file-name "docs/" sp-load-path)
  "Directory holding the literate and architecture docs of this configuration."
  :type 'directory)

(defun sp-org-doc-title (file)
  "Return the #+title of the Org FILE, or nil if it has none."
  (with-temp-buffer
    (insert-file-contents file nil 0 4096)
    (let ((case-fold-search t))
      (when (re-search-forward "^#\\+title:[ \t]*\\(.+?\\)[ \t]*$" nil t)
        (match-string 1)))))

(defun sp-org-insert-config-doc-link (&optional edit-description)
  "Insert an Org link to a file of the configuration docs at point.
Pick the file with the fuzzy search of `sp-find-file', restricted to the
Org files under `sp-config-docs-directory'.  The description is the
#+title of the file, or its name without extension when it has none.
With a prefix argument EDIT-DESCRIPTION, ask for the description."
  (interactive "P")
  (require 'sp-navi)
  (unless (file-directory-p sp-config-docs-directory)
    (user-error "No docs directory at %s" sp-config-docs-directory))
  (when-let* ((file (sp-find-file-pick sp-config-docs-directory "\\.org\\'")))
    (let* ((title (or (sp-org-doc-title file) (file-name-base file)))
           (description (if edit-description
                            (read-string "Description: " title)
                          title)))
      (insert (org-link-make-string
               (concat "file:" (abbreviate-file-name file))
               description)))))
#+end_src
