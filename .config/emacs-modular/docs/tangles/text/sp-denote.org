The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

Configuration for Protesilaos Stavrou's =denote= package, which names note files with a timestamp, title and keywords. It sets Org as the file type, adds keybindings under =M-n= and =C-c w d=, enables Denote's Dired and buffer-renaming integrations, keeps notes in =~/notes/=, and adds a small mechanism that puts any Denote note tagged =project= into =org-agenda-files= when saved.

The commentary says this module will be phased out in favour of the ID-based Vulpea workflow, since the long Denote file names are hard to read and are not used for anything. It is still loaded in both module lists in =init.el=, directly after =sp-org-base=.

* Denote package

** use-package denote

Installs =denote= unconditionally and loads it lazily on =denote=, =denote-create-note= and =denote-link-ol-store=. Once loaded it turns on =denote-rename-buffer-mode=, which renames note buffers to their titles.

Options: dates are prompted with Org's calendar reader, notes are Org files, multi-word keywords are allowed, keywords are sorted, renaming asks for confirmation only before changing the file name and adding front matter, and new notes prompt only for title and keywords. =denote-dired-mode= is enabled in Dired to fontify Denote file names.

Keybindings:
- Global: =M-n c= open or create a note, =M-n r= rename a file, =M-n f= rename from front matter.
- In text modes: =M-n I= insert links to notes matching a regexp.
- In Dired: =C-c C-d C-i= link marked notes, =C-c C-d C-r= rename marked files, plus a block under =C-c w d= (backlinks, date note, find link, link or create, rename keywords) borrowed from the Emacs Writing Studio config. Because those last five sit under =:map dired-mode-map=, they only work in Dired, which may not be what was intended.

#+begin_src emacs-lisp -i
(use-package denote
  :ensure t
  ;; :if (locate-library "denote")
  :commands (denote denote-create-note denote-link-ol-store)
  
  :config
  (denote-rename-buffer-mode)

  :custom
  ;; Use org-read-date
  (denote-date-prompt-use-org-read-date t)
  (denote-file-type 'org) ;; use org
  (denote-allow-multi-word-keywords t)
  (denote-rename-confirmations '(modify-file-name add-front-matter))
  (denote-sort-keywords t)

  ;; Set default prompts for note creation
  (denote-prompts '(title keywords))
  
  :hook
  (dired-mode . denote-dired-mode)

  :bind
  (:map global-map
      ("M-n c" . denote-open-or-create)
      ("M-n r" . denote-rename-file)
      ("M-n f" . denote-rename-file-using-front-matter)

      :map text-mode-map
      ("M-n I" . denote-add-links)

      :map dired-mode-map
      ("C-c C-d C-i" . denote-link-dired-marked-notes)
      ("C-c C-d C-r" . denote-dired-rename-marked-files)

      ;; these are copied directly from the Emacs Writing Studio configuration
      ("C-c w d b" . denote-find-backlink)
      ("C-c w d d" . denote-date)
      ("C-c w d l" . denote-find-link)
      ("C-c w d i" . denote-link-or-create)
      ("C-c w d k" . denote-rename-file-keywords)))
#+end_src

* Denote projects in the agenda

** Agenda filename pattern

=my-denote-to-agenda-regexp= is the pattern a note's file name must match to be added to the agenda. The default =_project= matches notes carrying the =project= keyword.

#+begin_src emacs-lisp -i
(defvar my-denote-to-agenda-regexp "_project"
  "Denote file names that are added to the agenda.
See `my-add-denote-to-agenda'.")
#+end_src

** Adding the current note to the agenda

=my-denote-add-to-agenda= checks that the current buffer visits a Denote note whose name matches the pattern and, if so, adds it to =org-agenda-files=. It can be called interactively. The change is in memory only, so it lasts for the session unless the agenda file list is saved elsewhere.

#+begin_src emacs-lisp -i
(defun my-denote-add-to-agenda ()
  "Add current file to the `org-agenda-files', if needed.
The file's name must match the `my-denote-to-agenda-regexp'.

Add this to the `after-save-hook' or call it interactively."
  (interactive)
  (when-let* ((file (buffer-file-name))
              ((denote-file-is-note-p file))
              ((string-match-p my-denote-to-agenda-regexp (buffer-file-name))))
    (add-to-list 'org-agenda-files file)))
#+end_src

** Running it on every save

Adds =my-denote-add-to-agenda= to the global =after-save-hook=, so saving a project note registers it automatically.

#+begin_src emacs-lisp -i
;; This will add the file automatically
(add-hook 'after-save-hook #'my-denote-add-to-agenda)
#+end_src

** Removing the current note from the agenda

=my-denote-remove-from-agenda= is the interactive counterpart, deleting the current file from =org-agenda-files= if its name matches the pattern.

#+begin_src emacs-lisp -i
(defun my-denote-remove-from-agenda ()
  "Remove current file from the `org-agenda-files'.
See `my-denote-add-to-agenda' for how to add files to the Org
agenda."
  (interactive)
  (when-let* ((file (buffer-file-name))
              ((string-match-p my-denote-to-agenda-regexp (buffer-file-name))))
    (setq org-agenda-files (delete file org-agenda-files))))
#+end_src
