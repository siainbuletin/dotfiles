This module collects Org packages for time tracking and scheduling: =org-pomodoro= for pomodoro timers on clocked tasks, =org-auto-scheduler= from GitHub, and =org-focus-hud=, which shows the clocked task and its checklist in a heads-up display.

No module list in =init.el= and no other module loads it, so these packages are currently inactive. The file ends with =(provide 'sp-org-time)=, so =(require 'sp-org-time)= works once it is added to a module list.

* Time tracking packages

** Org pomodoro

When extras are enabled and the package is installed, =org-pomodoro= is made available as a command, using macOS =afplay= to play its sounds. The comment trails off asking how best to trigger it; no key binding is set.

#+begin_src emacs-lisp -i
;;;; Org Pomodoro
;; Helps with time tracking
;; But how exactly can you trigger this we
(use-package org-pomodoro
  :if (locate-library "org-pomodoro")
  :commands org-pomodoro
  :init
  (progn
    (setq org-pomodoro-audio-player "/usr/bin/afplay")))
#+end_src

** Focus HUD

Configures =org-focus-hud=, bound globally to =C-c f=. Its display refreshes every 15 seconds and follows whichever task is newly clocked in. The comment says it plugs into org-auto-scheduler and covers checklist focus. There is no =:ensure= or availability check, so loading the module without the package installed would depend on the package manager's defaults.

#+begin_src emacs-lisp -i
;; Includes focus for checklists - plugs into org-auto-scheduler
(use-package org-focus-hud
  :bind ("C-c f" . org-focus-hud)
  :config
  ;; Optional: Customize refresh interval in seconds
  (setq org-focus-hud-refresh-interval 15)
  ;; Automatically follow newly clocked tasks (default t)
  (setq org-focus-hud-follow-active-clock t))
#+end_src
