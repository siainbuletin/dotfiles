The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module is the hub for Org extensions. Its first job is to load a group of other Org modules with =require=:

- appearance, capture, Babel, agenda, images,
- the =org-node= memory workflow,
- the Vulpea note database modules (base, UI, PARA, schemas and extensions, then my =sp-collection-query-tables= modules).

So loading =sp-org-ext= pulls in several modules that do not appear in the module lists themselves, such as =sp-org-babel=, =sp-org-images= and all of the =sp-vulpea-= files.

Its second job is to install a handful of smaller Org packages:

- =org-contrib= (for ignoring headlines on export),
- =org-autolist=,
- =org-journal=,
- =org-ranker=,
- =org-special-block-extras=,
- two local =org-context= libraries from the =cloned= directory.

Loading:

- Loaded near the end of the Org group in both the default and minimal module lists.
- Citation setup lives elsewhere, as the opening note says.

* Other Org packages

** org-contrib

After Org loads, =ox-extra= is required and its =ignore-headlines= extra is activated, so headings tagged =:ignore:= are dropped on export while their contents are kept.

#+begin_src emacs-lisp -i
;;;;; Other extensions

;;;; Org Contrib
(use-package org-contrib
  :ensure t
  :after org
  :config
  ;; ignore export of headlines marked with :ignore: tag
  (require 'ox-extra)
  (ox-extras-activate '(ignore-headlines)))
#+end_src

** org-journal

=org-journal=:

- Keeps dated journal files in =~/org/journal= with ISO dates.
- Shows them in the agenda.
- Carries unfinished =TODO=, =WAITING= and =DOING= items over to the next day.
- =C-M-S-i= creates a new entry.
- =C-M-S-j= calls =org-journal-new-entry= with a third argument set. The intent is inferred to be a variant such as opening the journal without a new entry. Whether it works depends on the installed org-journal version's signature.

#+begin_src emacs-lisp -i
(use-package org-journal
  :ensure t
  :defer t
  :bind
  (("C-M-S-j" . (lambda () (interactive) (org-journal-new-entry nil nil t)))
   ("C-M-S-i" . (lambda () (interactive) (org-journal-new-entry nil))))
  :init
  (setq org-journal-dir (sp-path sp-org-dir "journal")
        org-journal-date-format "%Y-%m-%d"
        org-journal-enable-agenda-integration t
        org-journal-carryover-items "TODO={TODO\\|WAITING\\|DOING}"))
#+end_src

** org-context
