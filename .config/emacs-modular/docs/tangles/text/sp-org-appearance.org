Literate source for =libraries/modules/text/sp-org-appearance.el=.

- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../tangling-instructions.org][Tangling instructions]].

This module sets the visual presentation of Org buffers:

- folding and ellipsis,
- startup visibility,
- inline images,
- entity and emphasis display,
- tag placement,
- source block fontification.

It also brings in:

- =org-modern= for styled headings and agenda,
- =org-autolist= and =org-bulletproof= for list behaviour,
- a strike-through face for finished checkboxes,
- =spacious-padding= for roomier frames.

Fonts and loading:

- Fonts are deliberately not set here. The commentary points to =sp-fonts= for that.
- The settings are plain =setq= forms that take effect when Org loads.
- Packages are installed through the config's package manager (the =:ensure= forms with =:wait= are Elpaca style).
- The module is loaded in the Org block of both module lists in =init.el=, after =sp-org-base= and =sp-denote=.

* Basic Org appearance

** Folding and ellipsis

Removes blank separator lines in folded views, shows folded content as a =[+]= marker instead of the default ellipsis (other symbols are left in a comment), and gives quote and verse blocks their own fontification.

#+begin_src emacs-lisp -i
;;;; General org basic appearance options
;;;; these were taken initially from Lambda Emacs
(setq org-cycle-separator-lines 0) ;; no empty lines in collapsed view
;; (setq org-ellipsis "…") ;; nicer elipses "↷" "↴" "▼"
(setq org-ellipsis " [+]")
(setq org-fontify-quote-and-verse-blocks t) ;; make quotes stand out
#+end_src

** Leading stars

Hides all but the last star of each heading, so nested headings look indented without the clutter.

#+begin_src emacs-lisp -i
(setq org-hide-leading-stars t)  ;; hide leading stars
#+end_src

** Dates and startup visibility

When a date is entered without a year or time, =org-read-date= assumes the future, including later times today. Files open in content view, showing every heading but no body text.

#+begin_src emacs-lisp -i
(setq org-read-date-prefer-future 'time) ;; Incomplete dates refer to future dates & times
(setq org-startup-folded 'content) ;; Show the content when starting up
#+end_src

** Inline images

Displays inline images at 500 pixels wide and shows them automatically when a file opens.

#+begin_src emacs-lisp -i
;;;;; Working with inline images
(setq org-image-actual-width  500) ;; show all images at 500px using imagemagik
(setq org-startup-with-inline-images t)
#+end_src

** Pretty entities

Displays entities such as =\alpha= and subscript or superscript markup as the actual characters.

#+begin_src emacs-lisp -i
;;;;; Prettify
(setq org-pretty-entities t) ;; make latex look good, etc.
(setq org-pretty-entities-include-sub-superscripts t) ;; prettify sub/superscripts
#+end_src

** Tags

Turns off automatic tag alignment and sets the tag column to 0, so tags sit right after the heading text instead of being pushed to the right margin.

#+begin_src emacs-lisp -i
;;;;; Tags
(setq org-auto-align-tags nil) ;; don't auto-align tags
(setq org-tags-column 0) ;; place tags directly next to headline text
#+end_src

** Source and quote fontification

Fontifies source blocks with their language's major mode. The quote and verse setting is repeated from above.

#+begin_src emacs-lisp -i
;;;;; Fontification
(setq org-src-fontify-natively t)
(setq org-fontify-quote-and-verse-blocks t)
#+end_src

** org-appear

Enables =org-appear= in Org buffers.

- It reveals emphasis markers and sub and superscript markup while point is on them. =org-appear-autoemphasis= and =org-appear-autosubmarkers= are on; =org-appear-autolinks= is off.
- It had been commented out because it was suspected of causing problems with invisible text. It is now back on.
- =org-hide-emphasis-markers= is not set, so emphasis markers are always visible and there is nothing for it to reveal there.
- It matters for sub and superscripts only, since =org-appear-autolinks= is off.

#+begin_src emacs-lisp -i
;; show markup at point -- this should be part of org!
(use-package org-appear
  :ensure (:wait t)
  :after org

  :hook (org-mode . org-appear-mode)

  :custom
  (org-appear-autoemphasis  t)
  (org-appear-autolinks nil)
  (org-appear-autosubmarkers t))
#+end_src

* Org-modern

** Org-modern setup

Enables =org-modern-mode= in Org buffers and =org-modern-agenda= when an agenda is built.

- Its TODO keyword and tag styling are turned off.
- Labels get a one pixel border.
- Heading stars are replaced with a sequence of circled and starred symbols, one per level.
- Hiding leading stars through org-modern is commented out because of the same invisible text issues.

#+begin_src emacs-lisp -i
;;;;; Org-modern
(use-package org-modern
  :ensure t
  :defer t
  :hook ((org-mode . org-modern-mode)
         (org-agenda-finalize . org-modern-agenda))

  :custom
  ;; (org-modern-hide-stars 'leading) ;; this causes issues with the invisible region -- this should be fixed at some point
  (org-modern-todo nil)
  (org-modern-tag nil)

  ;; Customize this per your font
  (org-modern-label-border 1)
  ;; Note that these stars allow differentiation of levels
  ;; "①" "②" "③" "④" "⑤" "⑥" "⑦"
  ;; Modify these levels so they don't actually show the numbers (that's bad)
  (org-modern-star 'replace)
  (org-modern-replace-stars "⦶⦷⦹⊕⍟⊛⏣❂"))
#+end_src

* List behaviour

** Org-autolist

Installs =org-autolist=, which makes RET and backspace behave like a word processor in lists: RET starts a new item and backspace on an empty item removes the bullet. It is installed but no hook enables =org-autolist-mode= in this module, so it may be turned on elsewhere or not at all. (It is: =sp-org-ext= adds the Org hook, without installing the package again.)

#+begin_src emacs-lisp -i
;;;;; List behavior
(use-package org-autolist
  :ensure t)
#+end_src

** Org-bulletproof

Installs =org-bulletproof=, waiting for it to finish installing, and enables =global-org-bulletproof-mode= after Org and org-modern. No options are set, so the package defaults apply; judging by its name it manages list bullets, but the module does not say.

#+begin_src emacs-lisp -i
(use-package org-bulletproof
  :ensure (:wait t)
  :after (org org-modern)
  :init
(global-org-bulletproof-mode))
#+end_src

** Face for done checkboxes

Defines =org-checkbox-done-text=, a gray strike-through face for the text of completed checklist items.

#+begin_src emacs-lisp -i
(defface org-checkbox-done-text
  '((t (:foreground "#71696A" :strike-through t)))
  "Face for the text part of a checked org-mode checkbox.")
#+end_src

** Apply the done face

Adds a font lock rule to Org mode that matches list items whose checkbox is =[X]=, or whose progress cookie is complete such as =[3/3]=, and applies the strike-through face from the checkbox to the end of the line. The rule is appended and the face prepended, so it layers over existing fontification.

#+begin_src emacs-lisp -i
(font-lock-add-keywords
 'org-mode
 `(("^[ \t]*\\(?:[-+*]\\|[0-9]+[).]\\)[ \t]+\\(\\(?:\\[@\\(?:start:\\)?[0-9]+\\][ \t]*\\)?\\[\\(?:X\\|\\([0-9]+\\)/\\2\\)\\][^\n]*\n\\)"
    1 'org-checkbox-done-text prepend))
 'append)
#+end_src

* Padding

** Spacious padding

Installs =spacious-padding= and turns on =spacious-padding-mode= immediately, adding space around windows, the mode line and the frame edges.

#+begin_src emacs-lisp -i
;;;;; Spacious padding --- and other padding settings
(use-package spacious-padding
  :ensure t
  :init
  (spacious-padding-mode))
#+end_src

** Padding widths

Sets the internal border, header line, mode line, tab, right divider, scroll bar and fringe widths. These are set after the mode is already enabled above, so they may only apply fully to frames created later or after the mode is toggled.

#+begin_src emacs-lisp -i
(setq spacious-padding-widths
      '( :internal-border-width 25
         :header-line-width 4
         :mode-line-width 10
         :tab-width 7
         :right-divider-width 30
         :scroll-bar-width 8
         :fringe-width 8))
#+end_src

** Subtle frame lines

Uses subtle lines instead of boxed mode lines: the active mode line takes the default face's colour and inactive ones the shadow face.

#+begin_src emacs-lisp -i
(setq spacious-padding-subtle-frame-lines
      `( :mode-line-active default
         :mode-line-inactive shadow))
#+end_src

** Graphic frames only

Around advice on =spacious-padding-set-parameters-of-frame= so padding is applied only to graphic frames. On a terminal frame, such as one made by =emacsclient -t=, theme colours are unspecified and the package builds an invalid underline spec that makes frame creation fail, so the server would delete the new frame.

#+begin_src emacs-lisp -i
;; On a tty frame (`emacsclient -c' from a terminal, `-t') the theme faces
;; have unspecified colors, and `spacious-padding-set-faces' builds an
;; invalid `:underline (:color unspecified ...)' for `header-line-inactive'.
;; The error aborts `make-frame', so the server deletes the new frame.
;; Padding only matters on graphic frames, so skip the rest.
(define-advice spacious-padding-set-parameters-of-frame
    (:around (fn &optional frame) sp-graphic-only)
  "Only apply spacious padding to graphic FRAME."
  (when (display-graphic-p frame)
    (funcall fn frame)))
#+end_src
