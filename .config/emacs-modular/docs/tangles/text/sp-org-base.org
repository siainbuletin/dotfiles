Literate source for =libraries/modules/text/sp-org-base.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module sets up the basic writing environment for =text-mode= and the core of Org mode: keybindings, indentation, lists, source blocks, logging, deadline highlighting, custom IDs for headings, quick-jump commands to the main Org files and a handful of small editing helpers. It is loaded from the Org section of =init.el= (both the default and minimal module lists), before the other Org modules such as =sp-org-appearance=, =sp-org-capture= and =sp-org-agenda=.

Org itself is the built-in package (=:ensure nil=). Extra packages pulled in here are =company-math=, =math-preview=, =org-fragtog=, =org-inline-anim= and =org-ql=. Some bindings point at commands defined in other modules: =org-emphasize-dwim= and friends come from =sp-org-emphasis=, and =sp-split-leave-parents= comes from =sp-vulpea-split=. The tag picker uses =-uniq= and =-difference= from dash and the =alet= macro from anaphora.

The file also carries some sections inherited from Lambda Emacs (the =sp-goto-*= commands, the checkbox macro, the block wrapper), which explains the mix of naming prefixes (=sp-=, =sia-=, =+org/=).

* Basic text editing

** text-mode defaults

Turns on =visual-line-mode= in every =text-mode= buffer, which includes Org buffers since =org-mode= derives from =text-mode=. It enables =delete-selection-mode=, disables two spaces after sentences, lets scrolling past the buffer edge move point to the top or bottom instead of erroring (=scroll-error-top-bottom=), and saves the system clipboard to the kill ring before a kill overwrites it.

The indented =add-hook= after the form is a separate top-level form that turns on =org-num-mode=, so every Org heading gets an outline number.

#+begin_src emacs-lisp -i
;; Basic settings for text-mode - getting text to work well
(use-package text-mode
  :ensure nil
  :hook
  (text-mode . visual-line-mode) ; Would this function enable text mode in all text buffers, and not just org-mode?
  :init
  (delete-selection-mode t)
  :custom
  (sentence-end-double-space nil)
  (scroll-error-top-bottom t)
  (save-interprogram-paste-before-kill t))

  (add-hook 'org-mode-hook #'org-num-mode)
#+end_src

* Org mode configuration

** Main use-package org block

The main Org setup, using the built-in Org and associating =.org= files with =org-mode=.

Keybindings:
- =C-c a= opens =org-agenda= globally.
- =C-M-h/j/k/l= move or promote subtrees (=org-meta*=) and =M-H/J/K/L= are the shift variants, in a vim-like layout.
- =C-x s t= runs =sp-split-leave-parents= to split a heading into its own vulpea note.
- =s-b= and =s-i= make text bold or italic, =s-M-`= and =s-M-~= make it verbatim or code.
- =s-v= pastes with =org-yank=.
- =C-x t i= and =C-x t h= toggle items and headings, =C-x t d= demotes, =C-c s i= sorts a list.
- =C-c f n= and =C-c f q= create and normalize footnotes.
- =C-c l d= toggles raw link display, =C-c s a= saves all Org buffers.

In =:init=, =org-emphasis-regexp-components= is widened so emphasis markers work next to more punctuation (including the em dash); this has to be set before Org loads.

The =:custom= section keeps footnotes next to their reference, turns on adaptive and startup indentation, preserves source block indentation, inserts headings after the current subtree, allows alphabetical lists, sets a bullet rotation for demoted list items, enables smart =C-a=/=C-e= on headings, raises imenu depth to 8, and makes source blocks fontify natively, edit in another window and confirm before evaluation.

=org-catch-invisible-edits= is set to =show-and-error= here, so editing a folded or hidden region is refused with an error after revealing it (the comment doubts it works). It used to be written as a =setq= inside =:custom=, which expects =(variable value)= pairs, so it did not set the variable.

In =:config= it maps =vimrc= source blocks to =vimrc-mode=, loads the Emacs Lisp, shell, Org and R Babel languages (R blocks need R installed, and usually ESS), and adds a hook so =electric-pair-mode= never auto-pairs =<= in Org buffers, which would break structure templates like =<s=. The hook checks that =electric-pair-inhibit-predicate= is bound first to avoid a void-variable error.

** Find and highlight due headlines

=sp-org-highlight-todays-deadlines= removes previous highlight overlays, parses the buffer's headlines and, for each one that is not in a done state and has a deadline on or before today, puts an overlay with the highlight face over the headline line. Dates are compared as absolute day numbers from =calendar=. It can also be run interactively.

#+begin_src emacs-lisp -i
(defun sp-org-highlight-todays-deadlines ()
  "Highlight headlines with a deadline of today or earlier in Org mode."
  (interactive)
  (remove-overlays (point-min) (point-max) 'siapip/deadline t)
  (let ((today (calendar-absolute-from-gregorian (calendar-current-date))))
    (org-element-map (org-element-parse-buffer 'headline) 'headline
      (lambda (hl)
        (when-let* ((deadline     (org-element-property :deadline hl))
                    (year         (org-element-property :year-start deadline))
                    (month        (org-element-property :month-start deadline))
                    (day          (org-element-property :day-start deadline))
                    (deadline-abs (calendar-absolute-from-gregorian (list month day year))))
          (when (and (not (eq (org-element-property :todo-type hl) 'done))
                     (<= deadline-abs today))
            (let* ((start (org-element-property :begin hl))
                   (end (save-excursion (goto-char start) (line-end-position)))
                   (ov (make-overlay start end)))
              (overlay-put ov 'siapip/deadline t)
              (overlay-put ov 'face 'siapip/org-deadline-highlight))))))))
#+end_src

* Readable custom IDs

These functions give headings a human-readable =CUSTOM_ID= derived from the title, and use it when inserting links with counsel.

** Title to ID

=sia-make-id-for-title= lowercases a title and replaces every non-alphanumeric character with a hyphen.

#+begin_src emacs-lisp -i
(defun sia-make-id-for-title (title)
  "Return an ID based on TITLE."
  (let* ((new-id (replace-regexp-in-string "[^[:alnum:]]" "-" (downcase title))))
    new-id))
#+end_src

** Create a CUSTOM_ID

=sia-org-custom-id-create= builds an ID from the current heading's title, stores it in the =CUSTOM_ID= property and registers it with =org-id-add-location= so ID lookups can find the file.

#+begin_src emacs-lisp -i
(defun sia-org-custom-id-create ()
  "Create and store CUSTOM_ID for current heading."
  (let* ((title (or (nth 4 (org-heading-components)) ""))
         (new-id (sia-make-id-for-title title)))
    (org-entry-put nil "CUSTOM_ID" new-id)
    (org-id-add-location new-id (buffer-file-name (buffer-base-buffer)))
    new-id))
#+end_src

** Get or create, and counsel link override

=sia-org-custom-id-get-create= returns an existing =CUSTOM_ID= at a position, or creates one (always recreating it when FORCE is non-nil).

The same block redefines =counsel-org-link-action= so inserting a link with =counsel-org-link= produces a =#custom-id= link, creating the ID if needed. Because this is a plain =defun= at top level, it only wins if counsel's own definition is loaded before this file; if counsel loads later its original function would replace this one.

#+begin_src emacs-lisp -i
(defun sia-org-custom-id-get-create (&optional where force)
  "Get or create CUSTOM_ID for heading at WHERE.
  If FORCE is t, always recreate the property."
  (org-with-point-at where
    (let ((old-id (org-entry-get nil "CUSTOM_ID")))
      ;; If CUSTOM_ID exists and FORCE is false, return it
      (if (and (not force) old-id (stringp old-id))
          old-id
        ;; otherwise, create it
        (sia-org-custom-id-create)))))

        ;; Now override counsel-org-link-action
  (defun counsel-org-link-action (x)
    "Insert a link to X.

X is expected to be a cons of the form (title . point), as passed
by `counsel-org-link'.

If X does not have a CUSTOM_ID, create it based on the headline
title."
    (let* ((id (sia-org-custom-id-get-create (cdr x))))
      (org-insert-link nil (concat "#" id) (car x))))
#+end_src

* Indirect buffers

** Subtree to indirect buffer

=sp-org-tree-to-indirect-buffer= opens the current subtree in an indirect buffer, narrowed to that subtree, and names it after the heading (coloured with the heading's outline face) followed by =::= and the file's buffer name. If a buffer with that name already exists it switches to it instead of making a new one. The interactive prefix argument is accepted but not used.

#+begin_src emacs-lisp -i
;; Working with indirect buffers
(defun sp-org-tree-to-indirect-buffer (&optional arg)
  "Create indirect buffer and narrow it to current subtree.
The buffer is named after the subtree heading, with the filename
appended.  If a buffer by that name already exists, it is
selected instead of creating a new buffer."
  (interactive "P")
  (let* ((new-buffer-p)
         (pos (point))
         (buffer-name (let* ((heading (org-get-heading t t))
                             (level (org-outline-level))
                             (face (intern (concat "outline-" (number-to-string level))))
                             (heading-string (propertize (org-link-display-format heading)
                                                         'face face)))
                        (concat heading-string "::" (buffer-name))))
         (new-buffer (or (get-buffer buffer-name)
                         (prog1 (condition-case nil
                                    (make-indirect-buffer (current-buffer) buffer-name 'clone)
                                  (error (make-indirect-buffer (current-buffer) buffer-name)))
                           (setq new-buffer-p t)))))
    (switch-to-buffer new-buffer)
    (when new-buffer-p
      ;; I don't understand why setting the point again is necessary, but it is.
      (goto-char pos)
      (rename-buffer buffer-name)
      (org-narrow-to-subtree))))
#+end_src

The comment asks what =with-eval-after-load= means: it delays the body until Org has been loaded, because =org-modules= is defined by Org.

#+begin_src emacs-lisp -i
;; What does this eval after load mean?
;;;; Org Modules
(with-eval-after-load 'org
;; Load additional org modules
(add-to-list 'org-modules 'org-habit t)
(add-to-list 'org-modules 'org-tempo t)
(add-to-list 'org-modules 'org-protocol t))
#+end_src

** Checkbox keyboard macro

=sp-org-checkbox-from-list= is a keyboard macro meant to turn a list item into a checkbox by inserting =[ ]=. The key sequence (=a=, escape, then =M-x=) looks like it was recorded with vim-style modal editing, so with plain Emacs bindings it probably does not do what its name says.

#+begin_src emacs-lisp -i
;;;;; Org Create Check Box From List Item

(fset 'sp-org-checkbox-from-list
      [?a ?  ?\[ ?  ?\] escape ?\M-x return])
#+end_src

** Tag selection

=sp-org-select-tags-completing-read= offers the buffer's tags with =completing-read-multiple= and toggles the chosen ones: selected tags that the heading already has are removed and the rest are added. It depends on the dash list functions and the =alet= macro from the anaphora package, which this config does not install explicitly.

#+begin_src emacs-lisp -i
;;;;; Org Tag Selection

(defun sp-org-select-tags-completing-read ()
  "Select tags to add to headline."
  (interactive)
  (let* ((current (org-get-tags (point)))
         (selected (completing-read-multiple "Select org tag(s): " (org-get-buffer-tags))))
    (alet (-uniq (append (-difference current selected)
                         (-difference selected current)))
      (org-set-tags it))))
#+end_src

** Copy and uncheck checkboxes

=sp-copy-and-uncheck= copies the active region to the kill ring with every =[X]= replaced by =[ ]=, which is handy for carrying a weekly checklist forward.

#+begin_src emacs-lisp -i
;;;;; Uncheck Org boxes
;;see https://www.reddit.com/r/emacs/comments/r107bg/comment/hlx54vf/?utm_source=share&utm_medium=web2x&context=3
(defun sp-copy-and-uncheck (start end)
  "copy a region of regularly repeating checkbox items forward from
one week to the next, unchecking them at the same time"
  (interactive "r")
  (kill-new (replace-regexp-in-string (rx "[X]") "[ ]" (buffer-substring start end)))
  (setq deactivate-mark t))
#+end_src

** Wrap text in a block

=org-block-wrap= asks for a single key and wraps the active region in the matching block (ascii, comment, center, example, emacs-lisp src, html, LaTeX, notes, quote, src or verse). Without a region it inserts an empty block at point. When point is in a table it instead runs =org-table-rotate-recalc-marks=. It is not bound to a key in this module.

#+begin_src emacs-lisp -i
;;;;; Org Wrap in Block Template
;; A helpful function I found for wrapping text in a block template.
;; http://pragmaticemacs.com/emacs/wrap-text-in-an-org-mode-block/

;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
;; function to wrap blocks of text in org templates                       ;;
;; e.g. latex or src etc                                                  ;;
;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
(defun org-block-wrap ()
  "Make a template at point."
  (interactive)
  (if (org-at-table-p)
      (call-interactively 'org-table-rotate-recalc-marks)
    (let* ((choices '(
                      ("a" . "ascii")
                      ("c" . "comment")
                      ("C" . "center")
                      ("e" . "example")
                      ("E" . "src emacs-lisp")
                      ("h" . "html")
                      ("l" . "laTeX")
                      ("n" . "notes")
                      ("q" . "quote")
                      ("s" . "src")
                      ("v" . "verse")
                      ))
           (key
            (key-description
             (vector
              (read-key
               (concat (propertize "Template type: " 'face 'minibuffer-prompt)
                       (mapconcat (lambda (choice)
                                    (concat (propertize (car choice) 'face 'font-lock-type-face)
                                            ": "
                                            (cdr choice)))
                                  choices
                                  ", ")))))))
      (let ((result (assoc key choices)))
        (when result
          (let ((choice (cdr result)))
            (cond
             ((region-active-p)
              (let ((start (region-beginning))
                    (end (region-end)))
                (goto-char end)
                (insert "#+end_" choice "\n")
                (goto-char start)
                (insert "#+begin_" choice "\n")))
             (t
              (insert "#+begin_" choice "\n")
              (save-excursion (insert "#+end_" choice))))))))))
#+end_src

* Following links with RET

** Point strictly inside a link

=sp-org-point-strictly-in-link-p= returns non-nil only when point is inside a link, not on its first character, its end or the blanks after it.

#+begin_src emacs-lisp -i
;;; Only follow links in org-mode if it's strictly in the link itself, not at the edges
(defun sp-org-point-strictly-in-link-p ()
  "Non-nil if point is inside a link, not at its edges or trailing blanks."
  (let ((ctx (org-element-context)))
    (and (eq (org-element-type ctx) 'link)
         (> (point) (org-element-property :begin ctx))
         (< (point) (- (org-element-property :end ctx)
                       (org-element-property :post-blank ctx))))))
#+end_src

** Advice on org-return

Advises =org-return= so =org-return-follows-link= only applies when point is strictly inside a link. Pressing =RET= at the very start or end of a link inserts a newline instead of opening it.

#+begin_src emacs-lisp -i
(define-advice org-return (:around (fn &rest args) strict-link-follow)
  (let ((org-return-follows-link
         (and org-return-follows-link
              (sp-org-point-strictly-in-link-p))))
    (apply fn args)))
#+end_src
