Configures =org-download= (by abo-abo), which lets you drag and drop images into Org buffers, paste them from the clipboard, or take screenshots, saving the files to disk and inserting a link. It is required by =sp-org-ext=. The package is only configured when =sp-load-extras= is non-nil and the library is actually installed, so a minimal or sandbox boot skips it cleanly.

* org-download

** Configuring org-download

Loads lazily on its three entry points =org-download-yank=, =org-download-screenshot= and =org-download-image=. Images are stored with the =directory= method in a single shared folder, =org-pictures/= under =org-directory=, rather than next to each note. LaTeX exports get a width of 500, and the timestamp prefix on file names is a plain date like =2026-10-18=.

#+begin_src emacs-lisp -i
(use-package org-download
  :if (and sp-load-extras (locate-library "org-download"))
  :commands (org-download-yank org-download-screenshot org-download-image)
  :custom
  (org-download-method 'directory)
  (org-download-image-dir (concat org-directory "org-pictures/"))
  (org-download-image-latex-width 500)
  (org-download-timestamp "%Y-%m-%d"))
#+end_src
