Literate source for =libraries/modules/text/sp-org-node-mem.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module sets up =org-mem=, a fast in-memory index of Org files, and =org-node=, which builds note-taking commands (find, insert link, backlinks) on top of it, for the notes in =~/notes/=. It no longer computes =org-agenda-files=: =vulpea-para= does (see =sp-vulpea-para= and [[file:../../../../../adr/0009-one-agenda-owner-per-setting.org][ADR 0009]], which keeps the old hook for reference). =org-mem= and =org-node= are planned to be removed from the configuration.

Packages: =org-mem=, =org-node= and =inspector= (installed for inspecting Lisp objects, possibly while debugging the index). The module is required by =sp-org-ext=. Note that =sp-vulpea-convert-properties= keeps =CREATED= in drawers specifically so org-node keeps working.

** org-mem

Installs =org-mem= and, once it loads, makes it sync with =org-id= locations, watch =~/notes/= for Org files, and start =org-mem-updater-mode= so the index stays current as files change. The comment notes that at least one of the two sources (org-id sync or watched directories) is required.

#+begin_src emacs-lisp -i
(use-package org-mem
  :ensure (:wait t)
  :defer
  :config
  ;; At least one of these two is needed
  (setq org-mem-do-sync-with-org-id t)
  (setq org-mem-watch-dirs
        (list sp-notes-dir))
  (org-mem-updater-mode))
#+end_src

* org-node

** org-node

Installs =org-node= and enables =org-node-cache-mode= after init. =M-o n n= turns the current entry into a node by giving it an ID, and =M-o n i= inserts a link to a node.

#+begin_src emacs-lisp -i
(use-package org-node
  :ensure (:wait t)
  :hook (after-init . org-node-cache-mode)
  :init
  ;; Optional key bindings
  ;; Tip: Try changing these to just "M-o"!
  (keymap-global-set "M-o n n" 'org-node-nodeify-entry)
  (keymap-global-set "M-o n i" 'org-node-insert-link)
)
#+end_src

** Backlinks not in drawers

Stops org-node from writing backlinks into =:BACKLINKS:= property drawers.

#+begin_src emacs-lisp -i
(setq org-node-backlink-do-drawers nil)
#+end_src
