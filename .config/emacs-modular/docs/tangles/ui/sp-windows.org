Literate source for =libraries/modules/ui/sp-windows.el=.

- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README.

This module configures how Emacs windows (the panes inside a frame) are split, decorated, moved around and highlighted.

- Frames are handled separately in =sp-frame=.
- It installs =balanced-windows=, =ace-window=, =pulsar=, =buffer-move=, =dimmer=.
- It binds the Emacs 31 window-layout commands.

The second half defines a set of interactive window helpers adapted from Lambda Emacs (named =lem-...=):

- toggling dedicated windows,
- swapping, rotating and re-splitting windows,
- splitting with focus.

The window prefix map in =sp-keys= binds these =lem-...= commands (rotate, toggle split, split and focus, exchange buffers). It used to name =sp-...= versions that do not exist, which left those leader keys dead.

The module is part of the window management group in the default module list, loaded after =sp-frame= and =sp-buffers=.

The commentary at the top of the module says:

(frames should be treated separately).

Eventually, the entire graphical environment and where information gets
placed should be moved to a larger file regarding window management,
and it should include controls for a daemonized Emacs which runs on a
tiling window manager under Linux.
#+end_quote

* Rearranging layouts

Commands for reshaping an existing layout without manually splitting and killing windows.

** Emacs 31 layout commands

Binds the window-layout commands that are new in Emacs 31 under =C-x w=:

- =t= transposes the layout (swapping horizontal and vertical arrangement).
- =r= rotates it clockwise.
- =f h= / =f v= mirror it left-to-right or top-to-bottom.
- Buffers stay in their windows.

Caveats:

- On older Emacs versions these keys point at undefined commands.
- The TODO says this area still needs work.

#+begin_src emacs-lisp -i
;;;; Moving windows around
;; TODO: this has to be configured better.

;; This is a fun set of new commands for rearranging your window layout
;; without manually splitting and killing windows:

(keymap-global-set "C-x w t" #'window-layout-transpose)        ; EMACS-31
(keymap-global-set "C-x w r" #'window-layout-rotate-clockwise) ; EMACS-31
(keymap-global-set "C-x w f h" #'window-layout-flip-leftright)   ; EMACS-31
(keymap-global-set "C-x w f v" #'window-layout-flip-topdown)     ; EMACS-31

;; Transpose swaps your horizontal and vertical arrangement, rotate spins
;; the whole layout around, and the flip commands mirror it left-to-right
;; or top-to-bottom. If you've ever built a three-window layout and then
;; wished the editor pane were on the other side, these do the job and
;; keep every buffer in place while they're at it.
#+end_src

** Split thresholds

=split-width-threshold= of 120 means Emacs only splits side by side when the window is at least 120 columns wide, and =split-height-threshold= of =nil= forbids automatic vertical (top/bottom) splits, so =display-buffer= prefers side-by-side windows.

#+begin_src emacs-lisp -i
;; Window splits
(setq split-width-threshold 120
      split-height-threshold nil)
#+end_src

** Invisible divider faces

Resets the three window-divider faces and colours their foreground with the default background, so the dividers act as blank spacing rather than visible lines. This reads the current theme's background at load time, so a later theme change may leave the dividers mismatched.

(dolist (face '(window-divider
                window-divider-first-pixel
                window-divider-last-pixel))
  (face-spec-reset-face face)
  (set-face-foreground face (face-attribute 'default :background)))
#+end_src

** Transpose buffers

=transpose-buffers= swaps the buffers shown in the current window and the next one, moving point along with them.

- A numeric prefix repeats the swap. A negative one walks backwards with =previous-window=.
- =sp-keys= binds it to =C-x t b=.
- It uses =plusp=, which is built in from Emacs 31 and otherwise comes from the cl library.

#+begin_src emacs-lisp -i
(defun transpose-buffers (arg)
  "Transpose the buffers shown in two windows."
  (interactive "p")
  (let ((selector (if (>= arg 0) 'next-window 'previous-window)))
    (while (/= arg 0)
      (let ((this-win (window-buffer))
            (next-win (window-buffer (funcall selector))))
        (set-window-buffer (selected-window) next-win)
        (set-window-buffer (funcall selector) this-win)
        (select-window (funcall selector)))
      (setq arg (if (plusp arg) (1- arg) (1+ arg))))))
#+end_src

** pulsar

=pulsar= briefly highlights the current line after large jumps, so the cursor is easy to find.

- The delay is 0.15 seconds with the generic face. =<f8>= pulses the line on demand.
- The =:config= adds many motion commands to =pulsar-pulse-functions=: recentering, scrolling, window and tab commands, bookmark jumps, and Org and outline heading motion.
- It also adds =winner=, =winum=, =ace-window= and =evil= window commands when those are loaded.
- =ha-new-window= is in the list although it is not defined in this config. It appears to come from another person's setup.
- Finally =pulsar-global-mode= is turned on.

#+begin_src emacs-lisp -i
(use-package pulsar
  :ensure t
  :custom
  (pulsar-face 'pulsar-generic)
  (pulsar-delay 0.15)

  :bind ("<f8>" . pulsar-pulse-line)

  :config
  (dolist (built-in-function '(recenter-top-bottom move-to-window-line-top-bottom reposition-window
                               bookmark-jump other-window delete-window delete-other-windows
                               forward-page backward-page scroll-up-command scroll-down-command
                               ha-new-window tab-new tab-close tab-next org-next-visible-heading
                               org-previous-visible-heading org-forward-heading-same-level
                               org-backward-heading-same-level outline-backward-same-level
                               outline-forward-same-level outline-next-visible-heading
                               outline-previous-visible-heading outline-up-heading))
    (add-to-list 'pulsar-pulse-functions built-in-function))

  (when (fboundp 'winner-undo)
    (add-to-list 'pulsar-pulse-functions 'winner-undo)
    (add-to-list 'pulsar-pulse-functions 'winner-redo))

  (when (fboundp 'winum-select-window-1)
    (add-to-list 'pulsar-pulse-functions 'winum-select-window-1)

    (add-to-list 'pulsar-pulse-functions 'winum-select-window-4)

** Close buffer and window

=close-buffer-and-window= kills the current buffer and then deletes its window if the window still exists. It is not bound to a key in this file.

#+begin_src emacs-lisp -i
;; Function for close buffer and window

(defun close-buffer-and-window ()
  "Close the current buffer and the window it's in."
  (interactive)
  (let ((window (selected-window)))
    (kill-buffer)               ;; Kill the current buffer
    (when (window-live-p window) ;; Check if the window is still live
      (delete-window))))         ;; Delete the window if it exists
#+end_src

** Toggle a single-window view

=siapip/window-toggle-fullscreen=:

- Maximises the current window with =delete-other-windows=.
- On the second press, restores the previous layout with =winner-undo=.
- =winner-mode= is enabled here (the =boundp= check is always true in modern Emacs).
- Bound to =S-<f11>=.
- The toggle state can drift if other window changes happen between the two presses.

#+begin_src emacs-lisp -i
(defun siapip/window-toggle-fullscreen ()
  (interactive)
  (if siapip/window-toggle-fullscreen:state
      (progn
        (winner-undo)
        (setq siapip/window-toggle-fullscreen:state nil))
    (progn
      (delete-other-windows)
      (setq siapip/window-toggle-fullscreen:state t))))
(when (boundp 'winner-mode)
  (winner-mode t))
(global-set-key (kbd "S-<f11>") 'siapip/window-toggle-fullscreen)
#+end_src

** Dim inactive windows

=dimmer= fades the text of non-selected windows by half to make the active window stand out.

- It starts on =after-init-hook=.
- The minibuffer is never dimmed, and frame focus events are ignored.
- The built-in helpers adjust dimming for which-key, Magit, posframe and Vertico.

#+begin_src emacs-lisp -i
;;;; Dim inactive windows
(use-package dimmer
  :ensure t
  :hook (after-init . dimmer-mode)
  :custom
  (dimmer-prevent-dimming-predicates '(window-minibuffer-p))
  (dimmer-fraction 0.5)
  (dimmer-adjustment-mode :foreground)
  (dimmer-use-colorspace :rgb)
  (dimmer-watch-frame-focus-events nil)
  :config
  (dimmer-configure-which-key)
  (dimmer-configure-magit)
  (dimmer-configure-posframe)
  (dimmer-configure-vertico))
#+end_src

* Window functions

Interactive helpers from Lambda Emacs for managing window layout.

** Toggle dedicated window

=lem-toggle-window-dedicated= flips the dedicated flag on the window showing the current buffer and reports the new state. A dedicated window keeps its buffer and is left alone by =display-buffer= and by the rotate command below.

#+begin_src emacs-lisp -i
;;;; Functions for windows
;;;; Window Functions
;;;;; Toggle Dedicated Window
(defun lem-toggle-window-dedicated ()
  "Toggle whether the current active window is dedicated or not"
  (interactive)
  (message
   (if (let ((window (get-buffer-window (current-buffer))))
         (set-window-dedicated-p window (not (window-dedicated-p window))))
       "Window '%s' is dedicated"
     "Window '%s' is normal")
   (current-buffer)))
#+end_src

** Rotate windows

=lem-rotate-windows= cycles the buffers (and their scroll positions) through all non-dedicated windows by COUNT steps.

- Dedicated windows are left untouched.
- It comes from Magnar Sveen's config, with dedicated-window support by ffevotte.
- With a single window it just prints a message.

#+begin_src emacs-lisp -i
;;;;; Rotate Windows
;; from magnars modified by ffevotte for dedicated windows support
(defun lem-rotate-windows (count)
  "Rotate your windows.
  Dedicated windows are left untouched. Giving a negative prefix
  argument takes the kindows rotate backwards."
  (interactive "p")
  (let* ((non-dedicated-windows (cl-remove-if 'window-dedicated-p (window-list)))
         (num-windows (length non-dedicated-windows))
         (i 0)
         (step (+ num-windows count)))
    (cond ((not (> num-windows 1))
           (message "You can't rotate a single window!"))
          (t
           (dotimes (counter (- num-windows 1))
             (let* ((next-i (% (+ step i) num-windows))

                    (w1 (elt non-dedicated-windows i))
                    (w2 (elt non-dedicated-windows next-i))

                    (b1 (window-buffer w1))
                    (b2 (window-buffer w2))

                    (s1 (window-start w1))
                    (s2 (window-start w2)))
               (set-window-buffer w1 b2)
               (set-window-buffer w2 b1)
               (set-window-start w1 s2)
               (set-window-start w2 s1)
               (setq i next-i)))))))
#+end_src

** Toggle window split

=lem-toggle-window-split= works only when exactly two windows are shown. It:

- notes which buffer is in which window, and whether they are arranged side by side or stacked,
- deletes the other window,
- re-splits in the other orientation,
- puts both buffers back in their original order.

With any other number of windows it does nothing.

#+begin_src emacs-lisp -i
;;;;; Toggle Window Split
(defun lem-toggle-window-split ()
  "Move from a horizontal to a vertical split and vice versa."
  (interactive)
  (if (= (count-windows) 2)
      (let* ((this-win-buffer (window-buffer))
             (next-win-buffer (window-buffer (next-window)))
             (this-win-edges (window-edges (selected-window)))
             (next-win-edges (window-edges (next-window)))
             (this-win-2nd (not (and (<= (car this-win-edges)
                                         (car next-win-edges))
                                     (<= (cadr this-win-edges)
                                         (cadr next-win-edges)))))
             (splitter
              (if (= (car this-win-edges)
                     (car (window-edges (next-window))))
                  'split-window-horizontally
                'split-window-vertically)))
        (delete-other-windows)
        (let ((first-win (selected-window)))
          (funcall splitter)
          (if this-win-2nd (other-window 1))
          (set-window-buffer (selected-window) this-win-buffer)
          (set-window-buffer (next-window) next-win-buffer)
          (select-window first-win)
          (if this-win-2nd (other-window 1))))))
#+end_src
