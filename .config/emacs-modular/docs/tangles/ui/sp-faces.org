Literate source for =libraries/modules/ui/sp-faces.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

This module gathers settings that change how text and the cursor look: outline heading faces in Lisp files, SVG tags in code, TODO and number highlighting, a TODO navigation transient, pulsing the current line after jumps, and highlighting of edited regions with Goggles. It also defines a small =what-face= helper for inspecting faces.

Optional packages (=outline-minor-faces=, =svg-tag-mode=, =highlight-numbers=, =hl-todo=, =goggles=) are only configured when =sp-load-extras= is non-nil and the library is installed. Built-ins used are =reveal=, =wid-edit=, =pulse= and =transient=. The =sp-todo-transient= defined here is bound under the leader map in =sp-keys=.

** What face

=what-face= reports the face at point in the echo area, which is handy when tweaking themes. It reads the face at =(point)= rather than its =pos= argument; since =pos= comes from =interactive "d"= these are the same when called interactively.

#+begin_src emacs-lisp -i
;;;; What Face?
;; https://stackoverflow.com/a/66287459/6277148
(defun what-face (pos)
  "State the face at point POS in the minibuffer."
  (interactive "d")
  (let ((face (or (get-char-property (point) 'read-face-name)
                  (get-char-property (point) 'face))))
    (if face (message "Face: %s" face) (message "No face at %d" pos))))
#+end_src

** Reveal mode

Turns on =global-reveal-mode=, which temporarily shows invisible text around point, such as folded Org headings, while you move through it. With =reveal-auto-hide= nil, revealed text stays visible after point leaves.

#+begin_src emacs-lisp -i
;;;; Reveal Mode
;; Toggle uncloaking of invisible text near point, including folded org headlines (Reveal mode).
(use-package reveal
  :ensure nil
  :defer 1
  :config
  (setq reveal-auto-hide nil)
  (global-reveal-mode))
#+end_src

** SVG tags in code

In programming buffers, =svg-tag-mode= draws matching text as rounded SVG labels when Emacs supports SVG. Any =:WORD:= pattern becomes a tag with the =success= face, and the markers =TODO:=, =FIXME:=, =HACK:=, =NOTE:= and =DONE:= get their own colours.

#+begin_src emacs-lisp -i
;;;; SVG Library (For Tags/Labels/etc.)
  ;;; SVG Tag Mode
(use-package svg-tag-mode
  :when (and sp-load-extras (locate-library "svg-tag-mode") (image-type-available-p 'svg))
  :hook (prog-mode . svg-tag-mode)
  :config
  (setq svg-tag-tags
        '(;; Replaces any occurence of :XXX: with a dynamic SVG tag displaying XXX
          ("\\(:[A-Z]+:\\)" . ((lambda (tag)
                                 (svg-tag-make tag :face 'success :inverse t :beg 1 :end -1))))
          ;; other tags
          ("DONE:"  . ((lambda (tag) (svg-tag-make "DONE:"  :face 'fringe  :inverse t ))))
          ("FIXME:" . ((lambda (tag) (svg-tag-make "FIXME:" :face 'error   :inverse t))))
          ("HACK:"  . ((lambda (tag) (svg-tag-make "HACK:"  :face 'warning :inverse t))))
          ("NOTE:"  . ((lambda (tag) (svg-tag-make "NOTE:"  :face 'warning :inverse t))))
          ("TODO:"  . ((lambda (tag) (svg-tag-make "TODO:"  :face 'warning :inverse t)))))))
#+end_src

** TODO navigation transient

=sp-todo-transient= offers =n= and =p= to jump to the next and previous TODO keyword and =o= to list them with occur, all staying in the menu, and =q= to quit. On invocation it turns =hl-todo-mode= on and registers a one-shot =transient-exit-hook= function that turns it off again and removes itself, so highlighting is only active while navigating. It is bound to =s t= under the leader key in =sp-keys=.

#+begin_src emacs-lisp -i
(transient-define-prefix sp-todo-transient ()
  "TODO navigation."
  ["TODO"
   ("n" "Next"     hl-todo-next     :transient t)
   ("p" "Previous" hl-todo-previous :transient t)
   ("o" "Occur"    hl-todo-occur    :transient t)
   ("q" "Quit"     transient-quit-one)]
  (interactive)
  (hl-todo-mode 1)
  (let (cleanup)
    (setq cleanup
          (lambda ()
            (hl-todo-mode -1)
            (remove-hook 'transient-exit-hook cleanup)))
    (add-hook 'transient-exit-hook cleanup))
  (transient-setup 'sp-todo-transient))
#+end_src

** Pulse the current line

Uses the built-in =pulse= library, following Karthink's "batteries included" article. =C-<return>= runs =pulse-line=, which briefly highlights the current line. Once pulse is loaded, the line also pulses on any change of selected window, through =window-selection-change-functions=. Because that hook is added in =:config=, it only takes effect after =pulse= has been loaded, for example by the first =C-<return>=.

This block used to advise =scroll-up-command=, =scroll-down-command=, =recenter-top-bottom= and =other-window= with =pulse-line= as well. That advice was removed: because =pulse-line= is interactive, its empty =(interactive)= spec replaced the advised command's own spec, so =C-x o= called =other-window= with no COUNT and failed with "Wrong number of arguments". Those commands already pulse through =pulsar= in =sp-windows=.

#+begin_src emacs-lisp -i
;;;;; Highlight Cursor Line with Pulse
;; From https://karthinks.com/software/batteries-included-with-emacs/
;; Replace external package with internal command

(use-package pulse
  :bind
  ("C-<return>" . pulse-line)
  :commands (pulse-line pulse-momentary-highlight-one-line)
  :config
  (setq pulse-delay 0.08)
  (defun pulse-line (&rest _)
    "Pulse the current line."
    (interactive)
    (pulse-momentary-highlight-one-line (point)))
  ;; pulse on window change
  (push 'pulse-line window-selection-change-functions))
#+end_src

** Goggles

Enables =goggles-mode= in programming and text buffers, which briefly highlights the region affected by yanks, undos and other edits, with a pulsing effect.

#+begin_src emacs-lisp -i
;;;; Goggles (Highlight Changes)
(use-package goggles
  :when (and sp-load-extras (locate-library "goggles"))
  :hook ((prog-mode text-mode) . goggles-mode)
  :config
  (setq-default goggles-pulse t)) ;; set to nil to disable pulsing
#+end_src
