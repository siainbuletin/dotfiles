This module installs two packages by yibie from GitHub:

- =textui=, which the comment describes as a new package for better rendering of widgets in a buffer.
- =org-table-widget=, which displays Org tables as interactive widgets.

Then:

- It turns on =org-table-widget-mode= in every Org buffer.
- The module is in the UI group of the default module list in =init.el=, loaded just before the themes.

** Packages

Installs =textui= and =org-table-widget= from their GitHub repositories with Elpaca.

#+begin_src emacs-lisp -i
(use-package textui
    :ensure (:host github :repo "yibie/textui"))

(use-package org-table-widget
    :ensure (:host github :repo "yibie/org-table-widget"))
#+end_src

** Enable in Org

Adds =org-table-widget-mode= to =org-mode-hook=, so every Org buffer shows its tables through the widget layer.

#+begin_src emacs-lisp -i
(add-hook 'org-mode-hook #'org-table-widget-mode)
#+end_src
