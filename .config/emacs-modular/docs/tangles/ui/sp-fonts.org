#+TITLE: sp-fonts.el: Fonts, text scaling and line highlighting
#+PROPERTY: header-args:emacs-lisp :tangle ../../../libraries/modules/ui/sp-fonts.el :comments no :padline yes :noweb no :mkdirp yes
#+STARTUP: content

Literate source for =libraries/modules/ui/sp-fonts.el=.

- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../tangling-instructions.org][Tangling instructions]].

This module sets up typography around =fontaine=. Its presets own:

- the default, fixed-pitch and variable-pitch families,
- their sizes,
- line spacing,
- the mode line height.

The rest of the file reacts to those faces:

- symbol and emoji fallbacks,
- text scaling,
- =mixed-pitch= for prose buffers,
- font size commands,
- the =lin= line-highlighting package.

The fontset block comes from Lambda Emacs.

Loading and fonts:

- Loaded early among the UI modules in =init.el=, after =sp-icons=, =sp-colors= and =sp-faces=.
- Packages it installs: =fontaine=, =mixed-pitch= and =lin=.
- It expects fonts such as Aporetic Sans Mono, Aporetic Serif Mono and IntoneMono Nerd Font to be installed, with Symbola or Apple Symbols for symbols and Apple Color Emoji for emoji.

Earlier versions had the options =sp-ui-default-font= and =sp-ui-variable-width-font=, the =ha-= font lists from Howard Abrams' configuration and three competing settings of the default face. They are gone: the presets are the one place that decides the fonts.

* Checking fonts

** Is a font installed?

=sp-font-available-p= returns non-nil when a font family name appears in =font-family-list=. It is used below to pick symbol and emoji fonts only when they exist.

#+begin_src emacs-lisp -i
;;;; Check Fonts
;; See https://emacsredux.com/blog/2021/12/22/check-if-a-font-is-available-with-emacs-lisp/
(defun sp-font-available-p (font-name)
  "Check if font is available from system installed fonts."
  (member font-name (font-family-list)))
#+end_src

* Fontaine

** Presets and startup

Installs =fontaine= and waits for it, so the presets exist before the rest of the file runs.

- The presets are listed in the table below. =t= holds what every preset shares.
- =fontaine-set-preset= is called with the preset saved by the last session, or =regular= the first time. The saved choice is kept in =sp-cache-dir=.
- =fontaine-mode= keeps the faces right when a theme is loaded.
- There is no =sp-ui-default-font= option any more. Change the fonts by editing a preset, or switch with =M-x fontaine-set-preset=.

| Preset         | Default face (fixed width)  | Variable-pitch face     | Default height | Variable-pitch height | Mode line | Line spacing |
|----------------+-----------------------------+-------------------------+----------------+-----------------------+-----------+--------------|
| =regular=      | Aporetic Sans Mono          | Aporetic Serif Mono     | 150            | 120                   | 150       | 0.1          |
| =presentation= | Aporetic Sans Mono          | Charter                 | 220            | 220                   | 220       | 0.2          |

Atkinson Hyperlegible and Literata are not part of a preset. They are set on single faces, see the next section.

#+begin_src emacs-lisp -i
(defface sp-text-face '((t))
  "Size of the text in Org and the other text modes, set by the fontaine presets.
Only its `:height' is used, as a multiple of the `default' height."
  :group 'faces)

(use-package fontaine
  :ensure (:wait t)
  :demand t
  :custom
  (fontaine-latest-state-file (concat sp-cache-dir "fontaine-latest-state.eld"))
  (fontaine-presets
   '((regular
      :default-family "Aporetic Sans Mono"
      :default-height 150
      :variable-pitch-family "Aporetic Serif Mono"
      :variable-pitch-height 120
      :mode-line-active-height 150
      :mode-line-inactive-height 150
      :line-spacing 0.1)
     (presentation
      :default-family "Aporetic Sans Mono"
      :default-height 220
      :variable-pitch-family "Charter"
      :variable-pitch-height 220
      :mode-line-active-height 220
      :mode-line-inactive-height 220
      ;; The default height is already large here.
      :sp-text-face-height 1.0
      :line-spacing 0.2)
     (t
      ;; 1.0 keeps the dashboard boxes on the grid of the `default' font; any other
      ;; value makes the box text and the box lines differ in width and misalign.
      :sp-dashboard-menu-face-height 1.0
      ;; Org and the other text modes are
      ;; 1.36 times the `default' height (4 `text-scale' steps of 1.08).
      :sp-text-face-height 1.36
      :default-weight regular
      :bold-weight bold
      :italic-slant italic)))
  :config
  ;; Faces of this configuration that the presets also size: a preset reads
  ;; `:FACE-height' as a multiple of the `default' height.  This has to run
  ;; before the first preset is set.
  (dolist (face '(sp-dashboard-menu-face sp-text-face))
    (add-to-list 'fontaine-faces face t))
  (fontaine-set-preset (or (fontaine-restore-latest-preset) 'regular))
  (fontaine-mode 1))
#+end_src

** Faces outside the presets

The =link= face keeps its own family (IntoneMono Nerd Font).

The Org document title, the text after =#+title:=, is the only place that uses Atkinson Hyperlegible. The Org quote face (=#+begin_quote=) uses Literata at height 1.0, which is the size of the default text in the buffer.

Heading sizes must follow the default text, because larger headings hurt readability.

- Nothing in this configuration sets a height on =org-level-1= to =org-level-8=, and none of the theme options in =sp-themes= does either.
- A theme package can still define them (the Lambda, Modus, EF and Doric themes are not read here).
- So =sp-fonts-org-faces= sets the height of all eight heading faces and of the title to 1.0.
- It runs after Org loads, after every theme change and after every =fontaine= preset change.
- If a theme sets a size, this overrides it.

#+begin_src emacs-lisp -i
(set-face-attribute 'link nil
                  :family "IntoneMono Nerd Font"
                  :height 150)

(defun sp-fonts-org-faces ()
  "Set the fonts of the Org title and quote, and keep headings at text size."
  (set-face-attribute 'org-document-title nil
                      :family "Atkinson Hyperlegible" :height 1.0)
  (set-face-attribute 'org-quote nil
                      :family "Literata" :height 1.0)
  (dotimes (n 8)
    (set-face-attribute (intern (format "org-level-%d" (1+ n))) nil
                        :height 1.0)))

(with-eval-after-load 'org
  (sp-fonts-org-faces))
(add-hook 'sp-after-load-theme-hook #'sp-fonts-org-faces)
(add-hook 'fontaine-set-preset-hook #'sp-fonts-org-faces)
#+end_src

* Symbols, emoji and fallbacks

** Fontset setup

The =fontset= block configures glyph fallbacks.

- =use-default-font-for-symbols= is t, so symbols use the default font where it has them. The comment says =org-modern-indent= needs this.
- For the rest, the first installed font among Symbola, Apple Symbols, Symbol and Segoe UI Symbol is assigned to the symbol script.
- On Emacs 28 or later, Apple Color Emoji is prepended for the emoji script to get colour emoji.

Finally a face named =fallback= (Fira Code, inheriting from =fringe=) is defined and used for the truncation and wrap indicators in the standard display table, so truncated lines end with an ellipsis and wrapped lines show a return arrow.

#+begin_src emacs-lisp -i
;;;; Set Symbol & Emoji Fonts
;; The fontset settings are necessary to make the lambda-line and lambda-dashboard work properly
(use-package fontset
  :ensure nil

  :custom
  ;; Set this to nil to set symbols entirely separately
  ;; Need it set to `t` in order to display org-modern-indent faces properly
  (use-default-font-for-symbols t)

  :config
  ;; Use symbola for proper symbol glyphs, but have some fallbacks
  (cond ((sp-font-available-p "Symbola")
         (set-fontset-font
          t 'symbol "Symbola" nil))
        ((sp-font-available-p "Apple Symbols")
         (set-fontset-font
          t 'symbol "Apple Symbols" nil))
        ((sp-font-available-p "Symbol")
         (set-fontset-font
          t 'symbol "Symbol" nil))
        ((sp-font-available-p "Segoe UI Symbol")
         (set-fontset-font
          t 'symbol "Segoe UI Symbol" nil)))

  ;; Use Apple emoji
  ;; NOTE that emoji here may need to be set to unicode to get color emoji
  (when (and (>= emacs-major-version 28)
             (sp-font-available-p "Apple Color Emoji"))
    (set-fontset-font t 'emoji
                      '("Apple Color Emoji" . "iso10646-1") nil 'prepend))

  ;; Fall back font for missing glyph
  (defface fallback '((t :family "Fira Code"
                         :inherit fringe)) "Fallback")
  (set-display-table-slot standard-display-table 'truncation
                          (make-glyph-code ?… 'fallback))
  (set-display-table-slot standard-display-table 'wrap
                          (make-glyph-code ?↩ 'fallback)))
#+end_src

* Text scaling

** Scale step and keys

Text scaling:

- =text-scale-mode-step= makes each step about one point.
- =s-== and =s--= scale up and down, and =s-0= adjusts interactively. They are bound with =bind-key*= so no mode overrides them.
- The comment notes the step should adapt to the screen resolution.

#+begin_src emacs-lisp -i
;;;; Scale Text
;; When using `text-scale-increase', this sets each 'step' to about one point size.
;;
;; This should be improved globally to adapt to the resolution of the screen that you're
;; working with.
(setopt text-scale-mode-step 1.08)
(bind-key* "s-=" #'text-scale-increase)
(bind-key* "s--" #'text-scale-decrease)
(bind-key* "s-0" #'text-scale-adjust)
#+end_src

** Minibuffer text size

The minibuffer and the posframe have no text size of their own: they use the =default= face. Two ways of enlarging them were tried and removed (a per-prompt face remap in #161, a posframe font in #174); see the [[file:sp-posframe.org::*Text size][=sp-posframe= doc]]. =text-scale-adjust= in a buffer does not change them.

** Larger text buffers

=sp-text-buffer= maps the fontaine face =sp-text-face= onto =default= in text modes, so Org is =:sp-text-face-height= (1.36, which is what 4 =text-scale= steps of 1.08 came to) times the =default= height. =sp-dashboard-menu-face= is added to =fontaine-faces= in the fontaine block, so each preset sets its own sizes (1.0 in =presentation=, whose =default= height is already large). =text-scale= (=s-==, =s--=) still works on top of them.

The dashboard box text is sized by fontaine, not here: =sp-dashboard-menu-face= is added to =fontaine-faces= in the =:config= of the fontaine block above, and the =t= preset sets =:sp-dashboard-menu-face-height= to 1.0 (a multiple of the =default= height, like every non-=default= face in a preset). The value is 1.0 because the box lines and the text share one character grid: another height makes them differ in width and the boxes no longer line up. A preset may still override it.

#+begin_src emacs-lisp -i
(defun sp-text-buffer ()
  "Make the font in the text buffer generally larger, by `sp-text-face'."
  (face-remap-add-relative 'default 'sp-text-face))

#+end_src

* Font size commands

** Adjusting the font size

=font-size-adjust= changes the height of the =default= face by ten units (one point) per step of DELTA, never below 60.

- It replaces the old version that rebuilt every face from the =ha-= font lists.
- The change lasts until the next =fontaine-set-preset=, which applies the preset height again.

#+begin_src emacs-lisp -i
(defun font-size-adjust (delta)
  "Adjust the height of the `default' face by DELTA points.
DELTA would be something like 1 or -1.  The next
`fontaine-set-preset' restores the height of the preset."
  (interactive "nFont size difference: ")
  (set-face-attribute 'default nil
                      :height (max 60 (+ (face-attribute 'default :height)
                                         (* 10 (or delta 1))))))
#+end_src

** Increase

Makes the font one point larger.

#+begin_src emacs-lisp -i
(defun font-size-increase ()
   "Increase the `default' font size of all frames."
   (interactive)

#+end_src

* Font cycling

** Families and state

The families to try are =sp-font-cycle-families= (the list from the Nerd Fonts you tried), plus the default families of the fontaine presets, so a preset's font is always in the cycle. Only installed families are used (=find-font=). The menu remembers the font it started from, so =r= can go back.

#+begin_src emacs-lisp -i
;;;; Font Cycling
(require 'seq)
(require 'subr-x)

(defcustom sp-font-cycle-families
  '("3270 Nerd Font Mono"
    "GoMono Nerd Font"
    "Hack Nerd Font Mono"
    "Hurmit Nerd Font Mono"
    "Inconsolata LGC Nerd Font"
    "Iosevka Nerd Font Mono"
    "IosevkaTerm Nerd Font Mono"
    "JetBrainsMono Nerd Font"
    "Lekton Nerd Font Mono"
    "M+CodeLat50 Nerd Font"
    "Maple Mono NF"
    "MartianMono Nerd Font"
    "SauceCodePro Nerd Font"
    "UbuntuMono Nerd Font Mono"
    "VictorMono Nerd Font Mono"
    "ZedMono Nerd Font Mono")
  "Font families to try with `sp-font-cycle'.
The families of the `fontaine-presets' are added to the list, and only
the installed ones are used."
  :type '(repeat string)
  :group 'faces)

(defvar sp-font-cycle--index 0
  "Position of the previewed family in `sp-font-cycle--installed'.")

(defvar sp-font-cycle--start nil
  "The (FAMILY . HEIGHT) of the `default' face when the menu was opened.")

(defun sp-font-cycle--preset-families ()
  "Return the default families of the `fontaine-presets'."
  (when (boundp 'fontaine-presets)
    (delq nil (mapcar (lambda (preset) (plist-get (cdr preset) :default-family))
                      fontaine-presets))))

(defun sp-font-cycle--installed ()
  "Return the families to cycle through that are installed on this system."
  (seq-filter (lambda (family) (find-font (font-spec :family family)))
              (delete-dups (append (sp-font-cycle--preset-families)
                                   sp-font-cycle-families))))

(defun sp-font-cycle--select (index)
  "Preview the installed family at INDEX, wrapping around both ends."
  (let ((fonts (sp-font-cycle--installed)))
    (unless fonts
      (user-error "None of the font families is installed"))
    (setq sp-font-cycle--index (mod index (length fonts)))
    (set-face-attribute 'default nil :family (nth sp-font-cycle--index fonts))))
#+end_src

** Cycling

Switching families wraps around at both ends. The height is changed by the existing =font-size-increase= and =font-size-decrease= (one point a step), so there is one definition of a size step.

#+begin_src emacs-lisp -i
(defun sp-font-cycle-next ()
  "Preview the next font."
  (interactive)
  (sp-font-cycle--select (1+ sp-font-cycle--index)))

(defun sp-font-cycle-previous ()
  "Preview the previous font."
  (interactive)
  (sp-font-cycle--select (1- sp-font-cycle--index)))

(defun sp-font-cycle-restore ()
  "Go back to the font and size the menu was opened with."
  (interactive)
  (when sp-font-cycle--start
    (set-face-attribute 'default nil
                        :family (car sp-font-cycle--start)
                        :height (cdr sp-font-cycle--start))
    (sp-font-cycle--sync-index)))

(defun sp-font-cycle--sync-index ()
  "Point `sp-font-cycle--index' at the family of the `default' face."
  (setq sp-font-cycle--index
        (or (seq-position (sp-font-cycle--installed)
                          (face-attribute 'default :family nil t))
            0)))
#+end_src

** Copying and the menu

=y= copies the =set-face-attribute= form, the way to try a font in a scratch buffer. =M-x sp-font-cycle= opens the menu: left and right change the family, up and down the size, =s= saves, =r= restores the font the menu started with, =q= leaves the menu with the previewed font still active. No key is bound; bind =sp-font-cycle= where it suits.

#+begin_src emacs-lisp -i
(defun sp-font-cycle--form ()
  "Return the `set-face-attribute' call for the previewed font."
  (format "(set-face-attribute 'default nil :family %S :height %d)"
          (face-attribute 'default :family nil t)
          (face-attribute 'default :height nil t)))

(defun sp-font-cycle-copy ()
  "Copy the previewed font as Elisp to the kill ring."
  (interactive)
  (kill-new (sp-font-cycle--form))
  (message "Copied: %s" (current-kill 0)))

(defun sp-font-cycle--description ()
  "Header showing the previewed font, its size and its place in the list."
  (format "%s  %dpt  [%d/%d]"
          (propertize (face-attribute 'default :family nil t) 'face 'bold)
          (/ (face-attribute 'default :height nil t) 10)
          (1+ sp-font-cycle--index)
          (length (sp-font-cycle--installed))))

(transient-define-prefix sp-font-cycle-menu ()
  "Preview fonts and sizes of the `default' face."
  [:description sp-font-cycle--description
   ["Font"
    ("<right>" "next" sp-font-cycle-next :transient t)
    ("<left>" "previous" sp-font-cycle-previous :transient t)]
   ["Size"
    ("<up>" "bigger" font-size-increase :transient t)
    ("<down>" "smaller" font-size-decrease :transient t)]
   ["Keep"
    ("s" "save in config" sp-font-cycle-save)
    ("y" "copy as elisp" sp-font-cycle-copy)
    ("r" "restore" sp-font-cycle-restore :transient t)
    ("q" "quit" transient-quit-one)]])

(defun sp-font-cycle ()
  "Preview the installed fonts and sizes with a menu; `s' saves the choice."
  (interactive)
  (setq sp-font-cycle--start (cons (face-attribute 'default :family nil t)
                                   (face-attribute 'default :height nil t)))
  (sp-font-cycle--sync-index)
  (sp-font-cycle-menu))
#+end_src

** Saving the choice

=s= writes the previewed family and height into a fontaine preset (the current preset by default; =regular= when none was set) in this doc and in =libraries/modules/ui/sp-fonts.el=, and the row of the preset table above. The doc is edited as well as the module so the tangle check passes and the next tangle does not undo the change. It refuses when a buffer visiting either file has unsaved changes. Then it asks whether to reload the module (=load=), which re-evaluates the presets and sets the preset again.

Only =:default-family= and =:default-height= of the preset are changed. The variable-pitch font, the mode line heights and the other presets are not.

#+begin_src emacs-lisp -i
;;;;; Saving the choice
;; The family and the height of a preset live in `fontaine-presets', in the
;; preset forms of this file and of its doc.  Saving edits both, so the doc
;; stays the source of the tangled file.

(defun sp-font-cycle--module-file ()
  "Return the path of this module."
  (expand-file-name "libraries/modules/ui/sp-fonts.el" user-emacs-directory))

(defun sp-font-cycle--doc-file ()
  "Return the path of the literate doc of this module."
  (expand-file-name "docs/tangles/ui/sp-fonts.org" user-emacs-directory))

(defun sp-font-cycle--table-row (preset family height)
  "Update the row of PRESET in the preset table of the current buffer, if any.
FAMILY and HEIGHT are the new values; the cell widths are kept."
  (goto-char (point-min))
  (when (re-search-forward (format "^| *=%s= *|.*$" (regexp-quote (symbol-name preset)))
                           nil t)
    (let* ((beg (match-beginning 0))
           (end (match-end 0))
           (cells (split-string (match-string 0) "|"))
           (set-cell (lambda (n text)
                       (setf (nth n cells)
                             (string-pad (concat " " text)
                                         (max (length (nth n cells))
                                              (+ 1 (length text))))))))
      (when (>= (length cells) 5)
        (funcall set-cell 2 family)
        (funcall set-cell 4 (number-to-string height))
        (delete-region beg end)
        (goto-char beg)
        (insert (string-join cells "|"))))))

(defun sp-font-cycle--rewrite (file preset family height)
  "Set the default family and height of PRESET in FILE to FAMILY and HEIGHT.
Return non-nil when FILE changed.  Signal a `user-error' when PRESET has no
`:default-family' and `:default-height' in FILE."
  (let ((buffer (find-buffer-visiting file)))
    (when (and buffer (buffer-modified-p buffer))
      (user-error "Save %s first" (abbreviate-file-name file)))
    (with-temp-buffer
      (insert-file-contents file)
      (let ((original (buffer-string)))
        (goto-char (point-min))
        (unless (re-search-forward
                 (format "(%s$" (regexp-quote (symbol-name preset))) nil t)
          (user-error "No preset %s in %s" preset (abbreviate-file-name file)))
        (let ((start (match-beginning 0))
              end)
          (setq end (with-syntax-table emacs-lisp-mode-syntax-table
                      (scan-sexps start 1)))
          (save-restriction
            (narrow-to-region start end)
            (dolist (change `((":default-family \"[^\"]*\""
                               . ,(format ":default-family %S" family))
                              (":default-height [0-9]+"
                               . ,(format ":default-height %d" height))))
              (goto-char (point-min))
              (unless (re-search-forward (car change) nil t)
                (user-error "Preset %s has no %s in %s" preset
                            (car change) (abbreviate-file-name file)))
              (replace-match (cdr change) t t))))
        (sp-font-cycle--table-row preset family height)
        (unless (string= original (buffer-string))
          (write-region (point-min) (point-max) file nil 'silent)
          (when buffer
            (with-current-buffer buffer (revert-buffer t t t)))
          t)))))

(defun sp-font-cycle--read-preset ()
  "Ask for the fontaine preset to change, the current one by default."
  (let* ((names (mapcar #'symbol-name
                        (seq-remove (lambda (name) (eq name t))
                                    (mapcar #'car fontaine-presets))))
         (current (and (boundp 'fontaine-current-preset)
                       (symbol-name fontaine-current-preset))))
    (intern (completing-read
             (format "Save font in preset (default %s): "
                     (or current "regular"))
             names nil t nil nil (or current "regular")))))

(defun sp-font-cycle-save (&optional preset)
  "Make the previewed font the one of PRESET in the config, permanently.
Edit the preset in the doc and in the module, then offer to reload the module.
PRESET is asked for, with the current fontaine preset as the default."
  (interactive)
  (unless (require 'fontaine nil t)
    (user-error "Fontaine is not available"))
  (let* ((preset (or preset (sp-font-cycle--read-preset)))
         (family (face-attribute 'default :family nil t))
         (height (face-attribute 'default :height nil t))
         (files (list (sp-font-cycle--doc-file) (sp-font-cycle--module-file)))
         (changed (delq nil (mapcar (lambda (file)
                                      (and (sp-font-cycle--rewrite
                                            file preset family height)
                                           (abbreviate-file-name file)))
                                    files))))
    (if (not changed)
        (message "Preset %s already is %s at %d" preset family height)
      (message "Preset %s is now %s at %d in %s" preset family height
               (string-join changed ", "))
      (when (y-or-n-p (format "Reload %s to make it permanent? "
                              (file-name-nondirectory
                               (sp-font-cycle--module-file))))
        (load (sp-font-cycle--module-file) nil 'nomessage)
        (fontaine-set-preset preset)))))
#+end_src

* Lin

** The lin package

Installs =lin=, which highlights the current line in modes where it helps. The face is =lin-blue=, and =lin-mode-hooks= lists the modes it applies to. Both are =:custom= entries; they used to be =setq= forms after the =use-package=.

#+begin_src emacs-lisp -i
;;;; Lin package
(use-package lin
  :ensure t

  :custom
  (lin-face 'lin-blue)  ; this can be set to whatever color I might want otherwise
  (lin-mode-hooks
   '(bongo-mode-hook
     dired-mode-hook
     elfeed-search-mode-hook
     git-rebase-mode-hook
     grep-mode-hook
     ibuffer-mode-hook
     ilist-mode-hook
     ledger-report-mode-hook
     log-view-mode-hook
     magit-log-mode-hook
     mu4e-headers-mode-hook
     notmuch-search-mode-hook
     notmuch-tree-mode-hook
     occur-mode-hook
