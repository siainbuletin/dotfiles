A small module for how Emacs handles colours. It makes macOS use the sRGB colour space and sets up =rainbow-mode=, which shows colour names and hex codes in their own colour. It is loaded in the UI section of =init.el=, right after =sp-icons=. The =rainbow-mode= setup only runs when =sp-load-extras= is non-nil and the package is installed.

* Colour settings

** sRGB on macOS

Tells the macOS (NS) port to interpret colours in sRGB, so colours match other applications. On other platforms the variable has no effect.

#+begin_src emacs-lisp -i
(setq-default ns-use-srgb-colorspace t)
#+end_src

** rainbow-mode

Turns on =rainbow-mode= in all programming modes, so colour strings such as =#ff0000= are drawn with that colour as background. With =rainbow-x-colors= nil, plain X colour names like =red= are not highlighted, only hex and similar codes. The package is loaded at startup since =:commands= is commented out and the config does not defer by default.

#+begin_src emacs-lisp -i
;;;; Show Colors
;; https://github.com/emacsmirror/rainbow-mode
;; Colorize color names in buffers
(use-package rainbow-mode
  :if (and sp-load-extras (locate-library "rainbow-mode"))
  ;; :commands rainbow-mode
  :config
  (progn (setq rainbow-x-colors nil)
         (add-hook 'prog-mode-hook 'rainbow-mode))
  )
#+end_src
