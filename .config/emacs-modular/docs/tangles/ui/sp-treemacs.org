Literate source for =libraries/modules/ui/sp-treemacs.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

This module installs =treemacs= and shows the emacs-modular folder as a file tree in a side window, so the modules and their docs in =docs/tangles= stay in view while editing. The tree only opens when asked for, with =<f9>=, which also closes it again. No treemacs extensions are installed.

The module is part of the window management group in the default module list, loaded after =sp-mini-frame=.

* Header

** File header and commentary

Lexical binding and a short commentary. It explains why the tree is rooted at a fixed folder: the dotfiles are a yadm repository whose root is the home folder, so treemacs' usual "current project" would be all of =$HOME=.

* Configuration

** The folder to show

=sp-treemacs-root= is the folder the tree starts from. It defaults to =user-emacs-directory=, which is =~/.config/emacs-modular/=. Set it to another folder, for example ="~/notes/"=, to look at something else; the old folder stays in the treemacs workspace until it is removed there with =C-c C-p r=.

#+begin_src emacs-lisp -i
(defcustom sp-treemacs-root user-emacs-directory
  "Folder shown in the treemacs side window by `sp-treemacs-toggle'."
  :type 'directory
  :group 'spconfig)
#+end_src

** treemacs

Installs treemacs through Elpaca and binds =<f9>= globally to =sp-treemacs-toggle=. Until the first press, =<f9>= is only an autoload: pressing it loads treemacs, runs the =:config= section, and then calls the command. The workspace treemacs saves between sessions goes to =sp-cache-dir= (under =var/=), so it doesn't appear as a new file in the config folder. The side window is 35 columns wide, and =treemacs-follow-mode= moves the tree's cursor to whichever file is being edited.

=sp-treemacs-toggle= closes the treemacs window when it is visible. Otherwise it adds =sp-treemacs-root= to the workspace (only the first time) and opens the window with point in it. It is defined in =:config= rather than at the top level because =treemacs-is-path= is a macro, which has to exist before the function is read. Inside the tree, =RET= or =TAB= opens a folder, =RET= on a file visits it, and =?= lists the other keys.

#+begin_src emacs-lisp -i
(use-package treemacs
  :ensure t
  :bind ("<f9>" . sp-treemacs-toggle)
  :custom
  ;; Keep the saved workspace out of the config folder.
  (treemacs-persist-file (expand-file-name "treemacs-persist" sp-cache-dir))
  (treemacs-width 35)
  :config
  ;; Move the tree's cursor to the file being edited.
  (treemacs-follow-mode t)

  ;; Defined here, after treemacs has loaded, because `treemacs-is-path' is
  ;; a macro. Until then <f9> is an autoload that loads treemacs.
  (defun sp-treemacs-toggle ()
    "Show or hide treemacs with `sp-treemacs-root' in its workspace.
The root is added to the workspace the first time it is shown."
    (interactive)
    (if (eq (treemacs-current-visibility) 'visible)
        (delete-window (treemacs-get-local-window))
      (let ((root (directory-file-name (expand-file-name sp-treemacs-root))))
        (unless (treemacs-is-path root :in-workspace)
          (treemacs-do-add-project-to-workspace
           root (file-name-nondirectory root))))
      (treemacs-select-window))))
#+end_src
