Literate source for =libraries/modules/ui/sp-tabs.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module configures the built-in =tab-bar= and the =tabspaces= package so that tabs act as workspaces: each tab holds a window layout and its own isolated set of buffers, usually tied to a project. It adds numbered tab names using circled digits, a do-what-I-mean tab switcher, a keymap of tabspaces commands and a consult buffer source limited to the current workspace.

The setup is inherited from Lambda Emacs (hence the =lem-= prefix). It is loaded in the window-management part of =init.el=, after =sp-buffers= and =sp-windows=. Note that nothing in the config turns on =tab-bar-mode= or =tabspaces-mode=, and =tab-bar-show= is nil, so most of this stays dormant until those modes are enabled by hand. The consult integration needs =consult= and the tabspaces predicate =tabspaces--local-buffer-p=.

* Header

** File header and commentary

Lexical binding and the commentary, which explains the idea: tab-bar tabs are used for window configurations belonging to a workspace (a project or another set of windows), and a tabspace is a tab with an isolated set of buffers.

* Tab bar

The tab bar replaces the older =eyebrowse= package for grouping window layouts.

** Numbered tab names

=lem-tab-bar--circle-numbers-alist= maps 0 to 15 to circled Unicode digits. =lem--tab-bar-tab-name-format= uses it to draw each tab as its number, a small gap, the tab name and optionally a close button, with the face given by =tab-bar-tab-face-function=. The number only appears when =tab-bar-tab-hints= is on and the index is below 16. The idea comes from a post by Christian Tietze.

#+begin_src emacs-lisp -i
;;;; Tab Bar
;; Use tab-bar for window grouping and configuration within a project (replaces eyebrowse)

;; https://christiantietze.de/posts/2022/02/emacs-tab-bar-numbered-tabs/
(defvar lem-tab-bar--circle-numbers-alist
  '((0 . "⓪")
    (1 . "①")
    (2 . "②")
    (3 . "③")
    (4 . "④")
    (5 . "⑤")
    (6 . "⑥")
    (7 . "⑦")
    (8 . "⑧")
    (9 . "⑨")
    (10 . "⑩")
    (11 . "⑪")
    (12 . "⑫")
    (13 . "⑬")
    (14 . "⑭")
    (15 . "⑮"))

  "Alist of integers to strings of circled unicode numbers.")
(defun lem--tab-bar-tab-name-format (tab i)
  (let ((current-p (eq (car tab) 'current-tab))
        (tab-num (if (and tab-bar-tab-hints (< i 16))
                     (alist-get i lem-tab-bar--circle-numbers-alist) "")))
    (propertize
     (concat
      " "
      tab-num
      (propertize " " 'display '(space :width (4)))
      (alist-get 'name tab)
      (or (and tab-bar-close-button-show
               (not (eq tab-bar-close-button-show
                        (if current-p 'non-selected 'selected)))
               tab-bar-close-button)
          "")
      (propertize " " 'display '(space :width (4))))
     'face (funcall tab-bar-tab-face-function tab))))
#+end_src

** tab-bar settings and DWIM switcher

Configures the built-in =tab-bar= once =project= is loaded. The tab bar is hidden (=tab-bar-show= nil) but tabs show numbers, new tabs open the =*scratch*= buffer and are placed at the far right, =s-1= to =s-9= select tabs by number, closing a tab returns to the most recently used one, and closing the last tab turns =tab-bar-mode= off. The new and close buttons are hidden, tabs keep their natural width, and the bar layout is history buttons, tabs, the suffix space and an add-tab element. =tab-bar-new-button= is set twice, which is harmless.

=lem-tab-bar-select-tab-dwim= creates a tab when there is only one, switches to the other when there are two, and otherwise asks with completion. It comes from Protesilaos Stavrou and is not bound to a key here.

#+begin_src emacs-lisp -i
(use-package tab-bar
  :ensure nil
  :after (project)
  :commands (tab-bar-new-tab
             tab-bar-switch-to-tab
             tab-bar-switch-to-next-tab
             tab-bar-switch-to-prev-tab)
  :custom
  ;; Set this to nil unless tab bar is in use
  (tab-bar-show nil)
  (tab-bar-tab-hints t) ;; show numbers in tabs
  ;; Unless another file/buffer is designated, start from workspace scratch buffer
  (tab-bar-new-tab-choice "*scratch*")
  (tab-bar-select-tab-modifiers '(super))
  (tab-bar-close-tab-select 'recent)
  (tab-bar-new-tab-to 'rightmost)
  (tab-bar-close-last-tab-choice 'tab-bar-mode-disable)
  (tab-bar-tab-name-format-function #'lem--tab-bar-tab-name-format)
  (tab-bar-new-button nil)
  (tab-bar-close-button nil)
  (tab-bar-close-button-show nil)
  (tab-bar-new-button nil)
  (tab-bar-auto-width nil)
  (tab-bar-format '(tab-bar-format-history
                    tab-bar-format-tabs
                    lem--tab-bar-suffix
                    tab-bar-format-add-tab))
  :config

  ;; https://protesilaos.com/codelog/2020-08-03-emacs-custom-functions-galore/
  (defun lem-tab-bar-select-tab-dwim ()
    "Do-What-I-Mean function for getting to a `tab-bar-mode' tab.
If no other tab exists, create one and switch to it.  If there is
one other tab (so two in total) switch to it without further
questions.  Otherwise use completion to select the tab."
    (interactive)
    (let ((tabs (mapcar (lambda (tab)
                          (alist-get 'name tab))
                        (tab-bar--tabs-recent))))
      (cond ((eq tabs nil)
             (tab-new))
            ((eq (length tabs) 1)
             (tab-next))
            (t
             (tab-bar-switch-to-tab
              (completing-read "Select tab: " tabs nil t)))))))
#+end_src

* Tabspaces workspaces

** tabspaces package

Installs =tabspaces= and makes its main commands autoload. Buffer lists are filtered to the current workspace by default, the default tab is called =Home=, removed buffers go back to it, and =*scratch*= is included in every workspace. Opening a project creates a =project-todo.org= file, workspaces are saved as a session and restored automatically, project paths are resolved to absolute ones, and =*Messages*= and =*Compile-Log*= are left out of workspaces. The commented-out hook would start =tabspaces-mode= at startup; it is not enabled anywhere in the config.

#+begin_src emacs-lisp -i
;;;; Tab Workspaces
(use-package tabspaces
  :ensure t
  ;; :hook
  ;; (after-init . tabspaces-mode) ;; use this only if you want the minor-mode loaded at startup.
  
  :commands (tabspaces-switch-or-create-workspace
             tabspaces-open-or-create-project-and-workspace)
  
  :custom
  (tabspaces-use-filtered-buffers-as-default t)
  (tabspaces-default-tab "Home")
  (tabspaces-remove-to-default t)
  (tabspaces-include-buffers '("*scratch*"))
  (tabspaces-initialize-project-with-todo t)
  (tabspaces-todo-file-name "project-todo.org")
  
  ;; sessions
  (tabspaces-session t)
  (tabspaces-session-auto-restore t)
  
  ;; additional options
  (tabspaces-fully-resolve-paths t)  ; Resolve relative project paths to absolute
  (tabspaces-exclude-buffers '("*Messages*" "*Compile-Log*"))  ; Additional buffers to exclude
  (tab-bar-new-tab-choice "*scratch*"))
#+end_src

** Tabspaces command map

Defines =tabspaces-command-map= with single-key commands: =s= switch or create a workspace, =o= open a project in a workspace, =b= switch buffer within the workspace, =t= switch to a buffer and its tab, =d= close a workspace, =k= kill its buffers and close it, =n= rename, =r= and =R= remove buffers, =C= clear buffers, =w= show workspaces and =T= toggle echo area display. Because it is defined before tabspaces loads, this map is the one tabspaces uses; it becomes reachable under =tabspaces-keymap-prefix= once =tabspaces-mode= is on.

#+begin_src emacs-lisp -i
;; Keybindings for tabspaces
(defvar tabspaces-command-map
  (let ((map (make-sparse-keymap)))
    (define-key map (kbd "C") 'tabspaces-clear-buffers)
    (define-key map (kbd "b") 'tabspaces-switch-to-buffer)
    (define-key map (kbd "d") 'tabspaces-close-workspace)
    (define-key map (kbd "k") 'tabspaces-kill-buffers-close-workspace)
    (define-key map (kbd "n") 'tabspaces-rename-workspace)
    (define-key map (kbd "o") 'tabspaces-open-or-create-project-and-workspace)
    (define-key map (kbd "r") 'tabspaces-remove-current-buffer)
    (define-key map (kbd "R") 'tabspaces-remove-selected-buffer)
    (define-key map (kbd "s") 'tabspaces-switch-or-create-workspace)
    (define-key map (kbd "t") 'tabspaces-switch-buffer-and-tab)
    (define-key map (kbd "w") 'tabspaces-show-workspaces)
    (define-key map (kbd "T") 'tabspaces-toggle-echo-area-display)
    map)
  "Keymap for tabspace/workspace commands after `tabspaces-keymap-prefix'.")
#+end_src

* Workspace buffers in consult

** Buffer filter

=lem-buff-filter= returns non-nil when a buffer is in the current frame's buffer list, other than the current buffer. It is not used anywhere else in the config.

#+begin_src emacs-lisp -i
;;;;; Consult Isolated Workspace Buffers
;; Filter Buffers for Consult-Buffer
(defun lem-buff-filter (buffer)
  (let ((blst (cl-remove (buffer-name) (frame-parameter nil 'buffer-list))))
    (memq buffer blst)))
#+end_src

** Consult source for workspace buffers

After consult loads, the normal buffer source is hidden from =consult-buffer= (still reachable with the =b= narrowing key) and is no longer the default. A new source, =consult-source-workspace=, lists only buffers that belong to the current tabspace, sorted by visibility, under the narrowing key =w=. The new source is not added to =consult-buffer-sources= in this module, so it only shows up if that is done elsewhere; as things stand, hiding the default source means =consult-buffer= lists fewer buffers by default.

#+begin_src emacs-lisp -i
(with-eval-after-load 'consult
  ;; hide full buffer list (still available with "b" prefix)
  ;; Use plist-put instead of consult-customize for internal sources
  ;; Use boundp check to handle package-quickstart timing issues
  (when (boundp 'consult-source-buffer)
    (plist-put consult-source-buffer :hidden t)
    (plist-put consult-source-buffer :default nil))
  ;; set consult-workspace buffer list
  (defvar consult-source-workspace
    (list :name     "Workspace Buffers"
          :narrow   ?w
          :history  'buffer-name-history
          :category 'buffer
          :state    #'consult--buffer-state
          :default  t
          :items    (lambda () (consult--buffer-query
                           :predicate #'tabspaces--local-buffer-p
                           :sort 'visibility
                           :as #'buffer-name)))

    "Set workspace buffer list for consult-buffer."))
#+end_src
