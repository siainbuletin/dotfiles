The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

Org always ends a tangled file with a newline, which the module file has too.

This module only changes how Magit looks. Section headings (=magit-section-heading=, the "Unstaged changes" lines) become larger, bold and overlined; per-file headings in diffs (=magit-diff-file-heading=) become slightly larger; folded and expanded sections get chevron indicators; and files and directories get a =nerd-icons= icon in front of their name. It depends on =magit= and, for icons, on =nerd-icons= (set up in [[file:../ui/sp-icons.org][sp-icons]]); without =nerd-icons= only the heading styling applies. It is loaded right after =sp-vcontrol= in the Programming group of =init.el=.

Status: written without being run. Nothing here has been tested in Emacs yet.

** Options

=sp-magit-style-icons= turns the icons off; =sp-magit-style-heading-height= is the relative height of section headings.

#+begin_src emacs-lisp -i
(defgroup sp-magit-style nil
  "Prettier Magit buffers."
  :group 'magit)

(defcustom sp-magit-style-icons t
  "Show nerd-icons next to files and directories in Magit buffers."
  :type 'boolean
  :group 'spconfig)

(defcustom sp-magit-style-heading-height 1.15
  "Relative height of Magit section headings."
  :type 'number
  :group 'spconfig)
#+end_src

** Icons

=magit-format-file-function= is called by Magit for every file it lists, with a KIND (=status=, =diff= or =tree=), the file name, a face, and for renames the old name. The function calls Magit's own default formatter and puts an icon in front. A name ending in =/= (an untracked directory) gets a directory icon from =nerd-icons-icon-for-dir=, anything else an icon by file name. Errors from =nerd-icons= are swallowed so a missing font never breaks the status buffer.

#+begin_src emacs-lisp -i
(defun sp-magit-style--icon (kind file)
  "Return an icon string for FILE (a path) in a Magit buffer of KIND, or nil."
  (when (and sp-magit-style-icons (fboundp 'nerd-icons-icon-for-file))
    (let ((dirp (string-suffix-p "/" file)))
      (ignore-errors
        (if dirp
            (nerd-icons-icon-for-dir file)
          (nerd-icons-icon-for-file (file-name-nondirectory file)))))))

(defun sp-magit-style-format-file (kind file face &optional status orig)
  "Format FILE like `magit-format-file-default', prefixed by an icon.
KIND, FACE, STATUS and ORIG are as for `magit-format-file-function'."
  (let ((text (magit-format-file-default kind file face status orig))
        (icon (sp-magit-style--icon kind file)))
    (if icon (concat icon " " text) text)))
#+end_src

** Faces

Sets the heading attributes. They are set directly on the faces rather than through =custom-set-faces=, so they win over what the theme does when Magit loads, and the hook below repeats them after every theme change.

#+begin_src emacs-lisp -i
(defun sp-magit-style--set-faces ()
  "Enlarge and underline Magit section headings."
  (dolist (face '(magit-section-heading magit-diff-file-heading))
    (when (facep face)
      (set-face-attribute face nil
                          :height (if (eq face 'magit-section-heading)
                                      sp-magit-style-heading-height
                                    1.05)
                          :weight 'bold)))
  (when (facep 'magit-section-heading)
    (set-face-attribute 'magit-section-heading nil
                        :overline t :extend t))
  (when (facep 'magit-branch-local)
    (set-face-attribute 'magit-branch-local nil :box nil)))
#+end_src

** Hooks

Chevron indicators come from =magit-section-visibility-indicators=; the two glyphs are Font Awesome chevron-right and chevron-down from the Nerd Font, so they need the same font as the icons (in a terminal, the terminal's Nerd Font). If they show as boxes, set the variable back to its default.

#+begin_src emacs-lisp -i
(with-eval-after-load 'magit-section
  ;; Chevrons instead of the default fringe bitmaps (also work in a TTY).
  (setq magit-section-visibility-indicators
        (list (cons (string #xf054) (string #xf078))))
  (sp-magit-style--set-faces)
  ;; Re-apply after a theme change, which resets face attributes.
  (add-hook 'enable-theme-functions
            (lambda (&rest _) (sp-magit-style--set-faces))))

(with-eval-after-load 'magit
  (setq magit-format-file-function #'sp-magit-style-format-file))
#+end_src
