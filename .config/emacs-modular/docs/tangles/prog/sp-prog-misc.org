- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../tangling-instructions.org][Tangling instructions]].

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

A grab bag of programming-related packages and general editor settings.

It installs:

- a set of major modes for configuration and data formats (YAML, JSON, Dockerfiles, systemd units and more),
- visual helpers such as =rainbow-delimiters= and =git-gutter=,
- =envrc= for per-directory environments.

It also sets many global defaults that are not specific to programming: short yes/no answers, focus following the mouse, recent files, ediff layout, mouse scrolling and terminal mouse support.

Loading and dependencies:

- Loaded in the Programming section of =init.el=, after =sp-base-code=.
- Packages are installed through use-package (with elpaca as the package manager elsewhere in the config).
- =envrc= expects the external =direnv= program.
- The ediff settings use the system =diff=.

** Selection and focus follows mouse

Enables =delete-selection-mode=, so typing replaces the selection.

- The option =siapip/focus-follows-mouse= (default t) drives =focus-follows-mouse=.
- =mouse-autoselect-window= is set to a negative delay.
- As the comment explains, the negative value means a window is only selected once the mouse rests on it, and the minibuffer is never auto-selected.
- So moving the mouse does not pull focus away from an active completion session.

#+begin_src emacs-lisp -i
;; Selection/Clipboard improvements
(delete-selection-mode t)
;; (transient-mark-mode t)
;;focus follow mouse
(defcustom siapip/focus-follows-mouse t
  "When non-nil, focus follows the mouse pointer."
  :type 'boolean
  :group 'spcustom)
;; Negative delay: debounces auto-selection (brushing past a split won't grab
;; it) and, crucially, suppresses minibuffer auto-selection so mouse nudges
;; don't yank focus out of an active vertico/consult session.
(setq mouse-autoselect-window -0.2
      focus-follows-mouse siapip/focus-follows-mouse)
;;(setq interprogram-paste-function 'x-cut-buffer-or-selection-value)
#+end_src

** Diff against the clipboard

=my/ediff-with-clipboard= starts ediff between two things:

- the current buffer, or a copy of the active region,
- a new buffer holding the latest kill or clipboard text.

Both sides use the current major mode so they are fontified the same. The comment says it is meant for comparing code with AI-generated versions.

#+begin_src emacs-lisp -i
;;;;; Diffing against the clipboard (for code generated with AI)
(defun my/ediff-with-clipboard ()
  "Ediff the current buffer (or active region) against the latest kill/clipboard."
  (interactive)
  (let* ((mode major-mode)
         (clip (generate-new-buffer "*clipboard*"))
         (orig (if (use-region-p)
                   (let ((b (generate-new-buffer "*region*"))
                         (s (buffer-substring (region-beginning) (region-end))))
                     (with-current-buffer b (insert s) (funcall mode))
                     b)
                 (current-buffer))))
    (with-current-buffer clip
      (insert (current-kill 0))
      (funcall mode))
    (ediff-buffers orig clip)))
#+end_src

** Mouse wheel scrolling

Defines =siapip/scroll-amount= (5 lines) and two small commands, =up-slightly= and =down-slightly=, then binds them to =mouse-4= and =mouse-5=, the wheel events used on X11 and in terminals.

#+begin_src emacs-lisp -i
;;Mouse scroll
(defcustom siapip/scroll-amount 5
  "Scolling up/down will jump by this amount."
  :type 'integer
  :group 'spcustom)
(defun up-slightly () (interactive) (scroll-up siapip/scroll-amount))
(defun down-slightly () (interactive) (scroll-down siapip/scroll-amount))
(global-set-key [mouse-4] 'down-slightly)
(global-set-key [mouse-5] 'up-slightly)
#+end_src

** Terminal mouse support

When Emacs runs in a terminal, it enables =xterm-mouse-mode= so clicks and scrolling work. It also defines =track-mouse= as an empty function, a workaround from an old Stack Overflow answer; =track-mouse= is normally a macro, so this may break code that relies on it in terminal frames.

#+begin_src emacs-lisp -i
;;Term or GUI mode mouse changes
(unless (display-graphic-p)
  (require 'mouse)
  ;;http://stackoverflow.com/questions/3466643/emacs-unicode-xterm-mouse-escape-sequences-and-wide-terminals
  (xterm-mouse-mode t)
  (defun track-mouse (e))
  (setq mouse-sel-mode t))
#+end_src

* Git, folding and environments

** git-gutter

Shows added, changed and deleted lines in the margin. It is turned on in programming modes through a hook, which also loads the package, and the =:config= then enables it globally and updates the markers every 0.2 seconds.

#+begin_src emacs-lisp -i
(use-package git-gutter
  :ensure t
  
  :config
  (global-git-gutter-mode t)
  (setq git-gutter:update-interval 0.2)
  
  :hook
  (prog-mode . git-gutter-mode)
)
#+end_src

** git-gutter-fringe and open thing at point

Installs =git-gutter-fringe=, which draws the git-gutter markers in the fringe instead of the margin.

The same block binds =C-c b= globally to a small command that opens the URL at point in a browser, or else visits the file name at point. In Org buffers =sp-citations= rebinds =C-c b= to =org-cite-insert=.

#+begin_src emacs-lisp -i
;; this will ensure that there's a git gutter in dired
(use-package git-gutter-fringe
  :ensure t)
         
(global-set-key
 (kbd "C-c b")
 (lambda ()
   (interactive)
   (let ((url (thing-at-point 'url))
         (filename (thing-at-point 'filename)))
     (cond
      (url (browse-url url))
      (filename (find-file filename))
      (t (message "No URL or file found"))))))
#+end_src
