Literate source for =libraries/modules/prog/sp-plantuml.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

This module defines a small home-made major mode, =siapip/plantuml-mode=, for PlantUML diagram files (=.puml=). Every time such a file is saved it runs the PlantUML jar through Java to render a PNG next to the source and shows that image in a preview buffer. It does not use the third-party =plantuml-mode= package and has no dependencies besides Java and a local =plantuml.jar=.

The module is not loaded by any module list or profile. Note also that the file ends with =(provide 'siapip/plantuml-mode)= rather than =(provide 'sp-plantuml)=, so =(require 'sp-plantuml)= would load the code but then signal that the file did not provide the expected feature. It would need to be loaded with =load= or have its =provide= changed to be used through the module loader.

* Options

** Enable the mode for .puml files

=siapip/plantuml:enable= is a boolean option whose =:set= function adds =.puml= to =auto-mode-alist= when true and removes it when false. Because =defcustom= runs the =:set= function when the file loads, the association is installed as soon as the module is loaded, and toggling the option through Customize takes effect immediately.

#+begin_src emacs-lisp -i
;; -*- lexical-binding: t; -*-
(defcustom siapip/plantuml:enable t
  "Whether the plantuml mode is enabled."
  :group 'siapip
  :type 'boolean
  :set (lambda (sym val)
         (set-default sym val)
         (if val
             (add-to-list 'auto-mode-alist '("\\.puml\\'" . siapip/plantuml-mode))
           (setq auto-mode-alist
                 (delete '("\\.puml\\'" . siapip/plantuml-mode) auto-mode-alist)))))
#+end_src

** Location of the PlantUML jar

=siapip/plantuml-jar-file= points at the PlantUML jar, =~/opt/plantuml/plantuml.jar= by default.

#+begin_src emacs-lisp -i
(defcustom siapip/plantuml-jar-file "~/opt/plantuml/plantuml.jar"
  "The path to the plantuml jar file."
  :group 'siapip
  :type 'file)
#+end_src

* Rendering and preview

** Generate a PNG

=siapip/plantuml-generate-png= runs =java -jar plantuml.jar -tpng= on the current file with both paths shell-quoted, which writes a PNG beside the source. It does nothing if the jar is missing. It uses =shell-command=, so Emacs waits until Java finishes, and the output buffer may pop up.

#+begin_src emacs-lisp -i
(defun siapip/plantuml-generate-png ()
  "Generate a PNG from the current plantuml file."
  (when (and siapip/plantuml-jar-file (file-exists-p siapip/plantuml-jar-file))
    (let ((cmd (format "java -jar %s -tpng %s"
                       (shell-quote-argument (expand-file-name siapip/plantuml-jar-file))
                       (shell-quote-argument buffer-file-name))))
      (shell-command cmd))))
#+end_src

** Show the preview

=siapip/plantuml-preview= looks for the PNG with the same base name as the current file. If it exists, it fills a read-only =*plantuml-preview*= buffer with the image, clearing the image cache first so the new render is shown. In that buffer =q= runs =quit-window=, and a header line says so. The buffer is displayed if it is not already visible.

#+begin_src emacs-lisp -i
(defun siapip/plantuml-preview ()
  "Display the PNG image for a plantuml file."
  (let* ((png-file (concat (file-name-sans-extension buffer-file-name) ".png"))
         (buf-name "*plantuml-preview*"))
    (when (file-exists-p png-file)
      (let ((preview-buffer (get-buffer-create buf-name)))
        (with-current-buffer preview-buffer
          (setq buffer-read-only nil)
          (erase-buffer)

          (use-local-map (make-sparse-keymap))
          (local-set-key (kbd "q") 'quit-window)
          
          (clear-image-cache png-file)
          (insert-image (create-image png-file))
          (setq header-line-format "Press 'q' to close.")
          (setq buffer-read-only t)
          (unless (get-buffer-window preview-buffer)
            (display-buffer preview-buffer)))))))
#+end_src

** Render on save

=siapip/plantuml-save-hook= regenerates the PNG and refreshes the preview, but only for files whose extension is =puml=.

#+begin_src emacs-lisp -i
(defun siapip/plantuml-save-hook ()
  "Hook to run after saving a plantuml file."
  (when (string= (file-name-extension buffer-file-name) "puml")
    (siapip/plantuml-generate-png)
    (siapip/plantuml-preview)))
#+end_src

* Major mode

** siapip/plantuml-mode

A major mode derived from =prog-mode=, shown as "PUML" in the mode line. It adds no syntax highlighting or indentation; its only job is to add the save hook locally in the buffer, so each save triggers a render and preview.

#+begin_src emacs-lisp -i
(define-derived-mode siapip/plantuml-mode prog-mode "PUML"
  "Major mode for editing plantuml files."
  :group 'siapip
  (add-hook 'after-save-hook 'siapip/plantuml-save-hook nil t))
#+end_src

** Provide the feature

Provides the feature =siapip/plantuml-mode=, which does not match the file name, as described in the introduction.

#+begin_src emacs-lisp -i
(provide 'siapip/plantuml-mode)
#+end_src
