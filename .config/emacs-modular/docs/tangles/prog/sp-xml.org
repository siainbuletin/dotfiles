A one-form module that configures the built-in =nxml-mode= for XML schema and stylesheet files. It ends with =(provide 'sp-xml)=, but it is not listed in any profile in =init.el= or =sp-config-profiles.el=, so it appears to be unused at present.

* nXML configuration

** nxml-mode

Opens =.xsd= and =.xslt= files in =nxml-mode=.

- In nXML buffers it indents with spaces rather than tabs.
- It adds =~/.emacs.d/nxml-schemas/schemas.xml= to =rng-schema-locating-files=, so nXML can find extra schemas for validation and completion.
- That path is hard-coded and does not follow the config's own directories.

#+begin_src emacs-lisp -i
;;; sp-xml.el --- XML editing with nXML -*- lexical-binding: t; -*-

;;; Commentary:

;; A one-form module that configures the built-in `nxml-mode' for XML schema
;; and stylesheet files. It ends with `(provide 'sp-xml)', but it is not listed
;; in any profile in `init.el' or `sp-config-profiles.el', so it appears to be
;; unused at present.

;;; Code:

(use-package nxml-mode
  :ensure nil
  :defer t
  :mode (("\\.xsd\\'" . nxml-mode)
         ("\\.xslt\\'" . nxml-mode))
  :hook (nxml-mode . (lambda ()
	               (make-local-variable 'indent-tabs-mode)
	               (setq indent-tabs-mode nil)
	               (add-to-list 'rng-schema-locating-files
			            "~/.emacs.d/nxml-schemas/schemas.xml"))))
#+end_src
