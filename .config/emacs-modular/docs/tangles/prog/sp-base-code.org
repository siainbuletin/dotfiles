- Every line of the module lives in the =emacs-lisp= blocks below, in order.
- The =:tangle= path in the =#+PROPERTY= line at the top says where they are written.
- To tangle, see [[file:../../tangling-instructions.org][Tangling instructions]].

This module holds the programming setup that other language modules build on. It installs and configures:

- =smartparens= for paired delimiters,
- =highlight-indent-guides=,
- the built-in =semantic= analyser for C and C++,
- =company= with =company-quickhelp= for in-buffer completion,
- =lsp-mode= and =lsp-ui= for language servers,
- =flycheck=,
- the built-in =outline= library for folding code by comment headings.

The language modules (for example =sp-go=, =sp-rust=, =sp-nix= and =sp-lisp=) turn on =company-mode= and call =lsp= or =lsp-deferred= themselves; this module only sets the shared defaults those packages use. It is loaded at the start of the Programming block in the default module list of =init.el=.

* Semantic completion guard

** String and comment predicates

From a company-mode issue thread.

- =inside-string-q= and =inside-comment-q= use =syntax-ppss= to report whether point is inside a string or comment. Both are interactive and echo their result, so every call prints a message.
- =semantic-completion-advice= is an around advice that skips the wrapped function when point is in a string or comment. It is used below to stop Semantic from offering completions there.

#+begin_src emacs-lisp -i
;;; sp-base-code.el --- Shared programming setup: completion, LSP and outlines -*- lexical-binding: t; -*-

;;; Commentary:

;; This module holds the programming setup that other language modules build
;; on.

;;; Code:

;; see https://github.com/company-mode/company-mode/issues/525#issuecomment-348635719
(defun inside-string-q ()
  "Returns non-nil if inside string, else nil.
Result depends on syntax table's string quote character."
  (interactive)
  (let ((result (nth 3 (syntax-ppss))))
    (message "%s" result)
    result))
(defun inside-comment-q ()
  "Returns non-nil if inside comment, else nil.
Result depends on syntax table's comment character."
  (interactive)
  (let ((result (nth 4 (syntax-ppss))))
    (message "%s" result)
    result))
(defun semantic-completion-advice (adviced-f &rest r)
  "Check if POINT it's inside a string or comment before calling semantic-*"
  (unless (or (inside-string-q) (inside-comment-q))
    (apply adviced-f r)))
#+end_src

* Editing aids

** Indent guides

Installs =highlight-indent-guides= with the fill method and dark gray faces for odd and even indentation levels.

- Automatic face colouring is turned off, so those explicit colours are used.
- No hook enables the mode, so it has to be turned on per buffer.

#+begin_src emacs-lisp -i
(use-package highlight-indent-guides
  :ensure t
  :config
  (setq highlight-indent-guides-auto-enabled nil)
  (setq highlight-indent-guides-method 'fill)
  (set-face-background 'highlight-indent-guides-odd-face "gray14")
  (set-face-background 'highlight-indent-guides-even-face "gray18")
  (set-face-foreground 'highlight-indent-guides-character-face "gray16"))
#+end_src

* Semantic, completion and language servers

** Semantic for C and C++

Enables the built-in =semantic-mode= in C and C++ buffers.

- The completion function is wrapped with the string and comment guard above.
- =global-semantic-idle-completions-mode= is turned off, so Semantic does not pop up completions while idle.
- The comment wondering whether this is the LSP shows it predates the LSP setup below.

#+begin_src emacs-lisp -i
;; Semantic coding (is this the LSP?)
(use-package semantic
  :ensure nil
  :commands semantic-mode
  :hook ((c-mode . semantic-mode)
         (c++-mode . semantic-mode))
  :config
  (advice-add 'semantic-analyze-completion-at-point-function
              :around #'semantic-completion-advice)
  (global-semantic-idle-completions-mode -1))
#+end_src

** Company quickhelp

Installs =company-quickhelp=, which shows documentation popups next to company candidates, deferred until needed.

The declaration itself sits after =company= in the file, because =company-quickhelp= requires =company= and Elpaca would otherwise queue =company= as a dependency first and warn.

** Start quickhelp lazily

=company-init-quickhelp= turns on =company-quickhelp-mode= the first time a completion starts, then tries to remove itself from =company-completion-started-hook=.

- It is added to the global hook but removed with the buffer local flag, so the removal probably does nothing.
- The mode is then simply re-enabled on each completion, which is harmless.

#+begin_src emacs-lisp -i
(defun company-init-quickhelp (b-enable)
  "Initialize company-quickhelp only if company is running"
  (company-quickhelp-mode t)
  (remove-hook 'company-completion-started-hook 'company-init-quickhelp t))
#+end_src

** Company and lsp-mode

Company itself is installed in =sp-completion= (which loads earlier, through =sp-minibuffer=); this form has =:ensure nil= and only configures it.

Company is configured with:

- a 0.2 second idle delay,
- wrap-around selection,
- aligned annotations,
- no forced match,
- case preserving dabbrev.

On load it:

- hooks quickhelp,
- enables =company-tng-mode= (tab and go, where TAB cycles and inserts candidates),
- resets the backends to just =company-capf=, so completion comes from completion at point functions such as the LSP client.

=lsp-mode= is deferred until =lsp= or =lsp-deferred= is called. It is set to:

- use flycheck rather than flymake,
- watch files up to 10000,
- disable multi-root workspaces, symbol highlighting and the headerline breadcrumb,
- drop =lsp-java= from the client packages it loads.

#+begin_src emacs-lisp -i
(use-package company
  ;; Installed by `sp-completion'; a second :ensure t is a duplicate order.
  :ensure nil
  :defer t

  :init 
  (setq company-async-timeout 5
        company-dabbrev-downcase 0
        company-idle-delay 0.2
        company-irony-ignore-case t
        company-require-match nil
        company-selection-wrap-around t
        company-tooltip-align-annotations t)
  
  :config
  (add-hook 'company-completion-started-hook 'company-init-quickhelp)
  (company-tng-mode t)
  (setq company-backends '())
  (add-to-list 'company-backends 'company-capf) ; LSP completion backend
) 

(use-package lsp-mode
  :ensure t
  :defer t
  :commands (lsp lsp-deferred)
  :config (setq lsp-prefer-flymake nil
                lsp-enable-file-watchers t
                lsp-enable-multi-root nil
                lsp-enable-symbol-highlighting nil
                lsp-headerline-breadcrumb-enable nil
                lsp-file-watch-threshold 10000)
          (setq lsp-client-packages (delete 'lsp-java lsp-client-packages)))

;; After `company', which it requires.
(use-package company-quickhelp
  :ensure t
  :defer t)
#+end_src

** Outline minor mode for code

Turns on the built-in =outline-minor-mode= in every programming buffer.

- =M-j= and =M-k= move a subtree down and up. =M-h= and =M-l= promote and demote.
- With =outline-minor-mode-cycle= set, TAB cycles the visibility of the current section and Shift TAB cycles the whole buffer. This works only while point is on a heading, so TAB still indents and completes everywhere else.
- The module used to bind =<tab>= to =outline-cycle= for the whole mode, which took TAB over in every programming buffer.
- For Emacs Lisp, the outline regexp treats comments starting with three or more semicolons as headings, with levels from the number of semicolons.
- =outline-level= is reset so =lispy= cannot override it.

#+begin_src emacs-lisp -i
;; Navigate elisp files easily. Outline is a built-in library and we can easily
;; configure it to treat elisp comments as headings.
(use-package outline
  :ensure nil
  :hook (prog-mode . outline-minor-mode)
  :custom
  ;; TAB and S-TAB cycle visibility only when point is on a heading, so TAB
  ;; keeps indenting and completing everywhere else in prog-mode buffers.
  (outline-minor-mode-cycle t)
  :bind (:map outline-minor-mode-map
         ("M-j"     . outline-move-subtree-down)
         ("M-k"     . outline-move-subtree-up)
         ("M-h"     . outline-promote)
         ("M-l"     . outline-demote))
  :config
  (add-hook 'emacs-lisp-mode-hook
            (lambda ()
              ;; prevent `outline-level' from being overwritten by `lispy'
              (setq-local outline-level #'outline-level)
              ;; setup heading regexp specific to `emacs-lisp-mode'
              (setq-local outline-regexp ";;;\\(;* \\)")
              ;; heading alist allows for subtree-like folding
              (setq-local outline-heading-alist
                          '((";;; " . 1)
                            (";;;; " . 2)
                            (";;;;; " . 3)
                            (";;;;;; " . 4)
                            (";;;;;;; " . 5))))))
#+end_src
