Literate source for =libraries/modules/text/sp-org-custom-highlight.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. Tangling this file (=C-c C-v t=) rewrites that =.el= file from these blocks; nothing is tangled unless you run it.

A tiny module that makes Org inline export snippets of the form =@@comment:...@@= stand out visually, so they can be used as review notes inside running text. It defines one face and adds a font-lock rule in =org-mode-hook=.

The file has no header, no =provide= form, and is not required by =init.el= or any other module, so at present it is not loaded. To use it, it would need a =(provide 'sp-org-custom-highlight)= line and a =require= from one of the Org modules.

* Inline comment highlighting

** The comment face

Defines =my-org-inline-comment=, a face with a pale yellow background and black text, like a highlighter mark. The colours are fixed, so on a dark theme the box will be bright.

#+begin_src emacs-lisp -i
(defface my-org-inline-comment
  '((t :background "#fff3a3" :foreground "black"))
  "Face for @@comment:...@@ inline comments.")
#+end_src

** Font-lock rule in Org buffers

On every Org buffer, adds a font-lock keyword that matches =@@comment:= followed by text up to the closing =@@=. The two delimiters are shown in the =shadow= face so they fade into the background, and the comment body gets =my-org-inline-comment=. The pattern stops at a newline or an =@= sign, so a comment cannot span lines or contain =@=. The rule is appended after Org's own keywords and uses =prepend= so it layers on top of existing fontification.

#+begin_src emacs-lisp -i
(add-hook 'org-mode-hook
          (lambda ()
            (font-lock-add-keywords
             nil
             '(("\\(@@comment:\\)\\([^@\n]*\\)\\(@@\\)"
                (1 'shadow prepend)
                (2 'my-org-inline-comment prepend)
                (3 'shadow prepend)))
             'append)))
#+end_src
