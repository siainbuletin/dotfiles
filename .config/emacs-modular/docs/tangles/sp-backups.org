#+TITLE: sp-backups.el: Backups, auto-saving and history
#+PROPERTY: header-args:emacs-lisp :tangle ../../libraries/modules/tooling/sp-backups.el :comments no :padline yes :noweb no :mkdirp yes
#+STARTUP: content

Literate source for =libraries/modules/tooling/sp-backups.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. Tangling this file (=C-c C-v t=) rewrites that =.el= file from these blocks; nothing is tangled unless you run it.

This module decides where Emacs keeps backup files and auto-save files, turns on aggressive automatic saving of every modified file, disables lock files and enables =savehist= so minibuffer history survives restarts. It relies on the directory constants =sp-var-dir= and =sp-cache-dir= from =early-init.el= and installs the =vc-backup= package.

The file has grown in layers: backup settings are set several times with different values, and the later assignments win. Reading top to bottom, the effective result is that backups go to =backups/= under =sp-var-dir=, numbered, keeping the 6 newest and 3 oldest versions, and auto-save files go to =auto-save-files/= under =sp-cache-dir=. The module is loaded with the utility modules in =init.el=, in both the default and minimal lists.

* Backup location

** First backup directory

Defines the option =siapip/backup-file-location= (default =~/.emacs.d/backups=), creates that directory, warning instead of failing if it cannot, and points =backup-directory-alist= at it with copying backups. This location is overridden twice further down, so in practice only the empty directory remains from this block.

#+begin_src emacs-lisp -i
(defcustom siapip/backup-file-location "~/.emacs.d/backups"
  "Directory where backup files will be stored.
This specifies the path where Emacs will save backup files when
editing. The default location is in the .emacs.d directory."
  :type 'directory
  :group 'siapip)
(condition-case nil
    (make-directory siapip/backup-file-location t)
  (error (message "Warning: Could not create backup directory")))
(setq backup-directory-alist (list (cons "." siapip/backup-file-location)))
(setq backup-by-copying t)
#+end_src

** Auto-save and lock files off

Turns off auto-saving and lock files. The auto-save part is reversed immediately by the =files= block below, which turns auto-saving back on.

(setq auto-save-default nil)
(setq create-lockfiles nil)
#+end_src

* Backups and auto-save

** use-package files

Configures the built-in =files= library. In =:init=:
- backups go to =backup= under =sp-cache-dir=, created if missing;
- the auto-save list and auto-save files are kept under =sp-cache-dir= as well;
- auto-saving is turned on for every buffer, every 30 idle seconds or 300 keystrokes, and auto-save files are deleted after a real save;
- =auto-save-visited-mode= is enabled, which saves file-visiting buffers directly to their files.

The =:config= turns on numbered backups by copying, silently deletes old versions, keeps 10 new and 0 old ones, and also backs up files under version control. It defines =lem-full-auto-save=, which saves every modified file buffer and ignores errors, runs it from =auto-save-hook= and from a repeating 5 second idle timer. The net effect is that modified files are written to disk whenever Emacs is idle for a few seconds.

Because =files= is always preloaded, the deferred =:config= most likely runs at once, so the kept-version counts it sets are overridden by the next blocks.

#+begin_src emacs-lisp -i
;;;; Backups / Auto-Save
(use-package files
  :ensure nil
  :defer 1
  :init
  
  ;; backups
  (let ((backup-dir (concat sp-cache-dir "backup")))
    ;; Move backup file to `~/.emacs.d/temp/cache/backup'
    (setq backup-directory-alist `(("." . ,backup-dir)))
    ;; Makesure backup directory exist
    (when (not (file-exists-p backup-dir))
      (make-directory backup-dir t)))
  
  ;; auto save
  (setq auto-save-list-file-prefix
        (concat sp-cache-dir "auto-save-list/.saves-"))
  (let ((auto-save-files-dir (concat sp-cache-dir "auto-save-files/")))
    (setq auto-save-file-name-transforms
          `((".*" ,auto-save-files-dir t)))
    (when (not (file-exists-p auto-save-files-dir))
      (make-directory auto-save-files-dir t)))
  
  ;; auto-save every file visiting buffer
  ;; see https://emacs.stackexchange.com/q/7729/11934
  (setq-default auto-save-default t)
  (setq-default
   auto-save-timeout 30              ; number of seconds idle time before auto-save (default: 30)
   auto-save-interval 300            ; number of keystrokes between auto-saves (default: 300)
   delete-auto-save-files t
   create-lockfiles nil)
  (auto-save-visited-mode 1)
  :config
  (setq  make-backup-files t               ; backup of a file the first time it is saved.
         backup-by-copying t               ; don't clobber symlinks
         version-control t                 ; version numbers for backup files
         delete-old-versions t             ; delete excess backup files silently
         kept-old-versions 0               ; oldest versions to keep when a new numbered backup is made
         kept-new-versions 10              ; newest versions to keep when a new numbered backup is made
         vc-make-backup-files t            ; backup versioned files, which Emacs does not do by default
         )

  (defun lem-full-auto-save ()
    (interactive)
    (save-excursion
      (dolist (buf (buffer-list))
        (when (buffer-live-p buf)  ; Check if buffer is still valid
          (with-current-buffer buf  ; Use with-current-buffer instead of set-buffer
            (when (and (buffer-file-name) (buffer-modified-p))
              (condition-case nil  ; Catch any errors during save
                  (basic-save-buffer)
                (error nil))))))))

  (add-hook 'auto-save-hook 'lem-full-auto-save)

  ;; Save all buffers after idle time
  (run-with-idle-timer 5 t (lambda () (lem-full-auto-save))))
#+end_src

** Backup version counts

Sets numbered backups with 6 new and 2 old versions, deleting extra versions silently.

#+begin_src emacs-lisp -i
;; What to do with the backups?
(setq delete-old-versions t)
(setq kept-new-versions 6)
(setq kept-old-versions 2)
(setq version-control t)
#+end_src

** vc-backup

Installs =vc-backup=, a VC backend that treats Emacs backup files as a version history, so older backups can be browsed and diffed with the normal VC commands. Note that =sp-prog-misc= empties =vc-handled-backends=, which may keep this backend from being used.

#+begin_src emacs-lisp -i
(use-package vc-backup
  :ensure (:wait t))
#+end_src

** Final backup settings

The last word on backups: the default =backup-directory-alist= points to =backups/= under =sp-var-dir=, backups are made by copying and also for version-controlled files, deleted files are moved to the system trash, and 6 new and 3 old numbered versions are kept. The inline comment on =vc-make-backup-files= says the opposite of what the setting does; t means files under version control are backed up too.

#+begin_src emacs-lisp -i
(setq-default backup-directory-alist
    `(("." . ,(expand-file-name "backups/" sp-var-dir)))
      make-backup-files t
      vc-make-backup-files t ; Won't create backup of files that are already under version control
      backup-by-copying t ; Avoid symlinks
      delete-old-versions t
      delete-by-moving-to-trash t ; This makes sure that the files aren't permanently deleted
      kept-new-versions 6
      kept-old-versions 3
      version-control t)
#+end_src

** No lock files

Disables the =.#file= lock files Emacs creates while a buffer has unsaved changes, which the comment says cause more trouble than they prevent.

#+begin_src emacs-lisp -i
;;; Lockfiles unfortunately cause more pain than benefit
(setq create-lockfiles nil)
#+end_src

* History

** savehist

Enables =savehist-mode=, which saves minibuffer history between sessions, with the history file stored in =sp-var-dir=. The mode is turned on in =:init= and the file is set in =:config=, after the mode has already read its default file, so the first session may read history from the default location.

#+begin_src emacs-lisp -i
;; What do you do with the saved history?
(use-package savehist
  :ensure nil
  :init
  (savehist-mode t)
  :config
  (setq savehist-file (expand-file-name "savehist" sp-var-dir)))
#+end_src
