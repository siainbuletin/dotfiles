This navigation sub-module, loaded by =sp-navi=, configures =consult-snapfile=, a Consult front-end that queries a local file-search server over a websocket. The package is loaded from a local checkout in =~/cloned-utilities/consult-snapfile/emacs= rather than from a package archive, and it needs the =consult= and =websocket= packages plus the snapfile server running on the configured host and port.

** Package

Loads =consult-snapfile= from the local checkout after Consult and websocket are available, and binds =C-c s f= to =consult-snapfile=. If the directory does not exist, the package will not be found.

#+begin_src emacs-lisp -i
(use-package consult-snapfile
  :load-path "~/cloned-utilities/consult-snapfile/emacs"
  :after (consult websocket)
  ;; Optional: bind to your preferred key
  :bind ("C-c s f" . consult-snapfile))
#+end_src

** Server settings

Points the client at the snapfile server on =127.0.0.1= port 9876.

#+begin_src emacs-lisp -i
;; Server settings
(setq consult-snapfile-server-port 9876)
(setq consult-snapfile-server-host "127.0.0.1")
#+end_src

** Result limit

Limits each query to 100 results.

#+begin_src emacs-lisp -i
;; Max results to return
(setq consult-snapfile-max-results 100)
#+end_src
