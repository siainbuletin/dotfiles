Literate source for =libraries/modules/media/sp-reading.el=. Every line of the module lives in the =emacs-lisp= blocks below, in order. The =:tangle= path in the =#+PROPERTY= line at the top of this file says where they are written; see [[file:../../README.org::*Tangling the literate files][Tangling the literate files]] in the README for how to tangle.

The original file has no newline after its last line. Org always ends a tangled file with one, so tangling adds that final newline and changes nothing else.

This module sets up e-book reading: =nov= for reading EPUB files inside Emacs and =calibredb= for browsing a Calibre library. A third reader is left commented out. The module is not in any module list in =init.el=, and =conditional-loading.org= marks it as unconfigured, so it is not currently loaded.

** nov for EPUB

Installs =nov= and opens =.epub= files in =nov-mode=. Text is shown in the default fixed-pitch font rather than a variable-pitch one, and lines are filled to 70 columns.

#+begin_src emacs-lisp -i
(use-package nov
  :ensure t
  :config
  (setq nov-variable-pitch nil
        nov-text-width 70)
  :init
  (add-to-list 'auto-mode-alist '("\\.epub\\'" . nov-mode)))
#+end_src

** calibredb

Configures =calibredb=, deferred until used, to point at the Calibre library in =~/Documents/calibre-library= and its =metadata.db= database. There is no =:ensure= on this block, so the package must be installed some other way. Calibredb needs the =sqlite3= program and, for some actions, Calibre's command-line tools.

#+begin_src emacs-lisp -i
(use-package calibredb
  :defer t
  :config
  (setq calibredb-root-dir "~/Documents/calibre-library")
  (setq calibredb-db-dir "~/Documents/calibre-library/metadata.db")
  )
#+end_src
