The user option denote-dired-directories-include-subdirectories specifies whether the denote-dired-directories also cover their subdirectories. By default they do not. Set this option to t to include subdirectories as well.

The faces we define for this purpose are:

- denote-faces-date
- denote-faces-delimiter
- denote-faces-extension
- denote-faces-keywords
- denote-faces-signature
- denote-faces-subdirectory
- denote-faces-time
- denote-faces-title

For more control, we also provide these:

- denote-faces-year
- denote-faces-month
- denote-faces-day
- denote-faces-hour
- denote-faces-minute
- denote-faces-second

For the time being, the =diredfl= package is not compatible with this facility.

The denote-dired-mode does not only fontify note files that were created by Denote: it covers every file name that follows our naming conventions (The file-naming scheme). This is particularly useful for scenaria where, say, one wants to organise their collection of PDFs and multimedia in a systematic way (and, perhaps, use them as attachments for the notes Denote produces if you are writing Org notes and are using its standand attachments’ facility).

* Saving files by default with denote

The user option denote-save-buffers controls whether commands that create new notes (Points of entry) or rename existing files save their buffer outright (Renaming files). By default, when the value of this user option is nil, buffers are not saved. They are saved when the value is non-nil.[fn:4]

Buffers are named by applying the function specified in the user option denote-rename-buffer-function. The default function is denote-rename-buffer: it renames the buffer based on the template set in the user option denote-rename-buffer-format, combined with the denote-buffer-name-prefix (Set the prefix of all Denote buffers). Other fields are explained elsewhere in this manual (The denote-rename-buffer-format).

Note that renaming a buffer is not the same as renaming a file (Renaming files). The former is just for convenience inside of Emacs. Whereas the latter is for writing changes to disk, making them available to all programs.

You can also format the way that the buffer is renamed with =denote-rename-buffer-format=.

** Prot's new solution

I asked on GitHub for a similar feature for this. Prot wrote a version that aborts the merge between two denote notes if the =OTHER_FILE= has backlinks to it. *Is there really no way to deal with all of the identifiers?*

#+begin_src emacs-lisp :tangle "init.el" :eval never
(defun denote-org--merge-get-file-data-without-front-matter (file)
  "Return data of FILE without its front matter.
Data is of the form (TITLE FILETAGS CONTENTS), all of which are strings.

Assume that front matter is a contiguous region of lines starting with
#+ from the beginning of the buffer and ending in an empty line."
  (with-temp-buffer
    (insert-file-contents file)
    (org-mode)
    (goto-char (point-min))
    (let ((title (org-get-title))
          (tags (org-get-tags))
          (contents (progn
                      (when-let* ((beginning (when (re-search-forward "^#\\+" nil t)
                                               (line-beginning-position)))
                                  (end (re-search-forward "^$" nil t)))
                        (delete-region beginning end))
                      (string-trim (buffer-string)))))
      (list title tags contents))))

;;;###autoload
(defun denote-org-merge-notes (target-file other-file)
  "Append OTHER-FILE to TARGET-FILE and delete OTHER-FILE.
When called interactively TARGET-FILE is the current file.
TARGET-FILE and OTHER-FILE are both derived from `org-mode'.

Abort the operation if OTHER-FILE has backlinks."
  (interactive
   (list
    buffer-file-name
    (denote-file-prompt
     "\\.org"
     (format "FILE to merge into `%s'" (propertize buffer-file-name 'face 'denote-faces-prompt-current-name)))))
  (dolist (file (list target-file other-file))
    (with-current-buffer (find-file-noselect file)
      (unless (derived-mode-p 'org-mode)
        (error "The file `%s' is not using `org-mode'" file))))
  (pcase-let ((`(,title ,tags ,contents) (denote-org--merge-get-file-data-without-front-matter other-file)))
    (if (denote--file-has-backlinks-p other-file)
        (error "The other file `%s' has backlinks; aborting the merge" other-file)
      (with-current-buffer (find-file-noselect target-file)
        (goto-char (point-max))
        (unless (looking-at "^$")
          (insert "\n\n"))
        (insert (format "* MERGED: %s :%s:" title (string-join tags ":")))
        (insert "\n\n")
        (insert contents))
      (when (y-or-n-p (format "Merged `%s'; now DELETE it and its buffer? " (propertize other-file 'face 'denote-faces-prompt-current-name)))
        (kill-buffer (get-file-buffer other-file))
        (delete-file other-file)))))
#+end_src

Added on <2025-11-17 Mon>. The rationale behind this is described in [[denote:20251117T160008][Collecting tasks from a writing project into org-agenda]]. This will work based on the presence of a =:project:= keyword in the =denote= file.

#+begin_src emacs-lisp :tangle "init.el" :eval never
    (defvar my-denote-to-agenda-regexp "_project"
      "Denote file names that are added to the agenda.
    See `my-add-denote-to-agenda'.")

    (defun my-denote-add-to-agenda ()
      "Add current file to the `org-agenda-files', if needed.
    The file's name must match the `my-denote-to-agenda-regexp'.

    Add this to the `after-save-hook' or call it interactively."
      (interactive)
      (when-let* ((file (buffer-file-name))
                  ((denote-file-is-note-p file))
                  ((string-match-p my-denote-to-agenda-regexp (buffer-file-name))))
        (add-to-list 'org-agenda-files file)))

    ;; This will add the file automatically
    (add-hook 'after-save-hook #'my-denote-add-to-agenda)

    (defun my-denote-remove-from-agenda ()
      "Remove current file from the `org-agenda-files'.
    See `my-denote-add-to-agenda' for how to add files to the Org
    agenda."
      (interactive)
      (when-let* ((file (buffer-file-name))
                  ((string-match-p my-denote-to-agenda-regexp (buffer-file-name))))
        (setq org-agenda-files (delete file org-agenda-files))))
#+end_src
