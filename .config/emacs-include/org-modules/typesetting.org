Is there any way to preserve the formatting?

I might need to use =ox-pandoc= for this to work well. This version is good if you want to use the same formatting for the export all the time. There's also the option to pass options for pandoc compilation via the org header: https://github.com/emacsorphanage/ox-pandoc#passing-options-to-pandoc It could be easy to set up with YASnippet.[fn:2]

You need to also set =pandoc= up to generate good looking DOCX files. For this, you need a template document. =pandoc= has to be set up properly with =pacman= in order to behave well. The best way to do a DOCX export with pandoc is to play by its rules. This means that you need to start from its own templates.

To get a document formatted as this reference, you need to run this command in the shell:

#+begin_src shell :eval never
pandoc -o custom-reference.docx --print-default-data-file reference.docx
#+end_src

After this, you should open the ~.docx~ document in the word processor and edit the styles as needed.[fn:2]

#+begin_src emacs-lisp :tangle "init.el" :eval never
;; default options for all output formats
(setq org-pandoc-options '((standalone . t)))
;; cancel above settings only for 'docx' format
(setq org-pandoc-options-for-docx '((standalone . nil)))
;; special settings for beamer-pdf and latex-pdf exporters
(setq org-pandoc-options-for-beamer-pdf '((pdf-engine . "xelatex")))
(setq org-pandoc-options-for-latex-pdf '((pdf-engine . "pdflatex")))
;; special extensions for markdown_github output
(setq org-pandoc-format-extensions '(markdown_github+pipe_tables+raw_html))
#+end_src
