** Configuring =consult=

=consult= is a package made for consulting =completing-read=. =consult-line= is basically indispensible to my workflow, as it allows a kind of search in the buffer that you're used to with =C-f= outside of Emacs.

#+begin_src emacs-lisp :tangle "init.el" :eval never
  (use-package consult)
#+end_src

Consult is also used for the BibTeX mode I have installed.

=consult-line= can be used as a replacement for =isearch= and it functions a lot more like a traditional =CTRL+F= that you know from other projects.

* Minibuffer completion packages
** =vertico=: minibuffer completion candidates

=Vertico= improves the minibuffer completion by showing the candidates in a vertical list, which improves the readability.

#+begin_src emacs-lisp :tangle "init.el" :eval never
  (use-package vertico
    :demand t
    :custom
    (vertico-count 13) ; Number of candidates to display
    (vertico-resize t)
    (vertico-cycle t) ; Once passing the last candidate in the list, it will loop back to the first
    :config
    (vertico-mode))
#+end_src

** =marginalia=: annotations for the commands showing up in the minibuffer

This is basically like adding a spark of documentation to the commands you're about to run. See [[file:manuals.org][Documentation and man-mode configuration]] for more on this issue of discoverability within Emacs.

The scope of =marginalia= is that it brings completion annotations to the commands that you're running.

#+begin_src emacs-lisp :tangle "init.el" :eval never
            (use-package marginalia
              :init
              (marginalia-mode)
              (setf (alist-get 'elpaca-info marginalia-command-categories) 'elpaca))
#+end_src
