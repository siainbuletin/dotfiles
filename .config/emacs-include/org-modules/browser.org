* TODO Making search more integrated with the research workflow

Since you don't want to be distracted during the moment of ideation, but you also want to be able to find information promptly as you're developing ideas, you want to be able to integrate searching into the buffer workflow that you have in Emacs (as well as integrating all of the org-mode goodies).

On the one hand, this can be done with =org-ref='s integration with =OpenAlex=, which makes it possible to search academic documents without actually leaving Emacs.

* Everyting before the browser interface: searching to narrow which pages you want

One way to improve focus would be to take away the part in which you look at potential search candidates in the normal Google search page. Instead, the options will be presented in the buffer (or maybe even within the =universal-launcher=. From there, you can manipulate the buffers as you want --- in any case, you always want to siphon data from the internet into your own boxes on which you can later act upon. This allows a task-based workflow and way of extracting information.

Also, easier integration with search engines by bringing results directly from websites to the front allows you to differentiate between the quality of different sources: you can either get community results (Reddit), video content which is easier to consume (YouTube and alternatives), or you can read a research paper (Google Scholar and OpenAlex) --- in this case, the process of reading is a lot more complicated.

Currently, the only easy implementation for this that I've seen is =consult-omni=, but I unfortunately haven't managed to configure it well, and I keep getting errors.

Adding different interactive commands from the consult-omni-multi, which will just perform a search for everything.

Consulting the web (=consult-omni-web=):

#+begin_src emacs-lisp :tangle no :eval never
  (defvar consult-omni-web-sources (list "gptel"
                                         "Brave"
                                         "elfeed"
                                         "mu4e"
                                         "Wikipedia"
                                         "GitHub"
                                         "Invidious"
                                         ))
  (defun consult-omni-web (&optional initial prompt sources no-callback &rest args)
    "Interactive web search”

  This is similar to `consult-omni-multi', but runs the search on
  web sources defined in `consult-omni-web-sources'.
  See `consult-omni-multi' for more details."
    (interactive "P")
    (let ((prompt (or prompt (concat "[" (propertize "consult-omni-web" 'face 'consult-omni-prompt-face) "]" " Search:  ")))
          (sources (or sources consult-omni-web-sources)))
      (consult-omni-multi initial prompt sources no-callback args)))
#+end_src

*** Configuring autosuggestion at point (another custom setting)

#+begin_src emacs-lisp :tangle "init.el" :eval never
  ;; AutoSuggest at point
  (defun consult-omni-autosuggest-at-point ()
    (interactive)
    (let ((input (or (thing-at-point 'url) (thing-at-point 'filename) (thing-at-point 'symbol) (thing-at-point 'sexp) (thing-at-point 'word))))
      (when (and (minibuffer-window-active-p (selected-window))
                 (equal (substring input 0 1) (consult--async-split-initial nil)))
        (setq input (substring input 1)))
      (consult-omni-brave-autosuggest input)))
#+end_src
