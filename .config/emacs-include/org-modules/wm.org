* Making the minibuffer big enough for reading

This is taken from XahLee: http://xahlee.info/emacs/emacs/emacs_minibuffer_font_size.html

#+begin_src emacs-lisp :tangle "init.el" :eval never
(defun sia-setup-minibuffer ()
  "make minibuffer use larger font size."
  (text-scale-increase 3))

(add-hook 'minibuffer-mode-hook 'sia-setup-minibuffer)
#+end_src

You can also change the global text scale for the current session with =text-scale-increase=. Maybe I could add a hook for any kind of text-mode hook.

#+begin_src emacs-lisp :tangle "init.el" :eval never
(defun sia-setup-text-buffer ()
  "Make the font in the text buffer generally larger."
  (text-scale-increase 4))

(add-hook 'text-mode-hook 'sia-setup-text-buffer)
#+end_src

                window-divider-first-pixel
                window-divider-last-pixel))

(set-face-background 'fringe (face-attribute 'default :background))

* What happens when you want to open a new file?

When clicking on links like the ~denote:~ type, I want to be able to simply open in place, instead of spawning another window there.

The behaviour for opening files is set up with =org-link-frame-setup=.[fn:2] You can set different behaviour depending on the link type that you're following. This is defined here:

#+begin_src emacs-lisp :tangle "init.el" :eval never
  (setq org-link-frame-setup
     '((denote . find-file)
       (vm . vm-visit-folder-other-frame)
       (vm-imap . vm-visit-imap-folder-other-frame)
       (gnus . org-gnus-no-new-news)
       (file . find-file)
       (wl . wl-other-frame)))
#+end_src

** TODO Enabling =perspective-el=

This would basically be better than trying to use the native =switch-to-buffer= functionality or =ibuffer=. For this, you can have different "workspaces", meaning different lists of buffers that you might be working with, which you can set up through =perspective-el=. The package is mostly concerned with the workspace concept.

Works pretty well with EXWM.[fn:3]

Perspectives are also attached to different frames. If you have multiple frames, each of them will have their own set of buffers. So it would be a lot better if it could be integrated with a tiling window manager (see [[id:5cfcd933-68fe-4f6e-9836-8a4fa5c6d064][Integrating Emacs with a tiling window manager]]).

Perspective can also be used for [[id:958d938a-39bf-4c82-b7c5-d9743925ea49][Session management]].

Perspective creation can also be automated through Emacs Lisp.[fn:3]

#+begin_src emacs-lisp :tangle "init.el" :eval never
  (use-package perspective
    :ensure t
    :bind
    ("C-x k" . persp-kill-buffer*) ; this basically replaces the built-in kill buffer command
    :custom
    (persp-mode-prefix-key (kbd "C-c M-p"))  ; pick your own prefix key here
    :init
    (persp-mode))
#+end_src

If you're using Emacs >28, you need to specificy =persp-mode-prefix-key= to be able to use =perspective-el=.

* Session management
:PROPERTIES:
:ID:       958d938a-39bf-4c82-b7c5-d9743925ea49
:END:

If the point is to persist the session across Emacs restarts (for instance when you need to reload the config file)

What I want it to be able to open up Emacs and actually get some essential buffers already on the screen without having to go hunting for them too much. Switching the sessions can be done without affecting the frame geometry.[fn:4]

#+begin_src emacs-lisp :tangle "init.el" :eval never
(use-package easysession
  :ensure t

  :custom
  (easysession-save-interval (* 10 60))  ; Save every 10 minutes

  ;; Display the active session name in the mode-line lighter.
  (easysession-save-mode-lighter-show-session-name t)

  ;; Optionally, the session name can be shown in the modeline info area:
  ;; (easysession-mode-line-misc-info t)

  :init
  ;; Automatically load the session at startup and restore frame size and
  ;; position (geometry)
  (add-hook 'emacs-startup-hook #'easysession-load-including-geometry 102)

  ;; Automatically save the current session every `easysession-save-interval'
  ;; seconds (default: 10 minutes)
  (add-hook 'emacs-startup-hook #'easysession-save-mode 103))
#+end_src

It is recommended to use the following functions:

easysession-switch-to to switch to another session or easysession-load to reload the current one,
easysession-save-as to save the current session as the current name or another name.
To facilitate session management, consider using the following key mappings:

#+begin_src emacs-lisp :tangle "init.el" :eval never
;; Main keybindings
(global-set-key (kbd "C-c sl") 'easysession-switch-to)  ; Load
(global-set-key (kbd "C-c ss") 'easysession-save-as)  ; Save

;; Other keybindings
(global-set-key (kbd "C-c sL") 'easysession-switch-to-and-restore-geometry)
(global-set-key (kbd "C-c sd") 'easysession-delete)
(global-set-key (kbd "C-c sr") 'easysession-rename)
(global-set-key (kbd "C-c sR") 'easysession-reset)
#+end_src
