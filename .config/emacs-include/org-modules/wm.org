* What happens when you want to open a new file?

When clicking on links like the ~denote:~ type, I want to be able to simply open in place, instead of spawning another window there.

The behaviour for opening files is set up with =org-link-frame-setup=.[fn:2] You can set different behaviour depending on the link type that you're following. This is defined here:

#+begin_src emacs-lisp :tangle "init.el" :eval never
  (setq org-link-frame-setup
     '((denote . find-file)
       (vm . vm-visit-folder-other-frame)
       (vm-imap . vm-visit-imap-folder-other-frame)
       (gnus . org-gnus-no-new-news)
       (file . find-file)
       (wl . wl-other-frame)))
#+end_src

* Configuring tab management

What's really good about =tab-bar-mode= in Emacs is that it allows more than one buffer per tab (and you can switch between them), and you can even have a window split set up for each tab. So they're "higher level" than your average tab bar, in reality. A window can be split in multiple ways, and then be given a name to switch to (which is more ergonomic, overall).

I want each new tab that I open to actually open in the [[file:dashboard.org][Dashboard mode]].

#+begin_src emacs-lisp :tangle "init.el" :eval never
(setq tab-bar-new-tab-choice "*dashboard*")
(setq tab-bar-new-tab-to 'right)
#+end_src

Configuring buffer groups with the tab bar

#+begin_src emacs-lisp :tangle no :eval never
(defun centaur-tabs-buffer-groups ()
  "`centaur-tabs-buffer-groups' control buffers' group rules.

Group centaur-tabs with mode if buffer is derived from `eshell-mode' `emacs-lisp-mode' `dired-mode' `org-mode' `magit-mode'.
All buffer name start with * will group to \"Emacs\".
Other buffer group by `centaur-tabs-get-group-name' with project name."
  (list
   (cond
    ((or (string-equal "*" (substring (buffer-name) 0 1))
         (memq major-mode '(magit-process-mode
                            magit-status-mode
                            magit-diff-mode
                            magit-log-mode
                            magit-file-mode
                            magit-blob-mode
                            magit-blame-mode
                            )))
     "Emacs")
    ((derived-mode-p 'prog-mode)
     "Editing")
    ((derived-mode-p 'dired-mode)
     "Dired")
    ((memq major-mode '(helpful-mode
                        help-mode))
     "Help")
    ((memq major-mode '(org-mode
                        org-agenda-clockreport-mode
                        org-src-mode
                        org-agenda-mode
                        org-beamer-mode
                        org-indent-mode
                        org-bullets-mode
                        org-cdlatex-mode
                        org-agenda-log-mode
                        diary-mode))
     "Org")
    (t
     (centaur-tabs-get-group-name (current-buffer))))))
#+end_src

** TODO Enabling =perspective-el=

This would basically be better than trying to use the native =switch-to-buffer= functionality or =ibuffer=. For this, you can have different "workspaces", meaning different lists of buffers that you might be working with, which you can set up through =perspective-el=. The package is mostly concerned with the workspace concept.

Works pretty well with EXWM.[fn:3]

Perspectives are also attached to different frames. If you have multiple frames, each of them will have their own set of buffers. So it would be a lot better if it could be integrated with a tiling window manager (see [[id:5cfcd933-68fe-4f6e-9836-8a4fa5c6d064][Integrating Emacs with a tiling window manager]]).

Perspective can also be used for [[id:958d938a-39bf-4c82-b7c5-d9743925ea49][Session management]].

Perspective creation can also be automated through Emacs Lisp.[fn:3]

#+begin_src emacs-lisp :tangle "init.el" :eval never
  (use-package perspective
    :ensure t
    :bind
    ("C-x k" . persp-kill-buffer*) ; this basically replaces the built-in kill buffer command
    :custom
    (persp-mode-prefix-key (kbd "C-c M-p"))  ; pick your own prefix key here
    :init
    (persp-mode))
#+end_src

If you're using Emacs >28, you need to specificy =persp-mode-prefix-key= to be able to use =perspective-el=.

** Switching buffers across a window split in Emacs

#+begin_src emacs-lisp :tangle "init.el" :eval never
(defun transpose-buffers (arg)
  "Transpose the buffers shown in two windows."
  (interactive "p")
  (let ((selector (if (>= arg 0) 'next-window 'previous-window)))
    (while (/= arg 0)
      (let ((this-win (window-buffer))
            (next-win (window-buffer (funcall selector))))
        (set-window-buffer (selected-window) next-win)
        (set-window-buffer (funcall selector) this-win)
        (select-window (funcall selector)))
      (setq arg (if (plusp arg) (1- arg) (1+ arg))))))

(global-set-key (kbd "C-x t b") 'transpose-buffers)
#+end_src

  (easysession-save-mode-lighter-show-session-name t)

  ;; Optionally, the session name can be shown in the modeline info area:
  ;; (easysession-mode-line-misc-info t)

  :init

  ;; position (geometry)
  (add-hook 'emacs-startup-hook #'easysession-load-including-geometry 102)

It is recommended to use the following functions:
