* Appearance of the emacs buffer
** Configuring =mixed-pitch= mode

Mixed pitch (variable pitch) for org buffers means that written prose is displayed in variable pitch, while metadata, code and other items are in fixed pitch. A hook is a construction in Emacs that associates modes with each other. In this case, variable pitch text is enabled for all text mode buffers.

#+begin_src emacs-lisp :tangle "init.el"
  (use-package mixed-pitch
    :hook
    (org-mode . mixed-pitch-mode))
#+end_src

** TODO Configuring =text-mode=

Text mode allows replacing text when you start typing. _This is taken directly from Emacs Writing Studio_.

#+begin_src emacs-lisp :tangle "init.el" :eval never
  (use-package text-mode
    :ensure nil
    ;; :hook
    ;; (text-mode . visual-line-mode) ; Would this function enable text mode in all text buffers, and not just org-mode?
    :init
    (delete-selection-mode t)
    :custom
    (sentence-end-double-space nil)
    (scroll-error-top-bottom t)
    (save-interprogram-paste-before-kill t))
#+end_src

This section also redefines the way Emacs defines a sentence (refer to section #sec-count in Emacs Writing Studio).

=save-interprogram-paste-before-kil= saves any existing clipboard text into the kill ring for better operability between the operating system's clipboard and Emacs's kill ring.

** TODO Spellchecking support

The Flyspell package interfaces with the Hunspell software and the relevant dictionary to check spelling on the fly.

Flyspell is built-in, so you have to change the way that it is called from =elpaca=.

*I currently can't get this one to work because I can't make =elpaca= not try to install it, despite it being actually built in.*

You must change the standard dictionary to your local variety by customising  the ~ews-hunspell-dictionaries~  variable. EWS uses this particular variable because the dictionaries are set in two places to enable multilingual spelling. You can set multiple dictionaries for the same buffer. In my configuration I use ="en_AU,nl_NL"= so I can write in either the Australian variant of English or Dutch without having to change dictionaries. Section #sec-spelling in Emacs Writing Studio explains how to use this package.

#+begin_src emacs-lisp :tangle no :eval never
  (use-package flyspell
    :custom
    (ispell-program-name "hunspell")
    (ispell-dictionary ews-hunspell-dictionaries)
    (flyspell-mark-duplications-flag nil) ;; Writegood mode does this
    (org-fold-core-style 'overlays) ;; Fix Org mode bug
    :config
    (ispell-set-spellchecker-params)
    (ispell-hunspell-add-multi-dic ews-hunspell-dictionaries)
    :hook
    (text-mode . flyspell-mode)
    :bind
    (("C-c w s s" . ispell)
     ("C-;"       . flyspell-auto-correct-previous-word)))
#+end_src
